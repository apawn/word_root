# 4232 · -wave — 音乐、文化潮流的类型标签

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

现代音乐名称中 -wave 的类比使用与 new wave 等既有词有关，后又在 chillwave、vaporwave 等名称中发展。

**-WAVE：从浪潮的比喻进入风格命名**

vaporwave 是蒸汽波音乐、视觉美学；名字里的 wave 延续一种风格、潮流的比喻，不是物理波的分类。

- **电子音乐与视觉美学名称**：vaporwave

## 词形与演化规律

既有音乐风格的 wave 材料 → -wave；vaporware 的部分词形 + -wave → vaporwave。每个流派的名称还有自己的文化背景。

## 逐词讲解

### 1. vaporwave — 蒸汽波〔电子音乐及视觉美学类型〕

**音标**：英 /ˈveɪpəweɪv/；美 /ˈveɪpərweɪv/

**先抓住这个画面**

怀旧的电子声、经过处理的旧音乐片段，加上早期电脑、商场广告般的视觉气氛，是蒸汽波常让人想到的画面。

**怎么拆**

vapor(ware) 相关截短材料 + 音乐风格词尾 -wave，形成二十一世纪初期的类型名称。vaporware 原指宣传过却迟迟未推出的软件等产品。

**怎么变成今天的意思**

**音乐分类中的 -wave 与 vaporware 相关材料**  
近代网络文化的类比造词

↓

**vaporwave**  
一类电子音乐及相邻视觉美学

vaporwave music 蒸汽波音乐；a vaporwave aesthetic 蒸汽波美学。类型作品多样，名称不规定每张图必须使用同一颜色或元素。

**常见搭配与例句**

a vaporwave album；vaporwave artwork。

> The playlist includes several vaporwave tracks.

歌单里有几首蒸汽波曲目。

> The artwork combines old computer graphics with a vaporwave aesthetic.

这幅作品把旧电脑图形和蒸汽波美学结合起来。

**别混淆**

这里的 wave 给流派、风格关系；vaporwave 不是一般蒸汽形成的物理波。中文蒸汽波是固定文化名称。

## 这一组要分清什么

共同末尾只是类型命名模式，不说明所有 -wave 作品声音一样。vaporwave 的复古、数字文化特点要从完整风格理解。
