# 4066 · hexa- — 六

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

经拉丁化 hexa- 接希腊 hex 六。hexadecimal 是现代技术词，借六、十的材料表达十六这一进制。

**HEXA-：从六这个数量认识十六进制的前半**

hexadecimal 不是六进制，而是十六进制；hexa- 六与 decimal 里的十这一材料组合，形成完整名称。

- **十六进制及相关表示**：hexadecimal

## 词形与演化规律

hexa- 六 + decimal 十相关 → hexadecimal；相应实际用法以 0–9 和 A–F 表示十六种数码。

## 逐词讲解

<a id="w-1"></a>

### 1. hexadecimal — 十六进制的；十六进制表示

**音标**：英 /ˌheksəˈdesɪməl/；美 /ˌheksəˈdesəməl/

**先抓住这个画面**

十个数字符号不够，再借六个字母，一共凑成十六个符号。

**怎么拆**

hexa- 六 + decimal 十进制的；这个现代混合造词指六加十，不是六乘十。

**怎么变成今天的意思**

**拉丁 decem → decimus／decima**  
十 → 第十、十分之一

↓

**拉丁 decimalis → 英语 decimal；希腊 hexa- 六**  
十进制词基 + 六

↓

**现代英语 hexadecimal**  
以十六为基数的记数法

常用符号是 0—9 和 A—F，A 表十，F 表十五，再往上进位。十六进制的 10 表示十进制的十六；外形一样，不代表数值一样。网页颜色代码中经常遇到这种写法。

**常见搭配与例句**

a hexadecimal number；hexadecimal notation；a hexadecimal color code。

> The color is stored as a hexadecimal code.

这个颜色以十六进制代码存储。

> In hexadecimal notation, F represents the decimal value fifteen.

在十六进制表示法里，F 代表十进制数值十五。

**别混淆**

decimal 基数十，binary 基数二，hexadecimal 基数十六。十六进制的 hex 缩写与“诅咒”那个 hex 不同源。

## 这一组要分清什么

hexa- 单独给六，但完整 hexadecimal 是十六进制。拆分帮助记词，最终要按固定的技术定义理解。

## 串起来练习

The colour is written as a hexadecimal code.

这个颜色用十六进制代码表示。
