# 2105 · -bot — 自动程序、机器人相关的缩短材料

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

bot 从 robot 截短；robot 更早借自捷克语，其词族与劳动有关。截短后的 bot 又进入聊天、搜索等现代复合。

**-BOT：把某种任务交给自动执行的主体**

chatbot 的 chat 给任务：聊天、对话。bot 给执行者：一个自动回应的软件系统。

- **完整名称与缩短**：robot · bot
- **对话任务的自动系统**：chatbot
- **robot → bot → bots：软件自动执行者的短称**：bot · bots

## 词形与演化规律

robot → bot；chat 聊天 + bot → chatbot。长词变短，再拿短词参与复合，是现代构词常见路径。

现代网络 bot 缩略 robot；bots 是多个自动程序、软件代理。词形与老虫名 bot 相同，不表示网络程序从虫名直接演变，现代任务也可能有益或有害。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [robot](#w-2) | 英 /ˈrəʊbɒt/；美 /ˈroʊbɑːt/ | 机器人；机械重复、缺乏个人反应的人〔比喻〕 |
| [bot](#w-3) | 英 /bɒt/；美 /bɑːt/ | 自动程序、机器人程序；机器人〔robot 的口语缩短〕 |
| [bots](#w-4) | 英 /bɒts/；美 /bɑts/ | 自动程序、机器人账号；软件机器人〔复数〕 |
| [chatbot](#w-1) | 英 /ˈtʃætbɒt/；美 /ˈtʃætbɑːt/ | 聊天机器人、自动对话程序 |

## 逐词讲解

<a id="w-2"></a>

### 1. robot — 机器人；机械重复、缺乏个人反应的人〔比喻〕

**音标**：英 /ˈrəʊbɒt/；美 /ˈroʊbɑːt/

**先抓住这个画面**

先想被安排来做任务的人工劳动者，后来成为自动执行任务的机器名称。它可以是工厂机械臂，不必长着人的脸。

**怎么拆**

借捷克语 robot，接 robota 苦役、强制劳动。卡雷尔·恰佩克的戏剧 R.U.R. 让这个词传播，名称建议来自兄弟约瑟夫；不是英语 rob 抢 + ot。

**怎么变成今天的意思**

**捷克语 robota**  
苦役、强制劳役、繁重劳动

↓

**恰佩克兄弟与戏剧 R.U.R. → robot**  
以人工劳动者命名；由卡雷尔的戏剧传播，约瑟夫建议这一名称

↓

**现代英语 robot → robotic / robotics**  
执行任务的机器；相关性质、设计和应用领域

an industrial robot 工业机器人，a cleaning robot 清洁机器人，a robot arm 机械臂，act like a robot 像机器一样反应。

**常见搭配与例句**

an industrial robot；a cleaning robot；a robot arm。

> The factory uses robots to move heavy parts.

工厂用机器人搬运重型零件。

> The actor deliberately spoke like a robot.

演员故意像机器人一样说话。

**别混淆**

robot 不必像人，也不必具有人的意识。原剧人工劳动者和后来金属机械的典型形象有变化；软件 bot 又是相关缩称扩展，不能把所有机器人都限定同一种机身。

<a id="w-3"></a>

### 2. bot — 自动程序、机器人程序；机器人〔robot 的口语缩短〕

**音标**：英 /bɒt/；美 /bɑːt/

**先抓住这个画面**

群里自动回答问题、网站上自动处理重复任务的程序，都可能叫 bot。先记住有些动作由程序自动做。

**怎么拆**

计算机及机器人用法由 robot 截短，保留后半 bot；robot 更早借自捷克语。英语还有来源不同的同形旧词，不能混进这条自动程序历史。

**怎么变成今天的意思**

**robot → bot**  
截去前部形成短词

↓

**计算机 bot 的扩展**  
自动执行任务的软件；相应程序账户

a search bot 搜索机器人；a moderation bot 管理机器人；a game bot 游戏程序角色等。bot 可以有益，也可以被滥用，词本身不保证目的和能力。

**常见搭配与例句**

an automated bot；a bot account；build a bot。

> The bot posts a reminder every morning.

这个机器人程序每天早晨发布一条提醒。

> A chatbot answers common questions on the website.

网站上的聊天机器人回答常见问题。

**别混淆**

bot 范围比 chatbot 广：聊天机器人是其中一种。普通脚本也能自动运行，但 bot 往往被当作持续执行任务、与平台或用户交互的主体。

<a id="w-4"></a>

### 3. bots — 自动程序、机器人账号；软件机器人〔复数〕

**音标**：英 /bɒts/；美 /bɑts/

**先抓住这个画面**

自动回答、抓取或执行任务的程序，常叫 bots。它们可以没有手脚，只是在软件里代人反复做事。

**怎么拆**

现代网络 bot 缩略 robot；bot + -s → bots，/t/ 后读 /s/。老词 bot 还有虫类等不同来源，网络义不靠那条虫名路线解释。

**怎么变成今天的意思**

**robot → 缩略 bot**  
机器人形象借给自动执行任务的软件

↓

**bot + -s → bots**  
多个自动程序、软件代理；作用可能不同

chat bots 是聊天机器人；search bots 是搜索自动程序；automated bots 是自动化程序；social media bots 是社交平台机器人账号。

**常见搭配与例句**

chat bots；search bots；social media bots。

> The website uses bots to answer simple questions.

网站用机器人程序回答简单问题。

> Some comments were posted by bots.

有些评论是机器人账号发布的。

**别混淆**

bots 不自动等于骗子账号：有的提供服务，有的制造垃圾内容。是否有害要看具体行为，词本身先说明自动执行。

<a id="w-1"></a>

### 4. chatbot — 聊天机器人、自动对话程序

**音标**：英 /ˈtʃætbɒt/；美 /ˈtʃætbɑːt/

**先抓住这个画面**

用户发一句，它回一句，界面像聊天；bot 说软件代理，不要求背后站着一个金属身体的机器人。

**怎么拆**

chat 聊天 + bot〔robot 的缩短形式〕，与较早 chatterbot 名称相关。不是 chat 先变出 robot，两个成分并列组成名称。

**怎么变成今天的意思**

**中古英语 chateren 等拟声词 → chatter**  
叽叽喳喳、快速细碎发声

↓

**chatter 缩短 → chat**  
较轻松、随意地聊

↓

**chat + bot → chatbot；另有较早 chatterbot**  
通过对话交互的软件程序

a customer service chatbot 客服聊天机器人，talk to a chatbot 与聊天机器人对话，a chatbot response 对话程序的回复。

**常见搭配与例句**

a customer service chatbot；talk to a chatbot；a chatbot response。

> The website uses a chatbot to answer common questions.

网站用聊天机器人回答常见问题。

> The chatbot asked which product I needed help with.

聊天机器人问我需要哪个产品的帮助。

**别混淆**

chatbot 说交互形式和程序角色，不保证一定用现代大模型；bot 的范围也比聊天程序大。

## 这一组要分清什么

bot 不一定有实体身体，也不一定使用生成式人工智能；chatbot 特别把任务限定到对话，具体能力因系统而异。

## 串起来练习

The chatbot helps visitors find opening hours.

聊天机器人帮助访客查询开放时间。
