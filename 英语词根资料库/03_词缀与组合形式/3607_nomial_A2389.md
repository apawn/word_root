# 3607 · -nomial — 数学名目、项的命名后部

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

binomial 的学术拉丁形式与 nomen 名称、名目相关，是主流词源分析之一；更早也有希腊 nomos 部分等分析。polynomial 参照这组模式构词。

**-NOMIAL：在固定数学词里，前面数有几项**

binomial 常说二项式，polynomial 常说多项式；这里后部帮助形成数学名称，不是一个日常独立单词。

- **二项、多项式名称**：binomial · polynomial

## 词形与演化规律

bi- 二 + 学术名词材料 → binomial；poly- 多 + -nomial → polynomial。实际历史不宜简单全写成英语前缀加独立名词。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. polynomial — 多项式；多项式的

**音标**：英 /ˌpɒlɪˈnəʊmiəl/；美 /ˌpɑːliˈnoʊmiəl/

**先抓住这个画面**

把有限个合乎规则的代数项相加，得到的一类式子。

**怎么拆**

poly-“多” + -nomial，仿照 binomial 构成。主流词源把 binomial 接到拉丁 nomen“名字、名目”；另有希腊 nomos“份额、部分”的分析，但不能因此直接并入 nomos“法则”词族。

**怎么变成今天的意思**

**拉丁语 nomen → binomius；英语 binomial**  
名字、名目 → 有两个名目；数学中指二项式

↓

**英语 poly- + -nomial → polynomial**  
仿二项式名称形成的多项式名称

例如 2x² + 3x + 1，有三项：2x²、3x、1。变量的指数必须是非负整数，项数有限；所以 1/x 不是关于 x 的 polynomial。英语数学定义也包括只有一项的情形，不能因为 poly 表“多”就硬性要求至少两项。

**常见搭配与例句**

a polynomial in x；a quadratic polynomial；a polynomial function；factor a polynomial。

> The polynomial x² + 2x + 1 can be written as (x + 1)².

多项式 x² + 2x + 1 可以写成 (x + 1)²。

> A polynomial function can be used to model the curve over a limited interval.

可以用多项式函数来拟合有限区间内的那段曲线。

**别混淆**

项数和次数不同：2x² + 3x + 1 有三项，但最高次数是 2。polynomial 是式子；把它设为零，例如 x² − 1 = 0，才得到相应的 polynomial equation。

<a id="w-2"></a>

### 2. binomial — 二项式；双名的；由两部分组成的物种学名

**音标**：英 /baɪˈnəʊmiəl/；美 /baɪˈnoʊmiəl/

**先抓住这个画面**

抓住“两个名称或项放在一起”。数学里是两个项，生物命名里则是属名加上第二个名称部分。

**怎么拆**

接中世纪／新拉丁 binomium、binomius，和 bi-“两”及“名称”这一构词背景相关。MW 将其接拉丁 binominis、nomen；更早形式分析另有分歧，因此不把现代英语 bi + 一个独立 nomial 当完整历史。

**怎么变成今天的意思**

**拉丁 bi-；bis；bini**  
两、双；两次；两个一组

↓

**中世纪拉丁 binomius／binomium；后用于新拉丁**  
两个名称或项；常接拉丁 nomen“名字”解释

↓

**英语 binomial**  
数学的二项式；用于由两部分组成的物种学名

x + 3 是一个简单的二项式。binomial nomenclature 是双名法，例如物种学名由属名和种加词等第二部分组成。这里的“二”数的是项或名称部分，不是二进制数字。

**常见搭配与例句**

a binomial expression；the binomial theorem；binomial nomenclature。

> The teacher asked us to expand the square of the binomial x + 3.

老师让我们展开二项式 x + 3 的平方。

> The guide explains why scientific species names follow a binomial system.

指南解释了为什么物种学名采用双名系统。

**别混淆**

binary 是二元、二进制；binomial 是两个项或名称部分。x + 3 可以是 binomial，却不是在说这个式子用二进制表示。

## 这一组要分清什么

这里的项与学术名称背景要看数学语境；不能因为相近字母就直接并入 nomos 法则的另一词族。
