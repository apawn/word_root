# 3575 · -scopic — 观察、检测方式相关的形容词

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

与 -scope 观察装置、-scopy 观察方法及 -ic 形容词材料相连，远接希腊 skopein 看、观察。现代科学按各领域形成对应。

**-SCOPIC：与怎样看、怎样检测有关**

telescopic 联系望远镜，endoscopic 联系内窥观察，spectroscopic 联系光谱分析，macroscopic 则联系肉眼可见的宏观层面。

- **远处、内部的观察**：telescopic · endoscopic
- **光谱与宏观层面**：spectroscopic · macroscopic

## 词形与演化规律

-scope／-scopy → -scopic 是学习对应；具体词可能从相应学术形容词借入，也可能在现代语言中构成。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. telescopic — 望远镜的；可伸缩的

**音标**：英 /ˌtelɪˈskɒpɪk/；美 /ˌtelɪˈskɑːpɪk/

**先抓住这个画面**

可以说看远处，也可以说像旧式望远镜的套筒一样一节缩进另一节。

**怎么拆**

telescope + -ic，去词尾 e；伸缩义来自仪器套管结构，不是任何 tele- 都有伸缩义。

**怎么变成今天的意思**

**希腊 skopein / skopos**  
观察；观察者、注视的目标；与 skeptesthai 观察、审视同源

↓

**希腊 tēle 远 + 观察词干 → 意大利 telescopio／近代拉丁 telescopium → 英语 telescope**  
望远镜

↓

**英语 telescope + -ic → telescopic**  
望远镜的；引申为套管式伸缩的

telescopic observations 是望远镜观测；a telescopic handle 是伸缩把手。读到后者时，别去找把手上的光学镜片。

**常见搭配与例句**

a telescopic handle；a telescopic sight；telescopic observations。

> The suitcase has a telescopic handle.

这个行李箱带有伸缩拉杆。

> Telescopic observations revealed details invisible to the naked eye.

望远镜观测显示了肉眼看不到的细节。

**别混淆**

extendable 泛指能伸长；telescopic 特别让人想到各节套接、滑动伸缩。

<a id="w-2"></a>

### 2. spectroscopic — 光谱的；光谱学、光谱分析的

**音标**：英 /ˌspektrəˈskɒpɪk/；美 /ˌspektrəˈskɑːpɪk/

**先抓住这个画面**

把光里的信息摊成一排谱线或强弱分布，再用它研究物质；spectroscopic 描写与这类谱观察、分析有关的方法、证据。

**怎么拆**

由 spectro- 谱与 -scopic 观察的相应形式构成，也有法语 spectroscopique 的借词对应。spectro- 接拉丁 spectrum 形象、呈现等词族，-scopic 接希腊 skopein 观察。

**怎么变成今天的意思**

**拉丁 spectrum 材料与希腊观察材料进入科学构词**  
谱与观察两层关系

↓

**spectro- + -scopic；法语相应形式**  
与光谱观察、分析有关的性质

spectroscopic analysis 光谱分析；spectroscopic evidence 光谱证据；spectroscopic methods 光谱方法。并不局限于人眼能看到的彩色条纹。

**常见搭配与例句**

spectroscopic data；spectroscopic observations。

> The researchers presented spectroscopic evidence for the compound’s structure.

研究人员展示了支持该化合物结构的光谱证据。

> The laboratory uses spectroscopic methods to study the sample.

实验室用光谱方法研究样品。

**别混淆**

spectroscopy 是学科、分析活动名词，spectroscopic 是相关性质；spectrometer 则是测谱仪器的名称。

<a id="w-3"></a>

### 3. endoscopic — 内镜的；借助内镜完成的

**音标**：英 /ˌendəʊˈskɒpɪk/；美 /ˌendoʊˈskɑːpɪk/

**先抓住这个画面**

说明某次检查、操作或图像用到了内镜。

**怎么拆**

endo- + -scopic；也可与 endoscope + -ic 对照，不是 endoscopy 后再直接拼 -ic。

**怎么变成今天的意思**

**希腊 skopein / skopos**  
观察；观察者、注视的目标；与 skeptesthai 观察、审视同源

↓

**近代医学 endo- 内部 + -scope → endoscope**  
向身体内部观察的仪器

↓

**英语 endoscope / endo- + -scopic → endoscopic**  
内镜设备 → 与内镜检查或操作有关的

endoscopic images 是内镜图像；an endoscopic procedure 是借助内镜进行的操作。这个形容词说明手段，不单独说明具体部位和目的。

**常见搭配与例句**

endoscopic examination；endoscopic images；an endoscopic procedure。

> The report includes several endoscopic images.

报告包含几幅内镜图像。

> The team discussed the findings from the endoscopic examination.

团队讨论了内镜检查的发现。

**别混淆**

endoscopic 不必等于纯检查，内镜也可用于某些治疗；surgical 则说明与外科手术有关。

<a id="w-4"></a>

### 4. macroscopic — 宏观的；肉眼可见尺度的

**音标**：英 /ˌmækrəˈskɒpɪk/；美 /ˌmækrəˈskɑːpɪk/

**先抓住这个画面**

把视野退远一些，看普通尺度上的整体表现。

**怎么拆**

macro- 大 + -scopic，仿 microscopic 构成；不必先假设有一个英语 macroscope 才能产生它。

**怎么变成今天的意思**

**希腊 skopein / skopos**  
观察；观察者、注视的目标；与 skeptesthai 观察、审视同源

↓

**英语 macro- + microscopic 的后半形式 → macroscopic**  
与显微尺度相对的宏观尺度

macroscopic changes 是肉眼或普通尺度上能观察的变化；macroscopic properties 可说物质整体表现出的性质。与 microscopic 的大小是相对比较，不一定意味着巨大。

**常见搭配与例句**

macroscopic changes；macroscopic properties；the macroscopic scale。

> No macroscopic cracks were visible on the surface.

表面看不见肉眼可辨的裂纹。

> The model connects molecular motion with macroscopic properties.

这个模型把分子运动与宏观性质联系起来。

**别混淆**

microscopic 关注微小结构；macroscopic 关注较大尺度的整体。macroeconomic 则专门属于宏观经济学。

## 这一组要分清什么

不都表示拿某一种镜子看；spectroscopic 常说分析方法，macroscopic 常直接说肉眼尺度。先看前部和完整搭配。

## 串起来练习

The report compares macroscopic observations with spectroscopic measurements.

报告比较了宏观观察与光谱测量。
