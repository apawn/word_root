# 3494 · giga- — 十亿倍；普通命名中的巨大规模

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

来自希腊 gigas 巨人，与 giant 的历史相关；近代科学约定单位前缀为十亿倍，商业等新词又借它强调规模。

**GIGA-：计量时精确到十亿，普通词可强调巨大**

gigabit 是十亿比特，gigabyte 是十亿字节；gigafactory 说超大工厂，通常不是精确在数十亿座工厂。

- **数据计量**：gigabit · byte · gigabyte
- **巨大规模命名**：gigafactory
- **giga-：从巨人的词源材料到十亿倍**：gigabytes

## 词形与演化规律

giga- + bit／byte → gigabit／gigabyte；giga- + factory → gigafactory。计量单位和一般命名的解释层次分开。

giga- 名称接希腊 gigas 巨人，在现代十进制 GB 中表示十亿倍。GiB 则明确表示二进制量，不能把二者拼写差别当装饰。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-4"></a>

### 1. byte — 字节

**音标**：/baɪt/

**先抓住这个画面**

电脑存数据时的一小组二进制位，现代通常八个 bit 合成一 byte；它像一个常用的小包装单位。

**怎么拆**

近代计算机术语，把 bite 咬下一小块的拼写改成 byte，以免与 bit 混淆。它是命名变形，不是 by 加表示技术的 -te。

**怎么变成今天的意思**

**bite 的小口、小块命名意象**  
计算机早期数据分组的命名材料

↓

**改拼 byte**  
字节，现代通常为八比特

one byte 一个字节；a byte of data 一个字节的数据；byte size 字节大小。符号常用大写 B，小写 b 通常表示 bit。

**常见搭配与例句**

read a byte；bytes of data。

> The program reads one byte at a time.

程序每次读取一个字节。

> Eight bits make up one byte in this format.

在这种格式中，八个比特组成一个字节。

**别混淆**

byte 读 /baɪt/，bit 读 /bɪt/；现代八比特对应一字节，历史上 byte 的长度曾有其他约定。

<a id="w-2"></a>

### 2. gigabyte — 吉字节；通常十亿字节

**音标**：/ˈɡɪɡəbaɪt/

**先抓住这个画面**

byte 太小，文件、存储空间一大就改用 gigabyte 计数；现代十进制的一 GB 是十亿字节。

**怎么拆**

giga- 十亿倍 + byte 字节，形成数据容量单位。计算机历史中也曾以这个名称指二进制的 2 的三十次方字节；现代 GiB 可明确表示后者。

**怎么变成今天的意思**

**giga- + byte → gigabyte**  
用十亿倍率放大字节单位

↓

**容量标记的现代区分**  
GB 通常十亿字节；GiB 明确二进制量

a file of two gigabytes 两吉字节文件；gigabytes of storage 以吉字节计的存储空间。阅读设备、系统显示时留意采用的计数习惯。

**常见搭配与例句**

a few gigabytes；storage in gigabytes。

> The video file takes up two gigabytes of storage.

这个视频文件占用两吉字节存储空间。

> The program displays file sizes in gigabytes.

程序以吉字节显示文件大小。

**别混淆**

gigabit 计比特，gigabyte 计字节；在相同十进制前缀下，一 gigabyte 对应八 gigabits。不要只看首字母 G。

<a id="w-5"></a>

### 3. gigabytes — 吉字节；十进制每单位十亿字节〔日常常说G〕

**音标**：英 /ˈɡɪɡəbaɪts/；美 /ˈɡɪɡəˌbaɪts/

**先抓住这个画面**

手机还剩多少空间、视频占了多少容量，常用 gigabytes。把字节成十亿地计，就能用较小数字说很大的数据量。

**怎么拆**

giga- 十亿 + byte 字节 → gigabyte；加复数 -s → gigabytes，词尾 /ts/。giga- 的命名材料接希腊 gigas 巨人。

**怎么变成今天的意思**

**希腊 gigas 巨人 → 计量 giga- 十亿倍**  
现代倍率有严格约定

↓

**gigabyte + -s → gigabytes**  
十进制 GB；与明确二进制的 GiB 区分

several gigabytes of video 是几吉字节的视频；free gigabytes 是可用空间。十进制 GB 为十亿字节，GiB 为2的30次方字节，旧显示可能混称。

**常见搭配与例句**

several gigabytes of video；free space in gigabytes；a few gigabytes left。

> The videos take up several gigabytes.

这些视频占了几吉字节空间。

> I still have twenty gigabytes of free space.

我还有二十吉字节的可用空间。

**别混淆**

同一堆数据换用 GB、GiB 显示，数字可以不同；不能仅凭数字变小就判断数据丢失。

<a id="w-1"></a>

### 4. gigabit — 吉比特；十亿比特

**音标**：/ˈɡɪɡəbɪt/

**先抓住这个画面**

把一个个比特按十亿个一组来计数。

**怎么拆**

giga- 国际单位制中的十亿倍前缀 + bit 比特。这里的 bit 来自 binary digit，而不是把食物小块放大。

**怎么变成今天的意思**

**giga- 十亿倍；bit 比特**  
并列构词部分

↓

**gigabit**  
十亿比特的数据量单位

one gigabit 是十亿比特；a gigabit per second 是每秒十亿比特，常见缩写 Gbit/s 或 Gbps。网络标称速率与实际应用传输速度不必完全相同。

**常见搭配与例句**

gigabits per second；a gigabit connection；gigabit Ethernet。

> The brochure advertises a gigabit connection.

宣传册介绍了一种吉比特连接。

> The diagram labels the link in gigabits per second.

图中把链路速率标成每秒多少吉比特。

**别混淆**

gigabit 的 b 是 bit，gigabyte 是字节；不要把广告里的1 Gbps 直接理解成每秒1 GB。

<a id="w-3"></a>

### 5. gigafactory — 超大型工厂

**音标**：/ˈɡɪɡəˌfæktəri/

**先抓住这个画面**

把制造规模放大到庞大的厂区和生产线，尤其在电池制造报道里，常会看到 gigafactory。

**怎么拆**

giga- 原是表示十亿倍的前缀，+ factory；现代产业语境借它突出巨大规模。

**怎么变成今天的意思**

![gigafactory 的词源演化](../assets/evolution/gigafactory-5badc1f4.svg)

这里的 giga 不保证厂里有十亿台机器或统一规定的产能，名称常与大规模电池生产及相关宣传语境相连。

**常见搭配与例句**

a battery gigafactory；build a gigafactory。

> The report describes a planned battery gigafactory.

报告介绍了一座规划中的超大型电池工厂。

> The gigafactory will require extensive power and transport infrastructure.

这座超大型工厂需要大规模供电和运输基础设施。

**别混淆**

factory 是通用工厂；gigafactory 强调巨大规模，是较新的产业用词。

## 这一组要分清什么

byte 与 bit 的基本单位不同；GB、GiB 还可明确区分十进制和二进制容量。普通词 gigafactory 则不按这些容量规则理解。

## 串起来练习

The application shows storage in gigabytes and network speed in gigabits per second.

应用用吉字节显示存储空间，用每秒吉比特显示网络速度。
