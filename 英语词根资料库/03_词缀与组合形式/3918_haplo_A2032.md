# 3918 · haplo- — 单一、一套

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

来自希腊 haploos 单一、简单，进入近代细胞学、遗传学术语。-ploid 是相应组数的科学命名材料。

**HAPLO-：在染色体组数中认出一套**

haploid 单倍体的，通常指具有一套染色体组。diploid 二倍体则通常有两套；数的是组，不是一共只有一条或两条染色体。

- **一套与两套染色体组**：haploid · diploid

## 词形与演化规律

haplo- 单一 + -ploid 组数材料 → haploid；diploid 是两套的相邻对照名称。

## 逐词讲解

<a id="w-4"></a>

### 1. diploid — 二倍体的；二倍体

**音标**：/ˈdɪplɔɪd/

**先抓住这个画面**

染色体按完整套数来数，有两套，而不是只有两条。

**怎么拆**

diplo- 双重 + -oid；现代生物学造词。与 diploma 的双重词干相关，但不是从毕业文凭演变出的术语。

**怎么变成今天的意思**

**希腊 diploos → 组合形式 diplo-**  
双重

↓

**科学构词 diplo- + -oid → 英语 diploid**  
用双重表示两套完整染色体

a diploid cell 有两套染色体。人类许多有核体细胞通常有 46 条，即 23 对；不同物种每套的条数可以不同。

**常见搭配与例句**

a diploid cell；a diploid organism；the diploid chromosome number。

> The diagram compares a haploid cell with a diploid cell.

示意图比较了单倍体细胞与二倍体细胞。

> A typical human diploid cell contains 23 pairs of chromosomes.

典型的人类二倍体细胞含有 23 对染色体。

**别混淆**

haploid 是一套，diploid 是两套。染色体复制后的 DNA 数量变化，不应仅凭多了复制品就说倍性改变。

<a id="w-1"></a>

### 2. haploid — 单倍体的；单倍体

**音标**：/ˈhæplɔɪd/

**先抓住这个画面**

细胞里只有一套染色体，重点是一套，不是一条。

**怎么拆**

haplo- 单一，接希腊 haploos 单的 + -oid；现代遗传学用来标明染色体组数。

**怎么变成今天的意思**

**希腊 eidos 形状 → -eidēs / -oeidēs；拉丁化 -oides → 英语 -oid**  
具有某种外形、性质；也用于近代科学分类造词

↓

**希腊 haploos 单的 → haplo- + -oid → 英语 haploid**  
单一的一套 → 单倍体的

a haploid cell 是单倍体细胞；人类正常精子、卵细胞各有一套染色体。套里可以有许多条，所以不能把单倍理解成单根染色体。

**常见搭配与例句**

a haploid cell；a haploid organism；a haploid set。

> A human sperm cell normally contains a haploid set of chromosomes.

人类精子通常含有一套染色体。

> The diagram compares haploid and diploid cells.

图中比较了单倍体细胞与二倍体细胞。

**别混淆**

diploid 是有两套染色体；haploid 是一套。倍性说的是套数，不是细胞体积大小。

## 这一组要分清什么

haploid 数染色体组；每组可以包含多条染色体。完整术语不等于一条染色体的细胞。
