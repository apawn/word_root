# 3564 · tera- — 一万亿倍，10¹²

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

国际单位制采用的前缀，名称与希腊 teras 巨物、怪物的材料相关。不要凭拼写把它当成 tetra- 四的普通同义形式。

**TERA-：比 giga- 再大一千倍的数量级**

GB 到 TB 每上一级乘一千：十进制一千 GB 是一 TB。先把 tera- 记成一万亿，单位再看后面。

- **数据数量级的相邻对照**：byte · gigabyte · terabyte
- **tera-：从巨物的名称材料到万亿倍**：terabytes

## 词形与演化规律

tera- 10¹² + byte 字节 → terabyte。作为标准前缀符号写大写 T，TB 的 B 又指 byte，不是小写 b 的 bit。

tera- 接希腊 teras 奇物、巨物、怪物等材料，现代十进制 TB 表示万亿字节；学习倍率按现代约定，旧词义只帮助记住大尺度。

## 逐词讲解

<a id="w-3"></a>

### 1. byte — 字节

**音标**：/baɪt/

**先抓住这个画面**

电脑存数据时的一小组二进制位，现代通常八个 bit 合成一 byte；它像一个常用的小包装单位。

**怎么拆**

近代计算机术语，把 bite 咬下一小块的拼写改成 byte，以免与 bit 混淆。它是命名变形，不是 by 加表示技术的 -te。

**怎么变成今天的意思**

**bite 的小口、小块命名意象**  
计算机早期数据分组的命名材料

↓

**改拼 byte**  
字节，现代通常为八比特

one byte 一个字节；a byte of data 一个字节的数据；byte size 字节大小。符号常用大写 B，小写 b 通常表示 bit。

**常见搭配与例句**

read a byte；bytes of data。

> The program reads one byte at a time.

程序每次读取一个字节。

> Eight bits make up one byte in this format.

在这种格式中，八个比特组成一个字节。

**别混淆**

byte 读 /baɪt/，bit 读 /bɪt/；现代八比特对应一字节，历史上 byte 的长度曾有其他约定。

<a id="w-4"></a>

### 2. gigabyte — 吉字节；通常十亿字节

**音标**：/ˈɡɪɡəbaɪt/

**先抓住这个画面**

byte 太小，文件、存储空间一大就改用 gigabyte 计数；现代十进制的一 GB 是十亿字节。

**怎么拆**

giga- 十亿倍 + byte 字节，形成数据容量单位。计算机历史中也曾以这个名称指二进制的 2 的三十次方字节；现代 GiB 可明确表示后者。

**怎么变成今天的意思**

**giga- + byte → gigabyte**  
用十亿倍率放大字节单位

↓

**容量标记的现代区分**  
GB 通常十亿字节；GiB 明确二进制量

a file of two gigabytes 两吉字节文件；gigabytes of storage 以吉字节计的存储空间。阅读设备、系统显示时留意采用的计数习惯。

**常见搭配与例句**

a few gigabytes；storage in gigabytes。

> The video file takes up two gigabytes of storage.

这个视频文件占用两吉字节存储空间。

> The program displays file sizes in gigabytes.

程序以吉字节显示文件大小。

**别混淆**

gigabit 计比特，gigabyte 计字节；在相同十进制前缀下，一 gigabyte 对应八 gigabits。不要只看首字母 G。

<a id="w-2"></a>

### 3. terabyte — 太字节、万亿字节〔TB〕

**音标**：/ˈterəbaɪt/

**先抓住这个画面**

电脑硬盘上写 1 TB，按十进制标准就是一万亿字节。tera- 告诉你数量级，byte 告诉你数的单位。

**怎么拆**

国际单位制数量级前缀 tera- 10 的十二次方 + byte 字节，进入计算机容量命名。tera- 名称与希腊 teras 巨物、怪物材料相关。

**怎么变成今天的意思**

**tera- 10¹² + byte**  
一万亿个字节

↓

**terabyte、符号 TB**  
十进制数据容量单位

a two-terabyte drive 两太字节硬盘；容量也写 2 TB。十进制 1 TB = 1000 GB；二进制 2 的四十次方字节的明确名称是 tebibyte，符号 TiB。

**常见搭配与例句**

a terabyte of data；a one-terabyte disk。

> The drive can store two terabytes of data.

这个硬盘能存两太字节的数据。

> The specification defines one terabyte as one trillion bytes.

规格说明将一太字节定义为一万亿字节。

**别混淆**

TB 与 TiB 不是同一精确数量。操作系统显示、旧用法有时把二进制容量也写作 TB，比较数值时要看采用哪种口径。

<a id="w-5"></a>

### 4. terabytes — 太字节；十进制每单位一万亿字节〔日常常说T〕

**音标**：英 /ˈterəbaɪts/；美 /ˈterəˌbaɪts/

**先抓住这个画面**

大量视频、照片和备份堆在一起，容量可能要按 terabytes 来数。它比 gigabytes 又放大了一层。

**怎么拆**

tera- 万亿 + byte 字节 → terabyte；加复数 -s → terabytes，词尾 /ts/。tera- 名称远接希腊 teras 奇物、巨物、怪物的材料。

**怎么变成今天的意思**

**希腊 teras 奇物、巨物等 → 现代 tera- 万亿倍**  
取大尺度的命名材料，不按旧词义计算容量

↓

**terabyte + -s → terabytes**  
十进制 TB；二进制可明确写 TiB

十进制下1000 gigabytes = 1 terabyte；TB 是10的12次方字节，TiB 是2的40次方字节，精确比较容量时先统一口径。

**常见搭配与例句**

several terabytes of data；capacity in terabytes；terabytes of backups。

> The archive contains several terabytes of video.

这个档案库里有几太字节的视频。

> The report lists storage capacity in terabytes.

报告用太字节列出存储容量。

**别混淆**

容量、已有数据量、剩余空间都能用 terabytes；名词前后的搭配告诉你到底在数哪一项。

## 这一组要分清什么

tera- 在 SI 中是精确的十进制数量级；TiB 的二进制单位另有名称。看硬盘、系统容量时同时核对数值和单位。

## 串起来练习

The archive occupies one terabyte of storage.

这个资料库占用一太字节的存储空间。
