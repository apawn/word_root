# 3075 · alpha- — alphabet 的字母缩短材料

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

本页这一用法由 alphabet 缩短形成，较深处接希腊字母名称 alpha、beta。它与 alpha 表第一、领先等另一组用法需要按词区分。

**ALPHA-：在字符词族里，先认字母这一半**

alphanumeric 把字母和数字归为一类：常见于账号、编号和密码规则。这里 alpha- 给字母，numeric 给数字。

- **字母表及排列性质**：alphabet · alphabetical
- **字母数字类字符**：alphanumeric
- **alphabet → alphabets：名词 s 复数**：alphabet · alphabets

## 词形与演化规律

alphabet → alpha-；alpha- + numeric → alphanumeric。alphabetic、alphabetical 是完整字母表词族的相邻形容词。

t 后加 s，尾 ts。

## 逐词讲解

<a id="w-2"></a>

### 1. alphabet — 字母表；一套字母系统

**音标**：英美 /ˈælfəbet/

**先抓住这个画面**

不是单个 A 或 B，而是把一套书写字母放在一起看。

**怎么拆**

经拉丁 alphabetum 接希腊 alphabetos，来自 alpha + beta，也就是希腊字母表的前两个字母名。像用“甲乙”指一整套次序，而不是把每个字母全念完。

**怎么变成今天的意思**

**腓尼基等闪语字母名 aleph、beth → 希腊 alpha、beta**  
希腊字母表开头的两个字母名

↓

**希腊 alphabetos → 拉丁 alphabetum**  
用头两个字母的名字指整套字母

↓

**中古英语 alphabete → 英语 alphabet**  
字母表；字母系统

the English alphabet 是英语的字母表；a different alphabet 是另一套字母系统。现代通用英语中，单个字母通常叫 a letter，不把每个 A、B 都叫 an alphabet。

**常见搭配与例句**

learn the alphabet；the Greek alphabet；letters of the alphabet。

> The children learned the alphabet through songs and games.

孩子们通过歌曲和游戏学习字母表。

> The two languages use different alphabets.

这两种语言使用不同的字母系统。

**别混淆**

letter 是一个字母；alphabet 是一套字母。alphabetical order 指按字母表的既定顺序排列，不是只要求内容里出现字母。

<a id="w-3"></a>

### 2. alphabetical — 按字母顺序的；字母的

**音标**：英美 /ˌælfəˈbetɪkəl/

**先抓住这个画面**

让名字或词语按 A、B、C 的次序排队，方便查找。

**怎么拆**

现代可看作 alphabet + -ical；也有接拉丁形容词 alphabeticus 再加 -al 的分析。不要仅凭它比 alphabetic 长，就认定必定由较短英语词先派生出来。

**怎么变成今天的意思**

**腓尼基等闪语字母名 aleph、beth → 希腊 alpha、beta**  
希腊字母表开头的两个字母名

↓

**希腊 alphabetos → 拉丁 alphabetum**  
用头两个字母的名字指整套字母

↓

**拉丁形容词 alphabeticus 与英语 -al；亦有 alphabet + -ical 分析**  
英语 alphabetical：与字母有关，尤指按字母顺序的

an alphabetical list 是按字母顺序排的名单。in alphabetical order 是最常用搭配；这时它说的是排列规则，不是名单里的内容都只有单个字母。

**常见搭配与例句**

in alphabetical order；an alphabetical list；an alphabetical index。

> Please put the surnames in alphabetical order.

请把姓氏按字母顺序排列。

> An alphabetical index makes the terms easier to find.

按字母顺序编排的索引让术语更容易查找。

**别混淆**

chronological order 按时间，numerical order 按数字，alphabetical order 按字母。说按姓氏排，还要交代 by surname。

<a id="w-4"></a>

### 3. alphabets — 字母表、字母系统〔复数〕

**音标**：/ˈælfəbets/

**先抓住这个画面**

把一套用来拼写语言的字母当作整体，是 an alphabet。比较几套不同的字母系统，就用 alphabets。

**怎么拆**

alphabet 经拉丁 alphabetum 接希腊 alphabetos，组合前两个字母名 alpha、beta，像用甲乙代表一整套。现代加 -s，/t/ 后读 /s/。

**怎么变成今天的意思**

**希腊 alpha + beta → alphabetos → 拉丁、英语 alphabet**  
用开头字母名指整套字母

↓

**alphabet + -s → alphabets**  
多套字母表、字母系统

different alphabets 不同字母表；ancient alphabets 古代字母系统；alphabets used by languages 各语言使用的字母系统。

**常见搭配与例句**

compare alphabets 比较字母表；two alphabets 两套字母系统。

> The chart compares three different alphabets.

图表比较了三套不同字母系统。

> The exhibition shows how ancient alphabets changed.

展览展示了古代字母系统如何变化。

**别混淆**

alphabets 数整套系统，letters 数单个字母。不能把一本字帖上的每个 A、B、C 都各叫一个 alphabet。

<a id="w-1"></a>

### 4. alphanumeric — 字母数字的；由字母、数字组成的

**音标**：/ˌælfənjuːˈmerɪk/；美也读 /ˌælfənuːˈmerɪk/

**先抓住这个画面**

密码规则写 alphanumeric characters，通常就是字母和数字这一类字符，如 A、b、7；具体是否必须两种都含，要看完整规则。

**怎么拆**

alpha- 在这里缩自 alphabet 字母表，再接 numeric 数字的。不是把希腊 alpha 第一个强行译成第一个数字。

**怎么变成今天的意思**

**alphabet → alpha-；加 numeric**  
字母材料 + 数字性质

↓

**alphanumeric 的字符用法**  
字母数字类字符、组合

an alphanumeric code 字母数字代码；alphanumeric characters 字母数字字符。通常排除标点符号，但系统的字符集、大小写要求应看实际说明。

**常见搭配与例句**

an alphanumeric identifier；an alphanumeric password。

> The code contains six alphanumeric characters.

代码包含六个字母数字字符。

> The form accepts alphanumeric identifiers but rejects spaces.

表单接受字母数字标识符，但不接受空格。

**别混淆**

numeric 只说数字相关；alphabetic 只说字母相关。alphanumeric 把两类合起来，不自动说明长度、顺序或强度。

## 这一组要分清什么

alphanumeric 本身通常把字母、数字归为允许字符类；若规则要求至少一个字母和一个数字，还要另外写清楚。

## 串起来练习

The identifier contains eight alphanumeric characters.

这个标识符包含八个字母数字字符。
