# 3630 · -genous — 产生、来源等科学关系

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

联系希腊产生、出生等 -genes、gen- 词族及形容词形式，近代科学又形成多组对应。现代可与 -gen + -ous 对照，不把每个词都临时拼造。

**-GENOUS：与某处产生，或引发某种感觉有关**

endogenous 是内生、内源，exogenous 是外生、外源；erogenous 又说能引起性兴奋的，前部决定产生的是来源还是某种反应。

- **内部、外部来源**：endogenous · exogenous
- **引起特定感觉的性质**：erogenous

## 词形与演化规律

endo- 内 + -genous → endogenous；exo- 外 + -genous → exogenous；ero- 爱欲材料 + -genous → erogenous。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. endogenous — 内生的；内源的

**音标**：英 /enˈdɒdʒənəs/；美 /enˈdɑːdʒənəs/

**先抓住这个画面**

先给系统画一个边界，再问：东西是里面自己产生的吗？

**怎么拆**

endo- 内部 + -genous 产生的；早期植物学“内生”用法后来扩大。

**怎么变成今天的意思**

**希腊 gígnesthai / génos / génesis**  
产生、出生；出身和种类；形成过程

↓

**endo- 内 + 希腊来源 -genous → endogenous**  
在内部生长或产生的

人体自己产生的激素可叫 endogenous hormone；模型中的 endogenous variable 是由模型内部关系决定的变量。“内部”总相对于当前系统，不是永远固定在人体里。

**常见搭配与例句**

endogenous production；an endogenous variable。

> The study measured endogenous hormone production.

研究测量了体内自身产生激素的情况。

> Prices are endogenous in this model.

在这个模型中，价格由模型内部关系决定。

**别混淆**

exogenous 来自外部；同一因素在一个模型中内生，在另一个模型中可能外生。

<a id="w-2"></a>

### 2. exogenous — 外生的；外源的

**音标**：英 /ekˈsɒdʒənəs/；美 /ekˈsɑːdʒənəs/

**先抓住这个画面**

改变来自边界之外，好像有人从盒子外向里面推了一下。

**怎么拆**

exo- 外部 + -genous 产生的；与 endogenous 成对。

**怎么变成今天的意思**

**希腊 gígnesthai / génos / génesis**  
产生、出生；出身和种类；形成过程

↓

**exo- 外 + 希腊来源 -genous → exogenous**  
在所讨论系统之外产生或从外部引入的

exogenous hormone 指从体外引入的激素；exogenous shock 在经济模型里指外来的冲击。这不是“外来的基因”，也不自动表示有害。

**常见搭配与例句**

an exogenous shock；exogenous factors。

> The model treats the weather as an exogenous factor.

模型把天气当作外生因素。

> The researchers distinguished endogenous from exogenous hormones.

研究人员区分了内源性激素与外源性激素。

**别混淆**

external 只是一般“外部”；exogenous 特别强调原因、产生地或决定因素在系统外。

<a id="w-3"></a>

### 3. erogenous — 可引起性兴奋的；性感觉敏感的

**音标**：英 /ɪˈrɒdʒənəs/；美 /ɪˈrɑːdʒənəs/

**先抓住这个画面**

在身体或心理语境里，指能引出性兴奋的敏感性。

**怎么拆**

ero- 由希腊 érōs“爱欲”而来 + -genous 产生的。

**怎么变成今天的意思**

**希腊 gígnesthai / génos / génesis**  
产生、出生；出身和种类；形成过程

↓

**希腊 érōs + 英语 -genous → erogenous**  
能引起性兴奋的

最常见搭配是 erogenous zone，指与性兴奋相关的敏感区域。这是生理、心理描述，具体敏感性因人而异，并不是“促进基因产生”。

**常见搭配与例句**

an erogenous zone；erogenous sensitivity。

> The textbook explains the term erogenous zone.

教材解释了“性敏感区”这个术语。

> Erogenous sensitivity varies between individuals.

性敏感程度因人而异。

**别混淆**

erotic 常指带情色或唤起性欲的表达；erogenous 常落在身体区域的敏感性。

## 这一组要分清什么

来源的内外要看研究怎样划定系统边界；-genous 的产生关系不是所有词都机械译成出生。

## 串起来练习

The model separates endogenous changes from exogenous influences.

模型把内部产生的变化与外部影响分开。
