# 2437 · -more — 再、此后延续或进一步，固定在副词组合里

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

几个词都能看见 more，但有的加一条论述，有的延长时间，不宜一律翻成更多数量。

**MORE：在这些组合里看进一步、此后延续**

furthermore 进一步补充；evermore 此后永远；nevermore 再也不。

- **论述补充**：furthermore
- **时间延续与否定**：evermore · nevermore

## 词形与演化规律

further、ever、never + more；nevermore 还有古英语相应短语历史。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. furthermore — 而且；此外

**音标**：英 /ˌfɜːðəˈmɔː/；美 /ˌfɜːrðərˈmɔːr/

**先抓住这个画面**

在已有理由上再加一条，把论证往前推一步。

**怎么拆**

further 进一步 + more 更多，形成补充论点的连接副词。不是说物理距离又远了几米。

**怎么变成今天的意思**

**古英语 forþor / furþor → 中古英语 further**  
更向前、更远

↓

**英语 further**  
进一步；更远；额外的；促进

↓

**further + more → furthermore**  
进一步 + 更多 → 此外、而且

Furthermore, ... 常在正式论述中引出同方向的补充信息。句首之后常有逗号，但它不像 and 那样在所有句式中都能直接顶替连词。

**常见搭配与例句**

Furthermore, ...；and furthermore；furthermore, it should be noted...。

> The room is too small. Furthermore, it has no windows.

房间太小，而且没有窗户。

> The plan is affordable; furthermore, it can be completed quickly.

计划花费不高，而且能很快完成。

**别混淆**

furthermore 补充支持点，however 则常转折；不要只因为都能放句首就忽略逻辑关系。

<a id="w-2"></a>

### 2. evermore — 永远；从此一直〔文学或郑重用语〕

**音标**：英 /ˌevəˈmɔː/；美 /ˌevərˈmɔːr/

**先抓住这个画面**

像把时间继续往后推：不只到现在，还要一直延续下去。

**怎么拆**

古英语 æfre ma，经中古英语 evermo、evermore 等成为现代词；相当于 ever + more。这里不是数量越来越多，而是时间继续延伸。

**怎么变成今天的意思**

**古英语 æfre 一直；ma 更多、继续**  
两个材料构成持续到以后的表达

↓

**古英语 æfre ma → 中古英语 evermo／evermore → evermore**  
成为文学色彩的永远

for evermore 和 evermore 都可出现在誓言、诗文里。日常说等车很久，用 forever 比 evermore 自然；ever more 分写常表示越来越，另看后面的形容词。

**常见搭配与例句**

for evermore；remain evermore；remembered evermore。

> The inscription promised that their names would be remembered for evermore.

碑文承诺，他们的名字将永被铭记。

> In the poem, the two travellers vow to remain together evermore.

诗中，两位旅人发誓永远相伴。

**别混淆**

evermore 是永远，ever more difficult 是越来越困难；分写时 more 真在提高程度。

<a id="w-3"></a>

### 3. nevermore — 再也不、永不再〔文学用语〕

**音标**：英 /ˌnevəˈmɔː/；美 /ˌnevərˈmɔːr/

**先抓住这个画面**

不只是这一次不做，而是把未来也关上：以后再也不。它比日常 never again 更有诗歌、故事的语气。

**怎么拆**

承中古英语 nevermore，更早有古英语 nǣfre mā 的相应短语。现代对应 never + more，此处 more 取再、此后延续的用法。

**怎么变成今天的意思**

**古英语 nǣfre mā → 中古英语 nevermore**  
在此以后再也不

↓

**never + more 的现代透明关系**  
never 从不、再不；more 再、进一步，合成文学副词

return nevermore 再不回来，nevermore to be seen 从此不再见到。现代常见于诗歌、标题、刻意文学化叙述，日常常说 never again。

**常见搭配与例句**

return nevermore；nevermore to be seen。

> In the legend, the ship sailed away and returned nevermore.

传说中，船驶远了，再也没有回来。

> The poem imagines a door that will open nevermore.

诗中想象一扇永不再开的门。

**别混淆**

nevermore 整体是副词，不是 no more 的每个场景都能替换；No more coffee. 不能换成一个 nevermore coffee。

## 这一组要分清什么

furthermore 是另外、更进一步；nevermore 带文学色彩，日常 never again 更普遍。

## 串起来练习

The legend says the old castle was seen nevermore.

传说说，那座旧城堡从此再未出现。
