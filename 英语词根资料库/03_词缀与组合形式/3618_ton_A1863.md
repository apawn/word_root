# 3618 · -ton — 地名、姓氏材料及少数固定人物词

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

地名后部接古英语 tun 围地、聚落。simpleton 常解释为仿姓氏的戏谑构词，singleton 又有参照 simpleton 或法语往返借入等来源分析。

**-TON：有地名历史，少数普通词又借用命名外形**

英国地名、姓氏里常见 -ton；simpleton、singleton 等普通词又与这种人物命名外形、词形类比有关，但不是普通村镇名称。

- **固定普通词**：simpleton · singleton

## 词形与演化规律

simple + 人名式 -ton → simpleton〔常见分析〕；single → singleton〔具体借入、类比路线有不同分析〕。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [singleton](#w-1) | /ˈsɪŋɡəltən/ | 单个成员；单身者；单元素集合；单胎儿；单例 |

## 逐词讲解

<a id="w-1"></a>

### 1. singleton — 单个成员；单身者；单元素集合；单胎儿；单例

**音标**：/ˈsɪŋɡəltən/

**先抓住这个画面**

该成组的地方只剩一个，或明确要求整个对象里只有一个成员。

**怎么拆**

围绕英语 single 构形，一种常见解释是参照 simpleton；Merriam-Webster 则记为由英语 single 进入法语，再借回英语。两说都不把 -ton 当成重量单位吨。

**怎么变成今天的意思**

**拉丁 singulus 单个；复数 singuli 每个、各一个**  
把人或事物一个一个分开看

↓

**古法语 sengle、sangle → 中古英语 single、sengle → single**  
单个的、独自的、未婚的；后来发展出相应名词和动词用法

↓

**single 形成 singleton：一说英语参照 simpleton；另一说经法语再借回**  
具体借入方向有分歧；早期用在纸牌某花色仅有一张的情形

↓

**singleton 扩展到单个对象、单元素集合、单胎儿与编程单例**  
各领域分别采用只有一个的意象

数学中 a singleton 是只有一个元素的集合；生育语境 a singleton 是单胎出生的孩子。编程中的 singleton pattern 指限制某类只有一个实例并提供访问方式的设计。 口语也可用 singletons 说单身人士。

**常见搭配与例句**

a singleton set；a singleton pregnancy；the singleton pattern。

> The set containing only zero is a singleton.

只包含零的集合是一个单元素集合。

> The study compared twins with singletons.

研究比较了双胞胎与单胎出生的孩子。

**别混淆**

single 是宽泛形容词；singleton 是有特定语境的名词。singleton set 不是空集合：里面有一个元素。

<a id="w-2"></a>

### 2. simpleton — 傻瓜；头脑简单的人，贬称

**音标**：英 /ˈsɪmpəltən/；美 /ˈsɪmpəltən/

**先抓住这个画面**

把 simple 的头脑简单义变成人物称呼，有瞧不起人的意味。

**怎么拆**

simple + 类似人名、姓氏构形的 -ton，形成固定人物称呼。不是 simple + tonne 吨，也不是可自由给所有形容词加的常用人名词规则。

**怎么变成今天的意思**

**拉丁语 simplex → 古法语 simple → 中古英语 symple**  
一重、一层；不复杂

↓

**英语 simple**  
简单、朴素、不加修饰；某些语境也可贬称头脑简单

↓

**simple + -ton → simpleton**  
头脑简单 → 傻瓜这一贬称

treat someone like a simpleton 把某人当傻子；小说人物可能这样骂人。不是称赞一个人生活朴素。

**常见搭配与例句**

treat someone like a simpleton；be mistaken for a simpleton。

> Don’t treat me like a simpleton; I understand the problem.

别把我当傻子，我明白这个问题。

> The story shows that the supposed simpleton is the wisest person in the village.

故事说明，那个被认为是傻子的人，其实是村里最有智慧的。

**别混淆**

simpleton 是带贬义的人物名词；a person with simple tastes 是品味朴素，意思完全不同。

## 这一组要分清什么

不能把 simpleton 直译成简单村，把 singleton 直译成单人镇；也不是重量 tonne 吨的词尾。不要把少数固定词当万能派生规则。

## 串起来练习

The set contains one element, so it is a singleton.

这个集合只含一个元素，所以是单元素集合。
