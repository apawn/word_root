# 1071 · host- — 敌人、敌对；与陌生人关系相连的历史支线

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 hostis 早期可指外来者，后来主要指敌人。hostile 与 hostility 分别通过完整的法语或拉丁词借入。英语 host 有多个来源，只有“军队、众多的一群”这一支直接接 hostis；“主人、主持者”经 hospes，圣餐饼则接 hostia，不能混成敌人变友好的一条简单路线。

**把对方看成站在另一边的人：hostile 是态度敌对，hostility 是敌意，hostilities 则常指已经发生的交战。**

陌生的外来者 → 敌人 → 敌意；态度敌对还可延伸到环境不利、条件难以生存。

- **态度与关系**：hostile, hostility, hostilely, nonhostile
- **交战及 host 的多源辨析**：hostilities, host

## 词形与演化规律

host- 在本页主要见 hostile、hostility。hostilities 是 hostility 的复数专门用法，不是多种不开心。nonhostile 的 non- 取消敌对，不保证亲切热情；hostilely 描述行为方式。

## 逐词讲解

<a id="w-1"></a>

### 1. host — 主人；主持人；主办；宿主；主机；大量〔另一路〕；圣饼〔另一路〕

**音标**：英 /həʊst/；美 /hoʊst/

**先抓住这个画面**

在最常见的一支里，它负责让别人来到这里、在这里活动或得到承载：主人接待客人，主持人组织节目，宿主容纳另一生物。

**怎么拆**

主人义经古法语 oste / hoste 接拉丁 hospitem；a host of 的“大量”另经法语军队词 ost 接 hostis；宗教“圣饼”另接 hostia。三条借入路线需分开，不能把大量解释成主人很多。

**怎么变成今天的意思**

**主人支：拉丁 hospes / hospitem → 古法语 oste / hoste → 英语 host**  
接待者；后来扩展到主持人、宿主、主机及动词

↓

**大量支：拉丁 hostis → 古法语 ost / host → 英语 host**  
敌方、军队 → 队伍、大群

↓

**圣饼支：拉丁 hostia → 古法语 hoiste 等 → 英语 host**  
祭品 → 基督教圣餐中的圣饼

host a meeting 是主办或主持会议。生物宿主不表示主动欢迎寄生者；网络 host 则说联网的主机，也可用作动词说提供网站运行环境。a host of problems 单独走“大量”这条路。

**常见搭配与例句**

the host of a show；host an event；a host organism；a host of reasons。

> Our host made sure everyone had a place to sit.

主人确保每个人都有座位。

> The city will host the music festival.

这座城市将举办音乐节。

> The change created a host of new problems.

这一变化带来了一大堆新问题。

**别混淆**

guest 是来客，host 是接待方；但 host 的所有义项并非都由 guest 的对面推出来。

<a id="w-2"></a>

### 2. hostile — 敌对的；不友好的；不利生存的

**音标**：英 /ˈhɒstaɪl/；美常 /ˈhɑːstəl/，也读 /ˈhɑːstaɪl/

**先抓住这个画面**

感觉对面正在排斥你，或环境根本不给你顺利待下去的条件。

**怎么拆**

来自法语 hostile 或拉丁 hostilis，接 hostis“敌人”；不要拆成英语 host“主人” + 一个虚构词尾。

**怎么变成今天的意思**

**拉丁语 hostis**  
早期外来者、陌生人 → 敌人

↓

**拉丁语 hostilis → 法语 hostile；亦可直接借拉丁语**  
敌人的、敌对的

↓

**英语 hostile**  
敌对、不友好；条件严酷的

hostile to a proposal 是反对提案；a hostile crowd 带敌意；a hostile environment 可能是极寒、缺氧等严酷环境。hostile takeover 则指被收购方管理层不支持的收购。

**常见搭配与例句**

hostile to；a hostile reception；a hostile environment。

> The audience was openly hostile to his proposal.

听众公开反对他的提案。

> Few plants can survive in such a hostile environment.

很少有植物能在这么严酷的环境里生存。

**别混淆**

unfriendly 可只是冷淡；hostile 常更强，含排斥、对抗或伤害性条件。

<a id="w-3"></a>

### 3. hostility — 敌意；强烈反对；敌对行为

**音标**：英 /hɒˈstɪləti/；美 /hɑːˈstɪləti/

**先抓住这个画面**

不只是意见不同，而是对方把你当成需要抵抗、排斥的对象。

**怎么拆**

经古法语 hostilité 或晚期拉丁 hostilitas 借入；名词在英语中较早出现，历史不能仅写成 hostile + -ity。

**怎么变成今天的意思**

**拉丁语 hostis**  
早期外来者、陌生人 → 敌人

↓

**拉丁语 hostilis → 晚期拉丁语 hostilitas**  
敌对的 → 敌意、敌对行为

↓

**古法语 hostilité / 拉丁语 → 英语 hostility**  
敌意；复数可指交战

通常不可数，show hostility to/towards somebody 是表现敌意。公共讨论中的 hostility to change 是强烈抗拒改变；不一定已经动武。

**常见搭配与例句**

open hostility；hostility towards；meet with hostility。

> Her suggestion met with unexpected hostility.

她的建议遭到了出乎意料的强烈反对。

> There was no sign of hostility between the neighbours.

邻居之间看不出有什么敌意。

**别混淆**

disagreement 是意见不合；hostility 还带对人的敌意或强烈对抗。

<a id="w-4"></a>

### 4. hostilities — 交战；敌对行动〔通常复数〕

**音标**：英 /hɒˈstɪlətiz/；美 /hɑːˈstɪlətiz/

**先抓住这个画面**

敌意已经变成实际冲突：不是心里不喜欢，而是双方在打、在对抗。

**怎么拆**

hostility 的复数，y 改为 -ies；复数逐渐固定用于交战、战争行动。

**怎么变成今天的意思**

**拉丁语 hostis**  
早期外来者、陌生人 → 敌人

↓

**拉丁语 hostilis → 晚期拉丁语 hostilitas**  
敌对的 → 敌意、敌对行为

↓

**古法语 hostilité / 拉丁语 → 英语 hostility**  
敌意；复数可指交战

↓

**英语 hostility → hostilities**  
敌对行为 → 交战、战事

the outbreak of hostilities 是战事爆发；cease hostilities 是停止敌对行动。复数也可用于较小规模冲突，但新闻、外交中常带军事含义。

**常见搭配与例句**

cease hostilities；renewed hostilities；the outbreak of hostilities。

> The agreement called for an immediate end to hostilities.

协议要求立即停止敌对行动。

> The village was evacuated before hostilities began.

战事开始前，村民已经撤离。

**别混淆**

hostility 可是态度；hostilities 通常指已经发生的敌对行动。

<a id="w-5"></a>

### 5. hostilely — 带敌意地；敌对地

**音标**：英 /ˈhɒstaɪli/；美 /ˈhɑːstəli/

**先抓住这个画面**

说话、看人或回应时，把排斥和对抗的态度露出来。

**怎么拆**

hostile + -ly；读音随 hostile 的英美常见变体变化。

**怎么变成今天的意思**

**拉丁语 hostis**  
早期外来者、陌生人 → 敌人

↓

**拉丁语 hostilis → 法语 hostile；亦可直接借拉丁语**  
敌人的、敌对的

↓

**英语 hostile**  
敌对、不友好；条件严酷的

↓

**英语 hostile + -ly → hostilely**  
敌对的 → 带敌意地

常配 react、respond、look 等动作。它较书面，口语也会说 in a hostile way。不能见 -ly 就以为它一定表示声音很大；冷冷的一眼也可能 hostile。

**常见搭配与例句**

respond hostilely；react hostilely；look at someone hostilely。

> He stared hostilely at the unfamiliar visitors.

他带着敌意盯着那些陌生来客。

> The group reacted hostilely to the proposed changes.

这个团体以强烈敌对的态度回应拟议的变更。

**别混淆**

angrily 是生气地；hostilely 更突出把对方当作对手的态度。

<a id="w-6"></a>

### 6. nonhostile — 非敌对的；没有敌意的

**音标**：英 /ˌnɒnˈhɒstaɪl/；美 /ˌnɑːnˈhɑːstəl/

**先抓住这个画面**

至少没有把你当敌人，也没有表现出对抗意图。

**怎么拆**

non- 否定 + hostile；可用来分类态度、行为或接触对象。

**怎么变成今天的意思**

**拉丁语 hostis**  
早期外来者、陌生人 → 敌人

↓

**拉丁语 hostilis → 法语 hostile；亦可直接借拉丁语**  
敌人的、敌对的

↓

**英语 hostile**  
敌对、不友好；条件严酷的

↓

**英语 non- + hostile → nonhostile**  
不是敌对的

nonhostile contact 可以只是和平接触，未必已经亲密友好。这个词常用于相对正式的报告，比 friendly 的积极程度低。

**常见搭配与例句**

a nonhostile response；nonhostile contact；a nonhostile manner。

> The visitors received a cautious but nonhostile welcome.

来客受到了谨慎但没有敌意的接待。

> The exercise focused on responding to nonhostile encounters.

演练着重练习如何应对非敌对接触。

**别混淆**

friendly 是友善；nonhostile 只说没有敌意，可能仍然保持距离。

## 这一组要分清什么

hostile 描述敌意，也可说环境严酷；hostilities 在新闻里常是交战，通常比 hostility 更具体。host 的主人、军队、圣餐饼三义必须分别看来源。

## 串起来练习

比较 a hostile reply、a hostile environment、an end to hostilities：分别说态度、条件还是交战？再说明 host a meeting 为什么不应直接拆成“敌人”。
