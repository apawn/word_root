# 0715 · fil- — 线；细丝

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 fīlum 指线、细丝。经法语、意大利语，它不只留下材料名称，还留下“排成一线”和“沿线画轮廓”的概念。file 的文档义最初与用线串存文件有关；今天变成电子文件，名称仍沿用了下来。

**fil- = thread：一根细线，可以串起东西，也可以画出轮廓。**

想象两种用线的方法：一根线串起纸张成为档案 file；一根线沿着侧脸描出 profile。细线本身则出现在 filament、filigree 里。

- **串存资料与排成一列**：file、filing、filename；defile 的峡道义
- **画出外形与关键特征**：profile、profiler、profiling
- **细丝、窄条和花饰**：filament、fillet、filigree

## 词形与演化规律

fil- 在 filament、filigree 中很清楚；file 的结尾 e 不读。profile 经过意大利语构词，不能用英语 pro“专业人士”加 file 猜历史。

## 逐词讲解

<a id="w-1"></a>

### 1. profile — 侧面轮廓；简介；个人资料；特征概况；介绍、分析

**音标**：英 /ˈprəʊfaɪl/；美 /ˈproʊfaɪl/

**先抓住这个画面**

先沿外边画一条线，让人一眼看出它是谁、有什么特点。

**怎么拆**

接意大利 profilo／profilare：pro-“向外、向前” + filare“拉出线”，更早为拉丁 fīlum。有词源分析列法语 profil 为中介；不能拆作英语 pro“专业” + file“档案”。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**后期拉丁 fīlāre → 意大利 filare；pro- + filare → profilare → profilo**  
拉出线 → 勾出轮廓 → 轮廓图

↓

**英语 profile；部分词源分析列法语 profil 为中介**  
侧面轮廓 → 人物、机构或对象的概要特征

a face in profile 是侧脸；an online profile 是网上个人资料；a company profile 是公司概况。raise your profile 是提高公众关注度。动词 profile someone 可以是撰写人物介绍。

**常见搭配与例句**

a user profile；a company profile；in profile；keep a low profile；profile an artist。

> She updated her profile with a short description of her work.

她更新了个人资料，加上一段简短的工作介绍。

> The magazine profiles a different designer each month.

杂志每月介绍一位不同的设计师。

**别混淆**

portrait 可以是详细描绘；profile 通常抓轮廓与关键特征。网上 profile 不仅指头像，还可能包含简介、兴趣等资料。

### 2. profiling — 特征分析；侧写；用户画像分析；性能分析

**音标**：英 /ˈprəʊfaɪlɪŋ/；美 /ˈproʊfaɪlɪŋ/

**先抓住这个画面**

不只收集零散数据，还把它们整理成能看出特点的轮廓。

**怎么拆**

profile + -ing；从绘出轮廓延伸到分析人物、群体或程序的表现。不同专业语境沿同一概念发展，不是古代已有的软件术语。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**后期拉丁 fīlāre → 意大利 filare；pro- + filare → profilare → profilo**  
拉出线 → 勾出轮廓 → 轮廓图

↓

**英语 profile；部分词源分析列法语 profil 为中介**  
侧面轮廓 → 人物、机构或对象的概要特征

↓

**英语 profile + -ing → profiling**  
勾勒轮廓 → 特征、行为或程序运行分析

customer profiling 是分析顾客特征；performance profiling 是查看程序资源消耗。racial profiling 则说依据种族特征对人作推断或区别对待，词组带有明显的歧视问题。

**常见搭配与例句**

customer profiling；criminal profiling；performance profiling；racial profiling。

> Performance profiling helped the team find a slow function.

性能分析帮助团队找到了一个运行缓慢的函数。

> The report questions how customer profiling affects people’s privacy.

报告探讨了顾客画像分析怎样影响个人隐私。

**别混淆**

profiling 形成特征概况；identification 是确定身份。一个特征轮廓本身并不能证明某人是谁或做过什么。

### 3. profiler — 特征分析人员；犯罪侧写师；性能分析工具

**音标**：英 /ˈprəʊfaɪlə/；美 /ˈproʊfaɪlər/

**先抓住这个画面**

把零散表现拼成一个特征轮廓，帮助人看出模式。

**怎么拆**

profile + -er；可表示做分析的人，也可表示执行分析的工具，后缀不只限于职业名称。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**后期拉丁 fīlāre → 意大利 filare；pro- + filare → profilare → profilo**  
拉出线 → 勾出轮廓 → 轮廓图

↓

**英语 profile；部分词源分析列法语 profil 为中介**  
侧面轮廓 → 人物、机构或对象的概要特征

↓

**英语 profile + -er → profiler**  
制作特征概况的人或工具

a criminal profiler 根据相关信息提出行为特征分析，不是凭空读心。软件 profiler 记录程序各部分的运行情况，例如耗时和调用次数，帮助定位性能问题。

**常见搭配与例句**

a criminal profiler；a memory profiler；a performance profiler；run a profiler。

> The profiler compared patterns across several case reports.

侧写分析人员比较了几份案件报告中的模式。

> The profiler showed that most of the time was spent loading images.

性能分析工具显示，大部分时间花在了加载图像上。

**别混淆**

debugger 常用于检查程序状态与错误；profiler 主要让你看清时间、内存等资源花在哪里。它不会自动修好程序。

### 4. file — 文件；档案；归档；正式提交；纵列；锉刀、锉磨〔另源〕

**音标**：/faɪl/

**先抓住这个画面**

一根线把纸张串成可查的记录；后来纸张和线都可以消失，记录仍叫 file。

**怎么拆**

文档与队列义经法语 fil／filer／file 接拉丁 fīlum“线”。锉刀义来自古英语 fēol，锉磨义接古英语 fīlian；这两支不能硬接“线”。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**古法语 fil → filer；法语 file**  
线 → 用线串起文件；一串、行列

↓

**英语 file：文件、归档、纵列**  
成串保存的文书 → 一组记录 → 计算机文件；人排成一列

↓

**另源并列：古英语 fēol／fīlian → 英语 file**  
锉刀；用锉刀磨平

open a file 是打开文件；file a report 可以是归档或正式提交报告，看语境决定。in single file 是前后排成一列；file your nails 是锉指甲，与文档没有词源关系。

**常见搭配与例句**

save a file；on file；file a complaint；in single file；a nail file。

> Save the image as a separate file.

把图像另存为一个文件。

> She filed a complaint about the repeated noise.

她对反复出现的噪声正式提出了投诉。

> The children walked through the gate in single file.

孩子们排成一列走过大门。

> He used a small file to smooth the metal edge.

他用一把小锉刀磨平金属边缘。

**别混淆**

folder 是收纳文件的文件夹；file 是其中的文件或一组档案。数字文件也不一定是文字，照片、声音都可以是 file。

### 5. filing — 归档；正式提交；提交的文件；锉屑〔另源〕

**音标**：/ˈfaɪlɪŋ/

**先抓住这个画面**

把材料送进正式记录中；说到金属屑时，走的却是锉刀那一支。

**怎么拆**

file + -ing。文档义继承拉丁 fīlum 经法语形成的 file；锉磨及 filings“锉屑”继承古英语锉刀义，现代词形合流。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**古法语 fil → filer；法语 file**  
线 → 用线串起文件；一串、行列

↓

**英语 file：文件、归档、纵列**  
成串保存的文书 → 一组记录 → 计算机文件；人排成一列

↓

**英语 file + -ing → filing**  
归档、提交；所提交的材料

↓

**另源并列：古英语锉刀一支 → 英语 file + -ing → filings**  
锉磨动作及磨下的细屑

do the filing 是整理归档；a court filing 是向法院提交的文件；filings 常指多份正式申报文件，也可指金属锉屑，必须看对象。

**常见搭配与例句**

a filing system；a filing deadline；a court filing；iron filings。

> A clear filing system makes old records easier to find.

清楚的归档制度让旧记录更容易找到。

> The company corrected an error in its latest filing.

公司更正了最新提交文件中的一个错误。

> Tiny iron filings clung to the magnet.

细小的铁屑附着在磁铁上。

**别混淆**

filing 强调归档或正式提交的动作、材料；folder 是收纳工具。iron filings 与 files“文档”不是同一词源支线。

### 6. filename — 文件名

**音标**：/ˈfaɪlneɪm/

**先抓住这个画面**

给文件贴一个可识别的名字，让人和程序能找到它。

**怎么拆**

file“文件” + name“名字”的现代英语合成词；file 沿文档一支接拉丁 fīlum，name 是另一个日耳曼来源成分。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**古法语 fil → filer；法语 file**  
线 → 用线串起文件；一串、行列

↓

**英语 file：文件、归档、纵列**  
成串保存的文书 → 一组记录 → 计算机文件；人排成一列

↓

**英语 file + name → filename**  
文件 + 名字 → 文件名

a descriptive filename 能提示文件内容；filename extension 是文件名里的扩展名部分。改名字通常不等于改变文件内部格式，不能把 photo.jpg 改成 photo.pdf 就当作完成转换。

**常见搭配与例句**

a descriptive filename；enter a filename；change the filename；a filename extension。

> Use a descriptive filename so that you can find the report later.

用一个能说明内容的文件名，方便以后找到报告。

> The two folders contain files with the same filename.

这两个文件夹里有同名文件。

**别混淆**

filename 说名称；file path 还包括它所在的位置。同名文件可以在不同文件夹里出现。

### 7. defile — 玷污、亵渎〔另源〕；狭窄峡道；列队通过

**音标**：/dɪˈfaɪl/；峡道名词及列队动词也读 /ˈdiːfaɪl/

**先抓住这个画面**

峡道窄得让队伍排成一根线；“玷污”则是另一个恰好同形的词。

**怎么拆**

峡道义借法语 défilé，接 défiler“列队行进”与 file“纵列”，最终接 fīlum。玷污义由中古英语 defoulen 等形变化，混合了法语“践踏”和英语 foul 一支的影响，不属线词根。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**法语 file → défiler → défilé → 英语 defile**  
一列 → 列队通过 → 狭窄通道

↓

**另源并列：法语 defouler；英语 foul／filen 一支 → 中古英语 defoulen／defilen**  
践踏、使污秽等形式相互影响

↓

**英语 defile 的玷污义**  
污染应受珍惜、尊重或视为神圣的东西

defile a sacred place 是亵渎圣地；a narrow defile 是狭窄峡道，常见于历史或地理叙述。“玷污”强调破坏洁净、尊严或神圣性，语气比 dirty 重。

**常见搭配与例句**

defile a sacred place；defile a memory；a narrow defile；pass through a defile。

> The villagers feared that the rubbish would defile the sacred spring.

村民担心那些垃圾会玷污神圣的泉水。

> The path narrowed as it entered the rocky defile.

小路进入岩石间的狭窄峡道后变得更窄。

**别混淆**

pollute 常说环境或物质被污染；defile 还强调本应受到尊重的东西遭到糟蹋。两个义支不能都靠“拆散一条线”记忆。

### 8. filament — 细丝；丝状物；灯丝；打印丝材

**音标**：/ˈfɪləmənt/

**先抓住这个画面**

细得像一根线，却可以是金属、塑料或生物组织。

**怎么拆**

借中世纪拉丁 fīlāmentum，接晚期拉丁 fīlāre“纺线、拉成线”，根为 fīlum。不是英语 fill“填满”加 -ament。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**后期拉丁 fīlāre → 中世纪拉丁 fīlāmentum**  
纺线、拉丝 → 丝状物

↓

**英语 filament**  
细丝；灯丝等细长材料

a light-bulb filament 是灯泡里的细灯丝；3D-printer filament 是供某类打印机使用的丝状材料。植物学还可指支撑花药的花丝，关键形状都是细长。

**常见搭配与例句**

a thin filament；a tungsten filament；plastic filament；a spool of filament。

> The bulb’s filament glowed orange before becoming bright.

灯泡的灯丝先发出橙光，然后变得明亮。

> She loaded a new spool of filament into the 3D printer.

她给三维打印机装上一卷新的丝材。

**别混淆**

fiber 常说构成材料的纤维；filament 更突出一条细长连续的丝。不能把所有灯泡都说成靠 filament 发光。

<a id="w-6"></a>

### 9. fillet — 去骨鱼片或肉块；把鱼去骨切片；窄条、饰带

**音标**：英 /ˈfɪlɪt/；美食物义常读 /fɪˈleɪ/，其他义也读 /ˈfɪlɪt/

**先抓住这个画面**

把较大的东西处理成一条利落的部分；在餐桌上通常就是去骨的鱼肉或肉块。

**怎么拆**

经古法语 filet，原是 fil“线”的小称。肉食义可能与过去用细绳捆扎肉块的做法有关，这是一种词源解释，不应编成确定发生过的故事。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**古法语 fil → filet → 中古英语 filet**  
线 → 小细条、饰带

↓

**英语 fillet；由名词发展动词**  
去骨肉块、鱼片；把鱼去骨切片

a salmon fillet 是一块去骨三文鱼肉；fillet the fish 是把鱼去骨并切取鱼片。工程图中的 fillet 可指两表面交接处的圆角；该义通常读 /ˈfɪlɪt/。

**常见搭配与例句**

a fish fillet；a fillet of beef；fillet a fish；a fillet knife。

> She baked two salmon fillets with lemon.

她用柠檬烤了两块三文鱼肉。

> The fishmonger showed him how to fillet the fish.

鱼贩示范给他看怎样给鱼去骨切片。

**别混淆**

slice 只是切下的一片，不保证去骨；fillet 在食物中突出无骨的肉块。美式也常拼 filet，不能把它看作完全无关的词。

### 10. filigree — 金银细丝花饰；精细的镂空纹样

**音标**：/ˈfɪlɪɡriː/

**先抓住这个画面**

把细金属丝弯成花纹，像用线在空中织出蕾丝。

**怎么拆**

经法语 filigrane，接意大利 filigrana，组合拉丁 fīlum“线、金属丝”与 grānum“颗粒”；英语先有 filigreen，后缩成 filigree。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**拉丁 fīlum + grānum → 意大利 filigrana → 法语 filigrane**  
细丝 + 颗粒 → 精细金属花饰

↓

**英语 filigreen → filigree**  
细金属丝装饰；比喻精细交错的纹样

silver filigree 常见于首饰；a filigree of branches 可比喻细枝交错成花纹。词的印象是细密、轻巧、精工，不是所有带洞的东西都叫 filigree。

**常见搭配与例句**

silver filigree；delicate filigree；filigree work；a filigree of branches。

> The pendant was framed with delicate silver filigree.

吊坠周围镶着精细的银丝花饰。

> Bare branches formed a dark filigree against the evening sky.

光秃的细枝在暮色天空前交织成深色花纹。

**别混淆**

lace 通常是纺织蕾丝；filigree 原本是金属丝工艺。两者外观都可轻巧通透，所以常用来互相比喻。

## 这一组要分清什么

file 的“锉刀”来自古英语，defile 的“玷污”也有另一条混合来源；它们只是与线词根后代同形。fillet 的肉食义与细绳的联系属于词源解释，不宜把可能的命名缘由说成确定史实。

## 串起来练习

先说一个 file 怎么存，再说自己的 profile 包含什么。遇到 nail file 或 iron filings 时，提醒自己已经走到锉刀那一支，别再强套“线”。
