# 3399 · opac- — 阴暗；遮蔽；看不透

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 opacus 的核心是阴暗、遮蔽。opaque 说物体或信息看不透；opacity 把这种性质或程度单独拿出来谈。记住看不透这个共同画面，比死记两个不相干的中文义项更容易。

**OPAC = DARK / OPAQUE**

一块板挡在眼前，光过不去；换成一套规则，外人同样看不清里面发生了什么。

- **东西或信息看不透**：opaque
- **看不透的性质与程度**：opacity

## 词形与演化规律

opaque 的 -que 拼写受法语影响；opacity 保留 opac- 词干，c 在这里读 /s/。两个英语词各有借入历史，现代的形容词—名词对应不等于只有一条英语内部造词路线。

## 逐词讲解

<a id="w-1"></a>

### 1. opaque — 不透明的；难懂的；不公开的

**音标**：英 /əʊˈpeɪk/；美 /oʊˈpeɪk/

**先抓住这个画面**

光穿不过去，看不见另一边；信息也可以让人看不透。

**怎么拆**

来自拉丁 opacus 阴暗的、遮蔽的。英语早期拼作 opake，后来拼写受法语 opaque 影响。

**怎么变成今天的意思**

**拉丁 opacus**  
阴暗、遮蔽

↓

**英语 opake → opaque**  
不透光的；难以看懂的，拼写受法语影响

一块 opaque 的塑料板挡住了光；一套 opaque 的收费规则让人看不出钱到底怎么算。后者把视觉上的看不透借来讲理解上的看不透，并不一定表示句子用了生词。规则缺少解释、过程不公开，也会让人觉得 opaque。

**常见搭配与例句**

opaque glass 不透明玻璃；opaque language 晦涩的语言；an opaque decision-making process 不透明的决策过程。

> The bottle is made of opaque white plastic.

这个瓶子是用不透明的白色塑料制成的。

> The pricing system was so opaque that customers could not predict their bills.

计价规则太不透明，顾客无法预估账单金额。

**别混淆**

transparent 能透过去，translucent 让光通过但看不清另一侧的细节，opaque 则不透光。opaque 不等于颜色黑，白色墙板也能不透明。

<a id="w-2"></a>

### 2. opacity — 不透明性；不透明度；晦涩；不公开

**音标**：英 /əʊˈpæsəti/；美 /oʊˈpæsɪti/

**先抓住这个画面**

把看不透这件事当成一种性质，或者可以调节的程度。

**怎么拆**

来自法语 opacité，追到拉丁 opacitas 阴暗、遮蔽，由 opacus 构成。现代可对应 opaque 的名词，但并非只能讲成英语 opaque 现加后缀。

**怎么变成今天的意思**

**拉丁 opacus → opacitas**  
阴暗的 → 阴暗、遮蔽的性质

↓

**法语 opacité → 英语 opacity**  
不透明性；意义或过程的难以看透

编辑图片时降低 opacity，图层就更透明，下面的内容更容易显出来。在常见图层和 CSS 设置里，100% opacity 是完全不透明，0% 才是完全透明。谈制度的 opacity，则是在说信息不公开、外人摸不清运作方式。英语历史中晦涩义也很早，不能把这个名词的全部发展简单套成先有物理义、后有比喻义。

**常见搭配与例句**

reduce the opacity 降低不透明度；the opacity of a system 一个系统的不透明性。

> Reduce the opacity of the top layer so that the image beneath it becomes visible.

降低顶层的不透明度，让下面的图像显出来。

> The report criticized the opacity of the selection process.

报告批评了选拔过程的不透明。

**别混淆**

opacity 与 transparency 方向相反：opacity 越高，越不透明。表达不透明的状态也可用 opaqueness；opacity 尤其常用于程度、技术参数和制度评论。

## 这一组要分清什么

opaque 不等于黑色，也不只是语言难懂。opacity 是不透明度，常用软件里的数值越高越不透明，别与透明度读反。

## 串起来练习

Opaque material blocks light; opacity tells us how difficult it is to see through.

不透明材料挡住光；不透明度说的是看透它有多难。
