# 2370 · ech- — 声音；回响

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

echo 最好先记真实的回声，再联想到别人重复或呼应一个观点。anechoic 处理的是反射，echolocation 利用回声找位置，echocardiography 则把心脏超声回波变成图像。catechism 的路径经过口头教导，不能按今天的音响术语硬译。

**声音再次出现，就能联系回声、呼应；把声音用于定位、成像或口头教导，又会发展出不同用途。**

希腊 ēkhō → 拉丁 echo → 英语 echo → echoing；an- + echoic → anechoic；echo + location → echolocation；口头教导 katēkhein → catechismus → catechism。

- **回声与观点呼应**：echo, echoing
- **抑制和利用回声**：anechoic, echolocation
- **用超声观察心脏**：echocardiography, echocardiogram
- **声音进入教导**：catechism

## 词形与演化规律

echo 的复数、第三人称单数都是 echoes，进行形式 echoing，过去式 echoed。echocardiogram 的 -gram 偏记录或一次检查，echocardiography 的 -graphy 偏技术方法。catechism 的 ch 读 /k/。

## 逐词讲解

<a id="w-1"></a>

### 1. echo — 回声；回响；重复、呼应

**音标**：英 /ˈekəʊ/；美 /ˈekoʊ/

**先抓住这个画面**

声音出去后又回来；别人的话在你这里再出现，也像有了一次回声。

**怎么拆**

名词借自拉丁 echo，接希腊 ēkhō；英语随后形成同形动词。神话中的 Echo 是回声的人格化形象，不能简单倒过来说普通词必定由她的名字创造。

**怎么变成今天的意思**

**希腊 ēkhō 回声，相关 ēkhein 发声、回响 → 拉丁 echo**  
声音返回或再次响起

↓

**英语 echo〔名词〕→ 动词 echo**  
回声 → 回响；又引申为重复、呼应别人的话

hear an echo 是听见回声；echo someone’s concerns 是表达与某人相似的担忧。后者不一定逐字重复，更常是立场或内容相呼应。

**常见搭配与例句**

an echo of；echo through the hall；echo someone’s words；echo a concern。

> We shouted into the tunnel and waited for an echo.

我们朝隧道里喊了一声，等着回声传回来。

> Her comments echoed the concerns raised by several residents.

她的评论呼应了几位居民提出的担忧。

**别混淆**

repeat 只说重复；echo 常让人感到前一个声音、想法或样式在后面再次出现。

<a id="w-2"></a>

### 2. echoing — 回响着的；回声很大的；正在呼应

**音标**：英 /ˈekəʊɪŋ/；美 /ˈekoʊɪŋ/

**先抓住这个画面**

一个声音还在空间里来回响，或一个观点正在被别人再次表达。

**怎么拆**

echo + -ing，o 保留；可作进行时中的动词形式，也可修饰有回声的空间。

**怎么变成今天的意思**

**希腊 ēkhō 回声，相关 ēkhein 发声、回响 → 拉丁 echo**  
声音返回或再次响起

↓

**英语 echo〔名词〕→ 动词 echo**  
回声 → 回响；又引申为重复、呼应别人的话

↓

**英语 echo + -ing → echoing**  
回响、呼应的过程；或带回声的性质

an echoing corridor 是容易产生回声的走廊；echoing an earlier warning 是呼应先前的警告。先看后面接地点还是观点，意思就容易分清。

**常见搭配与例句**

an echoing hall；an echoing corridor；echoing a warning；echoing someone’s view。

> A door slammed somewhere in the long, echoing corridor.

长长的走廊里有扇门砰地关上，声音在走廊中回荡。

> Several speakers were echoing the same concern about cost.

几位发言人都在表达同一个关于费用的担忧。

**别混淆**

echoed 常看作已经发生的呼应或过去分词；echoing 更容易突出正在发生的声音或重复。

<a id="w-3"></a>

### 3. catechism — 教理问答；问答式教本；固定的问答或训条

**音标**：/ˈkætəkɪzəm/

**先抓住这个画面**

老师问一句、学生答一句，把一套信仰或原则记下来。

**怎么拆**

经教会拉丁 catechismus，也有法语 catéchisme 路线，追到希腊 katēkhein 口头教导、使听见；其中 kata- 与表示声音的 ēkhein 相接。现代不能拆成 cat 猫。

**怎么变成今天的意思**

**希腊 ēkhein 发声 → katēkhein 使听见、口头教导**  
声音进入教导场景；后有扩展形式 katēkhizein

↓

**教会拉丁 catechismus；法语 catéchisme → 英语 catechism**  
以问答方式传授教义；后来也可说其他固定问答或训条

a catechism 常指基督教的教理问答文本。用于政治或其他体系时，可能带有把固定答案照本宣科的意味，具体褒贬看语境。

**常见搭配与例句**

learn the catechism；a catechism of beliefs；questions in a catechism。

> The old catechism presents each lesson as a question and an answer.

这本旧教理问答把每一课都写成一问一答。

> The critic called the manifesto a catechism of familiar slogans.

评论者把这份宣言称作一套由熟悉口号组成的训条。

**别混淆**

a questionnaire 是收集答案的问卷；a catechism 通常连标准答案一起教给人。

<a id="w-4"></a>

### 4. echolocation — 回声定位

**音标**：英 /ˌekəʊləʊˈkeɪʃən/；美 /ˌekoʊloʊˈkeɪʃən/

**先抓住这个画面**

先发出声音，再听回声何时、怎样回来，从而判断前面有什么、离多远。

**怎么拆**

echo- 回声 + location 定位；二十世纪英语科学构词，常与 Donald Griffin 的研究和命名相联系。

**怎么变成今天的意思**

**拉丁语 locus**  
地方、位置

↓

**拉丁语 locare**  
放置、安置；也指出租

↓

**拉丁语 locatio → 英语 location**  
放置、出租 → 位置、地点

↓

**英语 echo + location → echolocation**  
借回声确定物体位置

蝙蝠和齿鲸的例子最常见；部分人也能通过回声判断环境。它依赖声音返回的信息，不是靠眼睛看见的“夜视”。

**常见搭配与例句**

use echolocation；echolocation clicks。

> The bat uses echolocation to find insects in the dark.

蝙蝠利用回声定位在黑暗中寻找昆虫。

> The experiment measured changes in the animals’ echolocation clicks.

实验测量了这些动物回声定位声响的变化。

**别混淆**

hearing 是一般听觉；echolocation 特别利用声波反射来感知空间。

<a id="w-5"></a>

### 5. echocardiography — 超声心动描记；心脏超声检查技术

**音标**：英 /ˌekəʊˌkɑːdiˈɒɡrəfi/；美 /ˌekoʊˌkɑːrdiˈɑːɡrəfi/

**先抓住这个画面**

发出超声波，再接收心脏结构返回的信号，把看不见的内部运动变成图像。

**怎么拆**

echo 回声 + cardiography 心脏描记；cardio- 心脏 + -graphy 记录，是现代医疗技术组合名。

**怎么变成今天的意思**

**希腊 ēkhō 回声，相关 ēkhein 发声、回响 → 拉丁 echo**  
声音返回或再次响起

↓

**近代 echo + cardiography → echocardiography**  
用超声回波观察、记录心脏结构与活动

echocardiography 主要说技术或检查方法；它利用超声成像，可观察心脏结构和运动。词里的 echo 说明工作依据是回波。

**常见搭配与例句**

use echocardiography；echocardiography showed；training in echocardiography。

> Echocardiography allowed the team to examine how the valve moved.

心脏超声让团队观察到瓣膜是怎样活动的。

> She completed additional training in echocardiography.

她完成了额外的超声心动检查培训。

**别混淆**

electrocardiography 记录心电活动；echocardiography 用超声成像。开头 echo 和 electro 的区别决定了检查原理。

<a id="w-6"></a>

### 6. echocardiogram — 超声心动图；心脏超声检查

**音标**：英 /ˌekəʊˈkɑːdiəʊɡræm/；美 /ˌekoʊˈkɑːrdioʊɡræm/

**先抓住这个画面**

可以指检查产生的心脏图像，也常直接指做这样一次检查。

**怎么拆**

echo 回声 + cardio- 心脏 + -gram 记录；与 echocardiography 属同一技术命名词族，-gram 偏结果或一次检查。

**怎么变成今天的意思**

**希腊 ēkhō 回声，相关 ēkhein 发声、回响 → 拉丁 echo**  
声音返回或再次响起

↓

**近代 echo + cardio- + -gram → echocardiogram**  
超声回波生成的心脏记录；也用于称呼检查本身

have an echocardiogram 是做心脏超声；review the echocardiogram 是查看这次检查的图像或结果。它不必是一张静态纸图，也可以包含动态图像。

**常见搭配与例句**

have an echocardiogram；an echocardiogram showed；review an echocardiogram。

> Her appointment letter included a date for an echocardiogram.

她的预约信上写明了做心脏超声的日期。

> The specialist reviewed the echocardiogram with the patient.

专科医生和患者一起查看了超声心动图。

**别混淆**

electrocardiogram 是心电图，名字里的 electro 是电；echocardiogram 用的是超声回波。

<a id="w-7"></a>

### 7. anechoic — 消声的；无回声的

**音标**：英 /ˌænɪˈkəʊɪk/；美 /ˌænɛˈkoʊɪk/

**先抓住这个画面**

声音发出来后，尽量被吸收，避免又从墙面等地方反弹回来。

**怎么拆**

an- 没有 + echoic 回声的，是现代技术形容词；否定的是回声或反射，不是所有声源。

**怎么变成今天的意思**

**希腊 ēkhō 回声，相关 ēkhein 发声、回响 → 拉丁 echo**  
声音返回或再次响起

↓

**英语 echo → echoic；an- + echoic → anechoic**  
由回声相关构成缺少回声的技术用词

an anechoic chamber 是消声室。在里面讲话仍会听见声源，主要减少的是环境反射。电磁测量也会用这个词来描述抑制反射的环境。

**常见搭配与例句**

an anechoic chamber；anechoic measurements；an anechoic environment。

> The engineers tested the loudspeaker in an anechoic chamber.

工程师在消声室里测试了扬声器。

> The foam lining helps create an anechoic environment.

泡沫内衬有助于形成低反射的消声环境。

**别混淆**

soundproof 强调隔绝声音传进传出；anechoic 强调减少内部反射，两个要求并不相同。

## 这一组要分清什么

anechoic 不等于隔音 soundproof。echocardiography 用超声回波，electrocardiography 记录心电活动。catechism 的问答常有要传授的标准答案，不是普通调查问卷。

## 串起来练习

用 echo 分别讲山洞回声和观点呼应；解释消声室里为什么仍能听见人说话；分清 echocardiogram 与 electrocardiogram。
