# 3827 · fusc- — 暗；使模糊不清

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

最实用的是 obfuscate 和 obfuscation：说话绕、文字堆得复杂，让重点变难懂。字面上的暗发展成理解上的不清楚；代码混淆也是相似画面。

**像给内容蒙上一层暗色，使人难看清真正重点。**

拉丁 fuscus 暗 → fuscare 使暗 → obfuscare；obfuscatus 等 → obfuscate；拉丁名词 obfuscatio → 英语 obfuscation。

- **使理解变难**：obfuscate
- **混淆这种做法**：obfuscation

## 词形与演化规律

fusc- 不必单独作为英语词使用。obfuscation 的名词有自己的拉丁借入路线，不只看成现代动词加后缀。

## 逐词讲解

<a id="w-2"></a>

### 1. obfuscate — 使难懂；混淆；遮掩

**音标**：英 /ˈɒbfəskeɪt/；美 /ˈɑːbfəskeɪt/

**先抓住这个画面**

像在清楚的东西前面罩一层暗幕，让人看不出关键所在；文字也可以靠复杂术语做到这一点。

**怎么拆**

拉丁 ob- + fuscāre“使变暗”，接 fuscus“暗”；经拉丁分词形式或法语相关形式借入。

**怎么变成今天的意思**

**拉丁 ob / ob-**  
朝向；在前面；对着；有时加强后面动作

↓

**拉丁 fuscus → fuscāre → obfuscāre**  
暗 → 使暗 → 遮暗、弄得不清楚

↓

**拉丁 obfuscātus；法语相关形式 → 英语 obfuscate**  
遮暗 → 混淆、使不清楚

常带批评，暗示复杂表达在遮掩重点；也可只是描述让理解变难的效果。代码混淆语境指改写代码外观，尽量保持行为，却增加阅读难度。

**常见搭配与例句**

obfuscate the issue；obfuscate the truth；obfuscate code。

> The long explanation only obfuscated the issue.

那段冗长的解释反而把问题弄得更难懂了。

> The speaker used technical jargon to obfuscate the simple mistake.

发言者用专业术语掩盖那个简单的错误。

**别混淆**

clarify 是让人看清；obfuscate 是让人更难看清。复杂不必然等于混淆，关键是是否掩盖、妨碍理解。

<a id="w-1"></a>

### 2. obfuscation — 混淆；使难懂；遮掩

**音标**：英 /ˌɒbfəˈskeɪʃən/；美 /ˌɑːbfəˈskeɪʃən/

**先抓住这个画面**

把“罩上暗幕”这件事或结果拿出来说：重点被绕开，读者看了很多话却更难判断。

**怎么拆**

拉丁 obfuscātiō 进入中古英语 obfuscacioun；名词借入记录早于现代动词用法，不能写成英语动词先造再派生。

**怎么变成今天的意思**

**拉丁 ob / ob-**  
朝向；在前面；对着；有时加强后面动作

↓

**拉丁 fuscus → fuscāre → obfuscāre**  
暗 → 使暗 → 遮暗、弄得不清楚

↓

**拉丁 obfuscātiō → 中古英语 obfuscacioun → obfuscation**  
使暗、遮蔽 → 混淆、掩饰

常与 evasion 并列，批评回答回避重点。也见 code obfuscation。不要把它和加密完全等同：让内容难读与由密钥控制可读性不是一回事。

**常见搭配与例句**

deliberate obfuscation；a tactic of obfuscation；code obfuscation。

> The journalist demanded clarity rather than further obfuscation.

记者要求说清楚，而不是继续含糊遮掩。

> Obfuscation made the programme harder to read, but it did not change its intended output.

混淆处理让程序更难读，但没有改变其预期输出。

**别混淆**

confusion 是混乱或困惑；obfuscation 更关注造成不透明的做法或结果。

## 这一组要分清什么

clarification 是澄清；obfuscation 让内容更难懂。代码混淆不等于加密：难阅读与必须有密钥才能还原不是一回事。

## 串起来练习

把一段绕来绕去的解释改写清楚，再用 obfuscation 描述原来的问题。
