# 0390 · lax- — 松、宽；松开、放宽、放出

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁语 laxus 是松的、宽的，laxare 是使松开，relaxare 带出 relax、release 和 relaxation。lease 通过法语“让出”支线形成租赁义；relish 通常联系“留下来的余味”，早期关系有不确定性。delay、relay 的 laier 更有拉丁语与法兰克语来源争议，这里作为传统关联对照保留，不列为确定的拉丁语后代。

**把勒紧的带子松一点：身体不再紧绷，规则不再严密，被扣住的东西也可以放出来。**

一只握紧的手慢慢张开，分别对应 relax 的放松与 release 的放出；再想象把房屋使用权交给租客，就能理解 lease 的“让出”支线。

- **身心、组织和规则松下来**：relax, relaxed, relaxing, relaxation, relaxant, relaxer
- **不够严格或松弛的性质**：lax, laxity
- **把被保留的东西放出来**：release
- **让出使用权**：lease, leasable, sublease
- **余味到享受**：relish, disrelish〔早期关系保留不确定性〕
- **肠道和法律专门支线**：laxative, laxation；laches
- **远源有争议的传统关联**：delay, relay
- **release → released：松开、释放到公开发布**：release · released
- **release → releases：松开、放出与发布**：release · releases
- **delay → delayed：没有按原时点到来**：delay · delayed
- **release → releasing：松开、放出与发布**：release · releasing
- **delay → delays：让事情停住、晚一点发生**：delay · delays
- **relax：松开、放宽与几种具体放宽**：relax · relaxes · relaxed · relaxing · relaxation · relaxations
- **languere 词群：活力松下来**：languid · languidly · languor · languish · languishes · languished · languishing
- **lax- 放松、放开 → lease → leased**：leased

## 词形与演化规律

lax- 在 lax、laxity、laxative 中明显；经过法语后可以出现 leas-、les-、lach-。relax、release 是不同借入路线的近亲，不是一个英语词简单改拼写。lax 的鲑鱼义与 lease 的若干古旧同形义另有日耳曼来源。

release 接拉丁 relaxare 松开的词族，released 表过去或完成；不误归 ligare 捆绑词族。

法语松开词接拉丁 relaxare，和 relax 同源。

法语 laier 留下的更远来源有拉丁、法兰克语不同分析，不强归 lax- 直系。

法语 relaisser、relesser 接拉丁 relaxare，不从 ligare 绑直接推出。

古法语留下、让停留材料，深层拉丁或法兰克语来源分析有别。

拉丁 laxus、laxare 的松材料进入 relax；relaxation 名词有法语、拉丁借入路线，不只当作英语 relax 加固定字母串。

拉丁 languere 虚弱的材料，与 laxus 松的通常作更远的同源比较；不是由现代 lax 加后缀造出。languid、languor、languish 各有法语或拉丁借入路线，不把英语词形顺序强排为借入先后。

lease 经法语 laissier 让出、准许，远接拉丁 laxare 放松。现代去 e 加完整 -ed，/s/ 后读 /t/，出租与承租按对象、方向辨认。

## 逐词讲解

<a id="w-4"></a>

### 1. lease — 租约；出租；租用

**音标**：英、美 /liːs/

**先抓住这个画面**

所有权先不转走，但按协议把使用权在一段时间里交给别人。

**怎么拆**

租赁义的名词经盎格鲁法语 les、古法语 lais 传入，动词联系 lesser / laissier“让出、放开”，通常追到拉丁语 laxare；部分资料也考虑日耳曼语影响。

**怎么变成今天的意思**

**拉丁语 laxus → laxare**  
松的、宽的 → 使松开

↓

**古法语 laissier / lesser；名词 lais / lez**  
放开、让给 → 租让；部分研究也考虑日耳曼语影响

↓

**盎格鲁法语 les / lesser → 英语 lease〔名词与动词〕**  
租约；出租、租用

lease a car 可以是租车，也可以由出租方作主语说把车租出去，方向由上下文决定。旧的“拾取、说谎、草地”等同形词另有古英语来源，不由租赁义演变。

**常见搭配与例句**

sign a lease；lease a building from；lease equipment to。

> They signed a three-year lease for the workshop.

他们为这间工作室签了三年租约。

> The company leases equipment to small businesses.

该公司向小企业出租设备。

**别混淆**

rent 更日常；lease 常突出有约定期限的租赁安排和合同，具体法律用法看当地制度。

<a id="w-34"></a>

### 2. leased — 出租、租用了〔过去形式〕

**音标**：英、美 /liːst/

**先抓住这个画面**

物品、房屋没有卖掉，只按约定让另一方使用一段时间，就是 leased。谁提供使用权、谁付钱使用，要看 from 和 to 的方向。

**怎么拆**

lease 去末尾 e，加完整 -ed → leased，/s/ 后读 /t/。经法语 laissier 让、准许、留下，远接拉丁 laxare 放松、放开，形成租让使用权的词族。

**怎么变成今天的意思**

**法语让出、准许使用等材料 → lease 租让**  
相关名词表示租约

↓

**lease 动词 + -ed → leased**  
现代过去式可从出租方或租用方叙述

leased from 是从某人那里租用；leased to 是租给某人；leased equipment 是租赁设备。

**常见搭配与例句**

leased from；leased to；leased equipment。

> They leased a small studio from the owner.

他们向房主租了一间小工作室。

> The owner leased the building to a theatre group.

房主把建筑租给了一个剧团。

**别混淆**

She leased the room to an artist 是她把房间租给艺术家；she leased it from an artist 则是她向艺术家承租。动词相同，方向由介词决定。

<a id="w-16"></a>

### 3. leasable — 可出租的；可租赁的

**音标**：英、美 /ˈliːsəbəl/

**先抓住这个画面**

这块空间、这件设备，可以作为租赁对象交给别人使用。

**怎么拆**

lease + -able；去掉末尾 e 后加后缀，表示能够被租赁。

**怎么变成今天的意思**

**拉丁语 laxus → laxare**  
松的、宽的 → 使松开

↓

**古法语 laissier / lesser；名词 lais / lez**  
放开、让给 → 租让；部分研究也考虑日耳曼语影响

↓

**盎格鲁法语 les / lesser → 英语 lease〔名词与动词〕**  
租约；出租、租用

↓

**英语 lease + -able → leasable**  
可进入租赁安排的

leasable area 是可出租面积，不一定等于建筑的全部面积；走廊、设备间怎样计入，要看采用的口径。

**常见搭配与例句**

leasable space；leasable area；a leasable unit。

> The building contains several leasable units.

这栋楼里有几个可出租单元。

> The plan distinguishes leasable space from shared corridors.

平面方案把可出租空间与共用走廊区分开。

**别混淆**

available for lease 强调现在可供出租；leasable 也可以只描述性质或可出租部分，不保证目前空置。

<a id="w-1"></a>

### 4. release — 释放；放开；发布；发行

**音标**：英、美 /rɪˈliːs/

**先抓住这个画面**

原来被关着、扣着或留在内部的东西，现在让它出来。人可获释，消息可公开，电影可发行。

**怎么拆**

中古英语 relesen 来自古法语 relaisser / relesser 等，远源拉丁语 relaxare“松开”；不来自 ligare“绑”。另外 re- + lease“重新出租”是单独的现代构词。

**怎么变成今天的意思**

**拉丁语 laxus → laxare**  
松的、宽的 → 使松开

↓

**拉丁语 re- + laxare → relaxare**  
松开、舒缓、减弱约束

↓

**古法语 relaisser / relesser → 中古英语 relesen → release**  
放开、解除 → 释放、发布

↓

**并列的现代构词：re- + lease → release /ˌriːˈliːs/**  
重新出租；不由“发布”义演变

release a prisoner 是释放人；release data 是公开数据；release a new version 是发布新版本。名词 a release 可指发布行为或发行物。

**常见搭配与例句**

release from；a press release；a software release。

> The shelter released the recovered bird into the wild.

救护站把康复的鸟放归野外。

> The company will release the update next week.

公司将在下周发布更新。

**别混淆**

relax 让紧张或约束减弱；release 让被控制、保留的对象出来，两者同源而用法不同。

<a id="w-20"></a>

### 5. released — 释放了；松开了；发布、发行了；release 的过去式和过去分词

**音标**：/rɪˈliːst/

**先抓住这个画面**

原来被关着、握着或没有对外开放的东西，现在放出来了。人可以获释，按钮可以松开，新作品也可以向公众发布。

**怎么拆**

release 去末尾 e，加完整 -ed；原词结尾 /s/ 后读 /t/，整词结尾 /st/。经古法语 relaisser／relesser 等接拉丁 relaxare 松开，不源自 ligare 捆绑。

**怎么变成今天的意思**

**拉丁 relaxare → 古法语相关形式 → release**  
松开、放开 → 释放、公开提供

↓

**release 去 e + -ed → released**  
过去释放、松开、发布

released the button 松开了按钮；released a statement 发布声明；released an album 发行专辑；was released from ... 从……获释、解除。

**常见搭配与例句**

released to the public；released last month。

> The team released a new version of the app.

团队发布了这个应用的新版本。

> She released the button when the light turned green.

灯变绿时，她松开了按钮。

**别混淆**

released 描述已经放出或发布，relieved 更常说感到宽慰。release 与 relax 有历史联系，但现代 relax 通常说放松，不能直接替代发布文件的 release。

<a id="w-21"></a>

### 6. releases — 释放、放出、发布〔第三人称单数〕；发行物、发布消息等〔复数〕

**音标**：/rɪˈliːsɪz/

**先抓住这个画面**

把原来受限制、未对外开放的东西放出来，是 releases 的线索。人被释放，气体被放出，影片、软件、消息则被公开提供。

**怎么拆**

release + -s，/s/ 后读 /ɪz/。动词经古法语 relaisser、relesser 等接拉丁 relaxāre 松开，含 re- 与 laxāre 松；名词另有法语 reles 等来源，现代发布义后来扩展。

**怎么变成今天的意思**

**拉丁 relaxāre → 法语 → release**  
松开、放手 → 解除限制、释放

↓

**release + -s → releases；发布用途**  
单数主语放出；多次发布、发行物

releases information 发布信息；releases air 放出空气；new releases 新发行作品、版本。

**常见搭配与例句**

press releases 新闻稿；releases the button 松开按钮。

> The company releases a new version each year.

公司每年发布一个新版本。

> The valve releases air when the pressure rises.

压力升高时，阀门会放气。

**别混淆**

release 在这里和 relax 接同一较早词族。新发行作品叫 releases 时，数的是出版、发行项目；release a person 则是解除拘禁等限制。

<a id="w-23"></a>

### 7. releasing — 释放、放出；发布、发行〔现在分词、动名词〕

**音标**：/rɪˈliːsɪŋ/

**先抓住这个画面**

原来被限制、被留住的东西，现在松开让它出去，是 releasing。人、压力、信息、作品都能在各自场景里被放出来。

**怎么拆**

release 去 e 加 -ing，末尾 s 仍读 /s/。release 经古法语 relaisser、relesser 等接拉丁 relaxare 松开；与 ligare 绑不是直接派生关系。

**怎么变成今天的意思**

**拉丁 relaxare → 法语 → release**  
松开、放松 → 放出、解除限制

↓

**release 去 e 加 -ing → releasing**  
正在释放；也用于把作品、信息推向公众

releasing a new album 发行新专辑；releasing information 发布信息；releasing air 放出空气。

**常见搭配与例句**

releasing the birds 放飞鸟；releasing tension 释放紧张感。

> The band is releasing a new album next month.

乐队下月将发行一张新专辑。

> The volunteers are releasing the birds back into the wild.

志愿者正在把鸟放归野外。

**别混淆**

releasing 在音乐、软件语境常是发布，不一定是有人被关着。重新出租 re-lease 是另一种构形，不与普通 release 混讲。

<a id="w-14"></a>

### 8. sublease — 转租合同；转租

**音标**：名词 /ˈsʌbliːs/；动词 /ˌsʌbˈliːs/

**先抓住这个画面**

你不是房主，却依据原租约把租来的地方再租出去，于是又出现一层租约。

**怎么拆**

sub- + lease“租约、出租”，英语名词和动词用法相联系。

**怎么变成今天的意思**

**拉丁语：sub**  
在下面；从下向上；靠近

↓

**英语前缀：sub-**  
下方；下一级；低于某个标准

↓

**英语：sub- + lease → sublease**  
原租约之下的再出租安排

a sublease 关注合同或安排本身；to sublease an office 是转租办公室。是否允许、责任如何分配，要看具体租约。

**常见搭配与例句**

sign a sublease；sublease office space。

> The sublease runs until the end of August.

这份转租合同持续到八月底。

> The firm subleased part of its office to a small studio.

公司把办公室的一部分转租给了一家小工作室。

**别混淆**

sublet 更常直接说转租动作或房源；sublease 更突出租约，在正式文本中常见。

### 9. delay — 延误；推迟；拖延

**音标**：英、美 /dɪˈleɪ/

**先抓住这个画面**

事情本来该在某时发生，却被向后推了一截，或者迟迟没有开始。

**怎么拆**

来自古法语 delaie〔名词〕、delaiier〔动词〕，其中 laier 是留下、让停留。它可能联系拉丁语 laxare，也有法兰克语来源说，不能确定归入 lax- 直系。

**怎么变成今天的意思**

**古法语 laier“留下、让停留”；远源有争议**  
一说联系 laissier、拉丁语 laxare；另一说联系法兰克语

↓

**古法语 delaie 与 delaiier 分别借入英语**  
delay 名词与动词不是简单的现代派生先后

↓

**英语 delay**  
推迟、耽搁；延误时间

delay the meeting 是把会议推迟；delay doing something 是拖延做某事。交通延误可以没有人故意拖延。

**常见搭配与例句**

a delay of two hours；delay doing；without delay。

> Heavy rain delayed the start of the match.

大雨推迟了比赛开始的时间。

> We should not delay making a decision.

我们不该拖着不作决定。

**别混淆**

postpone 多指有意改到较晚时间；delay 也可指意外耽搁，不保证已经安排新时间。

<a id="w-22"></a>

### 10. delayed — 推迟、耽搁了；延误的〔过去式、过去分词及形容词〕

**音标**：/dɪˈleɪd/

**先抓住这个画面**

本来应该这时到、这时做，现在被留到后面，就是 delayed。它说明比原定或预期更晚，不自动说明最后取消了。

**怎么拆**

delay + -ed，ay 保留 y，元音后读 /d/。delay 经法语 delaie、delaiier，laier 留下的更远来源有拉丁 laxare、法兰克语等不同解释。

**怎么变成今天的意思**

**古法语留待以后相关名词、动词 → delay**  
留下、停留 → 推迟、延误

↓

**delay + -ed → delayed**  
事情已被推迟；处于延误状态

a delayed train 延误列车；delayed by traffic 被交通耽搁；a delayed response 迟来的回应。

**常见搭配与例句**

delayed until Friday 推迟到周五；delayed the start 推迟了开始时间。

> Our train was delayed by heavy snow.

我们的列车因大雪延误了。

> They delayed the start of the meeting by ten minutes.

他们把会议开始时间推迟了十分钟。

**别混淆**

delayed 是晚了，cancelled 是取消了。delay 后直接接要推迟的事情，或用 delay doing 谈推迟做某事。

<a id="w-24"></a>

### 11. delays — 延误、耽搁〔复数〕；推迟、拖延〔第三人称单数〕

**音标**：/dɪˈleɪz/

**先抓住这个画面**

原来应该往前走、按时发生的事，停了一下、往后挪了，就是 delays。可以数几次延误，也可以说什么使事情延后。

**怎么拆**

delay + -s，元音后读 /z/，ay 保留。delay 的名词、动词分别接古法语 delaie、delaiier，含留下、让停留的旧 laier，较远有拉丁、法兰克语等不同分析。

**怎么变成今天的意思**

**古法语 delaie、delaiier → 英语名词、动词 delay**  
让停留 → 延误、推迟

↓

**delay + -s → delays**  
多次延误；某人、某事推迟活动

traffic delays 交通延误；unexpected delays 意外耽搁；delays the start 推迟开始时间。

**常见搭配与例句**

causes delays 造成延误；delays leaving 推迟出发。

> The roadworks caused long delays.

道路施工造成了长时间延误。

> Heavy rain delays the start of the game.

大雨使比赛推迟开始。

**别混淆**

delays doing something 后面可接 ing，不直接说 delays to do。名词和动词都有自己的借入路线，现代同形不代表只在英语里临时互转。

### 12. lax — 松懈的；不严格的；松弛的

**音标**：英、美 /læks/

**先抓住这个画面**

本该绷紧的规则或责任松了，事情因此缺少必要的约束。

**怎么拆**

形容词借自拉丁语 laxus“松的、宽的”。另有古英语 leax 后代的鲑鱼名词，以及 lacrosse 的缩写 lax，都不是这个拉丁形容词的后代。

**怎么变成今天的意思**

**拉丁语 laxus → laxare**  
松的、宽的 → 使松开

↓

**拉丁语 laxus → 英语 lax〔形容词〕**  
松的 → 管理不严格、执行松懈

lax security 通常是批评安保不严。专业语音学中的 lax vowel 是一类元音术语，不能只靠中文“松懈”理解发音细节。

**常见搭配与例句**

lax security；lax enforcement；be lax about。

> The report criticized lax security at the entrance.

报告批评了入口处松懈的安保。

> He had been lax about keeping accurate records.

他一直疏于准确记录。

**别混淆**

relaxed 常可称赞自在；lax 通常说该严格的地方不够严格，带负面评价。

### 13. laxity — 松懈；松弛；不严格

**音标**：英、美 /ˈlæksəti/

**先抓住这个画面**

约束力不够，或原来负责拉紧、支撑的组织比较松。

**怎么拆**

经中古法语 laxité 借拉丁语 laxitas，来自 laxus；现代可对应 lax + -ity，历史上并非只在英语内部加后缀。

**怎么变成今天的意思**

**拉丁语 laxus → laxare**  
松的、宽的 → 使松开

↓

**拉丁语 laxitas → 中古法语 laxité → 英语 laxity**  
松的性质 → 松懈、松弛

laxity in supervision 是监管松懈；joint laxity 或 ligament laxity 是关节或韧带松弛的专业描述，不是在评价人的态度。

**常见搭配与例句**

laxity in supervision；ligament laxity；administrative laxity。

> The investigation found serious laxity in record keeping.

调查发现记录管理严重松懈。

> The examination assessed the degree of joint laxity.

检查评估了关节松弛的程度。

**别混淆**

relaxation 是变松的过程或放松状态；laxity 更直接指不够紧、不够严这种性质。

### 14. laxation — 松开；松弛；排便〔专业、较少见〕

**音标**：美 /lækˈseɪʃən/

**先抓住这个画面**

把“松下来”当成一个过程来讲；医学文字中也可特指排便或促进排便的作用。

**怎么拆**

来自拉丁语 laxatio，基于 laxare；它与 relaxation 共享松弛概念，但现代使用范围更窄。

**怎么变成今天的意思**

**拉丁语 laxus → laxare**  
松的、宽的 → 使松开

↓

**拉丁语 laxatio → 英语 laxation**  
松开、松弛；排便

普通休闲说 relaxation 更自然；laxation 多在旧式或技术文字里出现，尤其与肠道排空有关。

**常见搭配与例句**

promote laxation；normal laxation；laxation of tissue。

> The report recorded changes in laxation during the study.

报告记录了研究期间排便情况的变化。

> The old manual uses laxation to describe the loosening of tissue.

这本旧手册用 laxation 描述组织的松弛。

**别混淆**

laxative 是通便药或通便的；laxation 是松开、排便这类过程。

### 15. relax — 放松；松弛；放宽

**音标**：英、美 /rɪˈlæks/

**先抓住这个画面**

原来绷得很紧，现在把力量卸下一点：肌肉、心情、规则都可以这样变化。

**拉丁语 laxus → laxare**  
松的、宽的 → 使松开

↓

**拉丁语 re- + laxare → relaxare**  
松开、舒缓、减弱约束

↓

学校在最后一周放宽了着装规定。

**别混淆**

rest 偏停止劳作、休息；relax 偏紧张程度降低，休息时也可能心里仍很紧绷。

### 24. relish — 享受；喜爱；兴味；调味酱

↓

↓

风味、调味品；享受、喜欢

### 26. laxative — 泻药；通便的

**音标**：英、美 /ˈlæksətɪv/

### 27. languish — 长期困在不利处境；停滞不振；日渐衰弱

↓

**活力不足 → 没劲、懒洋洋；或久困其中、没有进展**  
学习画面是像失去支撑，精神和进展都垂下来

**常见搭配与例句**

> The proposal may languish in a drawer for months.

那份提案可能会在抽屉里搁上好几个月。

> Without new investment, the business could languish.

没有新投入，这门生意可能会一直萎靡不振。

**别混淆**

remain 可以中性说留下，languish 往往带不利处境、缺少进展、让人惋惜的感觉。

### 34. laches — 怠于行使权利；迟延失权〔衡平法术语〕

**音标**：英、美 /ˈlætʃɪz/

**先抓住这个画面**

本来有机会主张权利，却无合理理由拖延，拖到对方处境因而受损；法院可能据此拒绝某些救济。

**怎么拆**

来自盎格鲁法语 laches、古法语 lachesse“松懈、怠慢”，经 lasche、lascher 追到拉丁语 laxare。结尾 s 不是普通英语复数后缀。

**怎么变成今天的意思**

**拉丁语 laxus → laxare**  
松的、宽的 → 使松开

↓

**通俗拉丁语 \*lascare → 古法语 lascher / lasche → lachesse**  
松开 → 松懈、怠慢

↓

**盎格鲁法语 laches → 英语 laches**  
怠慢 → 衡平法中的不合理迟延

常用于 defense of laches。关键通常包含不合理迟延及对方因此受不利影响，不是“只要晚了一点就失去权利”。

**常见搭配与例句**

the doctrine of laches；a defense of laches；barred by laches。

> The defendant raised laches as an equitable defense.

被告提出以怠于行使权利为依据的衡平法抗辩。

> The court considered both the delay and the prejudice when assessing laches.

法院判断是否构成怠于行使权利时，同时考虑了迟延及其造成的不利影响。

**别混淆**

statute of limitations 通常是法定时效规则；laches 是衡平法上的迟延判断，两者不能直接等同。

## 这一组要分清什么

relaxed 往往是自在，lax 往往批评松懈；relaxing 说使人放松，relaxed 说已经放松。laxative 与 relaxant 是不同作用类别。delay、relay 不可只凭法语相似形式就当成确定同源。

## 串起来练习

比较 a relaxing evening、I feel relaxed、lax security 三个场景；再把 release a report、lease a room、relay a message 各说成一句，记住发布、租赁、转达三种动作。
