# 0722 · pagin- — 页

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 pagina 表示页，英语 page 经法语进入；pagination 保留更明显的 pagin-。更早常联系拉丁 pangere 固定，但从固定到页的具体中间画面有不同解释，不把装订纸张的猜想写成唯一事实。

**PAGIN = PAGE**

一本书的一页，延伸成屏幕里可以打开、阅读、跳转的一页。

- **页与分页**：page；pagination
- **网上的页**：webpage；homepage

## 词形与演化规律

pagina → 法语 page → 英语 page；pagination 保留 pagin- 的形式。webpage 和 homepage 是英语已有词的现代组合。

## 逐词讲解

<a id="w-1"></a>

### 1. page — 页；网页；侍童、侍从；呼叫某人

**音标**：/peɪdʒ/

**先抓住这个画面**

书页是一块可阅读的表面；呼叫人的 page 则走“派侍从找人”这条旁路。

**怎么拆**

纸页义经法语接拉丁 pāgina，与 pangere“固定”相关。侍童义另经法语 page、拉丁化的 pagius，远源有希腊 paidion“男孩”等分析，不应混为纸页派生。

**怎么变成今天的意思**

**拉丁 pangere**  
固定、钉牢；复合动词中可变为 -pingere，分词有 -pactus

↓

**拉丁 pāgina → 古法语 page → 英语 page**  
文字栏、书页；如何从“固定”转为书页有不同解释

↓

**并列旁支：中世纪拉丁 pagius → 古法语 page → 英语 page**  
少年侍从；更早来源有不同分析

↓

**侍从义 page → 动词 page**  
派人去找某人 → 广播或设备呼叫

一张纸的两面通常各是一 page；网页则把同一概念放到了屏幕上。纸页义更早的解释有“纸草片固定在一起”或“文字栏像架上的藤列”等说法，不能把其中一种记忆画面当成定论。page the doctor 是呼叫医生，与翻页不同。

**常见搭配与例句**

on page ten；a web page；turn the page；page someone。

> The answer is printed at the bottom of page twelve.

答案印在第十二页底部。

> This web page takes too long to load.

这个网页加载得太慢。

> The receptionist paged the doctor over the loudspeaker.

接待员通过广播呼叫医生。

**别混淆**

sheet 是一张纸，page 是其中一面。turn the page 也可比喻开始新阶段；page someone 不是给某人翻页。

<a id="w-2"></a>

### 2. homepage — 网站主页；浏览器主页

**音标**：英 /ˈhəʊmpeɪdʒ/；美 /ˈhoʊmpeɪdʒ/

**先抓住这个画面**

像进入一栋楼先到大厅：从这一页开始找其他内容。

**怎么拆**

英语 home 家、返回的起点 + page 页，在互联网语境中形成 home page，也连写为 homepage。home 的日耳曼来源与 page 的拉丁—法语来源在现代英语中组合。

**怎么变成今天的意思**

**英语 home + page**  
起点、归处 + 页

↓

**home page／homepage**  
网站主入口页；也用于浏览器设置的主页

一个学校的网站可能有招生、课程和新闻许多页面，homepage 通常是把主要入口集中起来的主页。浏览器设置里说 homepage，则是你设定的主页地址；它可以指向某个网站，但“浏览器的主页设置”和“网站本身的首页”是两个角度。

**常见搭配与例句**

visit the homepage；return to the homepage；set a homepage。

> The museum’s homepage links to ticket information and current exhibitions.

博物馆主页提供购票信息和当前展览的入口。

> I set the library website as my browser’s homepage.

我把图书馆网站设成了浏览器主页。

**别混淆**

homepage 是一种有入口作用的 webpage，不是整个 website 的严格同义词。home 在这里表示起点，不是说这页必须在自己家里制作或只能介绍家庭。

<a id="w-3"></a>

### 3. webpage — 网页

**音标**：/ˈwebpeɪdʒ/

**先抓住这个画面**

把网上的一份可打开、可阅读的内容看成一页。

**怎么拆**

现代英语 web 网络 + page 页。page 继承拉丁 pagina 经法语进入英语的历史；整个 webpage 是互联网时代的英语组合，不是拉丁古词。

**怎么变成今天的意思**

**拉丁 pagina → 法语 page → 英语 page**  
纸面上的页，后来也用于屏幕上的内容

↓

**英语 web + page → webpage**  
网络中的一页内容

读一篇网上的食谱、新闻或说明，打开的这一页就是 webpage。一个网站通常把许多这样的页面连起来；同一页也可以很长、有图片和按钮，不必像纸张那样刚好占一屏。

**常见搭配与例句**

open a webpage；refresh the webpage；a link to a webpage。

> The webpage includes a recipe and a short video.

这个网页包含一份食谱和一段短视频。

> She sent me a link to the webpage with the application form.

她发给我一个链接，点开是放有申请表的网页。

**别混淆**

webpage 是一页，website 是网站；浏览器 browser 则是打开这些内容的软件。这三个词分别指内容单位、组织起来的站点和使用工具。

<a id="w-4"></a>

### 4. pagination — 编页码；页码编排；分页

**音标**：/ˌpædʒɪˈneɪʃən/

**先抓住这个画面**

把长内容分成一页一页，并让读者知道自己到了哪一页。

**怎么拆**

接拉丁 pāgina“页”。有法语 pagination 借入分析，也有 paginate + -ion 的分析；不能只凭名词、动词的外观判定先后。

**怎么变成今天的意思**

**拉丁 pangere**  
固定、钉牢；复合动词中可变为 -pingere，分词有 -pactus

↓

**拉丁 pāgina → 法语 paginer / pagination**  
书页 → 编页码及其名词

↓

**英语 pagination**  
可能经法语名词借入；也有英语 paginate 派生分析

出版时 pagination 包含页码安排。网站或程序里则常指把很多结果分成多页显示，如每页二十条；它不只是在页面底部印一个数字。

**常见搭配与例句**

continuous pagination；check the pagination；pagination controls。

> The editor checked the pagination before sending the book to print.

编辑在送印前检查了页码编排。

> Pagination lets readers browse the search results twenty at a time.

分页功能让读者每次浏览二十条搜索结果。

**别混淆**

page numbering 明说编号；pagination 还可包含如何把内容划分为页面。不要与侍从义 page 的呼叫路线混淆。

## 这一组要分清什么

page 表示书页的历史与 page 表示侍童的历史不同；不能因为拼写相同就硬说侍童来自纸页。网络里也要分清一页、首页和整个网站。

## 串起来练习

The homepage is one page of the website; pagination divides a long list into several pages.

主页是网站中的一页；分页则把长列表分成几页。
