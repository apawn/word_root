# 3042 · sema- — 标记；信号；意义

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

semantic、semantics 讲语言意义；semiotic、semiotics 把范围扩到图像和各种符号；semaphore 实际传信或协调程序；polysemy、polysemous 说明一词多义。

**sema- 从“一个标记”走向“它表示什么”。**

看见信号，读出意义；一个符号也可能有多个相关解释。

- **语言意义**：semantic、semantics、semantically
- **符号研究**：semiotic、semiotics
- **传讯与同步**：semaphore
- **多个意义**：polysemy、polysemous

## 词形与演化规律

希腊 sēma“标记、信号”→ sēmainein“表示”及 sēmantikos；另一支 sēmeion → sēmeiōtikos。sem-/semant-/semiot- 来自这组历史形式。

## 逐词讲解

<a id="w-1"></a>

### 1. semantic — 语义的；意义层面的

**音标**：英美 /sɪˈmæntɪk/

**先抓住这个画面**

说的是“意思”，而不只是声音或字面形式。

**怎么拆**

接希腊 sēmantikos“表示意义的”，近代英语有经法语 sémantique 借入的路线。semant- 保存“表示、意义”的成分，-ic 是形容词形式。

**怎么变成今天的意思**

**希腊 sēma → sēmainein → sēmantikos**  
标记、信号 → 表示意义 → 有意义的

↓

**近代法语 sémantique**  
用于语言意义及其研究

↓

**英语 semantic**  
有关意义的形容词

a semantic difference 是意思不同；semantic change 是词义变化。技术中 semantic search 指按含义寻找相关内容，不只匹配完全相同的字词。

**常见搭配与例句**

semantic meaning；semantic difference；semantic change；semantic search。

> The translator explained the semantic difference between the two verbs.

译者解释了这两个动词在意义上的区别。

> The search tool uses semantic similarity to find related documents.

搜索工具利用语义相似度寻找相关文档。

**别混淆**

phonetic 关乎语音，syntactic 关乎句法，semantic 关乎意义。拼写相近不代表 semantic similarity 一定高。

<a id="w-2"></a>

### 2. semantics — 语义学；词句的意义

**音标**：英美 /sɪˈmæntɪks/

**先抓住这个画面**

研究我们用一个词、一句话，到底表达了什么。

**怎么拆**

从法语 sémantique 这一学术名称进入英语，末尾用英语学科形式 -ics；远源是希腊 sēma“标记”及 sēmantikos“表示意义的”。现代可与 semantic 配对记，但不是简单给形容词加复数 -s。

**怎么变成今天的意思**

**希腊 sēma → sēmainein → sēmantikos**  
标记、信号 → 表示意义 → 有意义的

↓

**近代法语 sémantique**  
用于语言意义及其研究

↓

**英语 semantics**  
以 -ics 形式命名意义研究；也指表达的意义

语义学会研究“买”和“卖”的意义关系，或一个句子为何有两种理解。日常说 That’s just semantics，常是在抱怨争论只停留在字眼上；这是一种说话态度，不等于语义研究没有价值。

**常见搭配与例句**

lexical semantics；the semantics of a sentence；argue about semantics；semantics is...〔学科通常作单数〕。

> The course covers the semantics of words and sentences.

这门课讲词语和句子的语义。

> We agreed on the plan but kept arguing about the semantics of the announcement.

我们同意了方案，却还在争论公告措辞究竟表达什么。

**别混淆**

syntax 侧重词句怎样组织，semantics 侧重组织出来是什么意思。两者有关，但问题焦点不同。

<a id="w-3"></a>

### 3. semaphore — 旗语；臂板信号；信号量〔计算机〕

**音标**：英 /ˈseməfɔː/；美 /ˈseməfɔːr/

**先抓住这个画面**

用看得见的信号告诉对方信息，或告诉程序现在能不能继续。

**怎么拆**

借法语 sémaphore，利用希腊 sēma“信号”和 -phore“承载、传送者”构成，远源 pherein“携带”。先用于视觉传讯装置，再用于计算机同步机制；动词“打旗语”由名词转用。

**怎么变成今天的意思**

**希腊 sēma + phoros → 近代法语 sémaphore**  
传递信号的装置

↓

**英语 semaphore**  
臂板或旗语信号；后来借用为计算机信号量

旗语以双臂和旗的位置传递信息。程序里的 semaphore 可以像“入场名额计数器”：有名额就进入，没有就等待，用完再归还；它不一定只允许一个任务进入。

**常见搭配与例句**

signal by semaphore；semaphore flags；a counting semaphore；acquire or release a semaphore。

> The sailors practised sending letters by semaphore.

水手们练习用旗语发送字母。

> The program uses a semaphore to limit the number of simultaneous downloads.

程序用信号量限制同时下载的数量。

**别混淆**

mutex 通常用于互斥访问；semaphore 可管理多个名额或协调事件。两者有关，但不能简单视作同义词。

<a id="w-4"></a>

### 4. semiotics — 符号学

**音标**：英 /ˌsemiˈɒtɪks/；美 /ˌsemiˈɑːtɪks/

**先抓住这个画面**

研究文字、图像、动作等怎样让人读出意义。

**怎么拆**

远源希腊 sēmeiōtikos“识别、解释征象的”，接 sēmeion“符号、征象”和 sēma“标记”。英语先有医学征象研究用法，后来发展为符号研究的名称；-ics 标学科，并非 semi-“一半”。

**怎么变成今天的意思**

**希腊 sēma → sēmeion → sēmeiōtikos**  
标记 → 征象、符号 → 识别或解释征象的

↓

**拉丁化形式 → 英语 semiotic**  
早期用于医学征象；后来用于符号研究

↓

**semiotic + 学科形式 -ics → semiotics**  
征象研究；后来用于更广的符号及意义研究

红灯、品牌标志、制服、电影里的颜色，都可能成为分析对象：它们怎样代表事物，人们又怎样学会读懂？所以 semiotics 的范围不只限于词典中的词义。

**常见搭配与例句**

the study of semiotics；visual semiotics；semiotics is...；semiotics and culture。

> The class used traffic signs to introduce semiotics.

课堂用交通标志来介绍符号学。

> She studies the semiotics of clothing in historical films.

她研究历史电影中服装所传达的符号意义。

**别混淆**

semantics 常聚焦语言意义；semiotics 讨论更广的符号系统，两者相交但不完全相同。

<a id="w-5"></a>

### 5. semantically — 在语义上；从意思来看

**音标**：英美 /sɪˈmæntɪkli/

**先抓住这个画面**

先把拼写、语音放到一边，比较实际表达的意思。

**怎么拆**

英语 semantic + -ally，形成副词。虽然写出 -ically，常见读法中 -cally 连成 /kli/，不必逐个字母拖长。

**怎么变成今天的意思**

**希腊 sēma → sēmainein → sēmantikos**  
标记、信号 → 表示意义 → 有意义的

↓

**近代法语 sémantique**  
用于语言意义及其研究

↓

**英语 semantic → semantically**  
语义的 → 从语义上说

semantically similar 是意思接近，不等于表达在所有场合都能互换；语气、语体、搭配仍可能不同。这个副词常用来说明比较的角度。

**常见搭配与例句**

semantically related；semantically equivalent；semantically different；semantically ambiguous。

> These two expressions are semantically similar but differ in tone.

这两个表达意思接近，但语气不同。

> The sentence is grammatical but semantically strange.

这个句子语法通顺，但意思很奇怪。

**别混淆**

grammatically correct 说语法没问题，semantically odd 说意思奇怪；一句话可以前者成立、后者也成立。

<a id="w-6"></a>

### 6. semiotic — 符号学的；有关符号意义的

**音标**：英 /ˌsemiˈɒtɪk/；美 /ˌsemiˈɑːtɪk/

**先抓住这个画面**

从“这个形象在传达什么”来观察事物。

**怎么拆**

源于希腊 sēmeiōtikos 的拉丁化借词路线。英语早期用于疾病征象，后来用于符号研究；现代与 semiotics 配成形容词、学科名，不应只解释成从较晚的现代学科名删掉 s。

**怎么变成今天的意思**

**希腊 sēma → sēmeion → sēmeiōtikos**  
标记 → 征象、符号 → 识别或解释征象的

↓

**拉丁化形式 → 英语 semiotic**  
早期用于医学征象；后来用于符号研究

↓

**现代 semiotic 用法**  
与符号及其解释有关

a semiotic analysis of an advertisement 会看颜色、姿势、文字如何共同制造意义，而不只是评价广告漂亮不漂亮。这里的 semi- 不是半个，也与半自动无关。

**常见搭配与例句**

semiotic analysis；a semiotic system；semiotic meaning；a semiotic approach。

> The essay offers a semiotic analysis of the company’s logo.

文章从符号意义的角度分析了公司的标志。

> Her semiotic approach connects colours, gestures, and words.

她的符号学方法把颜色、手势和文字联系起来分析。

**别混淆**

semantic 常谈表达的意义，semiotic 更强调符号怎样承载、组织并被解释。

<a id="w-7"></a>

### 7. polysemy — 一词多义

**音标**：英美 /pəˈlɪsɪmi/

**先抓住这个画面**

同一个词像一棵树，从核心意思长出几个相关意思。

**怎么拆**

poly-“多”与表示意义的 sem- 相连。英语有从法语 polysémie 借入的分析，远源接中古拉丁 polysemus 与希腊 polysēmos“多义的”；也可按 polyseme + -y 作英语构词分析。

**怎么变成今天的意思**

**希腊 poly- + sēma → polysēmos**  
多 + 意义、符号 → 多义的

↓

**中古拉丁 polysemus**  
多义的

↓

**近代法语 polysémie → 英语 polysemy**  
一词多义；英语中也可按 polyseme + -y 分析

head 可以是头部，也可以是负责人或队列前端，这些意思之间有可理解的联系。polysemy 常专指这种相关多义，而不是把所有拼写一样的词都不加区分地合为一个来源。

**常见搭配与例句**

lexical polysemy；an example of polysemy；polysemy and context。

> The word head is a useful example of polysemy.

head 是说明一词多义的好例子。

> Context helps readers choose the intended meaning when polysemy is involved.

一个词有多个意思时，语境帮助读者选出这里要表达的意思。

**别混淆**

homonymy 常谈同形或同音而意义、来源不同的词；polysemy 谈同一个词的多个相关意思。实际边界有时需要分析。

<a id="w-8"></a>

### 8. polysemous — 多义的

**音标**：英 /pəˈlɪsəməs/；美 /ˌpɑːliˈsiːməs/

**先抓住这个画面**

一个词不止一个意思，而且这些意思通常能联系起来。

**怎么拆**

借中古拉丁 polysemus，接希腊 polysēmos“多义的”，英语采用 -ous 形容词形式。它不是简单从英语 polysemy 改尾巴才首次出现；现代二者可配对学习。

**怎么变成今天的意思**

**希腊 poly- + sēma → polysēmos**  
多 + 意义、符号 → 多义的

↓

**中古拉丁 polysemus**  
多义的

↓

**英语 polysemous**  
具有多个意义的

说 a polysemous word，是在描述这个词的词义结构。它不意味着每次使用都含糊不清：放进具体句子后，读者往往很容易知道是哪一个意思。

**常见搭配与例句**

a polysemous word；polysemous expressions；highly polysemous verbs。

> Run is a highly polysemous verb in English.

run 是英语中一个义项很多的动词。

> The dictionary groups the related senses of this polysemous word.

词典把这个多义词中彼此相关的义项归在一起。

**别混淆**

ambiguous 说某次表达可能有歧义；polysemous 说词本身有多个义项。有多义词的句子不一定有歧义。

## 这一组要分清什么

semiotic 的 semi- 不是“一半”。词语 polysemous 也不等于每个使用它的句子都 ambiguous。

## 串起来练习

拿红灯、head 的多个意思、语义搜索三个例子，分别联系 semiotics、polysemy、semantic。
