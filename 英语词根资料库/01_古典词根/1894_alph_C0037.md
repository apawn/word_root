# 1894 · alph- — 希腊字母 alpha；第一

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

这里的 alph- 主要来自字母名，不是一个可以随便往单词前加的万能前缀。alpha 能延伸到最初阶段，alphabet 是整套字母；工作中最常用的延伸是 alphabetical order“字母顺序”及 alphabetize“按字母排列”。

**alpha 是希腊字母表的第一位；alphabet 则把 alpha 和 beta 拼在一起。**

像把“甲、乙”连起来指整套排列，alpha + beta 给整套字母起了名字。

- **字母与次序**：alpha、alphabet
- **描述字母和排序**：alphabetic、alphabetical、alphabetically
- **进行排序**：alphabetize、alphabetise

## 词形与演化规律

古字母名 aleph 一系进入希腊成为 alpha；alpha + beta → alphabetos，经拉丁进入英语 alphabet。alphabetic、alphabetical 的历史也涉及拉丁、法语形容词，不能只用长短判断派生先后。

## 逐词讲解

<a id="w-1"></a>

### 1. alpha — 希腊字母 α；最初阶段的版本；居主导地位者

**音标**：英美 /ˈælfə/

**先抓住这个画面**

因为排在第一，就被借来标记“第一、开始、较早的一阶段”。

**怎么拆**

经拉丁 alpha 接希腊字母名 alpha，更早接腓尼基等闪语 aleph 一系；这个古字母名与“牛”有关。现代英语 alpha 的通常意思是字母和次序，不是牛。

**怎么变成今天的意思**

**闪语字母名 aleph 一系**  
字母名的古义与牛有关

↓

**希腊 alpha → 拉丁 alpha → 英语 alpha**  
希腊字母表第一位的名称

↓

**英语扩展义**  
最初阶段的版本；也可说居主导位置的个体

软件的 alpha version 通常指较早的测试版本，“第一”的序列感仍在。形容某人为 the alpha 则是在说他占主导；这是一种用词和比喻，不是给所有人的性格划定科学等级。

**常见搭配与例句**

the letter alpha；an alpha version；alpha testing；the alpha of the group。

> The teacher used alpha to label the first angle.

老师用 alpha 标记第一个角。

> The team is testing an alpha version of the editing tool.

团队正在测试这款编辑工具的早期版本。

**别混淆**

beta 是第二个希腊字母，软件里通常是后续测试阶段；项目各自如何划阶段，还得看具体规则。

<a id="w-2"></a>

### 2. alphabet — 字母表；一套字母系统

**音标**：英美 /ˈælfəbet/

**先抓住这个画面**

不是单个 A 或 B，而是把一套书写字母放在一起看。

**怎么拆**

经拉丁 alphabetum 接希腊 alphabetos，来自 alpha + beta，也就是希腊字母表的前两个字母名。像用“甲乙”指一整套次序，而不是把每个字母全念完。

**怎么变成今天的意思**

**腓尼基等闪语字母名 aleph、beth → 希腊 alpha、beta**  
希腊字母表开头的两个字母名

↓

**希腊 alphabetos → 拉丁 alphabetum**  
用头两个字母的名字指整套字母

↓

**中古英语 alphabete → 英语 alphabet**  
字母表；字母系统

the English alphabet 是英语的字母表；a different alphabet 是另一套字母系统。现代通用英语中，单个字母通常叫 a letter，不把每个 A、B 都叫 an alphabet。

**常见搭配与例句**

learn the alphabet；the Greek alphabet；letters of the alphabet。

> The children learned the alphabet through songs and games.

孩子们通过歌曲和游戏学习字母表。

> The two languages use different alphabets.

这两种语言使用不同的字母系统。

**别混淆**

letter 是一个字母；alphabet 是一套字母。alphabetical order 指按字母表的既定顺序排列，不是只要求内容里出现字母。

<a id="w-5"></a>

### 3. alphabetic — 字母的；使用字母的；按字母顺序的

**音标**：英美 /ˌælfəˈbetɪk/

**先抓住这个画面**

重点常在“这些是字母”，或者“这种书写用字母来表示声音”。

**怎么拆**

现代可拆 alphabet + -ic；历史上有法语 alphabétique 和拉丁 alphabeticus 的借入来源，不要把现代拆法当成唯一生成经过。

**怎么变成今天的意思**

**腓尼基等闪语字母名 aleph、beth → 希腊 alpha、beta**  
希腊字母表开头的两个字母名

↓

**希腊 alphabetos → 拉丁 alphabetum**  
用头两个字母的名字指整套字母

↓

**拉丁形容词 alphabeticus；法语 alphabétique → 英语 alphabetic**  
与字母有关的，采用字母的

alphabetic characters 与数字、标点相对；alphabetic writing system 说字母式书写。它也能表示字母顺序，但单纯谈排序时 alphabetical 更常用。

**常见搭配与例句**

alphabetic characters；alphabetic writing；an alphabetic code。

> The code must begin with an alphabetic character rather than a digit.

代码必须以字母开头，而不能以数字开头。

> The lesson compares alphabetic and syllabic writing systems.

这节课比较字母文字系统与音节文字系统。

**别混淆**

alphabetic 通常强调字母这一性质；alphabetical 常强调排序。两者有重叠，不是绝对不能互换的一对。

<a id="w-3"></a>

### 4. alphabetical — 按字母顺序的；字母的

**音标**：英美 /ˌælfəˈbetɪkəl/

**先抓住这个画面**

让名字或词语按 A、B、C 的次序排队，方便查找。

**怎么拆**

现代可看作 alphabet + -ical；也有接拉丁形容词 alphabeticus 再加 -al 的分析。不要仅凭它比 alphabetic 长，就认定必定由较短英语词先派生出来。

**怎么变成今天的意思**

**腓尼基等闪语字母名 aleph、beth → 希腊 alpha、beta**  
希腊字母表开头的两个字母名

↓

**希腊 alphabetos → 拉丁 alphabetum**  
用头两个字母的名字指整套字母

↓

**拉丁形容词 alphabeticus 与英语 -al；亦有 alphabet + -ical 分析**  
英语 alphabetical：与字母有关，尤指按字母顺序的

an alphabetical list 是按字母顺序排的名单。in alphabetical order 是最常用搭配；这时它说的是排列规则，不是名单里的内容都只有单个字母。

**常见搭配与例句**

in alphabetical order；an alphabetical list；an alphabetical index。

> Please put the surnames in alphabetical order.

请把姓氏按字母顺序排列。

> An alphabetical index makes the terms easier to find.

按字母顺序编排的索引让术语更容易查找。

**别混淆**

chronological order 按时间，numerical order 按数字，alphabetical order 按字母。说按姓氏排，还要交代 by surname。

<a id="w-4"></a>

### 5. alphabetically — 按字母顺序地

**音标**：英美 /ˌælfəˈbetɪkli/

**先抓住这个画面**

给“排列、列出、保存”这些动作补一句：按 A 到 Z 的顺序做。

**怎么拆**

英语 alphabetical + -ly；常见读法把末段压为 /ɪkli/。词形仍保留 alphabetical 的构词来源，不能因读音缩短就漏写字母。

**怎么变成今天的意思**

**腓尼基等闪语字母名 aleph、beth → 希腊 alpha、beta**  
希腊字母表开头的两个字母名

↓

**希腊 alphabetos → 拉丁 alphabetum**  
用头两个字母的名字指整套字母

↓

**拉丁形容词 alphabeticus 与英语 -al；亦有 alphabet + -ical 分析**  
英语 alphabetical：与字母有关，尤指按字母顺序的

↓

**英语 alphabetical + -ly → alphabetically**  
把排序方式表达成副词

sort alphabetically 是按字母顺序排序；list alphabetically by surname 是按姓氏的字母顺序列出。副词告诉你怎么排，by 后面的内容再说明拿哪一个字段作依据。

**常见搭配与例句**

sort alphabetically；list alphabetically；arrange alphabetically by name。

> The app sorts contacts alphabetically by surname.

应用按姓氏的字母顺序排列联系人。

> The files were arranged alphabetically, so I found the folder quickly.

文件按字母顺序排好了，所以我很快找到了那个文件夹。

**别混淆**

an alphabetical list 用形容词修饰名单；list the names alphabetically 用副词修饰列出动作。

<a id="w-6"></a>

### 6. alphabetize — 把……按字母顺序排列

**音标**：英美 /ˈælfəbətaɪz/

**先抓住这个画面**

不用说一长串“按字母顺序整理”，一个动词就能表达这个动作。

**怎么拆**

英语 alphabet + -ize，形成使动、处理类动词。这里是按字母次序整理；-ize 拼法在美式常用，英式也使用。

**怎么变成今天的意思**

**腓尼基等闪语字母名 aleph、beth → 希腊 alpha、beta**  
希腊字母表开头的两个字母名

↓

**希腊 alphabetos → 拉丁 alphabetum**  
用头两个字母的名字指整套字母

↓

**中古英语 alphabete → 英语 alphabet**  
字母表；字母系统

↓

**英语 alphabet + -ize → alphabetize**  
把词、名字等按字母顺序排列

alphabetize the entries 就是把条目按字母顺序排列。它需要排序对象，不是“教别人字母表”；被动式 alphabetized by name 常出现在界面或整理说明里。

**常见搭配与例句**

alphabetize a list；alphabetize the entries；alphabetize by title。

> Could you alphabetize the list before sending it to the team?

你能先把名单按字母顺序排好，再发给团队吗？

> The program alphabetizes book titles automatically.

程序会自动按字母顺序排列书名。

**别混淆**

alphabetize 是动作；alphabetical 是结果或性质；alphabetically 是动作采用的方式。

<a id="w-7"></a>

### 7. alphabetise — 把……按字母顺序排列〔英式常见拼写〕

**音标**：英美 /ˈælfəbətaɪz/

**先抓住这个画面**

换用 -ise 的拼法，做的还是同一个“按字母排队”的动作。

**怎么拆**

alphabet + -ise；与 alphabetize 是同一个派生词的拼写变体。结尾仍读 /aɪz/，不是因为写 s 就读 /aɪs/。

**怎么变成今天的意思**

**腓尼基等闪语字母名 aleph、beth → 希腊 alpha、beta**  
希腊字母表开头的两个字母名

↓

**希腊 alphabetos → 拉丁 alphabetum**  
用头两个字母的名字指整套字母

↓

**中古英语 alphabete → 英语 alphabet**  
字母表；字母系统

↓

**英语 alphabet + -ise / -ize → alphabetise / alphabetize**  
两种拼法表达同一排序动作

alphabetise names 可以用于纸质档案，也可以用于数字列表。英式文本中 -ise 常见，但不能反过来说 -ize 在英国就是错的。

**常见搭配与例句**

alphabetise the names；alphabetise a bibliography；alphabetised entries。

> She alphabetised the labels before putting them on the shelves.

她把标签按字母顺序排好，再放到架子上。

> We need to alphabetise the bibliography by the authors’ surnames.

我们需要按作者姓氏的字母顺序整理参考书目。

**别混淆**

sort 只说排序，还可以按日期、大小；alphabetise 自带“字母顺序”这一规则。

## 这一组要分清什么

一个字母通常叫 letter，整套字母叫 alphabet。alphabetic characters 强调字符类别，alphabetical order 强调排列规则。

## 串起来练习

把“这是一个字母”“这是字母表”“按字母顺序排列名字”分别用 letter、alphabet、alphabetize 表达。
