# 0388 · gramm- — 写下、画出的符号；字母、记录

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

希腊语 gramma 指写下、画出的东西，与 graphein“写、画”相连；其变化词干 grammat- 解释了 grammatical、diagrammatic 中的 t。部分词直接承希腊语、拉丁语、法语历史，另一些如 telegram、hologram、pangram 是近代用古典成分新造，不能统统画成古希腊已有的技术名称。

**先在纸上留下一笔，再让这些笔画组成字母、图形、消息或安排。gramm- 抓住的不是某一种内容，而是写下或画出的标记。**

同一张纸上，几行文字成为 grammar 的研究对象，一份预告成为 program 的远源，几条关系线成为 diagram，一组重排字母成为 anagram。

- **语言怎样组成句子**：grammar, grammatical, grammatically, grammatic, grammaticist
- **预先安排到计算机程序**：program, programme, programmer, programming, programmable, reprogram, programmatic, programmatically
- **用图记录和说明**：diagram, diagrammatic, hologram, monogram, pentagram
- **远距离消息与记忆痕迹**：telegram, telegramme, engram
- **简短而机智的文字**：epigram, epigrammatic
- **字母重排与字母限制**：anagram, anagrammatic, lipogram, pangram, pangrammatic
- **把几个符号作为一组**：trigram, tetragram

## 词形与演化规律

-gram 常构成记录、图式、字母组合的名词；grammat- 常见于形容词。program / programme 的差别主要是拼写习惯。grammar 的 -ar 来自历史语音变化，不是英语另加的施事后缀。

## 逐词讲解

<a id="w-1"></a>

### 1. program — 程序；项目、计划；节目；编程、安排

**音标**：英 /ˈprəʊɡræm/；美 /ˈproʊɡræm/

**先抓住这个画面**

先把要做的事情写出一个安排，再照着执行。这个画面既能通向节目单，也能通向计算机指令。

**怎么拆**

经法语 programme、后期拉丁语 programma 来自希腊语 programma“公告”，基于 pro- + graphein“预先或公开写出”。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 prographein → programma**  
预先写出、公开写出 → 公告

↓

**后期拉丁语 programma → 法语 programme → 英语 program / programme**  
公告 → 事先列出的安排、节目；后来指计算机指令

美式英语各义通常写 program；英式计算机程序通常也写 program，其他义多写 programme。它可以是软件、培训计划，也可以是电视节目。

**常见搭配与例句**

a computer program；a training program；program a device。

> The program checks each file for duplicate records.

这个程序检查每个文件中的重复记录。

> The city launched a program to restore old buildings.

该市启动了修复老建筑的项目。

> We programmed the timer to switch off at midnight.

我们把定时器设为午夜关闭。

**别混淆**

application 通常是完成用户任务的软件；program 范围更广，短小脚本和底层工具也可以是程序。

<a id="w-2"></a>

### 2. programme — 节目；计划、项目；节目单〔主要英式拼写〕

**音标**：英 /ˈprəʊɡræm/；美 /ˈproʊɡræm/

**先抓住这个画面**

把接下来要发生的内容排成一套：可以是电视节目、音乐会安排，也可以是长期项目。

**怎么拆**

与 program 是同一历史词的拼写变体；法语 programme 经后期拉丁语连到希腊语 programma“公告”。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 prographein → programma**  
预先写出、公开写出 → 公告

↓

**后期拉丁语 programma → 法语 programme → 英语 program / programme**  
公告 → 事先列出的安排、节目；后来指计算机指令

英式常写 television programme、training programme；计算机程序通常仍写 program。两种拼写没有普遍适用的“一个是名词、一个是动词”区分。

**常见搭配与例句**

a television programme；a training programme；the concert programme。

> The programme explores the history of the railway.

这个节目探讨了铁路的历史。

> The university introduced a new training programme.

大学推出了一项新的培训计划。

**别混淆**

program 与 programme 的主要区别是地区和领域的拼写习惯，不能凭多出的 me 猜不同词根。

<a id="w-3"></a>

### 3. programming — 编程；节目编排；播出内容

**音标**：英 /ˈprəʊɡræmɪŋ/，也读 /ˈprəʊɡrəmɪŋ/；美 /ˈproʊɡræmɪŋ/

**先抓住这个画面**

把要做的动作安排成程序，或把要播出的节目安排成一套内容。

**怎么拆**

program / programme + -ing，双写 m；从动作分词和动名词发展出领域、活动名称。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 prographein → programma**  
预先写出、公开写出 → 公告

↓

**后期拉丁语 programma → 法语 programme → 英语 program / programme**  
公告 → 事先列出的安排、节目；后来指计算机指令

↓

**英语 program(me) + -ing → programming**  
编排的活动；计算机编程；节目内容

computer programming 是写程序；children’s programming 常指儿童节目内容。看到电视台语境时别自动译成儿童学编程。

**常见搭配与例句**

learn programming；a programming language；television programming。

> She learned programming by building small games.

她通过制作小游戏学习编程。

> The channel expanded its educational programming.

这个频道增加了教育节目内容。

**别混淆**

program 是一个程序或项目；programming 常说编写、安排这个活动或总体播出内容。

### 4. grammar — 语法；语法学；语法书

**音标**：英 /ˈɡræmə/；美 /ˈɡræmər/

**先抓住这个画面**

词不是随意堆在一起：怎样变化、怎样排队、怎样相互配合，构成一种语言的 grammar。

**怎么拆**

来自古法语 gramaire，经拉丁语 grammatica 连到希腊语 grammatike“有关文字的学问”；远源 gramma“写下的符号”。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 grammatike〔techne〕→ 拉丁语 grammatica**  
有关文字、语言的学问

↓

**通俗拉丁语 \*grammaria → 古法语 gramaire → 中古英语 gramere → grammar**  
文字学问 → 语言组织规则、语法学

grammar 包括词形和句子组织规则。口语和不同方言也有规则，并非只有教材上的标准书面语才“有语法”。

**常见搭配与例句**

English grammar；a grammar rule；a reference grammar。

> The course teaches grammar through short conversations.

这门课通过简短对话教授语法。

> Every language has a grammar, even without a written tradition.

每种语言都有语法，即使它没有书面传统。

**别混淆**

vocabulary 说有哪些词；grammar 说这些词怎样组织。grammar book 是讲规则的书，不是规则本身。

### 5. diagram — 示意图；图解；用图表示

**音标**：英、美 /ˈdaɪəɡræm/

**先抓住这个画面**

把不必照相式画真的细节省掉，留下最能说明结构和关系的线、点、箭头。

**怎么拆**

来自法语 diagramme，传统词源路线经拉丁语 diagramma 到希腊语 diagramma、diagraphein“用线画出”；另有词典列意大利语中介。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 dia- + graphein → diagramma**  
用线画出、描绘 → 图形

↓

**拉丁语 diagramma → 法语 diagramme → 英语 diagram**  
示意图；词典也有经意大利语的中介说明

电路图、流程图、结构图都可以叫 diagram。它的任务通常是解释关系，不是追求画得像照片。动词 diagram 是把内容画成图。

**常见搭配与例句**

a diagram of；a labelled diagram；diagram a sentence。

> The diagram shows how water moves through the system.

示意图展示了水怎样流经这个系统。

> She diagrammed the sentence to explain its structure.

她把句子画成结构图来解释它的构造。

**别混淆**

chart 常用于数据或安排；diagram 更常说明结构、过程和连接关系。

### 6. programmer — 程序员；节目编排者；编程装置

**音标**：英 /ˈprəʊɡræmə/；美 /ˈproʊɡræmər/

**先抓住这个画面**

把需要完成的工作变成一套可执行指令的人，现代最常想到程序员。

**怎么拆**

program + -er，拼写中双写 m；早期也可指安排节目的人，计算机时代强化了写程序义。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 prographein → programma**  
预先写出、公开写出 → 公告

↓

**后期拉丁语 programma → 法语 programme → 英语 program / programme**  
公告 → 事先列出的安排、节目；后来指计算机指令

↓

**英语 program + -er → programmer**  
安排程序的人或装置；程序员

程序员的工作不只是输入代码，还包括理解需求、排错和维护。技术语境的 device programmer 则可能是给芯片写入内容的设备。

**常见搭配与例句**

a computer programmer；a software programmer；a device programmer。

> The programmer traced the error to a missing condition.

程序员追查出错误来自一个遗漏的条件。

> A festival programmer selected the films for the event.

电影节的节目编排者为活动选出了参展影片。

**别混淆**

developer 常涵盖更广的软件开发工作；programmer 更直接点出编程这一职责，实际岗位名称有重叠。

### 7. telegram — 电报；电报消息

**音标**：英 /ˈtelɪɡræm/；美 /ˈteləɡræm/

**先抓住这个画面**

把短消息远距离传过去，再由对方收到写下的文字。

**怎么拆**

十九世纪用 tele-“远” + -gram“写下的消息”造词；不是古希腊已经存在的电报名称。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**近代英语 tele- + -gram → telegram**  
远距离传送的文字消息

传统电报通常讲究简短，因为费用与字数等因素有关。今天在历史叙述中更常见；大写 Telegram 也可另作应用名称。

**常见搭配与例句**

send a telegram；receive a telegram；a congratulatory telegram。

> A telegram arrived announcing the ship’s safe return.

一封电报送到了，通知船只已经平安返航。

> She kept the congratulatory telegram in a drawer.

她把那封贺电保存在抽屉里。

**别混淆**

telegraph 是通信系统、装置或发报动作；telegram 是通过它发出的消息。

### 8. grammatical — 语法的；符合语法的

**音标**：英、美 /ɡrəˈmætɪkəl/

**先抓住这个画面**

可以说“与语法有关”，也可以判断一句话是否符合正在讨论的语言变体的组织规则。

**怎么拆**

经中古法语 grammatical 来自拉丁语 grammaticalis，基于 grammaticus；不是现代 grammar 后简单加 -ical 的唯一历史。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 grammatikos → 拉丁语 grammaticus / grammaticalis**  
关于语言、语法的

↓

**中古法语 grammatical → 英语 grammatical**  
语法的；符合语法规则的

grammatical analysis 是语法分析；a grammatical sentence 是合乎相关语法规则的句子。合语法不保证意思合理或表达自然。

**常见搭配与例句**

grammatical structure；grammatical errors；a grammatical sentence。

> The sentence is grammatical, but its meaning is unclear.

这句话语法成立，但意思不清楚。

> The lesson focuses on grammatical differences between the two languages.

这节课侧重两种语言的语法差异。

**别混淆**

grammatical 判断结构；idiomatic 判断说法是否地道，两者可以分开。

### 9. hologram — 全息图；全息影像

**音标**：英 /ˈhɒləɡræm/；美 /ˈhɑːləɡræm/

**先抓住这个画面**

记录的不只是平面明暗，还包含重建光波所需的信息，所以换个角度看，可以显出空间深度。

**怎么拆**

加博在二十世纪以 holo-“全部、完整” + -gram“记录”命名。这里的完整指波前信息的记录思路，并不等于记录物体的一切属性。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 holos“整个” + gramma“记录”**  
完整记录这一构词想法

↓

**加博使用 hologram 命名干涉记录 → 现代英语 hologram**  
可用来重建波前的全息记录；相应影像

真正的全息记录利用波的干涉保存重建信息。日常也有人把舞台上的立体投影效果泛称 hologram，但那些效果未必采用全息技术。

**常见搭配与例句**

a hologram of an object；record a hologram；a security hologram。

> The hologram appears to change as you move your head.

你移动头部时，这幅全息影像看上去会发生变化。

> The experiment used a reference beam to record the hologram.

实验利用参考光束记录全息图。

**别混淆**

普通照片直接记录强度分布；全息方法把相位信息也编码进干涉记录，二者不是只差“看起来立体”。

### 10. programmable — 可编程的；可预设运行方式的

**先抓住这个画面**

### 14. anagram — 变位词；字母重排词

**音标**：英、美 /ˈænəɡræm/

**先抓住这个画面**

字母还是原来那一堆，只换排列顺序，就变成另一个词或短语。

**怎么拆**

经法语 anagramme 或新拉丁语 anagramma 传入，由希腊语 ana- 与 gramma 的成分组合，强调重新排列字母。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 ana- 与 gramma → 新拉丁语 anagramma、法语 anagramme**  
重新组合字母

↓

**英语 anagram**  
字母重排所得的词、短语

listen 与 silent 正好互为 anagram：每个字母及其次数都对应。一般忽略空格和大小写，但不能偷偷添字母或少字母。

**常见搭配与例句**

an anagram of；solve an anagram；rearrange into an anagram。

> “Silent” is an anagram of “listen”.

silent 是 listen 的字母重排词。

> The puzzle asks players to find an anagram of each name.

这个谜题要求玩家为每个名字找出字母重排形式。

**别混淆**

palindrome 是正读反读相同；anagram 只要求重排后字母总量相同。

### 18. engram — 记忆痕迹；记忆的生物学表征

**音标**：英、美 /ˈenɡræm/

**怎么拆**

借自德语 Engramm，由 Richard Semon 用希腊语 en-“在内”与 gramma“印记、记录”成分造词；后来进入英语记忆研究。

↓

**英语 engram**

记忆痕迹不是字面意义上存放在大脑某个小抽屉里的录像。

**别混淆**

memory 是记忆经验或能力；engram 专指支持记忆的物理、生物学痕迹这一概念。

anagrammatic 不只是“拼写相近”；多一个或少一个字母就不再是严格的变位关系。

<a id="w-24"></a>

### 24. grammatic — 语法的〔较旧、少见〕

**音标**：英 /ɡrəˈmætɪk/

**先抓住这个画面**

意思接近 grammatical，只是现代日常文章更少采用这个短一些的形式。

**怎么拆**

来自拉丁语 grammaticus，连到希腊语 grammatikos；不是现代英语把 grammatical 的 -al 随便截掉才有。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 grammatikos → 拉丁语 grammaticus → 英语 grammatic**  
与文字、语法学有关的

旧文献和较专门的论述可能说 grammatic forms。一般学习表达“语法上的”，优先使用 grammatical 更自然。

**常见搭配与例句**

grammatic forms；grammatic analysis；grammatic structure。

> The old treatise compares the grammatic forms of two languages.

这部旧论著比较两种语言的语法形式。

> The editor retained the author’s term “grammatic analysis”.

编辑保留了作者使用的 grammatic analysis 这一术语。

**别混淆**

grammatic 是已有的旧词形；grammatical 是现代更常用的对应形容词。

<a id="w-25"></a>

### 25. grammaticist — 语法研究者〔罕见〕

**音标**：构词参考读法 /ɡrəˈmætɪsɪst/

**先抓住这个画面**

把语言的词形和句法规则当作研究对象的人。这个词非常少见，日常一般称 grammarian。

**怎么拆**

形式上可分析为 grammatic + -ist“从事者”；grammatic 经拉丁语连到希腊语 gramma。现有材料能确认词义，不能确定最早造词者。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**拉丁语 grammaticus → 英语 grammatic**  
与语法有关的

↓

**英语 grammatic + -ist → grammaticist**  
语法研究者；具体首造历史未定

它说研究角色，不表示这个人说话一定处处标准。读到旧学术著作时把它理解为研究语法的人即可。

**常见搭配与例句**

a grammaticist；the work of a grammaticist。

> The grammaticist compared the verb forms in the surviving texts.

这位语法研究者比较了传世文本中的动词形式。

> Her essay discusses the methods of an early grammaticist.

她的文章讨论了一位早期语法研究者的方法。

**别混淆**

grammarian 常用得多；grammaticist 的词尾不是表示一种语法规则，而是表示人。

<a id="w-26"></a>

### 26. lipogram — 缺字文；刻意避用某字母的文章

**音标**：英 /ˈlɪpəʊɡræm/；美 /ˈlɪpəɡræm/

**先抓住这个画面**

给自己定一道限制：整篇文章都不能出现某个字母，然后照样把话写通顺。

**怎么拆**

来自希腊语表示“留下、略去”的 leipein 与 gramma“字母”一组构词；这里 lipo- 与脂肪无关。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**希腊语 leipein + gramma → 缺字写作相关形式**  
略去某个字母

↓

**英语 lipogram**  
有意避用特定字母的文本

一篇不用 e 的英语文章就是常见挑战。偶然没有某个字母的短句不一定是有意的缺字创作，关键在预设的限制。

**常见搭配与例句**

a lipogram without e；write a lipogram；a lipogrammatic constraint。

> The class wrote a lipogram that avoided the letter e.

全班写了一篇避用字母 e 的缺字文。

> A long lipogram can require unusual choices of words.

一篇长缺字文可能需要很不寻常的选词。

**别混淆**

pangram 尽量把字母表全部用到；lipogram 刻意留下某个字母不用。

<a id="w-27"></a>

### 27. pangram — 全字母句；包含字母表全部字母的句子

**音标**：英、美 /ˈpæŋɡræm/

**先抓住这个画面**

把字母表当成一张清单：句子写完后，每个字母都至少能打上一个勾。

**怎么拆**

英语 pan-“全部” + -gram“写下的字母、记录”；是近代组合词。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**英语 pan- + -gram → pangram**  
包含全部字母的句子

英语 pangram 通常覆盖 a 到 z 的 26 个字母，可有重复，常用于字形展示或打字练习。若每个字母恰好一次，则是更严格的 perfect pangram。

**常见搭配与例句**

write a pangram；a perfect pangram；a pangram for testing fonts。

> The designer used a pangram to compare the fonts.

设计师用一个全字母句比较不同字体。

> Our first attempt at a pangram was missing the letter q, so we revised it.

我们最初打算写成的全字母句漏了 q，于是又修改了一遍。

**别混淆**

anagram 重排已有字母；pangram 要求覆盖整个字母表，两个任务不同。

<a id="w-28"></a>

### 28. pangrammatic — 全字母句的；包含字母表所有字母的

**音标**：英、美 /ˌpæŋɡrəˈmætɪk/

**先抓住这个画面**

字母表上的每个成员都至少露过一次面，这句话或这种写作才算 pangrammatic。

**怎么拆**

pangram + -atic，仿 grammatic 的词形；pan- 表示全部，-gram 来自写下的字母。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**英语 pan- + -gram → pangram**  
用遍字母表的句子

↓

**英语 pangram + -atic → pangrammatic**  
具有全字母性质的

在英语里通常检查 26 个字母是否全部出现。可以有重复，不要求每字母恰好一次；后者属于更严格的完美全字母句。

**常见搭配与例句**

a pangrammatic sentence；a pangrammatic phrase；a pangrammatic test。

> The sentence is pangrammatic, but it sounds rather unnatural.

这个句子用遍了所有字母，但读起来很不自然。

> The software checks whether the sample is pangrammatic.

软件检查样例是否包含字母表中的全部字母。

**别混淆**

grammatical 是符合语法；pangrammatic 是包含全部字母，两项条件互不保证。

<a id="w-29"></a>

### 29. telegramme — 电报〔旧式拼写〕

**音标**：按 telegram 的英式读法 /ˈtelɪɡræm/；美 /ˈteləɡræm/

**先抓住这个画面**

这是 telegram 的另一种拼写，看到末尾 -me 不必以为多出一种通信工具。

**怎么拆**

tele- + -gramme；-gramme 是受法语形式影响的拼写，与 telegram 的 -gram 同源。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**近代 tele- + -gram / -gramme**  
远距离传送的文字

↓

**英语 telegramme**  
telegram 的旧式或少见拼写

旧报刊、信件可能保留此形式。现代普通英语通常写 telegram；法语 télégramme 则属于另一语言，不能直接照英语发音。

**常见搭配与例句**

send a telegramme〔旧式拼写〕；a telegramme from abroad。

> The archive contains a telegramme sent from Paris.

档案中有一封从巴黎发来的电报。

> The facsimile preserves the spelling “telegramme” on the original form.

影印件保留了原表格上 telegramme 的拼写。

**别混淆**

telegramme 与 telegram 的基本词义相同，主要差别在拼写传统和使用年代。

<a id="w-30"></a>

### 30. tetragram — 四字母组合；四个符号组成的图式

**音标**：英、美 /ˈtetrəɡræm/

**先抓住这个画面**

把四个字母或符号当成一个单位看，核心就是“四个写下的标记”。

**怎么拆**

现代以 tetra-“四” + -gram“符号、字母”构词；具体指哪四个单位由领域决定。

**怎么变成今天的意思**

**希腊语 graphein 与 gramma / grammat-**  
写、画 → 写下或画出的符号、字母

↓

**英语 tetra- + -gram → tetragram**  
四字母组合；四符号图式

可指四字母词、组合或名称；特定传统也用来称四层线符。不要见到 tetra 就自动当成四边形。

**常见搭配与例句**

a four-letter tetragram；a tetragram in a text；a sequence of tetragrams。

> The analyst counted each tetragram in the coded message.

分析人员统计了加密消息中的每个连续四字母组合。

> The inscription contains a sacred tetragram of four letters.

铭文中有一个由四个字母构成的神圣名称。

**别混淆**

trigram 是三个单位；tetragram 是四个单位。tetragon 则是四边形，是不同词。

## 这一组要分清什么

anagram 重排已有字母，pangram 用遍整个字母表，lipogram 故意避开某字母。monogram 可以包含多个字母；hologram 不是任何看起来立体的投影。grammatical 只判断语法，不保证表达自然或内容合理。

## 串起来练习

先把 listen 重排成 silent；再检查一句话是否用全 26 个字母。用 a computer program 与 a television programme 分清拼写习惯，并用 diagram 画出一件事情的结构。
