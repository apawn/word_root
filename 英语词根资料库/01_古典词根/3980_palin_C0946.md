# 3980 · palin-, palim- — 再次；回去

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

希腊 palin 表示再次、回去。palindrome 用回头跑的形象描述回文；palimpsest 用再次刮擦的过程命名重写本。共同前段只是线索，后段决定具体画面。

**PALIN / PALIM = AGAIN / BACK**

沿着文字往回读，或刮去旧文再次写：两种不同的回头动作。

- **回头读**：palindrome；palindromic
- **刮去旧字再写**：palimpsest

## 词形与演化规律

palin + drom- 跑 → palindrome；palin + 与刮擦相关的词形 → palimpsest。palim- 是结合中的变体。palindromic 在英语中描述回文性质。

## 逐词讲解

<a id="w-1"></a>

### 1. palindrome — 回文；顺读倒读相同的序列

**音标**：英 /ˈpælɪndrəʊm/；美 /ˈpælɪndroʊm/

**先抓住这个画面**

从左往右读一遍，再从右往左读回来，得到同样的字符顺序。

**怎么拆**

希腊 palin 向回 + dromos 跑，形成 palindromos 向回跑的，再形成英语 palindrome。

**怎么变成今天的意思**

**希腊 dramein 跑；dromos 跑、路线、跑道**  
从移动的动作扩展为跑过的路线和场地

↓

**希腊 palin 向回 + dromos → palindromos → 英语 palindrome**  
向回跑 → 顺读与倒读相同的文字或序列

level、radar 都是回文词；数字 1221 也可称 palindrome。整句回文常约定忽略空格、标点和大小写，所以检查前要先说明规则。

**常见搭配与例句**

a palindrome word；a numeric palindrome；form a palindrome。

> The word “radar” is a palindrome.

radar 这个词是回文。

> The program checks whether the number is a palindrome.

程序检查这个数字是否是回文数。

**别混淆**

anagram 是重新排列字母；palindrome 要求反向顺序相同。两个词都像文字游戏，规则却不同。

<a id="w-2"></a>

### 2. palimpsest — 重写本；留有旧痕的层叠事物

**音标**：/ˈpælɪmpsest/

**先抓住这个画面**

旧字擦掉后写上新字，但下面的痕迹并没有完全消失。

**怎么拆**

希腊 palin 再次、回去 + 与 psēn 刮擦相关的词形成 palimpsēstos 再刮过的，经拉丁进入英语。palin 在这里呈现 palim- 的形式。

**怎么变成今天的意思**

**希腊 palin 再次 + psēn 刮擦 → palimpsēstos**  
刮除后再次使用的

↓

**拉丁 palimpsestus → 英语 palimpsest**  
擦去旧文再写的材料或手稿；引申为多层痕迹叠加

羊皮纸贵重时，人们会清除旧文字再使用；旧字有时仍能被读出。后来城市、建筑或记忆也能比作 palimpsest：新的一层盖在旧的一层上，仔细看仍有前代痕迹。这个比喻突出层叠与残留，不只是年代久。

**常见搭配与例句**

a medieval palimpsest；the underlying text of a palimpsest；a city as a palimpsest。

> Researchers recovered traces of the earlier text beneath the palimpsest.

研究者找回了重写本下层旧文字的痕迹。

> The city is a palimpsest of roads, walls and buildings from different eras.

这座城市像一部重写本，不同时代的道路、城墙和建筑层层叠在一起。

**别混淆**

palindrome 是正反读相同的回文；palimpsest 是擦掉重写、仍有旧痕的材料。共同的 palin- 不能让两个整词互换。

<a id="w-3"></a>

### 3. palindromic — 回文的；具有回文结构的

**音标**：美 /ˌpælənˈdroʊmɪk/；亦 /ˌpælənˈdrɑːmɪk/

**先抓住这个画面**

形容一个词或序列，从两头向内比较时，位置相对的内容相同。

**怎么拆**

palindrome + -ic，去末尾 e；重音移到 drom 音节。

**怎么变成今天的意思**

**希腊 dramein 跑；dromos 跑、路线、跑道**  
从移动的动作扩展为跑过的路线和场地

↓

**希腊 palin 向回 + dromos → palindromos → 英语 palindrome**  
向回跑 → 顺读与倒读相同的文字或序列

↓

**英语 palindrome + -ic → palindromic**  
回文 → 具有回文结构的

a palindromic number 是回文数；a palindromic string 是回文字符串。在具体程序中，要约定是否忽略大小写、空格等差异。

**常见搭配与例句**

a palindromic number；a palindromic sequence；a palindromic string。

> The sequence 1, 2, 3, 2, 1 is palindromic.

序列 1、2、3、2、1 具有回文结构。

> The function returns true when the input string is palindromic.

输入字符串是回文时，函数返回 true。

**别混淆**

symmetric 是一般对称；palindromic 特别关乎序列的反向读取。生物学等专门语境中的判定规则还可能涉及互补关系。

## 这一组要分清什么

回文关注阅读方向是否改变文字；重写本关注同一材料上的新旧层次。不要把两个 palin- 词都背成反复。

## 串起来练习

A palindrome reads the same backwards; a palimpsest preserves traces of earlier writing.

回文倒着读仍一样；重写本保留着旧文字的痕迹。
