# 4114 · set- — 刚毛；刺毛

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 seta／saeta 是刚毛。seta 命名一根结构，setose 描述具有这种结构。苔藓学还把 seta 用作蒴柄名称。

**SET：一根根较硬的小毛**

在显微镜下看表面伸出的刚毛，再给整个表面加上形容词。

- **结构名**：seta
- **表面特征**：setose

## 词形与演化规律

单数 seta，复数 setae；setose 承接拉丁形容词形式。这里与英语 set 设置不是一个词根。

## 逐词讲解

<a id="w-1"></a>

### 1. seta — 刚毛；刺毛；苔藓蒴柄

**音标**：/ˈsiːtə/

**先抓住这个画面**

一根细而有一定硬度的小毛，或像细柄一样托着孢蒴。

**怎么拆**

借自拉丁 seta／saeta 刚毛；生物学借用为结构名称。

**怎么变成今天的意思**

**拉丁 saeta／seta**  
刚毛

↓

**英语 seta**  
刚毛；苔藓中托住孢蒴的细柄

昆虫等动物学语境常说刚毛，苔藓学中常译蒴柄。复数 setae 通常读 /ˈsiːtiː/；不同学科的具体结构不能互换。

**常见搭配与例句**

a sensory seta；setae on the body；the seta of a moss。

> A single seta projected from the surface.

一根刚毛从表面伸出。

> The moss capsule was supported by a slender seta.

苔藓的孢蒴由一根细长蒴柄托着。

**别混淆**

seta 不是英语 set 的单数形式。hair 是普通毛发，seta 是特定生物结构的名称。

<a id="w-2"></a>

### 2. setose — 具刚毛的；多刺毛的

**音标**：英 /ˈsiːtəʊs/；美 /ˈsiːtoʊs/

**先抓住这个画面**

表面不是光溜溜的，而是布着一根根刚毛。

**怎么拆**

来自拉丁 setosus，seta 刚毛 + 表示具有某物的形容词成分。

**怎么变成今天的意思**

**拉丁 seta → setosus**  
刚毛 → 具刚毛的

↓

**英语 setose**  
表面带刚毛、刺毛的

植物或动物描述中都可用，重点是有刚毛这一表面特征。与柔软绒毛相比，它通常让人想到较硬、较明显的毛。

**常见搭配与例句**

setose legs；a setose surface；setose margins。

> The insect has strongly setose legs.

这种昆虫的腿上长着明显的刚毛。

> The description notes a setose margin on each leaf.

描述指出每片叶子的边缘都有刚毛。

**别混淆**

setose 是有刚毛，glabrous 是无毛；两者在分类检索中往往能帮助区分外形。

## 这一组要分清什么

seta 在苔藓中的蒴柄义，不能照搬成毛发；先分清生物对象。

## 串起来练习

The surface is setose because it bears many setae.

这个表面具刚毛，因为它长着许多刚毛。
