# 4149 · api- — 蜜蜂

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 apis 表示蜜蜂。英语借来的 apiary 指养蜂处，近代 apiculture 则仿 agriculture 等名称表示养蜂活动；这里的 api 不是软件里的 API。

**API = BEE**

一排蜂箱，里面住着蜂群，外面有人照料。

- **养蜂的地方**：apiary
- **养蜂的活动、技术**：apiculture

## 词形与演化规律

apis → apiarium → apiary；apis 与 culture 一系的培育成分结合，形成 apiculture。英语 bee 的词形来自日耳曼语，不能写成 apis 变成了 bee。

## 逐词讲解

<a id="w-1"></a>

### 1. apiary — 养蜂场；集中放置蜂箱的地方

**音标**：英 /ˈeɪpiəri/；美 /ˈeɪpieri/

**先抓住这个画面**

把许多蜂箱安放在一个地方，养蜂人就在那里照料蜂群。

**怎么拆**

拉丁 apis 蜜蜂 → apiarius 蜜蜂的 → apiarium 养蜂处，借入英语 apiary。末尾的场所含义有拉丁来源，不是把英语 bee 塞进拼写里。

**怎么变成今天的意思**

**拉丁 apis → apiarius**  
蜜蜂 → 蜜蜂相关的

↓

**拉丁 apiarium → 英语 apiary**  
养蜂处 → 养蜂场

a hive 是一个蜂箱或蜂巢；an apiary 是安放、管理蜂箱的地方。它可以在农场，也可以在屋顶，不一定是一栋特别的房子。想成“蜂箱集中住的地方”，就能和单个蜂巢区分。

**常见搭配与例句**

keep an apiary；a rooftop apiary；hives in an apiary。

> The farm has a small apiary beside the orchard.

农场在果园旁有一个小养蜂场。

> The beekeeper inspected each hive in the apiary.

养蜂人检查了养蜂场里的每个蜂箱。

**别混淆**

apiary 养蜜蜂，aviary 养鸟：只差中间一个字母，动物却变了。apiculture 则说养蜂这门活动或技术。

<a id="w-2"></a>

### 2. apiculture — 养蜂；养蜂业

**音标**：英 /ˈeɪpɪkʌltʃə/；美 /ˈeɪpɪkʌltʃər/

**先抓住这个画面**

持续照料蜂群，而不是只去野外找一次蜂蜜。

**怎么拆**

api- 来自拉丁 apis“蜜蜂”，culture 是培育；参照农业词汇构词。

**怎么变成今天的意思**

**拉丁 apis；cultura**  
蜜蜂；培育、照料：并列来源

↓

**近代仿 agriculture 组合 api- ＋ culture**  
蜂群的饲养与管理

↓

**英语 apiculture**  
养蜂、养蜂业

包括蜂箱、蜂群和相关生产管理。日常直接说 beekeeping 更常见；apiculture 适合专业课程、研究或行业名称。

**常见搭配与例句**

study apiculture；an apiculture course；apiculture and pollination。

> The college offers a course in apiculture.

学院开设养蜂课程。

> Her work in apiculture involves monitoring the health of bee colonies.

她的养蜂工作包括观察蜂群健康状况。

**别混淆**

api- 是蜂，不是与人猿 ape 有关。apiculture 和 agriculture 只共享培养的尾部。

## 这一组要分清什么

apiary 与 aviary 拼写近：前者蜜蜂，后者鸟。hive 是蜂箱或蜂巢，apiary 则是设置蜂箱的场所。

## 串起来练习

An apiary is a place; apiculture is the practice of keeping bees.

apiary 是地方，apiculture 是养蜂活动。
