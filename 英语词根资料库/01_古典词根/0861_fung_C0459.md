# 0861 · fung-, funct- — 执行；履行职责；发挥作用

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

这一族接拉丁动词 fungi，词典第一人称形式是 fungor，表示履行、执行；它的分词词干是 funct-。先抓住“承担并完成一个作用”，就能把功能、职员、故障和敷衍几条支线连起来。

**FUNG / FUNCT = PERFORM**

一套系统像一组分工合作的人：每个部分都把自己的那份工作做起来。function 是它做什么；malfunction 是做错或做不动；defunct 是那段工作已经结束；perfunctory 则是心里只想赶紧交差。

- **把自己的作用发挥出来**：function, functional, functionality, functionally, functioning, multifunction
- **不能正常发挥作用**：nonfunctional, functionless, dysfunction, dysfunctional, dysfunctionality, malfunction, malfunctioning
- **承担工作的人；已结束的工作**：functionary, defunct
- **只求把流程走完**：perfunctory, perfunctorily, perfunctoriness
- **同等的一份可以代行作用**：fungible, fungibility, nonfungible
- **按功能解释与设计**：functionalism, functionalist, functionalistic
- **赋予结构新的功能**：functionalize, functionalization
- **物理中的函数名称**：wavefunction

## 词形与演化规律

funct- 常在 function、defunct、perfunctory 中出现；fung- 保留在 fungible，字母 g 在这里读 /dʒ/。拉丁动词 fungi 与英语 fungi“真菌的复数”不是同一个词源；看到一样的拼写也要看语言和语义。

## 逐词讲解

<a id="w-1"></a>

### 1. function — 功能；职能；正式活动；函数；起作用、运转

**音标**：/ˈfʌŋkʃən/

**先抓住这个画面**

一个东西或一个人，在整件事里负责做什么，这就是它的 function。

**怎么拆**

拉丁 fungi“履行、执行”的分词词干 funct- 形成 functio；经法语等路线借入为名词，后来在英语中也作动词。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 functio → 法语 fonction 等借入路线**  
执行、履行；某物承担的作用

↓

**英语 function**  
功能、职能；活动；起作用

The function of a lid 是盖子的作用；function as a desk 是当桌子用。a social function 是正式社交活动。数学函数给每个允许的输入指定一个输出；程序里的 function 则是一段可调用来完成任务的代码，不必每次都接收外部输入。

**常见搭配与例句**

the function of；function as；function properly；attend a function；call a function。

> The main function of the lid is to keep dust out.

盖子的主要作用是挡住灰尘。

> The old table now functions as a desk.

那张旧桌子现在当书桌用。

> The function returns the larger of the two numbers.

这个函数返回两个数中较大的一个。

**别混淆**

purpose 强调目的，function 强调承担的作用。软件的 feature 是一项用户可见特点；function 还可以指内部函数，范围并不完全相同。

<a id="w-2"></a>

### 2. functional — 能正常工作的；实用的；功能方面的

**音标**：/ˈfʌŋkʃənəl/

**先抓住这个画面**

先问“它能不能把该做的事做好”，再谈外观或其他特点。

**怎么拆**

现代可看作 function + -al；历史解释也包括中世纪拉丁 functionalis，都是“与履行作用有关”。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

a functional kitchen 是好用、布局满足需要的厨房；fully functional 表示功能已正常可用。a functional difference 是功能上的区别。医学、数学和编程中另有专门用法，需跟着领域读，不能全部机械翻成“实用”。

**常见搭配与例句**

fully functional；functional design；functional requirements。

> The room is small but functional.

房间虽小，但很实用。

> The replacement system is now fully functional.

替换后的系统现在已能正常发挥全部功能。

**别混淆**

functional 说明能发挥作用或侧重实用；decorative 强调装饰。东西可以既 functional 又 attractive。

<a id="w-3"></a>

### 3. functioning — 正在运转；能发挥作用的；运作情况

**音标**：/ˈfʌŋkʃənɪŋ/

**先抓住这个画面**

把功能真正用起来：机器在工作，流程在运行。

**怎么拆**

function 作动词后接 -ing；也可作形容词或名词性成分。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 functio → 法语 fonction 等借入路线**  
执行、履行；某物承担的作用

↓

**英语 function**  
功能、职能；活动；起作用

↓

**英语 function → functioning**  
发挥作用 → 正在运转、运作情况

a functioning clock 是能走时的钟；the functioning of a system 是系统如何运作。说 functioning well 时，well 告诉你运行质量好；只有 functioning，常只是说明它在发挥作用。

**常见搭配与例句**

functioning properly；a functioning system；the functioning of。

> The cooling system is functioning properly again.

冷却系统又能正常工作了。

> Clear communication is essential to the functioning of the team.

清楚的沟通对团队运作至关重要。

**别混淆**

function 是作用或运转这一动作；functioning 更容易突出运行过程和当前状态。

### 4. functionality — 功能性；具备的功能；发挥作用的能力

**音标**：/ˌfʌŋkʃəˈnæləti/

**先抓住这个画面**

把产品拿来实际用：它能做哪些事，这些本领合起来就是这里说的 functionality。

**怎么拆**

functional + -ity；词尾 -al 在接 -ity 后重音移到 /næl/ 附近。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional → functionality**  
具有功能的 → 功能性、功能集合

added functionality 常说增加了可用功能；test the functionality of a device 是检查它的功能是否能实现。谈软件时常用作整体概念，不必总译成拗口的“功能性”；added search functionality 就是增加了搜索功能。

**常见搭配与例句**

basic functionality；additional functionality；retain functionality。

> The update adds search functionality to the app.

这次更新给应用增加了搜索功能。

> We tested the device’s basic functionality before packing it.

打包前，我们测试了设备的基本功能。

**别混淆**

function 常能数出具体一个功能；functionality 常把能做的事或功能表现作为整体来谈。

### 5. dysfunction — 功能失常；运作不良

**音标**：/dɪsˈfʌŋkʃən/

**先抓住这个画面**

各个部分还在，却没按应该的方式配合，事情因此卡住或走偏。

**怎么拆**

dys-“不良、困难、异常” + function。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 functio → 法语 fonction 等借入路线**  
执行、履行；某物承担的作用

↓

**英语 function**  
功能、职能；活动；起作用

↓

**英语 dys- + function → dysfunction**  
正常发挥作用 → 运作失常

医学中可指器官功能异常；组织中也可说互相推诿、沟通失灵带来的 dysfunction。它比一次小失误更容易指向运作方式有问题，但具体程度仍由上下文决定。

**常见搭配与例句**

organ dysfunction；organisational dysfunction；signs of dysfunction。

> The report linked the delays to dysfunction within the organisation.

报告把这些延误与组织内部运作失常联系起来。

> Repeated communication failures revealed a deeper dysfunction.

反复的沟通失败暴露了更深层的运作问题。

**别混淆**

dysfunction 常用于身体、关系或组织的运作问题；malfunction 尤其常用于机器设备的故障。

### 6. dysfunctional — 运作失常的；功能不良的；关系模式有问题的

**音标**：/dɪsˈfʌŋkʃənəl/

**先抓住这个画面**

本来应当互相配合的环节，反而不断制造冲突、阻碍或伤害。

**怎么拆**

dysfunction + -al；也可看出 dys- 与 functional 的对应关系。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 functio → 法语 fonction 等借入路线**  
执行、履行；某物承担的作用

↓

**英语 function**  
功能、职能；活动；起作用

↓

**英语 dysfunction → dysfunctional**  
运作失常 → 处于失常状态的

a dysfunctional team 可能职责不清、沟通失灵；a dysfunctional relationship 常说相处模式反复出问题。描述的是运作或关系状况，不应据此把一个人的全部价值概括成“坏掉了”。

**常见搭配与例句**

a dysfunctional organisation；a dysfunctional relationship；become dysfunctional。

> The committee became dysfunctional when members stopped sharing information.

成员不再共享信息后，委员会的运作出了问题。

> The novel explores a dysfunctional relationship between two friends.

小说探讨了两个朋友之间一种有问题的相处关系。

**别混淆**

inefficient 强调效率低；dysfunctional 更可能涉及基本配合方式有问题，不只是速度慢。

### 7. malfunction — 故障；失灵；发生故障

**音标**：/ˌmælˈfʌŋkʃən/

**先抓住这个画面**

机器本来该完成某件事，却没有按预期工作。

**怎么拆**

mal-“坏、不正确” + function；可以作名词，也可以作动词。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 functio → 法语 fonction 等借入路线**  
执行、履行；某物承担的作用

↓

**英语 function**  
功能、职能；活动；起作用

↓

**英语 mal- + function → malfunction**  
发挥作用 → 工作失常、故障

a mechanical malfunction 是机械故障；The sensor malfunctioned 是传感器出了故障。它可以表现为完全不动，也可以是给出错误数据、间歇失灵，不一定只指彻底损坏。

**常见搭配与例句**

a technical malfunction；equipment malfunction；malfunction during use。

> A sensor malfunction caused the alarm to sound.

传感器故障使警报响了。

> The printer malfunctioned halfway through the job.

打印机在任务进行到一半时出了故障。

**别混淆**

damage 说受到损坏；malfunction 说工作不正常。设备可能外观完好却失灵，也可能受损后仍能工作。

### 8. defunct — 已停用的；不再存在或运作的；已倒闭的

**音标**：/dɪˈfʌŋkt/

**先抓住这个画面**

它曾经在发挥作用，如今那一段使命已经结束了。

**怎么拆**

拉丁 de-“完全、离开” + fungi“履行”形成 defungi，分词 defunctus 有已完成、死亡义，经法语或直接借入英语。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 defungi → defunctus**  
把职责做完 → 已结束的、死去的

↓

**法语 defunct 或直接借入 → 英语 defunct**  
不再运作、存在或使用的

a defunct company 是已停止经营的公司；a defunct system 是已经退出使用的系统。现在常用来谈机构、制度、设备，不是通常用来安慰人或表达某人去世的日常说法。

**常见搭配与例句**

a defunct company；a defunct railway；now defunct。

> The building once belonged to a defunct publishing company.

这栋楼曾属于一家已经停止经营的出版公司。

> The museum preserves maps of a defunct railway network.

博物馆保存着一个已停用铁路网络的地图。

**别混淆**

malfunctioning 是出故障，可能修好；defunct 更强调已经结束运作或退出使用。

### 9. functionally — 从功能上；就实际作用而言

**音标**：/ˈfʌŋkʃənəli/

**先抓住这个画面**

先把外观、名字放一边，只看它实际完成什么工作。

**怎么拆**

functional + -ly，表示评价采用功能或实际作用的角度。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional → functionally**  
从功能或实际作用来看

functionally equivalent 说两个东西能完成相同作用，不保证材料、结构和外观一样。functionally separate 说工作上各自负责不同任务，也不一定物理上隔得很远。

**常见搭配与例句**

functionally equivalent；functionally similar；functionally separate。

> The two buttons look different but are functionally identical.

这两个按钮外观不同，但功能相同。

> The teams are functionally separate even though they share an office.

这两个团队虽然共用办公室，但职责彼此独立。

**别混淆**

physically 看物理形态，functionally 看作用；不同结构也可能在特定任务上功能相近。

**音标**：/ˌmælˈfʌŋkʃənɪŋ/

**先抓住这个画面**

故障不是只写在报告里，此刻设备就没有按该有的方式工作。

**怎么拆**

malfunction + -ing；常作现在分词或修饰设备的形容词。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 functio → 法语 fonction 等借入路线**  
执行、履行；某物承担的作用

↓

**英语 function**  
功能、职能；活动；起作用

↓

**英语 malfunction → malfunctioning**  
出故障 → 正在失灵、有故障的

**常见搭配与例句**

a malfunctioning device；a malfunctioning sensor；keep malfunctioning。

> The engineer replaced the malfunctioning sensor.

工程师更换了失灵的传感器。

> One of the displays is malfunctioning and keeps flickering.

其中一块显示屏出了故障，一直闪烁。

**别混淆**

malfunction 是故障或出故障；malfunctioning 更容易放在名词前，直接指出哪个东西在失灵。

<a id="w-11"></a>

### 11. perfunctory — 敷衍的；草草了事的；例行公事般的

**音标**：英 /pəˈfʌŋktəri/；美 /pərˈfʌŋktəri/

**先抓住这个画面**

心里只想着“把这一步赶紧走完”，动作做了，关心和认真没有跟上。

**怎么拆**

拉丁 per-“贯穿、做完” + fungi“履行”形成 perfungi；晚期拉丁 perfunctorius 已有草率义，再借入英语。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 per- + fungi → perfungi**  
贯穿、完成 + 履行 → 把事情做完

↓

**晚期拉丁 perfunctorius → 英语 perfunctory**  
草率地应付过去 → 敷衍的

a perfunctory apology 是像完成任务一样说句对不起；a perfunctory check 是草草检查一下。重点不是动作短，而是缺少应有的投入、注意或真心；一个简短但认真负责的检查未必 perfunctory。

**常见搭配与例句**

a perfunctory nod；a perfunctory apology；a perfunctory inspection。

> He gave the report a perfunctory glance and signed it.

他敷衍地扫了一眼报告，就签了字。

> Her apology sounded perfunctory and did little to repair the relationship.

她的道歉听起来像走过场，没怎么改善关系。

**别混淆**

routine 只是例行、常规，可以做得很认真；perfunctory 通常带敷衍、仅走形式的批评。

### 12. functionary — 工作人员；官员；执行事务的人

**音标**：英 /ˈfʌŋkʃənəri/；美 /ˈfʌŋkʃəneri/

**先抓住这个画面**

组织里有一个职位，也有一套要履行的职责；占着这个岗位办事的人。

**怎么拆**

来自或仿造法语 fonctionnaire，接 fonction“职能”；现代外形可联系 function 与 -ary。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 functio → 法语 fonction／fonctionnaire**  
职能、履职 → 担任职务的人

↓

**英语 functionary**  
执行机构事务的人员、官员

a government functionary 是政府工作人员；有时这个词带一点“照章办事、权限有限”的距离感。它不必是大人物，也不能一看到就翻成贪官；态度要看修饰语和语境。

**常见搭配与例句**

a government functionary；a minor functionary；a party functionary。

小说描写了一个夹在相互冲突的命令之间的小职员。

**别混淆**

official 是较普通的官员或正式工作人员名称；functionary 更突出在机构里执行某种职能，常显得较冷淡或带批评意味。

### 13. multifunction — 多功能的

**音标**：/ˌmʌltiˈfʌŋkʃən/

**先抓住这个画面**

一台设备装下几种功能，不只完成一种工作。

**怎么拆**

multi- + function“功能”；作形容词时 function 不需要变成复数。

**怎么变成今天的意思**

**拉丁 multus → 组合形式 multi-**  
多、许多；多次

↓

**英语借用 multi- 参与构词**  
与已有名词、形容词等相接，表示多个、多方面

↓

**英语 multi- + function → multifunction**  
能执行多项功能的

a multifunction printer 可打印、扫描等；a multifunction button 根据操作方式承担不同功能。名称只说明功能不止一个，具体功能须看说明。

**常见搭配与例句**

a multifunction printer；a multifunction device；a multifunction button。

> The office replaced two machines with one multifunction printer.

办公室用一台多功能打印机替换了两台机器。

> The watch has a multifunction button on the side.

手表侧面有一个多功能按钮。

**别混淆**

multipurpose 强调用途，multifunction 强调实际功能模块；二者常有交集。

<a id="w-14"></a>

### 14. functionalism — 功能主义；重视作用与功能关系的观点

**音标**：/ˈfʌŋkʃənəlɪzəm/

**先抓住这个画面**

理解一个东西时先问：它在整套系统里做什么，这种作用怎样影响设计或解释？

**怎么拆**

functional + -ism“学说、主张”。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional + -ism → functionalism**  
功能的 → 以功能为中心的观点

建筑中的 functionalism 主张形式要配合用途、材料和结构。心灵哲学中的同名观点，则按某种心理状态在系统中发挥的作用来理解它。不同领域有不同版本，不能把所有“功能主义”缩成一句“只要好用就行”。

**常见搭配与例句**

architectural functionalism；a version of functionalism；the debate over functionalism。

> The architect’s design reflects an interest in functionalism.

建筑师的设计体现了对功能主义的重视。

> The seminar compared functionalism with other theories of mind.

研讨课比较了功能主义与其他心灵理论。

**别混淆**

functional 是功能方面的形容词；functionalism 是一种理论立场。说某物好用，不一定就在主张功能主义。

<a id="w-15"></a>

### 15. fungible — 可互换的；同等单位可以替代的

**音标**：/ˈfʌndʒɪbəl/

**先抓住这个画面**

给你同等的一份就行，不需要一定是原来那一份。

**怎么拆**

中世纪拉丁 fungibilis 接拉丁 fungi“履行”，尤其是 fungi vice“代行位置或作用”；先有代替作用，再有同等物可互换。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 fungi vice → 中世纪拉丁 fungibilis**  
代行某人的位置或作用 → 可互相替代的

↓

**英语 fungible**  
同等单位可互换、无须区分个体的

普通流通的一枚硬币，只要币种和面值相同，通常可以用另一枚替代；带纪念意义的那一枚，对收藏者就未必一样。fungible 关注是否可以不区分个体地互换，取决于比较的用途、规格和价值。

**常见搭配与例句**

fungible goods；fungible units；treat as fungible。

> For ordinary payment, coins of the same currency and denomination are generally fungible.

用于普通支付时，同币种、同面值的硬币一般可以互换。

> The collector did not regard the two signed copies as fungible.

收藏者并不把那两本签名本视为可以随意互换的东西。

**别混淆**

replaceable 只表示能替换；fungible 更强调同等单位可以互换，不必关注是哪一个具体个体。

### 16. functionalist — 功能主义者；功能主义的

**音标**：/ˈfʌŋkʃənəlɪst/

**先抓住这个画面**

习惯用“它承担什么作用”作为解释或设计出发点的人，以及这种观点。

**怎么拆**

functional + -ist；与 functionalism 的主张相对应，既可作名词也可作形容词。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional + -ist → functionalist**  
重视功能的观点 → 功能主义者、功能主义的

a functionalist 可以是某领域的功能主义者；a functionalist approach 是采取相应思路的方法。必须先看语境是在建筑、社会研究还是哲学，才知道具体主张。

**常见搭配与例句**

a functionalist approach；functionalist architecture；a functionalist account。

文章从功能主义角度解释了这个制度。

**别混淆**

functionalist 指理论立场或其支持者；functionary 指机构里的工作人员，两者虽然同族，意思相差很大。

**先抓住这个画面**

东西可能还摆在那里，但没有发挥所说的那项作用。

**怎么拆**

non-“不、非” + functional。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 non- + functional → nonfunctional**  
具有功能的 → 不起作用的、非功能方面的

a nonfunctional display 可能是不能工作的显示屏，也可能是只作展示的模型，须看语境。软件文档中的 nonfunctional requirements 通常谈性能、可靠性等质量要求；这里不是说这些要求“没用”。

### 18. wavefunction — 波函数〔物理〕

**音标**：/ˈweɪvˌfʌŋkʃən/

**先抓住这个画面**

像一份用于计算量子测量结果的数学描述；它记录的不只是“哪里有多大可能”，还包含相位等信息。

**怎么拆**

英语 wave“波” + function“函数”；function 的远源仍是拉丁“执行、作用”词族，两部分是在英语中组合的。

**怎么变成今天的意思**

**英语 wave + function**  
波 + 函数

↓

**英语 wavefunction**  
描述量子态的波函数

常用希腊字母 ψ 表示。对于归一化的位置波函数，取其模的平方得到位置的概率密度，再对某个区域积分得到在那里测到粒子的概率。初学时先分清：波函数本身与概率密度不是同一个量。

**常见搭配与例句**

a wavefunction；normalise a wavefunction；the phase of a wavefunction。

> The students plotted the wavefunction and its probability density separately.

学生分别画出了波函数和相应的概率密度。

> The wavefunction must be normalised before these probabilities are calculated.

计算这些概率之前，必须先把波函数归一化。

**别混淆**

wavefunction 包含振幅和相位信息；probability density 是由它计算出的概率密度。不能把波函数简单当成粒子的经典运动轨迹。

### 19. functionalization — 功能化；官能化〔化学等〕

**音标**：构词参考 /ˌfʌŋkʃənəlaɪˈzeɪʃən/

**先抓住这个画面**

把“给结构增加特定作用”的改变过程，作为一个整体来谈。

**怎么拆**

functional + -ization；与动词 functionalize 对应。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional → functionalize／functionalization**  
有功能的 → 使具有功能／这一过程

surface functionalization 是表面功能化或官能化；在化学语境中，常涉及引入官能团来改变反应性、结合能力等性质。看这个词时，继续追问“增加了什么基团、改变了什么作用”，就不会停留在空泛的“功能化”。

**常见搭配与例句**

surface functionalization；selective functionalization；functionalization of a molecule。

> Surface functionalization changed the material’s interaction with the coating.

表面功能化改变了材料与涂层的相互作用。

> The paper compares two methods of molecular functionalization.

论文比较了两种分子官能化方法。

**别混淆**

functionalization 是引入或改变功能的过程；functionality 常说现有的功能或功能性，在化学里还可有更专门的含义。

### 20. fungibility — 可互换性；同等物可以替代的性质

**音标**：/ˌfʌndʒəˈbɪləti/

**先抓住这个画面**

重点从“这一份能换吗”，转到“这一类东西在多大程度上可互换”。

**怎么拆**

fungible 的 -ible 换为 -ibility，形成性质名词。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 fungi vice → 中世纪拉丁 fungibilis**  
代行某人的位置或作用 → 可互相替代的

↓

**英语 fungible**  
同等单位可互换、无须区分个体的

↓

**英语 fungible → fungibility**  
可互换的 → 可互换性

the fungibility of a commodity 讨论同种商品的单位能否互相替代。规格、品质、用途改变，都可能影响这种判断。把它理解成“辨不辨认具体是哪一份”，比只背“可替代性”更清楚。

质量差异会限制这些货物的可互换性。

**别混淆**

fungibility 不等于 similarity：外观相似的两件东西，可能因身份、历史或用途不同而不能当作等价单位交换。

### 24. functionalistic — 功能主义的〔较少见〕

**音标**：/ˌfʌŋkʃənəˈlɪstɪk/

**先抓住这个画面**

看问题时，明显把功能和作用放在解释中心。

**怎么拆**

functional + -istic；对应 functionalism 的形容词形式。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional + -istic → functionalistic**  
功能的 → 具有功能主义特点的

functionalistic interpretation 是按功能主义方式作出的解释。它与形容词 functionalist 大体重叠，往往出现在较正式的学术文字里，不需要理解成程度更高的一种功能。

**常见搭配与例句**

a functionalistic view；a functionalistic interpretation。

> The reviewer questioned the book’s functionalistic interpretation.

评论者质疑了这本书的功能主义解释。

> The essay takes a functionalistic view of social roles.

这篇文章从功能主义角度看待社会角色。

**别混淆**

functional 只说与功能有关；functionalistic 通常表明与某种功能主义观点有关，带有理论立场色彩。

### 25. functionalize — 使具有功能；对……作官能化处理〔化学等〕

**音标**：/ˈfʌŋkʃənəlaɪz/

**先抓住这个画面**

给原来那套结构增加能参与特定作用的部分，让它能以新的方式工作。

**怎么拆**

functional + -ize“使成为、使具有”。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional + -ize → functionalize**  
有功能的 → 赋予功能、引入官能团

化学中常说给分子或材料表面引入官能团，使其具备特定反应性或相互作用。可以想成给结构装上新的“接口”，但这只是理解比喻，具体变化是化学结构的变化，不是随便贴上一个标签。

**常见搭配与例句**

functionalize a surface；functionalize a molecule；functionalize with a group。

> The researchers functionalized the surface to change how it interacted with water.

研究者对表面进行了官能化处理，以改变它与水的相互作用。

> The next experiment will functionalize the molecule at a different position.

下一项实验将在分子的另一位置进行官能化。

**别混淆**

modify 泛指修改；functionalize 更突出赋予特定功能，化学用法尤其关注官能团。

### 26. nonfungible — 不可按同等单位互换的；非同质化的

**音标**：英 /ˌnɒnˈfʌndʒɪbəl/；美 /ˌnɑːnˈfʌndʒɪbəl/

**先抓住这个画面**

你要的是这一件具体的东西，换成另一件同类物品并不能算完全一样。

**怎么拆**

non-“不” + fungible“可互换的”。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 fungi vice → 中世纪拉丁 fungibilis**  
代行某人的位置或作用 → 可互相替代的

↓

**英语 fungible**  
同等单位可互换、无须区分个体的

↓

**英语 non- + fungible → nonfungible**  
可互换的 → 需要区分个体、不能等价互换的

一件具有独特来历的原作可以用来理解 nonfungible：另一幅同尺寸画作不能自然顶替它。这个词早于数字代币用法；“不可互换”本身也不自动说明东西稀有、昂贵或值得购买。

**常见搭配与例句**

a nonfungible object；nonfungible assets；treat as nonfungible。

> The curator treats each original manuscript as a nonfungible object.

馆长把每份原稿都视为不能用另一份同类物件等价替代的对象。

> The rings were nonfungible to their owners because each carried a personal history.

对各自的主人而言，这些戒指不能互换，因为每一枚都承载着个人经历。

**别混淆**

unique 强调独一无二；nonfungible 强调不能当作等价单位互换。判断重点在交换关系，而不只是外观是否不同。

### 27. perfunctoriness — 敷衍；草率应付的态度〔较少见〕

**音标**：英 /pəˈfʌŋktərinəs/；美 /pərˈfʌŋktərinəs/

**先抓住这个画面**

不是指出某一个动作，而是概括“整件事做得只剩形式”的那种感觉。

**怎么拆**

perfunctory 的 y 变 i + -ness，形成性质名词。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**拉丁 per- + fungi → perfungi**  
贯穿、完成 + 履行 → 把事情做完

↓

**晚期拉丁 perfunctorius → 英语 perfunctory**  
草率地应付过去 → 敷衍的

↓

**英语 perfunctory → perfunctoriness**  
敷衍的 → 敷衍这一性质

the perfunctoriness of a response 说回复的态度让人觉得在应付。这个词偏书面，日常可以直接说 the reply felt careless 或用 perfunctory 修饰 reply，表达通常更轻便。

**常见搭配与例句**

the perfunctoriness of；a sense of perfunctoriness。

> The perfunctoriness of the reply disappointed the applicants.

回复中那种敷衍的态度令申请者失望。

> She noticed a new perfunctoriness in the weekly checks.

她发现每周检查最近开始有些敷衍了。

**别混淆**

perfunctoriness 强调形式走过了但缺少投入；carelessness 泛指粗心，未必涉及为了交差而走形式。

## 这一组要分清什么

functional 是能起作用或与功能有关；perfunctory 是投入不足、敷衍了事。defunct 表示已结束运作，malfunctioning 表示出故障。fungible 的可互换性不是长得像就够，还要看用途、规格和价值能否等价。

## 串起来练习

The device looked impressive, but one function was not working. A careful check found the malfunction; a perfunctory glance would have missed it.

设备看起来很气派，但有一个功能不能用。认真检查发现了故障；如果只是敷衍地看一眼，就会漏掉。
