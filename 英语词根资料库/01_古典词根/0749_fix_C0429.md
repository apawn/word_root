# 0749 · fix- — 刺入、钉住、固定；修理、词缀与执着

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 figere 的分词词干 fix- 是本组核心。不同英语词的近源并不都经过英语 fix：prefix、affix、fixation 有各自古典或法语路线；fixation 还早于 fixate。fixture 的拼写受类似 mixture 的类推影响，不能因此编造一个不存在的拉丁分词。

**先是把东西钉稳；时间可以定住，注意力可以停住，坏掉的东西可以修到正常状态。把一个成分固定到词上，就有了词缀。**

figere 钉住 → fixus → fix 固定、安排、修好；prae- 在前 → prefix；ad- 附着 → affix；trans- 穿过 → transfix，进而表示看呆、僵住。

- **把问题处理好、把状态定住**：fix, fixed, fixing, fixer, fixable, hotfix
- **固定在位置或日程上**：fixture
- **注意力被钉住**：fixation, fixate, fixated, transfix, transfixed
- **词语上的附加成分**：prefix, suffix, affix

## 词形与演化规律

fix 的 -ed 在 /s/ 后读 /t/，fixed、transfixed 不额外读一个 /ɪd/ 音节。affix 名词前重音、动词后重音；prefix 的动词也常前重音，不套用绝对规则。fixate 常见英美重音有别。

## 逐词讲解

<a id="w-1"></a>

### 1. fix — 修理；解决；固定；确定；安排、准备；操纵；解决办法、困境〔名词〕

**音标**：/fɪks/

**先抓住这个画面**

核心画面是把东西放到确定、稳妥的位置：坏的修好，时间定下，零件固定，问题处理掉。

**怎么拆**

接拉丁 fixus，是 figere“钉住、固定”的分词；通常推测经古法语 *fixer 进入中古英语，* 表示重建形式。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

fix a bike 是修车；fix a date 是定日期；fix a shelf to the wall 是固定架子。美式 fix dinner 是准备晚饭。fix a match 则是操纵赛果；a quick fix 是应急办法，in a fix 是陷入困境。

**常见搭配与例句**

fix a problem；fix a date；fix something to；a quick fix；in a fix。

> Can you fix the broken lock?

你能修好这把坏锁吗？

> We fixed a date for the next meeting.

我们定下了下次会议的日期。

> This patch is a quick fix, not a permanent solution.

这个补丁是临时办法，还不是长久的解决方案。

> The investigation found that the match had been fixed.

调查发现比赛结果遭到了操纵。

**别混淆**

repair 主要修复损坏；fix 更口语、更广，时间、规则、饭菜、结果都可能成为宾语。

<a id="w-2"></a>

### 2. fixed — 固定的；不变的；确定好的；被操纵的

**音标**：/fɪkst/

**先抓住这个画面**

位置、金额、时间或结果已经被钉住，不能随意变动。

**怎么拆**

fix + -ed，/s/ 后的 -ed 读 /t/；英语很早就把这个分词用于固定、不变的状态。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

↓

**英语 fix → fixed**  
固定 → 不变、已确定；也可指已修好、被操纵

a fixed price 是固定价格；a fixed schedule 是固定日程；a fixed smile 则是保持不动、可能不自然的笑容。The game was fixed 表示赛果被操纵，不是游戏修好了。

**常见搭配与例句**

a fixed price；fixed costs；a fixed schedule；a fixed smile。

> The course has a fixed start date.

这门课程的开课日期是固定的。

> She listened with a fixed smile on her face.

她听着，脸上一直挂着僵硬的笑容。

**别混淆**

stable 说相对稳定；fixed 更强调已经确定、不作变动。fixed costs 在特定业务范围内也不随产量直接变化。

<a id="w-3"></a>

### 3. fixing — 修理；固定；确定；操纵；固定配件〔常用复数〕

**音标**：/ˈfɪksɪŋ/

**先抓住这个画面**

要看后面接什么：修水管、定价格、把东西装牢，都是不同的 fixing。

**怎么拆**

fix + -ing，表示动作或过程；名词复数 fixings 还可指固定配件，美式口语也可指配菜、附件。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

↓

**英语 fix → fixing / fixings**  
修理、固定等过程；固定用的配件或配套东西

fixing the roof 是修屋顶；price fixing 通常指操纵价格的安排，不只是正常标价。英国商品说明里的 fixings 往往是螺钉、支架等安装配件。

**常见搭配与例句**

fixing a fault；price fixing；wall fixings；all the fixings。

> Fixing the leak took longer than expected.

修好漏水处花的时间比预计长。

> The shelf comes with all the necessary fixings.

这个架子附带了全部必要的安装配件。

**别混淆**

fixed 描述已经定住的状态；fixing 描述动作，或执行固定作用的配件。

<a id="w-4"></a>

### 4. fixture — 固定装置；常驻人物；预定赛事

**音标**：英 /ˈfɪkstʃə/；美 /ˈfɪkstʃər/

**先抓住这个画面**

原本是装在某处不轻易移走的东西；人长期总出现，也像成了固定陈设。

**怎么拆**

与 fixure“固定物”等旧形式有关，拼写受 mixture 一类形式影响；不能因此凭空造出拉丁 *fixtum。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

↓

**英语 fixure / fixture**  
固定行为、固定物；fixture 的形式受 mixture 等类推影响

↓

**现代英语 fixture**  
固定装置；常驻人物；预定比赛

a light fixture 是灯具安装装置；a fixture at the café 说某人总在咖啡馆出现。英式 sports fixtures 是赛程里的预定比赛，像已经钉在日历上。

**常见搭配与例句**

lighting fixtures；a permanent fixture；a home fixture；a fixture list。

> The room needs new lighting fixtures.

房间需要新的照明灯具。

> He has become a fixture at the village café.

他已经成了村里咖啡馆的常客。

> The club announced its fixtures for the coming season.

俱乐部公布了下个赛季的赛程。

**别混淆**

furniture 通常是可移动家具；fixtures 常与建筑安装相连。体育 fixture 是一次已安排的比赛，不是体育器材。

<a id="w-5"></a>

### 5. fixation — 执着；迷恋；固定、固着

**音标**：/fɪkˈseɪʃən/

**先抓住这个画面**

注意力像被钉在一点上，反复绕着同一个人、问题或想法转。

**怎么拆**

来自中世纪拉丁 fixatio，亦有经法语 fixation 的路线；早期有使物质固定、稳定的义，远早于英语动词 fixate。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**拉丁语 fixare → 中世纪拉丁语 fixatio**  
固定 → 固定化的过程

↓

**中世纪拉丁语或法语 fixation → 英语 fixation**  
固定、稳定；后来也指心理执着

a fixation on appearance 是对外貌过分执着；普通使用不等于在作医学诊断。科学里的 fixation 还可能是把物质固定为特定形式，必须按领域理解。

**常见搭配与例句**

a fixation on；develop a fixation；an unhealthy fixation。

> His fixation on minor details delayed the project.

他对细枝末节的执着拖慢了项目。

> The novel explores the character’s fixation on the past.

小说探讨了这个人物对过去的执迷。

**别混淆**

focus 可以是有用、可调整的专注；fixation 常暗示过分黏住某点、难以转移。

<a id="w-6"></a>

### 6. prefix — 前缀；放在前面的部分；在前面加

**音标**：名词 /ˈpriːfɪks/；动词常 /ˈpriːfɪks/，亦 /priːˈfɪks/

**先抓住这个画面**

把一个有作用的小部分接到词或字符串前面。

**怎么拆**

名词接拉丁 praefixum，来自动词 praefigere：prae-“前” + figere“固定”；英语动词经法语 prefixer 等进入，记录反而早于语法名词。

**怎么变成今天的意思**

**拉丁语 prae- + figere → praefigere / praefixus**  
在前 + 固定 → 放在前面

↓

**分支一：拉丁语 praefixum → 英语 prefix〔名词〕**  
接在前面的部分 → 前缀

↓

**并列分支二：法语 prefixer → 中古英语 prefixen → prefix〔动词〕**  
预先确定 → 把东西加在前面

unhappy 的 un- 是 prefix；编号前的字母也可叫 prefix。动词可说 prefix a name with a code，把代码放到名字前。不是所有开头相同的字母都是词源上的前缀。

**常见搭配与例句**

add a prefix；a telephone prefix；prefix something with。

> The prefix “un-” changes the meaning of “happy”.

前缀 un- 改变了 happy 的意思。

> Prefix each filename with the project code.

在每个文件名前加上项目代码。

**别混淆**

suffix 接后面；prefix 接前面；affix 是更一般的词缀名称。

<a id="w-7"></a>

### 7. suffix — 后缀；在末尾添加

**音标**：名词 /ˈsʌfɪks/；动词 /səˈfɪks/，也读 /ˈsʌfɪks/

**先抓住这个画面**

把一个小构词零件接到词尾，可能改变词性或补充语法信息。

**怎么拆**

拉丁语 sub- + figere“固定” → suffigere，分词 suffixus。名词经近代拉丁语 suffixum 借入；早期动词也有直接借分词的路线。

**怎么变成今天的意思**

**拉丁语：sub + figere → suffigere / suffixus**  
固定在下方；固定上的

↓

**近代拉丁语 suffixum → 英语 suffix〔名词〕**  
接在词尾的构词成分

↓

**英语语法用法：suffix〔动词〕**  
在词尾添加〔另有较早的一般动词借入〕

kind 加 -ness 成 kindness，-ness 就是后缀。过去式 -ed 也常称 suffix；不要求添加后一定变成完全不同的词。

**常见搭配与例句**

add a suffix；the suffix -ness。

> The suffix -less means “without” in words such as hopeless.

在 hopeless 这类词里，后缀 -less 表示“没有”。

> The system suffixes each filename with a number.

系统在每个文件名末尾加上一个数字。

**别混淆**

prefix 放在词前；suffix 放在词后；一个词最后几个字母不一定真是后缀。

### 8. fixer — 善于摆平事情的人；协调人；定影剂〔专业〕

**音标**：英 /ˈfɪksə/；美 /ˈfɪksər/

**先抓住这个画面**

遇到麻烦时，能找到人、安排资源、把事情办成的那个人。

**怎么拆**

fix + -er；人物义来自处理、安排事情，摄影中的材料义接使影像固定的作用。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

↓

**英语 fix + -er → fixer**  
安排、处理 → 能把事办成的人；固定作用的材料

a political fixer 常暗示靠关系运作，可能不光彩；新闻或摄制团队的 local fixer 则可中性指安排采访、交通和联络的人。摄影里的 fixer 是另一种具体工作材料。

**常见搭配与例句**

a political fixer；a local fixer；work as a fixer。

> The crew hired a local fixer to arrange interviews and transport.

摄制组雇了一名当地协调人，安排采访和交通。

> The novel centres on a fixer who knows everyone in city politics.

小说围绕一个熟悉城里所有政治人物的掮客展开。

**别混淆**

repairer 主要修坏东西；fixer 常解决组织、人际和安排上的麻烦，不只是修理工。

<a id="w-9"></a>

### 9. fixated — 执着于的；过度迷恋的

**音标**：英 /fɪkˈseɪtɪd/；美 /ˈfɪkseɪtɪd/

**先抓住这个画面**

心思已经被某个对象占住，讨论别的事又会绕回来。

**怎么拆**

fixate + -ed；常用 be fixated on，表示持续过分关注的状态。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

↓

**英语 fix + -ate → fixate**  
使固定、注视；心理义也可能受 fixation 反构影响

↓

**英语 fixate → fixated**  
把注意力定住 → 对某事过分执着的

fixated on success 是一门心思盯着成功；fixated on a detail 是被细节困住。这个词通常不只是表扬认真，而是提醒关注失衡。

**常见搭配与例句**

be fixated on；remain fixated on；become fixated on。

> The team became fixated on the deadline and ignored the quality problems.

团队只顾盯着期限，忽略了质量问题。

> She is still fixated on a comment he made years ago.

她仍对他多年前的一句评论耿耿于怀。

**别混淆**

interested in 是感兴趣；fixated on 通常强得多，暗示难以把心思转向其他地方。

<a id="w-10"></a>

### 10. affix — 词缀；附加物；粘上、贴上

**音标**：名词 /ˈæfɪks/；动词 /əˈfɪks/

**先抓住这个画面**

把某个部分接到另一东西上：可以是信封上的标签，也可以是词里的词缀。

**怎么拆**

拉丁 ad- 在 f 前同化为 af-，与 figere 组成 affigere；英语动词经中世纪拉丁 affixare 或法语 affixer，名词也可能经法语 affixe 借入。

**怎么变成今天的意思**

**拉丁语 ad- + figere → affigere / affixus**  
朝向 + 固定 → 附着、固定在上面

↓

**中世纪拉丁语 affixare / 法语 affixer → 英语 affix〔动词〕**  
使附着 → 贴上、加上

↓

**英语名词 affix〔由动词或法语 affixe〕**  
附加部分 → 词缀

动词 affix a label to a box 是把标签贴到盒子上，语气比 stick 正式。名词 affix 包含 prefix、suffix 等类型。注意名词前重音、动词后重音。

**常见搭配与例句**

affix a label to；affix a stamp；a derivational affix。

> Affix the label to the outside of the package.

把标签贴在包裹外面。

> The lesson explains how an affix can change a word’s meaning.

这一课解释了词缀如何改变一个词的意思。

**别混淆**

prefix 与 suffix 指定位置；affix 更概括。attach 更通用，affix 常有牢牢贴上、加上的感觉。

<a id="w-11"></a>

### 11. transfixed — 看呆的；出神的；僵住的

**音标**：/trænsˈfɪkst/

**先抓住这个画面**

整个人的注意力被牢牢吸住，像突然停在原地。

**怎么拆**

transfix + -ed，末尾读 /kst/；常用作分词形容词，说明被某种景象、情绪定住的状态。

**怎么变成今天的意思**

**拉丁语 trans- + figere → transfigere / transfixus**  
穿过 + 刺入 → 刺穿、钉住

↓

**法语 transfixer → 英语 transfix**  
刺穿 → 因惊恐或着迷而呆住

↓

**英语 transfix → transfixed**  
使呆住 → 已经看呆、出神的

stand transfixed 是站着看呆了；transfixed by fear 是恐惧得僵住。它可以来自美景、表演或惊恐，不只是“吓坏”。

**常见搭配与例句**

stand transfixed；watch transfixed；be transfixed by。

> The children stood transfixed by the fireworks.

孩子们站在那里，看烟花看得入了神。

> She remained transfixed, unable to look away from the screen.

她一直看得出神，无法把目光从屏幕上移开。

**别混淆**

fixated 常是持续过度执着于某个对象；transfixed 更像当下的一次震撼、出神或僵住。

<a id="w-12"></a>

### 12. fixable — 可以修好的；可以解决的

**音标**：/ˈfɪksəbəl/

**先抓住这个画面**

问题确实存在，但还有办法处理，不是已经无可挽回。

**怎么拆**

fix + -able；直接由现代动词的修理、解决义派生。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

↓

**英语 fix + -able → fixable**  
修好、解决 → 能够修好、解决的

a fixable fault 是可修复的故障；a fixable mistake 是可补救的错误。只说明存在办法，不表示一定便宜、容易或立刻能完成。

**常见搭配与例句**

a fixable problem；a fixable fault；easily fixable。

> The mechanic said the fault was fixable.

修理师说这个故障可以修好。

> The report contains several easily fixable errors.

报告中有几个很容易纠正的错误。

**别混淆**

fixed 是已经解决；fixable 只是有解决的可能。

<a id="w-13"></a>

### 13. fixate — 过分关注；执着于；把视线固定在

**音标**：英 /fɪkˈseɪt/；美 /ˈfɪkseɪt/

**先抓住这个画面**

目光或心思一直钉在一个点上，很难挪开。

**怎么拆**

fix + -ate 或接拉丁 fixus 构词；心理意义可能也从更早的 fixation 反构，不把名词都排在动词之后。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

↓

**英语 fix + -ate → fixate**  
使固定、注视；心理义也可能受 fixation 反构影响

日常常用 fixate on：不要一直纠结小错误。视觉研究中的 fixate a target 则可以仅指注视目标，没有负面情绪。英美常见重音位置不同。

**常见搭配与例句**

fixate on a mistake；fixate on the past；fixate a visual target。

> Try not to fixate on the one question you answered badly.

尽量不要一直纠结那一道没答好的题。

> Participants were asked to fixate a dot at the centre of the screen.

研究要求参与者注视屏幕中央的一个点。

**别混淆**

concentrate 强调集中注意力；fixate 在普通话语里常带过度、难以放下的意思。

<a id="w-14"></a>

### 14. hotfix — 紧急修复；针对具体问题的快速补丁

**音标**：英 /ˈhɒtfɪks/；美 /ˈhɑːtfɪks/

**先抓住这个画面**

等不到下一次常规发布，先把一个急迫的软件问题修掉。

**怎么拆**

hot“急迫、即时处理的” + fix“修复”；软件领域的现代复合词，不是把设备加热。

**怎么变成今天的意思**

**拉丁语 figere → 分词 fixus**  
插入、钉住、使固定 → 固定的

↓

**可能经古法语 \*fixer → 中古英语 fixen → fix**  
固定、把目光停住；后来指安排、修理；\* 为重建形式

↓

**英语 hot + fix → hotfix**  
即时、紧急 + 修复 → 针对问题快速发布的补丁

release a hotfix 是发布紧急补丁；apply a hotfix 是应用它。不同产品对发布方式的定义略有差别，不保证一定无需重启，也不保证涵盖所有改动。

**常见搭配与例句**

release a hotfix；apply a hotfix；a security hotfix。

> The developers released a hotfix for the login failure.

开发者为登录失败问题发布了紧急修复。

> The team tested the hotfix before deploying it.

团队在部署前测试了这个紧急补丁。

**别混淆**

patch 是补丁总称；hotfix 通常突出紧急、针对性强，release 则可包含功能等更广变化。

<a id="w-15"></a>

### 15. transfix — 使呆住；使出神；刺穿〔字面〕

**音标**：/trænsˈfɪks/

**先抓住这个画面**

像被一根看不见的钉子定在原地，眼睛挪不开，身体也一时不动。

**怎么拆**

拉丁 trans-“穿过” + figere“刺入、固定”构成 transfigere，分词 transfixus，经法语 transfixer 进入英语。

**怎么变成今天的意思**

**拉丁语 trans- + figere → transfigere / transfixus**  
穿过 + 刺入 → 刺穿、钉住

↓

**法语 transfixer → 英语 transfix**  
刺穿 → 因惊恐或着迷而呆住

现代阅读里常是 be transfixed by a sight：因为惊讶、恐惧或着迷而呆住。早期的实际刺穿义解释了“钉在原地”的比喻，但使用时不需要真实受伤。

**常见搭配与例句**

transfix an audience；be transfixed by；transfix with fear。

> The strange light transfixed everyone in the room.

那道奇异的光让屋里所有人都看呆了。

> The performer seemed able to transfix an entire audience.

那位表演者似乎能让全场观众都看得出神。

**别混淆**

interest 只是引起兴趣；transfix 强调强烈到让人暂时僵住、完全被吸住。

## 这一组要分清什么

fixated 常是长期、过度的执着；transfixed 更像一时看呆。prefix 在前、suffix 在后，affix 是总称。fixed 是已经固定或修好，fixable 只是能够修好。

## 串起来练习

用 fix 分别说修锁、定日期、操纵比赛；用 fixation 与 transfixed 区分纠结过去和看烟花出神。
