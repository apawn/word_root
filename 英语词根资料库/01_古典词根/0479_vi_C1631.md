# 0479 · vi- — 道路；路径

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 via 是道路。它在英语里并不总长成一眼可认的“路”义：计划可以是路线，困难可以挡路，意见也可以试着穿进人的心里。用这些画面理解语义，但实际借词先后仍分别看每个词的历史。

**先想一条路，再看是在路上、离开路，还是能不能穿过去**

via 沿路经过；deviate 偏出路线；obvious 迎面摆在路上；pervious 有路可穿；trivial 从公共路口的“寻常”走向“不重要”。

- **沿路与偏路**：via、deviate、deviation、deviant、deviance、devious、deviously、deviousness
- **迎面与事先挡住**：obvious、obviously、obviousness、obviate、obviation
- **公共、寻常与小事**：trivial、trivia、triviality、trivialize、trivially
- **道路能否通行**：viaduct、pervious、impervious

## 词形与演化规律

vi-、via、-vious 见于不同拉丁构词。deviate 与 deviation、obviate 与 obviation 各有独立借入路线，不能只按英语词长决定谁先谁后。trivium 里的 tri- 是三；viaduct 则是近代仿 aqueduct 的新造词。

## 逐词讲解

<a id="w-1"></a>

### 1. via — 经过；通过；借助

**音标**：/ˈvaɪə/；亦 /ˈviːə/

**先抓住这个画面**

告诉你从这里到那里，是沿哪条路或经过哪个渠道。

**怎么拆**

借拉丁 viā，via 的夺格形式，意为“经由某条路”；英语没有把它再拆成 vi + a。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 viā → 英语 via**  
经由某条道路 → 经过某地或使用某渠道

travel via Rome 说罗马在行程路线上，不一定是最终目的地。via email 则把道路换成信息渠道：消息沿邮件这条“路”送达。

**常见搭配与例句**

via a connecting airport；via email；access via the main entrance。

> We flew to Lisbon via Madrid.

我们经马德里飞往里斯本。

> The confirmation arrived via email.

确认信息通过电子邮件发来了。

**别混淆**

via 强调途经点或渠道；to 常直接说目的地。二者可以出现在同一句里。

<a id="w-3"></a>

### 2. obvious — 明显的；容易看出的

**音标**：英 /ˈɒbviəs/；美 /ˈɑːbviəs/

**先抓住这个画面**

东西就摆在你面前，不用费力绕过去找。

**怎么拆**

拉丁 obvius 中 ob- 是“迎面、在前”，via 是“路”；英语借入后形成 obvious，不是 ob + vision。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 ob + viam → obviam → obvius**  
在路前面、迎面可遇见的

↓

**英语 obvious**  
从容易遇到、摆在眼前，发展为明显的

它可以说肉眼可见的破损，也可以说容易推出的结论。“明显”总相对于某个观察者和已知条件；It is obvious to me 不保证别人已经知道。

**常见搭配与例句**

an obvious mistake；be obvious to someone；It is obvious that…。

> The crack was obvious even from across the room.

即使站在房间另一头，那道裂缝也很明显。

> It became obvious that we needed a larger table.

我们显然需要一张更大的桌子，这一点逐渐清楚了。

**别混淆**

visible 是能看见；obvious 是容易看出或理解。一个可见的小痕迹未必让原因变得 obvious。

<a id="w-2"></a>

### 3. obviously — 显然；明显地

**音标**：英 /ˈɒbviəsli/；美 /ˈɑːbviəsli/

**先抓住这个画面**

把一句话放在“根据眼前线索，这很容易判断”的位置上。

**怎么拆**

obvious + -ly；道路的画面经过 obvious，变成判断的清楚程度。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 ob + viam → obviam → obvius**  
在路前面、迎面可遇见的

↓

**英语 obvious**  
从容易遇到、摆在眼前，发展为明显的

↓

**英语 obvious + -ly → obviously**  
以明显的方式；显然如此

She was obviously tired 是说疲倦很容易从表现看出来。句首 Obviously 也常表示说话者把某点当成双方已知，所以语气有时会显得理所当然。

**常见搭配与例句**

obviously tired；obviously wrong；Obviously, …。

> He was obviously relieved when the keys turned up.

钥匙找到时，他显然松了一口气。

> Obviously, we cannot fit twelve people into this tiny room.

显然，这间小屋容不下十二个人。

**别混淆**

apparently 常保留“看起来如此、据说如此”的距离；obviously 表示说话者觉得证据很清楚。

<a id="w-16"></a>

### 4. obviousness — 明显；显而易见的程度

**音标**：英 /ˈɒbviəsnəs/；美 /ˈɑːbviəsnəs/

**先抓住这个画面**

说的不是某条结论本身，而是它有多容易被看出来。

**怎么拆**

obvious + -ness，把“明显的”变成一种性质。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 ob + viam → obviam → obvius**  
在路前面、迎面可遇见的

↓

**英语 obvious**  
从容易遇到、摆在眼前，发展为明显的

↓

**英语 obvious + -ness → obviousness**  
容易看出这一性质

the obviousness of the error 是错误明显到什么程度。这个名词比 obvious 更抽象，适合比较不同人的观察或解释为什么一个问题容易被忽略。

**常见搭配与例句**

the obviousness of a mistake；apparent obviousness。

> The obviousness of the error made the delay hard to explain.

错误如此明显，拖到现在才处理就很难解释。

> What surprised her was the obviousness of the solution once it was drawn.

令她惊讶的是，解法一画出来就显得那么明白。

**别混淆**

obviousness 讨论清楚程度；certainty 讨论确定程度。某件事乍看很明显，仍可能判断错。

<a id="w-4"></a>

### 5. trivial — 琐碎的；不重要的；很容易的；平凡的〔数学〕

**音标**：/ˈtrɪviəl/

**先抓住这个画面**

常见到不值得大费周章，或简单到几乎不用额外处理。

**怎么拆**

拉丁 trivialis 来自 trivium“三岔路口”：公共场所的 → 寻常的 → 不重要的。另有中世纪 trivium“三艺”的相关用法，不能编成“路口闲聊所以没价值”的故事。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 tri- + via → trivium → triviālis**  
三岔路口 → 公共场所的、寻常的

↓

**英语 trivial**  
寻常、不重要；专业语境中也指最简单的情形

a trivial error 是影响很小的错误；a trivial task 是很容易完成的任务。数学的 trivial solution 常指最简单、直接可见的解，具体是什么由问题决定，不是所有场合都固定等于零。

**常见搭配与例句**

a trivial detail；a trivial problem；a trivial solution。

> They argued for an hour over a trivial detail.

他们为一个无关紧要的细节争论了一小时。

> For this equation, zero gives a trivial solution.

对这个方程来说，零给出了一个平凡解。

**别混淆**

simple 只说简单；trivial 还可能把重要性压低。病人的担心不能仅因解释简单就称为 trivial。

<a id="w-13"></a>

### 6. trivially — 无足轻重地；轻而易举地；显然地〔推理〕

**音标**：/ˈtrɪviəli/

**先抓住这个画面**

有时说影响太小，有时说这一步几乎不用再费功夫。

**怎么拆**

trivial + -ly，修饰某个差别、动作或推导的程度与方式。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 tri- + via → trivium → triviālis**  
三岔路口 → 公共场所的、寻常的

↓

**英语 trivial**  
寻常、不重要；专业语境中也指最简单的情形

↓

**英语 trivial + -ly → trivially**  
以很小、很简单或显然的方式

differ trivially 是差别不重要。证明中 follows trivially 表示这一步直接推出；如果读者看不出，补上那一步通常比只写“显然”更有用。

**常见搭配与例句**

trivially small；trivially true；follow trivially from a definition。

> The two versions differ only trivially in punctuation.

两个版本只在标点上有些无关紧要的差别。

> The empty set trivially satisfies this condition.

空集显然满足这个条件。

**别混淆**

easily 只强调不费力；trivially 在学术中常暗含结论直接、没有额外实质难点。

<a id="w-15"></a>

### 7. trivialize — 轻视；把重要事情说得无足轻重

**音标**：/ˈtrɪviəlaɪz/

**先抓住这个画面**

本来有分量的事情，被说得像一点不值一提的小事。

**怎么拆**

trivial + -ize；把事情变成、或表现成 trivial 的样子。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 tri- + via → trivium → triviālis**  
三岔路口 → 公共场所的、寻常的

↓

**英语 trivial**  
寻常、不重要；专业语境中也指最简单的情形

↓

**英语 trivial + -ize → trivialize**  
使显得琐碎、不重要

一句“大家都这样”可能 trivialize someone’s experience，把对方真正遇到的困难轻轻带过。它常批评低估重要性，不是正常地把复杂说明讲简单。

**常见搭配与例句**

trivialize a problem；trivialize someone’s experience；avoid trivializing the issue。

> The joke trivialized the difficulties the workers had faced.

那个笑话把工人们经历的困难说得轻飘飘的。

> A short explanation need not trivialize a serious subject.

解释得简短，并不一定会把严肃话题讲得无足轻重。

**别混淆**

simplify 是减少复杂度，可能很有帮助；trivialize 是压低事情的分量，常带批评。

<a id="w-17"></a>

### 8. triviality — 琐碎；微不足道；琐事

**音标**：/ˌtrɪviˈæləti/

**先抓住这个画面**

既能说事情分量很轻，也能直接指那些轻得不值得纠缠的小事。

**怎么拆**

trivial + -ity，词尾变化使重音落到 -al- 所在音节。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 tri- + via → trivium → triviālis**  
三岔路口 → 公共场所的、寻常的

↓

**英语 trivial**  
寻常、不重要；专业语境中也指最简单的情形

↓

**英语 trivial + -ity → triviality**  
不重要这一性质；一件不重要的事

the triviality of the dispute 强调争端根本不值得闹大；argue over trivialities 则把一件件鸡毛蒜皮的事数出来。可数与不可数两种用法都常见。

**常见搭配与例句**

the triviality of an issue；discuss trivialities；an apparent triviality。

> The triviality of the disagreement made their anger seem absurd.

分歧如此微不足道，他们的怒气显得很荒唐。

> Let us settle the main question before discussing trivialities.

我们先把主要问题解决，再谈那些琐事。

**别混淆**

trivia 常是有趣但不重要的知识；trivialities 可以是日常琐事，不要求它们是知识题目。

<a id="w-5"></a>

### 9. trivia — 冷知识；琐碎信息；知识问答

**音标**：/ˈtrɪviə/

**先抓住这个画面**

一小块一小块的有趣事实，知道了能增添趣味，却不一定解决重要问题。

**怎么拆**

形式取自拉丁 trivia，trivium 的复数；现代“琐碎小事”用法受 Logan Pearsall Smith 的书名 Trivia 推动，后来发展出冷知识问答义。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 trivium → trivia〔复数〕**  
三岔路口、公共场所；与“寻常”的语义相连

↓

**英语书名 Trivia → 琐碎小事、零散知识 → trivia 问答**  
近现代英语中的意义发展，不是把古代课程直接搬成现代游戏

film trivia 可以是电影制作中的小细节。日常把它当集合信息，常说 a piece of trivia，而不是把一条事实叫 a trivia；trivia night 则是大家参加知识问答的活动。

**常见搭配与例句**

a piece of trivia；a trivia quiz；film trivia。

> He shared an amusing piece of trivia about the film’s opening scene.

他分享了关于电影开场的一条有趣冷知识。

> Our team came second at the library’s trivia night.

我们队在图书馆的知识问答之夜拿了第二名。

**别混淆**

triviality 可以是一件不重要的小事；trivia 更常专指零散事实或围绕这些事实的问答。

<a id="w-7"></a>

### 10. deviate — 偏离；离开原定路线或标准

**音标**：动词 /ˈdiːvieɪt/；较少见的名词、形容词 /ˈdiːviət/

**先抓住这个画面**

本来沿一条线走，后来朝旁边拐了出去。

**怎么拆**

借晚期拉丁 dēviātus，来自 dēviāre“离开道路”；de- 表离开，via 表道路，现代词尾对应 -ate。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**晚期拉丁 dē viā → dēviāre**  
离开道路 → 偏离

↓

**晚期拉丁 dēviātus → 英语 deviate**  
偏离的 → 偏离、改变原路线

常接 from：deviate from the route / plan / norm。偏离不自动等于做错；避开积雪而改变路线也可以是合理选择。名词指人的旧用法常带贬意，日常学习优先掌握动词。

**常见搭配与例句**

deviate from a plan；deviate slightly；never deviate from the procedure。

> We had to deviate from the marked path to avoid the fallen tree.

我们不得不偏离标出的路径，绕开倒下的树。

> The result deviates only slightly from the predicted value.

结果与预测值只有轻微偏差。

**别混淆**

deviate 描述离开原定方向；devious 常评价绕弯或不坦率，不能见到同根就互换。

<a id="w-6"></a>

### 11. deviation — 偏离；偏差；偏离的量

**音标**：/ˌdiːviˈeɪʃən/

**先抓住这个画面**

把“偏了”变成一件可描述、甚至可测量的事。

**怎么拆**

经中古法语 deviation、上溯中世纪拉丁 deviatio 独立借入；现代可对应 deviate + -ion，但英语名词的记录早于这个英语动词。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**晚期拉丁 dē viā → dēviāre**  
离开道路 → 偏离

↓

**中世纪拉丁 deviatio → 中古法语 deviation → 英语 deviation**  
偏离的行为或结果；独立名词路线

路线有 deviation，数值相对参考值也有 deviation。统计中的 standard deviation 是按特定公式计算的离散程度，不能随意解释成“所有差值的普通平均”。

**常见搭配与例句**

a deviation from the plan；a small deviation；standard deviation。

> Any deviation from the agreed route must be reported.

凡偏离约定路线的情况，都必须报告。

> The instrument showed a deviation of two degrees from the reference angle.

仪器显示的角度与参考角度相差两度。

**别混淆**

deviation 可中性地说数值偏离；deviance 更常讨论违反社会规范。

<a id="w-8"></a>

### 12. deviant — 偏离规范的；被视为不合常规的人或事物

**音标**：/ˈdiːviənt/

**先抓住这个画面**

周围人画出一条“正常路线”，它却走在那条线之外。

**怎么拆**

经中古英语 devyaunt，上溯晚期拉丁 dēviāns“正在偏离的”；这是拉丁分词的借入，不是必须先有英语 deviate 才造出的词。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**晚期拉丁 dē viā → dēviāre**  
离开道路 → 偏离

↓

**晚期拉丁 dēviāns → 中古英语 devyaunt → 英语 deviant**  
偏离的 → 不符合预期或社会规范的

↓

**英语形容词 deviant → 名词 deviant**  
把某人或某事称为偏离常规者

社会语境中的 deviant 带有“谁规定正常”的问题；不同群体的规范可能不同。直接把人叫 a deviant 通常带贬义，不能当作 individual“有个性的人”的中性替代。

**常见搭配与例句**

deviant behaviour；a deviant pattern；label someone deviant。

> The study asks why some behaviour is labelled deviant in one society but accepted in another.

研究追问：为什么某些行为在一个社会被视为越轨，在另一个社会却被接受。

> The analyst examined the deviant pattern instead of discarding it.

分析者研究了那种异常模式，而没有直接删掉它。

**别混淆**

unusual 只说少见；deviant 往往强调偏离预期规范，而且可能含负面评价。

<a id="w-12"></a>

### 13. deviance — 越轨；违反社会规范的行为

**音标**：/ˈdiːviəns/

**先抓住这个画面**

重点不在偏了多少米，而在跨出了某个群体认可的行为边界。

**怎么拆**

有 deviant + -ance 的英语派生分析，也有法语 déviance 借入分析；两条分析都接回拉丁“离开道路”，不强画唯一先后。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**晚期拉丁 dē viā → dēviāre**  
离开道路 → 偏离

↓

**并列分析：英语 deviant + -ance／法语 déviance 借入**  
形成 deviance，表示偏离规范的性质或行为

社会学里的规范包括法律，也包括习俗，因此 deviance 不等于 crime。穿着打破习惯可能被当作越轨，却未必违法；这个词描述的是与规范的关系。

**常见搭配与例句**

social deviance；the study of deviance；attitudes towards deviance。

> The course examines how definitions of deviance change over time.

这门课程研究社会对越轨的界定怎样随时间变化。

> The author distinguishes deviance from behaviour prohibited by law.

作者区分了偏离社会规范与法律禁止的行为。

**别混淆**

deviation 范围较广，可指测量偏差；deviance 常带社会规范的讨论背景。

<a id="w-9"></a>

### 14. devious — 狡猾的；绕弯的；不坦率的

**音标**：/ˈdiːviəs/

**先抓住这个画面**

为了达到目的，不直走，而是拐弯、掩饰，让别人难看清真实打算。

**怎么拆**

借拉丁 dēvius“离开道路的”；与 deviate 同根但独立借入，不是把英语 deviate 的尾巴改成 -ous。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 dēvius → 英语 devious**  
离开正路的 → 绕远的；后来也指耍弯子的

早期可说路线迂回，今天更常说人的手段和计划：a devious trick 往往暗含欺骗。它不是 clever 的单纯升级版，因为聪明可以光明正大，devious 通常让人不信任。

**常见搭配与例句**

a devious plan；devious methods；a devious mind。

> The villain devised a devious plan to turn the friends against each other.

反派设计了一个阴险的计划，让朋友们互相敌对。

> She distrusted his devious answers to simple questions.

对于简单问题，他总是绕着回答，这让她不信任他。

**别混淆**

indirect 可以只是间接或绕远；devious 常多出故意藏心思的意味。

<a id="w-19"></a>

### 15. deviously — 狡猾地；以迂回的方式

**音标**：/ˈdiːviəsli/

**先抓住这个画面**

动作表面看起来是一回事，背后却绕着另一套打算。

**怎么拆**

devious + -ly，说明做事的方式。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 dēvius → 英语 devious**  
离开正路的 → 绕远的；后来也指耍弯子的

↓

**英语 devious + -ly → deviously**  
以绕弯、不坦率的方式

deviously planned 强调计划里有曲折算计。deviously difficult 也可形容谜题巧妙得让人绕来绕去，语气未必真的谴责出题人。

**常见搭配与例句**

deviously clever；deviously planned；deviously difficult。

> The message was deviously worded to imply a promise without making one.

那条消息措辞狡猾，暗示了一个承诺，却没有真正作出承诺。

> The final puzzle was deviously difficult, with one clue hidden inside another.

最后一道谜题绕得巧妙，一条线索还藏在另一条里面。

**别混淆**

cleverly 只肯定聪明；deviously 把聪明与弯绕、隐蔽的办法联系起来。

<a id="w-20"></a>

### 16. deviousness — 狡猾；诡计多端；迂回程度

**音标**：/ˈdiːviəsnəs/

**先抓住这个画面**

把那种让人摸不清真实意图的弯绕心思，拿出来作为一种特点。

**怎么拆**

devious + -ness，名词化其做事方式或性质。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 dēvius → 英语 devious**  
离开正路的 → 绕远的；后来也指耍弯子的

↓

**英语 devious + -ness → deviousness**  
狡猾、不坦率这一性质

可评价人物的算计，也可说情节或谜题的曲折巧妙。具体褒贬靠语境：谈欺骗常负面，谈侦探小说机关则可能带欣赏。

**常见搭配与例句**

the deviousness of a scheme；admire the deviousness of a plot。

> The deviousness of the scheme became clear only after the final payment.

直到最后一笔钱付出后，这个骗局的狡猾之处才显露出来。

> Readers enjoyed the deviousness of the detective story’s plot.

读者很喜欢这部侦探小说情节中巧妙的曲折。

**别混淆**

deception 是欺骗行为或状态；deviousness 更强调达到目的时的弯绕和算计。

<a id="w-18"></a>

### 17. pervious — 可透过的；可通行的

**音标**：英 /ˈpɜːviəs/；美 /ˈpɜːrviəs/

**先抓住这个画面**

里面有路，水、空气或其他东西能穿过去。

**怎么拆**

借拉丁 pervius：per- “穿过” + via“路”；不是从 impervious 删除 im- 才首次产生。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 per + via → pervius**  
有路可穿过的、可通行的

↓

**英语 pervious**  
允许通过或渗透的

pervious concrete 指能让水穿过的透水混凝土。形容某材料时要看“对什么可透”：让水过去不表示能让所有物质都同样自由通过。

**常见搭配与例句**

pervious concrete；pervious to water；a pervious surface。

> The path uses pervious concrete so rainwater can pass through it.

这条路用了透水混凝土，让雨水能够穿过路面。

> The upper layer is pervious to water, but the layer below it is not.

上层能透水，下层却不能。

**别混淆**

porous 说有孔隙；pervious 说能透过。孔隙是否连通、物质能否通过，还要看材料。

<a id="w-10"></a>

### 18. impervious — 不能透过的；不受影响的

**音标**：英 /ɪmˈpɜːviəs/；美 /ɪmˈpɜːrviəs/

**先抓住这个画面**

外面的东西撞过来，却找不到能进入的路。

**怎么拆**

借拉丁 impervius：in- “不”在 p 前变 im-，加 pervius“可穿过的”；现代可对应 im- + pervious。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 per + via → pervius**  
有路可穿过的、可通行的

↓

**拉丁 in- + pervius → impervius → 英语 impervious**  
没有可穿过之路 → 不可渗透、不受影响

impervious to water 说水进不去；impervious to criticism 把批评想成进不了心里的东西。总要看后面的 to，不能只凭这个词就断言材料对任何东西都不透。

**常见搭配与例句**

impervious to water；impervious to criticism；an impervious coating。

> The coating makes the surface impervious to water.

这层涂料使表面不透水。

> He seemed impervious to every suggestion that he change the schedule.

不管别人怎样建议调整日程，他似乎都听不进去。

**别混淆**

waterproof 专说防水；impervious 可谈不同物质，也可比喻对意见、影响毫无反应。

<a id="w-11"></a>

### 19. viaduct — 高架桥；跨谷桥

**音标**：/ˈvaɪədʌkt/

**先抓住这个画面**

把道路架起来，一跨接一跨地越过山谷或其他障碍。

**怎么拆**

近代英语用拉丁 via“路”加 -duct“引导”构词，仿 aqueduct；并非古罗马已有这个完整英语名称。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**十九世纪英语 via + -duct，仿 aqueduct → viaduct**  
让道路跨越障碍的桥梁名称

常用于铁路或公路的长桥，往往有多跨。词里是“引路”，所以桥上主要通车，而 aqueduct 的核心任务是输水。

**常见搭配与例句**

a railway viaduct；cross a viaduct；a stone viaduct。

> The train crossed the valley on a tall stone viaduct.

火车沿高高的石砌跨谷桥穿过山谷。

> The new viaduct carries the motorway above the wetlands.

新高架桥让高速公路从湿地上方通过。

**别混淆**

bridge 是桥的总称；viaduct 常突出长距离、多跨地承载道路或铁路。

<a id="w-14"></a>

### 20. obviate — 避免；排除；使不再必要

**音标**：英 /ˈɒbvieɪt/；美 /ˈɑːbvieɪt/

**先抓住这个画面**

迎上可能挡路的问题，提前处理，让后面不必再为它绕路。

**怎么拆**

借晚期拉丁 obviātus，来自 obviāre“迎面而去、阻止”；它与 obvious 共用 obvius 支线，却不是“使明显”。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 ob + viam → obviam → obvius**  
在路前面、迎面可遇见的

↓

**晚期拉丁 obviāre → obviātus → 英语 obviate**  
迎上、阻挡 → 预防困难或消除某种需要

常见 obviate the need for：一个更好的办法让原先那步工作不必再做。它较正式，宾语通常是困难、风险或需要，不是直接说“避开某个人”。

**常见搭配与例句**

obviate the need for something；obviate a difficulty；obviate further checks。

> A shared calendar can obviate the need for repeated scheduling emails.

共享日历可以让大家不必反复发邮件确认时间。

> The clearer instructions obviated several possible misunderstandings.

更清楚的说明避免了几种可能的误解。

**别混淆**

avoid 可表示自己绕开问题；obviate 常表示采取办法，使那个问题或需要不再出现。

<a id="w-21"></a>

### 21. obviation — 避免；防止；使某种需要不再产生

**音标**：英 /ˌɒbviˈeɪʃən/；美 /ˌɑːbviˈeɪʃən/〔按构词读音〕

**先抓住这个画面**

把原先可能要处理的麻烦，在它成为负担之前化掉。

**怎么拆**

经中古英语 obviacioun，上溯后期拉丁 obviatio；现代与 obviate + -ion 对应，但英语这个名词早有记录，不应画成英语动词首次派生。

**怎么变成今天的意思**

**拉丁 via**  
道路、路径

↓

**拉丁 ob + viam → obviam → obvius**  
在路前面、迎面可遇见的

↓

**后期拉丁 obviāre → obviatio → 中古英语 obviacioun**  
迎上、接触等动作的名词

↓

**英语 obviation**  
后来用于避免困难、消除需要的过程

这是很正式的名词。the obviation of further work 说让后续工作不再必要；一般叙述直接用 obviate 或 remove the need 更轻快。

**常见搭配与例句**

the obviation of a need；the obviation of unnecessary work。

> The report lists the obviation of duplicate checks as a benefit of the new system.

报告把避免重复检查列为新系统的一项好处。

> The aim was the obviation of needless travel, not the cancellation of all meetings.

目的是免去不必要的奔波，并非取消所有会议。

**别混淆**

obviousness 是明显程度；obviation 是避免或免除的过程，虽然前几字母相同，不能混读意思。

## 这一组要分清什么

obvious 是明显，obviate 是避免困难。deviation 可中性地说偏差，deviance 常谈社会规范。trivial 的路口来源不等于“路边闲聊”的故事；三艺 trivium 是另一个历史用法。viable 属生命 vita 的支线，不是看见 vi- 就归道路。

## 串起来练习

把“消息经邮件送达”“路线偏了”“涂层不透水”“这个细节不重要”分别用 via、deviate、impervious、trivial 说出来，再解释每句里的“路”在哪里。
