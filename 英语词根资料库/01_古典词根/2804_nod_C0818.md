# 2804 · nod- — 结；结块

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 nodus 表示结。node 借入后扩展到网络、数据、植物与人体的不同“节”；nodule 接拉丁指小形式 nodulus。denouement 经法语“解结”绕了一条路，讲故事结尾怎样把线索交代清楚。

**nod-：绳子打成的结、小团块，以及系统里能够单独标出的节点。**

一张网有很多结；小结块是 nodule，故事的纠葛像绳结，最后解开则是 denouement。

- **体系中的节与连接点**：node、nodal
- **小结块的形状**：nodule、nodular
- **解开情节的结**：denouement

## 词形与演化规律

nodal 是英语 node + -al，nodular 是 nodule + -ar；node 与 nodule 各有自己的借入路线。denouement 中的 nou- 经法语变化，不能只靠现代拼写认亲。

## 逐词讲解

<a id="w-1"></a>

### 1. node — 节点；结；节

**音标**：英 /nəʊd/；美 /noʊd/

**先抓住这个画面**

像网绳打结的地方，一个体系里可以被单独标出来的点。

**怎么拆**

整体借拉丁 nodus“结、结块”。英语 node 原来就有结块义，后来延伸到交会处和各种节点；不是由 nod“点头”加 e 造出。

**怎么变成今天的意思**

**拉丁语 nodus**  
结、结块

↓

**中古英语 node → 英语 node**  
结块；再用于相交、连接或有特定作用的位置

网络中一个设备或处理单元可以是 node，树形数据结构中的一个位置也可以是 node。植物的 node 是茎上长出叶或芽等结构的节；lymph node 则是免疫系统中的淋巴结。共同画面是一个有位置、有作用的“结”。

**常见搭配与例句**

a network node；a child node；a leaf node；a lymph node；a stem node。

> Each node in the diagram represents one computer on the network.

图中的每个节点代表网络中的一台计算机。

> New leaves grow from nodes along the stem.

新叶从茎上的各个节长出来。

> The diagram labels the lymph nodes in the neck.

示意图标出了颈部的淋巴结。

**别混淆**

point 是泛泛的点，node 常属于某个结构或系统。node 不一定是最重要的中心，图论中甚至可以有暂时没有连边的孤立节点。

<a id="w-2"></a>

### 2. nodal — 节点的；结点处的；起枢纽作用的

**音标**：英 /ˈnəʊdəl/；美 /ˈnoʊdəl/

**先抓住这个画面**

把视线落在节点上，讨论那里发生的事或它在整体中的作用。

**怎么拆**

英语 node + -al，去掉词尾 e，再加表示有关性质的后缀。

**怎么变成今天的意思**

**拉丁语 nodus**  
结、结块

↓

**中古英语 node → 英语 node**  
结块；再用于相交、连接或有特定作用的位置

↓

**英语 node + -al → nodal**  
与节点有关的

a nodal point 可以是网络或线路交会的关键点；nodal connections 则是节点之间的连接关系。具体专业含义随 node 所属领域变化，不能把每个 nodal 都译成“中心的”。

**常见搭配与例句**

a nodal point；nodal connections；a nodal network；nodal analysis。

> The port became a nodal point in the regional transport network.

这个港口成为区域运输网中的一个枢纽点。

> The diagram shows how the nodal connections change when one link is removed.

图示说明移除一条连线后，节点连接关系怎样变化。

**别混淆**

central 强调位于中心或特别重要；nodal 强调节点角色。边缘的节点仍然有 nodal properties，不一定处于中心。

<a id="w-3"></a>

### 3. denouement — 结局；谜底揭晓；事情最后的解决

**音标**：英 /ˌdeɪˈnuːmɒ̃/；美 /ˌdeɪnuːˈmɑ̃ː/

**先抓住这个画面**

前面打下的一个个情节结，到这里终于解开。

**怎么拆**

借法语 dénouement，来自 dénouer“解结”，接 dé-“解除”与 nouer“打结”；nouer 再接拉丁 nodare、nodus。也写 dénouement，保留法语式拼写，不能把尾巴读成普通英语 -ment。

**怎么变成今天的意思**

**拉丁语 nodus**  
结、结块

↓

**拉丁语 nodare → 法语 nouer；古法语 desnouer → dénouer**  
打结；加解除成分后表示解结

↓

**法语 dénouement → 英语 denouement**  
解开情节的结 → 结局、最后的解决

侦探小说最后解释谁做了什么、先前线索怎样相连，那一部分就是 denouement。它也能用于现实事件的最终收束；重点不只是“停下”，而是前面的纠葛有了交代。

**常见搭配与例句**

the final denouement；a surprising denouement；the denouement of the story；a satisfying denouement。

> The final chapter delivers a denouement that explains every earlier clue.

最后一章揭开谜底，解释了此前的每一条线索。

> The long dispute reached its denouement when both sides signed the agreement.

双方签下协议，这场漫长争端终于有了结局。

**别混淆**

climax 是冲突或紧张的高点；denouement 常是高点之后的解释和收束。结局可以平静，不一定比高潮更惊险。

<a id="w-4"></a>

### 4. nodule — 小结节；小团块；小结核

**音标**：英 /ˈnɒdjuːl/；美 /ˈnɑːdʒuːl/

**先抓住这个画面**

像一小颗结起来、鼓起来的团块。

**怎么拆**

借拉丁 nodulus“一个小结”，其中 -ulus 是指小形式。它是独立借词，不是现代英语 node 临时加上一个规则的 -ule。

**怎么变成今天的意思**

**拉丁语 nodus**  
结、结块

↓

**拉丁语 nodulus**  
小结，是 nodus 的指小形式

↓

**中古英语 nodule → 英语 nodule**  
小结节、小团块

植物根上的小结块、岩石中的团块和人体检查中发现的结节都可能叫 nodule。医学里它描述一种团块或增生，单凭这个词不能判断良恶性。

**常见搭配与例句**

a small nodule；root nodules；a thyroid nodule；a mineral nodule。

> The bean plant has small nodules on its roots.

这株豆类植物的根上有小结节。

> The scan showed a small nodule that the doctor wanted to examine further.

扫描发现了一个小结节，医生希望进一步检查。

**别混淆**

node 常是系统中正常的节或节点；nodule 更突出一个小团块。lymph node 和 nodule 不能因为中文都带“结”就随意互换。

<a id="w-5"></a>

### 5. nodular — 结节状的；有小团块的

**音标**：英 /ˈnɒdʒələ/；美 /ˈnɑːdʒələr/

**先抓住这个画面**

看上去或构造上是一颗颗小团块，而不是平整的一片。

**怎么拆**

英语 nodule + -ar；去掉 nodule 末尾 e，形成描述形态或性质的形容词。

**怎么变成今天的意思**

**拉丁语 nodus**  
结、结块

↓

**拉丁语 nodulus**  
小结，是 nodus 的指小形式

↓

**中古英语 nodule → 英语 nodule**  
小结节、小团块

↓

**英语 nodule + -ar → nodular**  
像小结节的；由小结节构成的

nodular rock 可以说岩石有结核状团块，医学描述中的 nodular 则强调结节形态。它是“长成什么样”的描述，不能单靠这个形容词推出具体原因或诊断。

**常见搭配与例句**

a nodular surface；nodular rock；a nodular structure；nodular growth。

> The rock has a nodular structure rather than a smooth, uniform texture.

这块岩石呈结核状结构，并非平滑均匀的质地。

> The report describes the swelling as nodular.

报告把这处肿起描述为结节状。

**别混淆**

nodal 是与 node“节点、结”有关；nodular 是与 nodule“小团块”有关。网络节点的连接不称 nodular connections。

## 这一组要分清什么

node 不等于 nodule；nodal 不等于 nodular。结节这一形态名称本身不说明良恶性；denouement 说收束，不必是故事最惊险的高潮。

## 串起来练习

用一张网络图解释 node，用小团块解释 nodule，再用侦探小说最后一章解释 denouement。
