# 2824 · streph-, stroph-, strob-, stromb- — 转；翻转；转向

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

希腊 strephein 是转动，strophē 是转。catastrophe 接“向下翻转、倾覆”，早期也用于戏剧结局，后来突出大灾难；apostrophe 接“转开”，分别成为标点名称和修辞名称。

**streph- / stroph-：原本朝一个方向，再转到另一边。**

一个东西被整个翻过来；说话的人也可以从听众转向某个不在场的人。

- **倾覆，带来严重后果**：catastrophe、catastrophic、catastrophically
- **转开与转向另一对象**：apostrophe

## 词形与演化规律

streph-、stroph- 反映希腊相关词形；ph 读 /f/。catastrophe 与 catastrophic 的主重音位置不同，不能只在原词后添一个音节。

## 逐词讲解

<a id="w-2"></a>

### 1. catastrophe — 大灾难；惨败

**音标**：英、美 /kəˈtæstrəfi/

**先抓住这个画面**

局面像被整个掀翻，后果严重到不是补一个小漏洞就能恢复。

**怎么拆**

希腊 kata-“向下” + strephein“转” → katastrophē“倾覆、结局”，经拉丁 catastropha 借入英语。早期也指戏剧的转折、收尾，后来大灾难义突出。

**怎么变成今天的意思**

**希腊 kata-**  
向下；也可表彻底、按次序等关系，具体随词而定

↓

**希腊 katastrephein → katastrophē**  
向下翻转、倾覆 → 结局、突然的终止

↓

**拉丁 catastropha → 英语 catastrophe**  
早期多说戏剧的转折、结局；后来常指大灾难

一场严重洪灾可以是 catastrophe；让整个项目垮掉的错误也可以。它比普通 problem 重得多。日常夸张说晚餐做得像场 catastrophe，是把小事故意说大。

**常见搭配与例句**

a natural catastrophe；an environmental catastrophe；avert a catastrophe。

> The flood was a catastrophe for families living near the river.

这场洪水给河边居民家庭带来了巨大灾难。

> Keeping a second copy of the files prevented a minor error from becoming a catastrophe.

保留文件副本，避免了一个小错误酿成大祸。

**别混淆**

disaster 和 catastrophe 都可指灾难；catastrophe 往往强调极其严重的破坏。不能见到 kata- 就推成“坏”，灾难义来自整个词的历史。

<a id="w-1"></a>

### 2. catastrophic — 灾难性的；造成严重损失的

**音标**：英 /ˌkætəˈstrɒfɪk/；美 /ˌkætəˈstrɑːfɪk/

**先抓住这个画面**

强调后果极其严重，可能让一个系统、计划或生活一下子垮掉。

**怎么拆**

英语 catastrophe 的词干接 -ic；去掉结尾 e，形成 catastrophic，重音也移到后面的 /strɒf/ 或 /strɑːf/。

**怎么变成今天的意思**

**希腊 kata-**  
向下；也可表彻底、按次序等关系，具体随词而定

↓

**希腊 katastrephein → katastrophē**  
向下翻转、倾覆 → 结局、突然的终止

↓

**拉丁 catastropha → 英语 catastrophe**  
早期多说戏剧的转折、结局；后来常指大灾难

↓

**英语 catastrophe + -ic → catastrophic**  
具有灾难性后果的

catastrophic failure 不只是“没成功”，而是故障的影响特别大，例如整个系统突然停摆。这个词也能修饰自然灾害造成的破坏，重点始终是后果的严重程度。

**常见搭配与例句**

catastrophic damage；catastrophic failure；catastrophic consequences。

> The storm caused catastrophic damage to the coastal villages.

风暴给沿海村庄造成了灾难性的破坏。

> A catastrophic server failure brought the entire service offline.

一次灾难性的服务器故障让整个服务离线了。

**别混淆**

catastrophe 是灾难本身，catastrophic 是性质。严重不一定等于彻底：具体毁坏范围仍要看句子里的事实。

<a id="w-4"></a>

### 3. catastrophically — 灾难性地；极其严重地

**音标**：英 /ˌkætəˈstrɒfɪkli/；美 /ˌkætəˈstrɑːfɪkli/

**先抓住这个画面**

说明失败、受损或出错达到了灾难般的程度。

**怎么拆**

英语 catastrophic 对应的副词，常按 catastrophic + -ally 理解；也与较少用的 catastrophical + -ly 对应。拼写长，结尾通常压缩读 /kli/。

**怎么变成今天的意思**

**希腊 kata-**  
向下；也可表彻底、按次序等关系，具体随词而定

↓

**希腊 katastrephein → katastrophē**  
向下翻转、倾覆 → 结局、突然的终止

↓

**拉丁 catastropha → 英语 catastrophe**  
早期多说戏剧的转折、结局；后来常指大灾难

↓

**英语 catastrophe + -ic → catastrophic**  
具有灾难性后果的

↓

**英语 catastrophic / catastrophical → catastrophically**  
以灾难性的方式；严重到灾难般的程度

fail catastrophically 是失败或失效得很严重；catastrophically wrong 是错得后果惊人。它不是时间副词，不表示“终于”或“突然”，虽然灾难可能突然发生。

**常见搭配与例句**

fail catastrophically；go catastrophically wrong；be catastrophically damaged。

> The backup system failed catastrophically during the outage.

停电期间，备用系统发生了灾难性的故障。

> The forecast proved catastrophically wrong, leaving the region unprepared.

预测被证明错得非常严重，导致当地毫无准备。

**别混淆**

catastrophic 修饰名词，catastrophically 修饰动作或形容词。要表达普通程度的 badly，不必总用这个很重的词。

<a id="w-3"></a>

### 4. apostrophe — 撇号；省字号、所有格符号；呼语法

**音标**：英 /əˈpɒstrəfi/；美 /əˈpɑːstrəfi/

**先抓住这个画面**

写字时用一个小撇号标记省略或所属；修辞中则是说着说着，转向另一个对象呼喊。

**怎么拆**

两条历史支线都接希腊 apo-“离开” + strephein“转”：标点义经 apóstrophos、后期拉丁 apostrophus 及法语；修辞义经希腊 apostrophē、拉丁 apostropha。不是修辞手法直接变成了一个标点。

**怎么变成今天的意思**

**希腊 apo- + strephein → apostrephein**  
离开 + 转 → 转开、转向别处

↓

**标点支：apóstrophos → 后期拉丁 apostrophus；修辞支：apostrophē → 拉丁 apostropha**  
前者是省略标记；后者是说话时转向另一对象

↓

**英语 apostrophe；标点支也经法语借入**  
两个相关借词合用同一拼写与读音

don’t 中的撇号标出省去的字母；Maya’s book 中的撇号和 s 标出所属。不要把普通复数也随手加撇号。修辞的 apostrophe 可以是诗人忽然向“大海”发问：对象不必真的能听见，重点是把话转向它。标点名称为何用“转开”，古代解释有分歧，不必硬记成“把字母扭走”。

**常见搭配与例句**

an apostrophe；a possessive apostrophe；use an apostrophe；apostrophe in poetry。

> The apostrophe in “don’t” marks a missing letter.

don’t 里的撇号标记了省去的字母。

> Put the apostrophe before the s in “Maya’s notebook”.

Maya’s notebook 中的撇号要放在 s 前面。

> The poet uses apostrophe to ask the silent moon for an answer.

诗人用呼语法向沉默的月亮索求答案。

**别混淆**

its 表示“它的”，不带撇号；it’s 是 it is 或 it has 的缩写。apostrophe 与 comma“逗号”形状相近，但位置和用途不同；词末 e 也要读出来。

## 这一组要分清什么

转动本身没有好坏，不能把 stroph- 一律记成灾难。apostrophe 的两个义项有相关但不同的借入支线，标点不是从现代修辞手法造出来的。

## 串起来练习

先用灾难本身与灾难性后果区分 catastrophe / catastrophic；再解释 don’t 和 Maya’s 中撇号的不同作用。
