# 0060 · any — 任何；疑问或否定中的不定数量、对象

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

any 的古英语材料与 one 相关，但现代是完整的不定词。它把选择范围打开，和不同的名词、地点词、方式词组合，分别落到人、物、地点、时间等范围。

**ANY：先不指定哪一个，再看句子有没有否定**

Any cup is fine 随便哪只杯子都行；I don’t have any cups 则是杯子一只也没有。否定来自整个结构。

- **基本选择范围**：any
- **人和东西**：anyone · anybody · anything
- **地点**：anywhere · anyplace
- **时间与方式**：anytime · anyway · anyhow
- **any、way → anyways：不管怎样、回到正题**：anyways

## 词形与演化规律

any + one／body → anyone／anybody；any + thing → anything；any + where／place → anywhere／anyplace；any + time／way／how 形成相应扩展。

anyways 有 any way、any ways 的旧副词结构背景，末尾 -s 是历史副词属格材料，不是把现代 anyway 数成好几个的复数。

## 单词速览（按词族由简到繁）

## 逐词讲解

<a id="w-1"></a>

### 1. any — 任何一个；一些〔多见于疑问、否定〕；丝毫〔副词用法〕

**音标**：/ˈeni/

**先抓住这个画面**

一排杯子，你说 Take any cup，意思是随便拿哪一只都行；问 Is there any water? 则把门开着：有一点也算。

**怎么拆**

古英语 ǣniġ 经中古英语 any／eny 等延续，旧材料与 one 有关。可以理解为不特定某一个，但不能把现代拼写硬拆成 an + y 来推所有用法。

**怎么变成今天的意思**

**古英语 ǣniġ → 中古英语 any／eny**  
不特定的一个、任何

↓

**现代 any**  
任意选择；疑问、否定中的不定数量等

Any seat is fine 是任何座位都行；Do you have any questions? 是有没有问题；I don’t have any money 没有钱。Are you any better? 里是有没有好一点。

**常见搭配与例句**

any questions；any time；not any；any better。

> You can choose any colour you like.

你可以选任何自己喜欢的颜色。

> I do not have any spare batteries.

我没有备用电池。

**别混淆**

any 不只用于疑问、否定：Any student can join 是肯定句。some 也能用于期待肯定答复的请求、提供，如 Would you like some tea?，不是死规则。

<a id="w-2"></a>

### 2. anything — 任何东西或事情；什么东西〔疑问、否定语境〕

**音标**：/ˈeniθɪŋ/

**先抓住这个画面**

把选择范围敞开：有任何一个吗，或无论哪一个都可以。

**怎么拆**

古英语 ænig þing、aniþing 一类形式已把任何与东西组合；现代可认 any + thing，不是近代才第一次拼起来。

**怎么变成今天的意思**

**古英语 ænig 任何；þing 东西、事情**  
两个材料共同放开对象范围

↓

**晚期古英语 aniþing 等 → 中古英语 → anything**  
用于询问、否定、条件和任意选择

Do you need anything? 问是否需要什么；You can choose anything 表示任选。not anything 是否定任何一个，通常相当于 nothing。

**常见搭配与例句**

anything else；anything useful；anything can happen；not…anything。

> Did you notice anything unusual in the email?

你有没有注意到邮件里有什么不寻常的地方？

> You may choose anything from this shelf.

这个架子上的东西你可以任选。

**别混淆**

anything 的肯定用法强调不限制，如任选；something 则通常表示有某个未明确对象。不要把 anything 永远翻成任何东西而忽略句子里的否定。

<a id="w-3"></a>

### 3. anyone — 任何人；有人〔疑问等语境〕

**音标**：/ˈeniwʌn/

**先抓住这个画面**

不是指定小王或小李，而是把范围向所有可能的人打开：有没有人，谁都可以。

**怎么拆**

any + one，中古英语已有相应组合，后来常合写成表示不特定人物的代词。one 这里帮助指一个人，不等于句子只许涉及一个人。

**怎么变成今天的意思**

**中古英语 any + one 的组合**  
不特定的一个人

↓

**anyone**  
任何人；有没有人

Anyone can apply 谁都可以申请；Is anyone there? 有人在吗？通常接单数动词，但回指可用单数 they：If anyone calls, tell them I’m out。

**常见搭配与例句**

anyone else；anyone who；Does anyone ...?。

> Does anyone know where the keys are?

有人知道钥匙在哪儿吗？

> Anyone can join the reading group.

任何人都可以加入读书小组。

**别混淆**

anyone 是任何人；any one 可特指若干东西中的任意一个，如 any one of these books。anybody 常与 anyone 接近，不存在严格的“body 只能说身体”规则。

<a id="w-4"></a>

### 4. anyway — 无论如何；反正；话说回来

**音标**：/ˈeniweɪ/

**先抓住这个画面**

走哪条路都不影响这件事：不管前面那些情况怎样，后面这点仍成立。

**怎么拆**

any（任何）+ way（方式、路），由任一种方式的组合发展为转折、让步和转回话题的副词。

**怎么变成今天的意思**

**英语 any；way**  
组合时的两个材料

↓

**any + way → anyway**  
不论哪种情况；回到要说的事

It was raining, but we went anyway 是虽然下雨还是去了。Anyway, where were we? 则把谈话带回来。口语中也能略带不耐烦，语气要看上下文。

**常见搭配与例句**

do it anyway；thanks anyway；anyway, …。

> I was tired, but I went anyway.

我很累，但还是去了。

> Thanks anyway, even though you could not find it.

虽然你没找到，还是谢谢你。

**别混淆**

anyway 连写常是反正、总之；any way 分开是任何方法，如 Is there any way to help?。

<a id="w-10"></a>

### 5. anyways — 不管怎样；反正；话说回来〔随意说法〕

**音标**：英 /ˈeniweɪz/；美 /ˈɛniweɪz/

**先抓住这个画面**

说了一段岔开的话，Anyways... 可以把话题拉回来；讲完困难再说 I went anyways，是“反正我还是去了”。

**怎么拆**

有 any way、any ways 以任何方式的旧结构背景；末尾 -s 接历史副词属格材料，和 anyway 属同组现代用法。不是在数几个 anyway。

**怎么变成今天的意思**

**any + way：任何方式的旧副词表达**  
原是分写的短语，有 any ways 等形式

↓

**历史副词 -s → anyways**  
现代常用于不管怎样、转回话题，语体偏随意

Anyways, what happened next? 是话说回来，后来怎样；do it anyways 是反正还是做。

**常见搭配与例句**

Anyways, back to the plan.；do it anyways；go anyways。

> Anyways, what happened after the meeting?

话说回来，会议之后发生了什么？

> It was raining, but we went for a walk anyways.

当时在下雨，但我们还是去散步了。

**别混淆**

anyways 在一些随意口语、地区用法中自然；正式书写通常选 anyway。末尾 s 不是普通名词复数。

<a id="w-5"></a>

### 6. anywhere — 任何地方；在某个地方〔疑问等语境〕

**音标**：英 /ˈeniweə/；美 /ˈeniwer/

**先抓住这个画面**

地图上不先圈定一个点：能放在哪都行，或者到处找都没找到，都可用 anywhere。

**怎么拆**

any + where，把不特定范围接到地点词上，形成地点副词等用法。

**怎么变成今天的意思**

**any + where**  
不指定是哪一个地点

↓

**anywhere**  
任何地方；疑问、否定中的地点范围

Sit anywhere 随便坐哪；I can’t find it anywhere 哪儿也找不到；Are you going anywhere? 问是否要去某处。anywhere near 还可强调接近程度。

**常见搭配与例句**

go anywhere；not anywhere；anywhere else。

> You can sit anywhere you like.

你想坐哪里都可以。

> I cannot find the receipt anywhere.

我哪儿也找不到那张收据。

**别混淆**

anywhere 通常自己已经表达地点，不需写 go to anywhere；但 from anywhere 来自任何地方、anywhere in the room 房间里任何地方都可以成立。

<a id="w-6"></a>

### 7. anybody — 任何人；有人〔问句等〕

**音标**：英 /ˈenibədi/；美 /ˈenibədi/

**先抓住这个画面**

把范围向所有可能的人打开：有没有人？不管哪一个都可以。

**怎么拆**

any + body，接中古英语相应组合；body 借指人，不是只寻找任何人的身体。

**怎么变成今天的意思**

**古英语 bodiġ → 中古英语 body / bodi**  
身体、躯干

↓

**英语 body**  
身体；主体、实体；群体

↓

**any + body → anybody**  
任一可能的人；问有没有人

Is anybody there? 是有人在吗，Anybody can apply 是任何人都可申请。否定句 not ... anybody 常对应没有任何人，注意否定范围。

**常见搭配与例句**

anybody else；anybody can；not ... anybody；anybody who。

> Can anybody help me move this table?

有人能帮我搬这张桌子吗？

> Anybody with a ticket can enter.

任何持票人都可以进入。

**别混淆**

somebody 常引入有某个人，anybody 常打开选择或询问、否定范围；具体问句也可以 somebody 表示预期有人，不能背成绝对禁令。

<a id="w-7"></a>

### 8. anytime — 随时；在任何时候

**音标**：/ˈenitaɪm/

**先抓住这个画面**

对方问什么时候方便，你说 anytime，就是把可选时间放开：哪个时候都可以，具体范围仍由场景决定。

**怎么拆**

any 与 time 的组合，分写短语很早已有，连写 anytime 后来固定为副词。它不是把所有 any time 都强制合成一个词。

**怎么变成今天的意思**

**英语 any；time**  
任何一个；时间

↓

**较早 any time 短语 → 后来连写 anytime**  
从任意时刻的短语形成常用副词

Call anytime 表示随时打来；anytime soon 常问近期某个时候。回应感谢时 Anytime! 还可表达“随时乐意帮忙”。介词 at 后通常仍写 at any time。

**常见搭配与例句**

come anytime；anytime soon；Anytime!〔回应感谢〕。

> You can call me anytime tomorrow afternoon.

明天下午你随时都可以给我打电话。

> Will the repairs be finished anytime soon?

维修会在近期完成吗？

**别混淆**

anytime 是副词；any time 可以是名词短语，例如 Do you have any time? 是问有没有时间，不是问“随时吗”。

<a id="w-8"></a>

### 9. anyhow — 无论如何；用任何办法；随便、胡乱地

**音标**：英 /ˈenihaʊ/；美 /ˈenihaʊ/

**先抓住这个画面**

只要把事做成，办法先不挑；也可能是不肯好好挑办法，结果做得乱七八糟。看语气和搭配。

**怎么拆**

any + how，十八世纪已有“以任何方式”用法，后来固定扩展出“不管怎样”和“不讲究方式”的意思。

**怎么变成今天的意思**

**any + how**  
任何方式都可以

↓

**anyhow**  
无论如何；胡乱、随意地

I’ll go anyhow 可说不管怎样还是去；The books were stacked anyhow 说书随便乱堆。口语也常用于拉回话题，近于 anyway。

**常见搭配与例句**

do it anyhow；any old how；go anyhow。

> The books had been piled anyhow on the floor.

书被胡乱堆在地板上。

> The forecast looked poor, but we went anyhow.

天气预报看起来不太好，但我们还是去了。

**别混淆**

somehow 留下一个说不清的办法；anyhow 可以是不挑办法，也可以随便乱做。不能把两个词都只背成“不知怎么”。

<a id="w-9"></a>

### 10. anyplace — 任何地方〔主要美式，较口语〕

**音标**：/ˈenipleɪs/

**先抓住这个画面**

在美国口语里，We can meet anyplace 约等于“咱们在哪儿见都行”。它和 anywhere 的常见地点用法很近。

**怎么拆**

any + place，名词地点材料形成合写的地点表达；不是一个特殊地名，也没有独立的冷僻词根。

**怎么变成今天的意思**

**any + place**  
任意一个地方

↓

**anyplace**  
主要美式口语的任何地方

anyplace else 其他任何地方；don’t go anyplace 别到别处去。日常写 anywhere 通常适用范围更广。

**常见搭配与例句**

anyplace else；go anyplace。

> We can meet anyplace near the station.

我们可以在车站附近任何地方见面。

> I do not want to go anyplace else tonight.

今晚我不想再去别的地方了。

**别混淆**

anyplace 与 any place 的区别要看结构：any place with a table 中 place 后面接说明，分写自然；合写形式常作为地点副词使用。

## 这一组要分清什么

anyone 与 any one 分别看人物代词与任意一个；anyplace 偏美式口语；any 可以出现在肯定句，关键看它是在表示任意选择还是不定数量。

## 串起来练习

Anyone can choose any seat, and bags can go anywhere under the table.

任何人都可以随便选座位，包可以放在桌子下面任何地方。
