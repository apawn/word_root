# 0299 · build — 建造、逐步构成

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

build 接古英语造屋相关动词，ui 读 /ɪ/；built 是过去、分词。building 既说过程又说结果，builder 可是人、企业、工具。

**BUILD：把部分一点点搭成整体**

材料搭房，协作建团队，可靠行动积出信任，都是逐步构成的画面。

- **建造与执行者、结果、能力**：build · builder · building · buildable
- **再次建造**：rebuild
- **build 与 built：建成与体格**：build · built
- **build → building → buildings：建成的一座座整体**：building · buildings
- **build → builds：一层层建成、形成**：build · builds
- **booth：临时小屋，到小隔间、摊位**：booth · booths
- **re- 再 + build → rebuilt**：rebuilt

## 词形与演化规律

build → builder、building、buildable；rebuild 已有精讲，放回重建分支。

build → built → built；built 可直接作分词，也可在体格描写中作形容词。

-ing 的名词分支可指建成物，buildings 是建筑物复数。

古英语建造动词传承，三单保留 d，过去式 built 是不规则形式。

与 build 比较搭建空间；booth 经古丹麦等北欧临时住所词，相关居住材料可比较更远同源，不能写成现代 build 直接派生。

rebuild 含重新建造的关系，过去式沿 build → built 换为 rebuilt；没有加 -ed。实体重建与恢复信任等比喻都常见。

## 逐词讲解

<a id="w-2"></a>

### 1. build — 建造；建立；逐步积累；体格〔名词〕

**音标**：/bɪld/

**先抓住这个画面**

把材料、能力或关系一点点搭起来，最后形成一个整体。

**怎么拆**

接古英语 byldan、bytlan 等，经中古英语相关形式延续；更早与房屋、居所词族相关。ui 在这里读 /ɪ/，不读 /uː/。过去、分词 built /bɪlt/。

**怎么变成今天的意思**

**古英语 byldan / bytlan 等 → 中古英语 bilden / bylden**  
建造；与居所的旧词族相关

↓

**英语 build**  
建造、建立；逐步形成

build a house 建房，build trust 建立信任，build up strength 积累力量。名词 a person of slim build 是体格纤细的人。

**常见搭配与例句**

build a house；build trust；build up；a slim build。

> It takes time to build trust.

建立信任需要时间。

> They built a small shelter beside the path.

他们在小径旁搭了一个小遮蔽处。

**别混淆**

build 强调逐步构成，buy 购买不保证自己造；build confidence 培养信心，也不是一幢名叫信心的楼。

<a id="w-1"></a>

### 2. building — 建筑物；建造；建立过程

**音标**：/ˈbɪldɪŋ/

**先抓住这个画面**

动作是不断往上搭，结果是一幢能走进去的建筑；同形词能指过程也能指成品。

**怎么拆**

build + -ing，中古英语 byldynge 等已有相应形式。不是所有 ing 结尾都只表示现在正在做。

**怎么变成今天的意思**

**古英语 byldan / bytlan 等 → 中古英语 bilden / bylden**  
建造；与居所的旧词族相关

↓

**英语 build**  
建造、建立；逐步形成

↓

**build + -ing → building**  
建造过程 → 建成的建筑物

an office building 办公楼，building work 建筑施工，team building 团队建设。建筑物可数，活动过程常不可数。

**常见搭配与例句**

an office building；building work；a historic building；team building。

> The museum occupies a historic building.

博物馆设在一座历史建筑里。

> Building trust is part of the job.

建立信任也是工作的一部分。

**别混淆**

building 泛指建筑，house 常指居住房屋；不是每座 building 都是住宅。

<a id="w-7"></a>

### 3. buildings — 建筑物；楼房〔building 的复数〕

**音标**：/ˈbɪldɪŋz/

**先抓住这个画面**

把材料搭成可以使用的一座整体，是 a building；一座座这样的建筑就是 buildings。

**怎么拆**

build + -ing → building，再加 -s，/ŋ/ 后读 /z/。build 接古英语 byldan、bytlan 等建造词；building 在较早英语已有建造过程、建筑物的名词用法。这里 -ing 名词指建成物。

**怎么变成今天的意思**

**古英语建造词 → build → building**  
建造 → 建造过程、建成的建筑物

↓

**building + -s → buildings**  
多座建筑物

old buildings 老建筑；public buildings 公共建筑；office buildings 办公楼；buildings around the square 广场周围的建筑。

**常见搭配与例句**

a group of buildings；buildings made of stone。

> Several old buildings surround the square.

广场周围有几座老建筑。

> The map marks all the public buildings in the town.

地图标出了镇上的所有公共建筑。

**别混淆**

building 可以是住宅、办公楼、学校等建筑，house 通常更偏住宅。building work 则说建筑施工，buildings 这个复数一般数建成的建筑物。

<a id="w-6"></a>

### 4. built — 建造了、被建造的；体格……的；build 的过去式、过去分词

**音标**：/bɪlt/

**先抓住这个画面**

桥、房子被造起来是 built；a strongly built person 则把人的身体当成构造来描写，意思是体格健壮。

**怎么拆**

build 接古英语 byldan 建屋等，较早带过去词尾的形式后来形成 built；-t 与旧过去尾变化有关，另由分词扩展出体格形容词。

**怎么变成今天的意思**

**较早 build 词族与过去词尾变化**  
建造、构成的过去形式

↓

**现代 build → built → built**  
建成、被建造；体格构造如何

built a house 盖了房子；was built in 1900 建于 1900 年；strongly built 体格健壮的；built on experience 建立在经验之上的。

**常见搭配与例句**

built from stone；built a reputation。

> The bridge was built from local stone.

这座桥用当地石材建成。

> They built a good relationship over the years.

多年来，他们建立了良好的关系。

> He is strongly built.

他体格健壮。

**别混淆**

build 的 d 与 built 的 t 要听清，但不能把所有以 d 结尾的动词都照此变。was built 是被动表达，具体结构由整句判断。

<a id="w-8"></a>

### 5. builds — 建造、建立、逐渐形成〔第三人称单数〕；构建版本等〔复数〕

**音标**：/bɪldz/

**先抓住这个画面**

一部分一部分加上去，最后有了房子、关系、信心，就是 builds 的逐步做成画面。

**怎么拆**

build + -s，/d/ 后读 /z/。build 接古英语 byldan、bytlan 等建造词，较早连居所材料；ui 在这里读 /ɪ/。

**怎么变成今天的意思**

**古英语建造词 → build**  
建住所、造物 → 逐渐形成事物

↓

**build + -s → builds**  
某人建造、建立；也可数构建出的版本

builds houses 建房；builds confidence 建立信心；builds up strength 逐渐增强力量。

**常见搭配与例句**

builds a relationship 建立关系；software builds 软件构建版本。

> The company builds wooden houses.

公司建造木屋。

> Regular practice builds confidence.

经常练习能建立信心。

**别混淆**

builds 是现在三单，built 是过去式、分词，不能把 d 一直保留到过去形式。名词 builds 在软件语境可指构建结果，按句法识别。

<a id="w-5"></a>

### 6. builder — 建筑工、营造商；建造者；构建工具

**音标**：英 /ˈbɪldə/；美 /ˈbɪldər/

**先抓住这个画面**

把零件、材料或想法搭成整体的那一方，可以是人，也可以是软件工具。

**怎么拆**

build + -er，中古英语有 byldere、buyldere；不是 builder 的 ui 读成 buy“买”。

**怎么变成今天的意思**

**古英语 byldan / bytlan 等 → 中古英语 bilden / bylden**  
建造；与居所的旧词族相关

↓

**英语 build**  
建造、建立；逐步形成

↓

**build + -er → builder**  
从事建造者；构建工具

a local builder 当地建筑工、营造商，a website builder 网站构建工具。职业和企业规模按语境，不只某一种单一工种。

**常见搭配与例句**

a local builder；a house builder；a website builder。

> The builder checked the wall before starting work.

建筑工开工前检查了墙。

> The website builder lets users arrange pages visually.

网站构建工具让用户直观地排列页面。

**别混淆**

builder 建造角色，building 可以是建筑物或建造活动；a building builder 不是日常最自然的职业介绍，通常直接 a builder。

<a id="w-4"></a>

### 7. buildable — 可建造的；适合建造的

**音标**：/ˈbɪldəbəl/

**先抓住这个画面**

方案能搭出来，或这块地适合盖房；别把两个对象混成一个意思。

**怎么拆**

build + -able；没有删掉中间的 d，也不按过去式 built 再加 able。

**怎么变成今天的意思**

**古英语 byldan / bytlan 等 → 中古英语 bilden / bylden**  
建造；与居所的旧词族相关

↓

**英语 build**  
建造、建立；逐步形成

↓

**build + -able → buildable**  
可建成；可供建设的

a buildable design 可实施建造的设计，buildable land 可建设用地。后者在实际材料中可能含规划、地形等条件，词义本身不替具体土地作许可结论。

**常见搭配与例句**

a buildable design；buildable land；a buildable site。

> The team turned the sketch into a buildable design.

团队把草图变成了能实际建造的设计。

> The map distinguishes buildable land from protected areas.

地图区分了可建设用地和保护区。

**别混淆**

buildable 能建，built 已建成；a buildable model 是能搭的模型，不表示已经组装好。

<a id="w-3"></a>

### 8. rebuild — 重建；重新建立；重组

**音标**：/ˌriːˈbɪld/

**先抓住这个画面**

房子坏了再建起来，信任受损也得一点点重新搭起来。

**怎么拆**

英语 re- 再次 + build 建造。过去式、分词 rebuilt，读 /ˌriːˈbɪlt/；不是规则加 -ed。

**怎么变成今天的意思**

**re- 再次；英语 build 建造**  
外来前缀与英语本族动词组合

↓

**英语 rebuild**  
重建实体，也比喻恢复组织、生活和信任

rebuild a bridge 是重建桥梁；rebuild trust 是重新建立信任。它常暗示原来的结构已受损、散掉或不足，需要重新组织起来。

**常见搭配与例句**

rebuild a house；rebuild trust；rebuild someone’s life。

> The community helped rebuild the bridge after the flood.

洪水过后，社区帮助重建了桥梁。

> It took months to rebuild trust within the team.

团队内部花了好几个月才重建信任。

**别混淆**

repair 偏修好坏掉的部分；rebuild 往往动得更大，也可能保留部分旧材料，并不一定全部拆光。

<a id="w-11"></a>

### 9. rebuilt — 重建了；重新建立的〔过去形式〕

**音标**：英、美 /ˌriːˈbɪlt/

**先抓住这个画面**

旧的东西损坏了、拆了，或关系受挫了，再把它建起来，就是 rebuilt。可以是桥，也可以是信任、团队。

**怎么拆**

re- 再次 + build 建造 → rebuild，过去式、过去分词沿 build → built 变成 rebuilt。这里直接换用 built，没有加 -ed。

**怎么变成今天的意思**

**英语 re- + build → rebuild**  
把建造动作再做一次、恢复结构

↓

**build 的不规则形式 built → rebuilt**  
现代实体重建与关系恢复均常用

rebuilt a bridge 是重建了桥；a rebuilt engine 是经过重新修整、装配的发动机；rebuilt trust 是重建了信任。

**常见搭配与例句**

rebuilt a bridge；a rebuilt engine；rebuilt trust。

> The village rebuilt the bridge after the storm.

风暴过后，村里重建了那座桥。

> The two friends slowly rebuilt their trust.

两位朋友慢慢重建了彼此的信任。

**别混淆**

repaired 强调修好，rebuilt 强调重新建立、较大程度重做。具体工程中两者可能有交叠，读词时先抓住重新建起的程度与方向。

<a id="w-9"></a>

### 10. booth — 摊位、展位；小隔间、电话亭；餐馆卡座

**音标**：/buːð/ 或 /buːθ/

**先抓住这个画面**

圈出一小块专门办事的空间，就是 booth 的好画面：投票有小隔间，展会有展位，餐馆有两边高靠背围着桌子的卡座。

**怎么拆**

经古丹麦等北欧临时住所、小屋材料借入；接更早居住的词族。临时棚屋、摊位再扩成小型围合空间，不是现代 build 加一个词尾。

**怎么变成今天的意思**

**古丹麦等北欧语言：临时住所、小屋**  
接更早居住、存在的日耳曼材料

↓

**临时棚屋、摊位 → 围出的小工作空间、座席**  
现代有投票间、电话亭、展位、餐馆卡座

a voting booth 是投票间；a phone booth 是电话亭；a restaurant booth 是卡座，未必是能关门的独立房间。

**常见搭配与例句**

an exhibition booth；a phone booth；sit in a booth。

> The company had a booth at the trade fair.

公司在展会上设了一个展位。

> We sat in a booth by the window.

我们坐在窗边的卡座里。

**别混淆**

booth 常是小范围、半封闭或功能单一的空间，room 更一般；餐馆卡座不应一律译成包间。

<a id="w-10"></a>

### 11. booths — 摊位、展位、小隔间、卡座〔复数〕

**音标**：/buːðz/ 或 /buːθs/

**先抓住这个画面**

一排投票间、展厅里的几个摊位，或餐馆一排排卡座，都可以是 booths；共同点是一个个独立出来的小空间。

**怎么拆**

booth + -s；有 /buːðz/ 和 /buːθs/ 等常见读法。词尾 th 与复数后缀需一起考虑，不一律照书面字母读成同一种音。

**怎么变成今天的意思**

**古丹麦等北欧语言：临时住所、小屋**  
接更早居住、存在的日耳曼材料

↓

**临时棚屋、摊位 → 围出的小工作空间、座席**  
现代有投票间、电话亭、展位、餐馆卡座

↓

**booth + -s → booths**  
多个小型功能空间；有清、浊两组常见读法

trade-show booths 数展位；voting booths 数投票小隔间；restaurant booths 数座位区域。

**常见搭配与例句**

exhibition booths；voting booths；window booths。

> Visitors moved between the exhibition booths.

参观者在各个展位之间走动。

> The restaurant has six booths along the wall.

餐馆靠墙设了六个卡座。

**别混淆**

booths 与 tables 在餐馆不必一一对应同种布局；booth 强调围合座席，table 只命名桌子。

## 这一组要分清什么

builder 人或工具，building 活动或物；built 已建，buildable 能建；build trust 是积累信任。

## 串起来练习

The builder checked whether the proposed building was buildable.

营造商检查了拟建建筑能否实际建造。
