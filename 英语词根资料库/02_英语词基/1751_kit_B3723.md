# 1751 · kit — 装在一起的一套，动物幼崽另源

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

kitty 公款的起源未定，不能因为可以放进包就当成确定的 kit + -y 历史。rootkit 则明确取技术权限与套件材料。

**KIT：容器到成套装备；KITTY 不全接这支**

kit → toolkit、rootkit；kit 幼崽接 kitten 等缩短；kitty 猫称呼、钱池分别辨来源。

- **成套装备与同形基础**：kit
- **猫昵称、公共款与软件套件**：kitty · toolkit · rootkit
- **toolkit → toolkits：成套工具、资源**：kit · toolkit · toolkits
- **容器 → 随身物品 → kits**：kits

## 词形与演化规律

kitte 等容器名 → kit 成套用品；tool/root + kit；kitten、kitling → kit 幼崽；kitty 两路另辨。

kit 是成套用品，不仅一只箱子。

kit 较早指木桶等容器，可能借荷兰语相应词，远源未定；后来由容器转称里面的一套用品、工具与装配套件。复数 -s，词尾 /ts/。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. kit — 成套用品、装备；组装套件；幼崽〔另一来源〕

**音标**：/kɪt/

**先抓住这个画面**

一套急救用品、修理用具放在一起，就是 kit；买来零件自己拼的模型也叫 kit。狐狸幼崽 kit 则另有猫幼崽词的缩短背景。

**怎么拆**

装备义从可能接中古荷兰语 kitte 的容器名发展到所装整套用品；幼崽义由 kitten、kitling 缩短等路径而来，另有更冷门同形乐器词。

**怎么变成今天的意思**

**中古荷兰语 kitte 等 → 英语 kit〔容器、装备〕**  
装东西的器具 → 里面成套的用品、装备

↓

**另源动物幼崽 kit**  
由 kitten、kitling 等缩短，不是装备生出小猫

↓

**kitty 的两路**  
猫的昵称接 kitten 等；公共钱池近源未定，可能联系 kit 一套物品

a first aid kit 急救包，a repair kit 维修套件，a model kit 模型套件，a fox kit 狐狸幼崽，kit someone out 配齐装备。

**常见搭配与例句**

a first aid kit；a repair kit；a model kit；kit out。

> Keep a first aid kit in the car.

在车里放一个急救包。

> She built the model from a kit.

她用套件拼出了模型。

**别混淆**

kit 说成套配置，不只外面的包；kit 幼崽与 kit 工具包同音同形却非同一路词义。

<a id="w-2"></a>

### 2. kitty — 小猫、猫咪；公用款、钱池

**音标**：/ˈkɪti/

**先抓住这个画面**

招呼猫咪的 kitty 是亲昵口吻；旅行大家各出一点放进 the kitty，却是在攒公用钱，不是给猫投喂硬币。

**怎么拆**

猫义与 kitten 变体、昵称材料有关，也可能受人名昵称 Kitty 影响；钱池义来源未定，有 kit 成套用品加小后缀的分析，也有其他旧俚语路径。

**怎么变成今天的意思**

**另源动物幼崽 kit**  
由 kitten、kitling 等缩短，不是装备生出小猫

↓

**kitty 的两路**  
猫的昵称接 kitten 等；公共钱池近源未定，可能联系 kit 一套物品

↓

**英语 kitty 的常用同形义**  
猫咪昵称；公共经费池

a little kitty 小猫咪，put money in the kitty 凑钱进公款，the holiday kitty 旅行公用款。

**常见搭配与例句**

a little kitty；put money in the kitty；a holiday kitty。

> The little kitty slept beside the window.

小猫咪睡在窗边。

> We each put ten pounds into the kitty for dinner.

我们各拿出十英镑，凑作晚饭公款。

**别混淆**

kitty 钱池不等于 cat 猫的所有物；kitty 两支不能简单画成工具包里装猫、猫变钱的演化。

<a id="w-7"></a>

### 3. kits — 成套工具、用品；装备；装配套件〔复数〕

**音标**：英、美 /kɪts/

**先抓住这个画面**

修东西需要的零件和工具配成一套，就是一个 kit。重点是“为同一件事准备好的一套东西”，不一定非装在盒子里。

**怎么拆**

kit + -s → kits，/t/ 后读 /s/。kit 较早指木桶一类容器，可能借自中古荷兰语 kitte，更远来源不确定。

**怎么变成今天的意思**

**较早的 kit：木桶、容器**  
名称后来也指容器里携带的东西

↓

**随身物品、成套装备 → kit → kits**  
现代用于工具包、装配套件等

repair kits 是维修工具包；model kits 是需要自己组装的模型套件；drum kits 是一套套架子鼓。

**常见搭配与例句**

repair kits；model kits；camping kits。

> The shop sells repair kits for bicycles.

这家店卖自行车维修工具包。

> They spent the afternoon building model kits.

他们花了一下午组装模型套件。

**别混淆**

kit 强调配成一套的用品；box 强调容器。盒子可能是空的，kit 通常让人想到已经配齐的东西。

<a id="w-3"></a>

### 4. toolkit — 工具包、成套工具；一套方法或软件工具

**音标**：/ˈtuːlkɪt/

**先抓住这个画面**

把做某类事情要用的几样东西配成一套；不只指外面的包，还常指里面整套装备或方法。

**怎么拆**

tool 工具 + kit 成套用品，两个名词并列组合；可以是修车包，也可以是写程序、解决问题的一套资源。

**怎么变成今天的意思**

**古英语 tōl → 中古英语 tool、tol → tool**  
帮人完成事情的器具；与制作、准备词族有关

↓

**tool + kit → toolkit**  
为任务配齐的一套工具、方法

a repair toolkit 维修工具包，a software toolkit 软件工具包，a teaching toolkit 教学资源与方法包。

**常见搭配与例句**

a repair toolkit；a software toolkit；a teaching toolkit。

> She keeps a small toolkit in the car.

她在车里放着一套小工具。

> The workshop gave teachers a practical toolkit for group activities.

工作坊给老师提供了一套组织小组活动的实用方法。

**别混淆**

toolkit 侧重成套、为任务配置，toolbox 字面侧重装工具的箱子，但抽象用法会重叠；不能说所有 toolkit 都必须有实物袋。

<a id="w-6"></a>

### 5. toolkits — 成套工具、工具包、资源套件〔复数〕

**音标**：/ˈtuːlkɪts/

**先抓住这个画面**

为完成一类任务而配在一起的工具，是 toolkits。可以是修理工具，也可以是开发软件、开展活动的一套资源。

**怎么拆**

tool 工具 + kit 成套用品 → toolkit，现代加 -s，/t/ 后读 /s/。比喻扩展保留为某项任务配齐资源的核心。

**怎么变成今天的意思**

**tool + kit → toolkit**  
配成一套的工具、用品

↓

**toolkit + -s → toolkits**  
多套工具包、资源包

repair toolkits 修理工具包；software toolkits 软件工具包。

**常见搭配与例句**

toolkits for beginners 初学者工具包；carry toolkits 带着工具包。

> The workers carried small repair toolkits.

工人们带着小修理工具包。

> The course compares two software toolkits.

课程比较两套软件工具包。

**别混淆**

toolbox 更突出装工具的容器，toolkit 更突出搭配成套的内容。实际产品命名中二者可能重叠。

<a id="w-5"></a>

### 6. rootkit — 隐蔽控制系统的一组恶意软件工具、根套件

**音标**：/ˈruːtkɪt/

**先抓住这个画面**

把控制计算机、隐藏痕迹等工具配成一套；root 在这里接系统高权限那条技术用法，不是植物根部修剪工具包。

**怎么拆**

root 系统特权用户、根权限相关名称 + kit 工具套件，命名一类隐蔽控制系统的软件工具。现代用法不要求每个变种一定只在类 Unix 系统。

**怎么变成今天的意思**

**中古荷兰语 kitte 等 → 英语 kit〔容器、装备〕**  
装东西的器具 → 里面成套的用品、装备

↓

**root〔系统权限名〕+ kit → rootkit**  
用于隐蔽控制系统的软件工具集合

detect a rootkit 检出根套件，a rootkit infection 根套件感染，rootkit detection 根套件检测。

**常见搭配与例句**

detect a rootkit；rootkit detection；a rootkit infection。

> The security scan detected a rootkit.

安全扫描检测到了一组隐蔽控制软件。

> The report explains why rootkit detection can be difficult.

报告解释了为什么根套件可能难以检测。

**别混淆**

rootkit 是安全语境的特定工具类，不是所有需要管理员权限的正常软件；toolkit 则只是广义工具包。

## 这一组要分清什么

kit/toolkit 成套用品与特定工具包；kitty 猫与公款同形；rootkit 不泛指任何管理员软件。

## 串起来练习

We used money from the kitty to buy a repair kit.

我们用公用款买了一套维修工具。
