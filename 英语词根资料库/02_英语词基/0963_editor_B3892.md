# 0963 · editor — 把内容整理发布的人、编务和职务

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

编辑不只改错字，软件 editor 也不是人。editor 的借入先于 edit 的常见英语动词，不按现代可拆形式误画历史。

**EDITOR：让内容能正式给人看；名称比英语 edit 更早进入**

editor → editorial、editorship；一个人物与工具名，再分编务、社论和职位。

- **角色、编务与职位**：editor · editorial · editorship
- **editor → edit；editor → editors：英语长词早于常见短动词**：edit · editor · editors
- **edit → edited：整理、修改到可用**：edit · edited
- **editor → edit → editing：先有人物名词，再逆构动词**：editor · edit · editing
- **edit 的修改动作与未编辑状态**：edit · edits · unedited

## 词形与演化规律

拉丁 ēditor → editor；editor + -ial/-ship；editorial 形容词再发展社论名词。

editor 借拉丁 ēditor 发布者；现代英语 edit 的常见动词用法较晚，不能把全部词史倒置成 edit 先造 editor。

editor 逆构、法语及拉丁词干等来源分析均保留。

英语 edit 从 editor 逆构，也受法语 éditer 与拉丁材料影响；不是只按字数讲历史。

英语 edit 从较早 editor 逆构等历史要保留；现代 edits、unedited 是清楚的变化。

## 逐词讲解

<a id="w-4"></a>

### 1. edit — 编辑、修改；剪辑；编辑改动、剪辑版本

**音标**：/ˈedɪt/

**先抓住这个画面**

原稿或素材放在那里，你修改内容、安排顺序、剪掉不需要的部分，让它适合使用，这个过程是 edit。

**怎么拆**

英语从 editor 逆构出 edit，也受法语 éditer、拉丁 editus 等影响。今天可以按 edit → editor 学构词，但真实出现顺序不能直接倒过来讲。

**怎么变成今天的意思**

**拉丁 ēdere、ēditus 等出版相关形式 → editor**  
把作品刊出、整理出版的人

↓

**editor → edit〔逆构〕**  
英语从较长的人物名称取出动词，也受法语 éditer 影响

edit a document 修改文档，edit a video 剪辑视频，edit a magazine 担任杂志编辑，make an edit 作一次编辑改动。

**常见搭配与例句**

edit a document；edit a video；make an edit。

> Please edit the introduction to make it clearer.

请修改引言，让意思更清楚。

> He edited the footage into a short film.

他把素材剪成一部短片。

**别混淆**

edit 可改内容、结构、语言或素材顺序；proofread 更集中检查文字差错。一次 edit 也可能是一个剪辑版本。

<a id="w-1"></a>

### 2. editor — 编辑、主编；编辑器

**音标**：英 /ˈedɪtə/；美 /ˈedɪtər/

**先抓住这个画面**

把原始稿件、素材整理到能给读者或观众看的状态；具体可审稿、改文字、选内容、统筹，不只是捡错别字。软件帮你编辑内容，也叫 editor。

**怎么拆**

借拉丁 ēditor 发布者，接 ēdere 给出、发布的分词词干。英语 editor 早于现代 edit 的常见动词用法，不能把借入史倒画成先有英语 edit 再添 -or 的唯一路线。

**怎么变成今天的意思**

**拉丁 ēdere〔给出、发布〕→ ēditor → 英语 editor**  
发布、把作品推出去的人

↓

**英语 editor 的工作扩展**  
编辑文本、统筹内容；也可编辑软件

a newspaper editor 报纸编辑，a book editor 图书编辑，a video editor 视频剪辑者或编辑器，a text editor 文本编辑器。

**常见搭配与例句**

a newspaper editor；a book editor；a video editor；a text editor。

> The editor suggested a clearer opening paragraph.

编辑建议把开头一段写得更清楚。

> Open the file in a text editor.

用文本编辑器打开文件。

**别混淆**

editor 编辑，author 作者；一人可兼任但工作角色不同。edition 版本与 editor 同属发布词族，不是编辑人数的复数。

<a id="w-2"></a>

### 3. editorial — 编辑的、编务的；社论

**音标**：英 /ˌedɪˈtɔːriəl/；美 /ˌedɪˈtɔːriəl/

**先抓住这个画面**

editorial team 是做内容编辑的一组人；an editorial 则是表达报刊立场、观点的评论文章。不是所有被编辑过的文章都自动是社论。

**怎么拆**

editor + -ial，先形成与编辑有关的形容词；名词从相关评论文章用法发展。重音移到 -tor- 部分。

**怎么变成今天的意思**

**拉丁 ēdere〔给出、发布〕→ ēditor → 英语 editor**  
发布、把作品推出去的人

↓

**editor + -ial → editorial〔形容词〕→ 社论名词**  
编务相关 → 编辑立场的评论文章

an editorial team 编辑团队，editorial policy 编辑方针，write an editorial 写社论，an editorial on education 关于教育的社论。

**常见搭配与例句**

an editorial team；editorial policy；write an editorial；an editorial on。

> The editorial team meets every Monday.

编辑团队每周一开会。

> The newspaper published an editorial on public transport.

报纸发表了一篇讨论公共交通的社论。

**别混淆**

editorial 社论常表达立场，news report 新闻报道以报道事实为主；editorial work 则是编务，不是每项工作都在写社论。

<a id="w-5"></a>

### 4. editors — 编辑、编者；编辑器；editor 的复数

**音标**：英 /ˈedɪtəz/；美 /ˈedɪtərz/

**先抓住这个画面**

把材料筛选、整理、修改到能发表，是编辑的工作；让你编辑文字、图片的软件工具，也叫 editors。

**怎么拆**

editor + -s，词尾 /z/。editor 借拉丁 ēditor 发布者，接 ēdere 给出、发布；英语这个人物词早于现代 edit 的常见动词用法，edit 后来有逆构历史。

**怎么变成今天的意思**

**拉丁 ēdere → ēditor → 英语 editor**  
发布、给出 → 发布者、编辑

↓

**editor + -s → editors；另看 editor → edit 的逆构关系**  
多位编者；多个编辑工具

newspaper editors 报纸编辑；the editors of a collection 文集编者；text editors 文本编辑器；photo editors 图片编辑人员或图片编辑工具〔看语境〕。

**常见搭配与例句**

editors working on the draft；several different editors。

> The editors checked the names and dates before publication.

出版前，编辑们核对了人名和日期。

> These two text editors save files in the same format.

这两个文本编辑器以同一种格式保存文件。

**别混淆**

editors 可以是人，也可以是工具。现代 edit + -or 容易认，但真正英语词史里 editor 更早，不能只按今天短词、长词的外形排序判断先后。

<a id="w-3"></a>

### 5. editorship — 编辑职务、主编任期

**音标**：英 /ˈedɪtəʃɪp/；美 /ˈedɪtərʃɪp/

**先抓住这个画面**

不说是哪位编辑，而说担任这个职位的身份、任期；under her editorship 就是在她主编期间。

**怎么拆**

editor + -ship，后缀命名职位、身份、期间等抽象概念，不是运稿件的船。

**怎么变成今天的意思**

**拉丁 ēdere〔给出、发布〕→ ēditor → 英语 editor**  
发布、把作品推出去的人

↓

**editor + -ship → editorship**  
编辑职务；任职时期

the editorship of a journal 期刊主编职务，under her editorship 在她主编期间，take over the editorship 接任主编。

**常见搭配与例句**

the editorship of；under her editorship；take over the editorship。

> She took over the editorship of the journal last year.

她去年接任该期刊主编。

> The magazine gained readers under his editorship.

他主编期间，杂志读者增加了。

**别混淆**

editor 人或工具，editorship 职务、任期；editing 编辑过程，不能把 under her editorship 一律译成在她每次修改文字下面。

<a id="w-6"></a>

### 6. edited — 编辑了、修改了；剪辑过的〔过去式、过去分词〕

**音标**：/ˈedɪtɪd/

**先抓住这个画面**

把已有内容删、改、调整，让它更适合阅读、播放或使用，是 edited。可以编辑文章，也可以剪辑影像、修改文件。

**怎么拆**

edit + -ed，/t/ 后读 /ɪd/，不双写 t，重音不在末音节。edit 有从 editor 逆构、接法语 éditer 或拉丁 editus 的分析；英语较早出版义后扩到修订内容。

**怎么变成今天的意思**

**editor 逆构／法语、拉丁相关形式 → edit**  
出版、整理以便出版 → 修改、剪辑

↓

**edit + -ed → edited**  
已经编辑、修订过的

edited the article 编辑了文章；an edited version 修改版；edited the video 剪辑了视频。

**常见搭配与例句**

carefully edited 仔细编辑过的；edited for clarity 为更清楚而修改。

> She edited the article to make the argument clearer.

她修改了文章，让论证更清楚。

> We watched an edited version of the interview.

我们看了经过剪辑的访谈版本。

**别混淆**

edited 是内容做过处理，不能只凭这个词知道删改了多少。editor、edition 较早已有记录，词史不只按现代 edit 加后缀的方向理解。

<a id="w-7"></a>

### 7. editing — 编辑、修改、剪辑〔现在分词、动名词及相关名词〕

**音标**：/ˈedɪtɪŋ/

**先抓住这个画面**

作品已经有了，再删去多余的、调整顺序、修正细节，使它更适合发表或呈现。这一轮整理就是 editing。

**怎么拆**

edit + -ing，直接加 ing。英语 edit 从 editor 逆构，也受法语 éditer、拉丁 editus 等影响；现在可以从 edit 学 editor，真实历史顺序却不能倒讲。

**怎么变成今天的意思**

**拉丁出版相关材料 → editor；英语逆构并受法语影响 → edit**  
编辑、出版者名称 → 编辑动作

↓

**edit + -ing → editing**  
正在整理作品；编辑、剪辑这一过程

editing a report 编辑报告；video editing 视频剪辑；an editing tool 编辑工具。

**常见搭配与例句**

careful editing 仔细编辑；finish editing the chapter 完成本章的编辑。

> I spent the afternoon editing the report.

我花了一下午编辑报告。

> The film’s editing gives the final scene a faster pace.

这部电影的剪辑让最后一场戏节奏更快。

**别混淆**

editing 可改结构、措辞或剪辑顺序；proofreading 更集中在校对拼写、标点等表面错误。具体工作范围还要看上下文。

<a id="w-8"></a>

### 8. edits — 修改、编辑〔第三人称单数〕；改动、编辑版本〔复数〕

**音标**：/ˈedɪts/

**先抓住这个画面**

把现成内容改得更清楚、合适，是 edits；一处处改动也可数成 edits。

**怎么拆**

edit + -s，/t/ 后读 /s/。英语 edit 由较早 editor 逆构，并受相关法语、拉丁材料影响，不能把出现顺序简单倒过来。

**怎么变成今天的意思**

**editor → edit〔逆构等历史〕**  
编辑者名词先，英语编辑动词后

↓

**edit + -s → edits**  
它编辑；多处改动、多个剪辑版本

minor edits 小改动；edits the report 编辑报告。

**常见搭配与例句**

make edits 作修改；review the edits 查看改动。

> She edits the newsletter every week.

她每周编辑通讯。

> The final draft needed only a few small edits.

最后一稿只需几处小改动。

**别混淆**

edit 的范围可大可小，proofread 主要检查文字、呈现的小错。

<a id="w-9"></a>

### 9. unedited — 未经编辑、尚未修改的

**音标**：/ʌnˈedɪtɪd/

**先抓住这个画面**

录下来、写下来以后还没经过挑选、修改、整理，就是 unedited。保留着编辑前的样子。

**怎么拆**

un- 不 + edited 已编辑的；edited 为 edit + -ed，/t/ 后读 /ɪd/。这里否定状态，不表示把修改过程反向操作一遍。

**怎么变成今天的意思**

**edit → edited**  
编辑；经过编辑的

↓

**un- + edited → unedited**  
未经过编辑的状态

unedited footage 未剪辑素材；an unedited draft 未编辑草稿。

**常见搭配与例句**

unedited notes 未整理笔记；the unedited recording 未剪辑录音。

> She sent me the unedited draft.

她发给我尚未编辑的草稿。

> The archive kept the unedited recording.

档案库保存了未剪辑录音。

**别混淆**

unedited 只说明没编辑，不自动表示内容更真实、更完整或完全无误。

## 这一组要分清什么

editor/author 编辑与作者；editorial team 非一群社论；editorship 职位与任期、editing 过程不同。

## 串起来练习

The editor explained the editorial policy when she took over the editorship.

接任主编时，她解释了编辑方针。
