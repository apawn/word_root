# 0523 · allow — 允许、分配、留出与可接受限度

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

法语相近形式合并了分配和赞同两支历史，今天的多义因此不能只硬译成允许。

**ALLOW：批准可以做，也能给事情留一份**

allow 基本动作，allowance 分配的钱、额度，allowable 规则允许的性质。

- **动作、份额与限度**：allow · allowance · allowable
- **allowed：获准与被留出的限度**：allow · allowed
- **allow → allowing：许可与留出条件**：allow · allowing
- **allow → allows：给许可、留余地**：allow · allows
- **allow 分配、准许词族 → allowances**：allowances

## 词形与演化规律

allow → 相关名词 allowance、形容词 allowable；后二者各保留法语借入历史。

allow 历史合流了法语认可、赞许及分配相关词；allowed 可说获准做某事，或安排中留出的量。

分配、安排与赞同、认可两条较早来源在法语相近形式中汇合。

允许与分配、安排的较早来源汇合，小词决定现代结构。

allowance 经法语 aloance 等材料，承接分配、准许及赞许词线的汇合；现代 -s 常数津贴、零用钱安排，make allowances for 是体谅、考虑特殊情况。

## 逐词讲解

<a id="w-1"></a>

### 1. allow — 允许；给予；留出；考虑到

**音标**：/əˈlaʊ/

**先抓住这个画面**

你可以这样做，是允许；给预算留一笔、给路上留半小时，也是给这件事留出位置。

**怎么拆**

经法语相近词汇合：一支接 allocāre 分配，一支接 allaudāre 赞同、认可。现代允许与留出等义共同留下这两支影响，不拆成 all + low。

**怎么变成今天的意思**

**拉丁 allocāre〔安排、分配〕；allaudāre〔赞同、称赞〕**  
两条来源在法语相近形式中汇合

↓

**法语 alouer 等 → 英语 allow**  
分配、承认、认可 → 允许；为某事留出条件

allow someone to do 允许某人做，allow time for 留出时间，allow for delays 考虑可能延误；Smoking is not allowed 禁止吸烟。

**常见搭配与例句**

allow someone to do；allow time for；allow for；be allowed to。

> The ticket allows visitors to enter the garden twice.

这张票允许游客进入花园两次。

> Allow extra time for the journey during rush hour.

高峰时段出行要多留些时间。

**别混淆**

allow someone to do，let someone do；两者接动词方式不同。allow for 不是允许延误发生，而是把它计入安排。

<a id="w-4"></a>

### 2. allowed — 被允许的、获准的；留出的；allow 的过去式、过去分词

**音标**：/əˈlaʊd/

**先抓住这个画面**

本来有一道规则的门，现在规则说你可以过去：be allowed to do，就是获准做。

**怎么拆**

allow + -ed，结尾读 /d/。allow 经中古英语、法语，历史合流认可、赞许及分配的不同来源；现代常见许可与留出资源两条用法。

**怎么变成今天的意思**

**法语认可与分配相关动词 → allow**  
认可、允许；分配、留出

↓

**allow + -ed → allowed**  
曾允许；获准；被留出的

be allowed to enter 获准进入；Pets are not allowed 不许带宠物；the time allowed 留出的时间；allowed expenses 认可的费用，具体看制度语境。

**常见搭配与例句**

allowed to leave；within the time allowed。

> Visitors are allowed to take photographs here.

参观者可以在这里拍照。

> We completed the task within the time allowed.

我们在规定时间内完成了任务。

**别混淆**

allowed 与 aloud 读音相同。allowed 说许可，aloud 说出声：read aloud 大声读。许可结构用 be allowed to do，不用 be allowed doing 表同一关系。

<a id="w-6"></a>

### 3. allows — 允许；使能够；留出、考虑到；allow 的第三人称单数

**音标**：/əˈlaʊz/

**先抓住这个画面**

给一个动作放行，或为它留下可行的条件，就是 allows：规则允许、设计让人更方便、计划留出余地都可以用。

**怎么拆**

allow + -s，元音后读 /z/。allow 的法语来源汇合拉丁 allocāre 分配、安排与 allaudāre 赞同、认可的词族，形成现代许可、留出等用法。

**怎么变成今天的意思**

**较早分配、认可词族 → 法语 → allow**  
安排、同意 → 许可、留出条件

↓

**allow + -s → allows**  
单数主语允许、使能够；考虑余量

allows visitors to enter 允许访客进入；allows time for questions 留出提问时间；allows for changes 考虑到变化。

**常见搭配与例句**

allows easy access；allows someone to work from home。

> The wide entrance allows people to move through easily.

宽阔的入口让人们容易通行。

> The schedule allows time for questions after each talk.

日程在每场讲座后都留出了提问时间。

**别混淆**

allows someone to do 的 to 后接动词原形；allows for 看把什么条件算进去。This design allows easy access 说设计让进入更容易，不必一定存在发许可的人。

<a id="w-5"></a>

### 4. allowing — 正在允许、让……能够；考虑、留出余地〔allowing for〕

**音标**：/əˈlaʊɪŋ/

**先抓住这个画面**

给别人做一件事的许可，或为事情留出足够空间、时间，是 allowing 的两组常见感觉。

**怎么拆**

allow + -ing，直接加。allow 的法语来源汇合较早拉丁 allocāre 分配、安排与 allaudāre 赞同、认可两条词族，现代许可与留出等义保留了这些影响。

**怎么变成今天的意思**

**拉丁分配、赞同两条词族 → 法语相近形式 → allow**  
安排、认可 → 允许；留出条件

↓

**allow + -ing → allowing**  
正在许可；把某条件考虑进去

allowing visitors to enter 允许访客进入；allowing more time 留出更多时间；allowing for traffic 把交通状况考虑在内。

**常见搭配与例句**

a design allowing easy access；allowing for mistakes。

> The new door is wider, allowing people to enter more easily.

新门更宽，让人们更容易进入。

> We left early, allowing for traffic on the way.

我们考虑到路上的交通状况，提前出发了。

**别混淆**

allow someone to do 是允许某人做；allow doing 说允许某种活动；allow for something 是把可能的影响、需要预先考虑进去。

<a id="w-2"></a>

### 5. allowance — 零用钱；津贴；配额、限额；考虑余地

**音标**：/əˈlaʊəns/

**先抓住这个画面**

给某人预留的一份钱或额度：孩子每周零用钱、员工出差津贴、行李可带多少。

**怎么拆**

借古法语 alouance，经中古英语进入；现代可对应 allow + -ance。与 allow 一样涉及分配、批准，不是只讲允许的抽象名词。

**怎么变成今天的意思**

**拉丁 allocāre〔安排、分配〕；allaudāre〔赞同、称赞〕**  
两条来源在法语相近形式中汇合

↓

**法语 alouer 等 → 英语 allow**  
分配、承认、认可 → 允许；为某事留出条件

↓

**法语 alouance → 英语 allowance**  
获分配的钱、额度；考虑调整余地

a weekly allowance 每周零用钱，a travel allowance 出差津贴，baggage allowance 行李限额；make allowances for 考虑到、体谅某种情况。

**常见搭配与例句**

a weekly allowance；a travel allowance；baggage allowance；make allowances for。

> She saves part of her weekly allowance.

她把每周零用钱的一部分存起来。

> We should make allowances for his lack of experience.

我们应考虑到他经验不足。

**别混淆**

allowance 不全是 salary 工资；额度可按重量、金额等衡量。make allowances for inexperience 是体谅经验不足，不是给经验发津贴。

<a id="w-7"></a>

### 6. allowances — 津贴、定额钱款〔复数〕；体谅、酌情考虑〔固定搭配〕

**音标**：英 /əˈlaʊənsɪz/；美 /əˈlaʊənsɪz/

**先抓住这个画面**

每个月拨给你用于某项开支的钱，是 allowance；不同款项就是 allowances。make allowances for 则是把某种特殊情况留出余地考虑进去。

**怎么拆**

allowance 保留末尾 e，加 -s → allowances，/s/ 后读 /ɪz/。经法语 aloance 等，承接 allow 词族中分配、准许及赞许两条历史词线的汇合。

**怎么变成今天的意思**

**法语分配、准许与赞许材料 → allow、allowance**  
一条远接 allocare 分配，另一条接 allaudare 赞许

↓

**定额拨款、酌情体谅等义 → allowances**  
现代要分具体津贴和 make allowances for 的固定表达

travel allowances 是差旅津贴；monthly allowances 是每月津贴；make allowances for inexperience 是体谅缺乏经验。

**常见搭配与例句**

travel allowances；monthly allowances；make allowances for。

> The form lists travel and meal allowances.

表格列出了差旅和餐食津贴。

> We should make allowances for her lack of experience.

我们应该体谅她缺乏经验。

**别混淆**

allowances 说钱时在数拨给的款项；make allowances for someone 则常是评价时把对方处境算进去，不一定真的发钱。

<a id="w-3"></a>

### 7. allowable — 允许的；可接受的；在限度内的

**音标**：/əˈlaʊəbl/

**先抓住这个画面**

规则画出一条界线，界线以内可以接受、可以计入的，就是 allowable。

**怎么拆**

经中古英语接古法语 alouable，与 allouer 同族；现代可分析 allow + -able。不是每个 -able 都只说物理上做得到。

**怎么变成今天的意思**

**拉丁 allocāre〔安排、分配〕；allaudāre〔赞同、称赞〕**  
两条来源在法语相近形式中汇合

↓

**法语 alouer 等 → 英语 allow**  
分配、承认、认可 → 允许；为某事留出条件

↓

**法语 alouable → 英语 allowable**  
可认可、可允许；符合限度

the maximum allowable weight 最大允许重量，an allowable error 允许误差，allowable expenses 可计入的费用。具体界线依规则而定。

**常见搭配与例句**

maximum allowable weight；allowable limits；allowable error。

> The bag exceeds the maximum allowable weight.

包的重量超过允许上限。

> The difference falls within the allowable margin of error.

差异在允许误差范围内。

**别混淆**

possible 可能做到，allowable 规则上允许；possible but not allowable 可以发生，却不合规定。

## 这一组要分清什么

allow someone to do 对照 let someone do；allow for 计入；allowance 不全是工资；allowable 不只是可能。

## 串起来练习

The allowance must stay within the allowable budget.

津贴必须在允许预算内。
