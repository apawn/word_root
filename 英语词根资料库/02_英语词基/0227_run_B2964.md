# 0227 · run — 跑、流动、持续运行

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

run 接古英语与古诺尔斯语的相关形式，现代过去式 ran、过去分词 run；复合词常沿用变化。原目录的 ember“余烬”另接古英语 ǣmyrġe，不归 run，本页排除。

**RUN：向前流动、让过程持续进行**

腿在跑、水在流、机器在运转，都是不同对象上的连续推进。

- **基本运行、人物与流动性质**：run · runner · runny
- **比较超越、越界和重复**：outrun · overrun · rerun
- **场地和游戏流程**：runway · speedrun
- **run 的过去形式 ran**：run · ran
- **running：跑动、流动与持续运转**：run · running
- **run → runs：跑、运行与一段行程**：run · runs
- **zoom：嗡地冲过去，到镜头拉近**：zoom · zooms · zoomed · zooming

## 词形与演化规律

run → runner、runny；out- + run → outrun；over- + run → overrun；re- + run → rerun；runway、speedrun 分别看场地与流程。

run → ran → run；现代 run 汇合了较早相关动词的材料，ran 保留旧过去式的元音。

run 双写 n 加 -ing；运行、经营、连续等义承接 run 的不同支线，不都翻译成跑步。

跑动延伸到机器运转、事务经营，也能将一段连续活动作为可数名词。

本组与 run 比较速度、画面，不是现代 run 的后代。zoom 起于低沉嗡声的拟声材料，航空用法带来快速冲向、掠过，再有镜头变焦。

## 逐词讲解

<a id="w-1"></a>

### 1. run — 跑；流；运转；经营；一段连续过程

**音标**：/rʌn/

**先抓住这个画面**

脚步连续向前，水持续流过，机器一直运转；抓住“动起来并持续进行”。

**怎么拆**

接古英语 rinnan、iernan 及相关古诺尔斯语形式，中古英语旧词形受分词等影响逐渐形成 run。过去式 ran /ræn/，过去分词 run，不是 runned。

**怎么变成今天的意思**

**古英语 rinnan / iernan、古诺尔斯语 rinna → 中古英语 rinnen / runnen**  
奔跑；流动

↓

**英语 run**  
跑；流动；运行、经营；连续进行

run a race 跑比赛，water runs 水流，run a business 经营生意，run a program 运行程序。a run of good luck 是一连串好运，go for a run 是去跑步。

**常见搭配与例句**

run a business；run a program；run out of；go for a run；in the long run。

> She runs a small bookshop.

她经营一家小书店。

> Leave the program running while you check the results.

检查结果时，让程序继续运行。

**别混淆**

run 运行并不总是人腿在跑；running water 是流动水，running a shop 是经营商店。先看主语宾语是什么。

<a id="w-11"></a>

### 2. running — 跑步；运行、经营；流动的；连续的

**音标**：/ˈrʌnɪŋ/

**先抓住这个画面**

腿不停向前，是 running；水一直流、机器持续转、公司每天运作，也都抓住持续动起来这个画面。

**怎么拆**

run 双写 n 加 -ing。run 继承古英语 rinnan、irnan 等跑、流材料，现代分词又常用作名词、形容词；名词 running 可直接说跑步或管理运作。

**怎么变成今天的意思**

**古英语跑、流词族 → run**  
移动；流动；后来也说设备运转、经营

↓

**run + -ing → running**  
跑步、运转；流动或连续的

go running 去跑步；running water 流水、自来水；running costs 维持运作的费用；three days running 连续三天；in the running 仍有胜算。

**常见搭配与例句**

keep the business running；the day-to-day running of a school。

> Running helps me clear my head after work.

下班后跑步能让我头脑清醒。

> The village now has electricity and running water.

村里如今通了电和自来水。

> It rained for three days running.

雨连续下了三天。

**别混淆**

running water 在住宿介绍中常说有管道供水，不能只想成河水。three days running 表连续发生，不是跑了三天步。

<a id="w-10"></a>

### 3. ran — 跑了、运行了、经营过；run 的过去式

**音标**：/ræn/

**先抓住这个画面**

run 的跑、流动、运转、经营放进过去，形式变成 ran。看主语是人、机器、水，还是经营者，就能找到具体分支。

**怎么拆**

现代 run 汇合了较早英语中相关的跑、流动与使跑动词材料；古英语 rinnan、irnan 等有 ran 一类过去形式，后延续为现代 ran。

**怎么变成今天的意思**

**较早相关跑动词及 ran 等过去形式**  
跑、流动及对应过去

↓

**现代 run → ran → run**  
一般过去 ran；过去分词 run

ran home 跑回家；ran the shop 经营过商店；ran out of time 时间用完了；ran smoothly 运行顺利。

**常见搭配与例句**

ran a business；ran across the field。

> He ran across the field to catch the dog.

他跑过田野去追那只狗。

> She ran a small bookshop for ten years.

她经营过一家小书店，做了十年。

**别混淆**

ran 是一般过去，run 也承担过去分词：She ran the shop；She has run it for years。词形相同的 run 不一定都是现在时。

<a id="w-12"></a>

### 4. runs — 跑；流动；运行、经营；一段行程、连续活动〔名词复数〕

**音标**：/rʌnz/

**先抓住这个画面**

脚步向前跑，水向前流，机器、业务持续运转，都能抓住“持续进行”的画面；一次跑动或一段连续活动也可以数成 runs。

**怎么拆**

run + -s，/n/ 后读 /z/。run 继承古英语 rinnan、iernan 等并受相关词形影响；过去式 ran、过去分词 run 要单独记。

**怎么变成今天的意思**

**古英语及相关日耳曼语奔跑、流动词形 → run**  
跑；流动 → 运行、经营等

↓

**run + -s → runs**  
单数主语跑、运行；多次跑动或行程

runs a shop 经营商店；runs smoothly 运转顺畅；runs out of time 时间用尽；daily bus runs 每天的巴士班次。

**常见搭配与例句**

runs along the river；go for short runs。

> She runs a small bookshop near the station.

她在车站附近经营一家小书店。

> The bus makes four runs between the village and the town each day.

这辆巴士每天在村子和镇上之间开四个班次。

**别混淆**

runs a company 是经营公司；runs for office 是竞选公职。名词 runs 在板球、棒球中还可以说得分，需按运动背景理解。

<a id="w-2"></a>

### 5. runner — 跑步者；参赛者；蔓生枝；长条毯等

**音标**：英 /ˈrʌnə/；美 /ˈrʌnər/

**先抓住这个画面**

人向前跑，植物长枝向外延伸，长条毯沿地面铺开；都借持续延伸、活动的画面。

**怎么拆**

run + -er，双写 n；中古英语已有 rennere、rynner 等跑者形式。不同专业引申义不靠一个跑步的人硬译。

**怎么变成今天的意思**

**古英语 rinnan / iernan、古诺尔斯语 rinna → 中古英语 rinnen / runnen**  
奔跑；流动

↓

**英语 run**  
跑；流动；运行、经营；连续进行

↓

**run + -er → runner**  
跑者、参赛者；延伸、运行相关事物

a marathon runner 马拉松跑者，a front runner 领先竞争者，a table runner 桌旗，strawberry runners 草莓匍匐茎。先学常见语境，不堆所有技术同形义。

**常见搭配与例句**

a marathon runner；a fast runner；a table runner；strawberry runners。

> The runners gathered at the starting line.

跑者们聚集在起跑线。

> A narrow runner covered the middle of the table.

一条窄桌旗铺在桌子中央。

**别混淆**

runner 跑者，runny 流得出、稀的；a runny egg 不是会跑步的鸡蛋。

<a id="w-3"></a>

### 6. runway — 飞机跑道；时装走秀台

**音标**：/ˈrʌnweɪ/

**先抓住这个画面**

留出一条长通道，让飞机加速起飞，也让模特沿着展示服装。

**怎么拆**

run（跑、行进）+ way（通道）；较早有动物行经的路等用法，后来用于人工跑道、航空和时装展示。

**怎么变成今天的意思**

**英语 run；way**  
组合时的两个材料

↓

**run + way → runway**  
供行进、起降或展示的长条通道

航空 runway 是飞机起飞、降落的跑道；时装 show 的 runway 是伸展台。商业语境 cash runway 还比喻现有现金能撑多久。

**常见搭配与例句**

on the runway；a runway show；cash runway。

> The aircraft waited at the end of the runway.

飞机在跑道尽头等待。

> The model stepped onto the runway in a silver coat.

模特穿着银色外套走上伸展台。

**别混淆**

taxiway 是飞机在地面滑行时使用的连接通道，runway 负责起降，功能不同。

<a id="w-7"></a>

### 7. runny — 稀的；易流动的；流鼻涕的

**音标**：/ˈrʌni/

**先抓住这个画面**

本来应稠一点、稳一点的东西，现在稀得会往下流。

**怎么拆**

run（流动）+ -y，双写 n；不是 runner“跑步者”删尾巴。

**怎么变成今天的意思**

**古英语 rinnan / iernan、古诺尔斯语 rinna → 中古英语 rinnen / runnen**  
奔跑；流动

↓

**英语 run**  
跑；流动；运行、经营；连续进行

↓

**run + -y → runny**  
会流、易滴落、偏稀的

a runny nose 流鼻涕，a runny yolk 流心蛋黄，runny sauce 稀酱汁；有时是想要的口感，有时嫌太稀。

**常见搭配与例句**

a runny nose；a runny yolk；runny sauce。

> The sauce is too runny to stay on the spoon.

酱太稀，挂不住勺子。

> He likes his eggs with runny yolks.

他喜欢吃流心蛋。

**别混淆**

runny 形容流动、浓稠度，running 是 run 的分词。running water 是流动的水，不通常说 runny water。

<a id="w-4"></a>

### 8. overrun — 泛滥、侵占；超时、超支；超出量

**音标**：动词英 /ˌəʊvəˈrʌn/、美 /ˌoʊvərˈrʌn/；名词英 /ˈəʊvərʌn/、美 /ˈoʊvərʌn/

**先抓住这个画面**

数量冲进来占满地方，或进度一路跑过原定边界。

**怎么拆**

over-（越过、覆盖）+ run；过去式 overran，分词 overrun；名词常与动词重音不同。

**怎么变成今天的意思**

**古英语 rinnan / iernan、古诺尔斯语 rinna → 中古英语 rinnen / runnen**  
奔跑；流动

↓

**英语 run**  
跑；流动；运行、经营；连续进行

↓

**over- + run → overrun**  
大量侵入覆盖；超过计划边界

be overrun with weeds 杂草丛生，a meeting overruns 会议超时，a cost overrun 费用超支。共同点是越过原有容量、边界。

**常见搭配与例句**

overrun with；overrun by；a cost overrun；a project overrun。

> The garden was overrun with weeds.

花园里杂草丛生。

> The meeting overran by twenty minutes.

会议超时二十分钟。

**别混淆**

outrun 比另一方快、超过，overrun 常说超出范围或大量占据；一场 overrun 的会议是超时，不是跑步冠军。

<a id="w-6"></a>

### 9. outrun — 跑得比……快；超出、超过

**音标**：英 /ˌaʊtˈrʌn/；美 /ˌaʊtˈrʌn/

**先抓住这个画面**

同一方向前进，你跑到对方前面；引申为增长比资源、预期更快。

**怎么拆**

out-（胜过、超出）+ run；过去式 outran，过去分词 outrun，沿用 run 的不规则变化。

**怎么变成今天的意思**

**古英语 rinnan / iernan、古诺尔斯语 rinna → 中古英语 rinnen / runnen**  
奔跑；流动

↓

**英语 run**  
跑；流动；运行、经营；连续进行

↓

**out- + run → outrun**  
跑过、超过某人或某种限度

outrun a pursuer 跑过追赶者，demand outruns supply 需求增长超出供给。out- 这里是比较胜过，不只空间向外。

**常见搭配与例句**

outrun a pursuer；outrun expectations；outrun demand。

> The dog easily outran me.

狗轻轻松松就跑过了我。

> Demand has outrun our production capacity.

需求已经超过了我们的生产能力。

**别混淆**

outrun 强调比对方快、超出，run out 则是耗尽、用完；前后位置不同，不能混成同一短语。

<a id="w-8"></a>

### 10. rerun — 重播；重新运行；重做

**音标**：名词英 /ˈriːrʌn/、美 /ˈriːrʌn/；动词英 /ˌriːˈrʌn/、美 /ˌriːˈrʌn/

**先抓住这个画面**

同一段节目、测试或过程，再跑一遍。

**怎么拆**

re-（再次）+ run；名词常词首重音，动词常重读 run。动词过去式 reran，分词 rerun。

**怎么变成今天的意思**

**古英语 rinnan / iernan、古诺尔斯语 rinna → 中古英语 rinnen / runnen**  
奔跑；流动

↓

**英语 run**  
跑；流动；运行、经营；连续进行

↓

**re- + run → rerun**  
重新运行；再播、再做

rerun a test 重新跑测试，a rerun of a sitcom 情景喜剧重播。可重新执行过程，也可重放已有记录，按对象看。

**常见搭配与例句**

rerun a test；rerun the analysis；a rerun of；watch reruns。

> We reran the test with a larger sample.

我们换用更大样本重新跑了测试。

> They watched a rerun of an old comedy.

他们看了一部老喜剧的重播。

**别混淆**

rerun 重做、重放，remake 重拍、重新制作；电视剧重播不是重新请演员拍一次。

<a id="w-9"></a>

### 11. speedrun — 游戏速通；尽快完成一次流程〔引申〕

**音标**：/ˈspiːdrʌn/

**先抓住这个画面**

熟悉路线、尽量压缩耗时，把一轮游戏流程跑到尽可能快。

**怎么拆**

speed + run，现代游戏义由这两个词组合；较早工程语境有同形组合，不据此断言现代游戏义直接继承它。

**怎么变成今天的意思**

**speed；run〔一轮流程〕**  
并列构词成分

↓

**speedrun**  
以尽快通关为目标的一轮游戏过程

a speedrun of a game 某游戏的一次速通，a speedrun record 速通纪录。类别可对完成目标、允许技巧作不同规定，不是每类都必须清完全部内容。

**常见搭配与例句**

a speedrun record；attempt a speedrun；a speedrun of。

> She watched a speedrun of her favorite game.

她看了一次最喜欢的游戏的速通。

> His latest speedrun was two minutes faster than the previous one.

他最新一次速通比上一次快了两分钟。

**别混淆**

speedrun 强调完成时间，walkthrough 攻略、流程演示主要说明怎么过；两者可重叠但目标不同。

<a id="w-13"></a>

### 12. zoom — 飞快掠过、猛冲；迅速上升；变焦、缩放

**音标**：/zuːm/

**先抓住这个画面**

车嗖地开过，数字一下冲高，都能 zoom。相机 zoom in 像快速靠近对象，但画面变大不表示相机一定真的移了位置。

**怎么拆**

起于低沉嗡声的拟声材料；航空用法发展为快速冲向、掠过，后来摄影镜头借来表示变焦。现代界面也沿用放大、缩小。

**怎么变成今天的意思**

**zoom 起于低沉嗡声的拟声材料**  
航空中发展为快速冲向、飞掠

↓

**快速接近 → 摄影镜头变焦的用法**  
现代 zoom in / out 可用于镜头、地图和界面

zoom past 飞快掠过；zoom in 放大、拉近；zoom out 缩小、拉远。

**常见搭配与例句**

zoom through a task 飞快做完；a zoom lens 变焦镜头。

> A motorbike seemed to zoom past the window.

一辆摩托车嗖地从窗外掠过。

> Zoom in to see the small details on the map.

放大一点，看看地图上的小细节。

**别混淆**

zoom in 指视野拉近、细节变大，move closer 才明确说位置靠近；数字界面的缩放更不要求身体移动。
