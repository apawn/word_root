# 0265 · write — 写下有意义的痕迹；创作、记录

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

write 接古英语 wrītan，早有刻划等含义。现代 w 不发音，write → wrote → written；writing 一个t，written 两个t，不能按同一套字母规则随意类推。

**WRITE：把意思留下来，让它不只存在于当下声音**

刻划、纸笔书写、电脑文字、数据写入，都在让信息留到一个可读取的位置。

- **动作、作品、结果与人物**：write · writing · written · writer
- **再写、覆盖与历史专业用法**：rewrite · overwrite · underwrite
- **write、wrote、written 的三式连读**：write · wrote · written
- **write → writer → writers：写作、作者与写入工具**：write · writer · writers
- **write → writes：写下与写信**：write · writes
- **writing → writings：写作活动与一篇篇著作**：write · writing · writings
- **write 的两个组合：覆盖与重写，保留不规则变化**：overwrite · overwrites · overwrote · overwritten · overwriting · rewrite · rewrites · rewrote · rewritten · rewriting

## 词形与演化规律

write、writing、written、writer 先把动作、内容、结果、人放一起；rewrite 重新写，overwrite 覆盖或写过度，underwrite 从签署保证发展为风险、经费支持。

wrote 是过去式，written 是过去分词；词形接较早写、刻痕动词的强变位传统。

writer 接古英语 wrītere 等人物名词；现代认形去 e 加 -er，复数再加 s。

古英语刻划的动作发展到留下文字、创作。

旧英语 writing 已有名词，现代复数通常数写成的作品、文字。

over 的覆盖、过度与 re 的再次分开；wrote、written 的变化随基础词进入组合。

## 逐词讲解

<a id="w-3"></a>

### 1. write — 写；创作；写入

**音标**：/raɪt/

**先抓住这个画面**

先在表面留下有意义的痕迹，后来键盘输入、数据保存也都能叫写。

**怎么拆**

接古英语 wrītan，经中古英语 writen，早与刻划、划出痕迹有关。现代开头 w 不发音；过去式 wrote /rəʊt/（英）、/roʊt/（美），过去分词 written /ˈrɪtən/。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen**  
刻划、写出文字

↓

**英语 write**  
书写；创作；写入数据

write a letter 是写信，write a novel 是创作小说，write to someone 是给人写信；write data to disk 是把数据写入磁盘。

**常见搭配与例句**

write a letter；write about；write to；write down；write data to。

> Please write your name at the top of the page.

请在页顶写上姓名。

> She writes stories for children.

她为儿童写故事。

**别混淆**

write /raɪt/ 与 right 常同音但词源不同。write 关注写下或创作，不一定是用笔，作者在电脑上也在 write。

<a id="w-1"></a>

### 2. written — 写成的；书面的；write 的过去分词

**音标**：/ˈrɪtən/

**先抓住这个画面**

话没有只停在嘴边，已经落成文字，可以再看、保存、核对。

**怎么拆**

write 的过去分词，可辨历史 -en 分词后缀及元音变化。write /raɪt/ → wrote → written /ˈrɪtən/，不是把 -en 直接加到原形读音后。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen**  
刻划、写出文字

↓

**英语 write**  
书写；创作；写入数据

↓

**write → wrote → written**  
书写动作的过去式与过去分词变化

a written agreement 是书面协议，written instructions 是书面说明；has written 是完成时结构。形容词强调形式，具体效力不由这个词单独决定。

**常见搭配与例句**

a written agreement；written instructions；a written reply。

> We received written instructions before the visit.

访问前我们收到书面说明。

> She has written three books on local history.

她已写了三本当地历史著作。

**别混淆**

written 是书面的，spoken 是口头的；a written reply 不等于只能手写，打字回复也属于书面。

<a id="w-2"></a>

### 3. writing — 写作；书写；文字、作品

**音标**：/ˈraɪtɪŋ/

**先抓住这个画面**

既可以看人正在写，也可以看他已经写出的文字与表达风格。

**怎么拆**

write 去掉末尾 e 后加 -ing，接古英语 wrīting 等形式；只有一个 t，不写 writting。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen**  
刻划、写出文字

↓

**古英语 wrīting → 中古英语 writing → writing**  
书写活动；写成的内容

creative writing 是创意写作，in writing 是以书面形式，her writing 是她的文风或作品；writing skills 是写作能力。

**常见搭配与例句**

in writing；creative writing；writing skills；a piece of writing。

> Please confirm the arrangement in writing.

请以书面形式确认安排。

> Her writing is clear and direct.

她的文字清楚直接。

**别混淆**

writing 可以是写作、文风，handwriting 具体是手写字迹；文章内容优秀，不一定字写得整齐。

<a id="w-11"></a>

### 4. writings — 著作、作品、写下的文字〔复数〕

**音标**：/ˈraɪtɪŋz/

**先抓住这个画面**

写作是活动，写下来的一篇篇作品、留下的文字，则可合称 writings。常用来讨论某人的一批作品、思想表达。

**怎么拆**

writing + -s，/ŋ/ 后读 /z/。writing 继承古英语 writing 的名词，也可现代对应 write 去 e 加完整 -ing；复数转向可数的书面产物。

**怎么变成今天的意思**

**古英语 writan、writing → write、writing**  
刻写、写作 → 写成的文字

↓

**writing + -s → writings**  
一篇篇著作、书面表达

early writings 早期著作；collected writings 文集；writings on history 关于历史的著作。

**常见搭配与例句**

personal writings 个人文字；the author’s writings 作者的作品。

> The course explores the author’s early writings.

课程探讨这位作者的早期著作。

> Her writings cover art and everyday life.

她的文字涵盖艺术与日常生活。

**别混淆**

writing 说写作活动、字迹时常不可数；writings 常数作品、文章等写成的内容。拼写仍只有一个 t，w 不发音。

<a id="w-8"></a>

### 5. wrote — 写了、创作了；write 的过去式

**音标**：英 /rəʊt/；美 /roʊt/

**先抓住这个画面**

过去写下一封信、一句代码、一本书，都可以用 wrote。写什么、为谁写，通过宾语和搭配说明。

**怎么拆**

write 接古英语 writan 刻痕、书写，过去式有 wrat 等；经中古英语和后续语音变化成为 wrote，保留旧强变位的不同元音。

**怎么变成今天的意思**

**古英语 writan、wrat 等**  
刻写、书写的原形与过去形式

↓

**现代 write → wrote → written**  
一般过去 wrote；过去分词 written

wrote a letter 写了封信；wrote a novel 创作了小说；wrote to someone 给某人写信；wrote down the address 记下了地址。

**常见搭配与例句**

wrote a reply；wrote the first chapter。

> I wrote her a letter last week.

我上周给她写了一封信。

> He wrote down the address before leaving.

离开前，他记下了地址。

**别混淆**

wrote 用一般过去；written 常跟 have、has 或被动结构：She wrote it；She has written it；It was written yesterday。

<a id="w-4"></a>

### 6. writer — 作者；作家；写作者

**音标**：英 /ˈraɪtə/；美 /ˈraɪtər/

**先抓住这个画面**

把想法变成文字的人，不一定只写长篇小说，也可能写剧本、报道、技术说明。

**怎么拆**

write 去掉末尾 e 后加 -er，上接古英语 wrītere 等。-er 表写的人，也可能用于写入设备等技术名称，具体看后接对象。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen**  
刻划、写出文字

↓

**古英语 wrītere → 中古英语 writer → writer**  
记录、创作文字的人

a fiction writer 是小说作者，a technical writer 是技术文档作者，a freelance writer 是自由撰稿人。有没有出版作品、是不是职业写作，靠上下文。

**常见搭配与例句**

a freelance writer；a technical writer；a writer of fiction。

> She works as a technical writer.

她从事技术文档写作。

> The writer visited the town before beginning the novel.

作者动笔写小说前到访了小镇。

**别混淆**

writer 范围很宽，novelist 特指小说家，author 常强调某作品作者；一本说明书的撰稿者也可以是 writer。

<a id="w-9"></a>

### 7. writers — 作者、写作者；作家；写入设备等〔技术语境〕；writer 的复数

**音标**：英 /ˈraɪtəz/；美 /ˈraɪtərz/

**先抓住这个画面**

把想法、信息写下来的人是 writers。写小说、写报道、写说明的人都可以这样叫，不只限于以文学创作为职业的人。

**怎么拆**

writer + -s，词尾 /z/。现代认形 write 去掉 e 加 -er，历史接古英语 wrītere 等人物形式；write 词首 w 在现代不发音。

**怎么变成今天的意思**

**古英语 wrītere → writer；与 write 写相连**  
从事写作、记录的人

↓

**writer + -s → writers**  
多位作者、写作者；部分技术工具名称

novel writers 小说作者；travel writers 旅行写作者；writers and editors 作者与编辑；technical writers 技术文档写作者。

**常见搭配与例句**

works by local writers；writers in the group。

> The writers exchanged feedback on their first drafts.

写作者们互相交流了对初稿的意见。

> The magazine invited travel writers to describe their home towns.

杂志邀请旅行写作者介绍自己的家乡。

**别混淆**

writers 强调写作的人，authors 常强调某部作品的创作归属；范围会重叠。writer 的 /raɪ/ 与 write 同读，w 不另发音。

<a id="w-10"></a>

### 8. writes — 写；写信；创作；write 的第三人称单数

**音标**：/raɪts/

**先抓住这个画面**

把话、想法留下可读的痕迹，就是 writes；写几行字、写信、写整本书都沿用这个动作。

**怎么拆**

write + -s，/t/ 后读 /s/，开头 w 不发音。write 继承古英语 wrītan，早与刻划、划出痕迹有关，经中古英语 writen 延续。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen → write**  
刻划、留下文字 → 写作

↓

**write + -s → writes**  
单数主语写、创作或写信

writes stories 写故事；writes to a friend 给朋友写信；writes down the number 记下号码；writes for a magazine 为杂志撰稿。

**常见搭配与例句**

writes clearly；writes in a notebook。

> She writes down every new word in a small notebook.

她把每个生词都记在一个小笔记本里。

> He writes short stories about life in the village.

他写关于乡村生活的短篇小说。

**别混淆**

writes /raɪts/ 与 rights 权利、rites 仪式同音。writes down 强调把信息记下来，writes back 强调回复来信、消息。

<a id="w-5"></a>

### 9. rewrite — 重写；改写；重写后的稿件或版本

**音标**：动词 /ˌriːˈraɪt/；名词 /ˈriːraɪt/

**先抓住这个画面**

保留想表达的内容，却换一套写法，让文章、代码或规则变成新版本。

**怎么拆**

re- 回、再次 + write。英语早期也有书面答复义，后来常指重新写；名词用法较晚。不是从拉丁语借来一个现成的整词。

**怎么变成今天的意思**

**re- 回、再次；英语 write 写**  
两组材料在英语中组合

↓

**英语动词 rewrite → 较晚的名词 rewrite**  
从写回、再写到改写；一次重写或新稿

rewrite a paragraph 是改写一段，a complete rewrite 是彻底重写。过去式 rewrote、分词 rewritten；动词重音靠后，名词通常在前。

**常见搭配与例句**

rewrite the introduction；rewrite the rules；a major rewrite。

> Please rewrite the opening paragraph in simpler language.

请用更简单的语言改写开头一段。

> The editor asked for a complete rewrite.

编辑要求彻底重写一遍。

**别混淆**

proofread 主要查校错误；rewrite 往往更大幅改变表达或结构。rewrite history 还可指重新解释历史，有时带歪曲之意。

<a id="w-12"></a>

### 10. rewritten — 重写过的、改写的〔过去分词〕

**音标**：/ˌriːˈrɪtn/

**先抓住这个画面**

文字已经换了新的表达版本，就是 rewritten；可修饰稿件，也可放在 have、be 后。

**怎么拆**

rewrite 的过去分词，随 write → written；re- 再次保留。

**怎么变成今天的意思**

**re- + write → rewrite**  
重写、改写

↓

**write → written；rewrite → rewritten**  
重写后的分词形式

a rewritten chapter 重写的一章；has rewritten 已重写。

**常见搭配与例句**

a rewritten version 改写版；was rewritten 被重写了。

> The rewritten chapter was much clearer.

重写后的这一章清楚多了。

> The instructions have been rewritten for beginners.

说明已经为初学者重新编写。

**别混淆**

rewritten 说明有过重新写作，不单凭这个词判断改动大小、是否保留原意。

<a id="w-13"></a>

### 11. rewriting — 正在重写；重写、改写过程

**音标**：/ˌriːˈraɪtɪŋ/

**先抓住这个画面**

原稿还在变成新稿的途中，就是 rewriting。常要重新安排句子、段落和讲法。

**怎么拆**

rewrite 去 e 加 -ing → rewriting；write 的 w 不发音，组合后照样如此。

**怎么变成今天的意思**

**re- + write → rewrite**  
重新写、改写

↓

**rewrite + -ing → rewriting〔去 e〕**  
正在改写；改写过程

rewriting a draft 改写草稿；finish rewriting 完成重写。

**常见搭配与例句**

rewriting the rules 改写规则；a lot of rewriting 大量改写工作。

> She is rewriting the report for a wider audience.

她正为更多读者改写报告。

> Rewriting the paragraph helped me understand the idea.

重写那一段帮我理解了这个想法。

**别混淆**

改写可以从理解原意后重新组织表达开始，未必只是挨个换同义词。

<a id="w-14"></a>

### 12. rewrote — 重写、改写了

**音标**：英 /ˌriːˈrəʊt/；美 /ˌriːˈroʊt/

**先抓住这个画面**

原来已有一稿，后来又用新写法写了一遍，是 rewrote。

**怎么拆**

rewrite 的不规则过去式，随 write → wrote；前缀 re- 不变。

**怎么变成今天的意思**

**re- + write → rewrite**  
再次写、改写

↓

**write → wrote；rewrite → rewrote**  
过去重写

rewrote the opening 重写了开头；rewrote the rules 改写了规则。

**常见搭配与例句**

rewrote in plain language 用大白话改写了；rewrote the script 重写了剧本。

> She rewrote the opening in plain language.

她用大白话重写了开头。

> The team rewrote the instructions after the trial.

试用后，团队重写了说明。

**别混淆**

rewrote 不只改拼写，它可包含结构、语气、内容组织的大幅变化。

<a id="w-15"></a>

### 13. rewrites — 重写、改写〔第三人称单数〕；重写稿、重写次数〔复数〕

**音标**：动词 /ˌriːˈraɪts/；名词 /ˈriːraɪts/

**先抓住这个画面**

同一个想法换一套写法，是 rewrites；几次改稿或几个新稿，也能按名词这样数。

**怎么拆**

re- 再次 + write → rewrite，加 -s，/t/ 后读 /s/。名词通常前重音，动词后重音。

**怎么变成今天的意思**

**re- + write → rewrite 动词；后来名词**  
重新写；新稿、重写事件

↓

**rewrite + -s → rewrites**  
它改写；多次改写、多个新稿

rewrites the paragraph 改写段落；several rewrites 几轮重写。

**常见搭配与例句**

major rewrites 大幅改写；rewrites the rules 改写规则。

> She rewrites each paragraph until it is clear.

她一段段重写，直到意思清楚。

> The article went through several rewrites.

这篇文章经历了几轮重写。

**别混淆**

rewrite 往往调整表达、结构，proofread 主要查文字小错，工作范围不同。

<a id="w-6"></a>

### 14. underwrite — 承保；承销；资助、保证经费

**音标**：英 /ˌʌndəˈraɪt/；美 /ˌʌndərˈraɪt/

**先抓住这个画面**

不只是说支持，而是把名字、责任或资金放到承诺下面，愿意承担相应风险。

**怎么拆**

under- + write，古英语 underwrītan 有在下方签署等义；后来保险、融资语境以签名承担责任形成专业用法。不能把现代承保、承销说成在纸下面随便写字。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen**  
刻划、写出文字

↓

**古英语 underwrītan → 中古英语 underwriten**  
写在下方、签署

↓

**underwrite 的保证、金融用法**  
以资金或风险承担支持某事

underwrite an event 是保证活动经费，underwrite insurance 是承保；证券发行里还有承销义。几种业务的具体责任不同，不能只译成借钱。

**常见搭配与例句**

underwrite an event；underwrite a policy；underwrite an issue。

> A local foundation underwrote the exhibition.

当地基金会为展览提供了经费保障。

> The article explains how insurers underwrite policies.

文章解释了保险机构如何承保保单。

**别混淆**

underwrite 可能承担风险、保证经费，sponsor 是赞助更泛；赞助者是否有保证全部缺口的责任，要看约定，不能只按英文词推合同。

<a id="w-7"></a>

### 15. overwrite — 覆盖写入；写得过多、过度修饰

**音标**：英 /ˌəʊvəˈraɪt/；美 /ˌoʊvərˈraɪt/

**先抓住这个画面**

已有一层内容，新文字再压上去；数据里旧内容可能被替代，文风里则可能堆得过头。

**怎么拆**

over-（覆盖、过度）+ write，过去式 overwrote、过去分词 overwritten，与 write 的不规则变化一致。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen**  
刻划、写出文字

↓

**英语 write**  
书写；创作；写入数据

↓

**over- + write → overwrite**  
在上面写；过量写作

overwrite a file 是覆盖文件中的旧内容，overwritten prose 是过度铺陈的文字。改写作品用 rewrite 更泛，不都意味着数据覆盖。

**常见搭配与例句**

overwrite a file；overwrite existing data；overwritten prose。

> The program asked before overwriting the existing file.

覆盖已有文件前，程序先询问了确认。

> The editor thought the opening chapter was overwritten.

编辑觉得开篇写得过分铺陈。

**别混淆**

overwrite 常替代已有内容，append 是接到末尾；写入发生的位置、旧内容是否保留是关键差别。

<a id="w-16"></a>

### 16. overwritten — 被覆盖写入的；过度铺陈的〔过去分词〕

**音标**：英 /ˌəʊvəˈrɪtn/；美 /ˌoʊvərˈrɪtn/

**先抓住这个画面**

旧内容已被新内容压过去，是 overwritten；文字堆得过满也可以这样评价。

**怎么拆**

overwrite 的过去分词，承 write → written 的不规则变化；over- 保留。

**怎么变成今天的意思**

**over- + write → overwrite**  
覆盖写入；写得过多

↓

**write → written；overwrite → overwritten**  
过去分词，常表达结果状态

an overwritten file 被覆盖的文件；overwritten prose 过度铺陈的文字。

**常见搭配与例句**

has overwritten 已覆盖；was overwritten 被覆盖了。

> The original file had been overwritten.

原文件已经被覆盖写入。

> The editor found the final chapter overwritten.

编辑觉得最后一章写得太过铺陈。

**别混淆**

overwritten 的数据义说原位置被新内容取代；文风义说写作过度，评价对象不同。

<a id="w-17"></a>

### 17. overwriting — 正在覆盖写入；覆盖、过度写作的过程

**音标**：英 /ˌəʊvəˈraɪtɪŋ/；美 /ˌoʊvərˈraɪtɪŋ/

**先抓住这个画面**

新内容正在写入旧位置，是 overwriting；写作时不断添过多修饰，也可说这个过程。

**怎么拆**

overwrite 去 e 加 -ing；基础词 over- + write，write 的进行形式是 writing，不双写 t。

**怎么变成今天的意思**

**over- + write → overwrite**  
覆盖、过度写作

↓

**overwrite + -ing → overwriting〔去 e〕**  
相应动作的进行、过程

overwriting a file 覆盖写入文件；avoid overwriting 避免覆盖、过度铺陈。

**常见搭配与例句**

overwriting existing data 覆盖已有数据；overwriting the scene 把场景写得过满。

> The program was overwriting the old data.

程序正在覆盖旧数据。

> He worried that he was overwriting the scene.

他担心自己把这个场景写得太满。

**别混淆**

rewriting 改写不必直接覆盖同一文件；overwriting 特别关心原内容被新内容写上去。

<a id="w-18"></a>

### 18. overwrites — 覆盖写入；写得过多〔第三人称单数〕

**音标**：英 /ˌəʊvəˈraɪts/；美 /ˌoʊvərˈraɪts/

**先抓住这个画面**

新内容写到旧内容所在处、替代旧内容，是 overwrites；文风里也可说写得太满、过度修饰。

**怎么拆**

over- 覆盖、过度 + write → overwrite，加 -s，/t/ 后读 /s/。write 继承古英语 writan 刻写材料。

**怎么变成今天的意思**

**over- + write → overwrite**  
在上面写；写得过多

↓

**overwrite + -s → overwrites**  
它覆盖写入、过度铺陈

overwrites the file 覆盖写入文件；overwrites the scene 把场景写得过满。

**常见搭配与例句**

overwrites existing data 覆盖已有数据；the writer overwrites 作者过度铺陈。

> The program overwrites the old file.

程序覆盖写入了旧文件。

> The critic thinks the author overwrites the opening scene.

评论者觉得作者把开场写得过分铺陈。

**别混淆**

overwrite 替代原位置的内容，append 接到末尾，保存旧内容的方式不同。

<a id="w-19"></a>

### 19. overwrote — 覆盖写入了；写得过多了

**音标**：英 /ˌəʊvəˈrəʊt/；美 /ˌoʊvərˈroʊt/

**先抓住这个画面**

过去用新内容替掉旧内容，或写得过分铺陈，用 overwrote。

**怎么拆**

overwrite 的不规则过去式：write → wrote，前缀 over- 保留，不加 -ed。

**怎么变成今天的意思**

**over- + write → overwrite**  
覆盖、过度地写

↓

**write → wrote；overwrite → overwrote**  
相同基础动词的过去变化

overwrote the original 覆盖了原内容；overwrote the file 覆盖写入了文件。

**常见搭配与例句**

accidentally overwrote 不小心覆盖了；overwrote the opening 把开头写得太满。

> I accidentally overwrote the original file.

我不小心覆盖了原文件。

> She overwrote the paragraph with a shorter version.

她用较短的版本覆盖写入了那一段。

**别混淆**

过去式是 overwrote，过去分词是 overwritten；I overwrote，但 I have overwritten。

## 这一组要分清什么

writing 文风与内容不等于 handwriting 字迹。written 书面的不限定手写；underwrite 专业责任不等于所有赞助、借款。

## 串起来练习

The writer rewrote the opening, then saved the written draft without overwriting the original.

作者重写了开篇，保存新稿时保留了原稿。
