# 0237 · used — 使用过、习惯与使用过度

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

use 的分词在历史使用中形成固定构式，不能一个中文用过包办。发音 /zd/ 与 /st/ 也随用法变化。

**USED：读结构，分二手、过去常做和已经习惯**

used 的几种实用结构先讲，再让 unused、overused 紧随。

- **基本词形与结构**：used
- **否定与过度**：unused · overused

## 词形与演化规律

use + -ed → used；un- + used；overuse → overused。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [used](#w-1) | /juːzd/〔使用过〕；/juːst/〔used to 构式常见读法〕 | 用过的、二手的；过去常常；习惯于〔看结构〕 |
| [unused](#w-2) | /ʌnˈjuːzd/〔未使用〕；/ʌnˈjuːst/〔不习惯〕 | 未使用的；不习惯的 |

## 逐词讲解

<a id="w-1"></a>

### 1. used — 用过的、二手的；过去常常；习惯于〔看结构〕

**音标**：/juːzd/〔使用过〕；/juːst/〔used to 构式常见读法〕

**先抓住这个画面**

先分三件事：车被人用过，事情以前常做，人已经习惯某种环境。拼写相同，结构决定意思。

**怎么拆**

use + -ed，过去式、分词又参与固定构式。used car 通常读 /juːzd/；used to do 与 be used to 中 used 常读 /juːst/。

**怎么变成今天的意思**

**法语 user → 英语 use**  
使用；经法语接拉丁使用词族

↓

**use + -ed → used**  
使用过的；习惯；旧时经常发生的构式

a used car 二手车；I used to walk 表以前常走路，通常暗示如今不同；I am used to walking 表已经习惯步行。

**常见搭配与例句**

a used car；used to do；be used to doing；get used to doing。

> I used to cycle to work, but now I take the bus.

我以前骑车上班，现在坐公交。

> She is used to working at night.

她已经习惯夜间工作。

**别混淆**

used to do 后面原形，be/get used to 后面名词或 -ing。This tool is used to cut 则是被用来切，属于普通被动结构。

<a id="w-2"></a>

### 2. unused — 未使用的；不习惯的

**音标**：/ʌnˈjuːzd/〔未使用〕；/ʌnˈjuːst/〔不习惯〕

**先抓住这个画面**

一面是东西放着没用，另一面是人没适应某种情况；是否接 to 很有提示。

**怎么拆**

un- 不 + used，分别否定被使用、习惯这两个用法。读音随所用义项区分。

**怎么变成今天的意思**

**法语 user → 英语 use**  
使用；经法语接拉丁使用词族

↓

**use + -ed → used**  
使用过的；习惯；旧时经常发生的构式

↓

**un- + used → unused**  
没被用过；尚未习惯

an unused ticket 未用的票，unused space 闲置空间；be unused to doing 不习惯做某事。

**常见搭配与例句**

an unused ticket；unused space；be unused to doing。

> The unused tickets can be returned before Friday.

未使用的票可在周五前退回。

> He was unused to speaking in front of a large audience.

他不习惯在大批听众面前讲话。

**别混淆**

unused 未使用不一定是 brand-new 全新，东西可能旧但闲置；unused to 是不习惯，不能按没被用过逐字翻译人。

<a id="w-3"></a>

### 3. overused — 使用过度的；用滥了的

**音标**：英 /ˌəʊvəˈjuːzd/；美 /ˌoʊvərˈjuːzd/

**先抓住这个画面**

设备老是被用、某个说法到处都说，超过合适程度就容易损耗或变得没新意。

**怎么拆**

over- 过度 + used，描述使用太多后的状态；来源动词 overuse 由 over- + use 组成。

**怎么变成今天的意思**

**法语 user → 英语 use**  
使用；经法语接拉丁使用词族

↓

**use + -ed → used**  
使用过的；习惯；旧时经常发生的构式

↓

**over- + use → overuse；其分词 overused**  
使用过度 → 被用滥的

an overused phrase 用滥的说法，an overused muscle 过度使用的肌肉，an overused example 老被重复的例子。

**常见搭配与例句**

an overused phrase；an overused example；overused equipment。

> The article avoids overused phrases.

文章避免陈词滥调。

> The overused equipment needed frequent repairs.

设备使用过度，需要频繁维修。

**别混淆**

used 只说用过，overused 多了过度的评价；popular 受欢迎也未必是用滥。

## 这一组要分清什么

used to do 过去常做；be used to doing 习惯；be used to cut 被用于切割。

## 串起来练习

The used machine sat unused because its controls were unfamiliar.

这台二手机器因操作不熟悉而闲置着。
