# 0730 · process — 过程、处理；处理过的与处理主体

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

process 经法语接拉丁向前推进、进程词族。派生词保留处理关系，但不自动交代采用了什么算法、工艺或决定。

**PROCESS：东西经过一套步骤，变成结果**

申请、数据、食品都可以 process；processed 是处理过，processor 是处理它的设备、机构等。

- **过程、处理结果和主体**：process · processed · processor
- **processor → processors：按处理作用命名人、器具**：processor · processors

## 词形与演化规律

process → processed；process + -or → processor。

process 加 or，食品、数据、原料等对象让作用物形成不同专门用途。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. process — 过程；程序；处理；加工；列队行进

**音标**：名词及“处理”动词：英 /ˈprəʊses/；美 /ˈprɑːses/；“列队行进”动词 /prəˈses/

**先抓住这个画面**

事物一步步往前变化；处理它，就是让它走过所需步骤。

**怎么拆**

常用名词来自法语 proces 和拉丁 prōcessus；“处理”动词由名词发展。重音在后的“列队行进”动词则从 procession 逆构。

**怎么变成今天的意思**

**拉丁 cēdere；分词词干 cess-**  
走、离开；让步、让出

↓

**拉丁 prō- + cēdere → prōcēdere**  
朝前走、推进

↓

**拉丁 prōcessus → 古法语 proces；亦有直接拉丁来源**  
前进、进程；诉讼过程

↓

**中古英语 proces → 英语 process**  
过程、程序；后来也作处理、加工的动词

↓

**英语名词 → process“处理”；另一路 procession → process“列队行进”**  
两种动词的形成与重音不同

a learning process 是学习过程；process an application 是受理并处理申请。解剖学的 process 还能指突起，是“向外伸出”的专门义。重音在后的 process 较少见，别套到电脑处理数据上。

**常见搭配与例句**

a gradual process；process data；process an application。

> Learning a language is a gradual process.

学习语言是一个渐进过程。

> The office will process your application this week.

办公室本周会处理你的申请。

> The choir will process into the hall after the bell.

铃响后，合唱团将列队进入大厅。

**别混淆**

procedure 常是规定的操作步骤；process 可以包括自然发生的变化。proceed 是继续，不是“处理某物”。

<a id="w-2"></a>

### 2. processed — 处理过的；加工过的

**音标**：英 /ˈprəʊsest/；美 /ˈprɑːsest/

**先抓住这个画面**

原材料、资料或申请已经经过了一道或多道处理；究竟怎样处理要看对象。

**怎么拆**

process + -ed，过去式、过去分词并可作形容词；-ed 接在这里常读 /t/，不是额外完整的 /ɪd/ 音节。

**怎么变成今天的意思**

**拉丁 prōcēdere → prōcessus → 法语 proces → 英语 process**  
向前推进 → 行进、进程、过程

↓

**英语 process 的动词和派生词**  
按程序处理；处理过的；执行处理的设备、人或机构

↓

**process + -ed → processed**  
处理 → 已处理、加工过的

processed food 加工食品，processed data 已处理数据；The application has been processed 申请已处理，不自动等于获批。

**常见搭配与例句**

processed food；processed data；a processed application。

> The processed data was ready for analysis.

处理后的数据已经可以分析了。

> Your application has been processed, but a decision is still pending.

你的申请已处理，但决定仍待作出。

**别混淆**

processed 说经过处理，approved 说得到批准；食品加工方式很多，不能仅凭这一个词推断具体营养或安全状况。

<a id="w-3"></a>

### 3. processor — 处理器；加工设备、企业；处理某事者

**音标**：英 /ˈprəʊsesə/；美 /ˈprɑːsesər/

**先抓住这个画面**

把东西送进去，按规则变成结果的那个人、设备或机构；电脑里处理指令的芯片是常见一例。

**怎么拆**

process + -or，-or 形成执行作用的人、物名称。电脑处理器、食品加工机、加工企业等取不同对象，不是所有 processor 都是 CPU。

**怎么变成今天的意思**

**拉丁 prōcēdere → prōcessus → 法语 proces → 英语 process**  
向前推进 → 行进、进程、过程

↓

**英语 process 的动词和派生词**  
按程序处理；处理过的；执行处理的设备、人或机构

↓

**process + -or → processor**  
处理 → 执行处理的人、设备、机构

a computer processor 计算机处理器，a food processor 食品加工机，a payment processor 支付处理服务商；word processor 文字处理软件或设备。

**常见搭配与例句**

a computer processor；a food processor；a payment processor；a word processor。

> The laptop has a more powerful processor.

这台笔记本电脑有一个更强的处理器。

> She chopped the vegetables in a food processor.

她用食品加工机切碎了蔬菜。

**别混淆**

processor 是执行处理的设备或主体，process 是过程或处理动作；processing 是处理活动，三者句法对象不同。

<a id="w-4"></a>

### 4. processors — 处理器、加工机、加工者〔复数〕

**音标**：英 /ˈprəʊsesəz/；美 /ˈprɑːsesərz/

**先抓住这个画面**

把输入材料处理成可用结果的人或机器，按作用叫 processors。电脑处理数据，食品加工机处理食物，企业也能加工原料。

**怎么拆**

process 处理 + -or → processor，加 -s，读 /z/。process 的历史接拉丁 procedere 前进、推进的一系，现代词义已经固定。

**怎么变成今天的意思**

**process + -or → processor**  
按处理作用命名人、器具、企业

↓

**processor + -s → processors**  
多个处理器、加工机或加工者

computer processors 电脑处理器；food processors 食品加工机。

**常见搭配与例句**

data processors 数据处理者、设备；local processors 当地加工企业。

> The two computers use different processors.

两台电脑采用不同处理器。

> The shop sells food processors and mixers.

店里出售食品加工机和搅拌机。

**别混淆**

processor 不总等于 CPU；先找它处理的对象，才知道是在谈电脑、食物还是产业。

## 这一组要分清什么

processed 申请已处理不等于 approved 获批；processor 不只电脑芯片；process、processing、processor 各有句法角色。

## 串起来练习

The processor handled the data, and the processed results were stored.

处理器处理了数据，处理后的结果被保存了下来。
