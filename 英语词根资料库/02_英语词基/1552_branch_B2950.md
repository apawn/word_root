# 1552 · branch — 从主体分出去的一支

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

树根也可以是 branched，因为这里说形状，不是把根叫树枝。分支关系也不要求从主体彻底分离。

**BRANCH：先画主干，再画侧支**

branch 树枝 → 分店、学科、路线分支；branched 有分叉的结构。

- **树枝与各种分支**：branch
- **分支结构**：branched
- **branch → branches：主干伸出的分支**：branch · branches

## 词形与演化规律

branca → branche → branch；branch + -ed → branched；branch off/out 固定组合。

法语树枝词向支路、分店、学科等扩展；更早来源不作确定故事。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. branch — 树枝；支路、分支、分店；分叉、拓展

**音标**：英 /brɑːntʃ/；美 /bræntʃ/

**先抓住这个画面**

一根主干旁边分出一条，分出的那条还可再分；公司分店、知识分科也借这张树形图。

**怎么拆**

经古法语 branche 接晚期拉丁 branca 的爪、足印等材料，具体更远来源未定；爪形到枝形是解释线索，不臆造第一个命名者的故事。

**怎么变成今天的意思**

**晚期拉丁 branca 等 → 古法语 branche → 英语 branch**  
足印、爪等旧材料到枝条名称；更早来源未定

↓

**树枝状关系引申**  
主体分出的支路、分支、分店、学科

↓

**branch + -ed → branched**  
有分支、分叉的

a tree branch 树枝，a bank branch 银行分行，a branch of science 科学分支，branch off 分岔出去，branch out 拓展新领域。

**常见搭配与例句**

a branch of；a local branch；branch off；branch out。

> A bird landed on a low branch.

一只鸟落在低处的树枝上。

> The company opened a new branch in the city.

公司在城里开了一家新分店。

**别混淆**

branch 强调从主体分出，root 是根；计算机 branch 也借分支意象，不一定真复制出一个完整独立系统。

<a id="w-3"></a>

### 2. branches — 树枝；支路；分店、分部；学科分支；分叉〔第三人称单数〕

**音标**：英 /ˈbrɑːntʃɪz/；美 /ˈbræntʃɪz/

**先抓住这个画面**

从主干伸出一条支线，就是 branch 的共同画面；树枝、道路分叉、机构分店、知识分支都能放到这个画面里。

**怎么拆**

branch + -es，/tʃ/ 后增加 /ɪz/。branch 经古法语 branche 接晚期拉丁 branca 等足印、爪相关材料，更远来源未定；现代支线义从树枝形象发展。

**怎么变成今天的意思**

**晚期拉丁相关材料 → 古法语 branche → 英语 branch**  
树枝名称；更早来源不定

↓

**branch + -es → branches**  
多条树枝、支路、分部；单数主语分叉

tree branches 树枝；bank branches 银行网点；branches of science 科学分支；the road branches 道路分叉。

**常见搭配与例句**

branches stretching over the path；branches across the country。

> The branches stretched over the narrow path.

树枝伸到了窄路上方。

> The library has branches in several nearby towns.

这家图书馆在附近几个镇上设有分馆。

**别混淆**

branch 强调从主体分出的部分；root 强调根部、来源。branches 在机构语境常是分部、分店，读时不必逐字译成树枝。

<a id="w-2"></a>

### 3. branched — 有分支的、分叉的；已经分岔的

**音标**：英 /brɑːntʃt/；美 /bræntʃt/

**先抓住这个画面**

一条线走着走着分成两条、多条，或一个结构长出侧枝；形容的是枝状结构。

**怎么拆**

branch + -ed，可作过去式，也可作有分支的形容词；末尾 /t/ 接在 /tʃ/ 后面，不读额外 /ɪd/。

**怎么变成今天的意思**

**晚期拉丁 branca 等 → 古法语 branche → 英语 branch**  
足印、爪等旧材料到枝条名称；更早来源未定

↓

**树枝状关系引申**  
主体分出的支路、分支、分店、学科

↓

**branch + -ed → branched**  
有分支；已经分岔

a branched structure 分支结构，branched roots 分叉的根，a highly branched network 高度分支的网络。

**常见搭配与例句**

a branched structure；branched roots；a highly branched network。

> The plant has a highly branched root system.

这种植物的根系分支很多。

> The path branched near the old bridge.

小路在旧桥附近分岔了。

**别混淆**

branched 有分叉，broken 是断了；branching 也可描述正在分叉、分叉式结构，不保证枝条已断离主体。

## 这一组要分清什么

branched/broken 分叉与断裂；branch/root 分支与根，根本身也能分支。

## 串起来练习

The main path branched into two smaller paths.

主路分成了两条较小的路。
