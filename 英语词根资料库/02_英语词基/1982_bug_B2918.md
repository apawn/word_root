# 1982 · bug — 小虫、恼人问题与技术故障，以及多源近形词的辨认

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

本组要同时抓住活用与边界。系统故障的历史早于飞蛾故事，轻便车 buggy 和粗口 bugger 也不能用小虫一路解释。

**BUG：具体小虫与恼人问题有常用扩展，BUGGER 粗口另有来源**

bug → buggy 形容词、debug；jitterbug、firebug 已固定；bugger 的日常粗口不能按 bug + -er 拆。

- **基础与技术、性质**：bug · buggy · debug
- **固定人物、舞蹈和动物名**：jitterbug · firebug
- **常见近形、不同源词**：bugger
- **已学的具体虫名、比喻**：ladybug · bedbug · superbug · bugbear
- **bug → bugs：小虫与恼人的故障**：bug · bugs

## 词形与演化规律

旧 bugge 相关来源存在讨论；de- 去除、-y 性质；车辆 buggy 来源未明，粗口 bugger 经 bougre 等另线发展。

早期精怪、虫名关系未全明，技术故障义早于1947年的飞蛾故事。

## 逐词讲解

<a id="w-1"></a>

### 1. bug — 小虫；程序或系统缺陷；小病、病菌〔口语〕；烦扰；窃听器、装窃听器

**音标**：/bʌɡ/

**先抓住这个画面**

小虫让人烦，系统里一个不起眼的问题也能让人烦；现代 bug 就在这些真实用法间切换。It bugs me 直接说这让我很烦。

**怎么拆**

联系较早英语 bugge，小虫与精怪等旧义的远处关系不完全确定。技术故障 bug 十九世纪已使用，不是1947年电脑夹出飞蛾时才第一次造出的词。

**怎么变成今天的意思**

**较早英语 bugge 等**  
小虫、吓人的精怪等旧用；远源关系存在不同分析

↓

**现代 bug 的常见扩展**  
小虫；病菌、小毛病；技术故障；使人烦、装窃听器

↓

**十九世纪技术术语 → 计算机 bug**  
故障用法早于1947年电脑里发现飞蛾的故事

a software bug 软件缺陷，fix a bug 修复缺陷，catch a bug 得了点小病〔口语〕，bug someone 烦某人，a hidden bug 隐藏窃听器。日常小虫与昆虫学 true bug 的范围不完全相同。

**常见搭配与例句**

a software bug；fix a bug；catch a bug；bug someone。

> The team fixed a bug that caused the page to freeze.

团队修复了一个让页面卡住的缺陷。

> That clicking noise is really bugging me.

那种咔嗒声真让我心烦。

**别混淆**

1947年的飞蛾是著名实物与双关记录，不是故障术语的起源。system bug 也不只指一处拼写、语法错误，可能涉及逻辑、设计或硬件。

<a id="w-11"></a>

### 2. bugs — 小虫；程序故障〔复数〕；烦扰〔第三人称单数〕

**音标**：/bʌɡz/

**先抓住这个画面**

一只小虫很小，却能让人一直在意；程序里一个小毛病也能卡住事情。bugs 的几个常用意思都容易用这种恼人小问题来理解。

**怎么拆**

bug + -s，/ɡ/ 后读 /z/。bug 联系早期 bugge 等精怪、虫名材料，远处关系不全确定；技术故障义在十九世纪已出现。

**怎么变成今天的意思**

**早期英语 bugge 等 → bug**  
虫与精怪等旧义，远源仍有疑问

↓

**技术故障义及现代 + -s → bugs**  
多个小虫、故障；某事使人烦

software bugs 软件故障；fix bugs 修复问题；bugs me 让我烦。

**常见搭配与例句**

bugs in the garden 花园里的小虫；report bugs 报告程序问题。

> We found two bugs in the new version.

我们在新版本里发现了两个问题。

> That clicking noise really bugs me.

那个咔嗒声真让我烦。

**别混淆**

日常 bugs 可以泛指小虫，不只限于生物学上的某一类。程序故障这个用法早于1947年发现电脑飞蛾的故事。

<a id="w-2"></a>

### 3. buggy — 虫多的；程序错误多、不稳定的；轻便车、婴儿推车〔独立名词〕

**音标**：/ˈbʌɡi/

**先抓住这个画面**

形容软件 buggy，就是问题不少、运行不稳；形容住处则可能是虫多。a buggy 这辆小车却是另一条来源不明的名词。

**怎么拆**

形容词 bug + -y，双写 g。车辆名词 buggy 的来源未明，不能只因车小就断言像虫子而得名。

**怎么变成今天的意思**

**较早英语 bugge 等**  
小虫、吓人的精怪等旧用；远源关系存在不同分析

↓

**现代 bug 的常见扩展**  
小虫；病菌、小毛病；技术故障；使人烦、装窃听器

↓

**bug + -y → buggy 形容词**  
多虫；多程序缺陷

↓

**buggy 车辆名词**  
来源未明的独立词，轻便马车、机动车或推车等

buggy software 问题多的软件，a dune buggy 沙滩越野车，a baby buggy 婴儿推车〔地区用法〕。具体车种要看搭配。

**常见搭配与例句**

buggy software；a dune buggy；a baby buggy。

> The first version of the app was rather buggy.

应用最初版本的问题不少。

> They crossed the dunes in a buggy.

他们乘轻便越野车穿过沙丘。

**别混淆**

buggy software 的 buggy 是性质，a buggy 是车辆名词。不能把 every buggy 都当成一台有故障的电脑。

<a id="w-3"></a>

### 4. bugger — 家伙、讨厌鬼；麻烦事；弄坏、弄砸；抱怨感叹词〔粗俗口语〕

**音标**：英 /ˈbʌɡə/；美 /ˈbʌɡər/

**先抓住这个画面**

英国等地口语里可用来骂人、抱怨，熟人间又可能戏谑。bugger up 说弄砸；bugger all 是什么也没有，不能按小虫猜。

**怎么拆**

常用粗俗词经古法语 bougre 等，联系中世纪针对保加利亚人、某些宗教群体的蔑称及性指控；是历史偏见形成的联想。它不由 bug 小虫 + -er 普通派生。

**怎么变成今天的意思**

**中世纪 Bulgarus 等族群、宗教蔑称 → 法语 bougre**  
带偏见的异端指称、性指控，并非族群事实

↓

**英语 bugger 的粗俗用法扩展**  
辱骂、抱怨；有时亲昵戏谑；动词弄砸

bugger off 滚开，bugger all 什么也没有，bugger something up 把事情弄砸，You lucky bugger! 你这走运的家伙！语气强弱随地区、关系而变，正式表达较少用。

**常见搭配与例句**

bugger off；bugger all；bugger something up。

> Oh bugger, I have left my keys at home.

真糟，我把钥匙落家里了。

> The failed update buggered up the settings.

失败的更新把设置弄乱了。

**别混淆**

常用 bugger 与 bug 的派生词不是同一条历史。另有极罕见 bug + -er 安装窃听器者的同形词，不能用它解释日常粗口。

<a id="w-6"></a>

### 5. bugbear — 令人烦恼或害怕的事；老大难

**音标**：英 /ˈbʌɡbeə/；美 /ˈbʌɡber/

**先抓住这个画面**

有件事像个老在眼前晃的怪物，让你一想到就烦或担心。

**怎么拆**

bug 在这里是吓人之物的旧义，不是现代昆虫或程序漏洞义；加 bear 熊，早期指吓人的怪物，后来成为反复困扰人的事情。

**怎么变成今天的意思**

**bug 旧义：吓人之物；bear 熊**  
并列构词部分

↓

**bugbear**  
吓人的怪物 → 令人反复烦恼的事

a particular bugbear 特别让人烦的一件事；my biggest bugbear 我最烦的事。英式表达中很常见，也可指难解决的担忧。

**常见搭配与例句**

a major bugbear；a particular bugbear of mine；a longstanding bugbear。

> Unclear instructions are a particular bugbear of mine.

说明写得不清楚，是我特别烦的一件事。

> Parking remains a major bugbear for local residents.

停车问题仍是当地居民的一大烦心事。

**别混淆**

bugbear 不是昆虫和熊杂交的动物，也不是特指软件 bug；要从吓人、烦人的旧意象理解。

<a id="w-4"></a>

### 6. debug — 调试、排查并修正故障；清除窃听装置

**音标**：/ˌdiːˈbʌɡ/

**先抓住这个画面**

bug 是影响系统的问题，debug 就是找出它、理解它、把它处理掉。它常说排查过程，不只是把一段代码重新运行一遍。

**怎么拆**

de- 去除 + bug，接技术故障、窃听装置等不同义。技术词义不必经由真正拿镊子捉虫才成立。

**怎么变成今天的意思**

**现代 bug 的常见扩展**  
小虫；病菌、小毛病；技术故障；使人烦、装窃听器

↓

**十九世纪技术术语 → 计算机 bug**  
故障用法早于1947年电脑里发现飞蛾的故事

↓

**de- + bug → debug**  
排查、去除故障；清除隐藏窃听装置

debug a program 调试程序，debugging tools 调试工具，debug a room 清查房间窃听装置。技术文档里的 debug mode 是调试模式。

**常见搭配与例句**

debug a program；debugging tools；debug mode。

> She used the log messages to debug the program.

她利用日志消息排查程序故障。

> The lesson introduces tools that help developers debug errors.

这课介绍帮助开发者排查错误的工具。

**别混淆**

debug 不等于 deploy 发布，也不等于只看一次输出。它可以包含找问题、定位原因、验证修复；具体步骤随对象变化。

<a id="w-5"></a>

### 7. ladybug — 瓢虫〔美式常用〕

**音标**：/ˈleɪdibʌɡ/

**先抓住这个画面**

常见背上有斑点的小甲虫；名字中的 lady 不是说每只都是雌性。

**怎么拆**

lady 在此指 Our Lady 圣母玛利亚 + bug 虫。名称来自相关欧洲宗教、民间命名传统，不按现代女士虫逐字翻。

**怎么变成今天的意思**

**古英语 hlǣfdīġe → 中古英语 lafdi、lavedi 等 → lady**  
女主人、地位较高的女性；传统拆解联系面包与和面者，但语义动机有争议

↓

**现代 lady**  
女士；贵族、特定身份称呼；Our Lady 指圣母玛利亚

↓

**Our Lady〔圣母称呼〕+ bug → ladybug**  
传统命名的瓢虫；美式常用

a red ladybug 红色瓢虫，a ladybug on a leaf 叶上的瓢虫。不同种类颜色、斑点数量不同。

**常见搭配与例句**

a ladybug on a leaf；a red ladybug；a spotted ladybug。

> A ladybug landed on the leaf.

一只瓢虫落在叶子上。

> The children watched a ladybug crawl across the window.

孩子们看着一只瓢虫爬过窗面。

**别混淆**

ladybug 美式、ladybird 英式常指同类甲虫；两词都不按雌雄分，也不是 bug 与 bird 的现代生物分类较量。

<a id="w-7"></a>

### 8. bedbug — 臭虫；床虱

**音标**：/ˈbedbʌɡ/

**先抓住这个画面**

一种常躲在寝具、家具等缝隙附近的小虫，名字按常见藏身处来叫。

**怎么拆**

bed 床 + bug 虫，形成固定昆虫名；并不是床上所有小虫都归为 bedbug，也不是软件 bug 在床上出现。

**怎么变成今天的意思**

**bed 床；bug 虫**  
并列构词部分

↓

**bedbug**  
以寝具附近藏身习性命名的臭虫

look for bedbugs 检查是否有臭虫，a bedbug infestation 臭虫滋生；复数 bedbugs。

**常见搭配与例句**

bedbugs；look for bedbugs；a bedbug infestation。

> The hotel inspected the rooms for bedbugs.

酒店检查了房间是否有臭虫。

> The article explains how bedbugs got their name.

文章解释了臭虫这个英语名称的来历。

**别混淆**

bedbug 是特定虫名，不等于所有会咬人的 insect；词名也不证明它只待在床上。

<a id="w-8"></a>

### 9. jitterbug — 吉特巴舞、快节奏摇摆舞；跳这种舞

**音标**：英 /ˈdʒɪtəbʌɡ/；美 /ˈdʒɪtərbʌɡ/

**先抓住这个画面**

看舞者随快节奏抖动、旋转，jitter 的抖动感便容易记。jitterbug 后来成为这类摇摆舞、舞者的固定称呼。

**怎么拆**

jitter 紧张、抖动 + bug 迷、人物称呼等用法，联系三十年代爵士、摇摆乐语境及相关歌曲的流行。不是昆虫分类名称。

**怎么变成今天的意思**

**现代 bug 的常见扩展**  
小虫；病菌、小毛病；技术故障；使人烦、装窃听器

↓

**jitter + bug → jitterbug**  
人物、乐迷称呼及快节奏摇摆舞名

dance the jitterbug 跳吉特巴舞，a jitterbug dancer 吉特巴舞者，a jitterbug routine 一段舞蹈动作。具体舞步、历史形式有变化。

**常见搭配与例句**

dance the jitterbug；a jitterbug dancer。

> The dancers performed a lively jitterbug.

舞者跳了一段活泼的吉特巴舞。

> The film shows the couple learning to jitterbug.

电影里那对伴侣在学习跳吉特巴舞。

**别混淆**

jitterbug 不能只按一只紧张虫翻译；现代舞名是固定文化名称。jittery 紧张、抖动的则是另一个常用形容词。

<a id="w-9"></a>

### 10. firebug — 纵火者；红蝽〔昆虫名〕

**音标**：英 /ˈfaɪəbʌɡ/；美 /ˈfaɪərbʌɡ/

**先抓住这个画面**

在人称里，firebug 说纵火者；昆虫介绍里，它又可能是一种红黑相间的红蝽。两种对象各自借 fire、bug 的不同关系。

**怎么拆**

fire 火 + bug。人物义接着迷、人物等扩展，昆虫义接小虫与火色等命名联系；不是说那种昆虫真的会点火。

**怎么变成今天的意思**

**现代 bug 的常见扩展**  
小虫；病菌、小毛病；技术故障；使人烦、装窃听器

↓

**fire + bug → firebug**  
纵火人物称谓；独立固定的红蝽俗名

a suspected firebug 被怀疑的纵火者，a red-and-black firebug 红黑相间的红蝽。人物报道与自然观察中要换所指。

**常见搭配与例句**

a suspected firebug；a red-and-black firebug。

> The detective in the novel searches for a firebug.

小说中的侦探寻找一名纵火者。

> A firebug crawled across the dry leaf.

一只红蝽爬过干叶。

**别混淆**

firebug 不等于消防员 firefighter，也不能把所有失火都归成有人纵火；昆虫用法更与人的动机无关。

<a id="w-10"></a>

### 11. superbug — 超级病菌〔通常指耐药病原体〕

**音标**：英 /ˈsuːpəbʌɡ/；美 /ˈsuːpərbʌɡ/

**先抓住这个画面**

原来能对付它的药物不再奏效，所以像变得更难打败的病菌；“超级”强调治疗困难。

**怎么拆**

英语 super- + bug；bug 在这里是病菌的通俗说法，不是软件故障或普通昆虫。

**怎么变成今天的意思**

**拉丁 super**  
在上方、超过、越过

↓

**英语构词成分 super-**  
超出一般程度；在上、额外或超过某界限

↓

**英语 super- + bug → superbug**  
对相关抗微生物药物产生耐药性的病菌通俗称呼

常指耐药细菌，也可宽泛指耐药微生物；不意味着它对所有现有和未来药物都无敌。产生耐药性的是微生物，不是人的身体“习惯了药”。

**常见搭配与例句**

a drug-resistant superbug；the spread of superbugs。

> The report tracks the spread of a drug-resistant superbug.

报告追踪了一种耐药超级病菌的传播。

> Researchers tested whether the new compound was active against the superbug.

研究人员测试了新化合物是否对这种超级病菌有效。

**别混淆**

电脑飞蛾不是 bug 故障义的起源；bugger 粗口另有来源；buggy 名词可是一辆车。
