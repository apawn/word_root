# 1882 · thread — 纤维细线，到连续脉络、螺旋纹和信息串

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

物理线、螺纹、故事线和消息串各取连续或盘绕特点。程序线程是另一技术命名，不拿所有 threaded 都当计算机并行。

**THREAD：细长、连续，能穿过也能串起**

thread → threaded；threadbare 织物磨薄后露线，再到陈旧说法。

- **基本线及对应状态**：thread · threaded
- **磨旧露线的比喻**：threadbare
- **thread → threads：纺线到讨论串、螺纹**：thread · threads

## 词形与演化规律

þrǣd → thread；thread + -ed；thread + bare。

古英语继承；连续的线成为理解各类引申义的画面。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. thread — 线；螺纹；思路线索、讨论串、线程；穿线、穿行

**音标**：/θred/

**先抓住这个画面**

一根细线把分散东西串住；故事、回复也能沿着同一条线接下去，计算机里的执行步骤又借成线程名。

**怎么拆**

接古英语 þrǣd，与拧、搓等旧材料相关。名词的长细、连续和螺旋线形状，分别启发后来的不同专门义，不都指缝衣服。

**怎么变成今天的意思**

**古英语 þrǣd → 中古英语 thred → thread**  
由纤维拧纺成的线

↓

**英语扩展**  
线 → 螺纹、故事线、讨论串、执行线程；动词穿线、穿行

a needle and thread 针线，thread a needle 给针穿线，lose the thread of an argument 跟丢论证思路，a discussion thread 讨论串，a processing thread 执行线程。

**常见搭配与例句**

a needle and thread；thread a needle；lose the thread；a discussion thread。

> She threaded the needle carefully.

她小心地给针穿线。

> I lost the thread of his argument halfway through.

听到一半，我跟不上他的论证思路了。

**别混淆**

thread /θred/ 线，threat /θret/ 威胁；故事 thread 强调连续脉络，topic 更偏主题，不保证每个同主题消息都在同一讨论串。

<a id="w-4"></a>

### 2. threads — 线；讨论串、思路线索；螺纹、线程〔复数〕；穿过、穿针〔动词第三人称单数〕

**音标**：/θredz/

**先抓住这个画面**

一根线把东西串起来；一串回复把讨论接起来。这个连续、可接续的画面，能把 threads 的常见意思连住。

**怎么拆**

thread 继承古英语 þrǣd，与纺、捻线的老材料有关。后来把线的细长、连续结构用到螺纹、故事、讨论、计算机执行流程；现代加 -s，尾 /z/。

**怎么变成今天的意思**

**古英语 þrǣd → thread**  
纺成的细线

↓

**线的形态、连续性引申；thread + -s → threads**  
多根线、讨论串、螺纹或线程；穿线动作

loose threads 松脱的线头；discussion threads 讨论串；threads a needle 穿针。

**常见搭配与例句**

follow several threads 同时跟几条思路、讨论；cotton threads 棉线。

> Loose threads hung from the sleeve.

袖子上垂着松脱的线头。

> She followed two discussion threads about the book.

她跟进了两条讨论那本书的帖子串。

**别混淆**

计算机 thread 是可独立安排执行的一条流程；讨论 thread 是同一话题下接续的一串内容。它们借的是线索画面，具体对象不同。

<a id="w-2"></a>

### 3. threaded — 穿好线的；有螺纹的；按讨论串组织的

**音标**：/ˈθredɪd/

**先抓住这个画面**

针孔穿了线、金属杆刻了螺旋纹、消息按回复线串起来，都可说 threaded；每个场景选 thread 的那一支。

**怎么拆**

thread + -ed，过去式、分词和带某种线、螺纹的形容词。词末 /d/ 后 -ed 读 /ɪd/，形成两个音节。

**怎么变成今天的意思**

**古英语 þrǣd → 中古英语 thred → thread**  
由纤维拧纺成的线

↓

**英语扩展**  
线 → 螺纹、故事线、讨论串、执行线程；动词穿线、穿行

↓

**thread + -ed → threaded**  
穿线了、带螺纹；消息按线索组织

a threaded rod 螺纹杆，a threaded needle 穿好线的针，threaded replies 串式回复、按对话组织的回复。

**常见搭配与例句**

a threaded rod；a threaded needle；threaded replies。

> The two parts connect with a threaded rod.

两个部件通过一根螺纹杆连接。

> Threaded replies make the conversation easier to follow.

按讨论串组织的回复让对话更容易跟上。

**别混淆**

threaded 技术词不都指多线程程序；threaded rod 是螺纹杆，threaded discussion 是讨论串组织方式。

<a id="w-3"></a>

### 4. threadbare — 磨得露线的、破旧的；陈旧乏味的

**音标**：英 /ˈθredbeə/；美 /ˈθredber/

**先抓住这个画面**

布料磨薄，表面的绒、纤维没了，下面一根根线都露出来；借到借口、笑话，就是用得太多、已经磨旧。

**怎么拆**

thread 线 + bare 裸露，中古英语已有相应组合。实物露出织线到抽象说法被反复用旧，画面连续。

**怎么变成今天的意思**

**古英语 bær → 中古英语 bare → bare〔形容词〕**  
无遮盖、裸露

↓

**thread + bare → threadbare**  
衣料磨得织线裸露

↓

**实物磨旧 → 抽象套话用旧**  
破旧；陈词滥调般乏味

a threadbare coat 破旧外套，a threadbare carpet 磨薄的地毯，a threadbare excuse 老掉牙的借口。

**常见搭配与例句**

a threadbare coat；a threadbare carpet；a threadbare excuse。

> The stairs were covered with a threadbare carpet.

楼梯铺着一层磨薄的旧地毯。

> He offered the same threadbare excuse again.

他又拿出那个老掉牙的借口。

**别混淆**

threadbare 不是完全无线，而是磨得线都显出来；bare 光、露与 threadbare 磨薄露线的状态不同。

## 这一组要分清什么

thread/threat 线与威胁；threaded rod/discussion 螺纹杆与串式讨论；threadbare 也能说陈词滥调。

## 串起来练习

The threaded discussion helped us follow the thread without repeating threadbare arguments.

串式讨论帮助我们跟住思路，避免重复陈旧论调。
