# 0615 · data — 数据、资料；组织数据与描述数据

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

data 原是拉丁语 datum 的复数，英语现代又有整体不可数用法。database、datasheet 是英语后来的复合名称。

**DATA：给出的记录，拿来分析与使用**

先区别数据本身、组织数据的数据库、说明参数的资料表，再看描述数据的数据 metadata。

- **资料与组织**：data · database
- **参数说明与数据描述**：datasheet · metadata
- **data 的数据集合与数据库组合**：data · dataset · datasets · database · databases

## 词形与演化规律

data → database、datasheet；meta- + data → metadata。

dataset 的 set 取一组；database 的 base 取组织、存储的基础。它们不是同一个技术对象的必然同义词。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. data — 数据；资料

**音标**：常见 /ˈdeɪtə/；美式也 /ˈdætə/

**先抓住这个画面**

先收下已记录、给定的事实，再拿它们做比较、推理或处理。

**怎么拆**

借自拉丁语 datum 的复数 data；datum 来自表示给的动词 dō 的分词形式。英语后来把 data 也发展成整体、不可数的资料概念。

**怎么变成今天的意思**

**拉丁语 datum；复数 data**  
被给出的东西；给定事项

↓

**英语 data**  
供记录、研究、处理的数据、资料

collect data 收集数据，analyse data 分析数据。学术语境常用 the data are，普通和商业语境也广泛用 the data is；不要只凭拉丁语来源判后一用法一律错。

**常见搭配与例句**

collect data；analyse data；raw data；data on something；data protection。

> The study collected data from three schools.

研究从三所学校收集了数据。

> The data are consistent with the earlier findings.

这些数据与先前发现一致。

> The data is stored on a secure server.

数据存储在安全服务器上。

**别混淆**

data 不只等于数字，文本、图像等也能构成数据；datum 是对应单数，但日常一个数据点也常直接说 a data point。

<a id="w-2"></a>

### 2. database — 数据库

**音标**：/ˈdeɪtəbeɪs/

**先抓住这个画面**

把相关数据有组织地放在一起，让人或系统能查找、更新和使用。

**怎么拆**

data 数据 + base 基地、基础，复合为集中组织数据的系统、集合名称。不是只有一个普通表格文件才能叫 database。

**怎么变成今天的意思**

**data 数据；base 组织、存放的基础**  
并列构词部分

↓

**database**  
有组织的数据集合、数据库

a customer database 客户数据库，search a database 查数据库。数据库可采用不同组织方式，并不全是同一种行列形式。

**常见搭配与例句**

a searchable database；update a database；database records。

> The library maintains a searchable database of old newspapers.

图书馆维护着一个可检索的旧报纸数据库。

> Please update the customer’s address in the database.

请更新数据库中这位顾客的地址。

**别混淆**

database 是有组织的数据集合或相关系统，datasheet 是说明数据、参数的一张资料表；名字都含 data，作用不同。

<a id="w-5"></a>

### 3. databases — 数据库〔复数〕

**音标**：/ˈdeɪtəbeɪsɪz/〔data 另有其他读法〕

**先抓住这个画面**

数据经过组织，能按需要查找、更新的集合或系统，是 database；多个这样的数据库就是 databases。

**怎么拆**

data 数据 + base 基地、基础 → database，整词加 -s，/s/ 后复数读 /ɪz/。不是末尾 e 去掉再加别的后缀。

**怎么变成今天的意思**

**data + base → database**  
集中组织、存取数据的集合或系统

↓

**database + -s → databases**  
多个数据库

research databases 研究数据库；customer databases 客户数据库。

**常见搭配与例句**

search databases 检索数据库；separate databases 独立数据库。

> The library provides access to several research databases.

图书馆提供几个研究数据库的访问入口。

> The two offices kept separate customer databases.

两个办公室各自维护客户数据库。

**别混淆**

数据库不限定为一个普通表格文件；数据怎样组织、怎样访问，有不同实现。

<a id="w-6"></a>

### 4. dataset — 数据集

**音标**：/ˈdeɪtəset/〔data 另有 /ˈdɑːtə/、/ˈdætə/ 等读法〕

**先抓住这个画面**

为了一个问题，把有关的数据收成一组，像把同一次调查的答卷装进同一份材料包，这一组就是 dataset。

**怎么拆**

data 数据 + set 一组的现代英语组合。data 原是拉丁 datum 的复数，英语又可把它作为整体资料使用。

**怎么变成今天的意思**

**拉丁 datum → data；英语 set 的集合义**  
给出的资料；一组材料

↓

**data + set → dataset**  
按某种范围、目的形成的一组数据

a training dataset 训练数据集；a survey dataset 调查数据集。

**常见搭配与例句**

a dataset of measurements 一组测量数据；analyse a dataset 分析数据集。

> The dataset contains measurements from fifty farms.

这个数据集包含五十家农场的测量结果。

> We used a smaller dataset to test the method.

我们用一个较小的数据集测试方法。

**别混淆**

dataset 是选定的一组数据，database 是组织、存取数据的数据库；一个数据库可以包含多个数据集。

<a id="w-7"></a>

### 5. datasets — 数据集〔复数〕

**音标**：/ˈdeɪtəsets/〔data 的其他读法也可带入〕

**先抓住这个画面**

不同调查、不同范围各收成一组数据，多组就叫 datasets。组与组可以比较，也可以按研究目的合并。

**怎么拆**

data + set → dataset，加 -s，/t/ 后读 /s/。data 内部的历史复数与整个组合的现代复数是不同层次。

**怎么变成今天的意思**

**data + set → dataset**  
一组有边界、用途的数据

↓

**dataset + -s → datasets**  
多个数据集

compare datasets 比较数据集；public datasets 公开数据集。

**常见搭配与例句**

combine datasets 合并数据集；large datasets 大型数据集。

> The researchers compared datasets from two years.

研究者比较了两个年份的数据集。

> The website offers several public datasets.

网站提供几个公开数据集。

**别混淆**

data 原来有拉丁复数历史，不妨碍完整名词 dataset 在英语中正常形成 datasets。

<a id="w-4"></a>

### 6. datasheet — 数据表；产品参数表

**音标**：/ˈdeɪtəʃiːt/

**先抓住这个画面**

把一个产品或材料的关键数据集中放在一页或一份说明里，方便查。

**怎么拆**

data 数据 + sheet 表、纸页，形成参数资料表名称。数字文件也沿用 sheet，不一定真只有一张纸。

**怎么变成今天的意思**

**data 数据；sheet 表、页**  
并列构词部分

↓

**datasheet**  
集中列出数据、参数的资料表

a product datasheet 产品参数表；check the datasheet 查看参数。电子器件、设备、材料说明中常见。

**常见搭配与例句**

a technical datasheet；a product datasheet；download the datasheet。

> The datasheet lists the sensor’s dimensions and operating range.

参数表列出了传感器的尺寸和工作范围。

> She compared the two products using their datasheets.

她利用两款产品的参数表进行比较。

**别混淆**

datasheet 多突出规格、数据，user manual 用户手册多说明怎样使用；datasheet 不等于数据库。

<a id="w-3"></a>

### 7. metadata — 元数据；描述数据的数据

**音标**：/ˈmetəˌdeɪtə/

**先抓住这个画面**

照片是内容，拍摄时间、位置、尺寸这些标签是在描述这份内容。

**怎么拆**

meta-“关于……自身” + data“数据”。

**怎么变成今天的意思**

**希腊 meta**  
在……之后、之间；复合词中也表转变

↓

**现代构词 meta-**  
进一步发展出关于某事自身、在更高分析层次上的用法

↓

**现代术语 metadata**  
用数据说明另一份数据的属性、结构或背景

一张照片的拍摄时间、一篇文章的作者、文件的格式，都可以是 metadata。它不是“没用的附加信息”，也不一定总显示在文件正文里；用途是让资料更容易识别、管理和解释。

**常见搭配与例句**

image metadata；metadata fields；remove metadata。

> The image metadata includes the date the photo was taken.

图像元数据包含拍摄日期。

> Accurate metadata makes the archive easier to search.

准确的元数据让档案更容易检索。

**别混淆**

data 与 metadata 是相对角色：描述某份资料的标签，对另一个分析任务来说也可以成为研究数据。

## 这一组要分清什么

data are 与 data is 都有实际使用场景；database 数据库，datasheet 参数表，metadata 描述数据的信息。

## 串起来练习

The database stores product data, while each datasheet summarizes one product’s specifications.

数据库存放产品数据，每份参数表则概述一个产品的规格。
