# 1577 · combination — 组合成整体与口语缩短

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

combo 套餐、小乐队、游戏连招，都是不同场景的一组；recombination 的科学义有更具体对象。

**COMBINATION：几个部分合在一起，日常也简称 combo**

combination → combo；recombination 看已存在的材料重新组合。

- **组合及口语简称**：combination · combo
- **重新组合**：recombination
- **combine → combination → combinations**：combinations

## 词形与演化规律

combine 相关名词 combination 的借入历史；combination 缩短配 -o → combo；re- + combination。

晚期拉丁 combinatio 接 combinare 结合，含 com- 一起与 bini 两个两个的材料，经法语进入英语。现代 combination + -s，可说多种组合。

## 逐词讲解

<a id="w-1"></a>

### 1. combination — 组合、结合；组合结果；密码组合

**音标**：英 /ˌkɒmbɪˈneɪʃən/；美 /ˌkɑːmbɪˈneɪʃən/

**先抓住这个画面**

不只问怎么合，还可以说合成的这一套是什么：衣服颜色搭配、几种因素共同作用、锁的数字序列，都能叫 combination。

**怎么拆**

经法语 combination 接晚期拉丁 combīnātiō，名词有独立借入路线；现代对应 combine 去 e 加 -ation，但不是一定先有英语动词才新造名词。

**怎么变成今天的意思**

**拉丁 com- + bīnī → 晚期拉丁 combīnāre → 法语 combiner → combine**  
一起 + 两两 → 联结、合在一起

↓

**拉丁 combīnātiō → 法语 combination → combination**  
结合行为；形成的一套组合

a combination of A and B 两者组合，in combination with 与某物结合，a combination lock 密码锁，the combination to the safe 保险箱密码。

**常见搭配与例句**

a combination of；in combination with；a combination lock。

> The dish uses a combination of sweet and sour flavours.

这道菜把甜味与酸味结合起来。

> She forgot the combination to the lock.

她忘了锁的密码。

**别混淆**

combination 可组合结果也可行为；锁的 combination 常数字顺序也重要，不可仅按数学组合不计顺序的专义理解所有日常用法。

<a id="w-4"></a>

### 2. combinations — 组合；搭配；组合方式〔复数〕

**音标**：英 /ˌkɒmbɪˈneɪʃənz/；美 /ˌkɑːmbəˈneɪʃənz/

**先抓住这个画面**

同样几种颜色，换个搭法就有不同 combinations。它说的是哪些东西搭在一起，以及搭成了怎样的一组。

**怎么拆**

combination + -s → combinations。可与 combine、-ation 的动作或结果名词对应学习；历史经法语接晚期拉丁 combinatio，远含 com- 一起 + bini 两个两个。

**怎么变成今天的意思**

**拉丁 com- + bini → combinare 结合 → combinatio**  
较早有成双结合的材料

↓

**法语 combination → 英语 combination → combinations**  
现代指多种组合，不限于两件东西

color combinations 是配色；different combinations of ingredients 是不同食材搭配；possible combinations 是可能组合。

**常见搭配与例句**

color combinations；different combinations；possible combinations。

> We tried several combinations of colors.

我们试了几种颜色搭配。

> The game allows many different combinations.

这个游戏允许很多不同的组合方式。

**别混淆**

来源里有两个两个，不意味着现代 combination 只能由两个成分组成。数学组合与日常搭配还要按各自语境理解。

<a id="w-2"></a>

### 3. combo — 组合、小乐队；套餐；连招

**音标**：英 /ˈkɒmbəʊ/；美 /ˈkɑːmboʊ/

**先抓住这个画面**

几样东西搭在一起：小乐队几个人一组，套餐几种食物一组，游戏几下有效衔接成连招。

**怎么拆**

combination 截短并配 -o 口语结尾，常先见于小乐队等用法，再扩到组合套餐、动作连段。不是 com + bo 两个正式词根。

**怎么变成今天的意思**

**combination 的口语缩短 → combo**  
组合，常见小乐队称呼

↓

**现代场景扩展**  
食品组合、套餐；动作组合、游戏连招

a jazz combo 爵士小乐队，a combo meal 套餐，a winning combo 好用组合，perform a combo 打出连招。

**常见搭配与例句**

a jazz combo；a combo meal；a winning combo；perform a combo。

> A jazz combo played in the café.

一支爵士小乐队在咖啡馆演奏。

> She ordered a combo meal with a drink.

她点了一份配饮料的套餐。

**别混淆**

combo 较口语，combination 更一般、正式；游戏连招通常强调有效衔接，不是随便按很多次键就一定算。

<a id="w-3"></a>

### 4. recombination — 重新组合；重组〔生物、物理等〕

**音标**：英 /ˌriːkɒmbɪˈneɪʃən/；美 /ˌriːkɑːmbɪˈneɪʃən/

**先抓住这个画面**

重新合在一起这件事或形成的新组合；进入生物、物理课本后，可是特定机制的名称，不只说随便拼东西。

**怎么拆**

re- + combination，也与 recombine 的动作名词相对应。保留前缀和名词的分层，不把 re- 误认成 combination 内部的原生字母。

**怎么变成今天的意思**

**拉丁 com- + bīnī → 晚期拉丁 combīnāre → 法语 combiner → combine**  
一起 + 两两 → 联结、合在一起

↓

**re- + combination → recombination**  
重新结合的过程；再有各学科专义

genetic recombination 遗传重组，electron-hole recombination 电子空穴复合，the recombination of ideas 想法的重新组合。

**常见搭配与例句**

genetic recombination；the recombination of；recombination processes。

> The chapter introduces genetic recombination.

这一章介绍遗传重组。

> The design emerged from a recombination of older ideas.

这个设计来自对旧想法的重新组合。

**别混淆**

recombination 重组，不等于每次都 mutation 突变；技术名词不能仅由再加组合推断完整机制。

## 这一组要分清什么

combo 口语与 combination 一般用法；recombination 重新组合非完全凭空新造。

## 串起来练习

The small combo used an unusual combination of instruments.

小乐队采用了一种不常见的乐器组合。
