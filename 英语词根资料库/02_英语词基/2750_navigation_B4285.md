# 2750 · navigation — 航行；导航

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

navigation 经法语、拉丁航行一支传来，navigational 是相关形容词。circumnavigation 在前加绕行成分，常指环航。

**NAVIGATION：找到路线，并沿路线到达**

船走海路，车辆和网页也能借导航概念组织移动。

- **路线与属性**：navigation · navigational
- **绕行旅程**：circumnavigation

## 词形与演化规律

navigation system、navigational aid、circumnavigation of the globe；现代数字界面的 navigation 已是比喻扩展。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. navigation — 导航；航行；页面浏览路径

**音标**：/ˌnævɪˈɡeɪʃən/

**先抓住这个画面**

navigation 是弄清“我在哪里、接下来往哪里走”，最初在海上，后来也在道路和网页里。

**怎么拆**

现代可对应 navigate + -ion；历史经法语来自拉丁语 nāvigātiō，英语名词并非必须从英语动词派生。

**怎么变成今天的意思**

![navigation 的词源演化](../assets/evolution/navigation-d70d5a79.svg)

从驾驶船只扩展到为车辆定位和引路；网站 navigation 是帮助用户找到各个页面的结构。

**常见搭配与例句**

satellite navigation；a navigation system；website navigation。

> The boat carried basic navigation equipment.

船上带着基本的导航设备。

> Clear navigation helps users find the right page.

清晰的导航帮助用户找到所需页面。

**别混淆**

navigation 关注位置与路线；transportation 关注把人或物送到目的地。

<a id="w-2"></a>

### 2. navigational — 导航的；航行定位的

**音标**：/ˌnævɪˈɡeɪʃənəl/

**先抓住这个画面**

用来回答“我在哪、下一步往哪走”的设备、信号或安排。

**怎么拆**

navigation + -al；navigation 本身经法语或拉丁 navigatio 借入，接 navigare。

**怎么变成今天的意思**

**拉丁语 navis**  
船

↓

**拉丁语 navis + agere → navigare**  
船 + 驱动 → 驾船航行

↓

**拉丁语 navigatio → 法语 navigation / 英语 navigation**  
航行、确定路线

↓

**英语 navigation + -al → navigational**  
与定位、航行或找路有关的

navigational aids 可以是灯塔、浮标或仪器；软件里的 navigational elements 是菜单、链接等帮助用户移动的组件。

**常见搭配与例句**

navigational aids；navigational equipment；a navigational error。

> The vessel carries modern navigational equipment.

这艘船配有现代导航设备。

> The page keeps its navigational links in the left column.

页面把导航链接放在左侧栏。

**别混淆**

navigable 说对象能让人通行；navigational 说它与导航活动有关。

<a id="w-3"></a>

### 3. circumnavigation — 环航；环绕一周的旅程

**音标**：英 /ˌsɜːkəmˌnævɪˈɡeɪʃən/；美 /ˌsɜːrkəmˌnævɪˈɡeɪʃən/

**先抓住这个画面**

把出发点、整圈路线和返抵这件事看成一次完整行程。

**怎么拆**

circumnavigate + -ion，-ate 对应名词 -ation；英语名词从环航动词派生。

**怎么变成今天的意思**

**拉丁语 navis**  
船

↓

**拉丁语 navis + agere → navigare**  
船 + 驱动 → 驾船航行

↓

**拉丁语 circum- + navigare → circumnavigare / circumnavigatus**  
围绕 + 航行 → 绕行一周

↓

**英语 circumnavigate**  
环航、绕行

↓

**英语 circumnavigate → circumnavigation**  
环航 → 环航行动或行程

a circumnavigation of the world 是环球行程；a solo circumnavigation 强调独自完成。词本身不规定必须不停靠或必须使用同一种交通工具。

**常见搭配与例句**

complete a circumnavigation；a solo circumnavigation；a circumnavigation of the island。

> The book describes a difficult circumnavigation of the world.

这本书描写了一次艰难的环球航行。

> Their circumnavigation of the island ended at the harbour where it began.

他们绕岛一周后回到了出发的港口。

**别混淆**

voyage 只表示一次远航；circumnavigation 还包含绕目标一周的路线要求。

## 这一组要分清什么

navigation 是导航活动，navigator 是导航者或相关工具；环航是否绕地球，要看 circumnavigation 后的对象。

## 串起来练习

Accurate navigational information supported the ship’s circumnavigation.

准确的航行信息支持了船只环航。
