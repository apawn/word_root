# 0851 · return — 返回动作与不同返回者称呼

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

return 来自法语转回词。returner 可体育回击或返岗者，returnee 常指某个返归群体，语义有重合。

**RETURN：回来；RETURNER、RETURNEE：两种人物词**

return 已有精讲，两个后缀相邻对照，避免套主动被动公式。

- **基本动作与人物**：return · returner · returnee

## 词形与演化规律

return + -er → returner；return + -ee → returnee。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [return](#w-1) | 英 /rɪˈtɜːn/；美 /rɪˈtɜːrn/ | 返回；归还；回报；申报表 |
| [returner](#w-2) | 英 /rɪˈtɜːnə/；美 /rɪˈtɜːrnər/ | 返回者；重返工作者；接球回击者 |

## 逐词讲解

<a id="w-1"></a>

### 1. return — 返回；归还；回报；申报表

**音标**：英 /rɪˈtɜːn/；美 /rɪˈtɜːrn/

**先抓住这个画面**

沿着关系往回走：人回原处，书回主人手里，投入之后收益回到出资者手中。

**怎么拆**

动词经古法语 retorner / retourner，并受中世纪拉丁语 retornare 影响；名词经法语 retorn 等及中世纪拉丁语 returnum 借入。现代 re- + turn 容易看懂，但名词不是单一路线的后来产物。

**怎么变成今天的意思**

**希腊语 tornos → 拉丁语 tornus / tornare**  
画圆、车削的工具 → 在车床上旋转加工

↓

**古法语 retorner / retourner；中世纪拉丁语 retornare**  
转回、返回

↓

**并行名动词：法语 retorn 等 → 英语 return**  
返回、归还；正式报送的信息及回报

return home 不用 to，return to school 要用 to；return a book 是还书。tax return 是向税务机关提交的申报资料，不是“退税”，退税通常是 tax refund。

**常见搭配与例句**

return to；return something to someone；in return；a tax return。

> Please return the book to the library by Friday.

请在周五之前把书还给图书馆。

> They returned home after midnight.

他们午夜过后才回到家。

> She filed her tax return online.

她在网上提交了纳税申报表。

**别混淆**

go back 强调回去；return 可回去也可回来，且较正式。return 的投资回报可能是负数，不保证赚钱。

<a id="w-2"></a>

### 2. returner — 返回者；重返工作者；接球回击者

**音标**：英 /rɪˈtɜːnə/；美 /rɪˈtɜːrnər/

**先抓住这个画面**

按做返回这个动作称人；体育里是把球接过来再回击、回跑的人。

**怎么拆**

return + -er，执行 return 某种动作的人。工作语境 returner 可说离开一段时间后重返岗位者。

**怎么变成今天的意思**

**法语 retourner → 英语 return**  
转回来、回来；最终接拉丁旋转词族

↓

**return + -er／-ee**  
回来、返还或回击的人；特定返回群体成员

a returner to work 重返工作者，a kick returner 接开球并回跑的球员，a good returner 网球等项目中善于接发球的人。

**常见搭配与例句**

a returner to work；a kick returner；an experienced returner。

> The programme supports returners to work after a career break.

项目支持职业中断后重新工作的人。

> She is one of the strongest returners in the tournament.

她是本届比赛接发球最强的选手之一。

**别混淆**

returner 与 returnee 含义可重合，不能只凭 -er/-ee 就断言前者主动、后者被动；returnee 也可以自己回来。

<a id="w-3"></a>

### 3. returnee — 归来者；回国、返乡或重返某领域的人

**音标**：英 /rɪˌtɜːˈniː/；美 /rɪˌtɜːrˈniː/

**先抓住这个画面**

把回来的人看成一个有共同经历的群体：海外回来的人、重新回到工作岗位的人。

**怎么拆**

return + -ee，通常末尾重读。-ee 在此形成参与某过程的人，不必是被别人送回来，所以不机械等同于被动接受者。

**怎么变成今天的意思**

**法语 retourner → 英语 return**  
转回来、回来；最终接拉丁旋转词族

↓

**return + -er／-ee**  
回来、返还或回击的人；特定返回群体成员

↓

**return + -ee → returnee**  
经历返回的人，尤某一返归群体成员

overseas returnees 海外归来者，returnees to the workforce 重返劳动力市场者。实际返到哪里由补语说明。

**常见搭配与例句**

overseas returnees；returnees to work；a group of returnees。

> The centre provides advice for overseas returnees.

中心为海外归来者提供咨询。

> Several returnees joined the training after years away from work.

几位多年未工作的返岗者参加了培训。

**别混淆**

returnee 不自带海归高学历等评价；只说返回经历。refugee、employee 等 -ee 词各自历史、角色不同，不一概套成被动。

## 这一组要分清什么

-ee 在 returnee 中不一定被动；具体返回工作、国家还是场地，要看上下文。

## 串起来练习

The course welcomes both new workers and returnees.

课程欢迎新入职者，也欢迎重返工作的人。
