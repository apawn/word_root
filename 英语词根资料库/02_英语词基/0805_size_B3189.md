# 0805 · size — 大小、规格与调整规模

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

size 的大小义先接规定的量与规格，才成为现代通用大小词。施胶材料同形义另行保留来源不确定，不硬凑。

**SIZE：问它有多大、该用哪个规格**

先看 size，再把 sized 的具体尺寸和 sizable 的相当大分开；最后按超出、重设、缩减看前缀变化。

- **核心与性质**：size · sized · sizable
- **超出通常尺寸**：oversize · outsize · supersize
- **调整方向**：resize · downsize
- **size → sizes：规定的量到大小、尺码**：size · sizes

## 词形与演化规律

size → sized、sizable；over-、out- 超出 → oversize、outsize；re- 重设 → resize；down- 缩减 → downsize；共享 supersize。

法语 assise 缩短形式的历史，尺寸义与施胶材料义分源处理。

## 逐词讲解

<a id="w-1"></a>

### 1. size — 大小；尺寸、尺码；按大小分类、调整

**音标**：/saɪz/

**先抓住这个画面**

不只问大不大，还能问这东西占多大空间、该选哪个规格。

**怎么拆**

尺寸义经古法语 assise 的缩短形式入英语，早期与规定的量、规格有关，后来泛指大小。另有绘画、造纸的施胶材料义，来源关系不明，不强串到尺寸义里。

**怎么变成今天的意思**

**古法语 assise 的缩短形式 sise、cise → 中古英语 sise**  
规定、限度；规定的量

↓

**英语 size**  
数量、规格 → 大小、尺寸；按尺寸调整

the size of the room 房间大小，What size? 什么尺码，size ten 十号尺码；size up 还可说打量、判断一个人或局面。

**常见搭配与例句**

the size of；What size?；in different sizes；size up。

> What size shoes do you wear?

你穿多大码的鞋？

> The boxes are the same size but different shapes.

这些箱子大小相同，但形状不同。

**别混淆**

size 大小，shape 形状；两个箱子可以 the same size but different shapes。size 也不只长度，衣服尺码可能综合多项尺寸。

<a id="w-2"></a>

### 2. sized — 某种大小的；按尺寸处理的

**音标**：/saɪzd/

**先抓住这个画面**

通常等前面告诉你多大：medium-sized 是中等大小，不是只知道一个孤立的有大小。

**怎么拆**

size + -ed，保留 e 后加 d，形成动词过去形式或形容词；末尾读 /zd/。在复合修饰语中常接大小说明。

**怎么变成今天的意思**

**古法语 assise 的缩短形式 sise、cise → 中古英语 sise**  
规定、限度；规定的量

↓

**英语 size**  
数量、规格 → 大小、尺寸；按尺寸调整

↓

**size + -ed → sized**  
具有某种大小；已按尺寸处理

a medium-sized bag 中号包，similarly sized rooms 大小相近的房间；修饰语中的连字符是正常书写，不等于再单列一个新词。

**常见搭配与例句**

medium-sized；similarly sized；differently sized。

> They booked two similarly sized rooms.

他们订了两间大小相近的房间。

> A medium-sized bag should be enough for the trip.

一个中号包应该就够这趟旅行用了。

**别混淆**

size 是大小名词或动词，sized 常是已处理或带尺寸性质的形式；不要把 sized 单独当“大”的同义词。

<a id="w-9"></a>

### 3. sizes — 大小、尺寸、尺码〔复数〕；测量大小、按尺寸分级〔第三人称单数〕

**音标**：/ˈsaɪzɪz/

**先抓住这个画面**

东西有大有小，衣服有不同尺码，这些一档档、一个个大小可以说 sizes。动词则在看它多大、按大小整理。

**怎么拆**

size + -s，原词 s 发 /z/，后加 /ɪz/。尺寸 size 接古法语 assise 的缩短形式，早期规定的量、规格后来泛指大小；施胶材料的同形词另有不明关系。

**怎么变成今天的意思**

**古法语规定、规格材料的缩短形式 → size**  
规定量 → 大小、尺寸

↓

**size + -s → sizes**  
多个尺寸、尺码；某人测量或按大小分级

different sizes 不同大小；shoe sizes 鞋码；all shapes and sizes 各种形状、大小。

**常见搭配与例句**

comes in three sizes 有三个尺码；sizes up the room 打量、估计房间情况，属 size up 搭配。

> The shirt comes in four sizes.

这件衬衫有四个尺码。

> We sorted the boxes into different sizes.

我们按大小给盒子分了类。

**别混淆**

sizes 可以是一个个标准尺码，也可以是一般大小。衣服的 size 不能单凭数字跨品牌等同，词义先只是这套标示里的尺寸。

<a id="w-3"></a>

### 4. sizable — 相当大的；可观的

**音标**：/ˈsaɪzəbəl/

**先抓住这个画面**

不是普通地有尺寸，而是大到值得专门提一句：可观的一笔钱、数量或差距。

**怎么拆**

size + -able，常规写 sizable，也见 sizeable。这里成词后的固定义是相当大，不能机械译成能被定尺寸。

**怎么变成今天的意思**

**古法语 assise 的缩短形式 sise、cise → 中古英语 sise**  
规定、限度；规定的量

↓

**英语 size**  
数量、规格 → 大小、尺寸；按尺寸调整

↓

**size + -able → sizable**  
具有显著大小 → 相当大的

a sizable sum 一笔可观金额，a sizable crowd 相当多的人；可修饰抽象差距、比例。

**常见搭配与例句**

a sizable sum；a sizable crowd；a sizable difference。

> They received a sizable donation.

他们收到了一笔可观的捐款。

> There is a sizable gap between the two estimates.

两项估算之间有相当大的差距。

**别混淆**

sizable 强调规模可观，sized 常需前文交代具体大小；a sizable company 与 a medium-sized company 重点不同。

<a id="w-4"></a>

### 5. oversize — 超常尺寸的；特大号的

**音标**：英 /ˈəʊvəsaɪz/；美 /ˈoʊvərsaɪz/

**先抓住这个画面**

比通常的标准、用途或比例更大；可以是需要特殊运输，也可以是有意设计的宽大款式。

**怎么拆**

over- 超出 + size 大小，组合成超出通常尺寸的形容词，也有相关动词用法。oversized 是很常见的另一形容词形式。

**怎么变成今天的意思**

**古法语 assise 的缩短形式 sise、cise → 中古英语 sise**  
规定、限度；规定的量

↓

**英语 size**  
数量、规格 → 大小、尺寸；按尺寸调整

↓

**over- + size → oversize**  
超出通常尺寸 → 特大、超大

oversize luggage 超尺寸行李，an oversize coat 宽大外套；具体超出什么标准由场景确定。

**常见搭配与例句**

oversize luggage；an oversize load；an oversize coat。

> The airline charges extra for oversize luggage.

航空公司对超尺寸行李另行收费。

> He wore an oversize coat over his suit.

他在西装外穿了一件宽大的外套。

**别混淆**

oversize 不一定是买错尺码，服装可能有意宽大；overweight 说重量超标，两个标准不同。

<a id="w-5"></a>

### 6. downsize — 缩减规模；裁员；搬入较小住房

**音标**：/ˈdaʊnsaɪz/

**先抓住这个画面**

把现在的一整套规模往小里收：公司缩减人员，家庭也可能从大房子搬到小房子。

**怎么拆**

down- 向下、减少 + size。现代常用于组织、产品和住房规模调整，意义由具体对象决定。

**怎么变成今天的意思**

**古法语 assise 的缩短形式 sise、cise → 中古英语 sise**  
规定、限度；规定的量

↓

**英语 size**  
数量、规格 → 大小、尺寸；按尺寸调整

↓

**down- + size → downsize**  
把规模往小里改 → 缩减规模

downsize the workforce 缩减员工规模，downsize to a smaller home 换住较小房子；公司语境可能委婉指裁员。

**常见搭配与例句**

downsize the workforce；downsize the business；downsize to a flat。

> The company plans to downsize its workforce.

公司计划缩减员工规模。

> They decided to downsize to a smaller flat.

他们决定换住一套较小的公寓。

**别混淆**

resize 只说明改尺寸，downsize 明确变小；downsize 公司不一定等于公司关闭。

<a id="w-6"></a>

### 7. resize — 调整大小、尺寸

**音标**：/ˌriːˈsaɪz/

**先抓住这个画面**

把原有尺寸改成需要的尺寸，既可以缩小，也可以放大。

**怎么拆**

re- 重新 + size 按大小处理，现代常见于图片、窗口和物件尺寸调整；re- 不限定调整的方向。

**怎么变成今天的意思**

**古法语 assise 的缩短形式 sise、cise → 中古英语 sise**  
规定、限度；规定的量

↓

**英语 size**  
数量、规格 → 大小、尺寸；按尺寸调整

↓

**re- + size → resize**  
重新设定尺寸 → 调整大小

resize an image 调整图片大小，resize a window 调整窗口大小，resize a ring 改戒指尺寸。

**常见搭配与例句**

resize an image；resize a window；resize a ring。

> Resize the image before uploading it.

上传前先调整图片大小。

> You can resize the window by dragging its corner.

你可以拖动窗口一角来调整它的大小。

**别混淆**

resize 改大小，crop 裁掉边缘；两者都可能改变图像尺寸，但做的动作不同。

<a id="w-7"></a>

### 8. supersize — 放大；升级为特大份；特大号的

**音标**：英 /ˈsuːpəsaɪz/；美 /ˈsuːpərsaɪz/

**先抓住这个画面**

把原有尺寸或分量往上加一档，最容易想到餐饮里把普通份换成大份。

**怎么拆**

英语 super- + size，作为动词让尺寸增大，也可作形容词表示特大规格。

**怎么变成今天的意思**

**拉丁 super**  
在上方、超过、越过

↓

**英语构词成分 super-**  
超出一般程度；在上、额外或超过某界限

↓

**英语 super- + size → supersize**  
做成超大尺寸、份量；特大号的

常见于餐饮和营销，也能比喻扩大项目规模。它不提供统一的毫升或重量，具体大小仍取决于产品。

**常见搭配与例句**

supersize a meal；a supersize portion。

> They decided not to supersize their drinks.

他们决定不把饮料升级成特大杯。

> The company plans to supersize the exhibition next year.

公司计划明年大幅扩大展览规模。

**别混淆**

enlarge 是较中性的放大；supersize 带显著加大、常带消费宣传色彩。

<a id="w-8"></a>

### 9. outsize — 特大的；超常规模的

**音标**：英 /ˈaʊtsaɪz/；美 /ˈaʊtsaɪz/

**先抓住这个画面**

大到跑到普通规格之外；也能说影响、作用比通常预期更大。

**怎么拆**

out- 超出 + size，形成超常尺寸的表达。outsize 和 outsized 都可见，现代还常修饰抽象影响。

**怎么变成今天的意思**

**古法语 assise 的缩短形式 sise、cise → 中古英语 sise**  
规定、限度；规定的量

↓

**英语 size**  
数量、规格 → 大小、尺寸；按尺寸调整

↓

**out- + size → outsize**  
超出正常规格 → 特大、超常

an outsize suitcase 特大手提箱，an outsize influence 异常大的影响；不是只说位置在尺寸外面。

**常见搭配与例句**

an outsize suitcase；an outsize role；an outsize influence。

> The small country has an outsize influence on the industry.

这个小国对该行业有着超出其规模的影响力。

> An outsize suitcase blocked the narrow passage.

一只特大手提箱堵住了狭窄通道。

**别混淆**

outsize 与 oversize 在具体大小上有重合；outsize influence 更突出影响超过通常比例，不是衣服尺码。

## 这一组要分清什么

sizable 相当大，sized 常由修饰语交代多大；resize 不限定放大缩小，downsize 才说明缩小。

## 串起来练习

We resized the image without changing the size of the page.

我们调整了图片大小，没有改变页面尺寸。
