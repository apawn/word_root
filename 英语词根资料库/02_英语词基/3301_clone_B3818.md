# 3301 · clone — 嫩枝的植物学命名，进入同源繁殖与复制

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

先记植物嫩枝这个真实词源，再进入细胞、生物和电脑的不同用法。共通是来源与复制，具体机制不全一样。

**CLONE：一枝延续出一群，再走向复制比喻**

clone → clonal。

- **克隆、复制及相关性质**：clone · clonal

## 词形与演化规律

希腊 klon 嫩枝 → 植物学 clone；名词转动词；去 e 接 -al → clonal。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. clone — 克隆体、克隆群；复制品；克隆、复制

**音标**：英 /kləʊn/；美 /kloʊn/

**先抓住这个画面**

植物的一段枝条长出新植株，是旧命名的直观入口。后来细胞同源繁殖、复制现有产品或软件，也会用 clone。

**怎么拆**

1903 年植物学术语，取希腊 klon 嫩枝的拉丁化形式；名词后来发展出动词和复制比喻。不是由电脑文件复制这个用法倒推生物学。

**怎么变成今天的意思**

**希腊 klon 嫩枝 → 1903 年植物学 clone**  
由原植株材料繁殖的一组植物命名

↓

**clone 扩展至细胞、其他生物及复制比喻**  
同源复制个体、群体；复制、仿制

↓

**clone + -al → clonal**  
克隆相关、共同细胞或个体来源的

a plant clone 植物克隆体、克隆群；clone a repository 克隆代码仓库；a cheap clone 廉价仿制品。生物语境侧重无性繁殖、共同来源，软件操作取复制比喻。

**常见搭配与例句**

a plant clone；clone a repository；a clone of an existing product。

> The plants in this group belong to a single clone.

这组植物属于同一个克隆群。

> The developer cloned the repository to a local computer.

开发者把代码仓库克隆到了本地电脑。

**别混淆**

生物克隆不等于性格、经历全相同，也不等于每次都人工制造；自然无性繁殖也可形成克隆。

<a id="w-2"></a>

### 2. clonal — 克隆的；同一细胞或个体来源繁殖的

**音标**：英 /ˈkləʊnəl/；美 /ˈkloʊnəl/

**先抓住这个画面**

一群细胞沿着分裂往上追，来自同一个祖先细胞，就有 clonal 的来源关系。重点不只是长得相像。

**怎么拆**

clone + -al，去末尾 e → clonal。-al 形成相关性质形容词；不是 clone 加所有格。

**怎么变成今天的意思**

**希腊 klon 嫩枝 → 1903 年植物学 clone**  
由原植株材料繁殖的一组植物命名

↓

**clone 扩展至细胞、其他生物及复制比喻**  
同源复制个体、群体；复制、仿制

↓

**clone + -al → clonal**  
克隆相关、共同细胞或个体来源的

clonal growth 克隆生长；clonal population 克隆群体；clonal expansion 克隆扩增，常说同源细胞数量扩大。

**常见搭配与例句**

clonal growth；clonal expansion；a clonal population。

> The study follows the clonal expansion of a cell population.

研究追踪一个细胞群的克隆扩增。

> Some plants spread through clonal growth.

有些植物通过克隆生长扩展。

**别混淆**

clonal 强调共同来源、繁殖关系，不保证后续永远完全无变异；clonal growth 也不直接等于人工实验操作。

## 这一组要分清什么

clonal 不只表示看着相似；clone 不保证个体经历和性格一样，也不必都人工形成。
