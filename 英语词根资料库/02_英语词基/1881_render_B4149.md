# 1881 · render — 给回、交出、呈现的旧材料，发展出多种固定结果表达

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

计算机渲染只是常用分支之一。让文件无法读取、把诗译成英语、给出帮助都能用 render；后面的结构比一个中文译词更关键。

**RENDER：做出、交出某种结果，场景决定译法**

render → renderer；先分使成为、呈现与渲染，再看工具词。

- **多种呈现、结果动作与工具**：render · renderer
- **render → surrender：交还、交出去**：render · surrender
- **render → rendered：给出、呈现、使成**：render · rendered
- **render → rendering：呈现、译法与抹灰**：rendering
- **sur- 交到对方 + render 交还 → surrendered**：surrendered

## 词形与演化规律

reddere → rendere → rendre → render；render + -er → renderer。另有 rend + -er 的冷门同形人物词，不作主线。

古法语 sur- + rendre 构成 surrendre，发展为交出控制或所有权、投降。

法语 rendre 接拉丁给回词族，现代直接加完整 ed。

render 经法语 rendre 接拉丁返还、交付词族，现代呈现、译文、抹灰等义各有发展。加 -ing 保留原词；这里不是 rend 撕裂加 -er。

surrender 接法语 surrendre 交出，现代加完整 -ed，/r/ 等后读 /d/。放弃抵抗与交出某物要按宾语看。

## 逐词讲解

<a id="w-1"></a>

### 1. render — 使成为；提供、作出；翻译、表现；渲染；熬出油脂；抹灰层

**音标**：英 /ˈrendə/；美 /ˈrendər/

**先抓住这个画面**

可以先分几种场景：render it useless 让它变得无用；render assistance 提供帮助；render a scene 把场景表现成图像。不要每次都死译成渲染。

**怎么拆**

经古法语 rendre 接拉丁 reddere 给回及后来 rendere 形式。交出、呈现与结果状态等意义较早已分化；烹饪熬出脂肪、建筑抹灰等也有固定用法。

**怎么变成今天的意思**

**拉丁 red- 回 + dare 给的材料 → reddere 给回**  
晚期、通俗拉丁 rendere 等形式

↓

**古法语 rendre → 中古英语 renderen → render**  
交出、呈现、译出、使成某状态等

↓

**render + -er → renderer**  
做呈现动作的人、软件或硬件过程

render someone speechless 使人说不出话；render assistance 提供帮助；render into English 译成英语；render an image 渲染图像。

**常见搭配与例句**

render something useless；render into；render an image。

> The update rendered the old files unreadable.

更新使旧文件无法读取。

> The program renders the model as a shaded image.

程序把模型渲染成带明暗效果的图像。

> The poem was rendered into English.

这首诗被译成了英语。

**别混淆**

render 在图形学里是把数据、模型算成可见表示，不只指加滤镜或 AI 画图；render someone helpless 是使某人无助，不是画出那个人。

<a id="w-4"></a>

### 2. rendered — 呈现了、译成了；使处于某状态〔过去式、过去分词〕

**音标**：英 /ˈrendəd/；美 /ˈrendərd/

**先抓住这个画面**

把一种内容、服务或结果交出来，是 rendered 的常用感觉。画面被呈现、句子被译出，或某个变化把东西弄成新状态，都能这样说。

**怎么拆**

render 经古法语 rendre 接拉丁 reddere 给回、后来的 rendere 等形式，较早已有交出、使成、呈现等分支。现代直接加完整 -ed，词尾为浊音，读 /d/。

**怎么变成今天的意思**

**拉丁给回词族 → 古法语 rendre → render**  
交出 → 提供、呈现、使成

↓

**render + -ed → rendered**  
已经呈现、译出或使成某状态

rendered in English 译成英语；rendered useless 弄得没用了；rendered the scene 呈现了场景。

**常见搭配与例句**

services rendered 已提供的服务；beautifully rendered 描绘、演绎得优美。

> The damaged cable rendered the lamp useless.

损坏的电线使灯无法使用。

> The poem was rendered into simple English.

这首诗被译成了简单英语。

**别混淆**

rendered something useless 是使它失去用处；rendered something in blue 是用蓝色呈现它。后面的补语能帮你迅速认清意思。

<a id="w-5"></a>

### 3. rendering — 呈现、渲染；效果图；译文、演绎；抹灰〔名词、分词〕

**音标**：英、美 /ˈrendərɪŋ/

**先抓住这个画面**

把同一个内容换成别人能看到、读懂的形式，是 rendering 的常见方向：模型变图像，外语变译文，作品变一次演绎。建筑里又有抹灰的专门用法。

**怎么拆**

render + -ing → rendering，保留原词。render 经法语 rendre 接拉丁返还、交付的词族，呈现、翻译、使成为等意义后来分别发展。

**怎么变成今天的意思**

**拉丁 reddere 等返还、交付材料 → 法语 rendre → render**  
近源是给回、交出等词义，不从现代 rend 撕裂加 -er 推出

↓

**render + -ing → rendering**  
动作名词、分词，后来用于译法、形象呈现及各种专门活动

a rendering of a building 是建筑效果图；image rendering 是图像渲染；an English rendering 是英语译文；rendering a wall 是给墙抹灰。

**常见搭配与例句**

a rendering of the building；image rendering；an English rendering。

> The architect showed us a rendering of the new building.

建筑师给我们看了新楼的效果图。

> This English rendering of the poem is easy to follow.

这首诗的这个英语译本很容易读懂。

> The workers are rendering the outside wall.

工人们正在给外墙抹灰。

**别混淆**

先看对象：模型、图像常说渲染，文本常说译法，墙体常说抹灰。几种专门义按词史和语境理解，不逐字互译。

<a id="w-2"></a>

### 4. renderer — 渲染器；作呈现、处理的人或装置

**音标**：英 /ˈrendərə/；美 /ˈrendərər/

**先抓住这个画面**

render 是把数据、模型表现成图像的动作，renderer 就是完成这件事的软件、硬件过程或系统。-er 在这里常指工具。

**怎么拆**

render + -er → renderer，中古英语已有相应人物名。现代图形计算把它固定用作渲染组件名；较少见行业义另按处理对象理解。

**怎么变成今天的意思**

**拉丁 red- 回 + dare 给的材料 → reddere 给回**  
晚期、通俗拉丁 rendere 等形式

↓

**古法语 rendre → 中古英语 renderen → render**  
交出、呈现、译出、使成某状态等

↓

**render + -er → renderer**  
做呈现动作的人、软件或硬件过程

↓

**render + -er → renderer**  
进行呈现、处理的人或工具 → 图形渲染组件

a 3D renderer 三维渲染器；a software renderer 软件渲染器；the browser’s renderer 浏览器渲染组件。

**常见搭配与例句**

a 3D renderer；a software renderer。

> The renderer calculates shadows from the scene data.

渲染器根据场景数据计算阴影。

> The application uses a separate renderer for the preview.

这个应用使用单独的渲染器生成预览。

**别混淆**

renderer 是做渲染的工具、过程组件，render 可指动作或渲染结果；它也不同于单纯保存已有图片的查看器。

<a id="w-3"></a>

### 5. surrender — 投降；交出、放弃〔控制、权利等〕；投降、交出〔名词〕

**音标**：英 /səˈrendə/；美 /səˈrendər/

**先抓住这个画面**

原来东西在你手里、决定权在你这里，现在你把它交给另一方。交的是自己或抵抗，就叫投降；交的是控制权，也可以用 surrender。

**怎么拆**

古法语 sur- 在上、越过 + rendre 交还 → surrendre 交出，经法语进入英语。rendre 往前接拉丁 reddere 给回；现代不能把 surrender 拆成表示确定的 sure 和 rend。

**怎么变成今天的意思**

**拉丁 reddere → 法语 rendre**  
给回、交出、呈交

↓

**法语 sur- + rendre → surrendre → surrender**  
交给另一方 → 交出、屈服、投降

surrender to someone 向某人投降；surrender control 交出控制权；surrender a document 交出证件；refuse to surrender 拒绝投降。

**常见搭配与例句**

surrender without a fight；the surrender of control。

> The soldiers were ordered to surrender.

士兵们接到了投降的命令。

> She was unwilling to surrender control of the project.

她不愿交出项目的控制权。

**别混淆**

surrender 可不及物，直接说投降；及物时要说交出什么。give up 范围更广，surrender 更容易带有控制、抵抗被让出的意味。

<a id="w-6"></a>

### 6. surrendered — 投降了；交出了；放弃了〔过去形式〕

**音标**：英 /səˈrendəd/；美 /səˈrendɚd/

**先抓住这个画面**

原来还握在自己手里、还在抵抗，后来把控制权交给对方，就是 surrendered。交出去的可以是自己、物品，也可以是一项权利。

**怎么拆**

surrender + 完整 -ed → surrendered，末尾读 /d/。接法语 surrendre 交出，sur- 交到对方、越过 + rendre 交还；现代学习可连着 render 交出理解。

**怎么变成今天的意思**

**法语 sur- + rendre → surrendre → surrender**  
较早用于把东西交到另一方权力、所有之下

↓

**放弃抵抗、交出物品等义 + -ed → surrendered**  
现代有不接宾语的投降，也有接宾语的交出

surrendered to 是向某方投降；surrendered control 是交出控制权；surrendered a claim 是放弃一项要求、主张。

**常见搭配与例句**

surrendered to；surrendered control；surrendered a claim。

> In the film, the soldiers surrendered at dawn.

电影里，士兵们在黎明时投降了。

> The character surrendered the keys without saying a word.

那个人物一言不发地交出了钥匙。

**别混淆**

surrendered 说交出、放弃控制，不一定都是军事投降。He surrendered the keys 是他交出了钥匙，句中的宾语帮助确定意思。

## 这一组要分清什么

render + 宾语 + 形容词常表示使成某状态；renderer 多说工具或相应人员，不能一律读成画家。

## 串起来练习

The renderer failed, which rendered the preview unavailable.

渲染器出错，导致预览无法使用。
