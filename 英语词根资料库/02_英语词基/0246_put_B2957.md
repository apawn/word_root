# 0246 · put — 放到某位置、状态；投入与产出

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

put 经中古英语 putten 等发展，早期有推、放关联，更远来源不完全确定。原形、过去式、过去分词同为 put。

**PUT：把对象放到某个位置或关系里**

杯子放桌上，想法放进文字，数据送进系统；重点是位置、状态发生了安置。

- **基本动作**：put · putting
- **流程中的进、出与处理量**：input · output · throughput
- **多源同形提醒**：putter
- **put → puts：放到位置、状态与安排**：put · puts
- **in 向里 + put 放 → inputs**：inputs

## 词形与演化规律

put、putting 先说明常用动作；input、output、throughput 连起来看流程。高尔夫 putting、putter 的基词是 putt；putter around 又有另一来路，必须分支解释。

中古英语放、推动词延续，更远来源未定，过去形式仍是 put。

input 由 put in 的相关表达发展为投入物、输入内容；现代 -s，可数输入数据、投入因素，也可说某人输入数据。

## 逐词讲解

<a id="w-1"></a>

### 1. put — 放；使处于某状态；表达

**音标**：/pʊt/

**先抓住这个画面**

把东西放到一个位置，也可把问题放进某个说法、把人置于某种处境。

**怎么拆**

经中古英语 putten 等形式，早期与推、放动作有关，更远来源不完全确定。过去式和过去分词仍拼读 put /pʊt/，不加普通 -ed。

**怎么变成今天的意思**

**古英语相关推、放词形 → 中古英语 putten**  
推、放置；更远来源仍有争议

↓

**英语 put**  
放到某处、某状态；表达

put the cup on the table 是把杯子放桌上；put someone at ease 是让人放松；put it simply 是简单地表达。动作常需要说明放哪里、成什么状态，单说 put the cup 往往没说完。

**常见搭配与例句**

put something somewhere；put into words；put it simply；put someone at ease。

> Please put the keys on the table.

请把钥匙放在桌上。

> I don’t know how to put my feelings into words.

我不知道怎样用语言表达自己的感受。

**别混淆**

put 常表示主动放置，lie 可说物体躺着的状态。I put it there 说明谁放，It lies there 说明它在那里。put on、put off 等短语还须按搭配学。

<a id="w-2"></a>

### 2. putting — 放置；高尔夫推杆

**音标**：放置 /ˈpʊtɪŋ/；高尔夫推杆 /ˈpʌtɪŋ/

**先抓住这个画面**

同样一串字母，可能是在把书放回去，也可能是在果岭上轻推高尔夫球。

**怎么拆**

普通 putting 是 put + -ing，双写 t；高尔夫 putting 是 putt + -ing，putt 经苏格兰语相关形式进入英语。两种基词和读音要分清，不只按单词长度猜。

**怎么变成今天的意思**

**put + -ing → putting /ˈpʊtɪŋ/**  
放置等动作的形式

↓

**另一路：putt + -ing → putting /ˈpʌtɪŋ/**  
高尔夫推杆活动

putting things away 是收好东西；practise putting 是练习推杆。语境通常很清楚：书包、杯子接放置，球场、球杆接推杆。

**常见搭配与例句**

putting things away；putting it simply；practise putting。

> She is putting the books back on the shelf.

她正在把书放回书架。

> He spent an hour practising his putting.

他花了一小时练习高尔夫推杆。

**别混淆**

一般 put /pʊt/ 和高尔夫 putt /pʌt/ 在常见标准读音中不同；不能因为都写 putting 就只记一个 /ʊ/。

<a id="w-7"></a>

### 3. puts — 放、置；使处于某状态〔put 的第三人称单数〕

**音标**：/pʊts/

**先抓住这个画面**

把东西安到一个位置，或者让事情进入一种状态，就是 puts；具体地方、状态常在后面补出来。

**怎么拆**

put + -s，/t/ 后读 /s/，u 读 /ʊ/。put 经中古英语 putten 等延续，较早有推动、放置用法，更远来源未定；过去式、过去分词仍是 put。

**怎么变成今天的意思**

**中古英语 putten 等 → put**  
推、安放 → 放置、使处于状态

↓

**put + -s → puts**  
单数主语放、使进入某位置或状态

puts the book on the shelf 把书放上架；puts quality first 把质量放第一；puts an end to... 结束……。

**常见搭配与例句**

puts the keys in a drawer；puts the plan into action。

> She puts her keys in the same drawer each evening.

她每天晚上把钥匙放进同一个抽屉。

> The team puts clear communication first.

这个团队把沟通清楚放在第一位。

**别混淆**

put 常需要补足放在哪里、放成怎样，puts the book 后还要看 on the shelf 等。puts somebody at ease 是让某人放松的状态表达。

<a id="w-6"></a>

### 4. putter — 高尔夫推杆；慢悠悠做零碎事〔尤美〕

**音标**：高尔夫、闲忙 /ˈpʌtə/（英）、/ˈpʌtər/（美）；放置者旧义 /ˈpʊtə(r)/

**先抓住这个画面**

球场上一支用于轻推球的杆；家里又可能是人这儿整理一下、那儿弄一下的闲忙。

**怎么拆**

高尔夫名词是 putt + -er；putter around 的动词与 potter 的变体有关；另有 put + -er“放置者”等较少用名词。三路同形，不能讲成“拿推杆所以在家瞎忙”。

**怎么变成今天的意思**

**putt + -er → putter**  
用于推杆的球杆或做推杆的人

↓

**另一路：potter 的变体 putter**  
慢悠悠做零碎事；另有 put + -er 名词

高尔夫中 pick up a putter 是拿起推杆；美式 putter around the garden 是在花园做些零碎事，英式常用 potter about。

**常见搭配与例句**

a golf putter；practise with a putter；putter around。

> He chose a new putter at the golf shop.

他在高尔夫用品店选了一支新推杆。

> She likes to putter around the garden on Sundays.

她喜欢周日在花园慢悠悠做些零碎活。

**别混淆**

putter 的常用读音 /ʌ/ 与普通 put 的 /ʊ/ 不同；器具名与闲忙动词又不应被硬拼成同一现代派生过程。

<a id="w-3"></a>

### 5. output — 产量；输出内容；输出〔动词〕

**音标**：/ˈaʊtpʊt/

**先抓住这个画面**

系统投入运转之后，从另一头送出来的东西。

**怎么拆**

out＋put，和 put out“往外放、生产”相关。现代产量名词在工业语境中发展；英语更早已有表示排出等义的同形动词，不能把所有动词义都说成后来名词转用。

**怎么变成今天的意思**

**英语 out；put**  
向外；放置

↓

**英语 output 的动词及工业名词支线**  
早期排出等动词义；后来产量名词及生产、输出义

↓

**现代 output**  
产品数量、设备功率、数据或创作成果等输出

工厂的 output 可以按件数算；程序的 output 是计算后给你的数据；作家的 output 是写出的作品。共同点是流程产出了什么，而不只是做事有多忙。

**常见搭配与例句**

annual output；audio output；output data；increase output；the output of a program。

> The factory increased its output without adding another shift.

工厂没有增加班次，却提高了产量。

> The program outputs a short report after each run.

程序每次运行后都会输出一份简短报告。

**别混淆**

output 是产出本身；outcome 是这项活动最终带来的结果。做了十场培训是 output，员工是否学会是 outcome。

<a id="w-4"></a>

### 6. input — 输入；投入；意见、贡献；输入数据

**音标**：/ˈɪnpʊt/

**先抓住这个画面**

把某样东西送进处理过程：可以是数据，也可以是时间、材料或建议。

**怎么拆**

in-（向内）+ put（放），接较早英语 inputten 等形式；现代名词、动词都常用。

**怎么变成今天的意思**

**古英语相关推、放词形 → 中古英语 putten**  
推、放置；更远来源仍有争议

↓

**英语 put**  
放到某处、某状态；表达

↓

**in- + put → input**  
放进去 → 输入或投入的内容

user input 是用户输入，input data 是输入数据；Thanks for your input 是谢谢你的意见。生产分析中的 inputs 也可指各种投入资源。

**常见搭配与例句**

user input；data input；input from the team；input data。

> The form checks user input before saving it.

表单在保存前检查用户输入。

> We would welcome your input on the design.

我们欢迎你对设计提出意见。

**别混淆**

input 是进入过程的，output 是出来的结果；反馈意见也可算 input，不只键盘打字才叫输入。

<a id="w-8"></a>

### 7. inputs — 输入内容；投入因素；意见〔复数〕；输入〔第三人称单数〕

**音标**：英、美 /ˈɪnpʊts/

**先抓住这个画面**

为了让一个过程运转，你往里面放进去的东西，就是 inputs。电脑收到的数据、生产用的材料，都可以从投入这一侧来看。

**怎么拆**

in 向里 + put 放 → input，加 -s → inputs，末尾 /ts/。名词从投入、贡献等用法发展到设备能量、电脑数据；也有相应输入动词。

**怎么变成今天的意思**

**put in 放入的相关表达 → input 投入、贡献**  
较早也用于共同投入的钱

↓

**机器、生产、计算机的输入义 → inputs**  
现代复数数不同输入项，第三人称动词同形

data inputs 是数据输入项；production inputs 是生产投入；multiple inputs 是多个输入来源；inputs the data 是输入数据。

**常见搭配与例句**

data inputs；production inputs；multiple inputs。

> The diagram shows the inputs and outputs of the system.

图中展示了系统的输入与输出。

> The program checks all inputs before calculating the result.

程序先检查所有输入项，再计算结果。

**别混淆**

inputs 从投入、进入的方向看，outputs 从产出、离开的方向看。表示某人总体的意见贡献时，input 又常不可数，如 Thanks for your input。

<a id="w-5"></a>

### 8. throughput — 吞吐量；单位时间处理量

**音标**：/ˈθruːpʊt/

**先抓住这个画面**

不只看门口进了多少、最后出了什么，而是看一段时间能让多少东西穿过整个流程。

**怎么拆**

through（通过）+ put，仿 input、output 一类形式构成；不是 through“做完”单独变成了名词后缀。

**怎么变成今天的意思**

**英语 through；input / output 的命名模式**  
通过；输入输出相关构词参照

↓

**through + put → throughput**  
系统、生产流程的处理速率

网络数据、工厂、服务流程都可谈 throughput。必须带时间或明确计算口径，如每秒请求、每小时件数，不能直接当总容量。

**常见搭配与例句**

increase throughput；network throughput；production throughput。

> The new machine increased production throughput.

新机器提高了单位时间产量。

> The test measured throughput in requests per second.

测试用每秒请求数衡量吞吐量。

**别混淆**

throughput 是单位时间完成多少，latency 是一次任务等多久；系统吞吐高不保证每个人等待短。

## 这一组要分清什么

input 输入和投入，output 输出和产出，throughput 单位时间处理量；putting /ʊ/ 与高尔夫 putting /ʌ/ 区分。

## 串起来练习

We put more effort into checking the input before measuring throughput.

我们先多花精力检查输入，再测量吞吐量。
