# 0875 · tree — 树木、木制结构；分枝关系

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

gantry 的旧拼写和来源有不同分析，本轮不把它硬画成确定的 tree 直接派生。原有 doubletree 木制横杆用法复用旧精讲。

**TREE：从主干伸出枝条，也借来画关系**

tree → treeless；treehouse、treetop、doubletree 等按部位、场所、木制器具相邻。

- **树与没有树**：tree · treeless
- **部位、场所和木杆器具**：treetop · treehouse · doubletree
- **tree → trees：树木与分枝式结构**：tree · trees
- **maple：枫、槭树与枫木**：maple · maples
- **cedar：另源的雪松等树名**：cedar · cedars
- **willow：另源的柳树与柔软枝条**：willow · willows
- **elm、fir、spruce：并排辨认的树名，各有来源**：elm · elms · fir · firs · spruce · spruces

## 词形与演化规律

tree + -less；tree + house/top；double + tree 的 tree 有旧木制杆架义。

古英语树、木料词继承下来；家谱、数据树借用分枝画面。

和 tree 比较树种，不从 tree 派生。maple 承古英语 mapultreow 等，接更早日耳曼树名，远源未定；现代整体学习，不拆成 map 加 -le。

与 tree 比较树木，不由 tree 派生。古英语 ceder 与法语 cedre 等形式汇合，较远接拉丁 cedrus、希腊 kedros，远源不确定；俗名 cedar 也用于其他外形相近的树。

与 tree 比较树木，不从 tree 派生。willow 接古英语 welig、日耳曼语柳树名，更远可能接弯转词族，和柔软可弯枝条的关系有助记忆，但远源分析仍保留可能。

本支按树名比较，不由现代 tree 派生。elm 接古英语，fir 多认为经北欧语进入；spruce 则有普鲁士地名、进口木材的命名背景。三者不是彼此变形。

## 逐词讲解

<a id="w-1"></a>

### 1. tree — 树；树形结构；〔动词〕把动物赶上树

**音标**：/triː/

**先抓住这个画面**

一根主干向上，分成大枝、小枝；家谱、分类图、文件目录借它的分支结构叫 tree。

**怎么拆**

本族词，接古英语 trēow、trēo 等。旧义也包括木料和木制结构；现代树形图抓的是分支关系，不必每个分支都真长叶子。

**怎么变成今天的意思**

**古英语 trēow、trēo → 中古英语 tre → tree**  
树；木材、木梁等

↓

**英语 tree**  
树木；以分枝结构比喻家谱、分类和数据关系

a family tree 家谱，a tree diagram 树形图，plant a tree 种树；The dog treed the cat 表狗把猫追到树上。

**常见搭配与例句**

plant a tree；a family tree；a tree diagram；a directory tree。

> We planted a tree near the gate.

我们在门边种了一棵树。

> The diagram shows the family tree.

这张图展示了家谱。

**别混淆**

tree 树，wood 可木材、林地；tree 动词赶上树属于名词转动作，不是 tree 的过去式。

<a id="w-7"></a>

### 2. trees — 树木；树状结构、树形图〔复数〕

**音标**：/triːz/

**先抓住这个画面**

一棵树从主干分出枝条，所以树木的形状也被用来表示家谱、分类、数据的分支关系，这些图也叫 trees。

**怎么拆**

tree + -s，元音后读 /z/。tree 继承古英语 trēow、trēo 等，较早还涉及木材、木制结构；现代树形图借用分枝的形象。

**怎么变成今天的意思**

**古英语 trēow、trēo → 中古英语 → tree**  
树；较早也有木料等义

↓

**tree + -s → trees**  
多棵树；多个树状关系结构

fruit trees 果树；family trees 家谱；decision trees 决策树；trees along the road 路边的树。

**常见搭配与例句**

climb trees；draw family trees。

> Tall trees shade the path beside the river.

高大的树木为河边小路遮阴。

> The class drew family trees to show the relationships.

全班画了家谱来展示亲属关系。

**别混淆**

trees 说一棵棵树，wood 或 woods 可说一片树林。family trees 用树的分枝形象表现亲属关系。

<a id="w-2"></a>

### 3. treehouse — 树屋

**音标**：/ˈtriːhaʊs/

**先抓住这个画面**

平台和小屋依托树干、树枝或树旁结构，离地搭起。

**怎么拆**

tree（树）+ house（小屋、住所），按支撑位置命名。

**怎么变成今天的意思**

**英语 tree；house**  
并列组合的两部分

↓

**tree + house → treehouse**  
搭在树上或依托树的屋状结构

儿童游戏和旅行住宿语境都可用。树屋不一定由活树单独承重，实际结构需要看具体设施，不由名字推断。

**常见搭配与例句**

a wooden treehouse；climb to a treehouse；a treehouse platform。

> The children imagined their treehouse was a castle.

孩子们把树屋想象成城堡。

> A ladder led up to the treehouse.

一道梯子通向树屋。

**别混淆**

treehouse 是在树上等处搭的小屋，birdhouse 是给鸟用的巢箱；对象和尺寸不一样。

<a id="w-4"></a>

### 4. treeless — 没有树的

**音标**：/ˈtriːləs/

**先抓住这个画面**

放眼看去看不到树，可能是草原、山地或其他景观。它只否定树，不否定一切植物。

**怎么拆**

tree + -less，没有树木。保留 tree 的完整词形。

**怎么变成今天的意思**

**古英语 trēow、trēo → 中古英语 tre → tree**  
树；木材、木梁等

↓

**英语 tree**  
树木；以分枝结构比喻家谱、分类和数据关系

↓

**tree + -less → treeless**  
没有树木的

a treeless plain 无树平原，treeless hills 没有树的丘陵，a treeless landscape 无树景观。

**常见搭配与例句**

a treeless plain；treeless hills；a treeless landscape。

> We crossed a wide treeless plain.

我们穿过一片辽阔的无树平原。

> Grass covered the treeless hills.

没有树的丘陵上长满了草。

**别混淆**

treeless 没树，barren 贫瘠、少植被或不结果等；一大片青草地可以 treeless，却不必 barren。

<a id="w-5"></a>

### 5. treetop — 树梢；树冠上部

**音标**：英 /ˈtriːtɒp/；美 /ˈtriːtɑːp/

**先抓住这个画面**

目光顺着树干爬上去，直到最高的一片枝叶。

**怎么拆**

tree（树）+ top（顶部），常用复数 treetops 描写成片树木的上方。

**怎么变成今天的意思**

**英语 tree；top**  
并列组合的两部分

↓

**tree + top → treetop**  
树的最高枝叶部分

above the treetops 是在树梢上方，a treetop walkway 是树冠高度的步道。不是指砍下来的树顶木料才可使用。

**常见搭配与例句**

above the treetops；among the treetops；a treetop walkway。

> Birds were calling from the treetops.

鸟儿在树梢鸣叫。

> Mist drifted just above the treetops.

薄雾在树梢上方缓缓飘过。

**别混淆**

treetop 是树的顶端区域，treehouse 是建在树上的小屋；小屋未必位于树的最高点。

<a id="w-6"></a>

### 6. doubletree — 双马牵引横木；双马平衡牵引杆

**音标**：/ˈdʌbəltriː/

**先抓住这个画面**

两匹马各有一根牵引横杆，再通过共同的一根横杆连接车具，帮助汇合、平衡牵引力。

**怎么拆**

英语 double 双 + tree 木材、木制构件；tree 在这种器具名里不是地里长着的一棵树。

**怎么变成今天的意思**

**拉丁 duo“二” + 倍数后缀 -plus → duplus**  
两倍的、双重的

↓

**古法语 doble → 中古英语 double**  
双的、两倍的

↓

**英语 double + tree → doubletree**  
供两匹马共同牵引的横杆装置

见于马车、农具与相关历史描写。常连接两根 singletrees，再把两匹马的拉力传向车或工具。大写商标使用不能代替这个器具义。

**常见搭配与例句**

a wooden doubletree；attach the doubletree；a doubletree and singletrees。

> The farmer attached the two singletrees to the doubletree.

农夫把两根单马横杆连接到双马牵引横木上。

> The museum displays a wooden doubletree beside the old wagon.

博物馆在旧货车旁展示了一根木制双马牵引横杆。

**别混淆**

singletree 通常连接单匹马的挽具；doubletree 把两套单马牵引连接起来。

<a id="w-8"></a>

### 7. maple — 枫、槭树；枫木

**音标**：/ˈmeɪpəl/

**先抓住这个画面**

秋天叶色鲜明、叶片像张开手掌的树，常让人想到 maple；做家具时 maple 又是枫木。maple syrup 则把这类树和糖浆连在一起。

**怎么拆**

承古英语 mapultreow、mapolder 等枫树材料，更早日耳曼树名来源未定；英语逐渐缩成 maple。现代不按 map 地图加后缀来理解。

**怎么变成今天的意思**

**古英语 mapultreow、mapolder 等枫树材料**  
较远日耳曼树名的来源未定

↓

**中古英语 mapel 等 → maple**  
树名也按材料用来命名枫木

a maple tree 可数一棵，made of maple 按木材不可数；maple syrup 是枫糖浆，具体树种的用途各有区别。

**常见搭配与例句**

a maple leaf；maple wood；maple syrup。

> A maple tree shades the front garden.

一棵枫树为前院遮阴。

> The table is made of maple.

那张桌子是枫木做的。

**别混淆**

maple 是树类、木材名，map 是地图，二者不能凭前面几个相同字母认作现代派生；树本身也不等于糖浆。

<a id="w-9"></a>

### 8. maples — 枫树、槭树〔复数〕

**音标**：/ˈmeɪpəlz/

**先抓住这个画面**

街边一排枫树，是 maples；这里在数树，不是在数家具用的几块木料。

**怎么拆**

maple + -s，/l/ 后读 /z/；可数树名的普通复数。木材通常仍用不可数 maple。

**怎么变成今天的意思**

**古英语 mapultreow、mapolder 等枫树材料**  
较远日耳曼树名的来源未定

↓

**中古英语 mapel 等 → maple**  
树名也按材料用来命名枫木

↓

**maple + -s → maples**  
多棵、不同种的枫树、槭树

red maples、Japanese maples 可指不同种类；a row of maples 是一排树，具体秋色并非每棵都同样。

**常见搭配与例句**

maples along the street；a row of maples；Japanese maples。

> The street is lined with maples.

街道两旁种着枫树。

> Several maples in the park had turned bright red.

公园里几棵枫树的叶子已经变得鲜红。

**别混淆**

maples 数树，maple boards 数枫木板；材料名作修饰语时通常不因 boards 复数就也加 s。

<a id="w-10"></a>

### 9. cedar — 雪松等树木；相应木材

**音标**：英 /ˈsiːdə/；美 /ˈsidɚ/

**先抓住这个画面**

看到枝叶常绿的树，或闻到木柜里有香气的木材，标签可能写 cedar。它是树名，也能借给木材；具体种类要看名称语境。

**怎么拆**

古英语 ceder 与法语 cedre 等形式汇合，接拉丁 cedrus、希腊 kedros 雪松、杜松类旧名；更远来源不确定。

**怎么变成今天的意思**

**希腊 kedros 雪松、杜松类旧名 → 拉丁 cedrus**  
更远来源不明

↓

**古英语 ceder 与法语 cedre 等 → 英语 cedar**  
树木名称也借给木材，俗名范围未必等于严格属名

a cedar tree 是一棵 cedar 类树木；cedar wood 是相应木材；a cedar chest 是这种木材做的箱柜。

**常见搭配与例句**

a cedar tree；cedar wood；a cedar chest。

> A tall cedar shaded the corner of the garden.

一棵高大的雪松为花园一角遮阴。

> The chest was made of cedar.

箱柜由雪松类木材制成。

**别混淆**

日常 cedar 也用于一些不属于严格雪松属的树；认词时知道俗名可能宽于植物属名，便不会把所有 cedar 标签机械当同一种树。

<a id="w-11"></a>

### 10. cedars — 雪松等树木〔复数〕

**音标**：英 /ˈsiːdəz/；美 /ˈsidɚz/

**先抓住这个画面**

路旁一排 cedar 类树木，是 cedars。树按棵数，砍下加工成木材后，cedar 又常按材料不可数使用。

**怎么拆**

cedar + -s → cedars，后缀读 /z/；英美对末尾 r 的处理不同，复数后缀仍为浊音。

**怎么变成今天的意思**

**希腊 kedros 雪松、杜松类旧名 → 拉丁 cedrus**  
更远来源不明

↓

**古英语 ceder 与法语 cedre 等 → 英语 cedar**  
树木名称也借给木材，俗名范围未必等于严格属名

↓

**cedar + -s → cedars**  
多棵树；材料用法通常不按这个复数数木料

tall cedars 是高大的树；a row of cedars 是一排；cedar furniture 则以单数材料名修饰家具。

**常见搭配与例句**

tall cedars；a row of cedars；cedars along the path。

> A row of cedars screened the house from the road.

一排雪松挡住了从路上望向房子的视线。

> The old cedars cast long shadows across the lawn.

那些老雪松在草坪上投下长长的影子。

**别混淆**

cedars 常按树木个体计数；cedar wood 通常说木材，不能只因木料来自多棵树就必须用 cedars wood。

<a id="w-12"></a>

### 11. willow — 柳树；柳木

**音标**：英 /ˈwɪləʊ/；美 /ˈwɪloʊ/

**先抓住这个画面**

河边垂着柔软枝条的柳树，是 willow。weeping willow 像低垂着头哭泣，用这个姿态给垂柳起了形象的名字。

**怎么拆**

古英语 welig，经中古英语 wilwe 等成为 willow；较远可能联系弯转材料，和枝条柔韧可弯的形象相合，但远源分析仍带可能性。

**怎么变成今天的意思**

**古英语 welig → 中古英语 wilwe → willow**  
较远可能接弯转词族，具体分析保留可能

↓

**柳树、柔软枝条与木材名称**  
weeping willow 借下垂姿态指垂柳，像低垂着哭泣

a willow tree 是一棵柳树；a weeping willow 是垂柳；willow branches 是柳枝；willow 作材料名可指柳木。

**常见搭配与例句**

a willow tree；a weeping willow；willow branches。

> A willow leaned over the stream.

一棵柳树斜伸在溪流上方。

> We sat beneath a weeping willow.

我们坐在一棵垂柳下。

**别混淆**

willow 的 -ow 是词形历史变化的一部分，不按现代词尾添加一个独立意思。weeping willow 说下垂形象，不是树真的在哭。

<a id="w-13"></a>

### 12. willows — 柳树〔复数〕

**音标**：英 /ˈwɪləʊz/；美 /ˈwɪloʊz/

**先抓住这个画面**

河岸边一排柳树，是 willows。它数不同树木；柳枝作篮子材料时，又常把 willow 按材料单数使用。

**怎么拆**

willow + -s → willows，基础末音是元音 /əʊ/、/oʊ/，复数后缀读 /z/；不另加 /ɪz/ 音节。

**怎么变成今天的意思**

**古英语 welig → 中古英语 wilwe → willow**  
较远可能接弯转词族，具体分析保留可能

↓

**柳树、柔软枝条与木材名称**  
weeping willow 借下垂姿态指垂柳，像低垂着哭泣

↓

**willow + -s → willows**  
多棵柳树；末尾 /əʊz/、/oʊz/

weeping willows 是多棵垂柳；willows along a river 是河岸柳树；a row of willows 是一排。

**常见搭配与例句**

weeping willows；a row of willows；willows along the river。

> Willows grew along both sides of the river.

河流两岸长着柳树。

> The pond was shaded by three old willows.

池塘由三棵老柳树遮阴。

**别混淆**

willows 的 s 数树；willow branches 里的 willow 用单数修饰枝条，和 oak furniture 一样，不因来源有多棵树就必须加 s。

<a id="w-14"></a>

### 13. fir — 冷杉；冷杉木；某些针叶树的俗名

**音标**：英 /fɜː/；美 /fɝ/

**先抓住这个画面**

针状叶、常绿的 fir，常见中文对应是冷杉。先认树，再留意传统植物名称不总按现代分类划分。

**怎么拆**

现代词通常认为经古诺斯语、古丹麦语树名借入；更远的词族曾有橡树、树林等意义。不同地区树名转用，不能理解成某棵橡树真的变成了冷杉。

**怎么变成今天的意思**

**现代 fir 通常认为经古诺斯语、古丹麦语的树名借入**  
古英语也有同族形式，不能把近代借词和所有祖先混成一条直线

↓

**更远重建的词族有橡树、树林等旧义 → 北方针叶树名称**  
现代 fir 常指冷杉，也见于范围不同的传统植物俗名

a fir tree 是一棵冷杉；fir branches 是冷杉枝；fir wood 是冷杉木。

**常见搭配与例句**

a fir tree；fir branches；fir wood。

> A tall fir stood beside the cabin.

小屋旁立着一棵高大的冷杉。

> We decorated the room with fir branches.

我们用冷杉枝装饰了房间。

**别混淆**

fir、pine、spruce 通常分别说冷杉、松、云杉；传统俗名有交叉，具体树种还要看完整名称。fir 和 fur 毛皮同音。

<a id="w-18"></a>

### 14. firs — 冷杉〔复数〕

**音标**：英 /fɜːz/；美 /fɝz/

**先抓住这个画面**

山坡上一片常绿冷杉，便可以说 firs。复数的 s 接在原来长元音或卷舌元音之后。

**怎么拆**

fir + -s → firs，后缀读 /z/；这里数树的棵数，树名的历史借词关系不变。

**怎么变成今天的意思**

**现代 fir 通常认为经古诺斯语、古丹麦语的树名借入**  
古英语也有同族形式，不能把近代借词和所有祖先混成一条直线

↓

**更远重建的词族有橡树、树林等旧义 → 北方针叶树名称**  
现代 fir 常指冷杉，也见于范围不同的传统植物俗名

↓

**fir + -s → firs**  
多棵冷杉的规则复数

tall firs 是高大的冷杉；a row of firs 是一排冷杉；firs on the hillside 是山坡上的冷杉。

**常见搭配与例句**

tall firs；a row of firs；dark firs。

> Tall firs covered the hillside.

高大的冷杉覆盖了山坡。

> The path winds between dark firs.

小路在深色的冷杉之间蜿蜒。

**别混淆**

firs 和 furs 发音相同；前者是树，后者可能是毛皮，靠句意区分。

### 15. spruce — 云杉；整洁漂亮的；收拾、打扮整齐〔常接 up〕

**音标**：英、美 /spruːs/

**先抓住这个画面**

a spruce 是一棵云杉；spruce up a room 则是把房间收拾漂亮。它们背后都有旧时普鲁士物产名称的线索。

**怎么拆**

Spruce 曾是普鲁士地名的英语形式，与进口木材相连，后来用于树名；整洁漂亮的形容词通常联系进口皮革、时兴服饰，动词再来自形容词。

**怎么变成今天的意思**

**普鲁士地名的中古英语形式 Spruce → 进口物产、木材名称**  
树名 spruce 与普鲁士木材贸易背景有关

↓

**进口皮革、服饰名称又与 spruce 整洁漂亮的形容词相连**  
spruce 动词打扮、收拾整齐来自形容词，常接 up

a spruce tree 是云杉；look spruce 是看着整洁精神；spruce up the room 是把房间收拾漂亮。

**常见搭配与例句**

a spruce tree；look spruce；spruce up the house。

> A spruce grew at the edge of the wood.

树林边长着一棵云杉。

> We need to spruce up the guest room.

我们得把客房收拾漂亮些。

> He looked very spruce in his new jacket.

他穿着新夹克，看上去十分整洁精神。

**别混淆**

“打扮整齐”不是先把房间变成云杉树；两支用法要回到物产名称、衣着的不同发展去理解。

### 16. spruces — 云杉〔复数〕；收拾、打扮整齐

**音标**：英、美 /ˈspruːsɪz/

**先抓住这个画面**

一排云杉是 spruces；she spruces up the room 则说她把房间收拾漂亮。看句中位置区分树名和动作。

**怎么拆**

spruce + -s → spruces；原词末尾已有 e，只添 s。基础末音 /s/ 后后缀读 /ɪz/，不读成 /spruːsz/。

**怎么变成今天的意思**

**普鲁士地名的中古英语形式 Spruce → 进口物产、木材名称**  
树名 spruce 与普鲁士木材贸易背景有关

↓

**进口皮革、服饰名称又与 spruce 整洁漂亮的形容词相连**  
spruce 动词打扮、收拾整齐来自形容词，常接 up

↓

**spruce + -s → spruces**  
树名复数、动词第三人称单数，读 /ˈspruːsɪz/

blue spruces 是蓝云杉；tall spruces 是高云杉；spruces up the office 是收拾办公室。

**常见搭配与例句**

tall spruces；blue spruces；spruces up the room。

> Tall spruces sheltered the house from the wind.

高大的云杉为房子挡风。

> She always spruces up the room before guests arrive.

客人来之前，她总会把房间收拾漂亮。

**别混淆**

拼写只加 s，读音却多一个音节；判断词尾读法要看 /s/，不能只看有没有写 -es。

### 17. elm — 榆树；榆木

**音标**：英、美 /elm/

**先抓住这个画面**

一棵伸展着大树冠的榆树，是 an elm。它是沿用很久的树名，不需要找现代英语里的小零件硬凑。

**怎么拆**

古英语 elm 接古日耳曼语树名，与拉丁 ulmus 等有同族关系；更远可能联系红、棕颜色，但不能把猜测说成确定的命名故事。

**怎么变成今天的意思**

**古英语 elm ← 重建日耳曼语 \*elmaz**  
与拉丁 ulmus 等有同族关系

↓

**elm 榆树 → elms**  
更远可能联系红、棕颜色的古老词根，但不是定论

an old elm 是老榆树；elm wood 是榆木；an elm tree 把 tree 补出来也很自然。

**常见搭配与例句**

an elm tree；an old elm；elm wood。

> An old elm shaded the village square.

一棵老榆树为村庄广场遮阴。

> The bench was made of elm.

这张长凳是榆木做的。

**别混淆**

elm 是榆树，oak 是橡树，birch 是桦树；都可以修饰 wood，但指不同树种的木材。

### 18. elms — 榆树〔复数〕

**音标**：英、美 /elmz/

**先抓住这个画面**

路两边是一排排榆树，就可以说 rows of elms。末尾的 l、m 都留在发音里。

**怎么拆**

elm + -s → elms，/m/ 后读 /z/，结尾是 /lmz/；直接加 s。

**怎么变成今天的意思**

**古英语 elm ← 重建日耳曼语 \*elmaz**  
与拉丁 ulmus 等有同族关系

↓

**elm 榆树 → elms**  
更远可能联系红、棕颜色的古老词根，但不是定论

↓

**elm + -s → elms**  
多棵榆树，读 /elmz/

a row of elms 是一排榆树；tall elms 是高大的榆树；old elms 是老榆树。

**常见搭配与例句**

a row of elms；tall elms；old elms。

> Tall elms lined the road.

高大的榆树排列在道路两旁。

> The park has several old elms.

公园里有几棵老榆树。

**别混淆**

elm wood 说木材时常按材料不可数；elms 是把树一棵棵来数。
