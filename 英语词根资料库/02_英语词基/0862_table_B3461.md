# 0862 · table — 桌面、表格与餐桌用具

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

最终来自拉丁 tabula 板、列表；早期日耳曼借词和法语词在英语中汇合。table 的动词义需要留意英美差异。

**TABLE：一块能摆东西、排信息的平面**

先桌子和表格，再大匙、桌布、餐具；最后转盘与已有时间表、桌面词。

- **基本平面与安排**：table · timetable · tabletop
- **餐桌相关**：tablespoon · tablecloth · tableware
- **旋转平台**：turntable
- **table → tables：平面家具与排成行列的信息**：table · tables
- **tablecloth → tablecloths：桌面覆盖布**：table · tablecloth · tablecloths
- **tab 的截短支与标签支分开认识**：table · tab · tabs
- **tab 的标签、Tab 键动作及变化**：tab · tabs · tabbed · tabbing
- **turntable → turntables：转盘与唱盘机**：turntable · turntables

## 词形与演化规律

table + spoon/cloth/ware；turn + table；time + table → timetable；table + top → tabletop。

拉丁 tabula 板、列表，经较早英语借入和法语影响形成现代词。

cloths 为单块布的复数，和固定衣物名 clothes 区分。

账单 tab 可能缩自 tabulation 或 tablet；Tab 键缩自 tabulator。小片、标签这支的更早来源不确定，不能全部归为拉丁 tabula。

标签小片支远源不定，Tab 键则截短自 tabulator；tabbed 文档接界面标签，按 Tab 接键名。

table 提供平台材料；铁路转车盘、唱片播放设备按用途区别。

## 逐词讲解

<a id="w-1"></a>

### 1. table — 桌子；表格；提出或搁置议题〔地区用法不同〕

**音标**：/ˈteɪbl/

**先抓住这个画面**

一块平面既能摆饭菜，也能把文字、数字排得整整齐齐；于是有桌子和表格两种常用义。

**怎么拆**

最终接拉丁 tabula 板、列表；英语既有古英语阶段的早期借词，也有后来法语 table 的影响。家具义和表格义都围绕平面展开。

**怎么变成今天的意思**

**拉丁 tabula**  
板、写字板、列表

↓

**古英语 tabele 与古法语 table → 英语 table**  
早期借词与法语借词汇合；桌子、表格

a dining table 餐桌，a table of results 结果表，table of contents 目录。作动词 table a proposal，英式常指提交讨论，美式常指暂搁。

**常见搭配与例句**

set the table；a table of results；table of contents；table a proposal。

> The table shows the results for each month.

表格列出了每个月的结果。

> We booked a table for four near the window.

我们订了一张靠窗的四人桌。

**别混淆**

table a proposal 的地区意义可能相反，跨地区沟通用 submit for discussion 或 postpone 更明确。table 表格与 chart 图表也要按呈现方式选择。

<a id="w-8"></a>

### 2. tables — 桌子；表格；提出或搁置议案〔第三人称单数，地区用法不同〕

**音标**：/ˈteɪbəlz/

**先抓住这个画面**

把东西放在平面上，是桌子；把信息整齐排在平面上，就是表格。把议案放上讨论桌，也发展出了动词，不过英美会议语境的重点可能相反。

**怎么拆**

table + -s，/l/ 后读 /z/。table 接拉丁 tabula 板、写字板、列表，有较早英语借词及后来法语 table 的共同影响；名词再有把事项摆上桌的动词用法。

**怎么变成今天的意思**

**拉丁 tabula → 较早英语及法语 table → 英语 table**  
板、列表 → 桌子、表格

↓

**table + -s → tables；动词引申**  
多个桌子、表格；提出或暂时搁置事项

dining tables 餐桌；data tables 数据表；multiplication tables 乘法表；tables a proposal 处理一项议案〔看地区语境〕。

**常见搭配与例句**

tables in the report；tables arranged in a circle。

> The tables in the report summarize the main results.

报告中的表格概括了主要结果。

> We pushed two tables together for the meal.

我们把两张桌子拼在一起吃饭。

> The chair tables the proposal because several members are absent.

由于几名成员缺席，主持人暂时搁置提案。〔美式会议用法〕

**别混淆**

名词 tables 的桌子、表格靠场景区分。会议动词 table 在英式语境常说正式提出供讨论，在美式语境常说暂时搁置；读具体程序句时看后文。

<a id="w-3"></a>

### 3. tablespoon — 大汤匙；一大匙〔烹饪量〕

**音标**：/ˈteɪblspuːn/

**先抓住这个画面**

餐桌上的大勺子；食谱里更常指用量勺量出的一大匙。

**怎么拆**

table 餐桌 + spoon 勺子，合成后也用作烹饪容量名称。它是固定词，不按两部分各自翻译成桌子勺。

**怎么变成今天的意思**

**拉丁 tabula**  
板、写字板、列表

↓

**古英语 tabele 与古法语 table → 英语 table**  
早期借词与法语借词汇合；桌子、表格

↓

**table + spoon → tablespoon**  
餐桌用大勺 → 烹饪一大匙

a tablespoon of oil 一大匙油，常缩写 tbsp。食谱量有地区差异；不少标准用约15毫升，澳式常用20毫升，应按食谱和量勺标注。

**常见搭配与例句**

a tablespoon of oil；two tablespoons of sugar；tbsp。

> Add two tablespoons of olive oil to the pan.

往锅里加入两大匙橄榄油。

> She measured the sugar with a tablespoon.

她用一大匙量勺量糖。

**别混淆**

tablespoon 大匙通常大于 teaspoon 茶匙；普通家用餐勺大小不统一，精确烘焙宜用标有容量的量勺。

<a id="w-4"></a>

### 4. tabletop — 桌面；桌面用的；桌上进行的

**音标**：英 /ˈteɪbəltɒp/；美 /ˈteɪbəltɑːp/

**先抓住这个画面**

活动的场地缩到一张桌子的顶面，物件、模型或游戏就在上面展开。

**怎么拆**

table（桌子）+ top（顶面），可指实体桌面，也修饰摆在桌上使用或进行的东西。

**怎么变成今天的意思**

**英语 table；top**  
并列组合的两部分

↓

**table + top → tabletop**  
桌子顶面；桌上使用或进行的

a wooden tabletop 是木桌面，tabletop games 是桌上游戏，a tabletop model 是桌面模型。不是所有 tabletop 都涉及电脑。

**常见搭配与例句**

a wooden tabletop；tabletop games；a tabletop display。

> The tabletop was covered with maps and photographs.

桌面上铺满地图和照片。

> They meet every week to play tabletop games.

他们每周见面玩桌上游戏。

**别混淆**

tabletop 泛指桌面用途，desktop 的现代常用义还包括电脑；同样有 top，不要把 tabletop game 一律译为电脑游戏。

<a id="w-6"></a>

### 5. tablecloth — 桌布

**音标**：英 /ˈteɪblklɒθ/；美 /ˈteɪblklɔːθ/

**先抓住这个画面**

铺在桌面上的一层布，让桌面整洁，也能保护它。

**怎么拆**

table + cloth 布；中古英语已有对应形式，前部用 table 替换了更早同义组合里的 bord。

**怎么变成今天的意思**

**拉丁 tabula**  
板、写字板、列表

↓

**古英语 tabele 与古法语 table → 英语 table**  
早期借词与法语借词汇合；桌子、表格

↓

**table + cloth → tablecloth**  
铺在桌面上的布

a clean tablecloth 干净桌布，a linen tablecloth 亚麻桌布，spread a tablecloth 铺桌布。

**常见搭配与例句**

a linen tablecloth；spread a tablecloth；wash the tablecloth。

> She spread a white tablecloth over the table.

她在桌上铺了一块白桌布。

> We washed the tablecloth after dinner.

晚饭后我们洗了桌布。

**别混淆**

cloth 是布，clothes 是衣服；桌布不是 tableclothes。复数 tablecloths 保留完整词基。

<a id="w-9"></a>

### 6. tablecloths — 桌布〔复数〕

**音标**：英 /ˈteɪblklɒθs/；美 /ˈteɪblklɔːθs/，也读 /ˈteɪblklɑːθs/

**先抓住这个画面**

一块布铺开罩在桌面上，是 tablecloth，多块就是 tablecloths。位置加材料，能直接想出器物。

**怎么拆**

table + cloth；中古英语已有相应组合，table 替换更早同义组合中的 bord。现代加 -s，cloth 的普通复数常读 /θs/。

**怎么变成今天的意思**

**中古英语 table + cloth 等 → tablecloth**  
桌面覆盖布的名称

↓

**tablecloth + -s → tablecloths**  
多块桌布

white tablecloths 白桌布；linen tablecloths 亚麻桌布。

**常见搭配与例句**

wash the tablecloths 清洗桌布；tablecloths on the tables 桌上铺的桌布。

> White tablecloths covered the dining tables.

白桌布铺在餐桌上。

> They washed the tablecloths after the party.

聚会后，他们洗了桌布。

**别混淆**

tablecloths 是单块布的复数，不写成 tableclothes。clothes 的衣服义与普通布块复数已经分化。

<a id="w-7"></a>

### 7. tableware — 餐具〔总称〕

**音标**：英 /ˈteɪblweə/；美 /ˈteɪblwer/

**先抓住这个画面**

摆一桌饭要用的盘、碗、杯、刀叉等，统起来叫餐具。

**怎么拆**

table 餐桌 + ware 制品、用具，按使用场景形成集合名称。

**怎么变成今天的意思**

**拉丁 tabula**  
板、写字板、列表

↓

**古英语 tabele 与古法语 table → 英语 table**  
早期借词与法语借词汇合；桌子、表格

↓

**table + ware → tableware**  
餐桌上使用的器具总称

ceramic tableware 陶瓷餐具，a set of tableware 一套餐具。通常作不可数总称，具体几件可说 pieces of tableware。

**常见搭配与例句**

ceramic tableware；a set of tableware；disposable tableware。

> The shop sells simple ceramic tableware.

店里出售简洁的陶瓷餐具。

> They chose reusable tableware for the party.

他们为聚会选了可重复使用的餐具。

**别混淆**

tableware 是大范围总称；cutlery 侧重刀叉勺等，glassware 侧重玻璃器皿，范围并不完全相同。

### 8. timetable — 时刻表；课程表；时间安排；为……安排时间

**音标**：/ˈtaɪmteɪbəl/

**先抓住这个画面**

把每趟车几点出发、每节课什么时候开始列成表，就是 timetable。这里的 table 是表格，不是饭桌。

**怎么拆**

time 与 table“表、清单”在英语中合成；名词又可转为动词，表示把活动排进时间安排。

**怎么变成今天的意思**

**英语 time；table**  
时间；列表、表格

↓

**英语 timetable 名词 → 相应动词**  
时间安排表；把某事排入表中

它可以是固定运行的公交时刻表，也可以是项目各阶段的计划。英式英语很常用 timetable；美国英语常在这些场合用 schedule。

**常见搭配与例句**

a train timetable；the school timetable；a timetable for completion；timetable a meeting。

> The timetable shows the last train leaving at eleven.

时刻表显示末班车十一点发车。

> We need a realistic timetable for replacing the old system.

我们需要为替换旧系统制定切实可行的时间安排。

**别混淆**

a table 是表格，a timetable 是把时间与事项对起来的表或计划。没有具体纸面表格，也可以谈 a timetable for change。

### 9. turntable — 转盘；唱机转盘、唱盘机

**音标**：英 /ˈtɜːnteɪbl/；美 /ˈtɜːrnteɪbl/

**先抓住这个画面**

平台围着中心转：可以带唱片转，也可以让整辆机车转个方向。

**怎么拆**

turn 转动 + table 平台；早期用例包括铁路机车转向平台，后来用于唱片播放设备。

**怎么变成今天的意思**

**拉丁 tabula**  
板、写字板、列表

↓

**古英语 tabele 与古法语 table → 英语 table**  
早期借词与法语借词汇合；桌子、表格

↓

**turn + table → turntable**  
能转动的平台 → 铁路转车盘、唱片转盘

a record on the turntable 唱盘上的唱片，a railway turntable 铁路转车盘；日常音乐语境也可指整台唱盘机。

**常见搭配与例句**

a record turntable；a railway turntable；a rotating turntable。

> He placed a record on the turntable.

他把唱片放到唱盘上。

> The museum demonstrated how the turntable turned a locomotive.

博物馆演示了转车盘怎样使机车转向。

**别混淆**

turntable 是能旋转的实体平台；turn the tables 是扭转局面的固定表达，来自棋盘游戏背景，别按唱机解释。

<a id="w-14"></a>

### 10. turntables — 转盘、唱盘机、铁路转车盘〔复数〕

**音标**：英 /ˈtɜːnteɪblz/；美 /ˈtɜːrnteɪblz/

**先抓住这个画面**

一个平台围着中心转，按结构叫 turntables；可以让唱片转，也可以让机车调转方向。

**怎么拆**

turn 转动 + table 平台 → turntable，加 -s，/l/ 后读 /z/。较早铁路等转动平台用途，后来进入唱片设备。

**怎么变成今天的意思**

**turn + table → turntable**  
能转动的平台

↓

**唱盘等用途；+ -s → turntables**  
多台转盘、唱盘机

record turntables 唱盘机；railway turntables 铁路转车盘。

**常见搭配与例句**

old turntables 旧唱盘机；compare turntables 比较转盘设备。

> The museum displayed two old record turntables.

博物馆展示了两台旧唱盘机。

> The railway yard once had several turntables.

铁路站场过去有几座转车盘。

**别混淆**

turntable 是实体平台，turn the tables 是扭转局面的习语，不能用唱片播放解释那个短语。

<a id="w-10"></a>

### 11. tab — 小标签、凸片；标签页；账单、费用；Tab 键

**音标**：/tæb/

**先抓住这个画面**

文件夹边上露出的一小片，方便认出、翻到那一页，叫 tab；屏幕上的标签页借这个外形。账单和 Tab 键则另有截短的来源。

**怎么拆**

小片、标签支更早来源未定，中古英语有 tabbe 带、绳。账单支可能缩自 tabulation 或 tablet；Tab 键缩自 tabulator。不要把所有意思接成单一 tabula 故事。

**怎么变成今天的意思**

**tabbe／tab〔小片支，来源未定〕→ 实物标签 → 界面标签**  
突出的一小片转为区分内容的位置

↓

**tabulation 或 tablet → tab〔可能的账单来源〕；tabulator → Tab**  
另外的截短支；与 table 家族有关

a browser tab 浏览器标签页；pick up the tab 付账；the Tab key Tab 键。

**常见搭配与例句**

open a new tab 开一个新标签页；a tab on the folder 文件夹上的标签。

> I opened the article in a new tab.

我在新标签页里打开了文章。

> She offered to pick up the tab for dinner.

她提出晚饭由她付账。

**别混淆**

标签页的外形联想很直观，但不能用它证明账单义也由标签演来。tab 与 tag 有用法接近处，较早词源关系仍不确定。

<a id="w-11"></a>

### 12. tabs — 标签、标签页、凸片〔复数〕；掌握动向、留意〔keep tabs on 中〕

**音标**：/tæbz/

**先抓住这个画面**

一排文件标签、几个网页标签页，都是 tabs。keep tabs on 像持续记账、记下情况，变成留意某人或某事。

**怎么拆**

tab + -s，/b/ 后读 /z/。标签支与账目、记录支来源须分开；keep tabs on 接记录、掌握情况的用法。

**怎么变成今天的意思**

**tab 的小片、标签支；账目记录支**  
同形词分别形成常见用法

↓

**tab + -s → tabs；keep tabs on**  
多个标签；持续留意、掌握情况

browser tabs 浏览器标签页；keep tabs on spending 留意支出。

**常见搭配与例句**

close the tabs 关闭标签页；coloured tabs 彩色标签。

> I closed the tabs I no longer needed.

我关掉了不再需要的标签页。

> She keeps tabs on the project costs.

她持续留意项目费用。

**别混淆**

keep tabs on 后面接关注对象，不是把几个网页标签页保留着；它借的是持续记录、查看的意思。

<a id="w-12"></a>

### 13. tabbed — 带标签的、以标签页组织的；加了标签；按 Tab 移动了

**音标**：/tæbd/

**先抓住这个画面**

内容被分成一个个能点选的标签页，是 tabbed；在文字输入中也可表示用 Tab 键跳到下一位置。

**怎么拆**

tab 双写末尾 b，加完整的 -ed → tabbed，读 /d/。标签页接小标签名，键盘动作接 Tab 键名，两条近源分开看。

**怎么变成今天的意思**

**tab 的小标签支与 Tab 键截短支**  
可分别形成加标签、按键移动的动作

↓

**tab + -ed → tabbed〔双写 b〕**  
过去动作；带标签页的状态

a tabbed interface 标签页界面；tabbed browsing 标签页浏览。

**常见搭配与例句**

tabbed to the next field 用 Tab 跳到下一输入栏；tabbed sections 带标签的分区。

> The application has a tabbed interface.

这个应用采用标签页界面。

> She tabbed to the next field on the form.

她按 Tab 跳到了表单的下一输入栏。

**别混淆**

tabbed interface 是按标签组织内容，未必在说使用者按过键盘 Tab 键。

<a id="w-13"></a>

### 14. tabbing — 按 Tab 移动；加标签的过程

**音标**：/ˈtæbɪŋ/

**先抓住这个画面**

从当前输入位置按 Tab 跳到下一处，持续做这件事，可以说 tabbing；给材料加标签也能用这个动词形式。

**怎么拆**

tab 双写 b 加 -ing → tabbing，双写不让 /b/ 多读一遍。基础词有小标签、Tab 键的不同支。

**怎么变成今天的意思**

**标签名／Tab 键名 → tab 动词**  
加标签；按 Tab 移动

↓

**tab + -ing → tabbing〔双写 b〕**  
相应动作的过程

tabbing between fields 在输入栏之间按 Tab 移动；tabbing through a form 按 Tab 逐栏移动。

**常见搭配与例句**

tabbing to the next box 按 Tab 到下一框；tabbing pages 给书页加标签。

> Tabbing between the fields was quicker than using the mouse.

按 Tab 在输入栏间移动比用鼠标快。

> She was tabbing the pages she wanted to discuss.

她正在给想讨论的书页加标签。

**别混淆**

tabbing 通常说 Tab 键或加标签动作；单纯用鼠标点另一个标签页，直接说 switching tabs 往往更清楚。

## 这一组要分清什么

table 议题动词有地区差异；tablespoon 的容量看地区；tableware 总称与 cutlery 不完全同范围。
