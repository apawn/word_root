# 1007 · truth — 真实与不实之言

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

truth 与 untruth 都有古英语历史，现代 un- 帮助识别否定，但不需要把每个旧词都当现代新造。

**TRUTH：真相；UNTRUTH：说法与事实不符**

已有 truth → truthful，本页接 untruth；较专门的 truther 暂略。

- **真实、诚实与不实**：truth · truthful · untruth
- **true 真实 + -th 状态 → truths**：truths

## 词形与演化规律

truth → truthful；un- + truth → untruth。

truth 承古英语 triewð 可信、忠诚、真实词族，-th 是历史抽象名词词尾。复数可数真实陈述或事实，常见 /truːðz/，也有 /truːθs/。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [truth](#w-1) | /truːθ/ | 事实真相；真实；真理 |
| [truths](#w-4) | 英、美 /truːðz/，也读 /truːθs/ | 真实事实；真实陈述；道理〔复数〕 |
| [truthful](#w-2) | /ˈtruːθfəl/ | 诚实的；如实的 |
| [untruth](#w-3) | /ʌnˈtruːθ/ | 不实之言；谎话；不真实 |

## 逐词讲解

<a id="w-1"></a>

### 1. truth — 事实真相；真实；真理

**音标**：/truːθ/

**先抓住这个画面**

true 说一句话是真的，truth 则把那份真实、事情本来的样子当作名词谈。

**怎么拆**

接古英语 trēowþ、中古英语 trouthe，旧义也含忠实、信义。与 true 同族，现代可对照 true + -th 的抽象名词关系，不是读作 true 加 /tʰ/。

**怎么变成今天的意思**

**古英语 trēowþ → 中古英语 trouthe**  
忠实、信义；真实性

↓

**英语 truth；与 true 对应**  
真实、真相；真实道理

tell the truth 说实话，the truth about 某事真相，a universal truth 普遍真理。the truth 通常说实际情况，a truth 可以是一条真实认识。

**常见搭配与例句**

tell the truth；the truth about；in truth；a grain of truth。

> Please tell me the truth.

请告诉我实情。

> There may be a grain of truth in the rumor.

传闻里可能有一点真实成分。

**别混淆**

truth 事实、真实，opinion 看法；看法可以有理、可证，也不能只因称为 opinion 就自动免于核对事实。

<a id="w-4"></a>

### 2. truths — 真实事实；真实陈述；道理〔复数〕

**音标**：英、美 /truːðz/，也读 /truːθs/

**先抓住这个画面**

truth 可以统说真实性；把一件件确实如此的事分别讲出来，就是 truths。hard truths 是那些虽然真实，却让人不容易接受的事实。

**怎么拆**

truth + -s → truths。truth 与 true 同词族，-th 是历史上构成抽象名词的词尾；整个 truth 继承古英语 triewð 等形式。复数有 /ðz/ 与 /θs/ 两种读法。

**怎么变成今天的意思**

**古英语忠诚、可信、真实词族 → truth**  
从可靠、真实的性质，也发展出一条真实陈述的可数用法

↓

**truth 可数事实 + -s → truths**  
现代说几条事实、道理，或不同方面的真实情况

hard truths 是难以接受的事实；simple truths 是朴素的道理；uncomfortable truths 是令人不舒服的真相。

**常见搭配与例句**

hard truths；simple truths；uncomfortable truths。

> The book explores some uncomfortable truths about ambition.

这本书探讨了一些有关野心、让人不太舒服的真相。

> She explained two simple truths about teamwork.

她解释了团队合作中的两个朴素道理。

**别混淆**

the truth 常统说事实真相；several truths 则分开数几条真实陈述。复数发音存在变体，听到 /ðz/ 或 /θs/ 都可能是 truths。

<a id="w-2"></a>

### 3. truthful — 诚实的；如实的

**音标**：/ˈtruːθfəl/

**先抓住这个画面**

人说话愿意照事实来，叙述也尽量不给事实拧弯。

**怎么拆**

truth + -ful，-ful 表具有相应性质，不是 physically full of truth；与 true 的结构不同，th /θ/ 保留。

**怎么变成今天的意思**

**truth**  
真实、事实

↓

**truth + -ful → truthful**  
说实话的；符合事实的

a truthful person 诚实的人，a truthful account 如实叙述，be truthful about 对某事如实说明。

**常见搭配与例句**

a truthful answer；a truthful account；truthful about。

> She gave a truthful account of what happened.

她如实叙述了发生的事情。

> Please be truthful about how much time you need.

请如实说明你需要多少时间。

**别混淆**

true statement 说陈述属实；truthful person 说人诚实。true person 通常不能直接替换诚实的人。

<a id="w-3"></a>

### 4. untruth — 不实之言；谎话；不真实

**音标**：/ʌnˈtruːθ/

**先抓住这个画面**

说出来的话与事实对不上；有时委婉地说“这不是实话”。

**怎么拆**

un- 不 + truth 真实，已有古英语对应形式。旧词族涉及忠诚、真实，现代常用在不实陈述上。

**怎么变成今天的意思**

**古英语 untrēowþ 等形式 → 中古英语 untreuth**  
不忠实；虚假

↓

**现代 untruth**  
不实之言、谎话

tell an untruth 说不实之言，spread untruths 散播虚假说法；复数 untruths 可强调多条不实陈述。

**常见搭配与例句**

tell an untruth；spread untruths；a deliberate untruth。

> The article repeated several untruths about the event.

文章重复了几条关于事件的不实说法。

> He admitted that he had told an untruth.

他承认自己说了不实之言。

**别混淆**

lie 常明确指故意说假话；untruth 有时较委婉、只强调内容不实，但也可直指谎话。不能仅凭换词断定说话者动机。

## 这一组要分清什么

truth 真相、真实性；truthful 诚实的；untruth 不实陈述。

## 串起来练习

A truthful account should correct the untruths in the report.

一份如实的叙述应纠正报告中的不实之言。
