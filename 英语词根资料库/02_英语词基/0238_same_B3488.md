# 0238 · same — 相同；同一个

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

same 经中古英语延续，受到古诺斯语 samr 和古英语相关形式的共同历史影响。学习先分清“同一个对象”与“某种性质相同”，再看上下文比较的是什么。

**SAME：在比较的这一点上没有区别**

两件外套颜色相同，但仍是两件；两人坐同一班车，则指同一个班次。

- **基本比较**：same
- **性质名词**：sameness

## 词形与演化规律

same 是基本形容词，sameness 用 -ness 把性质名词化；抽象名词常进一步带出千篇一律的感觉。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

|---|---|---|

## 逐词讲解

<a id="w-1"></a>

### 1. same — 相同的；同一个

**音标**：/seɪm/

**先抓住这个画面**

两人指着一辆车，可能真是同一辆，也可能只是同一款；same 要结合比较的层次。

**怎么拆**

经中古英语 same，历史有古诺斯语 samr 与古英语 same、sama 等的影响，不能只凭现代字母另拆成 sa + me。

**怎么变成今天的意思**

**古诺斯语 samr；古英语 same / sama**  
相同的；相关形式共同影响英语

↓

**中古英语 same → 英语 same**  
同一个；相同的

the same person 是同一个人；the same colour 是颜色相同，不要求物体相同。常用 the same as，the same ... as；Same here. 口语说我也一样。

**常见搭配与例句**

the same as；at the same time；the same age；Same here.。

> We took the same train home.

我们乘同一班火车回家。

> Your coat is the same colour as mine.

你的外套和我的颜色相同。

**别混淆**

similar 只说相似，same 强调在所比较方面相同。We have the same bag 日常可能指同款包，并非两个人共同拥有那唯一的一只。

<a id="w-2"></a>

### 2. sameness — 相同性；千篇一律

**音标**：/ˈseɪmnəs/

**先抓住这个画面**

把几个东西摆在一起，几乎找不到区别；重复久了，也可能觉得单调。

**怎么拆**

same + -ness，末尾不发音的 e 仍保留；-ness 把相同这一性质变成名词。

**怎么变成今天的意思**

**古诺斯语 samr；古英语 same / sama**  
相同的；相关形式共同影响英语

↓

**中古英语 same → 英语 same**  
同一个；相同的

↓

**same + -ness → sameness**  
相同的性质；缺乏变化

可中性讨论相同性，也常有缺乏个性、单调的评价。the sameness of the days 是每天差不多，未必每件事精确复制。

**常见搭配与例句**

a sense of sameness；the sameness of daily life；escape the sameness。

> She wanted to escape the sameness of her daily routine.

她想摆脱日常生活的单调重复。

> The sameness of the rooms made the hotel feel impersonal.

房间千篇一律，让酒店显得缺乏个性。

**别混淆**

sameness 偏相同或单调的感觉；similarity 可以是一处相似点，复数 similarities 也常见。不能把两者都机械译成一样。

## 这一组要分清什么

same 不只是 similar“相似”；说 same 时仍要问：同一件东西，还是颜色、款式、时间等某一方面相同？

## 串起来练习

The rooms were the same size, but their sameness made the building feel dull.

房间大小相同，但千篇一律让整栋楼显得乏味。
