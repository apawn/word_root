# 1714 · index — 像指路手指，让人定位到内容

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

索引、编号、指数都能联系指示，但不能把技术含义混成一个定义；book index 与目录尤其分清。

**INDEX：指出在哪里，也指示某种水平**

index → indexer；书、数据库、经济指标分别有具体用法。

- **指示、索引与编号**：index
- **编索引主体和工具**：indexer
- **index 与 indices：指路的目录和指标**：index · indices
- **index 的索引、索引动作与规则变化**：index · indexes · indexed · indexing · indices

## 词形与演化规律

index、indicāre 拉丁指出词族 → index；index + -er → indexer。

indices 保留拉丁 index／indic- 的复数材料；英语规则形式 indexes 也用，领域有偏好，分工不是绝对禁令。

指出位置的拉丁词族进入英语，规则复数 indexes 与借来的 indices 并存，具体领域有惯用偏好。

## 逐词讲解

<a id="w-1"></a>

### 1. index — 索引；指数、指标；下标、位置编号；编索引、与指数挂钩

**音标**：/ˈɪndeks/

**先抓住这个画面**

像食指指给你看“去这里找”：书末词目指向页码，数据里的编号指向某个位置，指数则指示一种水平。

**怎么拆**

借拉丁 index，属指出、指示词族，食指和列表等意义在旧语言里已有。不是 in- 不 + dex 灵巧，就变成不灵巧。

**怎么变成今天的意思**

**拉丁 index、indicis，联系 indicāre 指出**  
指出者、指示物、食指等

↓

**英语 index 的列表与指标用法**  
指向内容所在的索引；指示水平的指数；数据位置编号

↓

**index + -er → indexer**  
编索引的人、程序或相应工具

the index of a book 书的索引，a price index 价格指数，an array index 数组位置编号，index a collection 给收藏编索引。复数 indexes、indices 按领域习惯都可见。

**常见搭配与例句**

a book index；a price index；an array index；index a collection。

> Look up the name in the index.

在索引里查这个名字。

> The programme uses an index to locate each item.

程序用位置编号来找到每一项。

**别混淆**

index 不是普通目录 table of contents 的唯一替换，书目索引常按词目找出现页；指数也不必是百分数。

<a id="w-3"></a>

### 2. indices — 指数、指标；索引〔复数之一〕；index 的复数

**音标**：/ˈɪndɪsiːz/

**先抓住这个画面**

一根手指能指出东西在哪里；目录把人指到书页，指标把人指向某种变化。indices 是 index 的多个版本。

**怎么拆**

index 来自拉丁 index，词干 indic-，表示指出者、指示物等；indices 保留拉丁复数材料，字母 c 在现代英语这里读 /s/。规则复数 indexes 也广泛使用。

**怎么变成今天的意思**

**拉丁 index、indic- → 英语 index**  
指出东西的人或物；索引、指标

↓

**拉丁复数形式 → indices；并存 indexes**  
多个索引、指标或指数

price indices 价格指数；refractive indices 折射率〔复数〕；stock indices 股票指数；book indices 书籍索引。现代不同领域对 indices、indexes 有习惯偏好。

**常见搭配与例句**

compare the indices；several performance indices。

> The chart compares price indices from several years.

图表比较了几年的价格指数。

> The report uses three indices to describe the changes.

报告用三个指标描述这些变化。

**别混淆**

不能规定 indices 只能数学、indexes 只能书籍。二者的使用确有领域倾向，具体还要看该领域惯用名称和编辑习惯。

<a id="w-4"></a>

### 3. indexes — 索引、指标〔复数〕；编索引、收录〔第三人称单数〕

**音标**：/ˈɪndeksɪz/

**先抓住这个画面**

索引把词条指向正文位置，指标把注意力指向某种状态；多份可写 indexes，动词也能说编索引、收录。

**怎么拆**

index + -es，/ks/ 后读 /ɪz/。index 借拉丁指出、指示词族的整词，另有复数 indices。

**怎么变成今天的意思**

**拉丁 index → 英语 index**  
指示物、食指；索引、指标

↓

**index + -es → indexes**  
多个索引、指标；它编索引、收录

book indexes 书籍索引；search indexes 搜索索引。

**常见搭配与例句**

indexes the documents 为文档编索引；separate indexes 分开的索引。

> The books have detailed indexes.

这些书有详细索引。

> The system indexes new documents every evening.

系统每天晚上收录新文档并编索引。

**别混淆**

indexes 是规则复数，indices 在数学等语境尤其常见；实际领域用法有偏好和交叠。

<a id="w-5"></a>

### 4. indexed — 编了索引、被收录的；与某指标挂钩的

**音标**：/ˈɪndekst/

**先抓住这个画面**

材料已经有了可检索入口，是 indexed；经济等语境还可说数值跟某项指标联动，先看对象。

**怎么拆**

index + -ed，基础末音 /s/ 后词尾读 /t/，全词末尾 /kst/；不是 /ɪd/。

**怎么变成今天的意思**

**index 名词 → 编索引、按指标调整的动词**  
按不同用途转为动作

↓

**index + -ed → indexed**  
已经编索引、已收录或挂钩的状态

indexed documents 已建索引文档；an indexed collection 有索引的藏品集。

**常见搭配与例句**

fully indexed 全部编入索引；indexed in the catalogue 收录在目录中。

> The collection has been fully indexed.

这批藏品已全部编好索引。

> The indexed documents were easy to find.

建好索引的文档很容易找到。

**别混淆**

索引常按词条、主题带你找到相关位置；目录 table of contents 则按章节结构带你看全书安排。

<a id="w-6"></a>

### 5. indexing — 编制索引；建立可检索记录的过程

**音标**：/ˈɪndeksɪŋ/

**先抓住这个画面**

先把材料里有什么、在什么位置整理成能查的入口，这个过程叫 indexing。

**怎么拆**

index + -ing，保留原拼写，不双写 x；基础名词的指示作用转成编索引动词。

**怎么变成今天的意思**

**index 指示、索引名 → 动词**  
给内容建立查找位置的入口

↓

**index + -ing → indexing**  
编索引的过程、进行动作

indexing documents 为文档编索引；book indexing 书籍索引编制。

**常见搭配与例句**

finish indexing 索引建好；automatic indexing 自动索引。

> The library was indexing the new collection.

图书馆正在给新藏品编索引。

> Indexing the documents made them easier to search.

给文档编索引后，更容易检索了。

**别混淆**

indexing 是预先组织查找入口，searching 是提出条件去找，两项工作目的相接、动作不同。

<a id="w-2"></a>

### 6. indexer — 索引编制者、索引程序；索引访问功能〔编程〕

**音标**：英 /ˈɪndeksə/；美 /ˈɪndeksər/

**先抓住这个画面**

把大量内容整理出可查入口的人或程序；技术里也可专指用索引读取对象内容的功能。

**怎么拆**

index 编索引、索引 + -er，工具、人物或相应功能名称。不是指标上涨的人。

**怎么变成今天的意思**

**拉丁 index、indicis，联系 indicāre 指出**  
指出者、指示物、食指等

↓

**英语 index 的列表与指标用法**  
指向内容所在的索引；指示水平的指数；数据位置编号

↓

**index + -er → indexer**  
编制索引的人、程序及相关功能

a professional indexer 专业索引编制者，a search indexer 搜索索引程序，the database indexer 数据库索引工具等。

**常见搭配与例句**

a professional indexer；a search indexer；an indexer process。

> A professional indexer prepared the book’s index.

专业索引编制者为这本书编了索引。

> The indexer processed the new documents overnight.

索引程序连夜处理了新文档。

**别混淆**

indexer 主体、工具或功能，index 是结果、数据结构、编号等；不同软件专门定义还须看所在语境。

## 这一组要分清什么

index/table of contents 词目索引与篇章目录；index/indexer 结果结构与编制者；indexes/indices 依领域习惯。

## 串起来练习

The indexer built an index so readers could find the topic quickly.

索引编制者做出了索引，让读者能很快找到主题。
