# 0835 · network — 网状结构；相互连接的系统；建立联系

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

net + work，早期网状构造义逐步扩展到线路、传播、社会关系等连接系统。现代 network 也可作动词，表示联网或建立人际联系。

**NETWORK：先看到节点之间有连接**

一张渔网有绳结与网线；计算机、道路、人际关系也能按这种连接结构理解。

- **网状构造和系统**：net · network
- **连接后的状态**：networked

## 词形与演化规律

network + -ed → networked。词中 work 这里是构造、制成物等关系，不是每次都直译成网正在工作。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-3"></a>

### 1. net — 网；用网捕捉；净的；净得

**音标**：/net/

**先抓住这个画面**

一边是一根根线连成的网，另一边是把应扣部分拿走后剩下的净数。两个画面分别记。

**怎么拆**

网继承古英语 net(t)。净的经古法语 net 追到拉丁语 nitidus 明亮、洁净。它们只是后来同形，不能把净利润编成渔网捞到的钱。

**怎么变成今天的意思**

**两条独立来路：古英语 net(t)；拉丁语 nitidus → 古法语 net**  
前者是网；后者是明亮、洁净

↓

**英语 net**  
网、用网捕捉；另一支为净的、扣除后的

a fishing net 捕鱼网；net a goal 把球打进球门。net weight 净重扣掉包装，net profit 净利润扣掉相关成本费用；net 也可作动词表示净得。the Net 常简称互联网。

**常见搭配与例句**

a safety net；a mosquito net；net weight；net profit；net a goal。

> The ball landed in the net.

球落进了网里。

> The net weight excludes the packaging.

净重不包括包装。

> The school fair netted enough money to buy new books.

学校义卖净得的钱足够买一批新书。

**别混淆**

gross 总的、未扣除的，net 净的、扣除后的；具体扣什么由所谈的重量、收入等决定。网络词中的 net 属于网这一支。

<a id="w-1"></a>

### 2. network — 网络；人脉网；建立联系

**音标**：英 /ˈnetwɜːk/；美 /ˈnetwɜːrk/

**先抓住这个画面**

一个点连着多个点，再连成一张网；节点可以是电脑、道路，也可以是人。

**怎么拆**

net（网）+ work（制成物、结构），先有网状结构等实体用法，后来扩大到相连系统。不是 computer 时代才首次出现的词。

**怎么变成今天的意思**

**英语 net；work**  
并列的两个构词材料

↓

**net + work → network**  
网状结构 → 相连的系统或关系

a rail network 是铁路网，a computer network 是计算机网络，a network of friends 是朋友支持网。动词 network 常说在职业场合结识人、建立联系。

**常见搭配与例句**

a support network；a network connection；network with colleagues。

> The storm damaged the railway network.

暴风雨损坏了铁路网。

> The event gave young designers a chance to network.

活动让年轻设计师有机会结识同行、建立联系。

**别混淆**

internet 是一种特定的全球互联体系；network 范围更宽，可以完全没有互联网连接。

<a id="w-2"></a>

### 3. networked — 联网的；通过网络相连的；建立了联系〔动词形式〕

**音标**：英 /ˈnetwɜːkt/；美 /ˈnetwɜːrkt/

**先抓住这个画面**

几台设备不再各干各的，而是连成一张可以交换信息的网；人、机构也可以形成相互联系的网络。

**怎么拆**

network + -ed，作动词过去式、分词，再作形容词。network 原由 net + work 形成网状构造名称，后来广泛说连接系统、人际网络。

**怎么变成今天的意思**

**net + work → network**  
网状构造；相互连接的系统

↓

**network + -ed → networked**  
已连接成网；有网络联系的

networked computers 联网计算机；a networked society 相互连接的社会。networked 不一定指接入互联网，也可以是内部网络。

**常见搭配与例句**

networked devices；a networked organization。

> The office uses networked printers.

办公室使用联网打印机。

> The exhibition connected several networked screens.

展览把几块屏幕连在同一个网络上。

**别混淆**

wireless 说不用线路，networked 说是否成网；有线设备也可以 networked，无线设备也不必已经连上某个网。

## 这一组要分清什么

network 不只互联网；networked 不一定无线。network 作动词谈人时常说建立、维护联系，不是把人接上电缆。

## 串起来练习

The network links several networked devices.

这个网络连接着几台联网设备。
