# 1735 · mere — 仅仅、纯粹与另一条水体词源

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

同形词要按来源分：merely asking 只是问，a mere 湖、marsh 湿地不能靠只有这个意思硬解释。

**MERE：常用形容词从纯粹来，湖和沼泽另走水体路**

mere → merely 是仅仅分支；marsh 经早期水体同族构词而来。

- **仅仅与副词**：mere · merely
- **水体词族的湿地名称**：marsh

## 词形与演化规律

merus 经法语 → mere 形容词 → merely；古英语 mere 水体；水体词族 merisc、mersc → marsh。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [mere](#w-2) | 英 /mɪə/；美 /mɪr/ | 仅仅的、不过是的；纯粹的；湖、池〔另名词来源，较多见地名〕 |
| [merely](#w-1) | 英 /ˈmɪəli/；美 /ˈmɪrli/ | 仅仅、只是、不过 |
| [marsh](#w-3) | 英 /mɑːʃ/；美 /mɑːrʃ/ | 沼泽、草本湿地 |

## 逐词讲解

<a id="w-2"></a>

### 1. mere — 仅仅的、不过是的；纯粹的；湖、池〔另名词来源，较多见地名〕

**音标**：英 /mɪə/；美 /mɪr/

**先抓住这个画面**

a mere ten minutes 是仅仅十分钟，the mere thought 是光想到这一点；湖名中的 mere 却沿水体旧词，和“仅仅”没有直接意思关系。

**怎么拆**

形容词经法语接拉丁 merus 纯的，后来有不外乎、只有等义；湖水名词继承古英语 mere。另有边界等更旧同形词，本页常用义先分两路。

**怎么变成今天的意思**

**拉丁 merus → 法语 mier、meer → mere〔形容词〕**  
纯、不掺杂 → 仅仅、不外乎；旧纯粹强调义也有保留

↓

**古英语 mere → mere〔湖水名词〕**  
海、湖、水体；与形容词分源

↓

**古英语 merisc、mersc → marsh**  
沿水体词族的湿地名称；不是 mere 仅仅加后缀

a mere child 不过是个孩子，a mere ten minutes 仅十分钟，the mere thought 光是这个想法，a shallow mere 浅湖〔地理描写〕。

**常见搭配与例句**

a mere child；a mere ten minutes；the mere thought；a shallow mere。

> The repair took a mere ten minutes.

修理只花了十分钟。

> The mere thought of the journey excited her.

光想到这趟旅程就让她兴奋。

**别混淆**

mere 常放名词前，merely 副词；mere 湖名与形容词不同源，不能把 Windermere 一类地名按仅仅解释。

<a id="w-1"></a>

### 2. merely — 仅仅、只是、不过

**音标**：英 /ˈmɪəli/；美 /ˈmɪrli/

**先抓住这个画面**

把额外的解释拿掉：我只是问问，并没有暗示别的；也可强调某事没达到你期待的更高程度。

**怎么拆**

mere 仅仅的 + -ly，中古英语已有 mereli 等形式；接形容词的纯粹、仅仅分支，不接湖名词。

**怎么变成今天的意思**

**拉丁 merus → 法语 mier、meer → mere〔形容词〕**  
纯、不掺杂 → 仅仅、不外乎；旧纯粹强调义也有保留

↓

**mere + -ly → merely**  
仅仅地、不外乎

merely a suggestion 只是个建议，not merely 不仅仅，merely because 仅因为，merely asking 只是问问。

**常见搭配与例句**

merely a suggestion；not merely；merely because；merely asking。

> I was merely asking a question.

我只是问个问题。

> The change is not merely cosmetic.

变化不只是表面修饰。

**别混淆**

merely 较书面对应 only、just 的某些用法；mere 修饰名词，merely 可修饰更宽的表达，不是把 merely 当动词使用。

<a id="w-3"></a>

### 3. marsh — 沼泽、草本湿地

**音标**：英 /mɑːʃ/；美 /mɑːrʃ/

**先抓住这个画面**

地势低湿、经常积水，长着草本湿地植物的一片地；不是任何有点泥的路面都叫 marsh。

**怎么拆**

继承古英语 mersc、merisc，经中古英语 mersch 等到 marsh；更早在水体 mere 同族词基上构成湿地名称，不是现代 mere 仅仅变了几字母。

**怎么变成今天的意思**

**古英语 mere → mere〔湖水名词〕**  
海、湖、水体；与形容词分源

↓

**水体词族 → 古英语 merisc、mersc → mersch → marsh**  
水边、湿地性质 → 沼泽名称

a salt marsh 盐沼，marsh grass 沼泽草，birds in the marsh 沼泽中的鸟，marsh habitat 湿地生境。

**常见搭配与例句**

a salt marsh；marsh grass；marsh habitat。

> Birds nested in the marsh.

鸟在沼泽里筑巢。

> A path crossed the salt marsh.

一条小路穿过盐沼。

**别混淆**

marsh 湿地类型，mere 水体名常湖池；swamp、bog 也可湿地，但生态分类、地区习惯不同，不能永远随意互换。

## 这一组要分清什么

mere/merely 形容副词；mere 两条来源；marsh/mere 湿地与水体；swamp/bog/marsh 不能无差别套用。

## 串起来练习

The crossing took a mere hour, but the marsh was not merely empty land.

穿越只花一小时，不过沼泽并不只是一片空地。
