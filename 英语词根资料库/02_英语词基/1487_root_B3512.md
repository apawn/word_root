# 1487 · root — 植物根、来源、扎根与拔根；拱土和喝彩分支

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

根能引出原因、词根、生活背景，但并非同形 root 每个义都由植物根直线派生。支持球队、拱土的历史关系要分别交代。

**ROOT：先抓固定、供养的根，再追到来源和生活根基**

root → rooting；beetroot 食材；rootstock 支撑基株；uproot 拔根、迁离；rootkit 技术词选系统根权限等支。

- **根与根的变化**：root · rooting
- **食材和根基植物**：beetroot · rootstock
- **拔根与技术组合**：uproot · rootkit
- **root → roots：根部、来源与词根**：root · roots
- **beet → beetroot：甜菜到甜菜根**：beet · beetroot
- **root → rooted：扎根与有根据**：rooted

## 词形与演化规律

rót → root 名词及生根动词；wrōtan → 拱土 root；root for 的习语来源有讨论；root + -ing/stock/kit；beet + root；up- + root。

植物根接北欧词族，拱土和支持喝彩的动词各有历史，本次以根与来源为重点。

beet 经古英语 bete 借拉丁 beta；beet + root 是甜菜的根。不是英语 beat 打击改一个字母形成。

植物根的 root 接古英语、北欧相应词族；生根、扎根动词在此词线发展。root + -ed，/t/ 后读 /ɪd/；rooted in 常说根源、基础在某处。

## 逐词讲解

<a id="w-1"></a>

### 1. root — 根、根源、词根；生根；拱土；支持〔root for〕

**音标**：/ruːt/

**先抓住这个画面**

植物靠根固定、吸收，问题、词形也能追到根；但给别人加油的 root for 和猪拱土的 root，需要交代各自旧词、习语线。

**怎么拆**

植物名承接北欧 rót 等材料；生根动词由此发展。拱土接古英语 wrōtan 的旧动词。美式喝彩义更晚，来源解释不一，不能直接断言支持就是把植物根送给对方。

**怎么变成今天的意思**

**古北欧 rót 等 → 晚期古英语、中古英语 root**  
植物根

↓

**英语名词及相应动词**  
根 → 原因、来源、词根；生根、扎根

↓

**另有旧动词和晚出习语**  
旧 wrōtan 拱土；美式 root for 支持、喝彩的来路另有讨论

take root 生根、扎根，the root cause 根本原因，word roots 词根，root around 翻找，root for someone 为某人加油。

**常见搭配与例句**

take root；the root cause；word roots；root around；root for。

> The idea took root in the community.

这个想法在社区扎下了根。

> I’ll be rooting for you in the final.

决赛时我会为你加油。

**别混淆**

root 根与 route 路线在部分口音同音，拼写和意义分开；root for 支持人，root out 清除问题等不能换介词。

<a id="w-7"></a>

### 2. roots — 根部；根源、出身；词根；数学的根〔复数〕

**音标**：/ruːts/

**先抓住这个画面**

植物靠根扎住、吸收生长所需；一个问题从哪里生出、一个词从什么基本材料长出来，也都可以用 roots 的根与来源画面理解。

**怎么拆**

root + -s，/t/ 后读 /s/。植物根的词承接北欧 rót 等材料，较早进入英语；原因、出身、词根等为相关引申。拱土的旧动词和 root for 支持的晚出表达，各有需另辨的历史。

**怎么变成今天的意思**

**北欧 rót 等 → 较早英语、中古英语 root**  
植物的根

↓

**root + -s → roots；相关引申**  
多条根 → 根源、出身、构词根本材料

tree roots 树根；family roots 家族根源；roots of the problem 问题根源；word roots 词根；square roots 平方根。

**常见搭配与例句**

put down roots；trace the roots of a word。

> The roots of the tree had lifted part of the path.

树根把一部分路面顶了起来。

> Learning word roots can help you recognize related words.

学习词根有助于识别相关单词。

> The book explores the roots of the disagreement.

这本书探究了分歧的根源。

**别混淆**

put down roots 可以说植物扎根，也可说人在一个地方安定下来。词根 roots 说构词的根本材料，但现代英语基本词与更早不可再分的历史词根，分析层次可能不同。

<a id="w-9"></a>

### 3. rooted — 扎根的；根源在……的；牢牢固定的〔过去式、过去分词〕

**音标**：英、美 /ˈruːtɪd/

**先抓住这个画面**

植物把根扎进土里，是 rooted；习惯、想法在某种经历里长出来，也可以说 rooted in that experience。

**怎么拆**

root + -ed → rooted，/t/ 后读 /ɪd/。植物根的 root 接古英语、古北欧相应材料，动词的扎根、使固定从名词发展。

**怎么变成今天的意思**

**古英语、北欧植物根材料 → root 名词**  
后来也借根说来源、根本

↓

**root 的生根、固定动词 → rooted**  
现代常说扎根、以某事为根源或依据

rooted in the soil 是扎在土里；rooted in experience 是源自经验；rooted to the spot 是像生根一样站住不动。

**常见搭配与例句**

rooted in the soil；rooted in experience；rooted to the spot。

> The tree was firmly rooted in the soil.

这棵树牢牢扎根在土里。

> Her interest in music is rooted in childhood memories.

她对音乐的兴趣源自童年记忆。

**别混淆**

rooted in 常说来源、基础；不必真有根。root for 支持、加油又是另一路用法，不能一概按植物故事推。

<a id="w-2"></a>

### 4. rooting — 生根、扎根；翻拱、翻找；加油支持〔rooting for〕

**音标**：/ˈruːtɪŋ/

**先抓住这个画面**

先看后面跟什么：rooting a cutting 让插枝生根，rooting around 四处翻找，rooting for a team 给球队加油；一个 -ing 盖不掉词基的分支。

**怎么拆**

root + -ing，生根名词、各类动词形式分别接 root 的对应来源。不要把所有 rooting 都当植物学过程。

**怎么变成今天的意思**

**古北欧 rót 等 → 晚期古英语、中古英语 root**  
植物根

↓

**英语名词及相应动词**  
根 → 原因、来源、词根；生根、扎根

↓

**另有旧动词和晚出习语**  
旧 wrōtan 拱土；美式 root for 支持、喝彩的来路另有讨论

↓

**root + -ing → rooting**  
生根、翻找或喝彩的形式，按所选动词义分

rooting cuttings 使插枝生根，rooting around in a drawer 翻抽屉，rooting for the home team 支持主队。

**常见搭配与例句**

rooting cuttings；rooting around；rooting for。

> The cuttings are rooting in the nursery.

插枝正在苗圃里生根。

> Everyone in the room was rooting for the same team.

屋里所有人都在支持同一支球队。

**别混淆**

rooting for 后接支持的对象，rooting around 常接翻找地点；routing 可是规划路线等，少了一个 o 不是同一词。

<a id="w-5"></a>

### 5. rootstock — 砧木、根砧；植物的根基部分

**音标**：英 /ˈruːtstɒk/；美 /ˈruːtstɑːk/

**先抓住这个画面**

嫁接时，下面那株负责长根、支撑，上面接想要的枝条；下面提供根基的植物就是 rootstock。

**怎么拆**

root 根 + stock 植株基部、基株等材料。stock 在这里不是股票，也不是仓库库存；词名按植物支撑功能解释。

**怎么变成今天的意思**

**古北欧 rót 等 → 晚期古英语、中古英语 root**  
植物根

↓

**root + stock → rootstock**  
提供根部、根基的植株，尤嫁接砧木

a hardy rootstock 强健砧木，graft onto rootstock 嫁接到砧木上，a dwarfing rootstock 矮化砧木。这里只认名称，不由字面推全部栽培特性。

**常见搭配与例句**

a hardy rootstock；graft onto rootstock；a dwarfing rootstock。

> The label identifies the rootstock used for the tree.

标签注明了这棵树使用的砧木。

> The grower selected a hardy rootstock.

种植者选了强健的砧木。

**别混淆**

rootstock 下面提供根基的植株，scion 接上去的接穗；两者都属嫁接术语但位置、作用不同。

<a id="w-6"></a>

### 6. rootkit — 隐蔽控制系统的一组恶意软件工具、根套件

**音标**：/ˈruːtkɪt/

**先抓住这个画面**

把控制计算机、隐藏痕迹等工具配成一套；root 在这里接系统高权限那条技术用法，不是植物根部修剪工具包。

**怎么拆**

root 系统特权用户、根权限相关名称 + kit 工具套件，命名一类隐蔽控制系统的软件工具。现代用法不要求每个变种一定只在类 Unix 系统。

**怎么变成今天的意思**

**中古荷兰语 kitte 等 → 英语 kit〔容器、装备〕**  
装东西的器具 → 里面成套的用品、装备

↓

**root〔系统权限名〕+ kit → rootkit**  
用于隐蔽控制系统的软件工具集合

detect a rootkit 检出根套件，a rootkit infection 根套件感染，rootkit detection 根套件检测。

**常见搭配与例句**

detect a rootkit；rootkit detection；a rootkit infection。

> The security scan detected a rootkit.

安全扫描检测到了一组隐蔽控制软件。

> The report explains why rootkit detection can be difficult.

报告解释了为什么根套件可能难以检测。

**别混淆**

rootkit 是安全语境的特定工具类，不是所有需要管理员权限的正常软件；toolkit 则只是广义工具包。

<a id="w-4"></a>

### 7. uproot — 连根拔起；使迁离熟悉环境、连根迁移

**音标**：/ˌʌpˈruːt/

**先抓住这个画面**

不只摘叶子，而是把原来扎住的根也拔起来；人被迫离开生活已扎根的地方，也会有 uprooted 的失去根基感。

**怎么拆**

up- 向上、移起 + root 根及拔根动词。英语有很早的相应构造；人的迁移比喻借生活根基，不要求身体真有植物根。

**怎么变成今天的意思**

**古北欧 rót 等 → 晚期古英语、中古英语 root**  
植物根

↓

**英语名词及相应动词**  
根 → 原因、来源、词根；生根、扎根

↓

**up- + root → uproot**  
把根拔起 → 迁离既有生活环境

uproot a tree 把树连根拔起，uproot a family 让一家迁离，be uprooted by conflict 因冲突流离失所。也可说主动 uproot yourself 搬离熟悉环境。

**常见搭配与例句**

uproot a tree；uproot a family；be uprooted。

> The storm uprooted several trees.

风暴把几棵树连根拔起。

> Moving overseas meant uprooting the whole family.

移居海外意味着全家离开熟悉的生活环境。

**别混淆**

uproot 常强调原有根基被动摇、搬离，move 更中性；不是任何挪动一张椅子都用 uproot。

<a id="w-8"></a>

### 8. beet — 甜菜；〔尤美〕甜菜根

**音标**：英、美 /biːt/

**先抓住这个画面**

切开会留下深红汁液的圆根，英语里常叫 beet 或 beetroot。甜菜也包括不同栽培类型，不是每次说 beet 都只指同一种红根。

**怎么拆**

经古英语 bete 借拉丁 beta 植物名；更远有凯尔特语来源的说法，但并不完全确定。beet + root 才是把“根”明说出来的复合词。

**怎么变成今天的意思**

**拉丁 beta 甜菜 → 古英语 bete → 英语 beet**  
早期借入的植物名

↓

**beet + root → beetroot**  
把植物名与根组合，明确所吃的部位

a beet 数一个根菜；beet salad 是甜菜沙拉；sugar beet 是制糖用的甜菜。美式日常食物语境也常见复数 beets。

**常见搭配与例句**

a roasted beet；beet salad；sugar beet。

> She sliced a roasted beet into the salad.

她把一颗烤甜菜切片加进沙拉。

> The farm grows sugar beet.

农场种植糖用甜菜。

**别混淆**

beet 与 beat 击打同音，来源不同。beetroot 的 root 才是根的意思，不能漏掉这层组合关系。

<a id="w-3"></a>

### 9. beetroot — 甜菜根、红菜头

**音标**：/ˈbiːtruːt/

**先抓住这个画面**

把 beet 甜菜的可食根部拿出来命名；常见深红色，切开容易让人记住，但不同品种也有其他颜色。

**怎么拆**

beet 甜菜 + root 根，英式常用整词称菜根；美式食物语境常直接说 beet。不是把 beat 打击 + root 拼成打根。

**怎么变成今天的意思**

**古北欧 rót 等 → 晚期古英语、中古英语 root**  
植物根

↓

**beet + root → beetroot**  
甜菜的根部、作为蔬菜的根

pickled beetroot 腌甜菜根，beetroot salad 甜菜根沙拉，beetroot juice 甜菜根汁。

**常见搭配与例句**

pickled beetroot；beetroot salad；beetroot juice。

> She added sliced beetroot to the salad.

她往沙拉里加了切片甜菜根。

> The sandwich came with pickled beetroot.

三明治配了腌甜菜根。

**别混淆**

beetroot 根菜，beet greens 甜菜叶；同一株植物的不同食材部位，不把 root 省到哪里都毫无区别。

## 这一组要分清什么

root/route 根与路线；root for/root out 支持与清除；rootstock/scion 砧木与接穗；rootkit 不等于所有管理员工具。

## 串起来练习

The gardener watched the cuttings rooting and checked the rootstock before uprooting an old tree.

园丁观察插枝生根、检查砧木，然后去拔一棵老树。
