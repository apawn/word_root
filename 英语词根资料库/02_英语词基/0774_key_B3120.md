# 0774 · key — 钥匙、按键、关键与音乐中心

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

key 继承古英语 cǣġ，更远来源不明。音乐的调与乐器键还接欧洲音乐术语传统，不能把所有意义都当现代开门记忆故事。

**KEY：打开、控制、解答与中心作用**

把钥匙物件、键盘按键和音乐中心分组，再看 keynote、keystone、turnkey 各自的具体故事。

- **核心与钥匙物件**：key · keyless · keyhole · keyring · keychain
- **按键与信息输入**：keyboard · keypad · keystroke · keyword
- **中心、支撑与即用交付**：keynote · keystone · turnkey
- **key → keys：开锁工具、按键与答案关键**：key · keys
- **key 的两种用品组合：钥匙孔与钥匙环**：key · keyhole · keyholes · keyring · keyrings
- **key 的输入组合：键盘、按键小面板**：key · keyboard · keyboards · keypad · keypads

## 词形与演化规律

key → keyless；key + hole、ring、chain；键义 → keyboard、keypad、keystroke；keynote 音乐主音 → 主旨；keystone 拱顶石 → 核心。

本族钥匙词与音乐语境的拉丁 clavis 影响共同参与相关意义发展。

hole 提供开口，ring 提供环状器具，不能换成音乐键和响铃义。

key 取键的用法，和钥匙的器物用途分别认。

## 逐词讲解

<a id="w-1"></a>

### 1. key — 钥匙；键；关键；答案；音乐的调

**音标**：/kiː/

**先抓住这个画面**

钥匙让门开起来，关键办法让问题解开；钢琴、键盘上用手按的部件也叫 key，但要分清各自的使用史。

**怎么拆**

继承古英语 cǣġ，更远来源不确定。音乐中的调、乐器上的键等用法受拉丁 clavis 钥匙及相关音乐传统影响，不全是英语开门比喻一条线直接变来。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

the key to the problem 问题的关键，an answer key 答案表，press a key 按键；in the key of C 指 C 调。作形容词 a key issue 是关键问题。

**常见搭配与例句**

the key to；a key issue；press a key；an answer key。

> Clear communication is the key to a successful project.

清楚的沟通是项目成功的关键。

> Press any key to continue.

按任意键继续。

**别混淆**

key to success 的 to 是介词，可接名词、动名词；the Florida Keys 中 Keys 是小岛名词，另接西班牙语及泰诺语来源，不是钥匙复数义。

<a id="w-13"></a>

### 2. keys — 钥匙；键；调；答案、关键〔复数〕；键入〔第三人称单数〕

**音标**：/kiːz/

**先抓住这个画面**

能把锁打开的是 keys；能把问题打开的答案、关键，也沿用钥匙的形象。键盘的键和音乐的调则有各自的专业发展。

**怎么拆**

key + -s，元音后读 /z/；y 前是元音 e，保留 y。key 继承古英语 cǣġ，远源不定；音乐相关义还受拉丁 clāvis 钥匙及相关传统影响，不只是一条现代开门比喻。

**怎么变成今天的意思**

**古英语 cǣġ → key；音乐传统另有 clāvis 影响**  
钥匙 → 关键、按键；调等专门义

↓

**key + -s → keys**  
多把钥匙、多个键或答案；单数主语键入

house keys 房门钥匙；piano keys 钢琴键；answer keys 参考答案；keys in the number 键入数字。

**常见搭配与例句**

the keys to the cupboard；press the keys。

> She left her keys on the kitchen table.

她把钥匙落在了厨房桌上。

> The answer keys are printed at the back of the book.

参考答案印在书的后面。

**别混淆**

keys 的复数直接加 s，与 valleys 相同；reply 的 y 前是辅音，复数 replies。answer keys 是列出答案的材料，the key to something 常说某事的关键。

<a id="w-2"></a>

### 3. keyboard — 键盘；键盘乐器

**音标**：英 /ˈkiːbɔːd/；美 /ˈkiːbɔːrd/

**先抓住这个画面**

一整排或几排按键装在同一个面板上，按它们来打字、输入或演奏。

**怎么拆**

key 键 + board 板、面板。用于乐器按键系统，后来也用于打字机、计算机等输入设备；不是开锁钥匙摆放板。

**怎么变成今天的意思**

**key 按键；board 面板**  
并列构词部分

↓

**keyboard**  
成组按键构成的键盘

a computer keyboard 计算机键盘，a piano keyboard 钢琴键盘；play keyboards 常说演奏电子键盘等键盘乐器。

**常见搭配与例句**

type on a keyboard；a keyboard shortcut；a piano keyboard。

> She typed the address on the keyboard.

她在键盘上输入了地址。

> He plays keyboards in a local band.

他在当地一支乐队里弹键盘。

**别混淆**

keyboard 是输入或演奏的一组键，keypad 常指较小的按键区，如数字键区；实际设备名称依设计。

<a id="w-16"></a>

### 4. keyboards — 键盘、键盘乐器〔复数〕

**音标**：英 /ˈkiːbɔːdz/；美 /ˈkiːbɔːrdz/

**先抓住这个画面**

一组可按的键排在面板上，是 keyboards。乐器、打字设备、电脑都可以沿这个结构名称理解。

**怎么拆**

key 键 + board 板、面板 → keyboard，乐器用法较早，后来进入打字、计算机设备。现代加 -s，/d/ 后读 /z/。

**怎么变成今天的意思**

**key + board → keyboard**  
成组按键的面板、系统

↓

**keyboard + -s → keyboards**  
多套键盘、键盘乐器

computer keyboards 电脑键盘；electronic keyboards 电子键盘乐器〔音乐语境〕。

**常见搭配与例句**

clean the keyboards 清洁键盘；play keyboards 演奏键盘乐器。

> The classroom has new computer keyboards.

教室装了新电脑键盘。

> She plays keyboards in a band.

她在乐队里演奏键盘乐器。

**别混淆**

computer、typing 常选出输入设备，play、band 常选出乐器。两类都借成组按键的结构。

### 5. keynote — 音乐主音；主旨、基调；主题演讲

**音标**：英 /ˈkiːnəʊt/；美 /ˈkiːnoʊt/

**先抓住这个画面**

音乐先有一个中心音，其他音围绕它组织；演讲或会议也可以有一个给全场定基调的中心主题。

**怎么拆**

key 音乐的调 + note 音符，先见音乐主音义，后用于主要思想、基调，再有 keynote speech 主旨演讲；不是钥匙上的便条。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**key + note → keynote**  
调的主音 → 中心主题、主旨演讲

give a keynote 发表主旨演讲，a keynote speaker 主旨演讲嘉宾，the keynote of the speech 演讲的基调。

**常见搭配与例句**

a keynote speech；a keynote speaker；deliver the keynote。

> She will deliver the keynote at the conference.

她将在会议上发表主旨演讲。

> Cooperation was the keynote of his speech.

合作是他演讲的主旨。

**别混淆**

keynote 是定主题、基调的演讲，不等于所有会议发言；note 在此的历史起点是音乐音符。

### 6. keystone — 拱顶石；关键基础、核心支撑

**音标**：英 /ˈkiːstəʊn/；美 /ˈkiːstoʊn/

**先抓住这个画面**

想一座石拱，顶上正中那块石头把两边结构合在一起；再借它说一个体系不可缺的核心支撑。

**怎么拆**

key 使其他部分结合的关键 + stone 石头。建筑义先指拱顶中间起锁合作用的石块，后有体系核心的比喻义。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**key + stone → keystone**  
锁合石拱的石块 → 核心支撑

the keystone of the policy 政策的核心支撑；keystone species 关键种借喻其对生态系统有关键作用。

**常见搭配与例句**

the keystone of；a stone arch keystone；a keystone species。

> Trust is the keystone of their partnership.

信任是他们合作关系的核心支撑。

> The arch has a carved keystone at its highest point.

石拱最高处有一块雕刻的拱顶石。

**别混淆**

keystone 不是随便一块重要石头，建筑里有特定位置与作用；cornerstone 基石是另一建筑比喻。

### 7. keyword — 关键词；编程语言中的关键字

**音标**：英 /ˈkiːwɜːd/；美 /ˈkiːwɜːrd/

**先抓住这个画面**

一段内容里最能抓住重点的词，或搜索时拿来缩小范围的词；编程里又是语言规定有特别作用的词。

**怎么拆**

key 关键的 + word 词。key 在这里是重要、关键的比喻，不是键盘上随便按出的任意单词。

**怎么变成今天的意思**

**key 关键的；word 词**  
并列构词部分

↓

**keyword**  
表示主题、检索重点或语言特定作用的词

search by keyword 按关键词搜索，a programming keyword 编程关键字；搜索系统里 keyword 也可能包含短语，按工具用法。

**常见搭配与例句**

search keywords；a keyword search；identify keywords；a programming keyword。

> Choose a few keywords before searching the archive.

查档案前先选几个关键词。

> The teacher highlighted the keywords in the paragraph.

老师标出了段落中的关键词。

**别混淆**

keyword 不必是全文出现最多的词；password 验证身份，keyword 搜索、概括或执行特定语言作用。

### 8. keypad — 小键盘；数字键盘

**音标**：/ˈkiːpæd/

**先抓住这个画面**

一小组聚在一起的按键，比如门禁输入数字的区域，或电脑键盘右侧的数字区。

**怎么拆**

key 按键 + pad 小块、垫状面板，组合成集中一组按键的输入部件。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**key + pad → keypad**  
按键组成的小面板 → 小键盘

a numeric keypad 数字小键盘，a door keypad 门禁键盘，enter a code on the keypad 在小键盘输入代码。

**常见搭配与例句**

a numeric keypad；a door keypad；use the keypad。

> Enter your code on the keypad beside the door.

在门旁的小键盘上输入你的代码。

> This keyboard has a separate numeric keypad.

这个键盘带有独立的数字小键盘。

**别混淆**

keyboard 常说完整键盘，keypad 通常是一小组按键；手机屏幕也可显示虚拟 keypad。

### 9. keypads — 按键面板、小键盘〔复数〕

**音标**：/ˈkiːpædz/

**先抓住这个画面**

小块面板上集中一组数字、功能键，是 keypads。key 给按键，pad 给集中操作的一小块面。

**怎么拆**

key + pad → keypad，现代整词加 -s，/d/ 后读 /z/。原词各部分的常用物件义在组合中清楚可认。

**怎么变成今天的意思**

**key + pad → keypad**  
按键集中在小面板上的输入部件

↓

**keypad + -s → keypads**  
多个按键面板

numeric keypads 数字小键盘；keypads on the machines 机器上的按键面板。

**常见搭配与例句**

use the keypads 使用按键面板；keypads beside the doors 门旁的按键面板。

> The machines have simple numeric keypads.

机器配有简单数字小键盘。

> The keypads beside the doors were worn.

门旁按键面板磨损了。

**别混淆**

keyboard 往往更大、可有完整字母键；keypad 常是一小组数字、功能键。具体大小不是严格词义界线。

### 10. keyhole — 钥匙孔

**音标**：英 /ˈkiːhəʊl/；美 /ˈkiːhoʊl/

**先抓住这个画面**

锁上供钥匙插进去的小孔，后来相似的小开口也可能借这个形状命名。

**怎么拆**

key + hole 孔，按用途直接组合。keyhole 不是门上所有洞的统称。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**key + hole → keyhole**  
供钥匙使用的孔 → 钥匙孔

put a key in the keyhole 把钥匙插进锁孔，look through the keyhole 从锁孔往里看；keyhole surgery 是小切口手术的形象名称。

**常见搭配与例句**

the keyhole of a lock；look through the keyhole；a keyhole shape。

> The key would not fit into the keyhole.

这把钥匙插不进锁孔。

> Light shone through the old keyhole.

光从旧钥匙孔里透出来。

**别混淆**

keyhole 是锁孔，peephole 是专门供人观察的窥视孔、门镜；二者用途不同。

### 11. keyholes — 钥匙孔〔复数〕

**音标**：英 /ˈkiːhəʊlz/；美 /ˈkiːhoʊlz/

**先抓住这个画面**

让钥匙伸进去操作锁的孔，就是 keyholes。key 给用途，hole 给孔洞形状。

**怎么拆**

key + hole → keyhole，现代加 -s，/l/ 后读 /z/。前部 key 是开锁器具，不取音乐调性或键盘键的用法。

**怎么变成今天的意思**

**key + hole → keyhole**  
给钥匙进入的孔

↓

**keyhole + -s → keyholes**  
多个钥匙孔

old keyholes 旧式钥匙孔；covers over the keyholes 钥匙孔上的盖片。

**常见搭配与例句**

keyholes in the doors 门上的钥匙孔；look through keyholes 从钥匙孔看。

> The old doors had large keyholes.

旧门上有大钥匙孔。

> Small covers protected the keyholes.

小盖片护着钥匙孔。

**别混淆**

门上其他用途的孔，不因位置相同就都叫 keyhole。这个组合靠钥匙这一用途限定。

### 12. keychain — 钥匙链；钥匙挂件

**音标**：/ˈkiːtʃeɪn/

**先抓住这个画面**

一件把钥匙串住、方便携带的小物，常带链条、环或装饰。

**怎么拆**

key + chain 链条，按用途与结构组合。现代名词不要求每种商品都有明显长链。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**key + chain → keychain**  
挂钥匙的链 → 钥匙链、挂件

a leather keychain 皮革钥匙挂件，a keychain charm 钥匙链饰物；软件中 keychain 另可借喻凭据存储，需看产品语境。

**常见搭配与例句**

a leather keychain；a souvenir keychain；a keychain charm。

> He bought a keychain as a souvenir.

他买了一个钥匙挂件作纪念。

> A small torch hung from her keychain.

她的钥匙链上挂着一个小手电筒。

**别混淆**

keychain 通常是整件挂钥匙的小物，chain 单独只是链条；数字 keychain 不是电脑里真的放了金属钥匙。

<a id="w-10"></a>

### 13. keyless — 无钥匙的；无需传统钥匙操作的

**音标**：/ˈkiːləs/

**先抓住这个画面**

门仍需要控制开启，只是不用把传统金属钥匙插进锁里。

**怎么拆**

key + -less 没有，形成无钥匙的形容词。现代车辆、门禁语境可能用遥控、感应等方式，名称不表示没有认证。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**key + -less → keyless**  
没有钥匙 → 无需传统钥匙操作

keyless entry 无钥匙进入，a keyless lock 无钥匙门锁；具体技术由系统决定。

**常见搭配与例句**

keyless entry；a keyless lock；keyless access。

> The car comes with keyless entry.

这辆车配有无钥匙进入功能。

> The hotel installed keyless locks on the guest rooms.

酒店给客房安装了无钥匙门锁。

**别混淆**

keyless 不等于 unlocked 没锁上；无钥匙系统也可以处于锁定状态。

<a id="w-11"></a>

### 14. keystroke — 一次按键；击键动作

**音标**：英 /ˈkiːstrəʊk/；美 /ˈkiːstroʊk/

**先抓住这个画面**

手指把一个键按下去，这次动作就能数成一个 keystroke。

**怎么拆**

key 按键 + stroke 一次敲击、动作，组合成一次击键。stroke 在这里不是脑卒中，也不是划船。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**key + stroke → keystroke**  
键 + 一次敲击 → 击键

a single keystroke 一次按键，save keystrokes 减少按键次数，keystroke shortcuts 与键盘操作有关。

**常见搭配与例句**

a single keystroke；a few keystrokes；save keystrokes。

> You can close the window with a single keystroke.

只需一次按键就能关闭窗口。

> The shortcut saves several keystrokes.

这个快捷操作能省下好几次按键。

**别混淆**

keystroke 是动作，key 是物件；一个快捷键操作可能包含多个键，不必与单个 keystroke 完全等同。

<a id="w-12"></a>

### 15. keyring — 钥匙圈

**音标**：/ˈkiːrɪŋ/

**先抓住这个画面**

把几把钥匙串在同一个环上，这样不用一把一把散着找。

**怎么拆**

key + ring 环。ring 在这里是环状物，不是响铃声；key ring 分写也常见。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**key + ring → keyring**  
钥匙 + 环 → 钥匙圈

a metal keyring 金属钥匙圈，attach a key to a keyring 把钥匙装到钥匙圈上；也可泛指带装饰的钥匙挂件。

**常见搭配与例句**

a metal keyring；a spare keyring；attach keys to a keyring。

> She attached the spare key to her keyring.

她把备用钥匙装在钥匙圈上。

> The souvenir shop sells keyrings shaped like buses.

纪念品店出售公交车形状的钥匙挂件。

**别混淆**

keyring 侧重环，keychain 侧重链或整件挂钥匙的饰物，日常指物范围可有重合。

<a id="w-14"></a>

### 16. keyrings — 钥匙环、钥匙圈〔复数〕

**音标**：/ˈkiːrɪŋz/

**先抓住这个画面**

把几把钥匙串在一起的环，是 keyrings。key 是被收拢的对象，ring 是环状器具。

**怎么拆**

key + ring → keyring，也常分写 key ring；现代加 -s，/ŋ/ 后读 /z/。ring 不接响铃动词的另一条来源。

**怎么变成今天的意思**

**key + ring → keyring**  
串钥匙的环

↓

**keyring + -s → keyrings**  
多个钥匙环

metal keyrings 金属钥匙环；spare keyrings 备用钥匙环。

**常见搭配与例句**

keys on keyrings 串在钥匙环上的钥匙；decorative keyrings 装饰钥匙圈。

> The shop sold postcards and keyrings.

店里卖明信片和钥匙圈。

> They put the spare keys on separate keyrings.

他们把备用钥匙放在不同钥匙环上。

**别混淆**

词尾 ing 是 ring 这个完整器物词的一部分，不是动词进行时尾。keychain 也常用于相近钥匙配件。

### 17. turnkey — 交付即可使用的；交钥匙式的

**音标**：英 /ˈtɜːnkiː/；美 /ˈtɜːrnkiː/

**先抓住这个画面**

把东西做好交给你，接手后像转一下钥匙就能开用；重点是交付整体成果，不是只交零件。

**怎么拆**

turn 转动 + key 钥匙。历史也曾指转钥匙锁门的狱卒；现代商业的即用形容词借转钥匙启用的画面，不必硬说从狱卒职业直接变来。

**怎么变成今天的意思**

**古英语 cǣġ → 中古英语 keye → 英语 key**  
钥匙；答案、解释等比喻也很早；更远来源不明

↓

**现代 key 多条用法**  
钥匙、关键；乐器与机器上的键；音乐的调

↓

**turn + key → turnkey**  
转钥匙启用的画面 → 交付即可使用

a turnkey solution 交付即可使用的整体方案，a turnkey project 交钥匙工程；实际包含哪些服务由项目约定。

**常见搭配与例句**

a turnkey solution；a turnkey project；a turnkey system。

> The supplier offered a turnkey system for the new factory.

供应商为新工厂提供了一套交付即可使用的系统。

> They wanted a turnkey solution rather than a box of separate parts.

他们想要一套接手就能用的整体方案，而非一箱单独零件。

**别混淆**

turnkey 强调交付后可投入使用，不等于永远不用维护；custom-made 说按需定制，维度不同。

## 这一组要分清什么

keypad 是小键盘，keystroke 是按键动作；keynote 的 note 接音符，keystone 的 stone 接石拱。keyless 不等于没上锁。

主旨演讲嘉宾称信任是团队合作的核心支撑。
