# 1358 · learned — 学得、博学；否定形容词和逆向学习分开

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

不把所有 -ed 都读同一音，也不把 un- 否定与 unlearn 改掉旧习的动词路径混淆。

**LEARNED：学过与有学问，同形而读音、用法有别**

learned → unlearned，把已有 learned 精讲与新增否定词放在一起。

- **学过、博学及否定**：learned · unlearned

## 词形与演化规律

un- + learned〔否定形容词〕；unlearn + -ed〔另一动词路径〕；有学问义 -ed 读 /ɪd/。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [learned](#w-1) | 有学问的：英 /ˈlɜːnɪd/、美 /ˈlɜːrnɪd/；学过、习得的：英 /lɜːnd/、美 /lɜːrnd/ | 有学问的；博学的；学到、习得的 |
| [unlearned](#w-2) | 未学过：英 /ʌnˈlɜːnd/、美 /ʌnˈlɜːrnd/；不博学：英 /ʌnˈlɜːnɪd/、美 /ʌnˈlɜːrnɪd/ | 未学过、非后天学来的；不博学、未受教育的 |

## 逐词讲解

<a id="w-1"></a>

### 1. learned — 有学问的；博学的；学到、习得的

**音标**：有学问的：英 /ˈlɜːnɪd/、美 /ˈlɜːrnɪd/；学过、习得的：英 /lɜːnd/、美 /lɜːrnd/

**先抓住这个画面**

a learned scholar 是学问深的人，分两个音节；I learned it 是我学会了，通常一个音节。

**怎么拆**

learn + -ed，中古英语有 lerned 等形容词，古时 learn 还可有教的用法。现代有学问义常保留 /ɪd/，普通过去、分词常 /d/，不能看同一拼写就统一读。

**怎么变成今天的意思**

**古英语 leornian → 中古英语 lernen**  
学习、获得知识技能

↓

**英语 learn**  
学会、学到；得知

↓

**learn + -ed → learned**  
博学形容词；普通过去、分词及习得的性质

a learned scholar 博学学者，a learned journal 学术刊物；learned behavior 后天习得行为通常一音节 learned。用义、位置一起判断。

**常见搭配与例句**

a learned scholar；a learned journal；learned behavior。

> The lecture was given by a learned historian.

讲座由一位博学的历史学家主讲。

> I learned the song from my grandmother.

我从祖母那里学会了这首歌。

**别混淆**

learned /ɪd/ 博学，learner 学习者；学习者可以尚未精通，博学者也仍能学新东西。

<a id="w-2"></a>

### 2. unlearned — 未学过、非后天学来的；不博学、未受教育的

**音标**：未学过：英 /ʌnˈlɜːnd/、美 /ʌnˈlɜːrnd/；不博学：英 /ʌnˈlɜːnɪd/、美 /ʌnˈlɜːrnɪd/

**先抓住这个画面**

一边问这件技能学过没有，另一边问这个人有没有学问。拼写相同，-ed 的读音却跟着两种 learned 变化。

**怎么拆**

un- 不 + learned；未受教育的形容词在中古英语已有。另有 unlearn 动词的过去式 unlearned，表示消除原有习惯、观念，不要与本条否定形容词混为一条。

**怎么变成今天的意思**

**learn → learned 的两类读音、用法**  
/lɜːnd/ 学过的；/ˈlɜːnɪd/ 有学问的〔英式示意〕

↓

**un- + learned → unlearned**  
未学过的；没有受教育、不博学的，随所接 learned 分读音

an unlearned response 可说非学得的反应，an unlearned person 说不博学者、未受教育者，较书面。句子解释为 unlearn 的过去式时，则是在摆脱旧习。

**常见搭配与例句**

an unlearned response；the learned and the unlearned；unlearned behaviour。

> The experiment examined an unlearned response to the sound.

实验研究了对声音的一种非后天习得反应。

> The lecture was intended for both learned and unlearned listeners.

这场讲座面向博学和不博学的听众。

**别混淆**

unlearned 未曾学得与 unlearned 已经改掉是不同构词：un- + learned 对照 unlearn + -ed。有学问义 -ed 另读一节 /ɪd/。

## 这一组要分清什么

a learned scholar 博学学者、a learned skill 学得技能；unlearned 未学得与消除旧习的过去式须看句法。

## 串起来练习

The response was unlearned, rather than a skill taught during training.

这种反应并非后天习得，不是训练中教会的技能。
