# 0106 · never — 从不、任何时候都不；否定的固定扩展

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

古英语 nǣfre 相当于旧否定 ne + æfre，后来成为 never。它可以真说从未，也可在某些固定短语里加强否定，不能逐字把 never mind 译为永远没有头脑。

**NEVER：把 ever 的时间范围整个否掉**

ever 把可能时间打开，never 则说一次也没有；nevertheless 又把旧的强调组合固定成尽管如此。

- **时间上的全面否定**：ever · never
- **固定让步副词**：nevertheless
- **文学中不再发生**：nevermore

## 词形与演化规律

旧 ne + ever 的对应 → never；never + the + less → nevertheless；never + more → nevermore。日常“别介意、算了”通常写 never mind 两词。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [ever](#w-6) | 英 /ˈevə/；美 /ˈevər/ | 曾经；在任何时候；一直；有史以来〔强调〕 |
| [never](#w-1) | 英 /ˈnevə/；美 /ˈnevər/ | 从未；绝不；任何时候都不 |

## 逐词讲解

<a id="w-6"></a>

### 1. ever — 曾经；在任何时候；一直；有史以来〔强调〕

**音标**：英 /ˈevə/；美 /ˈevər/

**先抓住这个画面**

把时间范围打开：从过去到现在，有没有哪一次；或往后不设终点地延续。

**怎么拆**

古英语 æfre 经中古英语成为 ever。更远可能由表示永远、在生命中之类材料缩合，也有其他分析；本页从确定的古英语形式起，不把假说当成唯一拆法。

**怎么变成今天的意思**

**古英语 æfre**  
曾经、任何时候、一直；更远构成有不同解释

↓

**中古英语 ever → 英语 ever**  
扩展到强调、任意范围及持续等用法

Have you ever…? 问到目前为止是否有过一次；the best ever 把比较范围拉到有记录以来。ever since 表示从那时一直到现在，ever so 可以加强程度。

**常见搭配与例句**

have you ever…?；hardly ever；better than ever；ever since。

> Have you ever repaired a bicycle yourself?

你有没有自己修过自行车？

> The two friends have kept in touch ever since school.

这两位朋友从上学时起就一直保持联系。

**别混淆**

ever 不等于每次都如此的 always。I have ever been… 通常不能直接表达我曾去过；常见提问、否定、最高级或其他特定结构。

<a id="w-1"></a>

### 2. never — 从未；绝不；任何时候都不

**音标**：英 /ˈnevə/；美 /ˈnevər/

**先抓住这个画面**

把时间线上所有可能的一次都划掉：一次也没有，往后也不许。

**怎么拆**

古英语 ne 不 + æfre 任何时候，缩合为 næfre；经中古英语成为 never。不是现代英语任意给 ever 加一个字母 n 的普遍造词规则。

**怎么变成今天的意思**

**古英语 ne 不；æfre 任何时候**  
否定与开放时间范围共同组合

↓

**古英语 næfre → 中古英语 never → never**  
在任何时候都不；也用于强调否定

I have never seen it 是以前一次也没见过；Never touch that 是禁止触碰。never mind 是别介意、算了，不必每个字都译成从不去想。

**常见搭配与例句**

never again；have never done；never mind；never too late。

> I have never seen the sea freeze.

我从未见过海面结冰。

> Please never share this password with anyone.

请绝不要把这个密码告诉任何人。

**别混淆**

not ever 与 never 常可对应，not always 却只是并非总是，仍允许有些时候发生。

<a id="w-2"></a>

### 3. nevertheless — 尽管如此；然而仍然

**音标**：英 /ˌnevəðəˈles/；美 /ˌnevərðəˈles/

**先抓住这个画面**

困难确实摆在那里，但没有把后面的事实压下去：事情很难，仍然值得做。

**怎么拆**

中古英语 never the less 一类组合固定成词；never 在这里有一点也不的强调，旧 the 与程度比较有关，不宜逐字背成永远那个更少。

**怎么变成今天的意思**

**中古英语 never the less**  
并不因此更少、较弱

↓

**nevertheless 合写**  
尽管前述因素，仍然如此

通常作为连接上下文的副词：The task was difficult. Nevertheless, we continued。句中也可说 It was nevertheless useful，表示前述不利因素没推翻判断。

**常见搭配与例句**

nevertheless continued；nevertheless important。

> The instructions were brief but nevertheless useful.

说明很简短，但仍然有用。

> It was raining heavily. Nevertheless, the game continued.

雨下得很大。尽管如此，比赛仍在继续。

**别混淆**

nevertheless 与 however 常相近，但更突出“虽有前面那个情况，仍然如此”。它不是 nevertheless than 一类比较结构。

<a id="w-5"></a>

### 4. nevermore — 再也不、永不再〔文学用语〕

**音标**：英 /ˌnevəˈmɔː/；美 /ˌnevərˈmɔːr/

**先抓住这个画面**

不只是这一次不做，而是把未来也关上：以后再也不。它比日常 never again 更有诗歌、故事的语气。

**怎么拆**

承中古英语 nevermore，更早有古英语 nǣfre mā 的相应短语。现代对应 never + more，此处 more 取再、此后延续的用法。

**怎么变成今天的意思**

**古英语 nǣfre mā → 中古英语 nevermore**  
在此以后再也不

↓

**never + more 的现代透明关系**  
never 从不、再不；more 再、进一步，合成文学副词

return nevermore 再不回来，nevermore to be seen 从此不再见到。现代常见于诗歌、标题、刻意文学化叙述，日常常说 never again。

**常见搭配与例句**

return nevermore；nevermore to be seen。

> In the legend, the ship sailed away and returned nevermore.

传说中，船驶远了，再也没有回来。

> The poem imagines a door that will open nevermore.

诗中想象一扇永不再开的门。

**别混淆**

nevermore 整体是副词，不是 no more 的每个场景都能替换；No more coffee. 不能换成一个 nevermore coffee。

## 这一组要分清什么

never 通常不再配普通标准否定：I have never seen it。nevertheless 不表示永远更少；口语 never mind 通常分写，不把罕见合写形式当基础词强记。

## 串起来练习

She had never tried it before; nevertheless, she agreed to learn.

她从没试过；尽管如此，她还是答应学。
