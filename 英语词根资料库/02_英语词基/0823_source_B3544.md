# 0823 · source — 来源、资源与获取方式

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

source 有泉源、来源的法语历史背景，现代还能作动词取得供应。众包词族仿照外包构词，先分获取信息、成果与筹钱的不同。

**SOURCE：东西从哪里来，以及从谁那里获取**

source 说起点、出处，resource 说可用资源；outsource 外包，crowdsource 则把获取范围扩大到开放人群。

- **来源与可用资料**：source · resource · sourcebook
- **外包与众包**：outsource · crowdsource · crowdsourcing

## 词形与演化规律

source → resource、sourcebook；outsource 外部承接；crowdsource → crowdsourcing 作为现代动词、活动名词一组。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. source — 来源；源头；消息来源；采购、取得

**音标**：英 /sɔːs/；美 /sɔːrs/

**先抓住这个画面**

顺着河水往上找，找到它最初冒出来的地方；消息、材料和问题也有各自的源头。

**怎么拆**

古法语 sourse 来自 sourdre“涌起”的分词名词形式，追到拉丁语 surgere；英语先作名词，取得货源义的动词是较晚发展。

**怎么变成今天的意思**

**拉丁语：regere**  
引导、使直；治理

↓

**拉丁语：sub- + regere → surrigere / surgere**  
从下向上挺起 → 升起

↓

**古法语 sourdre → sourse**  
涌起 → 泉源、起点

↓

**英语：source**  
来源；后来也作动词，表示取得货源

a source of income 是收入来源；cite your sources 是注明资料来源；source materials locally 是从本地采购材料。source code 则是程序的源代码。

**常见搭配与例句**

the source of a river；a reliable source；source something from…。

> Please name the source of this information.

请说明这条信息的来源。

> The restaurant sources its vegetables from local farms.

这家餐厅从当地农场采购蔬菜。

**别混淆**

cause 是造成结果的原因；source 更着重东西从哪里来，消息来源不等于事件原因。

<a id="w-4"></a>

### 2. sourcebook — 资料集；史料汇编；参考资料书

**音标**：英 /ˈsɔːsbʊk/；美 /ˈsɔːrsbʊk/

**先抓住这个画面**

研究一个话题，不只听概述，还需要集中查阅相关原文、材料和例子。

**怎么拆**

source（来源、资料）+ book，按收集资料的用途命名；游戏等领域也有扩展材料书的专门用法。

**怎么变成今天的意思**

**英语 source；book**  
并列组合的两部分

↓

**source + book → sourcebook**  
某主题的资料、文本汇编

a historical sourcebook 是历史资料集，a sourcebook of design ideas 是设计创意参考资料书。是否全为第一手材料要看编选说明。

**常见搭配与例句**

a historical sourcebook；a sourcebook of；a useful sourcebook。

> The course uses a sourcebook of medieval documents.

课程使用一部中世纪文献资料集。

> The volume is a useful sourcebook for local history.

这本书是研究当地历史的实用资料集。

**别混淆**

sourcebook 重材料汇集，textbook 重教学组织；同一本书可兼具功能，但别把所有参考书都当入门教材。

<a id="w-2"></a>

### 3. resource — 资源；可利用的办法或资料；提供资源

**音标**：英 /rɪˈsɔːs/、/rɪˈzɔːs/；美 /ˈriːsɔːrs/、/rɪˈsɔːrs/

**先抓住这个画面**

遇到需要时，手边能拿来帮忙的东西：钱、时间、人手、资料，甚至解决难题的办法。

**怎么拆**

法语 ressource / 古法语 resourse，来自 resourdre“重新起来、恢复”，远源为拉丁语 resurgere。不是简单在现代 source 前加 re- 来表示“再找一次来源”。

**怎么变成今天的意思**

**拉丁语：regere**  
引导、使直；治理

↓

**拉丁语：sub- + regere → surrigere / surgere**  
从下向上挺起 → 升起

↓

**拉丁语：resurgere**  
re- 再次 + surgere → 再升起

↓

**古法语 resourdre → resourse**  
重新起来、恢复 → 可补充的来源

↓

**法语 → 英语 resource**  
可借助的办法、资源

natural resources 是自然资源；learning resources 是学习材料和工具。复数 resources 常强调可调配的总体条件，动词 resource 则是给某项工作配好人力物力。

**常见搭配与例句**

natural resources；limited resources；a useful resource for…。

> Time is the project’s most limited resource.

时间是这个项目最紧缺的资源。

> The website is a useful resource for language teachers.

这个网站对语言教师来说是很有用的资源。

> The programme must be properly resourced before it can expand.

这个项目必须先配足资源，才能扩大规模。

**别混淆**

source 主要回答从哪里来；resource 回答有什么可以拿来用。

<a id="w-3"></a>

### 4. outsource — 外包

**音标**：英 /ˈaʊtsɔːs/；美 /ˈaʊtsɔːrs/

**先抓住这个画面**

本来可以自己组织人来做的工作，改为交给外部供应者完成。

**怎么拆**

out-“外部” + source〔动词，取得供应〕；现代英语商业构词。

**怎么变成今天的意思**

**拉丁语：regere**  
引导、使直；治理

↓

**拉丁语：sub- + regere → surrigere / surgere**  
从下向上挺起 → 升起

↓

**古法语 sourdre → sourse**  
涌起 → 泉源、起点

↓

**英语：source**  
来源；后来也作动词，表示取得货源

↓

**现代英语：out- + source → outsource**  
从组织外部取得某项服务

outsource payroll 是把工资核算交外部做；外包可以给同一城市的公司，并不必然转到国外。

**常见搭配与例句**

outsource work to；outsource production；outsource customer support。

> The firm outsources its payroll to a local specialist.

这家公司把工资核算外包给本地专业服务商。

> They decided not to outsource the design work.

他们决定不把设计工作外包。

**别混淆**

offshore 强调转移到海外；outsource 强调交给外部，两者可以同时发生，也可分别发生。

<a id="w-5"></a>

### 5. crowdsource — 众包；向大众征集信息、创意或工作成果

**音标**：英 /ˈkraʊdsɔːs/；美 /ˈkraʊdsɔːrs/

**先抓住这个画面**

不只找一个固定供应者，而是把问题或任务开放给许多人，让各人贡献一部分。

**怎么拆**

crowd 大众 + source 从某处获取，联系 crowdsourcing 对 outsourcing 的仿造构词。不是把人群直接当成要买卖的货物。

**怎么变成今天的意思**

**crowd 大众；source 获取来源；参照 outsourcing**  
向固定外部供应者获取 → 向开放人群征集

↓

**crowdsource**  
通过大众参与获取内容、答案或成果

crowdsource ideas 众包创意，crowdsource translations 向大众征集翻译；参与者可能有偿也可能自愿，词本身不规定。

**常见搭配与例句**

crowdsource ideas；crowdsource information；crowdsource a solution。

> The museum crowdsourced photographs from local residents.

博物馆向当地居民征集照片。

> The team decided to crowdsource ideas for the new logo.

团队决定向大众征集新标志的创意。

**别混淆**

crowdsource 向多人开放征集，outsource 外包可交给一家专业公司；两者不是只因都在组织外部就完全相同。

<a id="w-6"></a>

### 6. crowdsourcing — 众包；大众参与式征集

**音标**：英 /ˈkraʊdsɔːsɪŋ/；美 /ˈkraʊdsɔːrsɪŋ/

**先抓住这个画面**

把一大批人的小贡献汇到一起，成为解决问题、建立资料或完成任务的方法。

**怎么拆**

crowd 大众 + sourcing 获取来源，仿 outsourcing 形成名称；现代也对应 crowdsource + -ing。学习顺序先动词后名词方便使用，不代表每个短形式历史都一定更早。

**怎么变成今天的意思**

**crowd + sourcing；仿 outsourcing**  
从大众参与获取信息、创意或工作

↓

**crowdsourcing；对应 crowdsource 的 -ing 名词**  
众包这种方法、活动

a crowdsourcing project 众包项目，use crowdsourcing 使用大众征集；公开参与不是质量自动有保证，具体项目仍需筛选、组织。

**常见搭配与例句**

a crowdsourcing project；use crowdsourcing；crowdsourcing ideas。

> Crowdsourcing helped the archive identify people in old photographs.

大众参与征集帮助档案馆辨认老照片中的人物。

> The project uses crowdsourcing to collect local place names.

项目通过大众参与收集当地地名。

**别混淆**

crowdsourcing 汇集大众贡献，crowdfunding 众筹重点筹钱；可以一起发生，但钱和创意、信息不是同一个对象。

## 这一组要分清什么

crowdsourcing 不等于 crowdfunding；source 取得供应不只搜到一个网页；resource 不必全是自然资源。

## 串起来练习

The archive used crowdsourcing to find the source of an old photograph.

档案馆借助大众参与，查找一张老照片的来源。
