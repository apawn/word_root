# 0890 · pull — 拉、拔、牵引与吸引；活动和工具分清

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

本族旧拉动词延续，远源不强定；工具、运动和魅力比喻靠对象辨认。

**PULL：抓住往一个方向拉，也借指吸引和影响**

pull → pulling → puller；固定 pull it off、pull out 直接放常见场景解释。

- **动作、活动和器具**：pull · pulling · puller
- **pull → pulled：拉近、拉开与拔出**：pull · pulled
- **pull → pulls：往自己这边拉**：pull · pulls

## 词形与演化规律

pull + -ing/-er；pull it off、pull out 等为常用短语。

继承古英语拉、拔词族，方向由 out、away 等补明。

古英语 pullian 本族传承，更远来源不定；现代也说吸引、影响。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. pull — 拉、拖、拔；拉力；吸引力、影响力

**音标**：/pʊl/

**先抓住这个画面**

抓住一端往自己或指定方向带；抽象里也可说某种魅力把你吸过去。

**怎么拆**

继承古英语 pullian，更远来源不确定。名词拉、牵引力由相关动词发展，吸引、影响等借拉动的形象延伸。

**怎么变成今天的意思**

**古英语 pullian → 中古英语 pullen → pull**  
拉、拔、扯；更远来源不明

↓

**现代 pull**  
拉、拖；拉力；吸引、影响等引申

pull the door 拉门，pull a muscle 拉伤肌肉，pull out 拔出、退出，the pull of home 家的吸引力，pull it off 成功做到。

**常见搭配与例句**

pull the door；pull a muscle；pull out；pull it off。

> Pull the handle towards you.

把把手朝你这边拉。

> Nobody thought we could finish, but we pulled it off.

没人觉得我们能完成，但我们做到了。

**别混淆**

pull 拉向某处，push 向外或另一方向推；pull the door 与 push the door 操作相反。pull it off 是成功完成的固定说法。

<a id="w-4"></a>

### 2. pulled — 拉、拔、拖过；pull 的过去式和过去分词

**音标**：/pʊld/

**先抓住这个画面**

抓住东西朝自己或某个方向带，是 pulled；拔出钉子、拉开门、把椅子拉近，都可沿着这个动作理解。

**怎么拆**

pull + -ed，/l/ 后读 /d/，原词已写 ll。pull 继承古英语 pullian，经中古英语 pullen 延续，更远来源不确定。

**怎么变成今天的意思**

**古英语 pullian → 中古英语 pullen → pull**  
拉、拔、扯

↓

**pull + -ed → pulled**  
过去拉动、拔出、拖动

pulled the door 拉门；pulled out a nail 拔出钉子；pulled up a chair 拉来一把椅子；pulled away 驶离、离开。

**常见搭配与例句**

pulled gently；pulled the curtains closed。

> She pulled the chair closer to the table.

她把椅子拉得更靠近桌子。

> The train pulled away from the platform.

火车驶离了站台。

**别混淆**

pull 以拉的方式带动，push 以推的方式带动。pulled up 可说车停下，也可说拉来椅子，具体对象、场景决定方向和结果。

<a id="w-2"></a>

### 3. pulling — 拉、拖、牵引；pull 的 -ing 形式

**音标**：/ˈpʊlɪŋ/

**先抓住这个画面**

把拉的动作当作一段活动或持续过程；不是看到 -ing 就一定另有一个陌生词根。

**怎么拆**

pull + -ing，中古英语已有 pulling、pullyng 等活动名词。pull 为双 l 结尾，直接接 -ing，不再多加一个 l。

**怎么变成今天的意思**

**古英语 pullian → 中古英语 pullen → pull**  
拉、拔、扯；更远来源不明

↓

**现代 pull**  
拉、拖；拉力；吸引、影响等引申

↓

**pull + -ing → pulling**  
拉、拖的动作；相关分词用法

pulling power 拉力，也可吸引人的能力；keep pulling 继续拉。

**常见搭配与例句**

pulling power；keep pulling；pulling the rope。

> Keep pulling until the rope is tight.

继续拉，直到绳子绷紧。

> The engine has enough pulling power for the trailer.

发动机有足够牵引力拖动挂车。

**别混淆**

pulling 活动或分词，puller 执行者、拉具；pulling power 有时说吸引力，要看是发动机还是明星。

<a id="w-5"></a>

### 4. pulls — 拉、拔、吸引〔第三人称单数〕；拉动、吸引力〔复数〕

**音标**：/pʊlz/

**先抓住这个画面**

把东西朝自己这边带过来，是 pulls；能把注意力、人群带过来，也就有吸引的比喻。

**怎么拆**

pull + -s，/l/ 后读 /z/。pull 继承古英语 pullian，更远来源不确定；拉动、吸引等名词由相关动作发展。

**怎么变成今天的意思**

**古英语 pullian → pull**  
拉、拔、扯 → 吸引、影响等扩展

↓

**pull + -s → pulls**  
某人拉动、吸引；多次拉动或多方吸引力

pulls the door open 拉开门；pulls a cart 拉车；pulls in visitors 吸引游客。

**常见搭配与例句**

pulls the pieces apart 把部件拉开；pulls together 团结协作。

> The horse pulls a small cart.

马拉着一辆小车。

> The exhibition pulls in visitors from nearby towns.

展览吸引附近城镇的游客。

**别混淆**

pulls 的元音 /ʊ/ 和 pools /puːlz/ 不同。pulls 不是过去式，拉过、拔过是 pulled；pulls out、pulls in 的小品词又会改变方向、用法。

<a id="w-3"></a>

### 5. puller — 拉的人；拉拔器、牵引工具

**音标**：英 /ˈpʊlə/；美 /ˈpʊlər/

**先抓住这个画面**

负责把东西拉动的人或工具；技术场景里往往是帮助拔出紧配零件的器具。

**怎么拆**

pull + -er，中古英语已有人物形式。现代工具名按执行拉拔动作命名，常由前置名词说明拔什么。

**怎么变成今天的意思**

**古英语 pullian → 中古英语 pullen → pull**  
拉、拔、扯；更远来源不明

↓

**现代 pull**  
拉、拖；拉力；吸引、影响等引申

↓

**pull + -er → puller**  
执行拉、拔的人或器具

a gear puller 齿轮拉拔器，a nail puller 拔钉器。

**常见搭配与例句**

a gear puller；a nail puller；a cable puller。

> The mechanic used a gear puller to remove the part.

机械师用齿轮拉拔器拆下零件。

> A nail puller made the job easier.

拔钉器让工作轻松了些。

**别混淆**

puller 拉拔工具或人，pulley 滑轮是另一词；滑轮可帮拉动，但不是 pull + -ey 形成。

## 这一组要分清什么

pull 拉与 push 推相反；pulling power 可拉力或吸引力；puller 不是 pulley 的简单派生。

## 串起来练习

The puller has enough pulling power to remove the part.

拉拔器有足够的拉力把零件拆下来。
