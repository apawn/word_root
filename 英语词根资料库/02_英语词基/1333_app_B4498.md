# 1333 · app — application 的截短；小型应用程序

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

这组要学截短和小称后缀，而不是把字母都当古典词根。Java applet 的历史例子只用于认识词义。

**APP：把 application 程序义缩短成口语常用名**

app → applet，只保留常用基础软件称呼。

- **应用与小型程序**：app · applet

## 词形与演化规律

application → app〔截短〕；app + -let → applet。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [app](#w-1) | /æp/ | 应用程序、App |
| [applet](#w-2) | /ˈæplət/ | 小应用程序；嵌在较大环境中执行的小程序 |

## 逐词讲解

<a id="w-1"></a>

### 1. app — 应用程序、App

**音标**：/æp/

**先抓住这个画面**

手机里点一下就能记账、导航、聊天的那一个程序。app 是长词 application 剪短后的常用叫法。

**怎么拆**

application 的截短，不是三个字母各代表一个词的首字母缩写。这里研究软件义；菜单、体育统计里的同形缩略可另有来源。

**怎么变成今天的意思**

**application program 等 → application**  
为具体任务服务的应用程序

↓

**application 缩短 → app**  
应用程序，常用于手机、电脑软件

download an app 下载应用，a messaging app 聊天应用，an app developer 应用开发者。首音是元音，单数说 an app。

**常见搭配与例句**

download an app；open the app；a mobile app；an app developer。

> I use an app to track my spending.

我用一个应用记录开销。

> Open the app and choose a language.

打开应用，然后选择一种语言。

**别混淆**

app 应用，application 还可申请、应用、涂敷等；不能把 application form 申请表理解为手机软件表格。

<a id="w-2"></a>

### 2. applet — 小应用程序；嵌在较大环境中执行的小程序

**音标**：/ˈæplət/

**先抓住这个画面**

不是完整的大套软件，而是负责一小件事的程序单元；常在某个宿主环境中运行。

**怎么拆**

app〔application 缩短〕+ 小称后缀 -let。名称的具体早期背景还有其他影响说法，但基本构词可以这样理解；不拆成 apple 苹果加 t。

**怎么变成今天的意思**

**application program 等 → application**  
为具体任务服务的应用程序

↓

**application 缩短 → app**  
应用程序，常用于手机、电脑软件

↓

**app + -let → applet**  
小型应用程序；依附特定环境运行的程序单元

a Java applet 常见于旧技术文献，a small applet 小程序。这个英语词泛指的类别不必等同某个平台特定产品名里的小程序。

**常见搭配与例句**

a Java applet；run an applet；a small applet。

> The old manual describes a Java applet for drawing graphs.

旧手册介绍了一个绘图用的 Java 小程序。

> The applet performs a single calculation.

这个小程序完成一项计算。

**别混淆**

app 常泛称应用，applet 突出小型、宿主环境等背景；不是所有体积小的手机 app 都惯常叫 applet。

## 这一组要分清什么

app 不是逐字母首字母缩写；applet 不等于 apple+t；英语泛称不等于某一平台专有产品。

## 串起来练习

The app contains a small applet for converting units.

这个应用内含一个换算单位的小程序。
