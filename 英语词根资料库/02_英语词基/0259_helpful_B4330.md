# 0259 · helpful — 帮助的性质、方式及反面

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

把人的态度与事情的效果都留住。热心的人可以给出无用建议；有用的地图并没有人的感情，也能 helpful。

**HELPFUL：有用地帮上忙，或愿意伸手帮人**

help → helpful → helpfully/helpfulness；unhelpful 则是否定帮助效果或合作态度。

- **帮助及其性质、方式**：help · helpful · helpfully · helpfulness
- **无益、不配合**：unhelpful

## 词形与演化规律

help + -ful；helpful + -ly/-ness；un- + helpful。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [help](#w-5) | /help/ | 帮助；改善；有帮助 |
| [helpful](#w-1) | /ˈhelpfəl/ | 有帮助的；乐于助人的 |
| [helpfully](#w-3) | /ˈhelpfəli/ | 有帮助地、热心地 |
| [helpfulness](#w-4) | /ˈhelpfəlnəs/ | 乐于助人；有帮助的程度、性质 |
| [unhelpful](#w-2) | /ʌnˈhelpfəl/ | 无帮助的、不愿帮忙的；无益甚至添乱的 |

## 逐词讲解

<a id="w-5"></a>

### 1. help — 帮助；改善；有帮助

**音标**：/help/

**先抓住这个画面**

一个人搬不动箱子，另一双手过来分担一点，让事情容易完成。

**怎么拆**

来自古英语 help、helpan 等名词动词形式，经中古英语延续。现代过去式 helped；旧本族动词形式并不都照现代规则变化。

**怎么变成今天的意思**

**古英语 help；helpan**  
帮助；帮助这一动作

↓

**中古英语 help／helpen → 英语 help**  
帮助、协助；使情况好转

help someone do 或 help someone to do 都可说帮助做事。This helps 表示这样有用。can’t help doing 是忍不住做，不能按“不能帮助做”直译。

**常见搭配与例句**

help with；help someone do；help yourself to；can’t help laughing。

> Could you help me carry this box?

你能帮我搬这个箱子吗？

> A short break might help you concentrate.

短暂休息可能有助于你集中注意力。

**别混淆**

help someone 是帮人，help oneself to food 是自己取食物。helpful 是带来帮助，不只是“愿意提供帮助”的口头态度。

<a id="w-1"></a>

### 2. helpful — 有帮助的；乐于助人的

**音标**：/ˈhelpfəl/

**先抓住这个画面**

一句说明正好解开问题，或一个人主动把你卡住的地方处理了。

**怎么拆**

help + -ful；-ful 在这里造“具有帮助作用”的形容词。中古英语已有同形相关用法，不按字面译成“满是帮助”。

**怎么变成今天的意思**

**古英语 help；helpan**  
帮助；帮助这一动作

↓

**中古英语 help／helpen → 英语 help**  
帮助、协助；使情况好转

↓

**help + -ful → helpful**  
提供帮助或能派上用场的

a helpful guide 是能解决问题的指南；helpful staff 是愿意并能给顾客帮助的工作人员。helpful to someone、helpful for doing 常说明对象或用途。

**常见搭配与例句**

helpful advice；a helpful suggestion；find something helpful。

> The receptionist was friendly and helpful.

接待员亲切又乐于助人。

> It would be helpful to see a concrete example.

看一个具体例子会有帮助。

**别混淆**

helpful 评价帮助作用，useful 评价有用途；a useful tool 不一定像 a helpful person 那样带有待人友善的意味。

<a id="w-3"></a>

### 3. helpfully — 有帮助地、热心地

**音标**：/ˈhelpfəli/

**先抓住这个画面**

不只是人很热心，而是看他怎么做：顺手把门号指出来、把难点解释清楚，让别人省了麻烦。

**怎么拆**

helpful + -ly；helpful 含 help + -ful。原来的 -ful 保留，再接副词 -ly，写成 -fully。

**怎么变成今天的意思**

**古英语 helpan → help**  
帮助，让事情较容易完成

↓

**help + -ful → helpful**  
有帮助、愿意帮忙

↓

**性质转方式、名词或否定**  
helpfully / helpfulness / unhelpful

helpfully explain 热心解释，helpfully suggest 提出有帮助的建议，helpfully point out 好意指出；也可能被反讽使用，要看语气。

**常见搭配与例句**

helpfully explain；helpfully suggest；helpfully point out。

> She helpfully marked the entrance on the map.

她热心地在地图上标出了入口。

> The guide helpfully explained which tickets we needed.

导游热心解释了我们需要买哪些票。

**别混淆**

helpfully 修饰行为，helpful 可描述人、信息、工具。He helpfully explained it 与 His explanation was helpful 关注点不同。

<a id="w-4"></a>

### 4. helpfulness — 乐于助人；有帮助的程度、性质

**音标**：/ˈhelpfəlnəs/

**先抓住这个画面**

既能夸一个人愿意搭把手，也能评价说明、服务到底帮了多少忙；不是只数帮过几次。

**怎么拆**

helpful + -ness，-ness 把性质做成名词。helpfulness 可以对应态度，也可以对应实际帮助效果。

**怎么变成今天的意思**

**古英语 helpan → help**  
帮助，让事情较容易完成

↓

**help + -ful → helpful**  
有帮助、愿意帮忙

↓

**性质转方式、名词或否定**  
helpfully / helpfulness / unhelpful

↓

**helpful + -ness → helpfulness**  
愿意帮助的品质；实际有帮助的性质

kindness and helpfulness 友善与热心，the helpfulness of the advice 建议的帮助程度，appreciate someone’s helpfulness 感谢某人的热心帮助。

**常见搭配与例句**

kindness and helpfulness；the helpfulness of；appreciate someone’s helpfulness。

> We appreciated the staff’s patience and helpfulness.

我们很感激工作人员的耐心和热心。

> The survey asked users to rate the helpfulness of each answer.

问卷请用户评价每条回答的帮助程度。

**别混淆**

helpfulness 不等于结果总成功；help 好几种词性更直接，helpfulness 则专门评价性质、程度。

<a id="w-2"></a>

### 5. unhelpful — 无帮助的、不愿帮忙的；无益甚至添乱的

**音标**：/ʌnˈhelpfəl/

**先抓住这个画面**

你需要线索，对方只说“自己看着办”；没有推进事情，甚至让事情更难，这就 unhelpful。

**怎么拆**

un- 不 + helpful 有帮助的。否定整个性质，不是 undo 一类把动作反向做。

**怎么变成今天的意思**

**古英语 helpan → help**  
帮助，让事情较容易完成

↓

**help + -ful → helpful**  
有帮助、愿意帮忙

↓

**性质转方式、名词或否定**  
helpfully / helpfulness / unhelpful

↓

**un- + helpful → unhelpful**  
无助于当前事情，或态度不合作

an unhelpful comment 无益的评论，an unhelpful attitude 不合作的态度，be unhelpful to 对……没有帮助。

**常见搭配与例句**

an unhelpful comment；an unhelpful attitude；find something unhelpful。

> Telling us to hurry was unhelpful because the system had frozen.

系统已经卡住，催我们快点也没用。

> The instructions were vague and unhelpful.

说明含糊不清，帮不上忙。

**别混淆**

unhelpful 不一定完全没有信息，也可说在这个场景下帮不上忙；helpless 是无力自助、无可奈何，方向不同。

## 这一组要分清什么

helpfully 描动作；helpfulness 评性质；unhelpful 帮不上忙，helpless 自己无力应对。

## 串起来练习

She helpfully explained why the earlier advice had been unhelpful.

她热心解释了先前的建议为什么没有帮助。
