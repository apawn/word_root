# 0473 · add — 加上、相加；加法器与另源蛇名

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

add 借拉丁加上词；蛇 adder 来自 nadder 旧形式，与加法器的 -er 无关。

**ADD：把新的一份放到原有东西上**

add → adder 加法器很透明；同形蛇名另讲词界重分，不把两义混成一个故事。

- **增加与执行器具**：add · adder
- **add → added：加上了；补充说**：add · added
- **add → adding：再放上一份与补充说明**：add · adding
- **add → adds：把另一份放上去**：add · adds

## 词形与演化规律

add → adder；蛇名 a nadder → an adder 为独立历史。

added 的 -ed 在 /d/ 后读 /ɪd/；英语 add 保留拉丁 addere 加上的词源。

addere 的历史是 ad- 向与 -dere 放、置相连；这里区别于表示给的拉丁 dare。

拉丁 addere 的后半是放置材料，不是 dare 给。

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. add — 加上；相加；补充说

**音标**：/æd/

**先抓住这个画面**

原来有一些，再把新的一份放上去；说话时加一条信息也用同一画面。

**怎么拆**

借拉丁 addere 加上，历史是 ad- 向与 -dere 放、置的组合。现代不拆成 a- 与 dd 两个英语部分。

**怎么变成今天的意思**

**拉丁 ad- 向 + -dere 放、置 → addere → 英语 add**  
放上去、加上

↓

**现代 add**  
增加、相加；补充发言

add salt 加盐，add two numbers 两数相加，add to 增加，add that... 补充说……；add up 合计、说得通。

**常见搭配与例句**

add to；add something to；add up；add that。

> Add a little water to the mixture.

往混合物里加一点水。

> She added that the meeting would start at nine.

她补充说，会议九点开始。

**别混淆**

add to it 给它增加，add it to... 把它加到……；词序和介词关系决定加的是什么。

<a id="w-3"></a>

### 2. added — 加上了；相加了；补充说；额外增加的

**音标**：/ˈædɪd/

**先抓住这个画面**

原来已有一份，再添一份进去：杯里添水，清单添名字，话里添说明，都是 added 的画面。

**怎么拆**

add + -ed；add 原有双写 dd，直接接 ed，不是这一轮再多添一个 d。/d/ 后 -ed 读 /ɪd/。add 接拉丁 addere 加上，历史构成为 ad- 向 + -dere 放、置。

**怎么变成今天的意思**

**拉丁 ad- + dare → addere → add**  
放上去、加上

↓

**add + -ed → added**  
过去加上、补充；额外附加的

added water 加了水；added that ... 补充说……；added to the cost 增加了费用；an added benefit 额外的好处；no added sugar 未额外添加糖。

**常见搭配与例句**

added a name to the list；an added advantage。

> I added your name to the list.

我把你的名字加进了名单。

> She added that there was no need to hurry.

她补充说，不用着急。

> The quiet location is an added benefit.

位置安静是额外的好处。

**别混淆**

no added sugar 只说明没有额外添加糖，食物本身仍可能含糖。added to 是给……增加，added ... to ... 是把……加到……。

<a id="w-4"></a>

### 3. adding — 正在添加、相加；补充说明；add 的 -ing 形式

**音标**：/ˈædɪŋ/

**先抓住这个画面**

原来已经有一些，现在再放上一份，就是 adding；数学上把数量合起来，讲话时再补一句，也有加上去的感觉。

**怎么拆**

add + -ing，保留原词已有的 dd。add 借拉丁 addere，ad- 向与 -dere 放、置相连，原来是放到、附加；这里的放置成分与表示给的 dare 不同。

**怎么变成今天的意思**

**拉丁 ad- + -dere → addere → 英语 add**  
放到原有东西上、附加

↓

**add + -ing → adding**  
添加过程；正在相加、补充

adding water 正在加水；adding numbers 正在相加；adding a note 补充注释；adding to the problem 让问题更严重。

**常见搭配与例句**

keep adding；without adding extra weight。

> She is adding a few notes to the final page.

她正在最后一页加几条注释。

> The extra packaging is adding to the weight.

额外包装正在增加重量。

**别混淆**

add something to something 是把前者加到后者。add to something 可直接说增加、加重某种情况；adding up 则常说合计，或前后说得通。

<a id="w-5"></a>

### 4. adds — 加上、增加；补充说〔第三人称单数〕

**音标**：/ædz/

**先抓住这个画面**

原来已有一份，再往上放另一份，就是 adds。数值、配料、信息和一句补充的话，都能加进去。

**怎么拆**

add + -s，/d/ 后读 /z/。add 借拉丁 addere，较早 ad- 向 + -dere 放置；这里接放置词族，和 dare 给的拆法要分清。

**怎么变成今天的意思**

**拉丁 addere → add**  
朝某处放上去 → 加入、增加

↓

**add + -s → adds**  
单数主语把另一份加上、补充内容

adds water 加水；adds to the cost 增加成本；adds that... 补充说……。

**常见搭配与例句**

adds two numbers 把两个数相加；adds a new detail 补充一个新细节。

> She adds a little water to the mixture.

她往混合物里加一点水。

> The extra stop adds ten minutes to the journey.

多停这一站让行程增加了十分钟。

**别混淆**

add A to B 是把 A 加入 B；add to something 是使它增加。adds up to 给出总数或合起来产生的结果。

<a id="w-2"></a>

### 5. adder — 加法器；另源蝰蛇

**音标**：英 /ˈædə/；美 /ˈædər/

**先抓住这个画面**

计算机里能做相加的部件是 adder；自然观察中 a common adder 则可能是一种蝰蛇。

**怎么拆**

加法器义是 add + -er。蛇名接古英语 nædre，历史 a nadder 被重新分成 an adder，n 被听成冠词一部分；两条来源分开。

**怎么变成今天的意思**

**拉丁 ad- 向 + -dere 放、置 → addere → 英语 add**  
放上去、加上

↓

**现代 add**  
增加、相加；补充发言

↓

**另一路 nædre → nadder → adder**  
词界重分形成蛇名

a full adder 全加器，an electronic adder 电子加法器；a common adder 欧洲常见蝰蛇名。

**常见搭配与例句**

a full adder；an electronic adder；a common adder。

> The circuit contains a full adder.

电路包含一个全加器。

> The guide identified the snake as a common adder.

向导认出那条蛇是一条欧洲蝰蛇。

**别混淆**

adder 蛇不是会加法的蛇；n 的丢失是词界重分，不是所有 n- 开头名词都能照着变化。

## 这一组要分清什么

adder 加法器与蛇两源；add up 还可说事情合乎逻辑。

## 串起来练习

The adder adds the two binary values.

加法器把两个二进制数相加。
