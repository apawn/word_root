# 2624 · upload — 远端传输的动作，再说明执行者与重复次数

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

人或程序都能执行上传；重新上传是一次新传输，不只是重新打开页面。上传者与创作者身份也要分别判断。

**UPLOAD：把内容传到服务端，-er 指谁做，re- 指再做**

upload → uploader；reupload 再上传。

- **传输、执行者与重复动作**：upload · uploader · reupload
- **upload 的过程与执行者形式**：upload · uploading · uploader · uploaders
- **upload → uploads：向服务器上传及上传项目**：upload · uploads

## 词形与演化规律

up- + load → upload；-er 人、工具，re- 再次。

uploaders 可指人，也可指执行上传的软件工具。

up 向上 + load 装载 → upload，网络里说把本地内容送往远端服务的方向；uploads 兼名词复数与第三人称单数动词，重音常有差别。

## 逐词讲解

<a id="w-1"></a>

### 1. upload — 上传；上传的文件、过程

**音标**：动词英 /ˌʌpˈləʊd/、美 /ˌʌpˈloʊd/；名词常前重音

**先抓住这个画面**

从自己设备这端，把文件送到服务器或共享系统那端；up 是系统关系，不是往天空发。

**怎么拆**

up + load，现代计算机方向用语。动词常后重音，名词常前重音；不同说话者读法也可有变化。

**怎么变成今天的意思**

**古英语 lād 行程、运送 → 中古英语 lode、loade**  
运送 → 搬运的负荷

↓

**现代 load**  
货物、负担；装载 → 加载与数据传送

↓

**up + load → upload**  
向服务器、远端系统传送 → 上传

upload a photo 上传照片，upload to a website 上传到网站，a failed upload 上传失败。

**常见搭配与例句**

upload a file；upload a photo；upload to；an upload limit。

> Please upload the signed form to the portal.

请把签好的表格上传到门户。

> The video upload failed halfway through.

视频上传到一半失败了。

**别混淆**

upload 与 download 看当前设备、系统关系；同一传送在不同两端可从相反视角描述。

<a id="w-4"></a>

### 2. uploading — 正在上传；上传过程

**音标**：英 /ˌʌpˈləʊdɪŋ/；美 /ˌʌpˈloʊdɪŋ/

**先抓住这个画面**

资料从手边设备往远端系统、服务传，是 uploading。把 up 看成传送方向，就不用想象机器真的放在楼上。

**怎么拆**

up + load → upload，再加 -ing；load 从装载货物等用途扩到装载、传送数据。

**怎么变成今天的意思**

**up + load → upload**  
数据从本地一侧传到远端

↓

**upload + -ing → uploading**  
上传动作正在进行；上传过程

uploading photos 正在上传照片；finish uploading 上传完。

**常见搭配与例句**

while uploading 上传时；uploading a new version 上传新版本。

> She is uploading the photos to a private folder.

她正在把照片上传到私人文件夹。

> Uploading the video took longer than expected.

上传视频花的时间比预计长。

**别混淆**

上传只说明传送方向，本身不说明内容是否公开；发到私人空间也可以叫 uploading。

<a id="w-6"></a>

### 3. uploads — 上传的文件、上传操作〔复数〕；上传

**音标**：名词：英 /ˈʌpləʊdz/、美 /ˈʌploʊdz/；动词：英 /ʌpˈləʊdz/、美 /ʌpˈloʊdz/

**先抓住这个画面**

本地照片送到网站，是上传；网站里列出来的一份份上传内容，也可叫 uploads。它既能说动作，也能数动作、文件。

**怎么拆**

up + load → upload；加 -s → uploads，/d/ 后读 /z/。常见名词前重、动词后重；网络中的 up 标示传送方向，不是文件在物理空间里向天上飞。

**怎么变成今天的意思**

**up 向上 + load 装载 → upload 上传**  
将装载动作借给向远端系统送入数据

↓

**upload + -s → uploads**  
名词复数、第三人称单数动词；常有重音差别

recent uploads 是最近上传的内容；failed uploads 是失败的上传操作；uploads a photo 是上传一张照片。

**常见搭配与例句**

recent uploads；failed uploads；uploads a photo。

> Recent uploads appear at the top of the page.

最近上传的内容显示在页面顶部。

> She uploads a new drawing every Friday.

她每周五上传一幅新画。

**别混淆**

uploads 强调送到远端、服务一侧；downloads 则常从远端取回。方向按当前设备、系统语境判断。

<a id="w-2"></a>

### 4. uploader — 上传者；上传程序、上传工具

**音标**：英 /ʌpˈləʊdə/；美 /ʌpˈloʊdər/

**先抓住这个画面**

人把文件传上去，是 uploader；软件替你执行上传，也叫 uploader。-er 按动作命名，不一定是人。

**怎么拆**

upload + -er，来自 up- + load 的网络动词。人物名或执行上传的软件工具名。

**怎么变成今天的意思**

**load 装载；up + load → upload**  
把文件送到远端系统、服务

↓

**upload + -er；re- + upload**  
上传者、上传工具；再次上传及其结果

the original uploader 原上传者，a file uploader 文件上传工具。

**常见搭配与例句**

the original uploader；a file uploader。

> The original uploader corrected the file description.

原上传者更正了文件说明。

> The uploader supports several files at once.

上传工具支持一次传多个文件。

**别混淆**

uploader 是上传行为角色；并不单凭这个词说明作品版权归属、文件作者是谁。

<a id="w-5"></a>

### 5. uploaders — 上传者；上传工具〔复数〕

**音标**：英 /ʌpˈləʊdəz/；美 /ʌpˈloʊdərz/

**先抓住这个画面**

做上传动作的人，或替人完成上传的软件工具，都可以按作用叫 uploaders。

**怎么拆**

upload + -er → uploader，再加 -s。-er 按动作命名执行者或器具，复数 /z/。

**怎么变成今天的意思**

**up + load → upload；+ -er → uploader**  
上传；执行上传的人或程序

↓

**uploader + -s → uploaders**  
多个上传者、上传工具

original uploaders 最初上传的人；file uploaders 文件上传工具。

**常见搭配与例句**

video uploaders 视频上传者；uploaders on the website 网站上的上传工具。

> The uploaders added descriptions to their videos.

上传者给各自的视频补了说明。

> We compared two file uploaders for the website.

我们为网站比较了两种文件上传工具。

**别混淆**

uploader 是上传这一行为的角色名；author 是作者，两者可以是同一人，也可以不同。

<a id="w-3"></a>

### 6. reupload — 重新上传；再次上传的文件、行为

**音标**：动词 /ˌriːʌpˈləʊd/；名词 /ˌriːˈʌpləʊd/，美式末尾 /loʊd/

**先抓住这个画面**

已经 upload 过，再来一次，就是 reupload。原文件有问题、换了版本，都可能出现这一步。

**怎么拆**

re- 再次 + upload；动词再可作名词。是否覆盖原件、另存新件由实际系统和操作决定。

**怎么变成今天的意思**

**load 装载；up + load → upload**  
把文件送到远端系统、服务

↓

**re- + upload → reupload**  
再次上传；再次上传的结果

reupload the file 重新上传文件，a corrected reupload 更正后重传的版本。

**常见搭配与例句**

reupload a file；a new reupload。

> She corrected the caption and reuploaded the video.

她改正说明文字后重新上传了视频。

> This is a reupload of the original recording.

这是原录音的重新上传版本。

**别混淆**

reupload 是重新传输；refresh a page 刷新页面是另一操作，不保证文件被重新上传。

## 这一组要分清什么

uploader 不自动等于原作者；reupload 与 refresh 不同。

## 串起来练习

The uploader asked her to reupload the file after the failed upload.

上传失败后，上传工具提示她重新上传文件。
