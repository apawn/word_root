# 1672 · cloud — 成团的云；遮挡光线，再到模糊判断

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

古词先有岩块、团块义，后来把天空那一团叫云。看不清、心里蒙上一层阴影，都有遮蔽画面可抓。

**CLOUD：一团东西挡住了原本清楚的视线**

cloud → cloudy 多云、浑浊；clouded 被蒙蔽；cloudless 没有云。技术云另借抽象网络画法。

- **基本团块和直接状态**：cloud · cloudy
- **被遮挡和去掉云层**：clouded · cloudless
- **cloud → clouds：从团块到天空的云**：cloud · clouds

## 词形与演化规律

clūd → cloud；cloud + -y/-ed/-less。

古英语 clud 原为岩块、石堆等，后转指天空团状云；云计算另有技术比喻。

## 逐词讲解

<a id="w-1"></a>

### 1. cloud — 云、云团；云计算资源；遮蔽、使模糊

**音标**：/klaʊd/

**先抓住这个画面**

一团浮在天上的白灰色形状，挡住后面的光；愤怒把判断挡住、疑虑笼罩前景，也可以叫 cloud。

**怎么拆**

接古英语 clūd，原指岩块、石堆等团块，后来转指天空中成团的云。云计算又借了网络云图等抽象画法，不是真的把文件放进水汽。

**怎么变成今天的意思**

**古英语 clūd**  
一大块岩石、石堆、山丘等团块

↓

**中古英语 cloud → 英语 cloud**  
天空中的团块 → 云；遮蔽、使模糊

a cloud of dust 一团尘土，cloud your judgment 影响、蒙蔽判断，store files in the cloud 把文件存到云端，under a cloud 笼罩在怀疑中。

**常见搭配与例句**

a cloud of dust；cloud your judgment；in the cloud；under a cloud。

> A cloud of dust rose behind the truck.

卡车后扬起一团尘土。

> Do not let anger cloud your judgment.

别让愤怒蒙蔽你的判断。

**别混淆**

云由微小水滴、冰晶等构成，不是可见纯水蒸气本身；技术 cloud 指网络提供的资源，仍有实际设备承载。

<a id="w-5"></a>

### 2. clouds — 云；团状物、阴影等〔复数〕；使模糊、使蒙上阴影〔第三人称单数〕

**音标**：/klaʊdz/

**先抓住这个画面**

天空里一团团聚着的云，是 clouds 的直接画面。尘土、烟也会成团，忧虑、偏见也可能像云一样遮住清楚的判断。

**怎么拆**

cloud + -s，/d/ 后读 /z/。cloud 接古英语 clud，原指岩块、石堆等团块，后来用来称天空中的团状云。

**怎么变成今天的意思**

**古英语 clud → cloud**  
岩块、团块 → 天空里的云

↓

**cloud + -s → clouds**  
多团云、团状物；某事使看法不清或蒙上阴影

dark clouds 乌云；clouds of dust 一团团尘土；clouds someone’s judgement 使某人判断不清。

**常见搭配与例句**

clouds in the sky 天上的云；a cloud of smoke 一团烟。

> Dark clouds gathered over the hills.

乌云聚集在山丘上空。

> Personal bias sometimes clouds our judgement.

个人偏见有时让我们难以清楚判断。

**别混淆**

clouds 直接说云团；云计算中的 cloud 则是网络、服务环境的技术比喻。clouds the issue 是使问题更难看清的动词用法。

<a id="w-2"></a>

### 3. cloudy — 多云的；浑浊的；模糊不清的

**音标**：/ˈklaʊdi/

**先抓住这个画面**

天空有云不透亮，水里悬着细小东西也不透亮；事情讲不清，就借这种看不透的感觉。

**怎么拆**

cloud + -y 的现代对应；旧词有和团块、石多相关的历史形式，云义发展后再有多云、浑浊等用法。

**怎么变成今天的意思**

**古英语 clūd**  
一大块岩石、石堆、山丘等团块

↓

**中古英语 cloud → 英语 cloud**  
天空中的团块 → 云；遮蔽、使模糊

↓

**cloud + -y → cloudy**  
云多；不清澈、看不透

a cloudy day 多云的一天，cloudy water 浑浊的水，cloudy memories 模糊的记忆。天气多云不等于必定正在下雨。

**常见搭配与例句**

a cloudy day；cloudy water；cloudy memories。

> It was cloudy, but the rain held off.

天上多云，不过一直没下雨。

> The water turned cloudy when we stirred the sediment.

我们搅动沉淀物时，水变浑浊了。

**别混淆**

cloudy 天空多云，overcast 通常更强调云层铺满天空；cloudy water 不是水里有天上的完整云团。

<a id="w-3"></a>

### 4. clouded — 被遮蔽、蒙蔽的；模糊的；使模糊了

**音标**：/ˈklaʊdɪd/

**先抓住这个画面**

视线或头脑像隔着一层云：东西还在，但你看不清。也可描述情绪使一张脸失去原来明朗神色。

**怎么拆**

cloud + -ed，动词过去式、过去分词及相应形容词；词基末尾 /d/ 后加 -ed 读 /ɪd/。

**怎么变成今天的意思**

**古英语 clūd**  
一大块岩石、石堆、山丘等团块

↓

**中古英语 cloud → 英语 cloud**  
天空中的团块 → 云；遮蔽、使模糊

↓

**cloud + -ed → clouded**  
被覆盖、使模糊；判断、记忆等受干扰

clouded judgment 受蒙蔽的判断，clouded memories 模糊记忆，clouded by uncertainty 被不确定性笼罩。

**常见搭配与例句**

clouded judgment；clouded memories；clouded by uncertainty。

> His judgment was clouded by jealousy.

嫉妒蒙蔽了他的判断。

> The future was clouded by uncertainty.

未来笼罩在不确定性之中。

**别混淆**

clouded 常突出某种东西挡住、干扰了清晰度；cloudy 直接描述多云、浑浊、不清的状态，二者有重叠。

<a id="w-4"></a>

### 5. cloudless — 无云的、晴空无云的

**音标**：/ˈklaʊdləs/

**先抓住这个画面**

抬头是一整片清楚的天空，没有云团挡着；-less 把 cloud 拿掉。

**怎么拆**

cloud + -less，没有云。中古英语已有相应形式；没有云和天气是否温暖是两回事。

**怎么变成今天的意思**

**古英语 clūd**  
一大块岩石、石堆、山丘等团块

↓

**中古英语 cloud → 英语 cloud**  
天空中的团块 → 云；遮蔽、使模糊

↓

**cloud + -less → cloudless**  
没有云层、云团遮挡的

a cloudless sky 万里无云的天空，a cloudless night 无云之夜。文学里也可借来形容没有阴影的明朗状态。

**常见搭配与例句**

a cloudless sky；a cloudless night；cloudless blue。

> The stars were bright in the cloudless sky.

星星在无云的夜空里很明亮。

> We set off under a cloudless blue sky.

我们在湛蓝无云的天空下出发了。

**别混淆**

cloudless 无云，sunny 有阳光；夜空也可 cloudless，所以不能每次都译成阳光明媚。

## 这一组要分清什么

cloudy/overcast 多云与云层满布；cloudless 夜里也能用；技术 cloud 不是真把文件存进水汽。

## 串起来练习

A cloudy sky did not cloud her judgment, and by evening the sky was cloudless.

多云的天空没影响她的判断，到傍晚天空也无云了。
