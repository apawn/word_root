# 1169 · argue — 提出理由、论证；争论

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

argue 经古法语 arguer 接拉丁 arguere 显示、说明、证明、指责等材料。现代论证与争执从这些说清、质疑的关系展开。

**ARGUE：把理由摆出来，支持或反驳一种看法**

argue a point 可以理性论证，不要求脸红吵架；an argument 可以是一套理由，也可以是一场争执。

- **提出理由与论证**：argue · argument
- **可以主张、讨论的性质**：arguable
- **argument → arguments：证据、理由与争论**：argument · arguments

## 词形与演化规律

argue + -able → arguable，去末尾 e；argument 是同族名词。arguable 常说有理由可主张，也可能说尚有争议，需看上下文。

拉丁证明材料经法语借入，现代理由与吵架语境分开。

## 逐词讲解

<a id="w-2"></a>

### 1. argue — 争论、争吵；论证、主张

**音标**：英 /ˈɑːɡjuː/；美 /ˈɑːrɡjuː/

**先抓住这个画面**

可以是两个人各不相让地争，也可以是作者安静地拿理由支持观点。共同点是把自己的主张推到台面上。

**怎么拆**

经法语 arguer 接拉丁 arguere 显示、证明、指责；不是只从今天吵架义往回解释。

**怎么变成今天的意思**

**拉丁 arguere 显示、证明、指责 → 法语 arguer**  
把理由、指控摆出来

↓

**英语 argue；拉丁 argumentum 经法语 → argument**  
论证、争论；理由或争吵

argue with someone 与某人争论；argue about a topic 争论话题；argue that 主张；argue for/against 为某观点提供支持或反对理由。

**常见搭配与例句**

argue that；argue with；argue for/against。

> They argued about who should pay.

他们为该谁付钱争论。

> The author argues that the policy needs to change.

作者论证这项政策需要改变。

**别混淆**

argue that 在论文里通常是提出论证，不一定是发火。quarrel 更聚焦争吵、失和。

<a id="w-1"></a>

### 2. argument — 争论、争吵；理由、论证；参数〔计算机〕

**音标**：英 /ˈɑːɡjumənt/；美 /ˈɑːrɡjumənt/

**先抓住这个画面**

日常 an argument 可是一场争吵；写作里 an argument 则是一条有理由支撑的主张。先看场景，再决定中文。

**怎么拆**

经法语接拉丁 argumentum 证明、理由；现代对应 argue 去 e 加 -ment。计算机的参数义是另一项专门发展。

**怎么变成今天的意思**

**拉丁 arguere 显示、证明、指责 → 法语 arguer**  
把理由、指控摆出来

↓

**英语 argue；拉丁 argumentum 经法语 → argument**  
论证、争论；理由或争吵

↓

**argumentum → argument**  
理由、论证；争论事件；后有技术用法

have an argument 争吵；an argument for/against 支持、反对理由；a convincing argument 有说服力的论证；pass an argument 向函数传参。

**常见搭配与例句**

have an argument；a strong argument；a function argument。

> They had an argument about the budget.

他们为预算吵了一架。

> She presented a clear argument for keeping the library open.

她给出了保留图书馆开放的清晰理由。

**别混淆**

argument 不总是情绪冲突；a strong argument 可能在夸逻辑有力。编程中的 argument 也不是函数之间在吵架。

<a id="w-4"></a>

### 3. arguments — 理由、论证；争论；参数〔复数〕

**音标**：英 /ˈɑːɡjəmənts/；美 /ˈɑːrɡjəmənts/

**先抓住这个画面**

为了让别人看明白，你拿出的一套理由，是 arguments；双方互不认同时，这种来回论说又可成为争论。程序里的参数则是另一项专业用途。

**怎么拆**

argument + -s，/t/ 后读 /s/。法语 argument 接拉丁 argūmentum 证明、理由，联系 arguere 讲明、证明；现代与 argue、-ment 对照，但名词有独立借入历史。

**怎么变成今天的意思**

**拉丁 arguere、argūmentum → 法语、英语 argument**  
讲明、证明 → 理由、论证

↓

**argument + -s → arguments；不同语域扩展**  
多项理由、争论；程序调用传入的参数

arguments for and against 赞成、反对的理由；strong arguments 有力论证；function arguments 函数参数。

**常见搭配与例句**

arguments presented in the report；arguments about the plan。

> The report presents arguments for and against the change.

报告列出支持和反对这项改变的理由。

> The function accepts two arguments.

这个函数接收两个参数。

**别混淆**

arguments 不一定是吵架，文章里的 arguments 常是支持观点的理由链。写程序时传给函数的 arguments 则按技术语境理解。

<a id="w-3"></a>

### 4. arguable — 有理由主张的；可争论、有疑问的

**音标**：英 /ˈɑːɡjuəbəl/；美 /ˈɑːrɡjuəbəl/

**先抓住这个画面**

这说法能提出理由支持，但还不是铁板钉钉；arguable 因而可以从“有理由这样说”，也可以从“还值得争论”两面表达。

**怎么拆**

argue 去 e 加 -able → arguable；-able 保留可以论证、讨论的意义，具体是在支持主张还是质疑确定性，要看句子。

**怎么变成今天的意思**

**argue**  
争论；提出理由论证

↓

**argue + -able → arguable**  
有理由主张；可争论的

It is arguable that… 可以提出理由认为……；an arguable point 是可以论证、也可有争议的观点。

**常见搭配与例句**

It is arguable that；an arguable case。

> It is arguable that the simpler design works better.

有理由认为，较简单的设计效果更好。

> Whether the change was necessary remains arguable.

这次改动是否必要，仍有讨论余地。

**别混淆**

arguable 不是 unarguable 无可争辩的；副词 arguably 常表示可以说、按一种有依据的看法，并非绝对断言。

## 这一组要分清什么

argue with someone 与人争论，argue for a proposal 为提案辩护；a strong argument 是有力理由，不是声音特别大的争吵。

## 串起来练习

She argued calmly and supported her argument with examples.

她平静地论证，用例子支持自己的观点。
