# 0772 · web — 织成的网；蛛网、关系网与万维网

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

web 继承古英语 webb，与 weave 历史相关。cobweb 前半是蜘蛛旧称，不是玉米芯；现代 Web 与整个互联网基础设施分开。

**WEB：细线彼此牵连，织成一个整体**

先抓住织网，再理解谎言网、关系网；万维网借同样的互联图景。在线播出、商店再按功能形成词。

- **织网、蛛网与关系**：web · spiderweb · cobweb
- **在线页面、播出与商店**：website · webcast · webstore
- **web + cam → webcam → webcams：网络摄像头**：web · webcam · webcams
- **webcast 的网络播送与常用形式**：webcast · webcasts · webcasting

## 词形与演化规律

web → spiderweb、cobweb；Web → website、webcast、webstore。前一组具体网，后一组在线信息功能。

Web 给网络用途，cam 缩自 camera，不取机械凸轮的另源 cam。

web 是网络用途，cast 接播出材料；是否现场实时，另看 live 等限定。

## 逐词讲解

<a id="w-2"></a>

### 1. web — 网；蛛网；交织关系；万维网

**音标**：/web/

**先抓住这个画面**

很多细线相互牵连，织成一张网；关系、谎言、网页互相连接，也借这幅图景。

**怎么拆**

继承古英语 webb，与 weave 织有历史关联。现代 Web、World Wide Web 把互相链接的信息比成网，不是英语 web 最初就为计算机而造。

**怎么变成今天的意思**

**古英语 webb → 中古英语 web、webbe**  
织成的东西、网，与 weave 织的词族相关

↓

**英语 web**  
蛛网、交织关系；Web 用于互相链接的信息系统

a spider’s web 蛛网，a web of lies 一张谎言网；on the web 在万维网上。Web 是借互联网运行的信息系统之一，不等于所有互联网服务。

**常见搭配与例句**

a spider’s web；a web of lies；on the web；search the web。

> A web stretched between the branches.

树枝之间结着一张网。

> The detective uncovered a web of lies.

侦探揭开了一张交织的谎言网。

**别混淆**

web 万维网与 internet 互联网不是完全同义：网络基础设施能承载网页，也能承载其他服务。口语有时混用，学习时先分清。

<a id="w-1"></a>

### 2. website — 网站

**音标**：/ˈwebsaɪt/

**先抓住这个画面**

同一个网络地址体系下，一组彼此关联、供访问的网页组成一个站。

**怎么拆**

web（万维网）+ site（站点）→ website：把相关网页与功能组织在一起的网络站点。

**怎么变成今天的意思**

**web〔万维网〕；site**  
并列构词部分

↓

**website**  
互相组织、关联的网页站点

visit a website 访问网站，the official website 官方网站。网站可能分布在多台服务器，不能把一个网站定义成必须只放在一台机器上。

**常见搭配与例句**

visit a website；the official website；a website address。

> The museum’s website lists its opening hours.

博物馆网站列出了开放时间。

> She built a website for the village history project.

她为村史项目建了一个网站。

**别混淆**

website 网站整体，webpage 单个网页；一个 website 往往包含多个 webpages。

<a id="w-4"></a>

### 3. webcast — 网络音视频播出；网络转播

**音标**：英 /ˈwebkɑːst/；美 /ˈwebkæst/

**先抓住这个画面**

把活动、节目通过网络送到观众屏幕或耳机里，像把传统广播、电视播出搬上网。

**怎么拆**

web 万维网 + cast 播出相关构词部分，仿照 broadcast 等形成。不是把网撒进水里的字面动作。

**怎么变成今天的意思**

**古英语 webb → 中古英语 web、webbe**  
织成的东西、网，与 weave 织的词族相关

↓

**英语 web**  
蛛网、交织关系；Web 用于互相链接的信息系统

↓

**web + cast；联系 broadcast 的播出构词**  
网络 → 网络音视频播出

a live webcast 网络直播，a webcast of the ceremony 典礼网络转播；也可有录播、按需观看，不是每次都同时直播。

**常见搭配与例句**

a live webcast；watch a webcast；a webcast of the event。

> The lecture is available as a webcast.

讲座可以通过网络音视频节目观看。

> We watched a live webcast of the opening ceremony.

我们观看了开幕式网络直播。

**别混淆**

webcast 广播式网络节目，webinar 通常是在线研讨、讲座；实际活动形式可能交叠，不能只因在线就都叫 webinar。

<a id="w-11"></a>

### 4. webcasts — 网络播送节目〔复数〕；网络播送〔第三人称单数〕

**音标**：英 /ˈwebkɑːsts/；美 /ˈwebkæsts/

**先抓住这个画面**

通过 Web 把声音、画面播给观众，这些节目叫 webcasts；作动词则说通过网络播出。

**怎么拆**

web 万维网 + cast 播出材料 → webcast，加 -s，/t/ 后读 /s/；仿照 broadcast 一类名称形成。

**怎么变成今天的意思**

**web + cast → webcast**  
利用网络播出内容

↓

**webcast + -s → webcasts**  
多个网络节目；它网络播出

live webcasts 网络直播；educational webcasts 教育网络节目。

**常见搭配与例句**

watch webcasts 看网络播送；webcasts the lecture 网络播出讲座。

> The museum offers educational webcasts.

博物馆提供教育网络节目。

> The university webcasts the public lectures.

大学在网上播出公开讲座。

**别混淆**

webcast 名称强调网络播送，是否现场实时可用 live 等词进一步说明。

<a id="w-12"></a>

### 5. webcasting — 网络播送；正在通过网络播出

**音标**：英 /ˈwebkɑːstɪŋ/；美 /ˈwebkæstɪŋ/

**先抓住这个画面**

声音、画面经网络连续送到观众那里，这项播出活动叫 webcasting。

**怎么拆**

web + cast → webcast，加 -ing，基础词不改。cast 接播送构词材料，前半限定 Web 渠道。

**怎么变成今天的意思**

**web + cast → webcast**  
通过 Web 播送

↓

**webcast + -ing → webcasting**  
网络播送的进行、活动

webcasting a lecture 网络播送讲座；webcasting equipment 网络播送设备。

**常见搭配与例句**

live webcasting 实时网络播送；start webcasting 开始网络播送。

> The team is webcasting the public lecture.

团队正在网上播出公开讲座。

> Webcasting allowed distant viewers to follow the event.

网络播送让远处观众也能观看活动。

**别混淆**

webcasting 强调传播渠道，filming 强调拍摄内容，录制与播出可以分开进行。

<a id="w-8"></a>

### 6. webstore — 网店；在线商店

**音标**：英 /ˈwebstɔː/；美 /ˈwebstɔːr/

**先抓住这个画面**

顾客通过网页浏览商品、下单的店；没有临街门面，也能把它当一家商店。

**怎么拆**

web 万维网 + store 商店，也常写 web store、online store。不是把蜘蛛网存到仓库的 store 动词。

**怎么变成今天的意思**

**web 万维网；store 商店**  
并列构词部分

↓

**webstore**  
通过网页经营的商店

open a webstore 开网店，buy from a webstore 从网店购买；某些平台专名也使用 Web Store，需区分普通词与品牌。

**常见搭配与例句**

open a webstore；an official webstore；buy from a webstore。

> The artist opened a webstore for her handmade jewellery.

艺术家为手工首饰开了一家网店。

> The official webstore lists the available sizes.

官方网店列出了现有尺码。

**别混淆**

webstore 网店是一类 website 网站；不是所有网站都销售东西。storefront 则强调面向顾客的店面、界面。

<a id="w-6"></a>

### 7. cobweb — 蜘蛛网；陈旧积灰的蛛网印象

**音标**：英 /ˈkɒbweb/；美 /ˈkɑːbweb/

**先抓住这个画面**

和 spiderweb 都能说蛛网，但家务场景里 cobweb 常让人想到角落里积灰、久未清理的网。

**怎么拆**

中古英语 copweb 等，前半 cob、coppe 是蜘蛛的旧称，与现代 corn cob 玉米芯不同；后半 web 是网。它不是玉米芯织网。

**怎么变成今天的意思**

**古英语 webb → 中古英语 web、webbe**  
织成的东西、网，与 weave 织的词族相关

↓

**旧 coppe 蜘蛛 + web → cobweb**  
旧蜘蛛称呼 + 网 → 蛛网

cobwebs in the attic 阁楼蛛网；blow away the cobwebs 固定说去掉昏沉、焕发精神。自然分类里 cobweb 也有具体使用，不能一律要求蛛网已被废弃。

**常见搭配与例句**

clear away cobwebs；cobwebs in the corner；blow away the cobwebs。

> The old shed was full of cobwebs.

旧棚屋里到处是蛛网。

> A brisk walk helped blow away the cobwebs.

快步走一会儿，让人一扫昏沉。

**别混淆**

cobweb 和 spiderweb 意义重叠，前者日常更易联想到陈旧积灰；这不是把所有活蜘蛛的网都排除的硬规则。

<a id="w-7"></a>

### 8. spiderweb — 蜘蛛网；蛛网状结构

**音标**：英 /ˈspaɪdəweb/；美 /ˈspaɪdərweb/

**先抓住这个画面**

蜘蛛吐丝结成的网；交错线条、裂纹像它，也可以借这个名称。

**怎么拆**

spider 蜘蛛 + web 网，透明复合词，也常写 spider web。名字说的是来源、样子，不是所有蜘蛛网都同样圆、同样规则。

**怎么变成今天的意思**

**spider 蜘蛛；web 网**  
并列构词部分

↓

**spiderweb**  
蜘蛛结的网 → 蛛网状结构

a spiderweb in the corner 角落的蛛网，a spiderweb of cracks 蛛网般裂纹；后一种是外形比喻。

**常见搭配与例句**

a spiderweb；a spiderweb of cracks；a delicate spiderweb。

> A spiderweb glistened with morning dew.

蜘蛛网上的晨露闪着光。

> A spiderweb of cracks covered the old glass.

旧玻璃上布满蛛网般的裂纹。

**别混淆**

spiderweb 蛛网，website 网站；同有 web 并不能替代前面的对象。

<a id="w-9"></a>

### 9. webcam — 网络摄像头

**音标**：英 /ˈwebkæm/；美 /ˈwebˌkæm/

**先抓住这个画面**

把眼前画面送进电脑或网络，让另一端的人看见。

**怎么拆**

Web + cam，cam 是 camera 的截短；它沿用的是拍摄设备义。

**怎么变成今天的意思**

**古希腊语 kamara → 拉丁语 camera**  
有拱顶的空间、房间；更早来源未定

↓

**新拉丁语 camera obscura；英语简称 camera**  
暗室成像装置

↓

**英语 camera 的摄影、摄像义**  
暗箱式成像装置 → 拍照或录影设备

↓

**英语 Web + cam〔camera 截短〕→ webcam**  
面向联网使用的摄像头

可以是笔记本内置，也可以单独插上。视频会议、网络直播常用 webcam；它的名称不意味着每一刻都必须连着互联网。

**常见搭配与例句**

a built-in webcam；an external webcam；switch on the webcam。

> Her laptop has a built-in webcam.

她的笔记本电脑有内置摄像头。

> We tested the webcam before the online interview.

线上面试前，我们测试了摄像头。

**别混淆**

webcam 强调电脑联网拍摄用途；security camera 侧重监控，两者功能可能有交集。

<a id="w-10"></a>

### 10. webcams — 网络摄像头〔复数〕

**音标**：/ˈwebkæmz/

**先抓住这个画面**

把画面拍下来供网络交流、传送的摄像头，是 webcams。Web 给网络用途，cam 是 camera 的短称。

**怎么拆**

Web + cam，后者截短自 camera → webcam，再加 -s，/m/ 后读 /z/。cam 的拍摄设备义与机械凸轮同形词分开。

**怎么变成今天的意思**

**camera 截短 cam；Web + cam → webcam**  
拍摄设备名称缩短后形成新组合

↓

**webcam + -s → webcams**  
多个网络摄像头

webcams built into the computers 电脑内置摄像头；external webcams 外接摄像头。

**常见搭配与例句**

webcams on the computers 电脑上的摄像头；test the webcams 测试网络摄像头。

> The computers have webcams above the screens.

电脑屏幕上方有网络摄像头。

> They tested the webcams before the online lesson.

他们在线上课前测试了摄像头。

**别混淆**

cam 不是每次都要解释为凸轮；这里由 camera 的截短确定拍摄设备义。Web 部分再限定网络用途。

## 这一组要分清什么

web 不等于全部 internet；cobweb 不从玉米芯来；webcast 可以录播，webstore 只是网站的一类用途。

## 串起来练习

The webstore’s website hosted a webcast about handmade weaving.

网店的网站播出了一段介绍手工编织的网络节目。
