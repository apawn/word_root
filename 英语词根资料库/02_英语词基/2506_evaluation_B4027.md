# 2506 · evaluation — 按标准评估，再把判断重新拿出来衡量

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

第一次评估是 evaluation；补了数据、换了条件，再做则是 reevaluation。它表示过程重来，不预设结论。

**EVALUATION：先评价，再决定是否需要重新评价**

evaluation → reevaluation。

- **评估与重新评估**：evaluation · reevaluation

## 词形与演化规律

evaluate → evaluation；re- + evaluation → reevaluation。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. evaluation — 评估；评价过程；评估结果

**音标**：英、美 /ɪˌvæljuˈeɪʃən/

**先抓住这个画面**

把证据收集起来，与标准对照，再形成一个能说明理由的判断。

**怎么拆**

借自法语 évaluation；英语名词比 evaluate 的常见记录更早，所以历史图从名词借入讲起。

**怎么变成今天的意思**

![evaluation 的词源演化](../assets/evolution/evaluation-efe77b20.svg)

可以谈项目评估、表现评估，也可以指某一份具体评估。a positive evaluation 是好评；evaluation 本身不保证结论积极。

**常见搭配与例句**

a thorough evaluation；performance evaluation；an evaluation of…。

> The evaluation found that the new layout reduced waiting time.

评估发现，新布局缩短了等待时间。

> Each applicant received a written evaluation.

每位申请者都收到了一份书面评价。

**别混淆**

assessment 和 evaluation 常重叠；evaluation 尤其常用于判断价值、效果或质量，没有处处适用的硬分界。

<a id="w-2"></a>

### 2. reevaluation — 重新评估、再次评价

**音标**：/ˌriːɪvæljuˈeɪʃən/

**先抓住这个画面**

条件变了、资料多了，再把原先的判断拿出来衡量一次，就是 reevaluation。结果可以改变，也可以确认原来的判断。

**怎么拆**

re- 再、重新 + evaluation；里面 evaluate 联系 value 价值，-ation 把评估动作名词化。连续两个 e 分属 re- 和 evaluation。

**怎么变成今天的意思**

**evaluate 评估 → evaluation**  
按标准判断价值、表现等

↓

**re- + evaluation → reevaluation**  
再做一次或重新进行评估

a reevaluation of the plan 重新评估计划，call for reevaluation 要求重新评估，after reevaluation 再评估后。

**常见搭配与例句**

a reevaluation of；call for reevaluation。

> The new data prompted a reevaluation of the plan.

新数据促使人们重新评估计划。

> After reevaluation, the team kept its original design.

重新评估后，团队保留了原设计。

**别混淆**

reevaluation 不是自动否定旧结论；re- 说明再看一次，不规定结果必须相反。

## 这一组要分清什么

再评估可以保留原判断；of 后接评估对象。

## 串起来练习

A careful evaluation made later reevaluation easier.

仔细的初次评估让之后的重新评估更容易。
