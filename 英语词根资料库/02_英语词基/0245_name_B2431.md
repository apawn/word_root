# 0245 · name — 称呼；名称；名誉；命名

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

name 接古英语 nama、noma，动词还有 namian 等形式。name 的声誉义与命名、身份关系相通，但现代每个复合词选的对象不同。

**NAME：给对象一个可叫出来、可识别的称呼**

人要名字，账号、机器、项目也要名字；别人听到这个称呼的印象又成为名声。

- **名称、指明与改名**：name · namely · nameless · rename
- **人与同名关系**：namesake · surname
- **可见标牌**：nameplate · nametag
- **系统名称与项目代号**：username · hostname · filename · namespace · codename
- **name → nickname → nicknamed**：name · nickname · nicknamed
- **name → names：名称与命名、点名**：name · names · nickname
- **name → named：命名、点名、任命**：name · named
- **name → naming：给名称、指明是谁**：name · naming
- **username → usernames：系统识别名**：username · usernames
- **name 的文件识别组合及复数**：filename · filenames

## 词形与演化规律

先 name、namely、nameless、rename，再看 namesake 的同名和纪念关系；标识物 nameplate、nametag 放一起，username、hostname、filename、namespace 是系统里的不同名称层次，codename 是代号，surname 是姓。

nickname 原是额外的名字，历史上 an eke name 的 n 被重新划到后面的词；现代可作名词，也可作动词给人起绰号。

names 同时可作名词复数与动词第三人称，name names 是说出具体人名。

name 去末尾 e，加完整 -ed，named 词尾读 /d/；named after 是以……命名。

古英语名词、动词传承，现代去 e 加完整 ing。

user 为 use 去 e 加 er，整体再与 name 组合。

文件名是给文件起的标识名；文件路径还包含所在位置的信息。

## 逐词讲解

<a id="w-1"></a>

### 1. name — 名字；名称；名声；命名；指明

**音标**：/neɪm/

**先抓住这个画面**

给对象一个能叫得出来的称呼；别人听到这名字想到什么，又形成名声。

**怎么拆**

名词接古英语 nama、noma，动词有 namian 等形式，经中古英语延续。与多种印欧语言的名称词有历史关联，不是现代 na + me。

**怎么变成今天的意思**

**古英语 nama / noma → 中古英语 name**  
姓名、名称

↓

**英语 name**  
名称；名声；命名、指名

name a child 是给孩子起名，name three cities 是说出三个城市名称；a good name 是好名声，in the name of 是以……名义。name someone as ... 也能指定某人担任。

**常见搭配与例句**

by name；in the name of；name after；make a name for oneself。

> What name would you like us to use?

你希望我们怎样称呼你？

> Can you name three cities in Canada?

你能说出三个加拿大城市吗？

> She made a name for herself as a designer.

她作为设计师闯出了名声。

**别混淆**

name 是称呼、名声，title 常是头衔或作品题名；一本书的 name、title 可接近，人的 name 与职位 title 则不同。

<a id="w-17"></a>

### 2. named — 命名了；点名、列举、任命了；名叫……的；name 的过去式和过去分词

**音标**：/neɪmd/

**先抓住这个画面**

把一个名字明确安到人、物或职位上，是 named。它能说起名字，也能说公告指出谁，或宣布由谁担任。

**怎么拆**

name 去末尾 e，加完整 -ed；/m/ 后读 /d/。名词接古英语 nama、noma，动词有 namian 等相关形式；现代按规则产生 named。

**怎么变成今天的意思**

**古英语名称、命名词族 → name**  
名字；命名、说出名称

↓

**name 去 e + -ed → named**  
过去命名、点名、任命；名叫……的

a boy named Tom 名叫汤姆的男孩；named after ... 以……命名；named the winner 宣布获胜者；named someone as ... 指出某人是……；named captain 任命为队长。

**常见搭配与例句**

was named after her grandmother；named in the report。

> The boat was named after the owner’s daughter.

这条船以船主女儿的名字命名。

> Three people were named in the announcement.

公告里点到了三个人的名字。

**别混淆**

was named after someone 是名字取自某人；was named in a report 是报告里提到了名字。after 与 in 交代的关系不同。

<a id="w-16"></a>

### 3. names — 名字、名称〔复数〕；命名、点名、任命〔name 的第三人称单数〕

**音标**：/neɪmz/

**先抓住这个画面**

名单上的名字是 names；公告把某人明确点出来，或宣布某人担任某职，name 也能作动词，单数主语后写 names。

**怎么拆**

name 已有 e，直接加 s，/m/ 后读 /z/。name 接古英语 nama、noma 等名称词及相关命名动词，名词、动词形式现代相同。

**怎么变成今天的意思**

**古英语名称、命名词 → name**  
名字、称呼；给出名称

↓

**name + -s → names**  
多个名字；单数主语说出名字、命名等

first names 名；family names 姓；place names 地名；name names 说出具体人名；names a winner 指定、宣布获胜者。

**常见搭配与例句**

a list of names；remember people’s names。

> I am better at remembering faces than names.

我记脸比记名字更在行。

> The final paragraph names the people who helped.

最后一段列出了提供帮助的人。

**别混淆**

names 是复数；name’s 可是单数所有格，也可能是 name is 的缩写，靠句子判断。name names 的第二个 names 是名词复数。

<a id="w-2"></a>

### 4. namely — 也就是；具体说来

**音标**：/ˈneɪmli/

**先抓住这个画面**

刚说了一个范围，接着把里面到底是哪几项点名说清。

**怎么拆**

name + -ly，接中古英语 nameliche、namely 等副词形式。现代常见具体指明义，不是“以名字的方式”逐字翻译。

**怎么变成今天的意思**

**古英语 nama / noma → 中古英语 name**  
姓名、名称

↓

**英语 name**  
名称；名声；命名、指名

↓

**中古英语 nameliche / namely → namely**  
点名、具体指出 → 也就是

There is one problem, namely ... 是有一个问题，具体就是……。namely 后通常补充前面所指的具体内容，不只是随便举一个例子。

**常见搭配与例句**

namely ...；two things, namely ...；one issue, namely ...。

> We need one thing, namely more time.

我们需要一件东西，也就是更多时间。

> Two people were absent, namely Leo and Maya.

两人缺席，也就是利奥和玛雅。

**别混淆**

namely 指明前面到底是什么，for example 只是举例；We need two things, namely A and B 通常列明那两件，不是在很多项中随手举两例。

<a id="w-18"></a>

### 5. naming — 命名、点名、指明〔现在分词、动名词〕

**音标**：/ˈneɪmɪŋ/

**先抓住这个画面**

给一个东西安上称呼，或把原来泛泛说的人明确指出来，是 naming。既可以给新角色起名，也可以说出某个人是谁。

**怎么拆**

name 名词接古英语 nama、noma，动词有 namian 等形式，经中古英语延续。现代 name 去 e 加完整 -ing，/m/ 和前面的长元音保留。

**怎么变成今天的意思**

**古英语名称名词、命名动词 → name**  
名称 → 命名、指名

↓

**name 去 e + -ing → naming**  
正在起名、点出名称；命名过程

naming a character 给角色起名；naming the winner 公布获胜者姓名；naming conventions 命名惯例。

**常见搭配与例句**

without naming anyone 不点任何人的名；a naming ceremony 命名仪式。

> She enjoyed naming the characters in her story.

她喜欢给自己故事里的角色起名。

> He described the problem without naming anyone.

他描述了问题，却没有点名任何人。

**别混淆**

naming 不只说创造新名字。naming the winner 可以是把获胜者的姓名公开说出，不是重新给他改名。

<a id="w-6"></a>

### 6. nameless — 无名的；未透露姓名的；难以形容的

**音标**：/ˈneɪmləs/

**先抓住这个画面**

名字没有给出，可能根本无名，也可能知道却故意不说。

**怎么拆**

name + -less，接中古英语 nameles。用来修饰 fear 等时还可说难以说清名称的恐惧，不是恐惧没领身份证。

**怎么变成今天的意思**

**古英语 nama / noma → 中古英语 name**  
姓名、名称

↓

**英语 name**  
名称；名声；命名、指名

↓

**name + -less → nameless**  
无名、未指名 → 难以名状

a nameless hero 是无名英雄，remain nameless 是不透露姓名；a nameless fear 是莫名恐惧，强调难以说清恐惧对象。

**常见搭配与例句**

remain nameless；a nameless hero；a nameless fear。

> One colleague, who shall remain nameless, forgot the keys.

一位我就不点名的同事忘带了钥匙。

> The memorial honours nameless workers who built the railway.

纪念碑纪念修建铁路的无名工人。

**别混淆**

nameless 未给出姓名或难命名，anonymous 常强调作者、身份未公开；同一对象可有重叠，但 nameless hero 也可能指被历史遗忘的人。

<a id="w-7"></a>

### 7. namesake — 同名者；名字来源者；被以其名命名的人物

**音标**：/ˈneɪmseɪk/

**先抓住这个画面**

两个人的名字连到一起：可能因为纪念对方取名，也可能只是同名。

**怎么拆**

name + sake，历史与 for one’s name’s sake 这类为名誉、为某人之名的表达相连；现代已经固定为同名、命名关联，不是 name + sake 清酒。

**怎么变成今天的意思**

**英语 name；for one’s name’s sake 等表达**  
名字；为名誉、为其名

↓

**namesake**  
同名者、命名关联的双方

my grandfather and namesake 可指与我同名、作为命名来源的祖父；a child and her namesake 也可能指因取名产生关联。用时说清谁以谁命名，免得方向含混。

**常见搭配与例句**

someone’s namesake；a namesake city；a famous namesake。

> She shares her name with her grandmother, her namesake.

她与祖母同名，名字取自祖母。

> The town welcomed visitors from its namesake in another country.

小镇欢迎来自另一国家同名城镇的访客。

**别混淆**

namesake 可以只说同名，不要求亲属关系；nickname 是绰号，surname 是姓，三种 name 关系不同。

<a id="w-10"></a>

### 8. namespace — 命名空间

**音标**：英、美 /ˈneɪmspeɪs/

**先抓住这个画面**

像先把名字放进不同的通讯录：两个人都叫 Alex，也能因所属通讯录不同而分清。

**怎么拆**

name + space；space 在这里是容纳、区分名称的抽象范围，不是存放字节的物理空间。

**怎么变成今天的意思**

**拉丁语 spatium**  
空间、范围、距离；也指一段时间，远源尚有不同解释

↓

**古法语 espace / 盎格鲁法语 space → 中古英语 space → 现代 space**  
空间、间隔、时间段；后来包括太空和抽象活动领域

↓

**英语 name + space → namespace**  
名称所属的逻辑范围；用于区分同名对象

程序中，不同模块可以各有名为 count 的对象；借助所属 namespace 可以分清引用哪一个。具体机制由编程语言决定。

**常见搭配与例句**

a global namespace；a separate namespace；a namespace collision。

> The two libraries use different namespaces to avoid naming conflicts.

这两个库使用不同命名空间来避免命名冲突。

> The function name already exists in the global namespace.

全局命名空间中已经存在这个函数名。

**别混淆**

scope 关注代码中哪些位置能直接访问某个名字；namespace 关注名字及其对应对象的组织，两者相关但不相同。

<a id="w-11"></a>

### 9. nameplate — 名牌；姓名铭牌；标识牌

**音标**：/ˈneɪmpleɪt/

**先抓住这个画面**

名字不只口头叫，还被刻、印在一块固定的小牌上。

**怎么拆**

name + plate（板、牌），plate 这里不是装食物的盘子。也可指报刊刊名标识等相关用法。

**怎么变成今天的意思**

**英语 name；plate**  
并列组合的两部分

↓

**name + plate → nameplate**  
写有姓名、名称等的牌、标识

a brass nameplate 是黄铜铭牌，a desk nameplate 是桌上姓名牌。机器铭牌也可能附型号、额定信息，但具体内容看实物。

**常见搭配与例句**

a brass nameplate；a desk nameplate；a door nameplate。

> A brass nameplate was fixed beside the door.

门边固定着一块黄铜姓名牌。

> Her new desk came with a nameplate.

她的新办公桌配有姓名牌。

**别混淆**

nameplate 常是较固定、硬质的标牌，nametag 常是临时佩戴姓名标签；材料与使用习惯可有重叠。

<a id="w-12"></a>

### 10. nametag — 姓名标签；胸牌

**音标**：/ˈneɪmtæɡ/

**先抓住这个画面**

活动里不认识彼此，把姓名贴在衣服上，见面就能叫出来。

**怎么拆**

name + tag（标签），也常写 name tag 两词。tag 在这里是标记身份的物件，不是捉人游戏的动词。

**怎么变成今天的意思**

**英语 name；tag**  
并列组合的两部分

↓

**name + tag → nametag**  
显示佩戴者姓名的标签

wear a nametag 是戴姓名牌，a conference nametag 是会议胸牌；可以贴纸，也可挂牌，不必金属材质。

**常见搭配与例句**

wear a nametag；a conference nametag；write on a nametag。

> Everyone wore a nametag at the workshop.

工作坊里每个人都佩戴姓名牌。

> She wrote her first name on the blank nametag.

她在空白姓名牌上写了自己的名字。

**别混淆**

nametag 主要给现场的人认身份，username 用于系统账号；现场胸牌可以印昵称，但不必就是登录名。

<a id="w-14"></a>

### 11. nickname — 昵称、绰号、别名；给……起绰号

**音标**：/ˈnɪkneɪm/

**先抓住这个画面**

正式名字之外，大家又给你一个常叫的名字。这个额外的叫法可能亲昵，也可能带取笑意味，就是 nickname。

**怎么拆**

历史上 eke 表示增加，eke name 是额外的名字。an eke name 被重新听成 a neke name，冠词的 n 进了后面的词，逐渐形成 nickname；现代可整体作动词。

**怎么变成今天的意思**

**古英语增加词 → 中古英语 eke name**  
额外增加的名字

↓

**an eke name → a neke name → nickname**  
n 从冠词一侧重新划入名词

↓

**名词 nickname → 动词 nickname**  
别名 → 给人或事物起别名

have a nickname 有绰号；go by a nickname 用昵称；give someone a nickname 给某人起绰号；nickname someone ... 给某人起名为……。

**常见搭配与例句**

a childhood nickname；be known by a nickname。

> Most of her friends know her by her nickname.

她的大多数朋友都用昵称称呼她。

> The team nicknamed their old van Rocket.

队员们给那辆旧面包车起了个绰号，叫“火箭”。

**别混淆**

nickname 比 name 多一个额外叫法的角度；不保证友好。pen name 是笔名，screen name 是网络或屏幕显示名，范围各有侧重。

<a id="w-15"></a>

### 12. nicknamed — 给……起了绰号；被昵称为……；nickname 的过去式、过去分词

**音标**：/ˈnɪkneɪmd/

**先抓住这个画面**

先有一个额外的叫法，再说大家已经这么叫了：nicknamed。常见被动句把绰号直接接在后面。

**怎么拆**

nickname 去末尾 e，加完整 -ed；词末 /m/ 后的 -ed 读 /d/。动词来自额外名字的名词 nickname，过去形式保留这一给出称呼的意思。

**怎么变成今天的意思**

**额外名字 → nickname**  
正式名称以外的叫法；也作动词

↓

**nickname 去 e + -ed → nicknamed**  
起了绰号；被起了绰号

be nicknamed ... 被昵称为……；a player nicknamed ... 一位绰号叫……的球员；nicknamed after something 因某物的名字、特点而得到绰号。

**常见搭配与例句**

a town nicknamed ...；they nicknamed him ...。

> Her classmates nicknamed her Sunny because she was always cheerful.

同学们给她起了个绰号叫 Sunny，因为她总是很开朗。

> The tiny office was nicknamed the Cupboard.

那间很小的办公室被戏称为“小橱柜”。

**别混淆**

be nicknamed 可以直接接具体称呼；这个结构强调叫法，不等于正式改名的 be renamed。

<a id="w-3"></a>

### 13. username — 用户名；账号标识名

**音标**：英 /ˈjuːzəneɪm/；美 /ˈjuːzərneɪm/

**先抓住这个画面**

系统里用这个名称认出某个账号，它未必等于现实姓名。

**怎么拆**

user + name，user 是 use + -er；user 的 s 常读 /z/。前半限定这个 name 用于识别用户身份。

**怎么变成今天的意思**

**英语 user〔use + -er〕；name**  
并列组合的两部分

↓

**user〔use + -er〕 + name → username**  
系统识别用户账号的名称

choose a username 是选用户名，enter your username 是输入账号标识。是否能用邮箱、是否公开显示，取决于系统，不由词名保证。

**常见搭配与例句**

choose a username；enter a username；a username field。

> Choose a username that you can remember.

选一个你记得住的用户名。

> The username appears beside each comment.

用户名显示在每条评论旁。

**别混淆**

username 识别账号，display name 是展示名称，real name 是现实姓名；有的平台可以三者相同，也可不同。

<a id="w-19"></a>

### 14. usernames — 用户名、账户标识名〔复数〕

**音标**：英 /ˈjuːzəneɪmz/；美 /ˈjuːzərneɪmz/

**先抓住这个画面**

系统用来分清不同账户的名称，是 usernames；不一定是使用者的真实姓名。

**怎么拆**

use 去 e + -er → user，user + name → username，再加 -s，/m/ 后读 /z/。

**怎么变成今天的意思**

**user + name → username**  
用于识别账户的名称

↓

**username + -s → usernames**  
多个账户名称

choose usernames 选择用户名；a list of usernames 用户名列表。

**常见搭配与例句**

different usernames 不同用户名；usernames beside comments 评论旁的用户名。

> The students chose different usernames.

学生们选择了不同的用户名。

> The report listed usernames rather than real names.

报告列的是用户名，而不是真实姓名。

**别混淆**

username 侧重账户识别，display name 侧重展示；两者是否一样，由具体系统决定。

<a id="w-4"></a>

### 15. surname — 姓；家族名；别号〔历史义〕

**音标**：英 /ˈsɜːneɪm/；美 /ˈsɜːrneɪm/

**先抓住这个画面**

在个人名字之外，再加一个能指出家族或身份的名字；现代通常说姓氏。

**怎么拆**

拉丁 supernomen / supranomen“附加名”→ 法语 surnom / surnoun；英语借入后把后半部分对应为本族 name，属于部分仿译。sur- 接 super。

**怎么变成今天的意思**

**拉丁 super**  
在上方、超过、越过

↓

**后期拉丁 super- + nomen → supernomen / supranomen**  
额外 + 名字 → 附加名

↓

**古法语 surnom / surnoun → 中古英语 surname**  
附加名；英语后部采用 name

↓

**英语 surname**  
通常指家族姓氏

表格上 surname 与 given name 对照。不同文化的姓氏位置不同，所以不能从这个词推断姓一定写在最后。

**常见搭配与例句**

surname and given name；change one’s surname；a family surname。

> Please enter your surname exactly as it appears on your passport.

请按护照上的写法填写姓氏。

> In this list, the surname is written before the given name.

这份名单把姓写在名字前面。

**别混淆**

last name 在英语习惯里常指姓，但 surname 更不依赖排列位置。

<a id="w-5"></a>

### 16. rename — 重新命名；改名

**音标**：/ˌriːˈneɪm/

**先抓住这个画面**

对象还是那个对象，贴在它上面的称呼换了。

**怎么拆**

re-（再、重新）+ name，末尾 e 保留。rename 不自动意味着实物、内容也改变。

**怎么变成今天的意思**

**古英语 nama / noma → 中古英语 name**  
姓名、名称

↓

**英语 name**  
名称；名声；命名、指名

↓

**re- + name → rename**  
给予一个新名称

rename a file 是重命名文件，rename a street 是给街道改名；rename A as B 或 rename A B 按具体结构使用。

**常见搭配与例句**

rename a file；rename a street；rename something after someone。

> Please rename the file before sending it.

发送前请给文件改个名字。

> The school renamed the library after its founder.

学校把图书馆改为以创办人命名。

**别混淆**

rename 改名称，replace 换对象；文件改名并不一定替换里面内容。

<a id="w-8"></a>

### 17. filename — 文件名

**音标**：/ˈfaɪlneɪm/

**先抓住这个画面**

给文件贴一个可识别的名字，让人和程序能找到它。

**怎么拆**

file“文件” + name“名字”的现代英语合成词；file 沿文档一支接拉丁 fīlum，name 是另一个日耳曼来源成分。

**怎么变成今天的意思**

**拉丁 fīlum**  
线、细丝

↓

**古法语 fil → filer；法语 file**  
线 → 用线串起文件；一串、行列

↓

**英语 file：文件、归档、纵列**  
成串保存的文书 → 一组记录 → 计算机文件；人排成一列

↓

**英语 file + name → filename**  
文件 + 名字 → 文件名

a descriptive filename 能提示文件内容；filename extension 是文件名里的扩展名部分。改名字通常不等于改变文件内部格式，不能把 photo.jpg 改成 photo.pdf 就当作完成转换。

**常见搭配与例句**

a descriptive filename；enter a filename；change the filename；a filename extension。

> Use a descriptive filename so that you can find the report later.

用一个能说明内容的文件名，方便以后找到报告。

> The two folders contain files with the same filename.

这两个文件夹里有同名文件。

**别混淆**

filename 说名称；file path 还包括它所在的位置。同名文件可以在不同文件夹里出现。

<a id="w-20"></a>

### 18. filenames — 文件名〔复数〕

**音标**：/ˈfaɪlneɪmz/

**先抓住这个画面**

给每个文件起一个能认出的名字，多份文件的这些名称就是 filenames。

**怎么拆**

file + name → filename，整词加 -s，/m/ 后读 /z/。file 的文档来源经法语接拉丁 filum 线、串列。

**怎么变成今天的意思**

**file + name → filename**  
文档、数字文件的标识名

↓

**filename + -s → filenames**  
多个文件名

descriptive filenames 能说明内容的文件名；a list of filenames 文件名列表。

**常见搭配与例句**

change filenames 改文件名；duplicate filenames 重复文件名。

> The filenames included the date of each meeting.

文件名里包含每次会议的日期。

> She copied the filenames into a spreadsheet.

她把文件名复制进电子表格。

**别混淆**

文件名相同不一定是同一文件；它们可能在不同位置，位置由路径进一步说明。

<a id="w-9"></a>

### 19. codename — 代号；给……起代号

**音标**：英 /ˈkəʊdneɪm/；美 /ˈkoʊdneɪm/

**先抓住这个画面**

不直接说真实名称，用另一个约定称呼来指某个计划、人物或产品。

**怎么拆**

code（约定代号）+ name，可作名词、动词；code 在此不一定是程序源代码。

**怎么变成今天的意思**

**英语 code；name**  
并列组合的两部分

↓

**code + name → codename**  
替代真实名称的约定称呼

a project codename 是项目代号，codenamed Aurora 是代号为 Aurora。可能用于保密，也可能仅是开发期间临时命名。

**常见搭配与例句**

a project codename；under the codename；codenamed ...。

> The project was developed under the codename Aurora.

项目以 Aurora 为代号开发。

> Each team used a different codename during the exercise.

演练中每组使用不同代号。

**别混淆**

codename 常指约定使用的别名，nickname 常是个人绰号；代号不一定带亲昵、戏谑意味。

<a id="w-13"></a>

### 20. hostname — 主机名

**音标**：英 /ˈhəʊstneɪm/；美 /ˈhoʊstneɪm/

**先抓住这个画面**

网络里也要给设备一个可识别的名字，方便在系统中区分、引用。

**怎么拆**

host（网络主机）+ name，host 不是聚会主人这一义项。具体是简短主机名还是完整限定名，要看系统约定。

**怎么变成今天的意思**

**英语 host〔网络主机〕；name**  
并列组合的两部分

↓

**host〔网络主机〕 + name → hostname**  
网络主机的标识名称

set a hostname 是设置主机名，a server hostname 是服务器主机名。名字和 IP 地址不同，名称解析等机制把它们联系起来。

**常见搭配与例句**

a server hostname；set the hostname；resolve a hostname。

> The administrator changed the server’s hostname.

管理员修改了服务器主机名。

> The log records the hostname of the connecting machine.

日志记录了接入机器的主机名。

**别混淆**

hostname 指设备、服务定位中的主机名称，username 指用户账号；登录一台机器时两者都可能出现，不能把用户和机器混为一体。

## 这一组要分清什么

namely 具体指明，不只是举例；namesake 同名不一定同姓。username 用户、hostname 主机、filename 文件，前半先定对象。

The nametag showed her name, but the username on the screen was a nickname.

胸牌上是她的姓名，屏幕上的用户名却是昵称。
