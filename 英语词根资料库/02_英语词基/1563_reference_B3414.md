# 1563 · reference — 参考；提及；所指

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

reference 经法语和相关拉丁形式联系 referre 带回、转交。referential 表示涉及指称或参照的，尤其见于语言学和技术描述。

**REFERENCE：把读者或注意力指向别处**

可以指向一本文献、一个前文段落，或话语中某个对象。

- **指向与参照**：reference
- **相关属性**：referential

## 词形与演化规律

reference 可作名词或动词；referential 不是 referee 裁判的形容词。现代可用 refer 与 -ence 联想，但借入链要保留。

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. reference — 提及；参照、引用；参考资料；推荐证明；引用、提及

**音标**：英、美 /ˈrefrəns/

**先抓住这个画面**

在这里留一根线，让人能顺着它找到另一份信息或另一个可靠的人。

**怎么拆**

现代可拆 refer + -ence；历史有英语内部派生与法语 référence 借入两种分析。法语支线常上溯中世纪拉丁 *referentia，部分词源资料把它标为重构；动词 reference 后来由名词转用。

**怎么变成今天的意思**

**拉丁语：ferre；第一人称 ferō**  
带、承载；承受；生出

↓

**拉丁语：re- + ferre → referre**  
带回；报告；提交处理

↓

**两种分析：英语 refer 加名词后缀；或法语 référence 借入**  
法语支线常追到中世纪拉丁 \*referentia；此形式在部分词源资料中标为重构

↓

**英语：reference**  
提及；参照、引用；推荐证明

for reference 是留供查阅；a reference to something 是提到它；论文 references 列出依据。求职中的 reference 是对能力、人品的说明，也可指提供说明的人。

**常见搭配与例句**

for future reference；a reference book；a list of references；provide a reference。

> Keep this email for future reference.

保留这封邮件，方便以后查阅。

> The article includes references to three earlier studies.

文章引用了三项较早的研究。

> My former supervisor agreed to write a reference for me.

我以前的主管同意为我写推荐证明。

**别混淆**

quotation 是原话引用；reference 可以只指明出处，不必抄出原句。

<a id="w-2"></a>

### 2. referential — 指称的；涉及参照或引用的

**音标**：英、美 /ˌrefəˈrenʃəl/

**先抓住这个画面**

一个词、符号或记录，能把人引向它所对应的另一个对象。

**怎么拆**

reference + -ial，名词词尾改成 -ential 的形容词形式。

**怎么变成今天的意思**

**拉丁语：ferre；第一人称 ferō**  
带、承载；承受；生出

↓

**拉丁语：re- + ferre → referre**  
带回；报告；提交处理

↓

**两种分析：英语 refer 加名词后缀；或法语 référence 借入**  
法语支线常追到中世纪拉丁 \*referentia；此形式在部分词源资料中标为重构

↓

**英语：reference**  
提及；参照、引用；推荐证明

↓

**英语：reference → referential**  
具有指称或参照作用的

referential meaning 着眼于表达指向什么。数据库中的 referential integrity 要求相关引用保持有效，如订单引用的客户确实存在。

**常见搭配与例句**

referential meaning；referential expression；referential integrity。

> The essay examines the referential meaning of the phrase.

这篇文章讨论该短语的指称意义。

> Deleting that customer would break referential integrity.

删除那个客户会破坏引用完整性。

**别混淆**

referential 说是否在指向某物；reverential 是恭敬的，拼写与来源都不同。

## 这一组要分清什么

reference 不只指参考文献，也可指推荐人、提及或指称；翻译要看完整搭配。
