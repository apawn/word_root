# 2526 · starter — 开始动作的执行者、器具，前项再限定对象

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

starter 可说启动器、开场项目等；加 fire 后聚焦火的开始。前项限定了动作对象，词尾仍可命名人物或工具。

**STARTER：让某件事开始，可能是人也可能是东西**

starter → firestarter。

- **启动角色与引火复合**：starter · firestarter
- **start + -er → starters**：starters

## 词形与演化规律

start + -er → starter；fire + starter → firestarter。

starter 是使事情开始的人或物，现代 -s。发令员、启动装置、首发队员、前菜与 for starters 的用法分别看场景。

## 逐词讲解

<a id="w-1"></a>

### 1. starter — 起动装置；开胃菜〔尤英式〕；起步者、先发者

**音标**：英 /ˈstɑːtə/；美 /ˈstɑːrtər/

**先抓住这个画面**

先让后面的事情开起来：先吃的一道菜、让发动机起动的部件、首先出场的人。

**怎么拆**

start + -er，-er 可表人或用具。不同义项都抓开始的角色，不等于只有刚学英语的新手。

**怎么变成今天的意思**

**古英语 styrtan → 中古英语 sterten**  
突然跃起、冲出

↓

**英语 start**  
惊动、突然一动；开始、启动

↓

**start + -er → starter**  
开启某过程的人、物或先行部分

a starter motor 是起动机，have soup as a starter 是拿汤作前菜；a slow starter 可说起步慢的人。体育的 starter 可指发令者或先发选手，要看具体句子。

**常见搭配与例句**

a starter motor；a starter course；a slow starter；a conversation starter。

> We had soup as a starter.

我们先喝汤当开胃菜。

> The mechanic checked the starter motor.

修理工检查了起动机。

**别混淆**

starter 前菜与 dessert 甜点分处餐程前后；starter motor 起动发动机，不是整台发动机本身。

<a id="w-3"></a>

### 2. starters — 前菜；首发队员；启动者、启动装置〔复数〕

**音标**：英 /ˈstɑːtəz/；美 /ˈstɑːrtɚz/

**先抓住这个画面**

让一段事情开始的人、东西，是 starter。餐前第一道菜开启一餐，首发队员开始比赛，启动器让机器开始运转，都是不同场景的开始。

**怎么拆**

start + 完整 -er → starter，再加 -s → starters。starter 在英语中形成，较早就说使事情开始的人或物，后来各行业分别发展具体意义。

**怎么变成今天的意思**

**英语 start + -er → starter**  
以开始动作命名发起者、触发物

↓

**运动、机械、餐饮等意义扩大 → starters**  
现代复数要跟比赛、机器、菜单等对象一起看

starters and main courses 是前菜与主菜；team starters 是球队首发队员；for starters 是首先、先说一条。

**常见搭配与例句**

starters and main courses；team starters；for starters。

> We shared two starters before the main course.

吃主菜前，我们分着吃了两道前菜。

> For starters, we need a clearer plan.

首先，我们需要一个更清楚的计划。

**别混淆**

for starters 是口语里的首先，不一定说食物。菜单上的 starters 常是前菜，运动报道里的 starters 则是开场上阵的队员。

<a id="w-2"></a>

### 3. firestarter — 引火用品、点火工具；引起火的人

**音标**：英 /ˈfaɪəstɑːtə/；美 /ˈfaɪərstɑːrtər/

**先抓住这个画面**

start 让事情开始，firestarter 特别说让火开始的人或用品。露营装备名、人物评价要从对象和场景选择。

**怎么拆**

fire 火 + starter 启动者、启动用品，复合名词。既可人物，也可工具、材料，不限定某一种结构。

**怎么变成今天的意思**

**start 开始 + -er → starter**  
启动者、启动器；开场项目

↓

**fire + starter → firestarter**  
让火燃起的人、助燃引火用品

a camping firestarter 露营引火用品，a firestarter in a story 故事中引起火的人。

**常见搭配与例句**

a camping firestarter；a firestarter kit。

> The shop displayed several types of camping firestarter.

店里展示了几类露营引火用品。

> The novel reveals the identity of the firestarter in its final chapter.

小说最后一章揭示了引起火的人的身份。

**别混淆**

firestarter 单词本身不说明点火是否合法、出于什么目的；工具与人物两种义要看上下文。

## 这一组要分清什么

starter 不只人物名；firestarter 的具体工具结构与用途看场景。
