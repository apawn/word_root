# 0402 · issue — 议题、问题、一期刊物；签发与发布

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

issue 经法语接拉丁向外走、流出词族；议题分支由争讼待定点等历史展开。不要为一个中文问题忽略出版、行政这些高频场景。

**ISSUE：现代场景先分，词源再接向外发出**

a key issue 是议题，the latest issue 是最新一期；issue a warning 是发布，issuer 和 issuance 只从发出这支继续扩展。

- **基础多义及发行派生**：issue · issuance · issuer · reissue
- **issue → issues：议题、问题、刊物期次；发出**：issue · issues
- **issue → issued：向外发出、签发与发行**：issue · issued
- **向外走 → issue → issuing**：issuing

## 词形与演化规律

issue → issuance 动作、issuer 主体；re- 重新 → reissue。

issue 接拉丁 exire 向外走的法语路线；议题义经过争点等历史发展，不把所有义逐字译成出口。

向外走的早期词族，经发出用于票据、文件、声明与出版物。

issue 远接拉丁 ex- 向外 + ire 去，经法语流出、出口的材料进入英语。现代去末尾 e 加 -ing，保留 u；发放、发布、流出用法各自说明。

## 逐词讲解

<a id="w-1"></a>

### 1. issue — 议题；问题；一期刊物；签发、发布、发放

**音标**：/ˈɪʃuː/；英式也 /ˈɪsjuː/

**先抓住这个画面**

会议上是大家要处理的一件事；杂志架上是一期刊物；机构做动作时则是把文件、物品正式发出去。

**怎么拆**

经法语来自拉丁 exīre，ex- 向外 + īre 走。发出、发行较易连到向外；议题义则有诉讼中待裁定争点等历史，不把今天所有问题都直译出口。

**怎么变成今天的意思**

**拉丁 exīre → 法语 issir、issue → 英语 issue**  
向外走、流出、出口；后有结果等义

↓

**英语 issue 的不同分支**  
发出、签发及发行物；争讼待定点发展成议题、问题

a key issue 关键议题，an issue with the printer 打印机的问题；the latest issue of a magazine 最新一期杂志；issue a warning 发布警告，issue passports 签发护照。

**常见搭配与例句**

a key issue；the latest issue；issue a statement；take issue with。

> We need to discuss the main issue first.

我们得先讨论主要问题。

> The next issue of the magazine comes out on Monday.

杂志下一期周一出版。

> The office issued a statement that afternoon.

办公室当天下午发布了一份声明。

**别混淆**

issue 可中性说待讨论事项，不一定是故障；take issue with 反对、不认同，不是从对方手里拿走一本杂志。

<a id="w-5"></a>

### 2. issues — 议题、问题；刊物期次；发出、签发、发行〔issue 的第三人称单数〕

**音标**：英 /ˈɪʃuːz, ˈɪsjuːz/；美 /ˈɪʃuːz/

**先抓住这个画面**

会议里要讨论的事是 issues，杂志按期发出的几本也叫 issues。作动词时，则说某机构把通知、证件或刊物发出来。

**怎么拆**

issue + -s，元音后读 /z/。issue 经法语接拉丁 exire 向外走；发出、发行物与向外较好联系，议题义另经历待解决争点等语义发展。

**怎么变成今天的意思**

**拉丁 exire → 法语 issir／issue → 英语 issue**  
向外走、结果；发出、发行等

↓

**issue 名词、动词 + -s → issues**  
多个议题、问题、期次；单数主语发出

technical issues 技术问题；social issues 社会议题；back issues 过刊；issues a notice 发通知；issues tickets 出票。

**常见搭配与例句**

discuss the issues；three issues of the magazine。

> We discussed the main issues before choosing a plan.

选方案前，我们讨论了几个主要问题。

> The library keeps the last twelve issues of the magazine.

图书馆保存这本杂志最近十二期。

**别混淆**

issues 有时是待讨论的议题，不一定已是严重故障。problem 更直接说需要解决的困难；magazine issues 则是期刊的期次，不能只认问题这一义。

<a id="w-6"></a>

### 3. issued — 发出、签发了；发行了；流出；issue 的过去式和过去分词

**音标**：英 /ˈɪʃuːd, ˈɪsjuːd/；美 /ˈɪʃuːd/

**先抓住这个画面**

把文件、声明、票据正式向外发出去，是 issued；报刊、货币等发行，或水、声音流出，也属于这个向外的分支。

**怎么拆**

issue 末尾已有 e，加 -d，元音后读 /d/。issue 经法语 issir、issue 接拉丁 exīre，ex- 向外与 īre 走组成；动词发出、发行与向外的早期画面相连。

**怎么变成今天的意思**

**拉丁 ex- + īre → exīre → 法语、英语 issue**  
向外走、流出 → 发出、签发

↓

**issue 去 e + -ed → issued**  
过去发出、签发、发行

issued a statement 发表声明；issued tickets 签发、发售票券；issued a warning 发出警告；water issued from ... 水从……流出〔较正式〕。

**常见搭配与例句**

was issued yesterday；issued to all members。

> The museum issued new tickets for the evening event.

博物馆为晚间活动发放了新票。

> The office issued a short statement after the meeting.

办公室在会后发表了一份简短声明。

**别混淆**

issue 作名词可以是议题、问题，但 issued the tickets 中是发出票券的动词。issued to 交代发给谁，issued by 交代由谁签发。

<a id="w-7"></a>

### 4. issuing — 发布；发放；流出〔分词、动名词〕

**音标**：英、美 /ˈɪʃuːɪŋ/；亦 /ˈɪsjuːɪŋ/

**先抓住这个画面**

让东西从里面走出去，是 issue 的旧画面。通知发出去、票证发给人，都可以是 issuing；烟从门缝冒出来，也可以用这个词。

**怎么拆**

issue 去末尾 e，加完整 -ing → issuing，保留 u。远接拉丁 ex- 向外 + ire 去 → exire，经法语 issir、issue 等流出、出口词族进入英语。

**怎么变成今天的意思**

**拉丁 exire 向外走 → 法语 issir、issue → 英语 issue**  
较早有出来、流出等意思

↓

**issue 的发布、发放与流出义 + -ing → issuing**  
现代动词动作，不按名词问题来套意思

issuing tickets 是发票、出票；issuing a statement 是发表声明；smoke issuing from... 是烟从……冒出。

**常见搭配与例句**

issuing tickets；issuing a statement；issuing from。

> The office is issuing tickets for the concert.

办公室正在发放音乐会门票。

> Smoke was issuing from the old chimney.

烟正从旧烟囱里冒出来。

**别混淆**

issuing 主要是动词。an issue 是一个问题、一期刊物等，issuing a statement 却是发布声明，句法不同。

<a id="w-2"></a>

### 5. issuance — 签发；发行；正式发放〔书面〕

**音标**：/ˈɪʃuːəns/；亦 /ˈɪʃjuəns/

**先抓住这个画面**

不讲谁拿到手，而是把文件、证券、许可等正式发出去这一动作。

**怎么拆**

issue 发出、签发 + -ance 成动作名词，去末尾 e。较正式，常在机构、行政、金融文件出现。

**怎么变成今天的意思**

**拉丁 exīre → 法语 issir、issue → 英语 issue**  
向外走、流出、出口；后有结果等义

↓

**英语 issue 的不同分支**  
发出、签发及发行物；争讼待定点发展成议题、问题

↓

**issue + -ance → issuance**  
签发、发行 → 相应动作、过程名词

the issuance of a permit 许可证签发，bond issuance 债券发行；日常口语许多时候直接用 issuing 更自然。

**常见搭配与例句**

the issuance of；permit issuance；bond issuance。

> The office confirmed the issuance of the new permit.

办公室确认了新许可证已经签发。

> The report describes the process of bond issuance.

报告介绍了债券发行过程。

**别混淆**

issuance 是动作，issuer 是执行者；不是每个 issue 议题都变成 issuance，后者主要取发出、发行分支。

<a id="w-3"></a>

### 6. issuer — 发行者；签发机构、发卡机构

**音标**：英 /ˈɪʃuːə/；美 /ˈɪʃuːər/

**先抓住这个画面**

文件、卡、证券是谁正式发出来的，就把那个主体叫 issuer。

**怎么拆**

issue 发出、发行 + -er 执行者，去 e。主体常是机构，不因 -er 就必须是某个自然人。

**怎么变成今天的意思**

**拉丁 exīre → 法语 issir、issue → 英语 issue**  
向外走、流出、出口；后有结果等义

↓

**英语 issue 的不同分支**  
发出、签发及发行物；争讼待定点发展成议题、问题

↓

**issue + -er → issuer**  
发出、签发 → 发行、签发主体

a card issuer 发卡机构，a bond issuer 债券发行人、发行机构；the issuer of a certificate 证书签发者。

**常见搭配与例句**

a card issuer；a bond issuer；the issuer of the certificate。

> Contact the card issuer if the card is lost.

卡遗失时，请联系发卡机构。

> The document names the issuer of the certificate.

文件写明了证书签发者。

**别混淆**

issuer 发出的主体，holder 持有人，recipient 接收者；持卡人不是发卡机构。

<a id="w-4"></a>

### 7. reissue — 重新发行；重新签发；再版、重发物

**音标**：/ˌriːˈɪʃuː/；名词也重读 re-

**先抓住这个画面**

以前已经发过，现在再正式发一回，可能是旧作品再版，也可能是证件替换重发。

**怎么拆**

re- 重新 + issue 发出、发行，兼有动词和名词。重发可能改内容、改格式，也可能仅重新提供，不由前缀保证一定修订。

**怎么变成今天的意思**

**拉丁 exīre → 法语 issir、issue → 英语 issue**  
向外走、流出、出口；后有结果等义

↓

**英语 issue 的不同分支**  
发出、签发及发行物；争讼待定点发展成议题、问题

↓

**re- + issue → reissue**  
发行、签发 → 再次发行、签发；重发版本

reissue an album 重新发行专辑，reissue a ticket 重新出票；a reissue of the book 这本书的再版。

**常见搭配与例句**

reissue an album；reissue a ticket；a reissue of；a reissued edition。

> The publisher reissued the novel with a new cover.

出版社换了封面，重新发行了这部小说。

> The airline reissued the ticket after the name was corrected.

姓名改正后，航空公司重新签发了机票。

**别混淆**

reissue 重新发行、签发，revise 修订，reprint 重印；一份 reissue 是否改过正文要看具体版本。

## 这一组要分清什么

issue 议题不一定故障；issuance 动作、issuer 主体；reissue 重发不保证修订。

## 串起来练习

The latest issue explains why the issuer decided to reissue the document.

最新一期说明了签发机构为什么决定重新签发文件。
