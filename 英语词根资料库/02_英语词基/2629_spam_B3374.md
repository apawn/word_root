# 2629 · spam — 反复塞进来的内容，连接刷屏行为与执行者

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

品牌名经过喜剧中的重复唱喊，进入网络信息泛滥的比喻。-er 指发送者，-y 形容带着这种令人烦扰的特征。

**SPAM：你没想看，它却一遍遍占住位置**

spam → spammer、spammy。

- **内容、行为、人物及性质**：spam · spammer · spammy
- **spam → spammed、spamming；spammer → spammers**：spam · spammed · spamming · spammer · spammers

## 词形与演化规律

SPAM 品牌 → 喜剧重复场景 → spam 网络义；双写 m + -er、-y。

网络 spam 名称与 Monty Python 短剧中反复喊 Spam 淹没对话的形象有关，再用于垃圾消息、刷屏。spammed、spamming 双写 m 接完整后缀，spammer 加 -er 指发送者，再加 s。

## 逐词讲解

<a id="w-1"></a>

### 1. spam — 垃圾信息、垃圾邮件；刷屏、滥发消息；罐装午餐肉品牌相关称呼

**音标**：/spæm/

**先抓住这个画面**

你没要求，对方却把同样内容一遍遍塞进来，就是 spam 的网络画面。它从罐装肉品牌，经过喜剧里反复唱喊同一词的场景，变成信息泛滥的比喻。

**怎么拆**

原为 SPAM 品牌名，确切命名含义未公开确定；spiced ham 的拆法只是常见说法。网络义联系 Monty Python 喜剧中不断重复品牌名的桥段。

**怎么变成今天的意思**

**SPAM 罐装肉品牌名**  
品牌名称的确切含义未公开确定，spiced ham 等是常见解释

↓

**喜剧中反复喊 SPAM → 网络反复塞入内容的比喻**  
spam 垃圾信息、刷屏；再生 spammer、spammy

a spam filter 垃圾信息过滤器，the spam folder 垃圾邮件文件夹，spam a chat 在聊天里刷屏；名词垃圾邮件通常不可数。

**常见搭配与例句**

a spam filter；spam messages；stop spamming。

> The filter moved the message to the spam folder.

过滤器把消息移进了垃圾邮件文件夹。

> Please stop spamming the chat with the same link.

请别再在聊天里反复刷同一个链接。

**别混淆**

spam 不限电子邮件，也包括评论、即时消息等；收到的普通广告是否构成 spam，要看未经请求、大量或重复等语境。

<a id="w-4"></a>

### 2. spamming — 发送垃圾消息；刷屏

**音标**：英、美 /ˈspæmɪŋ/

**先抓住这个画面**

不断重复发消息，把别人的正常讨论顶走，是 spamming。它把垃圾消息的名词变成正在发生的动作。

**怎么拆**

spam 双写 m + -ing → spamming；可作现在分词、动名词。这个 m 是按现代拼写规则双写，不是原品牌名里藏着两个 m。

**怎么变成今天的意思**

**Spam 肉类罐头品牌 → 短剧中反复出现、淹没对话的词**  
网络用法借这种不请自来、铺天盖地的形象

↓

**spam 垃圾消息 → spam 动词大量发送、刷屏**  
动词变化、行为名词和发送者称呼继续形成

↓

**spam 双写 m + -ing → spamming**  
发垃圾消息、刷屏的动作形式

stop spamming 是停止刷屏；spamming the chat 是往聊天里刷消息；spamming links 是反复发链接。

**常见搭配与例句**

stop spamming；spamming the chat；spamming links。

> The moderator asked him to stop spamming the chat.

管理员让他停止在聊天里刷屏。

> The rules prohibit spamming links in the comments.

规则禁止在评论区刷链接。

**别混淆**

发很多有必要、被期待的消息不自动都叫 spamming；这个词通常包含不受欢迎、重复干扰的判断。

<a id="w-6"></a>

### 3. spammed — 群发了垃圾消息；被垃圾消息、刷屏内容淹没了

**音标**：英、美 /spæmd/

**先抓住这个画面**

同样的广告一遍遍塞进邮箱、讨论区，可以说被 spammed 了。重点是别人没要求，却被大量重复内容打扰。

**怎么拆**

spam 双写 m + -ed → spammed，/m/ 后后缀读 /d/；动词接网络垃圾消息名词，名字背后有短剧反复喊 Spam 淹没对话的形象。

**怎么变成今天的意思**

**Spam 肉类罐头品牌 → 短剧中反复出现、淹没对话的词**  
网络用法借这种不请自来、铺天盖地的形象

↓

**spam 垃圾消息 → spam 动词大量发送、刷屏**  
动词变化、行为名词和发送者称呼继续形成

↓

**spam 双写 m + -ed → spammed**  
规则过去式、过去分词；词尾 /md/

spammed with adverts 是被广告刷屏；spammed the forum 是给论坛发垃圾内容；users were spammed 是用户收到大量垃圾消息。

**常见搭配与例句**

spammed with adverts；spammed the forum；spammed with links。

> The forum was spammed with identical adverts.

论坛被一模一样的广告刷屏了。

> My inbox was spammed with unwanted offers.

我的收件箱被不想要的促销消息塞满了。

**别混淆**

emailed 只说发了邮件；spammed 还表明内容不请自来、数量多或重复，常带批评。

<a id="w-2"></a>

### 4. spammer — 垃圾信息发送者、刷屏者

**音标**：英 /ˈspæmə/；美 /ˈspæmər/

**先抓住这个画面**

spam 是滥发内容，spammer 就是做这件事的人或账号。-er 从动作推出执行者，未必是对方真实姓名。

**怎么拆**

spam + -er，双写 m。这里接网络滥发义，不接肉制品名。

**怎么变成今天的意思**

**SPAM 罐装肉品牌名**  
品牌名称的确切含义未公开确定，spiced ham 等是常见解释

↓

**spam 滥发信息 + -er → spammer**  
发送垃圾信息、反复刷屏者

block a spammer 屏蔽垃圾信息发送者，identify spammers 识别刷屏者。

**常见搭配与例句**

block a spammer；a persistent spammer。

> The moderator blocked the spammer.

管理员屏蔽了那个刷屏者。

> Several spammers posted identical comments below the article.

几名垃圾信息发送者在文章下发了相同评论。

**别混淆**

spammer 描述发送行为、账号角色；bot 强调自动程序，两者能重叠，但不能互相完全代替。

<a id="w-5"></a>

### 5. spammers — 垃圾消息发送者；刷屏者〔复数〕

**音标**：英 /ˈspæməz/；美 /ˈspæmɚz/

**先抓住这个画面**

不是一条条垃圾消息本身，而是发这些东西的人、账号，就是 spammers。后缀把动作变成“做这事的人”。

**怎么拆**

spam 双写 m + -er → spammer，再加 -s → spammers；名词复数词尾 /z/。发送账号也能被这样称呼，不一定强调屏幕后某个人的身份。

**怎么变成今天的意思**

**Spam 肉类罐头品牌 → 短剧中反复出现、淹没对话的词**  
网络用法借这种不请自来、铺天盖地的形象

↓

**spam 垃圾消息 → spam 动词大量发送、刷屏**  
动词变化、行为名词和发送者称呼继续形成

↓

**spam 双写 m + -er → spammer → spammers**  
-er 发送者，再以 -s 形成复数

block spammers 是屏蔽垃圾消息发送者；spammers in the comments 是评论区刷屏者；accounts used by spammers 是被其使用的账号。

**常见搭配与例句**

block spammers；persistent spammers；spammers in the comments。

> The forum blocks persistent spammers.

论坛会屏蔽反复刷屏的人。

> Spammers had filled the comments with adverts.

垃圾消息发送者把评论区塞满了广告。

**别混淆**

spam 是垃圾内容或刷屏动作，spammers 是发送者；不要把几条垃圾消息数成 three spammers。

<a id="w-3"></a>

### 6. spammy — 像垃圾信息的；广告过多、充斥刷屏内容的

**音标**：/ˈspæmi/

**先抓住这个画面**

一个页面满眼弹窗、重复推销，读着像被广告围住，可以说 spammy。它评价的是带有垃圾信息那种烦扰特征。

**怎么拆**

spam + -y，双写 m；由垃圾信息名词形成带该特征的口语形容词，也有较少见的肉制品相关用法。

**怎么变成今天的意思**

**SPAM 罐装肉品牌名**  
品牌名称的确切含义未公开确定，spiced ham 等是常见解释

↓

**spam 垃圾信息 + -y → spammy**  
像垃圾信息、广告重复过多的

spammy emails 像垃圾信息的邮件，a spammy website 充斥垃圾推广的网站。

**常见搭配与例句**

spammy comments；a spammy message。

> The repeated sales links made the message look spammy.

反复出现的推销链接让消息看起来像垃圾信息。

> She left the site because it felt too spammy.

她觉得网站垃圾推广太多，就离开了。

**别混淆**

spammy 常是印象或评价，不能单凭这个形容词断定内容全部虚假；真正有用的内容也可能被反复推广得很烦。

## 这一组要分清什么

品牌名的拆法未定；网络 spam 不只电子邮件。

## 串起来练习

The spammer filled the page with spammy links, most of which the spam filter removed.

刷屏者把页面塞满垃圾推广式链接，大部分被过滤器清除了。
