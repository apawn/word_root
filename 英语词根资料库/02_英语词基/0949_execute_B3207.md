# 0949 · execute — 把事跟进到底、实际做出

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

从实行看现代分支最清楚：计划、舞蹈动作、程序、刑罚都可能作执行对象。对象决定意思，不要被某个强烈义项盖住整个词。

**EXECUTE：计划不只放在纸上，而是照着做完**

execute 动作 → execution 过程、方式 → executable 能执行的文件或方案。

- **实行与完成**：execute · execution
- **能够执行**：executable
- **execute 与 executive：把事付诸实行**：execute · execution · executive
- **execute → executed：把计划、指令实行到底**：execute · executed
- **executive → executives：负责把事情落实的管理者**：execute · executive · executives

## 词形与演化规律

ex- + sequī → exsequī/exsecūtus → executer → execute；exsecūtiō → execution；execute + -able。

executive 接拉丁执行、完成的词干及 -ivus 形容词材料；行政、企业管理和管理者名词均接实际施行这一条支线。

法语接拉丁 exsequi、exsecutus，原含跟随到底、实行；现代刑罚义单独看宾语。

拉丁执行、跟进到底的词族，行政、企业管理人员义后来发展。

## 逐词讲解

<a id="w-2"></a>

### 1. execute — 执行、完成；表演动作；运行程序；处决

**音标**：/ˈeksɪkjuːt/

**先抓住这个画面**

把定下的步骤真正走完，是 execute 的共同感觉：计划落地、动作做出、程序运行；处决是执行死刑那一支。

**怎么拆**

经法语接拉丁 exsecūtus，属 exsequī 跟随到底、实行，含 ex- + sequī 跟随。词里 cut 只是拼写相似的一段，不是英语切割。

**怎么变成今天的意思**

**拉丁 ex- + sequī → exsequī；分词 exsecūtus**  
跟随到底、把事做完

↓

**法语 executer → 英语 execute**  
执行、实行；执行刑罚等

↓

**现代专门用法**  
完成动作、运行程序；execution 指执行过程或方式

execute a plan 执行计划，execute a turn 完成转身动作，execute a command 运行命令，execute a prisoner 处决囚犯。看宾语才能确定哪一支。

**常见搭配与例句**

execute a plan；execute a maneuver；execute a command；be executed。

> The team executed the plan with great care.

团队非常仔细地落实了计划。

> The interpreter executes the instructions one by one.

解释器逐条执行指令。

**别混淆**

execute 不一律杀死；执行程序和处决人的宾语语境差别很大。execute a document 在法律文本里可指按所需手续签署等，使其正式生效。

<a id="w-4"></a>

### 2. executive — 行政的、执行管理的；管理人员、高管；行政部门

**音标**：/ɪɡˈzekjətɪv/

**先抓住这个画面**

计划写出来，还需要有人决定怎么落地、调动资源做成。executive 把重点放在实际执行、管理的一方。

**怎么拆**

接拉丁 executivus，来自 exequi、exsequi 跟进完成、执行的分词词干；其 ex- 与 sequi 跟随材料相连。行政权用法后来形成企业管理人员、行政部门等名词义。

**怎么变成今天的意思**

**拉丁 exsequi／exequi → executivus**  
跟进、完成 → 执行相关的

↓

**英语 executive**  
行政、执行管理；相应人员或部门

an executive decision 管理者作出的决定；chief executive 首席执行官等；executive summary 给决策者看的概要；a company executive 企业管理人员。

**常见搭配与例句**

executive responsibility；the executive branch。

> She works as an executive at a publishing company.

她在一家出版公司担任管理职务。

> The report begins with a short executive summary.

报告开头有一份简短的决策概要。

**别混淆**

execute 是执行动作，executive 是相关性质或执行管理者。executive summary 不是计划下一步要去执行的摘要，而是供决策者快速掌握重点的概要。

<a id="w-6"></a>

### 3. executives — 高管、管理人员〔复数〕

**音标**：/ɪɡˈzekjətɪvz/

**先抓住这个画面**

负责把决定变成实际行动、带着组织运作的人，就是 executives；现代商业语境常指较高层的管理人员。

**怎么拆**

executive + -s，/v/ 后读 /z/。executive 接拉丁 executivus，与 exequi、exsequi 跟进到底、执行相关；行政义后来发展企业管理人员名词义。

**怎么变成今天的意思**

**拉丁执行词族 → executivus → executive**  
跟进完成 → 执行、行政相关；负责的人

↓

**executive + -s → executives**  
多位企业或组织管理人员

senior executives 高层管理人员；company executives 公司高管。

**常见搭配与例句**

a meeting of executives 管理人员会议；executives from several firms 几家公司的高管。

> The executives discussed the new strategy.

高管们讨论了新策略。

> Several executives visited the factory.

几位管理人员参观了工厂。

**别混淆**

executives 是人；executive 作形容词可说执行、行政相关。executors 常指执行特定职责、尤其遗嘱事务的人，不是普通公司高管的替代词。

<a id="w-1"></a>

### 4. execution — 执行、完成；完成方式、表现；程序运行；处决

**音标**：/ˌeksɪˈkjuːʃən/

**先抓住这个画面**

想法写得好是一回事，真正做出来做得如何，是 execution；节目里说 superb execution，可能是在夸动作完成得漂亮。

**怎么拆**

借法语 execution，接拉丁 exsecūtiō 行为名词，现代对应 execute + -ion，末尾形态与读音变化，不是直接把整个 execute 原样保留。

**怎么变成今天的意思**

**拉丁 ex- + sequī → exsequī；分词 exsecūtus**  
跟随到底、把事做完

↓

**法语 executer → 英语 execute**  
执行、实行；执行刑罚等

↓

**现代专门用法**  
完成动作、运行程序；execution 指执行过程或方式

↓

**拉丁 exsecūtiō → 法语 execution → 英语 execution**  
执行的过程、结果或方式；现代对应 execute + -ion

the execution of a plan 计划执行，flawless execution 完美完成，program execution 程序运行，public execution 公开处决。

**常见搭配与例句**

the execution of a plan；flawless execution；program execution。

> The idea was promising, but the execution was poor.

想法很有希望，但做出来的效果很差。

> The error interrupted program execution.

这个错误中断了程序运行。

**别混淆**

execution 是动作及完成方式，executor 是执行某任务的人或专门法律角色；听到 execution 时必须连同上下文理解，不能默认处决。

<a id="w-5"></a>

### 5. executed — 执行、实施、完成了；处决了〔过去式、过去分词〕

**音标**：/ˈeksɪkjuːtɪd/

**先抓住这个画面**

计划不只停在纸面上，步骤真的照着做完了，就是 executed 的常见画面。执行程序、完成动作也用它；若宾语是受刑的人，才可能是处决义。

**怎么拆**

execute + -d，末尾 /t/ 后读 /ɪd/。execute 经法语接拉丁 exsecutus，属 exsequi 跟随到底、实行，较早含 ex- 与 sequi。

**怎么变成今天的意思**

**拉丁 exsequi、exsecutus → 法语 → execute**  
跟随到底 → 把事实行、做完

↓

**execute 去 e + -ed → executed**  
计划、动作、指令等已被实行；特定语境指执行死刑

a well executed plan 执行得好的计划；executed the command 执行了命令；executed a difficult turn 完成高难度转身。

**常见搭配与例句**

beautifully executed 做得很漂亮；the program was executed 程序运行了。

> The team executed the plan with great care.

团队十分细致地执行了计划。

> The dancer executed a difficult turn smoothly.

舞者流畅地完成了一个高难度转身。

**别混淆**

executed 的宾语决定具体动作；不能看到它就译为处决。execute a plan 与 carry out a plan 常有重叠。

<a id="w-3"></a>

### 6. executable — 可执行的；可执行程序、文件

**音标**：/ˈeksɪkjuːtəbl/；也读 /ˌeksɪˈkjuːtəbl/

**先抓住这个画面**

一般说事情可以实行；电脑上常说一个文件能作为程序启动执行，而不只是供人阅读的一页文字。

**怎么拆**

execute + -able，末尾 e 去掉，-able 表可被执行。名词 executable 从可执行的文件这一形容用法转来，读音、重音有变体。

**怎么变成今天的意思**

**拉丁 ex- + sequī → exsequī；分词 exsecūtus**  
跟随到底、把事做完

↓

**法语 executer → 英语 execute**  
执行、实行；执行刑罚等

↓

**现代专门用法**  
完成动作、运行程序；execution 指执行过程或方式

↓

**execute + -able → executable**  
能够执行的 → 可执行文件、程序

an executable file 可执行文件，an executable program 可运行程序，an executable plan 可实施的计划。文件是否可执行涉及格式、运行环境与权限。

**常见搭配与例句**

an executable file；an executable program；an executable plan。

> The download contains an executable and a user guide.

下载包里有一个可执行程序和一份用户指南。

> The file is executable only in the supported environment.

这个文件只有在支持的环境中才能执行。

**别混淆**

executable 不保证程序安全、正确或在所有系统都能跑；也不只等于文件名后有 .exe，其他系统和文件类型同样可以执行。

## 这一组要分清什么

execute 的 cut 不是英语切割；execution 可夸完成得好；executable 不能推出安全或跨系统通用。

## 串起来练习

Good execution turns a plan into action; an executable turns instructions into a running program.

好的执行把计划落实；可执行程序把指令带进运行。
