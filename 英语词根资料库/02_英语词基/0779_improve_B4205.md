# 0779 · improve — 善加利用、产生收益到改善质量

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

旧法语收益背景，不硬拆 im- + prove；improvement 另有法语名词路径。进阶 improver 以实际课程场景理解。

**IMPROVE：让原有东西发挥得更好**

improve → improvement → improver，把动作、变化、人物或改良物放相邻。

- **改进、进步与进阶者**：improve · improvement · improver
- **improve → improved：使更好与变好**：improve · improved
- **improve → improving：从收益到变好**：improve · improving
- **improve → improvement → improvements：变好与具体改进**：improve · improvement · improvements
- **使有收益 → improve → improves**：improves

## 词形与演化规律

盎格鲁法语 emprouwer、emprouwement；现代 improve + -ment/-er。

收益、善加利用的早期词义发展为提高质量；不是现代 im 加 prove 的否定组合。

盎格鲁法语产生收益的词发展成改善，并受 prove 类拼写影响。

收益词发展成改善，英语 ment 命名改进或过程。

improve 经盎格鲁法语 emprouwer 使获益等，原来与 profit 词族有关，拼写后来受 -prove 类词影响。现代保留 e 加 -s，/v/ 后读 /z/。

## 逐词讲解

<a id="w-1"></a>

### 1. improve — 改进、改善；进步、变好

**音标**：/ɪmˈpruːv/

**先抓住这个画面**

原来的东西还不够好，做些调整后更有用、更有效，或表现上升；自己进步也可不带宾语。

**怎么拆**

接盎格鲁法语 emprouwer，使产生收益的旧意，后发展为使更好。词形后受 prove 等影响，不等于词源是 im- 否定 + prove 证明。

**怎么变成今天的意思**

**盎格鲁法语 emprouwer 等 → 英语 improve**  
使产生收益、善加利用；与 prou 收益相关

↓

**英语 improve**  
提高质量、改善；自己变好，拼写受 prove 等词影响

improve the design 改进设计，improve your English 提高英语，conditions improve 情况改善，improve on a result 取得更好成绩。

**常见搭配与例句**

improve the design；improve your English；improve on；improve steadily。

> The new handle improves the design.

新把手让设计更好了。

> Her English has improved a lot this year.

她的英语今年进步很大。

**别混淆**

improve 及物改进某物、不及物自身变好都可；prove 证明，不是 improve 的相反动作。

<a id="w-4"></a>

### 2. improved — 改进、提高了；改善了；改良的

**音标**：/ɪmˈpruːvd/

**先抓住这个画面**

比原来更好、更能达到目的，是 improved 的共同意思；人可以改进方法，状态也可以自己变好。

**怎么拆**

improve 末尾已有 e，加 -d，/v/ 后读 /d/。improve 接盎格鲁法语 emprouwer 等，使产生收益、善加利用的意义发展为使更好；后来拼写受 prove 等影响。

**怎么变成今天的意思**

**盎格鲁法语收益、善加利用词族 → improve**  
让它有收益、用得好 → 改善

↓

**improve 去 e + -ed → improved**  
已经变好；改进后的

improved the design 改进了设计；skills improved 技能提高了；an improved version 改进版；much improved 好多了。

**常见搭配与例句**

has improved greatly；improved over time。

> The new layout improved the flow of people through the building.

新的布局让楼内人员通行更顺畅了。

> Her pronunciation improved with regular practice.

经过经常练习，她的发音进步了。

**别混淆**

improved something 说使某物更好；something improved 说某物变好了。improved 作形容词可修饰新版、方法，比较的是过去状态或某个基准。

<a id="w-3"></a>

### 3. improvement — 改善、进步；改进之处

**音标**：/ɪmˈpruːvmənt/

**先抓住这个画面**

既可说整体变好的过程，也可数具体改了哪几处。a small improvement 是有进步，不保证已经完美。

**怎么拆**

有盎格鲁法语 emprouwement 的名词来源，现代对应 improve + -ment。保留平行名词借入背景，不把词尾讲成毫无历史的现拼。

**怎么变成今天的意思**

**盎格鲁法语 emprouwer 等 → 英语 improve**  
使产生收益、善加利用；与 prou 收益相关

↓

**盎格鲁法语 emprouwement → improvement**  
使产生收益、改善；现代与 improve + -ment 对照

an improvement in accuracy 准确性提高，an improvement on the old version 比旧版更好，make improvements 作改进。

**常见搭配与例句**

an improvement in；an improvement on；make improvements。

> There has been a clear improvement in her writing.

她的写作有了明显进步。

> The new version includes several small improvements.

新版包含几处小改进。

**别混淆**

improvement 过程或具体变化，improver 人或改良物；有 improvement 仍可能有问题待解决。

<a id="w-6"></a>

### 4. improvements — 改进、改善；提升的地方、改善项目〔复数〕

**音标**：/ɪmˈpruːvmənts/

**先抓住这个画面**

把原来的东西变得更好，能够指出具体改了哪些地方，就是 improvements。可以是设计细节、服务速度，也可以是实际修缮项目。

**怎么拆**

improve + -ment → improvement，保留词尾 e；再加 -s，/t/ 后读 /s/。improve 较早接盎格鲁法语产生收益词，后扩为改善，ment 命名过程或结果。

**怎么变成今天的意思**

**盎格鲁法语收益词 → improve；加 -ment → improvement**  
使产生收益 → 使更好 → 改善或改善结果

↓

**improvement + -s → improvements**  
多项改进、可分别说明的提升

make improvements 作出改进；improvements in service 服务改善；improvements to the building 建筑改造。

**常见搭配与例句**

small improvements 小改进；suggest improvements 提出改进建议。

> The new design includes several small improvements.

新设计包含几项小改进。

> The school made improvements to the library.

学校改善了图书馆设施。

**别混淆**

improvement 泛说改善过程时可不可数；improvements 常把具体措施、结果数出来。improvements in 侧重哪方面变好，to 常接被改的对象。

<a id="w-5"></a>

### 5. improving — 改善、提高；好转〔现在分词、动名词〕

**音标**：/ɪmˈpruːvɪŋ/

**先抓住这个画面**

同一件事比原来更好，是 improving：既可以主动把它改好，也可以说它自己在好转。

**怎么拆**

improve 去 e + -ing → improving。底词接盎格鲁法语 emprouwer 使产生收益，含 en- 与 prou 利益；收益增加的意思后来扩展为品质、状况变好。拼写曾受 -prove 类词影响。

**怎么变成今天的意思**

**盎格鲁法语 emprouwer → improve**  
产生收益、利用 → 改善、变好

↓

**improve 去 e + -ing → improving**  
正在改进某物；某种情况正在好转

improving skills 提高技能；improving the service 改进服务；the weather is improving 天气在好转。

**常见搭配与例句**

improving steadily 稳步提高；ways of improving sleep 改善睡眠的办法。

> Her writing is improving with regular practice.

随着经常练习，她的写作正在进步。

> We are improving the instructions for new users.

我们正在改进给新用户的说明。

**别混淆**

improve 可以有宾语，也可没有：improving the system 是改进系统，the system is improving 是系统正在变好。两种句子中的行动者不同。

<a id="w-7"></a>

### 6. improves — 改善；使变好；进步〔第三人称单数〕

**音标**：英、美 /ɪmˈpruːvz/

**先抓住这个画面**

原来的状态往更好的方向变，是 improves。可以是做某件事使另一件事变好，也可以是它自己在进步。

**怎么拆**

improve 保留末尾 e，加 -s → improves，/v/ 后读 /z/。经盎格鲁法语 emprouwer 使获益、增收益等，远连拉丁 prode 有利；拼写后来受 -prove 类词影响。

**怎么变成今天的意思**

**盎格鲁法语获益、使有收益的词族 → improve**  
早期常联系利用资源、增加收益

↓

**使获益 → 提高质量、变好；加 -s → improves**  
现代改善状态与自身进步两种句法

improves the design 是改进设计；improves with practice 是练习后进步；improves the view 是改善视野、景观。

**常见搭配与例句**

improves the design；improves with practice；improves over time。

> The new window improves the view from the room.

新窗户改善了房间的视野。

> Her handwriting improves with practice.

她的字随着练习不断进步。

**别混淆**

improve 的早期获益义后来扩大为质量变好。improves 可以直接带宾语，也可以让正在变好的事物作主语。

<a id="w-2"></a>

### 7. improver — 进阶学习者；改进者、改良材料

**音标**：英 /ɪmˈpruːvə/；美 /ɪmˈpruːvər/

**先抓住这个画面**

比刚开始多学了一些、还在继续进步的人，在课程分组里可叫 improver；某些材料则以改善效果得名。

**怎么拆**

improve + -er，人或改善用物名称。即兴表演 improv 的人物词也可能同形，但来源和重音不同，不混入改进义。

**怎么变成今天的意思**

**盎格鲁法语 emprouwer 等 → 英语 improve**  
使产生收益、善加利用；与 prou 收益相关

↓

**英语 improve**  
提高质量、改善；自己变好，拼写受 prove 等词影响

↓

**improve + -er → improver**  
有进步的学习者；改良者或材料

a class for improvers 进阶班，beginners and improvers 初学者与进阶者，a bread improver 面包改良剂〔行业用语〕。

**常见搭配与例句**

a class for improvers；beginners and improvers；a bread improver。

> The swimming class is suitable for beginners and improvers.

游泳课适合初学者和已有一些基础的人。

> She joined the improvers’ group after learning the basics.

她学过基础后加入了进阶组。

**别混淆**

improver 学习者分组依课程标准，不是一种统一考试等级；improvement 进步本身。

## 这一组要分清什么

improve/prove 改进与证明不同；improvement 变化、improver 人或材料；进步不等于完美。

## 串起来练习

The improvers made steady improvements through practice.

这些已有基础的学习者通过练习不断进步。
