# 1419 · install — 使设备、软件或人就位，另分清分期义的 installment

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

安装一组看就位与动作方向，分期一组看分批提供。字形接近不代表现代 install 直接派生了所有意义。

**INSTALL：安置到位，让设备或职务开始运作**

install → installation、installer、uninstall、reinstall；installment 的常用分期义走相关但不同的法语路径。

- **安装、过程与执行者**：install · installation · installer
- **撤销与重新安装**：uninstall · reinstall
- **分期提供的另一支**：installment
- **install → installed：放到位到安装**：install · installed
- **安置在位置上 → installation → installations**：installations

## 词形与演化规律

in- + stallum 位置 → install；-ation 名词，-er 执行者，un- 撤销，re- 再；estaler 等 → 分期 installment。

中世纪拉丁席位词经法语进入英语，就任义和安装义分别发展。

install 较早是安置到职务座位，含 in- 在内与 stall 的位置材料。installation 有拉丁名词来源，现代复数可说设施、安装项目、装置艺术。

## 逐词讲解

<a id="w-1"></a>

### 1. install — 安装、设置好；使就任；安置

**音标**：英 /ɪnˈstɔːl/；美 /ɪnˈstɔːl/，部分美音 /ɪnˈstɑːl/

**先抓住这个画面**

把设备放到该在的位置，接好、设好，能用起来，是 install；把人正式安置到职位上，也可用这个旧核心。

**怎么拆**

经法语 installer 上接中世纪拉丁 installāre，in- 在内 + stallum 席位、位置，后者来自日耳曼语言。早期任职就位义再扩到设备、软件安装。

**怎么变成今天的意思**

**日耳曼语位置、座位词 → 中世纪拉丁 stallum**  
固定位置、席位

↓

**in- 在内 + stallum → installāre → 法语 installer → install**  
使就位、就任 → 安装、安置

install a heater 安装暖气设备，install an app 安装应用，install someone as chair 让某人正式就任主席，install yourself in a chair 在椅子里安坐。

**常见搭配与例句**

install an app；install a heater；install someone as chair。

> They installed new lights in the kitchen.

他们在厨房安装了新灯。

> I installed the app after downloading it.

下载后，我安装了这个应用。

**别混淆**

download 把数据下载过来，install 把东西设置成可用状态。软件有时下载后还需安装，两个动作不总是同一步。

<a id="w-7"></a>

### 2. installed — 安装了、安置了；使就任〔过去式、过去分词〕

**音标**：英 /ɪnˈstɔːld/；美 /ɪnˈstɔːld/

**先抓住这个画面**

把东西放到需要的位置，并让它能够使用，是 installed 的常见画面。给某人正式安排一个职位，也保留就位的意思。

**怎么拆**

install + -ed，/l/ 后读 /d/。底词经法语 installer 接中世纪拉丁 installāre，in- 在内 + stallum 席位，后者是日耳曼来源。任职就位义较早，设备和软件义后扩展。

**怎么变成今天的意思**

**中世纪拉丁 installāre → 法语 → install**  
放入席位、使就任 → 安置、安装

↓

**install + -ed → installed**  
安装了；已经放置到位或就任

installed the software 安装了软件；newly installed equipment 新安装的设备；installed as chair 正式就任主席。

**常见搭配与例句**

installed on a computer 安装在电脑上；installed in the office 安装在办公室。

> She installed the new software on her laptop.

她在笔记本电脑上安装了新软件。

> The lights were installed above the desks.

灯安装在书桌上方。

**别混淆**

软件 downloaded 是下载到本机，installed 是完成安装；两个步骤常相连，含义不同。具体介词按设备、位置、职位选。

<a id="w-6"></a>

### 3. installation — 安装、就任；整套设备、设施；装置艺术作品

**音标**：/ˌɪnstəˈleɪʃən/

**先抓住这个画面**

可以说把设备装好的过程，也可以说已经布置好的一整套设备。艺术里用空间、物件等布置出的作品，也叫 installation。

**怎么拆**

经法语 installation 上接中世纪拉丁 installātiō，现代对应 install + -ation。名词从动作扩到安排好的系统、设施、作品。

**怎么变成今天的意思**

**日耳曼语位置、座位词 → 中世纪拉丁 stallum**  
固定位置、席位

↓

**in- 在内 + stallum → installāre → 法语 installer → install**  
使就位、就任 → 安装、安置

↓

**installātiō → installation**  
安装、就任；安装好的设备、设施与空间作品

software installation 软件安装，an electrical installation 电气装置，an art installation 装置艺术作品，a military installation 军事设施。

**常见搭配与例句**

software installation；an art installation。

> The installation took less than an hour.

安装花了不到一小时。

> Visitors walked through the light installation.

观众从那件灯光装置作品中走过。

**别混淆**

installation 既可不可数地说安装过程，也可用 an installation 说一套装置、一个作品。不是每次都翻成安装操作。

<a id="w-8"></a>

### 4. installations — 安装工程；成套设施；装置艺术作品〔复数〕

**音标**：英、美 /ˌɪnstəˈleɪʃənz/

**先抓住这个画面**

把设备安放好，让它能工作，是安装；安放完成的一整套设施，也叫 installation。艺术家把材料、声音、灯光安排成一个空间，便有了装置艺术这个意思。

**怎么拆**

installation + -s → installations。install 词族含 in- 在内与 stall 的座位、位置材料；installation 接拉丁 installatio，早期联系正式就位、任职。

**怎么变成今天的意思**

**拉丁 installare 安置就位 → installatio → installation**  
较早用于安排到职务、座位上

↓

**英语 installation 的安装、设施义 → installations**  
后来又用于由多个部分组成的空间艺术作品

electrical installations 是安装好的电气设施；art installations 是装置艺术作品。先看它是在数安装项目、成套设施，还是艺术作品。

**常见搭配与例句**

electrical installations；technical installations；art installations。

> The museum has three interactive installations.

博物馆有三件互动装置艺术作品。

> The plans show the building’s electrical installations.

图纸标出了这座楼的电气设施。

**别混淆**

installations 不总是“安装几次”。a room full of installations 在美术馆里通常是在说一屋子的装置艺术作品。

<a id="w-2"></a>

### 5. installment — 分期付款中的一期；连载、系列的一期、一部

**音标**：英 /ɪnˈstɔːlmənt/；美 /ɪnˈstɔːlmənt/

**先抓住这个画面**

总额分几次交，每次是一笔 installment；故事分几次发表，每期也可以是 installment。共同点是整件事分批提供。

**怎么拆**

常用分期义是 estallment 的变形，联系法语 estaler 安排付款、estal 固定位置等，不能全按 install 安装 + -ment 解释。另有历史同形词确实指就任、安装。

**怎么变成今天的意思**

**另一路：法语 estaler 等 → installment**  
安排付款 → 每期付款、分期提供的一部分

↓

**分批付款 → installment 的一般扩展**  
系列中按次提供的一部分

pay in installments 分期付款，a monthly installment 每月一期款，the latest installment 最新一集、一部。英式也常拼 instalment。

**常见搭配与例句**

pay in installments；a monthly installment；the latest installment。

> They paid for the furniture in six installments.

他们分六期支付了家具款。

> The next installment of the story appears on Friday.

故事的下一期周五刊出。

**别混淆**

常用 installment 是分期提供的一部分，installation 才常说安装、设施。分期总额、次数等要另外说明，词本身不规定。

<a id="w-4"></a>

### 6. installer — 安装工；安装程序

**音标**：英 /ɪnˈstɔːlə/；美 /ɪnˈstɔːlər/

**先抓住这个画面**

安装的人是 installer；软件里替你复制文件、完成设置的程序，也用 -er 叫 installer。

**怎么拆**

install + -er，标示安装这一动作的执行者，可是人，也可是程序。

**怎么变成今天的意思**

**日耳曼语位置、座位词 → 中世纪拉丁 stallum**  
固定位置、席位

↓

**in- 在内 + stallum → installāre → 法语 installer → install**  
使就位、就任 → 安装、安置

↓

**install + -er → installer**  
安装的人或程序

a window installer 窗户安装工，a software installer 软件安装程序，run the installer 运行安装程序。

**常见搭配与例句**

a software installer；run the installer。

> The installer checked that every window closed properly.

安装工检查每扇窗是否能正常关上。

> The installer asked me to choose a folder.

安装程序让我选择一个文件夹。

**别混淆**

installer 是执行安装的人或程序，installation 是安装过程或装好的设施。

<a id="w-3"></a>

### 7. uninstall — 卸载、移除已安装的软件或硬件

**音标**：英 /ˌʌnɪnˈstɔːl/；美 /ˌʌnɪnˈstɔːl/

**先抓住这个画面**

东西先被安装进系统，再把相应安装关系撤去，就是 uninstall。常见的是卸载应用。

**怎么拆**

un- 逆转动作 + install。这里不是形容某物尚未安装，而是说执行卸载。

**怎么变成今天的意思**

**日耳曼语位置、座位词 → 中世纪拉丁 stallum**  
固定位置、席位

↓

**in- 在内 + stallum → installāre → 法语 installer → install**  
使就位、就任 → 安装、安置

↓

**un- + install → uninstall**  
撤销安装、卸载

uninstall an app 卸载应用，uninstall a driver 卸载驱动，an uninstall option 卸载选项。

**常见搭配与例句**

uninstall an app；an uninstall option。

> She uninstalled the game to free some space.

她卸载游戏，腾出一些空间。

> The menu includes an option to uninstall the program.

菜单中有卸载程序的选项。

**别混淆**

uninstall 与 delete 不总是同一操作；只删桌面图标通常并没有卸载程序。具体残留数据取决于软件。

<a id="w-5"></a>

### 8. reinstall — 重新安装；重新使就任

**音标**：英 /ˌriːɪnˈstɔːl/；美 /ˌriːɪnˈstɔːl/

**先抓住这个画面**

原来装过，再装一遍，是 reinstall。重点是安装这个动作再做一次。

**怎么拆**

re- 再 + install，与 uninstall 的撤销方向不同。

**怎么变成今天的意思**

**日耳曼语位置、座位词 → 中世纪拉丁 stallum**  
固定位置、席位

↓

**in- 在内 + stallum → installāre → 法语 installer → install**  
使就位、就任 → 安装、安置

↓

**re- + install → reinstall**  
再次安装、重新就位

reinstall an app 重新安装应用，reinstall the operating system 重新安装操作系统。

**常见搭配与例句**

reinstall an app；reinstall the software。

> He reinstalled the app after replacing his phone.

换手机后，他重新安装了应用。

> The instructions explain how to reinstall the software.

说明解释了怎样重新安装软件。

**别混淆**

reinstall 是重装，restart 是重新启动。关掉再打开程序，不一定发生重新安装。

## 这一组要分清什么

download、install、restart 是不同动作；installment 不要误当现代安装名词。

## 串起来练习

The installer completed the installation, so there was no need to reinstall the app.

安装程序完成了安装，因此无需重装应用。
