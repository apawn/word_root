# 2434 · logical — 逻辑；合乎推理

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

logical 联系 logic 与希腊 logos 的论述、推理一支。logically 作副词，illogical 是否定。词根不是保证一个人的所有判断正确的标签。

**LOGICAL：结论和前提之间能接得上**

每一步有理由，但前提本身仍可能需要核实。

- **推理与否定**：logical · illogical
- **推理方式**：logically

## 词形与演化规律

il- 是 in- 在 l 前的同化形式；logical → logically。logical conclusion 说明推理关系，不单是结论听着顺耳。

## 逐词讲解

<a id="w-1"></a>

### 1. logical — 合乎逻辑的；合理的；逻辑上的

**音标**：英 /ˈlɒdʒɪkəl/；美 /ˈlɑːdʒɪkəl/

**先抓住这个画面**

前一步和后一步接得上，让人能看见为什么走到这里。

**怎么拆**

英语 logic + -al，表示与逻辑有关或符合逻辑。

**怎么变成今天的意思**

**希腊 légō / lógos**  
选取、收集 → 讲述；话语、说明、道理、计算

↓

**希腊 logikḗ → 拉丁 logica → 古法语 logike → 中古英语 logic**  
推理的技艺 → 逻辑

↓

**英语 logic + -al → logical**  
逻辑的；推理有条理的

a logical conclusion 是从所给条件合理推出的结论；the logical next step 是顺着已有目标自然应做的一步。技术中的 logical structure 常指概念关系，未必等于物理摆放位置。

**常见搭配与例句**

a logical explanation；the logical next step；logical structure。

> Testing the smaller model was the logical next step.

测试较小的模型是顺理成章的下一步。

> Her explanation was clear and logical.

她的解释清楚而有条理。

**别混淆**

logical 不保证每个前提都正确；先把未经证实的前提放进去，也可能推出形式上整齐的错误判断。

<a id="w-2"></a>

### 2. logically — 合乎逻辑地；按照推理

**音标**：英 /ˈlɒdʒɪkli/；美 /ˈlɑːdʒɪkli/

**先抓住这个画面**

让结论沿着理由一步步走来，不靠突然跳过去。

**怎么拆**

logical + -ly，常把末尾 -cal- 的元音弱化，连读为 /kli/。

**怎么变成今天的意思**

**希腊 légō / lógos**  
选取、收集 → 讲述；话语、说明、道理、计算

↓

**希腊 logikḗ → 拉丁 logica → 古法语 logike → 中古英语 logic**  
推理的技艺 → 逻辑

↓

**英语 logic → logical → logically**  
逻辑 → 合乎逻辑地

think logically 描述思考方式；logically follows 表示结论在推理上接得上。它也可用于组织文章，把信息按明确关系排列。

**常见搭配与例句**

think logically；argue logically；follow logically from…。

> Arrange the evidence logically before writing the conclusion.

写结论前，先按逻辑关系整理证据。

> That claim does not follow logically from the figures provided.

那个主张不能从给出的数字中合乎逻辑地推出。

**别混淆**

chronologically 是按时间先后；logically 是按推理关系，两种顺序未必相同。

<a id="w-3"></a>

### 3. illogical — 不合逻辑的；不合理的

**音标**：英 /ɪˈlɒdʒɪkəl/；美 /ɪˈlɑːdʒɪkəl/

**先抓住这个画面**

推理走到一半断了线，结论却已经跳到了另一边。

**怎么拆**

否定前缀 in- 在 l 前同化为 il-，加 logical；不是 ill“生病的”加 logical。

**怎么变成今天的意思**

**希腊 légō / lógos**  
选取、收集 → 讲述；话语、说明、道理、计算

↓

**希腊 logikḗ → 拉丁 logica → 古法语 logike → 中古英语 logic**  
推理的技艺 → 逻辑

↓

**英语 il- + logical → illogical**  
不符合逻辑、理由前后接不上的

如果“价格高”就直接推出“适合我”，中间还缺用途、预算等条件。illogical 可以指出这种推理缺口；不喜欢一个结论，本身却不能证明它不合逻辑。

**常见搭配与例句**

an illogical argument；seem illogical；an illogical conclusion。

> It would be illogical to blame the new rule for a problem that began last year.

问题去年就开始了，把它怪到新规则上并不合逻辑。

> The essay moves from one unsupported assumption to another in an illogical way.

这篇文章不合逻辑地从一个未经证实的假设跳到另一个。

**别混淆**

unpopular 是不受欢迎；illogical 是推理不成立，不是大家不同意就不合逻辑。

## 这一组要分清什么

logical 与 true 有区别：推理形式正确仍须检查前提是否真实。

## 串起来练习

The conclusion follows logically if the premises are true.

如果前提为真，结论就能合乎逻辑地推出。
