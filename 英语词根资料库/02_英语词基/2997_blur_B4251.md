# 2997 · blur — 轮廓被抹开，影像和概念都失去清楚边界

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

照片失焦给最直观画面，记忆模糊、工作生活界限不清再借同样形象。两种形容形式常可重叠使用，不强造绝对区分。

**BLUR：有东西在那里，但边界糊到一起了**

blur → blurred、blurry，动作与结果、性质相连。

- **模糊动作、结果与性质**：blur · blurred · blurry

## 词形与演化规律

blurre → blur，可能接 blear；双写 r + -ed → blurred，+ -y → blurry。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. blur — 使模糊、变模糊；模糊影像；难分清的一团

**音标**：英 /blɜː/；美 /blɜːr/

**先抓住这个画面**

原来边缘清清楚楚，现在像被抹开，分不出线，是 blur。照片可以糊，记忆、工作与生活的界限也能糊成一片。

**怎么拆**

来自较早英语 blurre，可能是 blear 的改形，最早细节未定。由弄脏、使看不清等用法发展出影像、记忆、分类边界模糊。

**怎么变成今天的意思**

**英语较早 blurre → blur，可能联系 blear 眼花、模糊**  
早期来源细节并不完全确定

↓

**blur 动作、模糊块 → blurred、blurry**  
模糊后的结果；模糊不清的性质

blur the image 模糊图像；blur the distinction 模糊区别；a blur of movement 一团看不清的动作；in a blur 模糊一片。

**常见搭配与例句**

blur the distinction；a blur of movement。

> The rain blurred the view through the window.

雨让窗外景象变得模糊。

> The film blurs the line between memory and imagination.

电影模糊了记忆与想象的界限。

**别混淆**

blur 关注清晰边缘、区别变弱；block 常是遮住，可能仍有明确边缘，效果不同。

<a id="w-2"></a>

### 2. blurred — 模糊的；blur 的过去式、过去分词

**音标**：英 /blɜːd/；美 /blɜːrd/

**先抓住这个画面**

blur 是变糊，blurred 常呈现已经看不清、被模糊处理的结果。a blurred face 可能是失焦，也可能是为了遮身份而作了处理。

**怎么拆**

blur + -ed，双写 r → blurred。过去分词可作形容词，描述模糊状态；单凭词形不能确定具体原因。

**怎么变成今天的意思**

**英语较早 blurre → blur，可能联系 blear 眼花、模糊**  
早期来源细节并不完全确定

↓

**blur + -ed → blurred**  
被弄模糊、变得模糊的结果

a blurred image 模糊图像；blurred outlines 模糊轮廓；blurred vision 视物模糊，是描述词组。

**常见搭配与例句**

a blurred image；blurred outlines。

> The photograph had blurred edges.

照片边缘模糊。

> The editor blurred the faces in the background.

编辑把背景中的人脸作了模糊处理。

**别混淆**

blurred 与 blurry 常有重叠；blurred 还可明确接被处理、变模糊的动词过程，不必说成两者永远不同。

<a id="w-3"></a>

### 3. blurry — 模糊不清的；边界不鲜明的

**音标**：英 /ˈblɜːri/；美 /ˈblɜːri/

**先抓住这个画面**

看得见有东西，却抓不到清楚轮廓，就是 blurry。拍照手抖、焦点没对好，都可能出现这种效果；回忆也可以只剩模糊印象。

**怎么拆**

blur + -y，双写 r → blurry，形成性质形容词。实体影像与记忆、概念的模糊性质共用这一形式。

**怎么变成今天的意思**

**英语较早 blurre → blur，可能联系 blear 眼花、模糊**  
早期来源细节并不完全确定

↓

**blur + -y → blurry**  
轮廓、区分或记忆不清晰的

a blurry photo 模糊照片；a blurry memory 模糊记忆；blurry boundaries 模糊边界。

**常见搭配与例句**

a blurry photo；a blurry memory。

> The photo was too blurry to identify the number.

照片太模糊，辨认不出号码。

> I have only a blurry memory of that afternoon.

对那个下午，我只剩模糊印象。

**别混淆**

blurry 说看不清、界限不明；dim 主要说光弱，光线够亮的照片仍可以 blurry。

## 这一组要分清什么

blurred 与 blurry 常重叠；blurry 不只因为光线暗，dim 的重点不同。

## 串起来练习

The blurred photograph left only a blurry outline.

那张模糊的照片只留下一个不清楚的轮廓。
