# 0670 · parent — 生育者到现代养育角色，再借作上一级关系

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

词源的生育画面帮助记忆，现代 parent 还包括实际养育关系；透明 transparent 不属于这个父母分支。

**PARENT：人物是父母，动作是养育，结构里是上一级**

parent → parenthood、parenting；grandparent 往上一代。

- **角色、经历与日常养育**：parent · parenthood · parenting
- **上一代**：grandparent
- **parent → parents：父母、家长；养育**：parent · parents
- **grandparent → grandparents：亲属关系复数**：grandparent · grandparents
- **parent- 父母 + -al 对应 → parental**：parental

## 词形与演化规律

parere → parēns、parentem，经法语 → parent；parent + -hood；parent 作动词 + -ing；grand- + parent。

parent 经法语接拉丁 parens／parentem 生育者；现代人物关系也包括养育、收养等，不能被字面生育义限制。

grand 在亲属称谓中标上一代，不是夸赞亲属伟大。

parental 借拉丁 parentalis，接 parens、parent- 父母词族，远有生育、产生的材料。现代可按 parent + -al 形容词来对应学习，含父方母方。

## 逐词讲解

<a id="w-1"></a>

### 1. parent — 父亲或母亲；家长；母体、上一级；抚养、教养

**音标**：英 /ˈpeərənt/；美 /ˈperənt/

**先抓住这个画面**

一个 parent 是父母中的一位，也可按实际关系指承担养育责任的人。公司、文件夹有 parent，则是在说它是上一级或来源。

**怎么拆**

经法语接拉丁 parēns、parentem，原是表示生育的动词分词。现代人物关系不限于生物生育，名词再可作动词表示养育。

**怎么变成今天的意思**

**拉丁 pariō、parere → parēns、parentem**  
生出、带来 → 生育者、父母

↓

**古法语、盎格鲁法语 parent → 中古英语 parent**  
父母、亲属等 → 现代父母与照顾孩子的人

↓

**英语动词与派生**  
parent 抚养 → parenting；parenthood 为人父母的身份、经历

a single parent 单亲家长，a parent company 母公司，the parent folder 上级文件夹，parent a child 抚养孩子。

**常见搭配与例句**

a single parent；a parent company；the parent folder；both parents。

> A parent came to collect the child after school.

放学后，一位家长来接孩子。

> The files are stored in the parent folder.

文件存放在上级文件夹里。

**别混淆**

parent 一位父母，parents 通常复数说父母；transparent 透明的有另一条显现词源，不能按字母 parent 把它编成育儿词。

<a id="w-6"></a>

### 2. parents — 父母、家长；养育〔parent 的第三人称单数〕

**音标**：/ˈpeərənts/〔英〕；/ˈperənts/〔美〕

**先抓住这个画面**

和孩子构成父母、养育关系的人，是 parents。说到学校通知时，常包括承担这层角色的家长，不只是在追生物学上的来源。

**怎么拆**

parent + -s，/t/ 后读 /s/。经法语接拉丁 parens、parentem 生育者，来自 parere 生育的分词材料；现代含义扩展到养育关系，动词还可说抚养。

**怎么变成今天的意思**

**拉丁 parere → parens／parentem → 法语、英语 parent**  
生育者 → 父母、家长及养育关系

↓

**parent 名词、动词 + -s → parents**  
多位父母、家长；单数主语抚养

my parents 我的父母；parents and children 家长和孩子；adoptive parents 养父母；parents’ evening 家长会、家长沟通活动〔常见英式〕。

**常见搭配与例句**

parents of young children；a meeting for parents。

> The school invited parents to see the children’s work.

学校邀请家长来看孩子们的作品。

> My parents taught me how to cook a few simple meals.

我父母教会了我做几道简单的饭菜。

**别混淆**

my parents 常指我的父母二人，a parent 是一位家长。parents 是复数，parent’s 是一位家长的，parents’ 是多位家长的所有格。

<a id="w-5"></a>

### 3. parenting — 养育、育儿；养育方式

**音标**：英 /ˈpeərəntɪŋ/；美 /ˈperəntɪŋ/

**先抓住这个画面**

每天怎么照顾、引导、回应孩子，这些实际做法和过程合起来就是 parenting。

**怎么拆**

parent 由人物名词作动词，抚养、教养；加 -ing 形成过程名词 parenting。现代常说不同的育儿方式。

**怎么变成今天的意思**

**拉丁 pariō、parere → parēns、parentem**  
生出、带来 → 生育者、父母

↓

**古法语、盎格鲁法语 parent → 中古英语 parent**  
父母、亲属等 → 现代父母与照顾孩子的人

↓

**parent〔名词〕→ parent〔抚养动词〕→ parenting**  
父母角色 → 实际养育过程、方法

parenting skills 育儿技能，parenting styles 养育方式，shared parenting 共同养育，a parenting class 育儿课程。

**常见搭配与例句**

parenting skills；parenting styles；shared parenting；a parenting class。

> They attended a class on parenting skills.

他们参加了一堂育儿技能课。

> The article compares different parenting styles.

文章比较了不同养育方式。

**别混淆**

parenting 不是只指母亲的工作，也不只限于婴儿护理；parenthood 是身份经历，parenting 是如何养育。

<a id="w-8"></a>

### 4. parental — 父母的；与父母身份、职责有关的〔形容词〕

**音标**：英、美 /pəˈrentəl/

**先抓住这个画面**

把视角放在父母这一方：他们给予的支持、承担的责任、作出的许可，都可以用 parental 来修饰。

**怎么拆**

学习时可对应 parent + -al 形容词后缀；历史上 parental 接拉丁 parentalis，来自 parens、parent- 父亲、母亲的词干。

**怎么变成今天的意思**

**拉丁 parens、parent- 父母 → parentalis**  
表示属于父母、与父母有关

↓

**英语 parental**  
与 parent 对照学习，用来修饰支持、责任等名词

parental support 是父母的支持；parental responsibility 是父母的责任；parental permission 是家长许可。

**常见搭配与例句**

parental support；parental responsibility；parental permission。

> The story explores the value of parental support.

这个故事探讨了父母支持的价值。

> The activity requires parental permission.

这项活动需要家长许可。

**别混淆**

parental 可以涉及父亲、母亲或双方。要专指母方、父方，常分别用 maternal、paternal。

<a id="w-3"></a>

### 5. parenthood — 为人父母的身份、经历

**音标**：英 /ˈpeərənthʊd/；美 /ˈperənthʊd/

**先抓住这个画面**

不是一次喂饭或一次辅导，而是进入当父母这种人生角色，以及随之而来的生活经历。

**怎么拆**

parent + -hood 状态、身份，与 childhood 的词尾同类；hood 在这里不是连帽衫的帽子。

**怎么变成今天的意思**

**拉丁 pariō、parere → parēns、parentem**  
生出、带来 → 生育者、父母

↓

**古法语、盎格鲁法语 parent → 中古英语 parent**  
父母、亲属等 → 现代父母与照顾孩子的人

↓

**parent + -hood → parenthood**  
为人父母的身份、阶段和体验

the joys of parenthood 为人父母的喜悦，adjust to parenthood 适应父母身份，early parenthood 初为父母阶段。

**常见搭配与例句**

adjust to parenthood；the joys of parenthood；early parenthood。

> They were still adjusting to parenthood.

他们还在适应初为父母的生活。

> The book describes the challenges and joys of parenthood.

这本书描写了为人父母的挑战与喜悦。

**别混淆**

parenthood 侧重角色和经历，parenting 侧重具体养育过程、做法；两者关系密切，镜头位置不同。

<a id="w-4"></a>

### 6. grandparent — 祖父母或外祖父母中的一人；祖辈

**音标**：英 /ˈɡræn(d)peərənt/；美 /ˈɡræn(d)perənt/

**先抓住这个画面**

不先指定男性女性、父系母系，只说父母上一辈的亲人。

**怎么拆**

grand- + parent；与 grandfather、grandmother 同属英语亲属关系构词。

**怎么变成今天的意思**

**拉丁语 grandis**  
大的、成长充分的；更早来源未定

↓

**古法语 grant / grand → 英语 grand**  
大、重要 → 宏伟、盛大、出色

↓

**英语 grand- + parent → grandparent**  
比父母再上一代的父母

单数 one grandparent 是一位祖辈，复数 grandparents 常统称祖父母或外祖父母。它不必只指某一对夫妻，要看所指家庭范围。

**常见搭配与例句**

a grandparent；grandparents and grandchildren；visit one’s grandparents。

> Each child was invited to bring a grandparent to the event.

每个孩子都可以邀请一位祖辈参加活动。

> Her grandparents live in different cities.

她的祖辈住在不同的城市。

**别混淆**

ancestor 包括更早许多代祖先；grandparent 明确只在父母之上一代。

<a id="w-7"></a>

### 7. grandparents — 祖父母、外祖父母〔复数〕

**音标**：英 /ˈɡræn(d)peərənts/；美 /ˈɡræn(d)perənts/

**先抓住这个画面**

从自己往上数，父母再上一代，就是 grandparents。英语这个词把爸爸、妈妈两边的祖父母都涵盖进去，不必换另一套基本名称。

**怎么拆**

英语 grand- 加 parent，亲属词里的 grand- 表比父母再上一代；parent 经法语、拉丁父母材料借入。现代 grandparent 加 -s，尾 /nts/。

**怎么变成今天的意思**

**grand- + parent → grandparent**  
父母的上一代：祖父母或外祖父母中的一位

↓

**grandparent + -s → grandparents**  
多位祖父母、外祖父母

my grandparents 我的祖父母或外祖父母；maternal grandparents 外祖父母；paternal grandparents 祖父母。

**常见搭配与例句**

visit the grandparents 探望祖辈；both sets of grandparents 双方祖父母。

> My grandparents taught me how to grow vegetables.

我的祖辈教过我怎样种蔬菜。

> Both sets of grandparents came to the school concert.

祖父母和外祖父母都来听了学校音乐会。

**别混淆**

grandparents 不限定只有父亲一方。需要明确哪边时，加 maternal 或 paternal，日常也能直接说 on my mother’s side 等。

## 这一组要分清什么

parent 单数与 parents 复数；parenthood 身份经历与 parenting 过程；transparent 不按现代字母切进本族。

## 串起来练习

Parenting skills helped them adjust to parenthood.

育儿技能帮助他们适应为人父母的生活。
