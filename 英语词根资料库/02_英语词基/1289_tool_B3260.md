# 1289 · tool — 借一样东西，把手头的事做成

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

工具可以有形，也可以是程序、方法；说某个人是别人的 tool，往往是说他被利用，而非夸他有用。

**TOOL：实物器具，也可是一套方法**

tool → tooled、retool；toolkit、toolbox、toolset 成套配置；toolbar、tooltip 接软件工具界面。

- **基础、加工与重配**：tool · tooled · retool
- **成套装备与界面**：toolkit · toolbox · toolset · toolbar · tooltip
- **tool → tools：帮人完成事情的器具、方法**：tool · tools
- **tool 的容器、成套资源组合及复数**：tool · toolbox · toolboxes · toolkit · toolkits
- **tool 的界面提示组合**：tool · tooltip · tooltips
- **tool 的工具栏组合及复数**：toolbar · toolbars

## 词形与演化规律

tōl → tool；tool + kit/box/set/bar/tip；tool + -ed；re- + tool。

实物工具与软件、思考工具保留帮助完成任务的共同画面。

box 强调容器，kit 强调配成一套；软件、方法用法仍可沿这两幅画认识。

简短说明工具或界面对象用途，形成固定界面名词。

与 tooltips 的说明文字分开认识。

## 逐词讲解

<a id="w-1"></a>

### 1. tool — 工具、手段；被利用的人；用工具加工、配置工具

**音标**：/tuːl/

**先抓住这个画面**

手直接做不方便，就借一样东西把事做成；电脑程序、分析方法也可充当这种“帮手”。

**怎么拆**

继承古英语 tōl，与古老制作、准备词族有关。现代不拆成 too 太 + l；名词后来可转成加工、配置工具等动词。

**怎么变成今天的意思**

**古英语 tōl → 中古英语 tool、tol → tool**  
帮人完成事情的器具；与制作、准备词族有关

↓

**实物到抽象手段**  
锤子、软件、思考方法，甚至被人利用的人

↓

**组合与再装备**  
toolkit；tooled 用工具加工的；retool 重新配置工具、调整方案

a useful tool 有用工具，the tools of the trade 行业工具，a learning tool 学习工具，a tool of powerful interests 被强势利益方利用的人。口语叫人 a tool 还可能是骂人蠢、讨厌。

**常见搭配与例句**

a useful tool；the tools of the trade；a learning tool；tool up。

> A dictionary is a useful learning tool.

词典是一种有用的学习工具。

> He chose the right tool for the job.

他为这项工作选对了工具。

**别混淆**

tool 不限手持铁器；instrument 也可工具、仪器，但特定固定名称不能随意互换。称人为 a tool 常有贬意。

<a id="w-9"></a>

### 2. tools — 工具、器具；手段；用工具加工〔第三人称单数〕

**音标**：/tuːlz/

**先抓住这个画面**

能帮你把事情做成的器具就是 tools；软件、方法也能充当工具，因此不只指锤子、螺丝刀。

**怎么拆**

tool + -s，/l/ 后读 /z/。tool 继承古英语 tōl，与较早制作、准备的词族有关；名词后来转作加工、配置工具等动词。

**怎么变成今天的意思**

**古英语 tōl → 中古英语 tool、tol → tool**  
帮助完成任务的器具

↓

**tool + -s → tools**  
多件工具；软件、方法等抽象手段

garden tools 园艺工具；hand tools 手工工具；software tools 软件工具；tools for learning 学习工具。

**常见搭配与例句**

choose the right tools；a box of tools。

> She put the garden tools back in the shed.

她把园艺工具放回了棚屋。

> The course introduces useful tools for planning a project.

这门课介绍了规划项目的实用工具。

**别混淆**

tool 侧重帮助完成任务的手段，device 常说为某种用途设计的装置；equipment 是设备总体，通常不可数。工具也可抽象，如 a tool for thinking。

<a id="w-2"></a>

### 3. toolkit — 工具包、成套工具；一套方法或软件工具

**音标**：/ˈtuːlkɪt/

**先抓住这个画面**

把做某类事情要用的几样东西配成一套；不只指外面的包，还常指里面整套装备或方法。

**怎么拆**

tool 工具 + kit 成套用品，两个名词并列组合；可以是修车包，也可以是写程序、解决问题的一套资源。

**怎么变成今天的意思**

**古英语 tōl → 中古英语 tool、tol → tool**  
帮人完成事情的器具；与制作、准备词族有关

↓

**tool + kit → toolkit**  
为任务配齐的一套工具、方法

a repair toolkit 维修工具包，a software toolkit 软件工具包，a teaching toolkit 教学资源与方法包。

**常见搭配与例句**

a repair toolkit；a software toolkit；a teaching toolkit。

> She keeps a small toolkit in the car.

她在车里放着一套小工具。

> The workshop gave teachers a practical toolkit for group activities.

工作坊给老师提供了一套组织小组活动的实用方法。

**别混淆**

toolkit 侧重成套、为任务配置，toolbox 字面侧重装工具的箱子，但抽象用法会重叠；不能说所有 toolkit 都必须有实物袋。

<a id="w-10"></a>

### 4. toolkits — 成套工具、工具包、资源套件〔复数〕

**音标**：/ˈtuːlkɪts/

**先抓住这个画面**

为完成一类任务而配在一起的工具，是 toolkits。可以是修理工具，也可以是开发软件、开展活动的一套资源。

**怎么拆**

tool 工具 + kit 成套用品 → toolkit，现代加 -s，/t/ 后读 /s/。比喻扩展保留为某项任务配齐资源的核心。

**怎么变成今天的意思**

**tool + kit → toolkit**  
配成一套的工具、用品

↓

**toolkit + -s → toolkits**  
多套工具包、资源包

repair toolkits 修理工具包；software toolkits 软件工具包。

**常见搭配与例句**

toolkits for beginners 初学者工具包；carry toolkits 带着工具包。

> The workers carried small repair toolkits.

工人们带着小修理工具包。

> The course compares two software toolkits.

课程比较两套软件工具包。

**别混淆**

toolbox 更突出装工具的容器，toolkit 更突出搭配成套的内容。实际产品命名中二者可能重叠。

<a id="w-3"></a>

### 5. toolbox — 工具箱；一组可用方法、工具

**音标**：/ˈtuːlbɒks/；美 /ˈtuːlbɑːks/

**先抓住这个画面**

先装锤子、螺丝刀，后来也借来装一套解决问题的方法。

**怎么拆**

tool 工具 + box 箱，实体容器义扩展到软件工具集、方法集合。

**怎么变成今天的意思**

**拉丁、晚期拉丁容器词 → 古英语 box → 现代 box**  
盒、箱；与黄杨木、木盒词有历史联系

↓

**现代容器 box**  
实体容器 → 邮件、软件隔离空间等比喻

↓

**tool + box → toolbox**  
装工具的箱 → 工具集、方法库

a metal toolbox 金属工具箱，a digital toolbox 数字工具集；a toolbox of techniques 一套技巧。

**常见搭配与例句**

a metal toolbox；a digital toolbox；a toolbox of techniques。

> He put the screwdriver back in the toolbox.

他把螺丝刀放回工具箱。

> The course gives students a toolbox of practical techniques.

课程为学生提供了一套实用方法。

**别混淆**

toolbox 不必是真有箱子，软件界面也可叫 toolbox；toolkit 与其有重合，更强调一套工具。

<a id="w-11"></a>

### 6. toolboxes — 工具箱、工具集〔复数〕

**音标**：英 /ˈtuːlbɒksɪz/；美 /ˈtuːlbɑːksɪz/

**先抓住这个画面**

箱子里收着一组工具，是 toolboxes。软件、解决问题的方法也可以像工具一样，被打包成工具集。

**怎么拆**

tool + box → toolbox，现代整个词加 -es；box 的 /ks/ 后复数增加 /ɪz/。容器名到资源集合的比喻，沿可从中取用工具的画面发展。

**怎么变成今天的意思**

**tool + box → toolbox**  
存放工具的箱子

↓

**toolbox + -es → toolboxes；集合比喻**  
多个工具箱；多套可用资源

metal toolboxes 金属工具箱；software toolboxes 软件工具集。

**常见搭配与例句**

toolboxes under the benches 工作台下的工具箱；open the toolboxes 打开工具箱。

> Metal toolboxes stood under the benches.

工作台下放着金属工具箱。

> The course introduces several software toolboxes.

课程介绍了几套软件工具集。

**别混淆**

box 突出把工具收在一个容器里。抽象 toolboxes 说一组可取用的方法、软件资源，未必对应真实箱体。

<a id="w-4"></a>

### 7. toolbar — 工具栏

**音标**：英 /ˈtuːlbɑː/；美 /ˈtuːlbɑːr/

**先抓住这个画面**

把常用工具按钮排成一条，方便随手点，就是界面上的工具栏。

**怎么拆**

tool 工具 + bar 条状区域，软件界面借长条形状命名，不是真有一根金属杆放在屏幕里。

**怎么变成今天的意思**

**古法语 barre → 中古英语 barre → bar**  
杆、横木、阻隔物；更远来源不确定

↓

**现代 bar**  
条杆、障碍；柜台和酒吧；屏幕条状区域等支线

↓

**tool + bar → toolbar**  
排列工具按钮的界面区域

the editing toolbar 编辑工具栏，a toolbar button 工具栏按钮，hide the toolbar 隐藏工具栏。

**常见搭配与例句**

the editing toolbar；a toolbar button；hide the toolbar。

> Click the save button on the toolbar.

点击工具栏上的保存按钮。

> You can hide the toolbar to gain more space.

你可以隐藏工具栏，腾出更多空间。

**别混淆**

toolbar 提供工具，taskbar 通常列出应用、任务等；不同软件具体排布可变化，不只由上下位置辨认。

<a id="w-13"></a>

### 8. toolbars — 工具栏〔复数〕

**音标**：英 /ˈtuːlbɑːz/；美 /ˈtuːlbɑːrz/

**先抓住这个画面**

把一组工具按钮沿一条区域排好，方便随手使用，这些条栏就是 toolbars。

**怎么拆**

tool 工具 + bar 条、栏 → toolbar，再加 -s，读 /z/。

**怎么变成今天的意思**

**tool + bar → toolbar**  
把工具功能集中排列的条状区域

↓

**toolbar + -s → toolbars**  
多个工具栏

editing toolbars 编辑工具栏；custom toolbars 自定工具栏。

**常见搭配与例句**

show the toolbars 显示工具栏；toolbars at the top 顶部工具栏。

> The program has separate toolbars for drawing and editing.

程序分别提供绘图和编辑工具栏。

> The toolbars left little space for the document.

这些工具栏给文档剩下的空间很少。

**别混淆**

toolbar 放工具入口，tooltip 给对象的简短说明；两词一起出现，也各做不同的事。

<a id="w-5"></a>

### 9. tooled — 用工具加工的；压制、刻制装饰纹样的

**音标**：/tuːld/

**先抓住这个画面**

皮面上的纹样不是画笔随便涂上去，而是借工具压、刻加工；词选中的是加工方式。

**怎么拆**

tool 动词 + -ed 的分词、形容词，接工具加工一支；不是 too 很 + led 引导。

**怎么变成今天的意思**

**古英语 tōl → 中古英语 tool、tol → tool**  
帮人完成事情的器具；与制作、准备词族有关

↓

**实物到抽象手段**  
锤子、软件、思考方法，甚至被人利用的人

↓

**tool + -ed → tooled**  
经工具加工、带压刻纹样

tooled leather 压花、雕花皮革，a tooled cover 压纹封面，finely tooled decoration 精细工具加工的装饰。

**常见搭配与例句**

tooled leather；a tooled cover；finely tooled decoration。

> The book has a tooled leather cover.

这本书有一个压纹皮封面。

> The belt is decorated with finely tooled patterns.

皮带饰有精细加工出的纹样。

**别混淆**

tooled 接工艺，不等于 printed 印刷；tooled up 则可说配齐工具等，需看有无 up 与具体语境。

<a id="w-7"></a>

### 10. toolset — 工具集；一套工具

**音标**：/ˈtuːlset/

**先抓住这个画面**

为同类工作把几样工具放到一起，使用时可以互相配合。

**怎么拆**

tool + set（一组），实体工具和软件工具都能这样叫，不是把工具的开关设置一下。

**怎么变成今天的意思**

**英语 tool；set〔一组〕**  
并列组合的两部分

↓

**tool + set〔一组〕 → toolset**  
为某类任务配套的一组工具

a basic toolset 是基本工具组合，a development toolset 是开发工具集；有时也泛说一个人的技能工具箱。

**常见搭配与例句**

a basic toolset；a development toolset；expand one’s toolset。

> The course introduces a basic toolset for data analysis.

课程介绍一套基础数据分析工具。

> He keeps a small toolset in the car.

他在车里放着一套小工具。

**别混淆**

toolset 关注工具组合，settings 关注配置；装好 toolset 后往往还要调整 settings，两者不同层次。

<a id="w-8"></a>

### 11. tooltip — 工具提示、浮动说明框

**音标**：/ˈtuːltɪp/

**先抓住这个画面**

指到某个按钮、图标附近时出现的一小块解释文字，告诉你它做什么；tip 在这里是提示，不是工具最尖的一端。

**怎么拆**

tool 工具 + tip 提示，早用于解释工具栏图标功能，后来泛用到界面里的简短提示框。

**怎么变成今天的意思**

**旧 tip〔递、给〕→ 小费、信息提示**  
具体更早关系不确定，不把全词都从一个尖端故事演出

↓

**tool + tip → tooltip**  
说明工具、界面对象用途的小提示

a tooltip on an icon 图标上的工具提示，show a tooltip 显示提示框，tooltip text 提示文字。

**常见搭配与例句**

show a tooltip；tooltip text；a tooltip on an icon。

> A tooltip explained what the icon meant.

工具提示解释了图标含义。

> The designer shortened the tooltip text.

设计师缩短了提示文字。

**别混淆**

tooltip 通常简短、贴近界面对象，tutorial 教程更系统；具体由鼠标、键盘还是触摸触发，要看界面设计。

<a id="w-12"></a>

### 12. tooltips — 工具提示、浮动说明框〔复数〕

**音标**：/ˈtuːltɪps/

**先抓住这个画面**

按钮或图标旁冒出几字说明，帮你看懂它做什么，这些小提示就是 tooltips。

**怎么拆**

tool 工具 + tip 提示 → tooltip，再加 -s，/p/ 后读 /s/。tip 用信息提示义。

**怎么变成今天的意思**

**tool + tip → tooltip**  
给工具、界面对象附的简短提示

↓

**tooltip + -s → tooltips**  
多个工具提示框或其中的文字

short tooltips 简短工具提示；tooltips for the icons 图标的提示。

**常见搭配与例句**

write tooltips 编写提示文字；helpful tooltips 有帮助的小提示。

> The tooltips explained the unfamiliar icons.

工具提示解释了那些不熟悉的图标。

> The designer rewrote the tooltips in plain language.

设计师用大白话重写了工具提示。

**别混淆**

tooltips 往往紧挨要说明的对象、文字较短；tutorials 是更成体系的教程。具体触发方式由界面决定。

<a id="w-6"></a>

### 13. retool — 重新配置工具、改装生产设备；调整改造

**音标**：/ˌriːˈtuːl/

**先抓住这个画面**

工厂换做另一种产品，先得换一套工装；借到方案、团队，就是把做事的配置重新调一遍。

**怎么拆**

re- 再 + tool 动词，早期可重新用工具加工，后常说工厂重新装备，再引申调整组织、计划。

**怎么变成今天的意思**

**古英语 tōl → 中古英语 tool、tol → tool**  
帮人完成事情的器具；与制作、准备词族有关

↓

**实物到抽象手段**  
锤子、软件、思考方法，甚至被人利用的人

↓

**re- + tool → retool**  
重新加工、配工具；调整配置

retool a factory 改装工厂设备，retool a strategy 调整策略，retool for a new product 为新产品重配设备。

**常见搭配与例句**

retool a factory；retool a strategy；retool for。

> The factory retooled to make smaller engines.

工厂改装设备，转而生产较小的发动机。

> The team retooled its strategy after the trial.

试行后，团队调整了策略。

**别混淆**

retool 重新改造做事的装备、配置，repair 可只修坏的东西；改装不必原设备已经损坏。

## 这一组要分清什么

toolkit/toolbox 成套工具与箱体、抽象用法交叉；retool/repair 改装重配与维修。
