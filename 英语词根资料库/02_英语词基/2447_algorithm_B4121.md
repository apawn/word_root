# 2447 · algorithm — 人名成为计算术名称，再发展成明确步骤的方法名

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

先用排序步骤建立概念，再回看数学家名字、拉丁与法语的传播。拼写中的 -th- 是后来的联想影响，不要据此编出原始词根拆分。

**ALGORITHM：一套可以照着执行的步骤，词名来自人名**

algorithm → algorithmic。

- **方法与性质**：algorithm · algorithmic
- **人名传入的计算方法 → algorithm → algorithms**：algorithms

## 词形与演化规律

al-Khwarizmi → algorismus → algorisme、algorithme → algorithm；+ -ic → algorithmic。

algorithm 接数学家 al-Khwarizmi 名称经拉丁、法语的传写变化，词形受希腊 arithmos 数的联想影响；不是英语 rhythm 的派生词。现代复数说一套套算法。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [algorithm](#w-1) | 英 /ˈælɡərɪðəm/；美 /ˈælɡərɪðəm/ | 算法；一套明确的计算、解题步骤 |
| [algorithms](#w-3) | 英 /ˈælɡərɪðəmz/；美 /ˈælɡəˌrɪðəmz/ | 算法〔复数〕 |
| [algorithmic](#w-2) | /ˌælɡəˈrɪðmɪk/ | 算法的；由算法完成、控制的 |

## 逐词讲解

<a id="w-1"></a>

### 1. algorithm — 算法；一套明确的计算、解题步骤

**音标**：英 /ˈælɡərɪðəm/；美 /ˈælɡərɪðəm/

**先抓住这个画面**

给定输入，一步一步按明确规则处理，得到结果，就是 algorithm 的基本想法。排序数字、规划路线都可以有算法；名字却从一位数学家的名字来。

**怎么拆**

接数学家 al-Khwarizmi 的名字，经中世纪拉丁 algorismus、法语相关形式进入英语。由算术计算方法扩展到算法；-th- 拼写受希腊 arithmos 数的联想影响，非原本同源拆分。

**怎么变成今天的意思**

**数学家 al-Khwarizmi 的名字 → 中世纪拉丁 algorismus**  
与其著作传播相关的计算术名称

↓

**古法语 algorisme、法语 algorithme → algorithm**  
拼写受希腊 arithmos 数的影响；意义推广到计算步骤

a sorting algorithm 排序算法，a search algorithm 搜索算法，a recommendation algorithm 推荐算法；口语 the algorithm 常简称平台推荐系统。

**常见搭配与例句**

a sorting algorithm；design an algorithm；a recommendation algorithm。

> The algorithm sorts the numbers from smallest to largest.

算法把数字从小到大排列。

> A different algorithm found the same result with fewer steps.

另一种算法用更少步骤得到了同样结果。

**别混淆**

算法是一套明确过程，代码是某种实现；algorithm 不等于人工智能，简单排序也有算法。

<a id="w-3"></a>

### 2. algorithms — 算法〔复数〕

**音标**：英 /ˈælɡərɪðəmz/；美 /ˈælɡəˌrɪðəmz/

**先抓住这个画面**

告诉别人按怎样明确的步骤处理输入、得到结果，就是 algorithms 的基本理解。比如找出最大数、把名字排序，各有相应做法。

**怎么拆**

algorithm + -s → algorithms，/m/ 后读 /z/。词名经拉丁、法语等传写数学家 al-Khwarizmi 的名称，字形后来又受 arithmos 数的联想影响。

**怎么变成今天的意思**

**数学家 al-Khwarizmi 的名称 → 中世纪拉丁 algorismus 等**  
较早用来称相应数字计算方法

↓

**法语 algorithme 等 → algorithm → algorithms**  
现代泛指按明确步骤计算、解决问题的方法

sorting algorithms 是排序算法；search algorithms 是搜索算法；compare algorithms 是比较算法。算法不只属于人工智能。

**常见搭配与例句**

sorting algorithms；search algorithms；compare different algorithms。

> The lesson compares two sorting algorithms.

这节课比较了两种排序算法。

> Different algorithms can solve the same problem in different ways.

不同算法可以用不同方法解决同一个问题。

**别混淆**

algorithm 的名字与人名传写有关，rhythm 节奏不是它的英语词基。实际理解算法时先看输入、步骤和结果。

<a id="w-2"></a>

### 3. algorithmic — 算法的；由算法完成、控制的

**音标**：/ˌælɡəˈrɪðmɪk/

**先抓住这个画面**

algorithm 是步骤本身，algorithmic 把这种方式放在系统、决策、过程前面。algorithmic recommendation 就说推荐由算法规则完成。

**怎么拆**

algorithm + -ic；与算法相关的性质形容词，重音转到后面的 /rɪðm/ 一带。

**怎么变成今天的意思**

**数学家 al-Khwarizmi 的名字 → 中世纪拉丁 algorismus**  
与其著作传播相关的计算术名称

↓

**古法语 algorisme、法语 algorithme → algorithm**  
拼写受希腊 arithmos 数的影响；意义推广到计算步骤

↓

**algorithm + -ic → algorithmic**  
与算法有关、由算法处理的

algorithmic thinking 算法思维，algorithmic recommendation 算法推荐，algorithmic decision making 算法决策。

**常见搭配与例句**

algorithmic thinking；algorithmic recommendation。

> The course develops algorithmic thinking through small problems.

课程通过小问题培养算法思维。

> The platform uses algorithmic recommendation to rank videos.

平台用算法推荐给视频排序。

**别混淆**

algorithmic 只说明使用算法，不保证决策公平、结果正确；这些要看目标、规则、数据和验证。

## 这一组要分清什么

algorithm 不等于人工智能；algorithmic 也不自动保证公平或正确。

## 串起来练习

The algorithmic approach follows an explicit algorithm.

这种算法式方法遵循一套明确步骤。
