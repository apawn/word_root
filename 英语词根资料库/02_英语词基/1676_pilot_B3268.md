# 1676 · pilot — 引航、驾驶与先行探路

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

把方向掌住、先探一段路，能把引航员、试播集、试点项目连起来。它不是因为现代飞机而新造的词。

**PILOT：替船、飞机或新计划把方向**

pilot 引航、驾驶 → pilot project 先试路；copilot 协同驾驶者；autopilot 自动系统。

- **引航、驾驶和试点**：pilot
- **协同与自动**：copilot · autopilot
- **pilot → pilots：掌舵、驾驶与试行**：pilot · pilots

## 词形与演化规律

piloto → pilote → pilot；co- + pilot；auto- + pilot。

法语、意大利语形式接希腊舵桨、掌舵材料，船舶用法早于航空用法。

## 逐词讲解

<a id="w-1"></a>

### 1. pilot — 飞行员；引航员；试点、试播；驾驶、试行

**音标**：/ˈpaɪlət/

**先抓住这个画面**

最初先想带船安全走过水路的人，再把带路、掌舵搬到飞机；一个新方案先探路，也叫 pilot。

**怎么拆**

经法语接意大利语 piloto 等，较早形式常联系到希腊舵桨、掌舵词；中间形式和变化有推测，不能拆成 pi + lot。英语的船舶用法早于飞机用法。

**怎么变成今天的意思**

**意大利语 piloto 等 → 法语 pilote/pillot**  
航行、掌舵、引航的人

↓

**英语 pilot**  
引航员 → 飞行员；引导、试行、试播

an airline pilot 航空公司飞行员，a harbor pilot 港口引航员，a pilot project 试点项目，a pilot episode 试播集；pilot a scheme 试行方案。

**常见搭配与例句**

an airline pilot；a harbor pilot；a pilot project；a pilot episode。

> A local pilot guided the ship into the harbor.

一名当地引航员引导船只进港。

> The city will pilot the scheme in two neighborhoods.

该市将先在两个街区试行这个方案。

**别混淆**

pilot 人员义不只飞机驾驶员，船上的引航员也常见；pilot project 是先小范围试验，不是飞行员专用项目。

<a id="w-4"></a>

### 2. pilots — 飞行员；领航员、引航员；试点项目等〔复数〕；驾驶、引导、试行〔第三人称单数〕

**音标**：/ˈpaɪləts/

**先抓住这个画面**

让交通工具沿合适方向走的人，是 pilots 的人物义。一个新安排先小范围试着走起来，又可以是 pilot 试点。

**怎么拆**

pilot + -s，/t/ 后读 /s/。pilot 经法语、意大利语等，较早常接希腊舵桨、掌舵词族；英语船舶用法早于航空，部分中间词形有推测。

**怎么变成今天的意思**

**法语、意大利掌舵名称 → pilot**  
船舶引航 → 飞机驾驶；后有试行、试点用法

↓

**pilot + -s → pilots**  
多位驾驶、引航人员；多个试点；某人驾驶、引导

airline pilots 航空公司飞行员；harbour pilots 港口引航员；pilots a new programme 试行新项目。

**常见搭配与例句**

trained pilots 受训驾驶员；pilot projects 试点项目，前置 pilot 通常单数。

> The pilots prepared for the flight.

飞行员们为航班作准备。

> The school pilots a new reading programme each year.

学校每年试行一项新的阅读项目。

**别混淆**

pilots 不只指飞机驾驶员，船舶引航也是老用法。项目试点的 pilot 则是先引导、试着运行的一支。

<a id="w-2"></a>

### 3. autopilot — 自动驾驶仪；自动控制飞行的系统；下意识照常做事的状态

**音标**：英 /ˈɔːtəʊpaɪlət/；美 /ˈɔːtoʊpaɪlət/，也读 /ˈɑːtoʊpaɪlət/

**先抓住这个画面**

机器接管设定范围内的操纵；比喻到日常生活，就是熟到不用想，身体照着惯例走。

**怎么拆**

auto- 自动 + pilot 驾驶员、驾驶，近代英语复合词；auto- 在此不是 automobile“汽车”的缩略。

**怎么变成今天的意思**

**希腊 autos**  
自己；自身；同一

↓

**英语 auto- + pilot → autopilot**  
自动控制驾驶的装置；后来形成 on autopilot 的比喻用法

航空里指执行某些飞行控制任务的系统，不等于飞机从此不需要飞行员。I was on autopilot 则可以说自己一早按习惯做事，心思没有完全投入。

**常见搭配与例句**

engage the autopilot；the autopilot system；be on autopilot；go through a routine on autopilot。

> The display showed that the autopilot was engaged.

显示屏表明自动驾驶仪已接通。

> I made breakfast on autopilot while thinking about the meeting.

我一边想着会议，一边下意识地做好了早餐。

**别混淆**

autonomous 更强调自主运作能力；autopilot 是特定自动控制系统的名称，也有习惯性行动的比喻义。

<a id="w-3"></a>

### 4. copilot — 副驾驶员；共同驾驶、协助驾驶

**音标**：英 /ˈkəʊpaɪlət/；美 /ˈkoʊpaɪlət/

**先抓住这个画面**

不是坐旁边看热闹的乘客，而是能协同完成驾驶任务的另一位飞行员。co- 抓一起协作。

**怎么拆**

co- 共同、协同 + pilot 驾驶员，也常拼 co-pilot。较新的工具命名借它表示协助工作，但词的基本职业义先存在。

**怎么变成今天的意思**

**意大利语 piloto 等 → 法语 pilote/pillot**  
航行、掌舵、引航的人

↓

**英语 pilot**  
引航员 → 飞行员；引导、试行、试播

↓

**co- + pilot → copilot**  
协同驾驶的另一位驾驶员、助手

the pilot and copilot 机长与副驾驶员〔具体职位按语境〕，serve as copilot 担任副驾驶；a writing copilot 是借喻协作写作工具。

**常见搭配与例句**

the pilot and copilot；serve as copilot。

> The copilot read the checklist aloud.

副驾驶员大声读出了检查单。

> She served as copilot on the return flight.

返程飞行中，她担任副驾驶员。

**别混淆**

copilot 是协同驾驶者，autopilot 是自动驾驶系统或机制；人和系统不能只凭中文都有驾驶就混。

## 这一组要分清什么

pilot/captain 岗位不完全相同；copilot/autopilot 协同驾驶者与自动系统；pilot episode 试播集。

## 串起来练习

The pilot and copilot tested the autopilot during the flight.

飞行中，两位驾驶员测试了自动驾驶系统。
