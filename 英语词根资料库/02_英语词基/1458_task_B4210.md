# 1458 · task — 一件要做的事，以及任务安排、界面组合

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

task 与 tax 历史相关，现代不用每次想到税；take someone to task 是责备，taskmaster 带严格催促意味。

**TASK：把工作落实成一项项要完成的事**

task → taskmaster；multitask 多项处理，taskbar 显示任务或应用的界面栏。

- **任务与督促者**：task · taskmaster
- **同时处理与界面**：multitask · taskbar
- **task → tasks：规定下来的工作项**：task · tasks

## 词形与演化规律

taxa、tasque 等 → task；task + master；multi- + task；task + bar。

法语 tasque 等接估定、征收的拉丁词族，后泛指工作任务。

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. task — 任务、要做的一项工作；交给……任务

**音标**：英 /tɑːsk/；美 /tæsk/

**先抓住这个画面**

把一大堆工作切出一件明确要做的事，就是 a task；也能作动词说把任务交给某人。

**怎么拆**

经法语 tasque 等接估定、征收的拉丁词族，与 tax 有历史关系。原来规定给人的劳务逐渐泛指一项工作，不是每个 task 都涉及税。

**怎么变成今天的意思**

**拉丁 taxāre、taxa 等 → 法语 tasque → task**  
估定、征收等 → 规定的劳务、任务

↓

**一般工作与英语动词**  
一件要做的事；给某人分派任务

↓

**组合限定**  
taskmaster 督工；multitask 多任务；taskbar 任务栏

complete a task 完成任务，a difficult task 难任务，be tasked with doing 被交付某事，take someone to task 责备、质问某人。

**常见搭配与例句**

complete a task；be tasked with；take someone to task；a difficult task。

> The task took longer than expected.

任务花的时间比预想长。

> She was tasked with organizing the files.

她被安排整理文件。

**别混淆**

task 具体任务，work 工作常不可数；take someone to task 是批评，不是把人带去做任务。

<a id="w-6"></a>

### 2. tasks — 任务、工作项〔复数〕；派给任务〔第三人称单数〕

**音标**：英 /tɑːsks/；美 /tæsks/

**先抓住这个画面**

把需要做的工作切成一项项，每一项有要完成的事情，就是 tasks。它比笼统的 work 更容易一条条列出来。

**怎么拆**

task + -s，/k/ 后读 /s/。task 经法语 tasque 等接估定、征收的拉丁词族，原来规定给人的劳务逐渐泛指工作项。

**怎么变成今天的意思**

**法语 tasque 等 → task**  
规定的劳务、工作 → 一项要完成的事

↓

**task + -s → tasks**  
多项任务；或某人把任务派给别人

daily tasks 日常任务；complete tasks 完成任务；tasks someone with something 指派某人做某事。

**常见搭配与例句**

a list of tasks 任务清单；tasks for the week 本周要做的事。

> We divided the tasks between the three of us.

我们三个人分了工。

> The manager tasks each team with a different part of the project.

经理给各团队分派了项目中的不同部分。

**别混淆**

tasks 通常可数，work 在一般工作量义下不可数。job 可以是职位，也可以是一件工作；task 常把要做的具体一项突出出来。

<a id="w-4"></a>

### 3. taskmaster — 督工、严厉的任务安排者

**音标**：英 /ˈtɑːskmɑːstə/；美 /ˈtæskmæstər/

**先抓住这个画面**

不断派活、盯着你做完，而且要求很严的人；也可比喻时间、工作本身成了催着人不停干的主人。

**怎么拆**

task 任务 + master 主人、掌控者，不是 master’s degree 硕士的简称。传统督工画面引申到严厉上司等。

**怎么变成今天的意思**

**拉丁 taxāre、taxa 等 → 法语 tasque → task**  
估定、征收等 → 规定的劳务、任务

↓

**task + master → taskmaster**  
控制、督促任务的人 → 要求严的上司或责任

a hard taskmaster 严厉督工，a demanding taskmaster 要求苛刻的安排者，be a strict taskmaster 督促严格。

**常见搭配与例句**

a hard taskmaster；a demanding taskmaster；a strict taskmaster。

> The coach was a hard taskmaster.

教练要求非常严格。

> She was a demanding taskmaster but praised good work.

她要求很严，但会表扬做得好的工作。

**别混淆**

taskmaster 常强调要求高、催得紧；manager 经理可以宽松，并非所有经理都带相同评价。

<a id="w-5"></a>

### 4. taskbar — 任务栏

**音标**：英 /ˈtɑːskbɑː/；美 /ˈtæskbɑːr/

**先抓住这个画面**

把应用和正在做的任务放成一条，便于切换、打开；常见于电脑桌面界面。

**怎么拆**

task 任务 + bar 条状区域，按显示任务、应用的功能命名。具体系统功能和位置可不同。

**怎么变成今天的意思**

**古法语 barre → 中古英语 barre → bar**  
杆、横木、阻隔物；更远来源不确定

↓

**现代 bar**  
条杆、障碍；柜台和酒吧；屏幕条状区域等支线

↓

**task + bar → taskbar**  
显示任务、应用等的界面区域

pin an app to the taskbar 把应用固定到任务栏，a taskbar icon 任务栏图标。

**常见搭配与例句**

a taskbar icon；pin to the taskbar；hide the taskbar。

> The app’s icon appeared on the taskbar.

应用图标出现在任务栏上。

> He pinned the browser to the taskbar.

他把浏览器固定到了任务栏。

**别混淆**

taskbar 便于管理应用、任务；toolbar 多是当前程序的工具按钮。不要把所有带图标的横条都叫同一个名字。

<a id="w-3"></a>

### 5. multitask — 同时处理多项任务

**音标**：英 /ˌmʌltiˈtɑːsk/；美 /ˈmʌltiˌtæsk/

**先抓住这个画面**

手头不只一件事，需要在几项工作之间安排或切换。

**怎么拆**

现代可拆 multi- + task；计算机名词 multitasking 的记录早于常用动词 multitask，动词可看作从这一用法逆构。不能只因 -ing 像词尾，就断言先有动词。

**怎么变成今天的意思**

**拉丁 multus → 组合形式 multi-**  
多、许多；多次

↓

**英语借用 multi- 参与构词**  
与已有名词、形容词等相接，表示多个、多方面

↓

**英语 multi- + tasking → multitasking；后有动词 multitask**  
多任务执行 → 同时处理几件事

人在工作中 multitask 常包含注意力切换；计算机 multitask 可以通过调度让多个任务并发推进。词本身不承诺每项任务都在同一瞬间执行。

**常见搭配与例句**

learn to multitask；multitask effectively；a computer can multitask。

> I find it harder to multitask when the work is unfamiliar.

工作不熟悉时，我更难同时兼顾多项任务。

> The system can multitask while a large file is downloading.

下载大文件时，系统仍能同时处理其他任务。

**别混淆**

multitask 说任务处理方式；multithread 涉及程序线程结构，不是同义词。

## 这一组要分清什么

task/work 可数任务与一般工作；take to task 非带去做事；taskmaster 评价比 manager 窄。

## 串起来练习

The taskmaster expected every task to be finished on time.

督工要求每项任务按时完成。
