# 1666 · row — 一排、划船、争吵分来源与读音

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

rowed 划过的过去式读 /roʊd/，行列的 row 与划船词却不是一条现代派生。不要把同音等于同源。

**ROW：前两义同读，争吵换成 /raʊ/**

row → rower、rowboat 接划船；hedgerow 接排列；row 的争吵单独辨音。

- **基础同形词与排列组合**：row · hedgerow
- **划船人物与器具**：rower · rowboat
- **rows 的三路：排列、划船、争吵**：rows

## 词形与演化规律

ræw → row 一排；rōwan → row 划船 → rower、rowboat；较晚来源不定词 → row 争吵；hedge + row。

排列名词 row /rəʊ/ 接古英语一行名称；划船 row /rəʊ/ 接古英语 rowan；争吵 row /raʊ/ 更远不明确。现代加 -s 后仍按两种主要元音分读，不能混成一条来源。

## 逐词讲解

<a id="w-1"></a>

### 1. row — 一排、一行；划船；争吵、吵闹

**音标**：一排、划船：英 /rəʊ/、美 /roʊ/；争吵 /raʊ/

**先抓住这个画面**

座位排一条是 row；用桨划船也 row，但有另一条旧词源。have a row 是争吵，读成 /raʊ/，不能只看三个字母一直同读。

**怎么拆**

行列继承古英语 ræw 等；划船继承 rōwan；争吵为较晚、来源不定的同形词。它们不是一排人开始吵架、然后一起划船的单线故事。

**怎么变成今天的意思**

**古英语 ræw 等 → row〔一排〕**  
一条线、一列相继排列的东西

↓

**古英语 rōwan → row〔划船〕**  
用桨推进船；与一排名词分历史

↓

**较晚 row /raʊ/**  
吵闹、争吵；源头不明

↓

**派生词各选一义**  
hedgerow 接行列；rower、rowboat 接划船

a row of houses 一排房，the first row 第一排，row a boat 划船，in a row 连续地，have a row 争吵。

**常见搭配与例句**

a row of；in a row；row a boat；have a row。

> We sat in the front row.

我们坐在前排。

> She rowed the boat across the lake.

她划船穿过湖面。

> They had a row about the broken window.

他们为破窗户吵了一架。

**别混淆**

表格 row 行与 column 列按软件常见布局区分；争吵 row /raʊ/ 与划船 row /roʊ/ 不同读音。

<a id="w-6"></a>

### 2. rows — 一排排；划船〔第三人称〕；争吵〔复数或第三人称，另读音〕

**音标**：排列、划船：英 /rəʊz/，美 /roʊz/；争吵：英、美 /raʊz/

**先抓住这个画面**

rows of seats 是一排排座位，读 /rəʊz/；she rows a boat 读同样的长元音；family rows 家庭争吵，却读 /raʊz/。拼写相同，不能只背一个声音。

**怎么拆**

三条基础 row 词线分开：一排接古英语 ræw 等；划船接古英语 rowan；争吵义的较远来源不明。各自加 -s，词尾都读 /z/。

**怎么变成今天的意思**

**古英语一行、排列名 → row /rəʊ/**  
名词 rows 数排数

↓

**古英语 rowan 划船 → row /rəʊ/**  
动词 rows 用于单数主语

↓

**较晚争吵名 row /raʊ/ → rows**  
另源、另元音，不从划船动作硬推

rows of chairs 是一排排椅子；rows across the lake 是划船过湖；rows over money 是为钱发生的争吵。

**常见搭配与例句**

rows of chairs；rows across the lake；family rows。

> The chairs were arranged in neat rows.

椅子排成了整齐的一排排。

> She rows across the lake every morning.

她每天早上划船过湖。

> The neighbours complained about the loud rows next door.

邻居们抱怨隔壁大声争吵。

**别混淆**

写作时不区别，朗读时要由意思选 /rəʊz/、/roʊz/ 或 /raʊz/。别把争吵读成座位排列。

<a id="w-2"></a>

### 3. rower — 划船者、赛艇运动员；划船机〔部分用法〕

**音标**：英 /ˈrəʊə/；美 /ˈroʊər/

**先抓住这个画面**

用桨推船的人；健身房里的 rower 也可指模仿这套动作的机器。不是把一排人称作一个 rower。

**怎么拆**

row 划船 + -er，中古英语已有 rowere 等人物词；现代器械义延伸到执行、模拟划船动作的工具。

**怎么变成今天的意思**

**古英语 rōwan → row〔划船〕**  
用桨推进船；与一排名词分历史

↓

**row〔划船〕+ -er → rower**  
划船的人；相应锻炼机器

a skilled rower 熟练划船者，an Olympic rower 奥运赛艇运动员，an indoor rower 室内划船机。

**常见搭配与例句**

a skilled rower；an Olympic rower；an indoor rower。

> The rower moved smoothly across the water.

划船者平稳地划过水面。

> The gym added two indoor rowers.

健身房增加了两台室内划船机。

**别混淆**

rower 人物或机器，rowboat 是船；-er 不直接告诉你器具究竟是船还是健身设备。

<a id="w-4"></a>

### 4. rowboat — 划艇、用桨划的小船〔尤美式〕

**音标**：英 /ˈrəʊbəʊt/；美 /ˈroʊboʊt/

**先抓住这个画面**

人握桨划水，船就前进；名字直接说划行这种动力。

**怎么拆**

row 划桨 + boat 船。row 这里读 /rəʊ/、/roʊ/，不读吵架的 /raʊ/。英式也常说 rowing boat。

**怎么变成今天的意思**

**古英语 bāt → 中古英语 bot、boot 等 → boat**  
船、较小的船舶；更远与劈木等联系的解释不强定

↓

**英语 boat 与用途、动力合成**  
乘船、划船；按帆、桨、牵引和渡运给船命名

↓

**row + boat → rowboat**  
以划桨行进的小船

rent a rowboat 租划艇，a wooden rowboat 木划艇，row a rowboat 划小船。

**常见搭配与例句**

a wooden rowboat；rent a rowboat；row a rowboat。

> We rented a rowboat for an hour.

我们租了一小时划艇。

> A wooden rowboat was tied to the dock.

一条木划艇系在码头边。

**别混淆**

rowboat 划桨船，motorboat 机动船；row 的划桨义与 a row 争吵读音、来源用法不同。

<a id="w-5"></a>

### 5. hedgerow — 树篱、灌木篱行

**音标**：英 /ˈhedʒrəʊ/；美 /ˈhedʒroʊ/

**先抓住这个画面**

一排密植的灌木或小树形成边界、遮挡，不是任意一棵独立树；row 在这里选排列义。

**怎么拆**

hedge 树篱 + row 一排，早期英语已有相应组合，经中古英语传下；不是 edge 边缘少了、加了几个字母。

**怎么变成今天的意思**

**古英语 ræw 等 → row〔一排〕**  
一条线、一列相继排列的东西

↓

**hedge + row → hedgerow**  
连成一排的篱木、灌丛边界

a thick hedgerow 浓密树篱，birds in the hedgerow 篱间鸟，a path along the hedgerow 沿树篱的小路。

**常见搭配与例句**

a thick hedgerow；birds in the hedgerow；along the hedgerow。

> Birds nested in the hedgerow.

鸟在树篱里筑巢。

> We followed a path along the hedgerow.

我们沿树篱边的小路走。

**别混淆**

hedgerow 植物行列，fence 可木、金属等围栏；row 在此不接划船或争吵。

## 这一组要分清什么

row /roʊ/、/rəʊ/ 与争吵 /raʊ/；row/column 行列；hedgerow/fence 植物与广义围栏；rower/rowboat 人机与船。

## 串起来练习

The rower passed a row of houses by the river.

划船者经过河边一排房屋。
