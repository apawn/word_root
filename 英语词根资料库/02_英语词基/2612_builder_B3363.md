# 2612 · builder — 建造者名称，再按建造对象限定职业或活动

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

造船者造船，健美者通过训练塑造体形，builder 本身则看建造人、机构、工具等上下文。bodybuilder 的 build 不按砌砖逐字翻。

**BUILDER：把东西一点点建起来的人、工具或角色**

builder → shipbuilder、bodybuilder，建造的对象改变，具体活动也改变。

- **建造者与具体对象**：builder · shipbuilder · bodybuilder
- **build + -er → builder → builders**：builders

## 词形与演化规律

build + -er → builder；ship + builder；body + builder。

build 承古英语建房的动词，与房屋名词词族相关。-er 构成建造者，现代复数 -s；比喻也可说关系、桥梁等的建设者。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. builder — 建筑工、营造商；建造者；构建工具

**音标**：英 /ˈbɪldə/；美 /ˈbɪldər/

**先抓住这个画面**

把零件、材料或想法搭成整体的那一方，可以是人，也可以是软件工具。

**怎么拆**

build + -er，中古英语有 byldere、buyldere；不是 builder 的 ui 读成 buy“买”。

**怎么变成今天的意思**

**古英语 byldan / bytlan 等 → 中古英语 bilden / bylden**  
建造；与居所的旧词族相关

↓

**英语 build**  
建造、建立；逐步形成

↓

**build + -er → builder**  
从事建造者；构建工具

a local builder 当地建筑工、营造商，a website builder 网站构建工具。职业和企业规模按语境，不只某一种单一工种。

**常见搭配与例句**

a local builder；a house builder；a website builder。

> The builder checked the wall before starting work.

建筑工开工前检查了墙。

> The website builder lets users arrange pages visually.

网站构建工具让用户直观地排列页面。

**别混淆**

builder 建造角色，building 可以是建筑物或建造活动；a building builder 不是日常最自然的职业介绍，通常直接 a builder。

<a id="w-4"></a>

### 2. builders — 建造者；建筑工人、建筑商〔复数〕

**音标**：英 /ˈbɪldəz/；美 /ˈbɪldɚz/

**先抓住这个画面**

把房屋、结构一步步建起来的人，是 builders。把组织、关系等逐渐建起来的人，也可以比喻用这个称呼。

**怎么拆**

build + -er 人 → builder，再加 -s → builders。build 承古英语 byldan 建房，与古老房屋名词词族相连，现代读 /bɪld/。

**怎么变成今天的意思**

**古英语房屋词族 → byldan 建房 → build**  
由建房扩展到各种建造、建立

↓

**build + -er → builder → builders**  
现代建造者、建筑工作者或经营者的复数

house builders 是建房者、住宅建筑商；local builders 是当地建筑人员、建筑商；bridge builders 可说造桥者，也可比喻促进联系的人。

**常见搭配与例句**

house builders；local builders；bridge builders。

> The builders finished the roof before winter.

建筑工人在冬天前完成了屋顶。

> The exhibition celebrates the bridge builders of the past.

展览向过去的造桥者致敬。

**别混淆**

builders 既可能是工人，也可能是建筑公司、承建方的名称；由句子中的主体和工作范围判断。

<a id="w-2"></a>

### 3. bodybuilder — 健美运动员；健美爱好者

**音标**：英 /ˈbɒdibɪldə/；美 /ˈbɑːdibɪldər/

**先抓住这个画面**

把肌肉形体作为长期塑造目标的人，有的参加比赛，也有的只是爱好。

**怎么拆**

body + builder，builder 是 build + -er；与 bodybuilding 对照，前者人物、后者活动。不是说此人负责从零制造人体。

**怎么变成今天的意思**

**英语 body；builder〔build + -er〕**  
并列组合的两部分

↓

**body + builder〔build + -er〕 → bodybuilder**  
从事肌肉形体塑造的人

a competitive bodybuilder 是参赛健美运动员。日常宽泛称呼也不一定都在备赛，按上下文区分。

**常见搭配与例句**

a competitive bodybuilder；an amateur bodybuilder；a professional bodybuilder。

> The documentary follows an amateur bodybuilder.

纪录片跟拍一位业余健美爱好者。

> Several bodybuilders took part in the exhibition.

几位健美运动员参加了展示活动。

**别混淆**

bodybuilder 是健美从事者，personal trainer 是私人教练；同一个人可兼任，但肌肉发达不自动说明职业教练资格。

<a id="w-3"></a>

### 4. shipbuilder — 造船工；造船商、造船企业

**音标**：英 /ˈʃɪpbɪldə/；美 /ˈʃɪpbɪldər/

**先抓住这个画面**

把船造出来的人或公司；-er 可以是一整个企业，不只站在现场的一个工人。

**怎么拆**

ship + builder 建造者，按造船职责组合；与 shipbuilding 造船业、造船活动一起学。

**怎么变成今天的意思**

**古英语 sċip → 中古英语 schip 等 → ship**  
船；更远来源的劈木解释不作定论

↓

**动词 ship 及现代复合词**  
用船运输 → 不限交通方式的发运；船舶类型与人员

↓

**ship + builder → shipbuilder**  
建造船舶的主体 → 造船者、造船商

a major shipbuilder 大型造船商，a skilled shipbuilder 熟练造船工；先看所说对象是人还是企业。

**常见搭配与例句**

a major shipbuilder；a skilled shipbuilder；a commercial shipbuilder。

> The shipbuilder received an order for two ferries.

这家造船商接到了两艘渡轮的订单。

> Her grandfather worked as a shipbuilder.

她的祖父曾是一名造船工。

**别混淆**

shipbuilder 造船，shipowner 拥有船，skipper 指船长；同一人可能兼任，但词义分工清楚。

## 这一组要分清什么

bodybuilder 是健美训练者，不等于所有体力劳动者；shipbuilder 按造船职责命名。

## 串起来练习

The builder admired the shipbuilder’s careful planning.

建筑工人赞赏造船者细致的规划。
