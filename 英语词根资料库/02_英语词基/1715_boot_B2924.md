# 1715 · boot — 靴子及踢出、后备厢等扩展，另经提带比喻形成电脑启动

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

不要凭现代同形词编一脚踢开电脑的词源。booted 也要随上下文判断穿靴、被赶走还是启动。

**BOOT：计算机启动要经过 bootstrap 这座桥**

boot 靴子 → bootstrap 提带、借喻自举 → boot 电脑启动 → reboot、bootable。

- **基础和旧扩展**：boot · booted · bootleg
- **自举与电脑启动**：bootstrap · reboot · bootable
- **boot → boots：靴子、踢与启动**：boot · boots
- **reboot 的电脑重启、作品重启及变化**：reboot · reboots · rebooted · rebooting

## 词形与演化规律

古法语 bote → boot；boot + strap；计算机 bootstrap 缩成 boot；re- 再次、-able 可用于。

靴子接法语；电脑启动缩自 bootstrap 的技术用法。

boot 缩自计算机 bootstrap；reboot 再有作品系列等重新起步的比喻。

## 逐词讲解

<a id="w-1"></a>

### 1. boot — 靴子；踢、赶出；汽车后备厢〔英式〕；启动〔计算机〕

**音标**：/buːt/

**先抓住这个画面**

从脚上的靴子，可以想到一脚踢开、赶走。电脑启动义却要绕过 bootstrap：不是踢电脑一脚，它就启动了。

**怎么拆**

靴子义经古法语 bote 进入英语，远源不确定。计算机 boot 缩自 bootstrap 的启动义；to boot 此外、而且则另承古英语 bōt 好处等旧义，不能一条线全包。

**怎么变成今天的意思**

**古法语 bote → 中古英语 bote／boote → boot**  
靴子；更远来源未定

↓

**boot + strap → bootstrap**  
靴子提带；借给自行带起、逐步建立的过程

↓

**bootstrap 的计算机义缩短 → boot**  
启动计算机；再有 reboot、bootable

walking boots 徒步靴，the car boot 汽车后备厢〔美式 trunk〕，boot someone out 把某人赶出去，boot the computer 启动电脑。

**常见搭配与例句**

walking boots；the car boot；boot out；boot the computer。

> She put her walking boots in the car boot.

她把徒步靴放进汽车后备厢。

> The computer takes a minute to boot.

这台电脑需要一分钟启动。

**别混淆**

boot the computer 和 boot someone out 是不同扩展。to boot 而且是另一条旧词历史，不是又来一只靴子。

<a id="w-7"></a>

### 2. boots — 靴子〔复数〕；踢；启动〔第三人称单数〕

**音标**：/buːts/

**先抓住这个画面**

脚上包得较高的靴子是 boots；用靴子踢，是动词的一条路。电脑 boots up 的启动义又经 bootstrap 这个较长技术词缩短而来。

**怎么拆**

boot + -s，/t/ 后读 /s/。靴子 boot 经古法语 bote 借入，更远来源未定；动词踢接靴子动作，电脑 boot 缩自 bootstrap 的启动用途，不能只用踢解释电脑。

**怎么变成今天的意思**

**古法语 bote → boot 靴子；英语相关动词**  
靴子 → 穿靴踢等动作

↓

**bootstrap 技术用途缩短 → boot；加 -s → boots**  
电脑启动；多双或多只靴子、动词单数形式

walking boots 徒步靴；a pair of boots 一双靴子；boots up quickly 启动很快。

**常见搭配与例句**

muddy boots 沾泥的靴子；boots the ball downfield 把球踢向前场。

> Leave your muddy boots by the door.

把沾泥的靴子留在门边。

> The new computer boots up in a few seconds.

新电脑几秒钟就能启动。

**别混淆**

boots 作鞋类常按复数说，一双用 a pair of boots。to boot 此外、而且接另一古英语好处词的历史，不与电脑启动硬串。

<a id="w-3"></a>

### 3. booted — 穿靴的；被踢出、赶出的；已启动〔boot 的词形〕

**音标**：/ˈbuːtɪd/

**先抓住这个画面**

a booted foot 是穿靴的脚；got booted out 是被赶走；系统 booted 则说它启动了。先看 boot 用的是哪条意思，再判断 -ed。

**怎么拆**

boot + -ed。末尾 /t/ 后 -ed 读 /ɪd/；既可作过去式、过去分词，也可由名词形成穿着靴子的形容词。

**怎么变成今天的意思**

**古法语 bote → 中古英语 bote／boote → boot**  
靴子；更远来源未定

↓

**boot + strap → bootstrap**  
靴子提带；借给自行带起、逐步建立的过程

↓

**bootstrap 的计算机义缩短 → boot**  
启动计算机；再有 reboot、bootable

↓

**boot + -ed → booted**  
穿靴的性质；踢出、启动等动词的过去形式

booted feet 穿靴的双脚，got booted from the game 被踢出游戏，the computer booted successfully 电脑成功启动。

**常见搭配与例句**

booted feet；got booted out；booted successfully。

> His booted feet left muddy marks on the floor.

他穿靴的双脚在地板上留下泥印。

> The computer booted successfully after the update.

更新后电脑成功启动了。

**别混淆**

booted 不固定就是启动完毕。The booted figure stood at the door 的人影穿着靴子，与电脑无关。

<a id="w-4"></a>

### 4. bootleg — 未经授权制作或流通的录音、翻版；私酒；非法制作或贩卖

**音标**：/ˈbuːtleɡ/

**先抓住这个画面**

先想靴筒：旧时把东西藏在靴筒里偷运，后来 bootleg 就常指绕开许可做出来、卖出去的酒或录音。

**怎么拆**

boot 靴 + leg 腿部、靴筒。原可直接指靴筒，私酒、走私义与藏酒的旧背景相连，后来扩到未经授权的录音等。

**怎么变成今天的意思**

**古诺斯语 leggr → 中古英语 leg、legge → leg**  
腿、肢骨、杆状部位 → 腿

↓

**boot + leg → bootleg〔靴筒〕**  
靴筒可用于藏物

↓

**私酒、非法流通 → 未经授权的录音等**  
从藏运场景扩到许可之外的制作、传播

a bootleg recording 未经授权的录音，a bootleg copy 翻版，bootleg liquor 私酒；bootleg jeans 又可按靴筒形状说裤脚较宽的裤型。

**常见搭配与例句**

a bootleg recording；a bootleg copy；bootleg liquor。

> The shop sold bootleg recordings of old concerts.

那家店出售旧演唱会未经授权的录音。

> He found a bootleg copy with poor sound quality.

他找到一份音质很差的翻版。

**别混淆**

bootleg recording 不等于正式发行的 live recording 现场录音；是否现场与是否授权是两回事。

<a id="w-5"></a>

### 5. bootstrap — 靴子提带；靠已有资源逐步建立；启动、自举；自助重采样法

**音标**：/ˈbuːtstræp/

**先抓住这个画面**

本来是帮助穿靴子的提带。提着自己的靴带把自己抬起来原是办不到的画面，后来却借给自力起步、用小步骤带起大系统。

**怎么拆**

boot 靴子 + strap 带。由 pull oneself up by one’s bootstraps 的比喻发展；计算机、统计、创业等领域各自固定术语，不把它们说成同一种具体操作。

**怎么变成今天的意思**

**古法语 bote → 中古英语 bote／boote → boot**  
靴子；更远来源未定

↓

**boot + strap → bootstrap**  
靴子提带；借给自行带起、逐步建立的过程

↓

**bootstrap 的计算机义缩短 → boot**  
启动计算机；再有 reboot、bootable

bootstrap a system 自举、逐步建立系统，bootstrap a business 靠自身资源起步经营，a bootstrap estimate 自助法估计。统计用法通常从观测数据反复有放回抽样，估计统计量的变化。

**常见搭配与例句**

bootstrap a system；bootstrap a business；a bootstrap estimate。

> A small program helps bootstrap the rest of the system.

一段小程序帮助带起系统其余部分。

> The researchers used a bootstrap method to estimate uncertainty.

研究人员用自助重采样法估计不确定性。

**别混淆**

计算机自举是由初始机制带起后续系统，不是凭空没有外部条件。统计 bootstrap 是特定抽样方法；大写 Bootstrap 还可作软件框架名称。

<a id="w-6"></a>

### 6. bootable — 可启动的；可用于引导系统的

**音标**：英 /ˈbuːtəbəl/；美 /ˈbuːtəbəl/

**先抓住这个画面**

普通U盘只是存文件，bootable USB drive 则具备让相应电脑从它开始加载系统的条件。词尾告诉你能不能用于启动。

**怎么拆**

boot 启动 + -able 能够、可用于。不是拿得动、能穿上的靴子的常规形容词。

**怎么变成今天的意思**

**boot + strap → bootstrap**  
靴子提带；借给自行带起、逐步建立的过程

↓

**bootstrap 的计算机义缩短 → boot**  
启动计算机；再有 reboot、bootable

↓

**boot + -able → bootable**  
可启动；可以用作启动来源

a bootable USB drive 启动U盘，a bootable disk 可引导磁盘。是否能在某台机器启动，还涉及格式、内容与兼容性。

**常见搭配与例句**

a bootable USB drive；a bootable disk。

> She created a bootable USB drive for the test computer.

她为测试电脑制作了一个启动U盘。

> The installer checked whether the disk was bootable.

安装程序检查磁盘是否可用于启动。

**别混淆**

bootable 不等于盘里随便有一个系统文件；bootable 说明可用于相应启动，portable 说明便携或可移植。

<a id="w-2"></a>

### 7. reboot — 重新启动；重新开始；重启作品系列

**音标**：动词常 /ˌriːˈbuːt/；名词常 /ˈriːbuːt/

**先抓住这个画面**

电脑已经启动过，再让启动过程走一遍，是 reboot。电影、剧集的故事体系重新开篇，也借这个重新起步的意思。

**怎么拆**

re- 再次 + boot 计算机启动义；再从系统重启扩到项目、作品重新开始。不同作品对是否沿用旧设定处理不一。

**怎么变成今天的意思**

**boot + strap → bootstrap**  
靴子提带；借给自行带起、逐步建立的过程

↓

**bootstrap 的计算机义缩短 → boot**  
启动计算机；再有 reboot、bootable

↓

**re- + boot → reboot**  
重新启动；重新组织开篇

reboot the computer 重启电脑，a system reboot 一次系统重启，a reboot of the series 系列作品重启版。

**常见搭配与例句**

reboot the computer；a system reboot；a reboot of the series。

> Please reboot the computer after the installation.

安装完成后请重启电脑。

> The studio announced a reboot of the old series.

制片公司宣布重启那部老系列作品。

**别混淆**

reboot 不等于 reinstall 重装，也不必擦除用户所有资料。作品 reboot 与续集 sequel 重点不同，但市场称法可能有交叠。

<a id="w-8"></a>

### 8. rebooted — 重新启动了；重新开篇、重启了

**音标**：/ˌriːˈbuːtɪd/

**先抓住这个画面**

机器启动流程再走了一遍，是 rebooted；项目或作品重新起步，也可借这个词。

**怎么拆**

reboot + -ed，/t/ 后词尾读 /ɪd/。reboot 接计算机 boot，后者缩自 bootstrap。

**怎么变成今天的意思**

**bootstrap → boot；re- + boot → reboot**  
启动；再次启动

↓

**reboot + -ed → rebooted**  
过去重启机器或作品、项目

rebooted the computer 重启了电脑；a rebooted series 重启的系列。

**常见搭配与例句**

the machine rebooted 机器重新启动了；rebooted the project 让项目重新起步。

> I rebooted the computer after saving the file.

保存文件后，我重启了电脑。

> The studio rebooted the series with a new cast.

制片公司用新演员阵容重启了这个系列。

**别混淆**

rebooted 说重新启动，不自动等于资料被清空、软件被重装。

<a id="w-9"></a>

### 9. rebooting — 正在重启；重新启动、重新起步的过程

**音标**：/ˌriːˈbuːtɪŋ/

**先抓住这个画面**

机器正在重新走启动流程，是 rebooting。电影、项目重新开篇时，也可以借同一个重新起步的画面。

**怎么拆**

reboot + -ing。基础 re- 再次 + boot 启动，boot 的近源是计算机 bootstrap 的截短。

**怎么变成今天的意思**

**bootstrap → boot；re- + boot → reboot**  
重新启动的计算机用语

↓

**reboot + -ing → rebooting**  
重启动作的进行、过程

rebooting the system 重启系统；after rebooting 重启后。

**常见搭配与例句**

the computer is rebooting 电脑正在重启；rebooting a series 重启一个系列。

> The computer was rebooting when I came back.

我回来时，电脑正在重启。

> Rebooting the old series gave the writers a fresh start.

重启老系列给编剧带来了重新开篇的机会。

**别混淆**

rebooting 强调重新启动过程，resetting 强调重设状态，操作目的和影响未必相同。

<a id="w-10"></a>

### 10. reboots — 重启〔第三人称单数〕；重启操作、重启版作品〔复数〕

**音标**：动词 /ˌriːˈbuːts/；名词 /ˈriːbuːts/

**先抓住这个画面**

电脑重新走启动过程，是 reboots；老作品系列重新开篇，名词复数也可叫 reboots。

**怎么拆**

re- 再次 + boot 启动 → reboot，加 -s，/t/ 后读 /s/。boot 的计算机义缩自 bootstrap。

**怎么变成今天的意思**

**bootstrap 计算机义 → boot；re- + boot → reboot**  
启动；重新启动

↓

**reboot + -s → reboots**  
它重启；多次重启、多个作品重启版

system reboots 系统重启操作；film reboots 电影重启版。

**常见搭配与例句**

the computer reboots 电脑重新启动；frequent reboots 频繁重启。

> The computer reboots after the installation.

安装后电脑会重新启动。

> The article compares three reboots of the series.

文章比较了这个系列的三个重启版本。

**别混淆**

作品 reboot 强调重新开篇，sequel 强调承接前作；实际作品的设定延续程度还要看内容。

## 这一组要分清什么

to boot 此外、而且另有来源；reboot 不等于重装全部系统。

## 串起来练习

The computer can boot from the bootable drive and reboot after installation.

电脑能从启动盘启动，并在安装后重启。
