# 1630 · loading — 东西装进去，系统也可载入资源或承受负荷

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

有一个承载空间，东西进入其中。loading 看过程，overloading 再加过量限制，工程和程序的具体承载对象不同。

**LOADING：从车厢装货到程序载入**

load → loading；overloading 是超过适当负荷。

- **装载、加载与过载**：load · loading · overloading

## 词形与演化规律

load + -ing；over- 过度 + loading。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| [load](#w-3) | 英 /ləʊd/；美 /loʊd/ | 负荷；一批装载物；装载；加载 |

## 逐词讲解

<a id="w-3"></a>

### 1. load — 负荷；一批装载物；装载；加载

**音标**：英 /ləʊd/；美 /loʊd/

**先抓住这个画面**

放到车上、机器里、系统里让它承担的东西都可想成负载；具体是货、工作还是数据，看对象。

**怎么拆**

接古英语 lād 行程、运送相关词，中古英语发展出负担、载量义；与 lode 矿脉等形式后来分化。现代计算机加载接把内容装入可用位置的画面。

**怎么变成今天的意思**

**古英语 lād 行程、运送 → 中古英语 lode、loade**  
运送 → 搬运的负荷

↓

**现代 load**  
货物、负担；装载 → 加载与数据传送

a heavy load 重负载，a load of washing 一批洗衣物，load a truck 给卡车装货，load a page 加载页面；loads of 口语很多。

**常见搭配与例句**

a heavy load；load a truck；load a page；loads of。

> Workers loaded the boxes onto the truck.

工人把箱子装上卡车。

> The page took several seconds to load.

页面花了几秒钟才加载好。

**别混淆**

load 装载的量或动作，weight 具体重量不等同；一批资料可 load into memory，不需物理卡车。

<a id="w-1"></a>

### 2. loading — 装载；加载；负荷、施载过程

**音标**：英 /ˈləʊdɪŋ/；美 /ˈloʊdɪŋ/

**先抓住这个画面**

货物进入车厢是 loading；数据进入程序、页面也借这个装进去的动作。工程里则可能是在说承受、施加负荷。

**怎么拆**

load + -ing，分词、过程名词；实体装载义扩展到数据、资源加载及工程负荷语境。

**怎么变成今天的意思**

**load 装载、负荷**  
把东西装上，或让系统承载

↓

**load + -ing → loading**  
装载、加载过程；工程里也可说施加负荷

cargo loading 货物装载，a loading screen 加载画面，loading time 加载时间，loading capacity 装载能力。

**常见搭配与例句**

cargo loading；loading time；a loading screen。

> Loading the truck took most of the morning.

给卡车装货花了大半个上午。

> A progress bar showed the page’s loading status.

进度条显示页面的加载状态。

**别混淆**

loading 不全是网络下载：程序从本地读取资源也能 loading；download 更具体说从远端获取数据。

<a id="w-2"></a>

### 3. overloading — 超载；使负担过重；重载〔编程〕

**音标**：英 /ˌəʊvəˈləʊdɪŋ/；美 /ˌoʊvərˈloʊdɪŋ/

**先抓住这个画面**

一条线是把东西装得太多；编程里还有同名操作按不同参数区分的专门名称。

**怎么拆**

overload + -ing；通常继承负荷过量义。编程术语 function／operator overloading 已是专门约定，不能只靠超负荷的日常画面理解。

**怎么变成今天的意思**

**英语 overload；-ing**  
组合时并列的材料

↓

**overload + -ing → overloading**  
超载过程；编程中约定的重载用法

overloading a vehicle 是超载行为。编程 function overloading 常说同名函数的不同参数形式，是否支持以及怎样解析依语言，不是函数太忙。

**常见搭配与例句**

avoid overloading；overloading the system；function overloading。

> Overloading the server led to slower responses.

服务器负担过重，响应变慢了。

> The chapter introduces function overloading with simple examples.

本章用简单例子介绍函数重载。

**别混淆**

overloading 不是 overriding：后者在编程中特别常说覆写继承行为，两者不能仅因 over 开头就混为一谈。

## 这一组要分清什么

loading 不等于一律下载；overloading 说超过适当范围。

## 串起来练习

The loading crew avoided overloading the truck.

装货人员避免让卡车超载。
