# 1368 · path — 通路、轨迹；方法与探路、牵船用途

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

近源古英语明确，更远借入说有争议。小路、风暴路线和做事途径按路线画面联系，不见 path 就当供人走的铺装路。

**PATH：从此处到彼处的一条路线**

path → pathway、footpath；pathfinder 人物、towpath 岸路；warpath 已有比喻精讲复用。

- **路线与步行通道**：path · pathway · footpath
- **开路人物和用途**：pathfinder · towpath · warpath
- **path → paths：一条条路和实现目标的途径**：path · paths
- **path 的数字定位路线及复数**：path · filepath · filepaths

## 词形与演化规律

path + way/finder；foot/tow/war + path；finder 为 find + -er。

古英语 paeth 本族旧词，更远是否借入仍有争论；复数 th 有变体。

数字路径借找位置的路线，不表示磁盘里真有供人走的道路。

## 逐词讲解

<a id="w-1"></a>

### 1. path — 小路、路径；轨迹；做事途径；文件路径

**音标**：英 /pɑːθ/；美 /pæθ/

**先抓住这个画面**

从这里到那里，脚或物体走过一条线；做事怎样一步步到目标，也可借这条路来理解。

**怎么拆**

接古英语 pæþ，经中古英语延续。更远是否从伊朗语等借入仍有争议，不能把重建的通过词根说成已确证。现代数字文件路径借定位路线来命名。

**怎么变成今天的意思**

**古英语 pæþ → 中古英语 path、peth → path**  
路、足迹踩出的通道；更远来源有争议

↓

**英语 path**  
小路、行进轨迹；行动途径、文件位置等

a narrow path 小路，the path of a storm 风暴路径，a path to success 通向成功的途径，a file path 文件位置路径。

**常见搭配与例句**

follow a path；a path through；a path to；a file path。

> A narrow path led through the woods.

一条小路穿过树林。

> The guide explained a possible path to solving the problem.

指南说明了解决问题的一种可行途径。

**别混淆**

path 常步行小路、路线，road 常道路，way 更广也可方法；path 不一定铺了供汽车行驶的路面。

<a id="w-7"></a>

### 2. paths — 小路、路径；途径〔复数〕

**音标**：英 /pɑːðz/；美 /pæðz/，也读 /pæθs/

**先抓住这个画面**

脚下一条条可走的路线是 paths；事情要怎么推进、文件到哪里找，也可以借路径这个画面。

**怎么拆**

path + -s，常把 /θ/ 浊化成 /ð/ 后读 /z/，也有保留 /θs/ 的读法。path 接古英语 paeth，更远来源的借词分析仍有争论。

**怎么变成今天的意思**

**古英语 paeth → path**  
小路、通道 → 行进路线、行动途径

↓

**path + -s → paths**  
多条路、多个实现办法或文件路径

forest paths 林间小路；career paths 职业发展道路；file paths 文件路径。

**常见搭配与例句**

different paths 不同道路；our paths crossed 我们相遇了，固定比喻。

> Several paths lead down to the lake.

几条小路通向湖边。

> The program checks the file paths before opening them.

程序打开文件前先检查路径。

**别混淆**

paths 的 th 不一定照原形清音读，常用 /ðz/，也有变体。a path through the woods 说穿过树林的路，paths to a goal 则说达到目标的途径。

<a id="w-2"></a>

### 3. pathway — 小径；途径；通路

**音标**：英 /ˈpɑːθweɪ/；美 /ˈpæθweɪ/

**先抓住这个画面**

沿着一个个相接的步骤往前，可以走到某地，也可以达到某个结果。

**怎么拆**

path（小路、途径）+ way，中古英语已有 pathwei。两部分共同强化通行路线，不能把 path 说成 way 的历史后代。

**怎么变成今天的意思**

**英语 path；way**  
组合时的两个材料

↓

**path + way → pathway**  
可行走的小路；达到结果的一条通路

日常可指花园步道；a pathway to a career 是进入职业的途径。生物学 metabolic pathway 说一系列相关反应，不是一条能看见的细小管道。

**常见搭配与例句**

a garden pathway；a pathway to success；a metabolic pathway。

> A narrow pathway leads down to the lake.

一条狭窄小径通向湖边。

> The programme creates a pathway into skilled employment.

这个项目为人们进入技能型岗位开辟途径。

**别混淆**

pathway 常强调具体路线或相连步骤；goal 是目的地或目标，途径与目标不是一回事。

<a id="w-3"></a>

### 4. pathfinder — 探路者、开拓者

**音标**：英 /ˈpɑːθfaɪndə/；美 /ˈpæθfaɪndər/

**先抓住这个画面**

别人还不知道该怎么走，他先找出一条能过的路；也能比喻开辟新方法的人。

**怎么拆**

path 路 + finder〔find + -er〕，构成人物名。军事或探险等领域可能有专门角色，但基本画面仍是先找路。

**怎么变成今天的意思**

**古英语 pæþ → 中古英语 path、peth → path**  
路、足迹踩出的通道；更远来源有争议

↓

**英语 path**  
小路、行进轨迹；行动途径、文件位置等

↓

**path + finder → pathfinder**  
找到通路的人；方法开拓者

a skilled pathfinder 熟练探路者，a scientific pathfinder 科学开拓者，act as a pathfinder 充当探路者。

**常见搭配与例句**

a skilled pathfinder；a scientific pathfinder；act as a pathfinder。

> The pathfinder checked the route before the group moved on.

探路者先检查路线，队伍才继续前进。

> The researcher became a pathfinder in the new field.

那位研究者成了新领域的开拓者。

**别混淆**

pathfinder 开辟、找到路者，follower 跟随者；大写 Pathfinder 还可专名，不能凭词就推定具体产品。

<a id="w-4"></a>

### 5. footpath — 步行小径；人行道

**音标**：英 /ˈfʊtpɑːθ/；美 /ˈfʊtpæθ/

**先抓住这个画面**

留给人用脚走的路径，不以车辆通行为核心。

**怎么拆**

foot 步行 + path 小路，构成步行路线名；具体是否有铺装、位于城市还是郊外，看当地用法。

**怎么变成今天的意思**

**foot 步行；path 小路**  
并列构词部分

↓

**footpath**  
供人步行的路径

a public footpath 公共步行小径；a footpath through the woods 林间小径。某些地区也用它说街道旁的人行道。

**常见搭配与例句**

follow a footpath；a woodland footpath；a public footpath。

> A narrow footpath leads through the woods.

一条窄小步道通进树林。

> We followed the footpath beside the river.

我们沿河边步道走。

**别混淆**

footpath 不必泥土路，sidewalk 在美式常说街旁人行道；名称不是跨地区完全统一的地图符号。

<a id="w-5"></a>

### 6. warpath — 征战之路；盛怒找人算账的状态〔习语〕

**音标**：英 /ˈwɔːpɑːθ/；美 /ˈwɔːrpæθ/

**先抓住这个画面**

像已经踏上开战的路，今天 on the warpath 常说某人怒气冲冲，准备追责。

**怎么拆**

war + path（路）；字面战争路径，在历史美洲原住民相关英语叙述中有特定使用背景，现代常见于夸张习语。

**怎么变成今天的意思**

**war；path**  
并列构词成分

↓

**warpath**  
通向征战的路 → 盛怒、准备找人算账

be on the warpath 大发雷霆、准备找人算账。多是非正式夸张，不表示说话者掌握真正军事行动。

**常见搭配与例句**

be on the warpath；on the warpath about；put someone on the warpath。

> The manager was on the warpath after another missed deadline.

再次误了截止时间后，经理怒气冲冲准备追责。

> She is on the warpath about the missing documents.

文件不见了，她正火冒三丈要找人算账。

**别混淆**

on the warpath 形容盛怒态度，at war 才可说处于战争状态；不要把办公室习语当实战描述。

<a id="w-6"></a>

### 7. towpath — 纤道、运河岸牵船路

**音标**：英 /ˈtəʊpɑːθ/；美 /ˈtoʊpæθ/

**先抓住这个画面**

过去人或马在岸上沿路走，用绳子牵着船前进；这条岸路就是 towpath。今天有些成了散步、骑行道。

**怎么拆**

tow 拖、牵引 + path 小路，按牵船用途命名。不是 toe 脚趾 + path。

**怎么变成今天的意思**

**古英语 pæþ → 中古英语 path、peth → path**  
路、足迹踩出的通道；更远来源有争议

↓

**英语 path**  
小路、行进轨迹；行动途径、文件位置等

↓

**tow + path → towpath**  
沿水道岸边供牵船用的路

a canal towpath 运河纤道，walk along the towpath 沿纤道走，a restored towpath 修复的纤道。

**常见搭配与例句**

a canal towpath；along the towpath；a restored towpath。

> We walked along the canal towpath.

我们沿运河纤道散步。

> The old towpath is now popular with cyclists.

旧纤道现在很受骑行者欢迎。

**别混淆**

towpath 特定历史用途岸路，footpath 步行小路更泛；不靠它今天是否还有马来决定名称。

<a id="w-8"></a>

### 8. filepath — 文件路径

**音标**：英 /ˈfaɪlpɑːθ/；美 /ˈfaɪlpæθ/

**先抓住这个画面**

要找文件，不仅要知道它叫什么，还要知道在哪一层文件夹里；指向那个位置的路线就是 filepath。

**怎么拆**

file 文件 + path 路径的英语组合。file 接文档、串列一支，path 接古英语 pæþ 路，数字义借位置路线。

**怎么变成今天的意思**

**file 的文档义；path 的路线义**  
文件与定位路线两项材料

↓

**file + path → filepath**  
指定文件所在位置的路径表达

a full filepath 完整文件路径；a relative filepath 相对文件路径。

**常见搭配与例句**

check the filepath 检查文件路径；enter a filepath 输入文件路径。

> The error message showed the full filepath.

错误信息显示了完整文件路径。

> She copied the filepath into her notes.

她把文件路径复制进笔记。

**别混淆**

filename 偏文件本身的名字，filepath 还交代怎样定位它；实际书写规则由所在系统决定。

<a id="w-9"></a>

### 9. filepaths — 文件路径〔复数〕

**音标**：英 /ˈfaɪlpɑːðz/；美 /ˈfaɪlpæðz/ 或 /ˈfaɪlpæθs/

**先抓住这个画面**

几个文件各有自己的定位路线，这些路线叫 filepaths。可以指向不同文件夹、不同文件。

**怎么拆**

file + path → filepath，再加 -s。path 的复数有末音变 /ðz/ 与保留 /θs/ 的读法差异。

**怎么变成今天的意思**

**file + path → filepath**  
用路线信息定位文件

↓

**filepath + -s → filepaths**  
多个文件路径

absolute filepaths 绝对文件路径；relative filepaths 相对文件路径。

**常见搭配与例句**

a list of filepaths 文件路径列表；compare filepaths 比较文件路径。

> The report listed the filepaths of the missing images.

报告列出了缺失图片的文件路径。

> We checked the filepaths before moving the files.

移动文件前，我们核对了文件路径。

**别混淆**

两条路径字面不同，不足以单靠词义判断是否一定指向不同文件，具体定位要看实际系统。

## 这一组要分清什么

path/road/way 范围不同；towpath 历史牵船用途；pathfinder 人物，file path 可数字位置。

## 串起来练习

The pathfinder followed the towpath beside the canal.

探路者沿运河旁的纤道前进。
