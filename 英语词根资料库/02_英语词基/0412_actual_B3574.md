# 0412 · actual — 实际、真实存在

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

actual 经法语接晚期拉丁 actuālis，上接 actus、agere 的行动词族。今天重点抓真实、实际，不按同形法语硬译成当前。

**ACTUAL：把设想对上真正发生的事**

估计表写一百，结账是八十；actual cost 看结账的八十。

- **真实的情况**：actual
- **说清实情**：actually
- **实际存在的状态**：actuality

## 词形与演化规律

actual → actually；actual → actuality。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [actual](#w-2) | /ˈæktʃuəl/ | 实际的；真实的 |
| [actually](#w-1) | /ˈæktʃuəli/ | 实际上；其实；居然〔强调与预期不同〕 |
| [actuality](#w-3) | /ˌæktʃuˈæləti/ | 实际情况；真实存在的事物 |

## 逐词讲解

<a id="w-2"></a>

### 1. actual — 实际的；真实的

**音标**：/ˈæktʃuəl/

**先抓住这个画面**

宣传图是一回事，真正拿到手、量出来、发生过的那个才是 actual。

**怎么拆**

经法语 actuel 接晚期拉丁 actuālis，再接 actus、agere“做、行动”。现代可认出 act 的词源联系，不拆成 act + u + al 三个现代部件。

**怎么变成今天的意思**

**拉丁 agere → actus → 晚期拉丁 actuālis**  
做、行动 → 行为、实施 → 实践中的

↓

**法语 actuel → 中古英语 actual**  
实际、真实的相应用法

the actual cost 是实际费用，the actual size 是实物大小，the actual reason 强调真正原因。actual 在现代英语里通常不表示“目前的”，那往往用 current。

**常见搭配与例句**

the actual cost；actual size；the actual number；actual experience。

> The actual cost was lower than we expected.

实际费用比我们预计的低。

> The model is shown at actual size.

模型按实物大小展示。

**别混淆**

actual 与 real 都可强调真实；actual 常拿实情对照估计、想象。法语 actuel 常有“当前”义，不能直接搬进英语。

<a id="w-1"></a>

### 2. actually — 实际上；其实；居然〔强调与预期不同〕

**音标**：/ˈæktʃuəli/

**先抓住这个画面**

听起来像这样，可把真实情况摊开看，原来是另一回事。

**怎么拆**

actual + -ly；常见口语弱化读音 /ˈæktʃəli/。这里 -ly 接整个 actual，不要误认成 act + ually。

**怎么变成今天的意思**

**拉丁 agere → actus → 晚期拉丁 actuālis**  
做、行动 → 行为、实施 → 实践中的

↓

**法语 actuel → 中古英语 actual**  
实际、真实的相应用法

↓

**actual + -ly → actually**  
按实际情况来说

Actually, I live nearby 可以温和纠正对方；Did he actually say that? 强调难以相信他真说了。语气用太重也可能显得居高临下，日常按上下文用。

**常见搭配与例句**

actually happen；actually mean；actually work；Actually, ...。

> I thought the shop was closed, but it was actually open.

我以为商店关门了，其实还开着。

> Actually, I have already read the report.

其实，这份报告我已经看过了。

**别混淆**

actually 说实情，不是 currently“目前”。I actually work here 是“我其实就在这里工作”，不是专门交代现在这个时段。

<a id="w-3"></a>

### 3. actuality — 实际情况；真实存在的事物

**音标**：/ˌæktʃuˈæləti/

**先抓住这个画面**

把想象、可能性放一边，已经确实存在的现实摆到面前。

**怎么拆**

actual + -ity，-ity 表性质、状态；重音落在 /ˈæ/ 上，不沿用 actual 的词首重音。

**怎么变成今天的意思**

**拉丁 agere → actus → 晚期拉丁 actuālis**  
做、行动 → 行为、实施 → 实践中的

↓

**法语 actuel → 中古英语 actual**  
实际、真实的相应用法

↓

**actual + -ity → actuality**  
实际存在；实际状况

in actuality 较正式，相当于“实际上”；turn a possibility into an actuality 是把可能变为现实。普通交流里 reality、in fact 往往更自然。

**常见搭配与例句**

in actuality；become an actuality；possibility and actuality。

> The journey looked short on the map, but in actuality it took six hours.

地图上路程看着不长，实际上走了六小时。

> What was once a distant possibility is now an actuality.

从前遥远的可能，如今已成为现实。

**别混淆**

actuality 侧重确实实现、存在的状态，possibility 是可能；actuality 不等于 current affairs 时事。

## 这一组要分清什么

actual 实际，current 当前；actually 其实，currently 目前；actuality 比日常 reality 更正式。

## 串起来练习

The actual result was better than expected; actually, it was our best result so far.

实际结果比预期好；其实，这还是我们迄今最好的成绩。
