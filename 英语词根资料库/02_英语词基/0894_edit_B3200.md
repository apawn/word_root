# 0894 · edit — 整理、修改文本与素材，形成可发布或可用的版本

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

现代构词可以帮助记忆，历史顺序则要另说。edit 的直接英语来历是从 editor 逆构，不能只按长短猜先后。

**EDIT：把现成内容整理、改成合用的样子**

edit → editable；editor 是历史上先出现的人物名称。

- **编辑动作与可编辑性质**：edit · editable
- **人物、版本与编辑相关**：editor · edition · editorial
- **edition → editions：拿出来发表的版本**：edition · editions

## 词形与演化规律

拉丁出版相关形式 → editor → 逆构 edit；-able 可编辑；edition、editorial 是同族相关词。

拉丁 editio 的借入早于现代英语 edit，不能倒着画成英语 edit 加 ion。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [edit](#w-1) | /ˈedɪt/ | 编辑、修改；剪辑；编辑改动、剪辑版本 |
| [edition](#w-3) | /ɪˈdɪʃən/ | 版、版本；〔报刊〕期；一次播出的节目版本 |
| [editions](#w-6) | /ɪˈdɪʃənz/ | 版本、版次；一期、某次发行〔复数〕 |
| [editor](#w-4) | 英 /ˈedɪtə/；美 /ˈedɪtər/ | 编辑、主编；编辑器 |
| [editorial](#w-5) | 英 /ˌedɪˈtɔːriəl/；美 /ˌedɪˈtɔːriəl/ | 编辑的、编务的；社论 |
| [editable](#w-2) | /ˈedɪtəbəl/ | 可编辑、可修改的 |

## 逐词讲解

<a id="w-1"></a>

### 1. edit — 编辑、修改；剪辑；编辑改动、剪辑版本

**音标**：/ˈedɪt/

**先抓住这个画面**

原稿或素材放在那里，你修改内容、安排顺序、剪掉不需要的部分，让它适合使用，这个过程是 edit。

**怎么拆**

英语从 editor 逆构出 edit，也受法语 éditer、拉丁 editus 等影响。今天可以按 edit → editor 学构词，但真实出现顺序不能直接倒过来讲。

**怎么变成今天的意思**

**拉丁 ēdere、ēditus 等出版相关形式 → editor**  
把作品刊出、整理出版的人

↓

**editor → edit〔逆构〕**  
英语从较长的人物名称取出动词，也受法语 éditer 影响

edit a document 修改文档，edit a video 剪辑视频，edit a magazine 担任杂志编辑，make an edit 作一次编辑改动。

**常见搭配与例句**

edit a document；edit a video；make an edit。

> Please edit the introduction to make it clearer.

请修改引言，让意思更清楚。

> He edited the footage into a short film.

他把素材剪成一部短片。

**别混淆**

edit 可改内容、结构、语言或素材顺序；proofread 更集中检查文字差错。一次 edit 也可能是一个剪辑版本。

<a id="w-3"></a>

### 2. edition — 版、版本；〔报刊〕期；一次播出的节目版本

**音标**：/ɪˈdɪʃən/

**先抓住这个画面**

把一份内容按某次形式推出去，就是一个 edition。可能是书改版，也可能是今天这一期报纸。

**怎么拆**

经法语 édition 或直接拉丁语 ēditiōn-，接 ēdere 出版、拿出来。英语 edition 早于现代 edit，不能画成较晚英语 edit 加 -ion 生出较早 edition。

**怎么变成今天的意思**

**拉丁语 ēdere → ēditiō、ēditiōnem**  
拿出来、出版 → 出版、推出之物

↓

**法语 édition → 英语 edition**  
作品版本；一期刊物、一次新闻节目等

the first edition 第一版，a revised edition 修订版，today’s edition 今日这一期，the evening edition 晚报版、晚间节目。

**常见搭配与例句**

a revised edition；the first edition；today’s edition；a limited edition。

> The revised edition includes a new chapter.

修订版新增了一章。

> I read the interview in today’s edition of the paper.

我在今天的报纸上读了那篇访谈。

**别混淆**

edition 一种出版版本、一期内容，copy 一份实物；第一版可以印很多 copies。edition 与 addition 增加不是同词。

<a id="w-6"></a>

### 3. editions — 版本、版次；一期、某次发行〔复数〕

**音标**：/ɪˈdɪʃənz/

**先抓住这个画面**

作品以某种编排、内容状态推出的一版，是 edition；不同推出版本或期次可叫 editions。

**怎么拆**

edition 经法语或直接借拉丁 editio，接 edere 拿出来、发表；英语词早于现代 edit。整词加 -s，/n/ 后读 /z/。

**怎么变成今天的意思**

**拉丁 edere → editio → edition**  
拿出来发表；发行、版本

↓

**edition + -s → editions**  
多个版本、版次、期次

revised editions 修订版；first editions 初版书。

**常见搭配与例句**

compare editions 比较版本；later editions 后来的版本。

> The library has several editions of the dictionary.

图书馆有这部词典的几个版本。

> The collector specialises in first editions.

这位收藏者专门收藏初版书。

**别混淆**

edition 和 edit 同族，但不是较晚的英语 edit 临时添 ion 造出较早的 edition。

<a id="w-4"></a>

### 4. editor — 编辑、主编；编辑器

**音标**：英 /ˈedɪtə/；美 /ˈedɪtər/

**先抓住这个画面**

把原始稿件、素材整理到能给读者或观众看的状态；具体可审稿、改文字、选内容、统筹，不只是捡错别字。软件帮你编辑内容，也叫 editor。

**怎么拆**

借拉丁 ēditor 发布者，接 ēdere 给出、发布的分词词干。英语 editor 早于现代 edit 的常见动词用法，不能把借入史倒画成先有英语 edit 再添 -or 的唯一路线。

**怎么变成今天的意思**

**拉丁 ēdere〔给出、发布〕→ ēditor → 英语 editor**  
发布、把作品推出去的人

↓

**英语 editor 的工作扩展**  
编辑文本、统筹内容；也可编辑软件

a newspaper editor 报纸编辑，a book editor 图书编辑，a video editor 视频剪辑者或编辑器，a text editor 文本编辑器。

**常见搭配与例句**

a newspaper editor；a book editor；a video editor；a text editor。

> The editor suggested a clearer opening paragraph.

编辑建议把开头一段写得更清楚。

> Open the file in a text editor.

用文本编辑器打开文件。

**别混淆**

editor 编辑，author 作者；一人可兼任但工作角色不同。edition 版本与 editor 同属发布词族，不是编辑人数的复数。

<a id="w-5"></a>

### 5. editorial — 编辑的、编务的；社论

**音标**：英 /ˌedɪˈtɔːriəl/；美 /ˌedɪˈtɔːriəl/

**先抓住这个画面**

editorial team 是做内容编辑的一组人；an editorial 则是表达报刊立场、观点的评论文章。不是所有被编辑过的文章都自动是社论。

**怎么拆**

editor + -ial，先形成与编辑有关的形容词；名词从相关评论文章用法发展。重音移到 -tor- 部分。

**怎么变成今天的意思**

**拉丁 ēdere〔给出、发布〕→ ēditor → 英语 editor**  
发布、把作品推出去的人

↓

**editor + -ial → editorial〔形容词〕→ 社论名词**  
编务相关 → 编辑立场的评论文章

an editorial team 编辑团队，editorial policy 编辑方针，write an editorial 写社论，an editorial on education 关于教育的社论。

**常见搭配与例句**

an editorial team；editorial policy；write an editorial；an editorial on。

> The editorial team meets every Monday.

编辑团队每周一开会。

> The newspaper published an editorial on public transport.

报纸发表了一篇讨论公共交通的社论。

**别混淆**

editorial 社论常表达立场，news report 新闻报道以报道事实为主；editorial work 则是编务，不是每项工作都在写社论。

<a id="w-2"></a>

### 6. editable — 可编辑、可修改的

**音标**：/ˈedɪtəbəl/

**先抓住这个画面**

文件里的文字、表格能直接改动，便是 editable；截图上看得到字，却未必能像原文档一样编辑。

**怎么拆**

edit + -able，表示能够接受编辑的性质。

**怎么变成今天的意思**

**拉丁 ēdere、ēditus 等出版相关形式 → editor**  
把作品刊出、整理出版的人

↓

**editor → edit〔逆构〕**  
英语从较长的人物名称取出动词，也受法语 éditer 影响

↓

**edit + -able → editable**  
能够编辑、修改的

an editable file 可编辑文件，editable text 可编辑文字，an editable template 可编辑模板。

**常见搭配与例句**

an editable file；editable text；an editable template。

> Please send an editable version of the document.

请发送可编辑版本的文档。

> The names are editable, but the logo is fixed.

名称可以修改，但标志是固定的。

**别混淆**

editable 说能否编辑，readable 说能否读取、读懂。文件可读，不表示有编辑权限或内容结构方便改。

## 这一组要分清什么

edit 比校对范围广；editable 与 readable 不同；词短不保证历史更早。

## 串起来练习

The editor asked for an editable file so she could edit the introduction.

编辑要了一个可编辑文件，以便修改引言。
