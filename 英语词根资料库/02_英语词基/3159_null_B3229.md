# 3159 · null — 无效；空值；使无效

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

null 接拉丁 nullus 没有一个一支。nullify 是使无效，nullification 是这一动作；计算机中的 null 又有按语言、系统定义的专门含义。

**NULL：没有有效内容或不具成立效力**

一份决定可以被判无效，数据字段也可能没有值。

- **无效或特殊空值**：null
- **使失效的动作**：nullify · nullification

## 词形与演化规律

null and void、nullify a decision、a null value；编程中的 null 不必等于数字零或空字符串。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. null — 无效的；空值的

**音标**：/nʌl/

**先抓住这个画面**

原来该起作用的东西，在这里不算数；技术语境也可表示没有值。

**怎么拆**

借法语 nul，接拉丁 nūllus“没有任何”。这不是把英语 no 和某个后缀拼起来。

**怎么变成今天的意思**

**拉丁 nūllus〔没有任何；无〕**  
把某物看成没有、算不上

↓

**法语 nul → 英语 null**  
先用于不具有效力，后扩展到数量及技术语境

a null agreement 是无效的协议；代码中的 null 则常用来表示“这里没有对象或值”。例如 JavaScript 的 null 是一个特定的空值，不是数字 0，也不是空字符串。两种语境都能联系“没有”，但具体规则不能混用。

**常见搭配与例句**

null and void；a null value；return null。

> The agreement was declared null and void.

这份协议被宣布无效。

> The function returns null when it cannot find a matching user.

找不到匹配用户时，这个函数返回 null。

**别混淆**

zero 是数值零；null 常表示缺少值或对象。法律表达 null and void 中两个词加强同一意思：不具有效力。

<a id="w-2"></a>

### 2. nullify — 使无效；抵消

**音标**：/ˈnʌlɪfaɪ/

**先抓住这个画面**

原本存在的效力或优势，被另一件事抹掉。

**怎么拆**

有后期拉丁 nullificāre 借入分析，组成是 nūllus 无 + facere 做、使；现代也常按 null + -ify“使成为”理解。

**怎么变成今天的意思**

**拉丁 nūllus〔没有任何；无〕**  
把某物看成没有、算不上

↓

**后期拉丁 nullificāre〔使归于无〕**  
由 nullus 与 facere 的组合形成

↓

**英语 nullify**  
使规则、决定或实际效果失去作用

它既能用于正式规则，也能用于生活中的效果：折扣省下的钱全被运费吃掉，运费就 nullifies the saving。重点不是事物消失，而是它产生的作用被抵消了。

**常见搭配与例句**

nullify a decision；nullify an advantage；nullify the effect of something。

> The extra delivery charge nullified the saving from the discount.

额外运费抵消了折扣省下的钱。

> The court nullified the disputed decision.

法院宣布那项有争议的决定无效。

**别混淆**

annul 常强调正式宣布无效；nullify 也能说没有正式程序的实际抵消。

<a id="w-3"></a>

### 3. nullification — 使无效；废止；抵消

**音标**：/ˌnʌlɪfɪˈkeɪʃən/

**先抓住这个画面**

把“让它不再起作用”这件事作为一个名词来谈。

**怎么拆**

借后期拉丁 nullificātiō，接 nullificāre 使归于无。现代对应 nullify → nullification 的动名词变化，但历史名词本身有拉丁借入路线。

**怎么变成今天的意思**

**拉丁 nūllus〔没有任何；无〕**  
把某物看成没有、算不上

↓

**后期拉丁 nullificāre → nullificātiō**  
使归于无 → 这个行为或结果

↓

**英语 nullification**  
使某物失效；在政治与法律中也有专门用法

读到 the nullification of the result，就把它展开为“让这个结果失效”。比 cancellation 更正式，常用于评论一项结果、决定或规则如何被取消效力。历史上的政治专名用法，还要结合具体背景理解。

**常见搭配与例句**

the nullification of an election result；the nullification of a decision。

> The report called for the nullification of the disputed result.

报告呼吁宣布那个有争议的结果无效。

> The novel ends with the nullification of the king’s decree.

小说以国王法令被废止而告终。

**别混淆**

nullity 偏向无效状态，nullification 偏向使它无效的行为或结果。

## 这一组要分清什么

zero 是数值零，null 往往表示没有值等状态，不能不看系统规则就互换。

## 串起来练习

The missing field contains null, while a separate field contains zero.

缺失字段包含 null，另一个字段则包含零。
