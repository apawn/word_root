# 3404 · duplicate — 做出同样一份，从复制动作到副本与重复性质

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

先分 duplicate 名词、形容词、动词，再看 duplicative 描述重复、重叠性质。别把它误读成有欺骗性的 duplicitous。

**DUPLICATE：同样的东西，又来一份**

duplicate → duplicative，副本可以有用，重复劳动则常可合并。

- **副本、复制与重复性质**：duplicate · duplicative

## 词形与演化规律

拉丁 duplic- 两重、duplicare 使成双 → duplicate；-ive 性质。duplicate 名、形末尾 /kət/，动词末尾 /keɪt/。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [duplicate](#w-1) | 英：名、形 /ˈdjuːplɪkət/，动 /ˈdjuːplɪkeɪt/；美：名、形 /ˈduːplɪkət/，动 /ˈduːplɪkeɪt/ | 副本；完全相同的；复制、重复 |
| [duplicative](#w-3) | 美 /ˈduːpləˌkeɪtɪv/〔亦有其他读法〕 | 重复的、工作重叠的；可复制的 |

## 逐词讲解

<a id="w-1"></a>

### 1. duplicate — 副本；完全相同的；复制、重复

**音标**：英：名、形 /ˈdjuːplɪkət/，动 /ˈdjuːplɪkeɪt/；美：名、形 /ˈduːplɪkət/，动 /ˈduːplɪkeɪt/

**先抓住这个画面**

同样的东西又有一份。可以是有用的备用件，也可能是误存的重复记录。

**怎么拆**

来自拉丁语 duplicatus，基于 duplicare“使成双”；形容词、名词与动词发展成不同用法和词尾读音。

**怎么变成今天的意思**

**拉丁语 duplex / duplic-**  
两重、双倍；duo“二”与表示折、重的成分相合

↓

**拉丁语 duplicare / duplicatus**  
使成双、加倍

↓

**拉丁语 duplicatus → 英语 duplicate**  
双重的 → 相同副本；复制

a duplicate key 是配出的同样钥匙；duplicate work 是重复劳动。动词末尾读 /keɪt/，名词、形容词末尾读 /kət/。

**常见搭配与例句**

a duplicate copy；duplicate a file；remove duplicates。

> Keep a duplicate key somewhere safe.

把一把备用钥匙放在安全的地方。

> The software flags records that duplicate existing entries.

软件会标出与已有条目重复的记录。

**别混淆**

copy 最宽泛；duplicate 常强调与已有对象相同，尤其在系统里辨认重复项。

<a id="w-3"></a>

### 2. duplicative — 重复的、工作重叠的；可复制的

**音标**：美 /ˈduːpləˌkeɪtɪv/〔亦有其他读法〕

**先抓住这个画面**

两个部门各填一遍内容相同的表、各查一遍同一件事，这些工作就是 duplicative：又做了一份。

**怎么拆**

duplicate + -ive，去末尾 e。duplicate 接拉丁 duplicare 使成双；-ive 在这里形成性质词，常用于重复工作、流程。

**怎么变成今天的意思**

**拉丁 duplic- 两重 → duplicare、duplicatus**  
使成双、加倍

↓

**英语 duplicate + -ive → duplicative**  
能复制的；具有重复、重叠性质的

duplicative work 重复劳动；duplicative procedures 重叠流程；duplicative requests 重复请求。正式语境常暗含可以省掉重复部分，但不表示所有副本都没用。

**常见搭配与例句**

duplicative work；duplicative procedures；avoid duplicative effort。

> A shared database can reduce duplicative work.

共享数据库可以减少重复劳动。

> The review found that the two checks were largely duplicative.

审查发现两项检查的内容大体重复。

**别混淆**

duplicitous 是两面派、欺骗性的，duplicative 是重复的；两个词都接双重材料，现代评价对象不同。

## 这一组要分清什么

duplicative 重复、重叠；duplicitous 表里不一。保留备用副本，不必等于做无用功。

## 串起来练习

Keep a duplicate key, but remove duplicative steps from the process.

留一把备用钥匙，同时去掉流程里的重复步骤。
