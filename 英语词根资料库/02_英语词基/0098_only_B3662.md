# 0098 · only — 唯一；把范围限定在某一项

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

only 源于古英语 ānlīċ、ǣnlīċ，经过中古英语 oonly、only。现代可用 one + -ly 理解关联，但 one 与 only 的读音各有历史，不把现代字母拆分当成完整演变。

**ONLY：圈出这一项，其余不算在内**

一串钥匙里只有这一把开得了门；桌上不是很多钱，而是仅剩五元。

- **唯一与范围限制**：only

## 词形与演化规律

这一词基没有需要硬凑的常用无连字符扩展，重点讲好 only 本身：形容词“唯一的”和副词“只、才”都在缩小范围。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. only — 唯一的；只；仅仅；才

**音标**：英 /ˈəʊnli/；美 /ˈoʊnli/

**先抓住这个画面**

把范围缩小：不是一群人，只这一个；不是更多钱，只这么多。

**怎么拆**

接古英语 ānlīċ、ǣnlīċ，经中古英语 oonly、only 延续；现代可对照 on(e) + -ly，但它不是今天才拿 one /wʌn/ 新拼出来，所以读音不能机械相加。

**怎么变成今天的意思**

**古英语 ānlīċ / ǣnlīċ**  
独一的、单独的；与 one 对应的古形式有关

↓

**中古英语 oonly / only → 英语 only**  
唯一的；只、仅仅

the only key 是唯一的钥匙；only five minutes 是只有五分钟；only then 是直到那时才。位置影响限制范围：Only I called 是只有我打了电话，I called only Tom 是我只给汤姆打了电话。

**常见搭配与例句**

the only one；an only child；only once；only then；if only。

> This is the only key that opens the door.

这是唯一能打开这扇门的钥匙。

> I called only Tom, not the rest of the team.

我只给汤姆打了电话，没有给团队其他人打。

> She was only five when she learned to swim.

她学会游泳时才五岁。

**别混淆**

only child 是独生子女，不是 lonely child“孤独的孩子”。alone 强调独自，lonely 强调感到孤独，only 强调范围没有其他项。

## 这一组要分清什么

only child 是独生子女，lonely child 才是感到孤独的孩子；only 的位置和语气共同决定排除了什么。

## 串起来练习

Only Mia had the only key to the cupboard.

只有米娅拿着那把唯一能打开柜子的钥匙。
