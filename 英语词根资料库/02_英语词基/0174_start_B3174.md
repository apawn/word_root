# 0174 · start — 突然动起；开始、启动

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

start 接古英语 styrtan、经中古英语 sterten 的跃起、冲出义。startle 有相关古英语形式，保留突然惊动的感觉，不能只按现代开始义硬拆。

**START：从静止或尚未进行，到突然动起来**

人惊跳、车发动、计划开工，都抓住开始动的那一下。

- **开始与启动**：start · starter · restart · startup
- **突然崛起的人**：upstart
- **受惊动作与引发惊讶**：startle · startling
- **start → started：开始、启动了**：start · started
- **start → started／starting：开始的过去与进行形式**：start · starting
- **start → starts：启动与起点**：start · starts
- **restart 的重新起步与 startup 的起步名词**：restart · restarts · restarted · restarting · startup · startups

## 词形与演化规律

start → starter、restart、startup；upstart 调换构词方向，另成冒头者；startle → startling。

start 原有突然跃起的动作义；started 的词尾增加 /ɪd/ 一个音节。

starting 不双写末尾 t；starting point 是起点，starting to do 可说开始做。

突然一动的早期画面，发展到活动开始。

restart 是 re 加 start；startup 来自 start up，不把两种构词次序混为一条。

## 逐词讲解

<a id="w-1"></a>

### 1. start — 开始；启动；惊跳；开端

**音标**：英 /stɑːt/；美 /stɑːrt/

**先抓住这个画面**

原来静着，忽然动了起来：人一惊跳起，机器运转起来，一件事也从零开始。

**怎么拆**

接古英语 styrtan，经中古英语 sterten，早有突然跃起、冲出的意思。名词 start 与动词相连，不拆成 star“星”加 t。

**怎么变成今天的意思**

**古英语 styrtan → 中古英语 sterten**  
突然跃起、冲出

↓

**英语 start**  
惊动、突然一动；开始、启动

start the car 是启动车，start doing 是开始做。with a start 是一惊、猛地一动，保留较直观的旧动作感觉。at the start 是在开头。

**常见搭配与例句**

start doing；start with；make a start；with a start；from the start。

> We need to start planning now.

我们现在得开始计划了。

> She woke with a start when the door slammed.

门砰地关上，她惊醒了。

**别混淆**

start 与 begin 在开始做事时常能换；启动设备通常说 start the engine，不能照搬为 begin the engine。

<a id="w-8"></a>

### 2. started — 开始了；启动了；惊跳了一下；start 的过去式和过去分词

**音标**：英 /ˈstɑːtɪd/；美 /ˈstɑːrtɪd/

**先抓住这个画面**

原来还没动，一下进入了行动：课开讲了，车发动了，人受惊一跳，都能接上 start 原来的动作画面。

**怎么拆**

start + -ed；原词以 /t/ 收尾，-ed 读 /ɪd/，所以多一个音节。接古英语 styrtan、中古英语 sterten 的突然跃起、冲出词族。

**怎么变成今天的意思**

**古英语 styrtan → 中古英语 sterten → start**  
突然跃起、冲出 → 开始、启动

↓

**start + -ed → started**  
过去开始、启动；受惊而动

started doing／started to do 开始做；started with ... 从……开始；started the engine 启动发动机；got started 开始动手。

**常见搭配与例句**

started raining；started a new job。

> It started raining just as we reached the station.

我们刚到车站，天就开始下雨了。

> Once we got started, the task felt much easier.

一旦动起手来，这项任务就感觉容易多了。

**别混淆**

The meeting started 说会议开始；We started the meeting 说我们让会议开始。had started 则把开始放在另一个过去事件之前。

<a id="w-9"></a>

### 3. starting — 正在开始、启动；开始时的；start 的 -ing 形式

**音标**：英 /ˈstɑːtɪŋ/；美 /ˈstɑːrtɪŋ/

**先抓住这个画面**

事情刚从还没做跨到动手做，就是 starting。用它修饰 point、salary 等名词时，常标出开始时的位置或数值。

**怎么拆**

start + -ing，直接拼接，不双写 t；原词末尾是 rt 两个辅音字母，不双写 t。start 接古英语 styrtan 突然跃起等材料。

**怎么变成今天的意思**

**古英语 styrtan → 中古英语 sterten → start**  
突然跃起、冲出 → 开始、启动

↓

**start + -ing → starting**  
开始中的动作；起始位置或条件

starting now 从现在开始；starting point 起点；starting salary 起薪；starting to understand 开始理解；starting from ... 从……起。

**常见搭配与例句**

starting a new job；the starting line。

> I am starting to understand how the pieces fit together.

我开始明白这些部分是怎样配合起来的了。

> This example is a useful starting point for the discussion.

这个例子很适合作为讨论的起点。

**别混淆**

starting a car 是启动车，a starting point 是用作起点的位置或思路。starting 修饰名词时不一定说某个物体正在开始，它也可以指出起始阶段。

<a id="w-10"></a>

### 4. starts — 开始；启动；起点、开端〔复数〕；突然惊动

**音标**：英 /stɑːts/；美 /stɑːrts/

**先抓住这个画面**

一件原本没动起来的事开始动了，是 starts；回头数一次次开头，也可说 starts。

**怎么拆**

start + -s，/t/ 后读 /s/。start 接古英语 styrtan 的突然跃起、冲出，经中古英语 sterten 延续；从突然一动发展到开始、启动。

**怎么变成今天的意思**

**古英语 styrtan → 中古英语 sterten → start**  
突然跃起、一动 → 开始

↓

**start + -s → starts**  
单数主语开始；多次开端

starts work 开始工作；starts raining 开始下雨；starts the engine 启动引擎；false starts 抢跑，也比喻失败的开头。

**常见搭配与例句**

starts at nine；starts with a question。

> The film starts at half past seven.

电影七点半开始。

> After several false starts, we found a method that worked.

几次尝试开头都不顺之后，我们找到了有效的方法。

**别混淆**

start doing 和 start to do 都常表示开始做。starts at 多接时间、起点，starts with 多接第一个内容。名词 a start 可以说一个开头或惊跳一下。

<a id="w-2"></a>

### 5. starter — 起动装置；开胃菜〔尤英式〕；起步者、先发者

**音标**：英 /ˈstɑːtə/；美 /ˈstɑːrtər/

**先抓住这个画面**

先让后面的事情开起来：先吃的一道菜、让发动机起动的部件、首先出场的人。

**怎么拆**

start + -er，-er 可表人或用具。不同义项都抓开始的角色，不等于只有刚学英语的新手。

**怎么变成今天的意思**

**古英语 styrtan → 中古英语 sterten**  
突然跃起、冲出

↓

**英语 start**  
惊动、突然一动；开始、启动

↓

**start + -er → starter**  
开启某过程的人、物或先行部分

a starter motor 是起动机，have soup as a starter 是拿汤作前菜；a slow starter 可说起步慢的人。体育的 starter 可指发令者或先发选手，要看具体句子。

**常见搭配与例句**

a starter motor；a starter course；a slow starter；a conversation starter。

> We had soup as a starter.

我们先喝汤当开胃菜。

> The mechanic checked the starter motor.

修理工检查了起动机。

**别混淆**

starter 前菜与 dessert 甜点分处餐程前后；starter motor 起动发动机，不是整台发动机本身。

<a id="w-5"></a>

### 6. startle — 使吃一惊；使惊跳

**音标**：英 /ˈstɑːtəl/；美 /ˈstɑːrtəl/

**先抓住这个画面**

安静看书时背后突然一响，身体先抖一下，脑子才反应过来。

**怎么拆**

中古英语 startlen、stertlen 接古英语 steartlian“踢动、挣扎、绊动”等，与 start 词族相连；现代形态可对照 start + -le，不是英语 begin 新加后缀。

**怎么变成今天的意思**

**古英语 steartlian → 中古英语 startlen / stertlen**  
突然动作、惊动的相关形式

↓

**英语 startle**  
使突然受惊、惊跳

startle someone 是使某人一惊，be startled by a noise 是被声响吓一跳。强调突然性，不一定长时间恐惧。

**常见搭配与例句**

startle someone；be startled by；a startled look。

> The sudden knock startled me.

突然的敲门声吓了我一跳。

> Try not to startle the sleeping cat.

尽量别惊着睡觉的猫。

**别混淆**

startle 突然惊一下，frighten 使害怕可以持续；surprise 范围更宽，惊喜也可，不一定身体一颤。

<a id="w-7"></a>

### 7. startling — 令人吃惊的；惊人的

**音标**：英 /ˈstɑːtlɪŋ/；美 /ˈstɑːrtlɪŋ/

**先抓住这个画面**

消息、变化或反差突然撞进眼里，让人忍不住“啊？”一下。

**怎么拆**

startle + -ing，去掉末尾不发音 e；分词形容词描写引起惊讶的那一方。

**怎么变成今天的意思**

**startle**  
使突然吃惊

↓

**startle + -ing → startling**  
令人惊讶的

a startling discovery 是惊人的发现，a startling contrast 是出人意料的鲜明反差。未必是坏事，也可以惊艳。

**常见搭配与例句**

a startling discovery；a startling contrast；startling results。

> The report revealed a startling increase in demand.

报告显示需求出现了惊人的增长。

> There was a startling contrast between the two rooms.

两个房间之间的反差令人吃惊。

**别混淆**

startling 令人吃惊，startled 是感到惊讶。The news was startling；I was startled。

<a id="w-3"></a>

### 8. restart — 重新开始；重启

**音标**：动词英 /ˌriːˈstɑːt/、美 /ˌriːˈstɑːrt/；名词英 /ˈriːstɑːt/、美 /ˈriːstɑːrt/

**先抓住这个画面**

原来的运行停了，重新让它动起来。

**怎么拆**

re-（再次）+ start。名词和动词常有重音差别，实际口音也有变化。

**怎么变成今天的意思**

**古英语 styrtan → 中古英语 sterten**  
突然跃起、冲出

↓

**英语 start**  
惊动、突然一动；开始、启动

↓

**re- + start → restart**  
再次启动、开始

restart a computer 是重启电脑，restart talks 是重启谈判。可以有原内容延续，不必从所有资料清零开始。

**常见搭配与例句**

restart the computer；restart the engine；restart talks；after a restart。

> Please save your work before restarting the computer.

重启电脑前，请保存工作。

> The two sides agreed to restart talks next week.

双方同意下周重启谈判。

**别混淆**

restart 是重新启动；reset 是重设、恢复某种设置。重启电脑不等于恢复出厂状态。

<a id="w-12"></a>

### 9. restarted — 重新开始、重新启动了

**音标**：英 /ˌriːˈstɑːtɪd/；美 /ˌriːˈstɑːrtɪd/

**先抓住这个画面**

已经停过的东西又开始运行、推进，是 restarted。可以是机器，也可以是暂停的活动。

**怎么拆**

restart + -ed，/t/ 后读 /ɪd/；re- 表再次。

**怎么变成今天的意思**

**re- + start → restart**  
重新开始、启动

↓

**restart + -ed → restarted**  
过去重新开始、重新启动

restarted the engine 重启了发动机；restarted the talks 重启了谈判。

**常见搭配与例句**

the game restarted 比赛重新开始了；restarted after a pause 暂停后重新开始。

> She restarted the engine after a short wait.

等了一会儿后，她重新启动发动机。

> The discussion restarted after lunch.

午饭后，讨论重新开始了。

**别混淆**

restarted 不必从零清空原有进展；中断后接着推进也可以用。

<a id="w-13"></a>

### 10. restarting — 正在重新开始、重启；重新开始的过程

**音标**：英 /ˌriːˈstɑːtɪŋ/；美 /ˌriːˈstɑːrtɪŋ/

**先抓住这个画面**

从停着的状态往再次运行过渡，正在发生时用 restarting。

**怎么拆**

restart + -ing，保留原拼写；基础词是 re- 再次 + start 开始。

**怎么变成今天的意思**

**re- + start → restart**  
再次开始、运行

↓

**restart + -ing → restarting**  
重新开始的过程或进行动作

restarting the computer 重启电脑；before restarting 重新开始前。

**常见搭配与例句**

restarting talks 重新展开谈判；the machine is restarting 机器正在重启。

> The machine is restarting now.

机器现在正在重启。

> Restarting the discussion helped us find a compromise.

重新展开讨论帮我们找到了折中办法。

**别混淆**

restarting 可以是不及物：机器自己正在重启；也可带宾语：某人正在重启机器。

<a id="w-14"></a>

### 11. restarts — 重新开始、重启〔第三人称单数〕；重启、重新开始〔复数〕

**音标**：动词英 /ˌriːˈstɑːts/、美 /ˌriːˈstɑːrts/；名词英 /ˈriːstɑːts/、美 /ˈriːstɑːrts/

**先抓住这个画面**

停下的运行、谈判又开始，是 restarts；把几次重新开始当成事件来数，也可用它。

**怎么拆**

re- 再次 + start 开始 → restart，再加 -s，/t/ 后读 /s/。

**怎么变成今天的意思**

**start 的开始义 + re- → restart**  
再次开始、启动

↓

**restart + -s → restarts**  
它重新开始；多次重新开始

restarts the engine 重新启动发动机；several restarts 几次重启。

**常见搭配与例句**

the race restarts 比赛重新开始；frequent restarts 频繁重启。

> The race restarts after the track is cleared.

赛道清理好后，比赛重新开始。

> The computer needed two restarts during the test.

测试期间，电脑需要重启两次。

**别混淆**

start 的旧词源与突然跃起、冲出有关；现代 restart 直接用已经固定的开始义，不用每次都想跳跃。

<a id="w-4"></a>

### 12. upstart — 骤然崛起者；自命不凡的新人；新贵〔常贬〕

**音标**：英 /ˈʌpstɑːt/；美 /ˈʌpstɑːrt/

**先抓住这个画面**

一个新人突然冒到前面，旧圈子觉得“你怎么也上来了”。

**怎么拆**

up + start，历史有中古英语 upstarten、upsterten 等突然起来的形式。人物义带对社会地位骤升或新人冒头的评价。

**怎么变成今天的意思**

**up；start〔跃起、突然起来〕**  
并列构词部分

↓

**upstart**  
突然冒头、常遭旧圈子轻视的人或组织

an arrogant upstart 常骂自大的新人，an upstart company 可是老企业眼中突然崛起的挑战者。被叫 upstart 不证明这个人实际没能力。

**常见搭配与例句**

an arrogant upstart；an upstart company；dismiss someone as an upstart。

> The established firms dismissed the small competitor as an upstart.

老牌公司把这家小对手看作冒头的新来者，不当回事。

> He was treated as an upstart by the old club members.

俱乐部老会员把他当成不懂规矩的新贵。

**别混淆**

upstart 带评价，newcomer 较中性；startup 是初创企业。不要把每家 startup 都译作傲慢的新贵。

<a id="w-6"></a>

### 13. startup — 初创企业；启动过程

**音标**：英 /ˈstɑːtʌp/；美 /ˈstɑːrtʌp/

**先抓住这个画面**

事业或设备刚从停着到运转起来，正在起步阶段。

**怎么拆**

由短语动词 start up 形成名词；常见另写 start-up，本页用不带连字符的词形作标题。

**怎么变成今天的意思**

**start；up〔开始运转的短语成分〕**  
并列构词部分

↓

**startup**  
启动；起步阶段的企业

a startup company 常指寻求发展、验证商业模式的初创公司，不必只做互联网。during startup 在设备文档里常说启动时。

**常见搭配与例句**

a startup company；join a startup；startup costs；during startup。

> She joined a startup developing tools for teachers.

她加入了一家为教师开发工具的初创公司。

> The screen stays blank for a few seconds during startup.

启动时，屏幕会黑几秒。

**别混淆**

startup 说初创企业或启动过程，upstart 常带新来者冒头、被轻视的评价；拼写顺序一换，态度也不同。

### 14. startups — 初创企业；启动过程、启动事件〔复数〕

**音标**：英 /ˈstɑːtʌps/；美 /ˈstɑːrtʌps/

**先抓住这个画面**

事业刚开始起步的公司，是 startups；设备的几次启动过程，也可用这个复数。

**怎么拆**

动词短语 start up 形成合写名词 startup，再加 -s，/p/ 后读 /s/。

**怎么变成今天的意思**

**start up → startup**  
启动过程；处于起步阶段的企业

↓

**startup + -s → startups**  
多家初创企业、多个启动事件

local startups 当地初创企业；technology startups 科技初创企业。

**常见搭配与例句**

support startups 支持初创企业；system startups 系统启动过程。

> The programme supports local startups.

这个项目支持当地初创企业。

> The log recorded three system startups that morning.

日志记下了那天上午的三次系统启动。

**别混淆**

startup 不要求公司只能做互联网业务；说的是初创、起步这个角度。

## 这一组要分清什么

startup 初创企业，upstart 常带轻视；restart 重启，reset 重设；startled 人受惊，startling 事物令人吃惊。

## 串起来练习

The startup restarted the test after a startling noise startled everyone.

一阵惊人的响声把大家吓了一跳后，这家初创公司重新开始测试。
