# 2132 · resource — 可利用的资源、提供资源与善用办法

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

有资源、给资源和会用资源是三层意思。人手紧缺时仍能足智多谋，但不能拿一句聪明解决所有资源缺口。

**RESOURCE：有东西可调用，还要安排到位**

resource → resourcing 配置；resourceful 善于想办法、利用可用条件。

- **资源、配置与能力**：resource · resourcing · resourceful

## 词形与演化规律

resource 名词转动词；resource + -ing → resourcing；resource + -ful → resourceful。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. resource — 资源；可利用的办法或资料；提供资源

**音标**：英 /rɪˈsɔːs/、/rɪˈzɔːs/；美 /ˈriːsɔːrs/、/rɪˈsɔːrs/

**先抓住这个画面**

遇到需要时，手边能拿来帮忙的东西：钱、时间、人手、资料，甚至解决难题的办法。

**怎么拆**

法语 ressource / 古法语 resourse，来自 resourdre“重新起来、恢复”，远源为拉丁语 resurgere。不是简单在现代 source 前加 re- 来表示“再找一次来源”。

**怎么变成今天的意思**

**拉丁语：regere**  
引导、使直；治理

↓

**拉丁语：sub- + regere → surrigere / surgere**  
从下向上挺起 → 升起

↓

**拉丁语：resurgere**  
re- 再次 + surgere → 再升起

↓

**古法语 resourdre → resourse**  
重新起来、恢复 → 可补充的来源

↓

**法语 → 英语 resource**  
可借助的办法、资源

natural resources 是自然资源；learning resources 是学习材料和工具。复数 resources 常强调可调配的总体条件，动词 resource 则是给某项工作配好人力物力。

**常见搭配与例句**

natural resources；limited resources；a useful resource for…。

> Time is the project’s most limited resource.

时间是这个项目最紧缺的资源。

> The website is a useful resource for language teachers.

这个网站对语言教师来说是很有用的资源。

> The programme must be properly resourced before it can expand.

这个项目必须先配足资源，才能扩大规模。

**别混淆**

source 主要回答从哪里来；resource 回答有什么可以拿来用。

<a id="w-2"></a>

### 2. resourceful — 足智多谋的；善于想办法的

**音标**：英 /rɪˈsɔːsfl/、/rɪˈzɔːsfl/；美 /rɪˈsɔːrsfl/

**先抓住这个画面**

工具不齐也不会干瞪眼，能把手边有限的东西凑成一个解决办法。

**怎么拆**

resource + -ful；这里 resource 包含可用的办法，不是单说钱多或矿产多。

**怎么变成今天的意思**

**拉丁语：regere**  
引导、使直；治理

↓

**拉丁语：sub- + regere → surrigere / surgere**  
从下向上挺起 → 升起

↓

**拉丁语：resurgere**  
re- 再次 + surgere → 再升起

↓

**古法语 resourdre → resourse**  
重新起来、恢复 → 可补充的来源

↓

**法语 → 英语 resource**  
可借助的办法、资源

↓

**英语：resource + -ful → resourceful**  
办法多；善于利用现有条件

通常是对人的赞美。一个人即使没有很多资源，也可以很 resourceful，因为他会找替代办法。

**常见搭配与例句**

a resourceful person；resourceful and practical。

> She is resourceful enough to repair the shelter with what she finds nearby.

她很会想办法，能用附近找来的东西修好棚屋。

> A resourceful teacher turned empty boxes into learning materials.

一位善于动脑筋的老师把空盒子变成了教学材料。

**别混淆**

wealthy 是有钱；resourceful 是会想办法，条件紧张时尤其能看出来。

<a id="w-3"></a>

### 3. resourcing — 资源配置、提供所需资源

**音标**：英 /rɪˈzɔːsɪŋ/；美 /ˈriːsɔːrsɪŋ/

**先抓住这个画面**

不只说有个好计划，还要给它人手、钱、设备和时间；把这些安排到位，就是 resourcing。

**怎么拆**

resource 的动词用法去 e + -ing。名词 resource 资源转成提供资源的动词后，再形成过程名词。

**怎么变成今天的意思**

**resource 名词 → resource 动词**  
可利用资源 → 为某事提供资源

↓

**resource + -ing → resourcing**  
资源的供给、安排、配置

project resourcing 项目资源配置，adequate resourcing 充足资源保障，staff resourcing 人手配置。

**常见搭配与例句**

project resourcing；adequate resourcing；staff resourcing。

> The plan failed because of poor resourcing.

计划因资源保障不足而失败。

> The meeting focused on staffing and resourcing for the project.

会议重点讨论项目的人手和资源配置。

**别混淆**

resourcing 不只采购实物，也包含人员、经费等；resourceful 足智多谋强调善用办法，不保证资源本来充足。

## 这一组要分清什么

resourcing 不只实物；resourceful 不是资源很多的简单同义词。

## 串起来练习

The resourceful manager still needed adequate resourcing.

足智多谋的经理仍需要充足资源保障。
