# 0563 · test — 从金属检验到考试与测试

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

检验义的历史接陶制器皿与金属检验，不是从考试纸张凭空生出。现代 test 能检验知识、产品、假设或耐心。

**TEST：给一个条件，看实际表现**

先看 test 这个动作，再读谁来测、重新测和能不能测；已有 pretest、testbed 一起归在本族。

- **核心、执行者与可检验性**：test · tester · testable
- **先后与环境**：pretest · retest · testbed
- **test → testing：检验，以及考验人的**：test · testing
- **test → tests → tested：检验、考验与已试过**：test · tests · tested

## 词形与演化规律

test → tester、testable；re- 再 → retest；pre- 预先 → pretest；test + bed → testbed。

检验容器的名词发展到检验动作；testing 也能形容费力、考验人的情况。

test 的检验动作和检验事项有相连的词族，tests 形成 sts 辅音连接，tested 则增加 id 音节。

## 逐词讲解

<a id="w-1"></a>

### 1. test — 测试；检验；考试；考验

**音标**：/test/

**先抓住这个画面**

不是光看一眼，而是给它一个问题、条件或操作，看看实际表现怎么样。

**怎么拆**

借法语词上接拉丁 testum 陶器，历史英语有金属检验用容器义，后从检验金属扩展为一般检验。别与 testify 作证只按相似字母混在一起。

**怎么变成今天的意思**

**拉丁 testum → 古法语 test、teste**  
陶制容器；检验金属所用的器皿

↓

**英语 test**  
金属检验 → 检查品质、能力与结果

take a test 参加考试，test a product 测产品，put something to the test 实际考验；a test result 是测试结果，不自动是合格结果。

**常见搭配与例句**

take a test；pass a test；test a theory；put to the test。

> We tested the new system before the launch.

上线前，我们测试了新系统。

> The long journey put their patience to the test.

漫长的旅程考验了他们的耐心。

**别混淆**

test 范围很广，exam 常指正式考试；一次 test 也不一定证明所有环境下都可靠。

<a id="w-8"></a>

### 2. tests — 测试、考试；考验；检验、测试〔第三人称单数〕

**音标**：/tests/

**先抓住这个画面**

拿出一项检查，看看能力、品质或判断是否站得住，就是一个 test；多项检查是 tests，主动去检验也可用动词 tests。

**怎么拆**

test + -s，末尾 /sts/ 连在一起，通常不加额外元音。test 的较早借词背景是法语及拉丁 testum 陶制容器，借词早期涉及检验金属用的器皿，后来扩大为一般检验。

**怎么变成今天的意思**

**拉丁陶器词 → 法语、英语 test；检验用器皿的用法**  
检验器皿 → 检验、考试

↓

**test + -s → tests**  
多项测试；单数主语检验

school tests 学校测验；quality tests 质量检验；tests a theory 检验理论；tests our patience 考验耐心。

**常见搭配与例句**

carry out tests；tests the equipment regularly。

> The team carried out several tests on the new material.

团队对新材料做了几项测试。

> The long wait tests everyone’s patience.

漫长的等待考验着每个人的耐心。

**别混淆**

tests 名词可以是题目测验，也可以是仪器、品质检验。动词 tests our patience 是把等待等情况比作对耐心的考验，语义比考试更宽。

<a id="w-7"></a>

### 3. testing — 测试、检验；正在测试；考验人的、费力的

**音标**：/ˈtestɪŋ/

**先抓住这个画面**

拿一个东西试试看是否合格，是 testing；如果一件事把人的耐心、能力都拿来考一遍，形容起来也可以是 testing。

**怎么拆**

test + -ing，直接加。test 经法语接拉丁 testum 陶制容器，英语早有检验金属所用器皿的相关义，再扩到检验品质、能力的动作；testing 又可作形容词。

**怎么变成今天的意思**

**拉丁陶制容器词 → 法语、英语 test**  
检验用器皿 → 检验

↓

**test + -ing → testing；形容词用法**  
正在测试；像在考验人的、费力的

testing the equipment 测试设备；product testing 产品测试；a testing time 艰难、考验人的时期；a testing question 费思量的问题。

**常见搭配与例句**

careful testing；testing the new design。

> The team is testing the new design before building a full-size version.

团队正在测试新设计，再制作全尺寸版本。

> It was a testing week for everyone involved.

对每个参与者来说，那都是充满考验的一周。

**别混淆**

testing a machine 是动作，a testing situation 是形容词说情况很考验人。testify 作证另属见证词族，不能只按 test 这些字母把两条来源混起来。

<a id="w-9"></a>

### 4. tested — 测试、检验过；经过检验的；经受考验的

**音标**：/ˈtestɪd/

**先抓住这个画面**

已经拿去试过、检查过，就是 tested；用来修饰方法、设计时，常强调经历过实际检验。

**怎么拆**

test + -ed，/t/ 后增加 /ɪd/。test 从较早检验金属的器皿、检验名词发展到动词；tested 是英语规则过去形式和相应分词用法。

**怎么变成今天的意思**

**较早检验词族 → 英语 test 名词、动词**  
检验品质、能力或判断

↓

**test + -ed → tested**  
已经检验、试过；经历考验的

tested the equipment 测试过设备；a tested method 经过检验的方法；tested our patience 考验了耐心；tried and tested 久经考验的。

**常见搭配与例句**

carefully tested；has been tested。

> We tested the equipment before the visitors arrived.

访客到来前，我们测试了设备。

> The lesson uses a tried and tested method.

这节课采用了一种久经考验的方法。

**别混淆**

tested 只说进行了检验，结果是否合格要看后文；a tried and tested method 常表达方法经过使用、比较可靠的评价。test results 则是检验结果。

<a id="w-2"></a>

### 5. tester — 测试人员；测试器；试用样品

**音标**：英 /ˈtestə/；美 /ˈtestər/

**先抓住这个画面**

可能是负责测试的人，也可能是用来测量的工具；商店里让顾客先试一试的样品也这样叫。

**怎么拆**

测试义是 test + -er，构成人、工具等名词。历史上同形 tester 另有床顶罩等名词，来源不同；本页只讲常用测试分支。

**怎么变成今天的意思**

**拉丁 testum → 古法语 test、teste**  
陶制容器；检验金属所用的器皿

↓

**英语 test**  
金属检验 → 检查品质、能力与结果

↓

**test + -er → tester**  
执行测试的人、器具；供试用的样品

a software tester 软件测试员，a battery tester 电池测试器，a perfume tester 香水试用装。

**常见搭配与例句**

a software tester；a battery tester；a perfume tester。

> The tester found a bug in the payment screen.

测试人员在付款页面发现了一个漏洞。

> The shop keeps perfume testers beside the display.

商店把香水试用装放在陈列架旁。

**别混淆**

-er 不只表示人；The tester needs a battery 中 tester 很可能是工具，要用句意判断。

<a id="w-4"></a>

### 6. testable — 可检验的；可测试的

**音标**：/ˈtestəbəl/

**先抓住这个画面**

能想出办法，用观察或实验去检查它，而不是永远只能凭感觉争论。

**怎么拆**

test + -able 可被、能，构成可测试的形容词。这个能力描述只说存在检验办法，不预先给出真假结论。

**怎么变成今天的意思**

**拉丁 testum → 古法语 test、teste**  
陶制容器；检验金属所用的器皿

↓

**英语 test**  
金属检验 → 检查品质、能力与结果

↓

**test + -able → testable**  
能够被检验的

a testable hypothesis 可检验假设，a testable prediction 可检验预测，testable code 易于开展测试的代码。

**常见搭配与例句**

a testable hypothesis；a testable claim；testable code。

> The team turned the idea into a testable hypothesis.

团队把这个想法变成了可检验的假设。

> The design makes each component separately testable.

这种设计使每个组件都能单独测试。

**别混淆**

testable 能检验，tested 已经检验；testable hypothesis 不等于已证实的理论。

<a id="w-5"></a>

### 7. testbed — 试验平台；测试环境

**音标**：/ˈtestbed/

**先抓住这个画面**

先搭一个可控制的环境，让新想法、设备或系统在这里试，再决定怎样继续。

**怎么拆**

test 测试 + bed 基础、承托平台，比喻可开展试验的基底。可以是实体设备，也可以是软件环境，不是真拿床来睡一晚作测试。

**怎么变成今天的意思**

**test 测试；bed 基础、承托平台**  
并列构词部分

↓

**testbed**  
供验证系统、想法的试验平台或环境

a testbed for new technology 新技术试验平台，a software testbed 软件测试环境；能支持测试，不保证模拟了现实所有条件。

**常见搭配与例句**

a testbed for；a software testbed；serve as a testbed。

> The small network served as a testbed for the new software.

这张小网络用作新软件的试验平台。

> The lab built a testbed for evaluating the sensors.

实验室搭了一个评估传感器的试验平台。

**别混淆**

testbed 供实验的平台、环境，test case 一项具体测试案例；一个 testbed 可以运行很多 test cases。

<a id="w-3"></a>

### 8. retest — 重新测试；复试、补测

**音标**：动词 /ˌriːˈtest/；名词 /ˈriːtest/

**先抓住这个画面**

已经测过，再测一遍；可能因为原结果有疑问，也可能想确认改动后的情况。

**怎么拆**

re- 再次 + test。动词和名词都常见，一些读法中动词重音偏后、名词偏前，实际口音可有变化。

**怎么变成今天的意思**

**拉丁 testum → 古法语 test、teste**  
陶制容器；检验金属所用的器皿

↓

**英语 test**  
金属检验 → 检查品质、能力与结果

↓

**re- + test → retest**  
再次测试 → 复测；复测这件事

retest a sample 复测样品，request a retest 要求复测，take a retest 参加补测。再次测不自动表示第一次一定失败。

**常见搭配与例句**

retest a sample；request a retest；a driving retest。

> The laboratory will retest the sample tomorrow.

实验室明天将重新检测样品。

> He requested a retest after questioning the result.

他质疑结果后要求复测。

**别混淆**

retest 强调再测，review 可以只是复查已有资料；没有实际重做测试时不必说 retest。

<a id="w-6"></a>

### 9. pretest — 前测；预测试；事先测试

**音标**：名词英、美 /ˈpriːtest/；动词 /ˌpriːˈtest/

**先抓住这个画面**

正式教学、研究或使用开始前，先测一下原来的水平，或者试试看测试工具是否好用。

**怎么拆**

英语 pre- + test；既可作名词，也可作动词，常见读法的主重音不同。

**怎么变成今天的意思**

**拉丁语 prae → 法语、中世纪拉丁语 pre- → 英语 pre-**  
时间在先；位置在前；后来可与英语现成词自由组合

↓

**英语 pre- + test → pretest**  
正式过程前的测量或试测

教学中的 pretest 常用来了解学生原有知识；问卷的 pretest 则可能是在正式调查前试用题目，发现歧义。参照点不同，目的也不同。

**常见搭配与例句**

give a pretest；pretest a questionnaire；pretest scores。

> The pretest showed which topics the students already understood.

前测显示了学生已经掌握哪些主题。

> We will pretest the questionnaire with a small group.

我们将先找一个小组试测这份问卷。

**别混淆**

posttest 是干预或教学后的测量；pilot test 强调小范围试运行，不一定用来测量起点水平。

## 这一组要分清什么

testable 不是已证实，retest 不是只复看旧报告；tester 可指人，也可指仪器、试用品。

## 串起来练习

The tester will retest the system after the update.

更新后，测试人员将重新测试系统。
