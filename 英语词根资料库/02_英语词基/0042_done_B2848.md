# 0042 · done — 做完、完成；做过的分词形式与状态

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

done 从古英语 do 的过去分词 dōn／ġedōn 等经中古英语延续，今天与 do、did 配套。分词、形容词已经有多种固定用法，不把每个 done 都只翻成做。

**DONE：先看动作已经完成，再看完成得怎样**

The work is done 工作做完；overdone 做过头；undone 却可能是未完成，也可能是解开的状态。

- **基本完成形式**：do · done
- **未完成、解开等相反状态**：undone
- **超过合适程度**：overdone

## 词形与演化规律

do—did—done 是现代不规则形式；un- + done → undone；over- + done → overdone。烤肉食物 doner 来自土耳其语 döner，不能因拼写像 done 就归为做熟的派生。

## 逐词讲解

<a id="w-5"></a>

### 1. do — 做；实施；疑问、否定或强调的助动词；do〔音乐唱名，另源〕

**音标**：动词强读 /duː/，弱读 /də/；唱名英 /dəʊ/、美 /doʊ/

**先抓住这个画面**

可以表示“动手做”，也可以只负责把句子搭起来。

**怎么拆**

日常动词继承古英语 dōn、中古英语 don。does、did、done 属于其屈折变化。音乐唱名 do 则来自意大利语唱名体系，用来替换 ut，与“做”不是同一来源。

**怎么变成今天的意思**

**日常动词：古英语 dōn；音乐唱名：意大利语 do**  
做；另一路是替换 ut 的唱名

↓

**中古英语 do；近代音乐用语 do**  
动词逐渐兼作助动词；唱名独立借入

↓

**现代英语 do**  
同形词须按动词或音乐读法区分

I do the washing 中，do 真正在表达做事；Do you agree? 中，它不表示另做一件事，只帮助提问。I do agree 把 do 读重，就成了“我确实同意”。英式口语 a do 还可以是一场聚会，来自活动义。

**常见搭配与例句**

do the work；do your best；do not／don’t；Do you…?；I do agree。一般活动常用 do，制作出东西常用 make，但具体搭配要单独记。

> I’ll do the washing while you cook.

你做饭时，我来洗衣服。

> Do you need a copy of the report?

你需要一份报告副本吗？

> I do understand why you’re upset.

我确实明白你为什么难过。

> The choir sang the scale from do to the higher do.

合唱团从 do 唱音阶，一直唱到高八度的 do。

**别混淆**

do you make bread? 里的 do 帮助提问，make 才描述制作。唱名 do 的元音与动词 do 不同。

<a id="w-1"></a>

### 2. done — do 的过去分词；完成的；熟了的

**音标**：/dʌn/

**先抓住这个画面**

事情已经做到某个结果，或食物已经做熟。

**怎么拆**

继承古英语过去分词 ġedōn，经中古英语 don／idon／ydon 到 done。它与 did 是同一动词的不同语法形式，不是 did 后来又变成 done。

**怎么变成今天的意思**

**古英语 ġedōn**  
dōn 的过去分词

↓

**中古英语 don／idon／ydon**  
保留完成、做过的分词形式

↓

**英语 done**  
过去分词；也作“完成的、熟了的”形容词

I’ve done it 强调事情已经做过；I’m done 可以是“我做完了”。The work is done 可能强调工作完成的状态，也可能在上下文中作被动表达。食物 done 是火候到位，不是食物自己“做了事”。

**常见搭配与例句**

have done；get something done；be done with something；Is it done?。

> I’ve done everything on the list.

清单上的事我已经全部做完了。

> Are you done with the scissors?

你用完剪刀了吗？

> The cake is done, but it needs time to cool.

蛋糕烤好了，不过还需要时间冷却。

**别混淆**

did 能独立作过去时谓语；done 通常搭配助动词或作形容词。I done it 不是通行标准书面语。

<a id="w-2"></a>

### 3. undone — 没做完的；解开的；被毁掉的；undo 的过去分词

**音标**：/ʌnˈdʌn/

**先抓住这个画面**

先看是“还没做”，还是“做好的东西又被解开了”。

**怎么拆**

两条构形在这里同形：否定 un-＋done 表示未完成；undo 的过去分词则表示撤销、松开或毁掉。后一条接旧英语的解开动词，不要把两种 un- 合成一个意思。

**怎么变成今天的意思**

**两条材料：done 完成；undo 撤销、解开**  
未完成与撤销后的结果并非同一结构

↓

**un- ＋ done；undo 的过去分词 undone**  
否定义与反向动作的分词并存

↓

**英语 undone**  
未完成；松开；毁掉等结果状态

leave the work undone 是工作没完成；the lace came undone 是鞋带原本系着，后来松开了。文学里 a person undone 还可以说一个人彻底垮掉，像支撑他的东西被拆散。

**常见搭配与例句**

leave something undone；come undone；be undone by a mistake。

> Several important tasks were left undone.

几项重要任务还没有完成。

> My shoelace came undone as I was running.

我跑步时鞋带松开了。

**别混淆**

unfinished 主要说没有完成；undone 除此之外还可以表示松开、被撤销，必须看上下文。

<a id="w-3"></a>

### 4. overdone — 做过头的；煮老、烤过头的；过分夸张的

**音标**：英 /ˌəʊvəˈdʌn/；美 /ˌoʊvərˈdʌn/

**先抓住这个画面**

牛排做得太久、妆画得太重、笑话讲得太满，都像手没有及时收住，可说 overdone。

**怎么拆**

overdo 的过去分词，over- 过度 + do 做；变化 overdo—overdid—overdone，done 不是独立表示完成度太高的后缀。

**怎么变成今天的意思**

**over- + do → overdo**  
做得过度

↓

**overdo → overdone**  
已经做过头；固定形容用法

overdone meat 煮老的肉；an overdone joke 反复用、讲过头的笑话；the makeup looks overdone 妆显得过重。

**常见搭配与例句**

slightly overdone；an overdone effect。

> The vegetables were a little overdone.

蔬菜煮得稍过了头。

> The dramatic ending felt overdone.

那个戏剧性的结尾让人觉得有些用力过猛。

**别混淆**

done 可以说完成、熟了，overdone 加入过头的判断；well done 在食物语境还可按所要求熟度使用，不总是在抱怨做坏。

## 这一组要分清什么

have done 与 did 的结构不同；undone 不只未做，还可说纽扣松开；overdone 可以说食物过熟，也可以说装饰、表演过火。

## 串起来练习

The main work is done, but a few small tasks remain undone.

主要工作已完成，但还有几项小任务没做。
