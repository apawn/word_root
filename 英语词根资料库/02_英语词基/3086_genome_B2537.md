# 3086 · genome — 基因组；基因组学

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

genome 是现代遗传学经德语等命名传播的术语，联系 gene 及整体成分的造词。genomic 是形容词，genomics 是基因组学，不是 genome 的普通复数。

**GENOME：把一套遗传信息作为整体研究**

不只盯一个基因，而是看整个遗传信息集合。

- **遗传信息整体**：genome
- **属性与学科**：genomic · genomics

## 词形与演化规律

genome → genomic；genomics 为学科名。对象的基因组范围应按所研究的生物和定义确认。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. genome — 基因组

**音标**：英 /ˈdʒiːnəʊm/；美 /ˈdʒiːnoʊm/

**先抓住这个画面**

gene 像一段有功能的文字，genome 像整套遗传文本，连基因之间的部分也算。

**怎么拆**

德语 Gen“基因”与 Chromosom“染色体”的缩合 Genom，进入英语后形成 genome。

**怎么变成今天的意思**

**希腊 gígnesthai / génos / génesis**  
产生、出生；出身和种类；形成过程

↓

**德语 Gen“基因” + Chromosom“染色体” → Genom**  
以两词的缩合命名整套遗传信息

↓

**德语 Genom → 英语 genom / genome**  
借入英语，指整套基因组

一个生物的 genome 不只是所有蛋白质基因的清单，还包含非编码区域。细胞生物通常用 DNA 储存这套信息；一些病毒的基因组是 RNA。

**常见搭配与例句**

sequence a genome；the human genome；genome size。

> The team sequenced the entire bacterial genome.

团队测定了这个细菌的完整基因组序列。

> The mutation lies in a noncoding region of the genome.

这个突变位于基因组的非编码区域。

**别混淆**

genome 大不直接等于生物更复杂；这里数的是遗传材料总量。

<a id="w-2"></a>

### 2. genomic — 基因组的

**音标**：英 /dʒəˈnəʊmɪk/；美 /dʒəˈnoʊmɪk/

**先抓住这个画面**

把镜头从一小段基因拉远到整套遗传材料。

**怎么拆**

genome 去词尾 e + -ic。

**怎么变成今天的意思**

**希腊 gígnesthai / génos / génesis**  
产生、出生；出身和种类；形成过程

↓

**德语 Gen“基因” + Chromosom“染色体” → Genom**  
以两词的缩合命名整套遗传信息

↓

**德语 Genom → 英语 genom / genome**  
借入英语，指整套基因组

↓

**英语 genomic**  
关于基因组的

genomic data 是基因组层面的数据；genomic region 是基因组中的一段区域。这个形容词不保证每项研究都测到了所有位置。

**常见搭配与例句**

genomic analysis；genomic data；a genomic region。

> The database stores genomic data from many species.

数据库保存了许多物种的基因组数据。

> This genomic region contains several genes.

这个基因组区域含有几个基因。

**别混淆**

genetic 范围更广，可指遗传性质；genomic 明确以基因组为对象。

<a id="w-3"></a>

### 3. genomics — 基因组学

**音标**：英 /dʒəˈnəʊmɪks/；美 /dʒəˈnoʊmɪks/

**先抓住这个画面**

把整本遗传文本放在一起研究：有哪些部分，它们怎样配合，不只盯住一句。

**怎么拆**

genome + 学科后缀 -ics。

**怎么变成今天的意思**

**希腊 gígnesthai / génos / génesis**  
产生、出生；出身和种类；形成过程

↓

**德语 Gen“基因” + Chromosom“染色体” → Genom**  
以两词的缩合命名整套遗传信息

↓

**德语 Genom → 英语 genom / genome**  
借入英语，指整套基因组

↓

**英语 genomics**  
研究完整基因组结构、功能及比较的领域

comparative genomics 比较不同生物的基因组；functional genomics 问这些部分怎样发挥作用。它和 genetics 相连，区别在常见研究尺度而非两道绝对隔墙。

**常见搭配与例句**

comparative genomics；functional genomics。

> Genomics has changed how researchers compare species.

基因组学改变了研究人员比较物种的方式。

> She works in comparative genomics.

她从事比较基因组学研究。

**别混淆**

genome 是对象，genomics 是研究领域；末尾 s 通常不当复数处理。

## 这一组要分清什么

genetics 是遗传学，genomics 更突出基因组整体及其相互关系；不能把 -s 全当作复数。

## 串起来练习

The genomics course uses genomic data from several genomes.

基因组学课程使用几个基因组的基因组数据。
