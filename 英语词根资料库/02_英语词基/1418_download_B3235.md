# 1418 · download — 把远端文件载到本地

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

down 是传输方向的约定画面，不是文件真的从天空掉下；可下载不代表免费，也不代表已经下载。

**DOWNLOAD：从网络那端拿到自己的设备上**

download → downloadable、downloader，分动作、文件可用方式、执行工具。

- **动作、可下载与执行工具**：download · downloadable · downloader
- **download → downloads、downloaded、downloading**：download · downloads · downloaded · downloading

## 词形与演化规律

down + load → download；download + -able/-er。

同一个传入动作，用名词、时态、过程形式分别表达。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. download — 下载；下载物、下载过程

**音标**：动词英 /ˌdaʊnˈləʊd/、美 /ˌdaʊnˈloʊd/；名词常 /ˈdaʊnləʊd/ 等

**先抓住这个画面**

把服务器、网站等处的文件取到当前设备，和 upload 上传方向相对。

**怎么拆**

down + load，现代数据传送词。down 表传送关系中的接收一端，不说明服务器真在高楼上。

**怎么变成今天的意思**

**古英语 lād 行程、运送 → 中古英语 lode、loade**  
运送 → 搬运的负荷

↓

**现代 load**  
货物、负担；装载 → 加载与数据传送

↓

**down + load → download**  
从远端取得文件 → 下载

download a file 下载文件，a free download 免费下载物，download speed 下载速度。

**常见搭配与例句**

download a file；download from；download speed；a free download。

> You can download the guide as a PDF.

你可以把指南下载成 PDF。

> The download stopped when the connection failed.

连接中断后，下载停止了。

**别混淆**

download 保存取得文件，stream 流式播放通常侧重边传边用；具体软件可能缓存，不按字面定绝对技术边界。

<a id="w-4"></a>

### 2. downloaded — 下载了；下载得到的

**音标**：英 /ˌdaʊnˈləʊdɪd/；美 /ˌdaʊnˈloʊdɪd/

**先抓住这个画面**

文件已经从远端传到这里，是 downloaded。完成的是传入动作，至于有没有打开、读懂，是另一件事。

**怎么拆**

download + -ed，基础词末为 /d/，所以 -ed 读 /ɪd/。

**怎么变成今天的意思**

**down + load → download**  
接收、装载远端数据

↓

**download + -ed → downloaded**  
过去下载；下载得到的文件状态

downloaded a report 下载了报告；downloaded files 下载得到的文件。

**常见搭配与例句**

a downloaded copy 下载副本；already downloaded 已经下载。

> I downloaded the report before leaving the office.

离开办公室前我下载了报告。

> The downloaded map worked during the journey.

旅途中那张下载好的地图能用。

**别混淆**

downloaded 与 uploaded 指相反的传送视角；文件可在一次传送中对发送者是上传、对接收者是下载。

<a id="w-5"></a>

### 3. downloading — 正在下载；下载过程

**音标**：英 /ˌdaʊnˈləʊdɪŋ/；美 /ˌdaʊnˈloʊdɪŋ/

**先抓住这个画面**

远端资料还在往接收设备传，动作没结束，就是 downloading。

**怎么拆**

download + -ing，基础词不改拼写；down、load 原有组合仍清楚。

**怎么变成今天的意思**

**down + load → download**  
把远端数据传到接收侧

↓

**download + -ing → downloading**  
传入动作正在进行；下载这件事

downloading a file 正在下载文件；finish downloading 下完。

**常见搭配与例句**

while downloading 下载时；downloading large files 下载大文件。

> The computer is downloading the recording.

电脑正在下载录音。

> Downloading the photos took ten minutes.

下载这些照片花了十分钟。

**别混淆**

downloading 强调传入过程；opening 是打开已有内容，二者可能先后发生，也可能部分重叠。

<a id="w-6"></a>

### 4. downloads — 下载〔第三人称单数〕；下载文件、下载次数〔复数〕

**音标**：动词英 /ˌdaʊnˈləʊdz/、美 /ˌdaʊnˈloʊdz/；名词英 /ˈdaʊnləʊdz/、美 /ˈdaʊnloʊdz/

**先抓住这个画面**

资料从远端传到接收设备，动词说下载；传下来的文件或下载次数，也可叫 downloads。

**怎么拆**

down + load → download，整词加 -s，/d/ 后读 /z/。down 给相对传入方向，load 给装载数据的画面。

**怎么变成今天的意思**

**down + load → download**  
远端数据传到接收一侧

↓

**download + -s → downloads**  
它下载；多个下载文件、次数

recent downloads 最近下载的文件；the program downloads updates 程序下载更新。

**常见搭配与例句**

a list of downloads 下载文件列表；thousands of downloads 数千次下载。

> The program downloads a new map each morning.

程序每天早上下载一张新地图。

> My recent downloads include three audio files.

我最近下载的文件里有三个音频文件。

**别混淆**

文件、次数都能用复数 downloads，具体看数量在数什么；这不表示远端机器在物理上方。

<a id="w-2"></a>

### 5. downloadable — 可下载的、供下载的

**音标**：英 /ˌdaʊnˈləʊdəbl/；美 /ˌdaʊnˈloʊdəbl/

**先抓住这个画面**

网页上能拿到本地保存、安装的文件，就可说 downloadable；它说提供方式，不自动说免费。

**怎么拆**

download + -able 可……，组成可下载的形容词；-able 是能力、可能性，不是 table 桌子的一段。

**怎么变成今天的意思**

**down + load → download**  
从远端把数据载到本地；down 是传输关系的传统方向说法

↓

**download + -able/-er**  
可下载；执行下载的人或工具

a downloadable file 可下载文件，downloadable content 可下载内容，a downloadable guide 可下载指南。

**常见搭配与例句**

a downloadable file；downloadable content；a downloadable guide。

> The museum provides a downloadable map.

博物馆提供可下载地图。

> Some downloadable content requires a separate purchase.

有些可下载内容需要另行购买。

**别混淆**

downloadable 可下载不等于 free 免费，也不等于已经 downloaded 下载好了；一个说可能，一个说结果。

<a id="w-3"></a>

### 6. downloader — 下载工具、下载器；下载者

**音标**：英 /ˈdaʊnləʊdə/；美 /ˈdaʊnloʊdər/

**先抓住这个画面**

负责把远端文件拿下来的程序或人；软件名里多指工具，不能看到 -er 就一定找真人。

**怎么拆**

download + -er，表示执行下载的人或工具。具体是否有管理、排队等功能，取决于程序本身，不由一个后缀保证。

**怎么变成今天的意思**

**down + load → download**  
从远端把数据载到本地；down 是传输关系的传统方向说法

↓

**download + -er → downloader**  
执行下载的人或程序工具

a file downloader 文件下载器，a video downloader 视频下载工具，a built-in downloader 内置下载器。

**常见搭配与例句**

a file downloader；a video downloader；a built-in downloader。

> The downloader saved the files in a new folder.

下载器把文件保存到新文件夹。

> She paused the downloader before leaving the office.

离开办公室前，她暂停了下载器。

**别混淆**

downloader 是执行工具，downloadable 说文件可以下载；下载功能不等于对文件内容有使用许可。

## 这一组要分清什么

download/upload 方向相对；downloadable/downloaded 可能与完成；downloader 工具非文件性质。

## 串起来练习

The downloader saved the downloadable guide.

下载器保存了那份可下载指南。
