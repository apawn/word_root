# 2909 · processed — 已处理与未处理，看流程走到了哪一步

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

process 本来就是有步骤的过程；processed 把完成相应处理当成状态，unprocessed 则说明那一步尚未进行。

**PROCESSED：经过了某一步，un- 把这个状态否定**

processed 与 unprocessed 对照看材料、数据、图像的处理状态。

- **处理状态的正反对照**：processed · unprocessed

## 词形与演化规律

process + -ed → processed；un- + processed → unprocessed。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [processed](#w-1) | 英 /ˈprəʊsest/；美 /ˈprɑːsest/ | 处理过的；加工过的 |
| [unprocessed](#w-2) | 英 /ʌnˈprəʊsest/；美 /ʌnˈprɑːsest/ | 未经处理、加工的 |

## 逐词讲解

<a id="w-1"></a>

### 1. processed — 处理过的；加工过的

**音标**：英 /ˈprəʊsest/；美 /ˈprɑːsest/

**先抓住这个画面**

原材料、资料或申请已经经过了一道或多道处理；究竟怎样处理要看对象。

**怎么拆**

process + -ed，过去式、过去分词并可作形容词；-ed 接在这里常读 /t/，不是额外完整的 /ɪd/ 音节。

**怎么变成今天的意思**

**拉丁 prōcēdere → prōcessus → 法语 proces → 英语 process**  
向前推进 → 行进、进程、过程

↓

**英语 process 的动词和派生词**  
按程序处理；处理过的；执行处理的设备、人或机构

↓

**process + -ed → processed**  
处理 → 已处理、加工过的

processed food 加工食品，processed data 已处理数据；The application has been processed 申请已处理，不自动等于获批。

**常见搭配与例句**

processed food；processed data；a processed application。

> The processed data was ready for analysis.

处理后的数据已经可以分析了。

> Your application has been processed, but a decision is still pending.

你的申请已处理，但决定仍待作出。

**别混淆**

processed 说经过处理，approved 说得到批准；食品加工方式很多，不能仅凭这一个词推断具体营养或安全状况。

<a id="w-2"></a>

### 2. unprocessed — 未经处理、加工的

**音标**：英 /ʌnˈprəʊsest/；美 /ʌnˈprɑːsest/

**先抓住这个画面**

相机直接留下的原始资料、还没整理的输入，都可能是 unprocessed。重点是某一步处理还没发生，具体哪一步要看对象。

**怎么拆**

un- 否定 + processed，后者为 process + -ed。否定前缀盖住已处理这一状态，形成未处理的形容词。

**怎么变成今天的意思**

**process 处理 → processed 已处理的**  
完成某种加工、程序或处理

↓

**un- + processed → unprocessed**  
没有经过所说的那种处理

unprocessed data 未处理数据；unprocessed images 未处理图像；unprocessed materials 未加工材料。

**常见搭配与例句**

unprocessed data；unprocessed images。

> The folder contains the unprocessed images from the camera.

文件夹里是相机导出的未处理图像。

> The report separates unprocessed input from processed results.

报告把未处理输入与已处理结果分开。

**别混淆**

unprocessed 不自动保证更好、更安全；它只说相应处理状态，评价需要另看标准。

## 这一组要分清什么

已处理、未处理都只说明相应流程，不能单凭词形判断优劣。

## 串起来练习

The unprocessed images were stored beside the processed copies.

未处理图像存放在处理后副本的旁边。
