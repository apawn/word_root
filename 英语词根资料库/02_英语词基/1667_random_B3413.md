# 1667 · random — 无特定方向到随机、随意，再分技术与口语

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

随机不自动等概率，随机化不是肉眼看着乱；日常不相干评论与技术随机分配要放回场景。

**RANDOM：没有事先固定一个结果，但随机也可以有明确机制**

random → randomly、randomness、randomization；rando 为口语人物分支。

- **基础、方式、性质和过程**：random · randomly · randomness · randomization
- **口语陌生人物**：rando

## 词形与演化规律

randon、randoun → at random → random；random + -ly/-ness/-ization；random 词基 + -o。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [random](#w-1) | /ˈrændəm/ | 随机的；随意的、不相干的；偶然碰到的〔口语〕 |
| [randomly](#w-2) | /ˈrændəmli/ | 随机地；随意地、无固定规律地 |
| [randomness](#w-3) | /ˈrændəmnəs/ | 随机性；无规律、偶然成分 |

## 逐词讲解

<a id="w-1"></a>

### 1. random — 随机的；随意的、不相干的；偶然碰到的〔口语〕

**音标**：/ˈrændəm/

**先抓住这个画面**

没按预先指定的一条路线、一个名单挑结果。统计里的随机有具体概率机制；日常 a random comment 也可能只是突然冒出来、不相干。

**怎么拆**

经中古英语 randon 等接古法语奔跑、疾冲词族，at random 从无特定方向的旧画面进入随意、随机。词尾 m 是历史词形变化，不是 rand + om 后缀。

**怎么变成今天的意思**

**古法语 randon、randir → 中古英语 randoun、randon**  
疾冲、奔跑、冲劲

↓

**at random 等说法 → random 形容词**  
不朝特定方向 → 无固定目的、随机

↓

**现代日常与技术语境**  
随意、不相干；概率、抽样中的随机需看具体机制

at random 随机地，a random sample 随机样本，random numbers 随机数，a random comment 突然的不相干评论。

**常见搭配与例句**

at random；a random sample；random numbers；a random comment。

> The program selected a name at random.

程序随机选了一个名字。

> He made a random comment about the weather.

他突然冒出一句有关天气的评论。

**别混淆**

random 不自动等于各结果概率相同；a random sample 的抽样方式仍有具体要求，随手拿几个不一定构成规范随机抽样。

<a id="w-2"></a>

### 2. randomly — 随机地；随意地、无固定规律地

**音标**：/ˈrændəmli/

**先抓住这个画面**

把 random 放到动作上：随机分配、随机打乱，重点是动作没有按固定名单或特定目标来选。

**怎么拆**

random + -ly，副词；技术语境要看采用什么随机过程，日常则可宽泛说随意。

**怎么变成今天的意思**

**古法语 randon、randir → 中古英语 randoun、randon**  
疾冲、奔跑、冲劲

↓

**at random 等说法 → random 形容词**  
不朝特定方向 → 无固定目的、随机

↓

**random + -ly → randomly**  
以随机、随意方式做事

randomly selected 随机选取的，randomly assigned 随机分配的，arranged randomly 无固定次序排列。

**常见搭配与例句**

randomly selected；randomly assigned；arranged randomly。

> The cards were arranged randomly on the table.

卡片在桌上随意摆放。

> Participants were randomly assigned to two groups.

参加者被随机分配到两组。

**别混淆**

randomly 是方式，randomness 是性质名词；randomly assigned 不代表已经消除所有组间差异。

<a id="w-3"></a>

### 3. randomness — 随机性；无规律、偶然成分

**音标**：/ˈrændəmnəs/

**先抓住这个画面**

不是某一个偶然结果，而是结果不能按固定确定方式预先锁死的性质；也可日常说事情显得没规律。

**怎么拆**

random + -ness，性质名词。随机性可对应不同概率分布，不把它定义成所有结果一律等可能。

**怎么变成今天的意思**

**古法语 randon、randir → 中古英语 randoun、randon**  
疾冲、奔跑、冲劲

↓

**at random 等说法 → random 形容词**  
不朝特定方向 → 无固定目的、随机

↓

**random + -ness → randomness**  
随机的性质、偶然成分

a source of randomness 随机性来源，introduce randomness 引入随机性，test for randomness 检查随机性。

**常见搭配与例句**

a source of randomness；introduce randomness；test for randomness。

> The game uses randomness to keep each round different.

游戏借随机性让每轮有所不同。

> The lesson distinguished randomness from equal probability.

课程区分了随机性与等概率。

**别混淆**

randomness 不等于 uniformity 均匀、等概率；结果暂时出现图案，也不能只凭外观就断定没有随机性。

<a id="w-4"></a>

### 4. randomization — 随机化、随机分配的过程

**音标**：英 /ˌrændəmaɪˈzeɪʃən/；美 /ˌrændəməˈzeɪʃən/

**先抓住这个画面**

主动给选择、次序、分组加入随机机制，这个安排过程叫 randomization；不是任何看着凌乱的结果都叫做了随机化。

**怎么拆**

random + -ization，可经 randomize 随机化动词再接动作名词；英式也见 randomisation。

**怎么变成今天的意思**

**古法语 randon、randir → 中古英语 randoun、randon**  
疾冲、奔跑、冲劲

↓

**at random 等说法 → random 形容词**  
不朝特定方向 → 无固定目的、随机

↓

**random → randomize → randomization**  
随机性质 → 使随机 → 随机化过程

randomization of order 顺序随机化，randomization procedure 随机分配程序，use randomization 采用随机化。

**常见搭配与例句**

randomization procedure；randomization of order；use randomization。

> The experiment used randomization to assign the tasks.

实验采用随机化来分配任务。

> The report described the randomization procedure.

报告描述了随机分配过程。

**别混淆**

randomization 是过程，randomness 是性质；shuffle 洗牌可实现某种随机化，是否合适取决于具体办法。

<a id="w-5"></a>

### 5. rando — 陌生人、不相关的路人〔口语，可能轻蔑〕

**音标**：英 /ˈrændəʊ/；美 /ˈrændoʊ/

**先抓住这个画面**

不是特意找来的熟人，而是随便冒出来一个不认识的人；说 some rando 常有“不知哪来的谁”那种口气。

**怎么拆**

random 截取词基配口语人物词尾 -o，形成人物称呼。另有运动领域同形缩写，本页先记日常陌生人用法。

**怎么变成今天的意思**

**古法语 randon、randir → 中古英语 randoun、randon**  
疾冲、奔跑、冲劲

↓

**at random 等说法 → random 形容词**  
不朝特定方向 → 无固定目的、随机

↓

**random 的词基 + -o → rando**  
不特定、无关的人 → 陌生路人称呼

some rando 不知哪来的某个人，a rando online 网上一个陌生人，a group of randos 一群不认识的人。

**常见搭配与例句**

some rando；a rando online；a group of randos。

> Some rando joined the group chat by mistake.

一个不认识的人误进了群聊。

> I would not trust a rando online with that decision.

这个决定我不会随便交给网上一个陌生人。

**别混淆**

rando 很口语，也可能不礼貌；stranger 较中性，random 本身通常是形容词，不是所有语境都可换成 rando。

## 这一组要分清什么

randomness/equal probability 不同；randomization 过程；rando 口语可冒犯，stranger 较中性。

## 串起来练习

Randomization determined the order, and the cards were presented randomly.

随机化确定了顺序，卡片按随机顺序呈现。
