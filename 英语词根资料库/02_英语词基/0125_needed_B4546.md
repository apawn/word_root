# 0125 · needed — 所需要的；需要过；当前不需要的相反形式

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

needed 是 need + -ed，既能作过去式、分词，也形成所需要的这一形容词用法。unneeded 再否定它，表达某个场景里不需要。

**NEEDED：先看谁、什么被需要，再看是不是已过去的动作**

We needed help 是过去需要帮助；the needed information 是当前所需信息，字面有 -ed 不保证这份信息只在过去需要。

- **需要这一动作、状态**：need
- **过去动作与所需性质**：needed
- **不再需要或当前用不上**：unneeded

## 词形与演化规律

need + -ed → needed；un- + needed → unneeded。普通定语、被动结构和过去动作按整句判断，不凭一个 -ed 就一律译成过去。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [need](#w-3) | /niːd/ | 需要；必要；需求 |
| [needed](#w-1) | /ˈniːdɪd/ | 需要的；need 的过去式、过去分词 |
| [unneeded](#w-2) | /ʌnˈniːdɪd/ | 不需要的；多余而用不上的 |

## 逐词讲解

<a id="w-3"></a>

### 1. need — 需要；必要；需求

**音标**：/niːd/

**先抓住这个画面**

缺了这件东西，事情就办不成；need 指向这个缺口。

**怎么拆**

中古英语合流了古英语表示必要的 nīed／nēd 与表示欲求的 nēod 等形式。现代 need 可作名词、普通动词，也有情态用法。

**怎么变成今天的意思**

**古英语 nīed／nēd；nēod**  
必要、迫切需要；欲求

↓

**中古英语 nede → 英语 need**  
需要；有必要

I need help 是需要帮助，You need to rest 是有必要休息。needn’t 表没有必要；名词 in need 是处于困境、需要帮助。

**常见搭配与例句**

need to do；need help；meet a need；in need。

> You need to save the file before closing it.

关闭文件前你需要先保存。

> The charity supports families in need.

这家慈善机构帮助有困难的家庭。

**别混淆**

needn’t go 是不必去，mustn’t go 是禁止去。need 强调必要，want 常只是想要；二者在实际对话里也可重叠。

<a id="w-1"></a>

### 2. needed — 需要的；need 的过去式、过去分词

**音标**：/ˈniːdɪd/

**先抓住这个画面**

缺口已经明确，正好能填这个缺口的东西就是 needed。

**怎么拆**

need + -ed；词末 /d/ 后的 -ed 读 /ɪd/，因此 needed 是两个音节。过去分词可用于被动，也可修饰名词。

**怎么变成今天的意思**

**古英语 nīed／nēd；nēod**  
必要、迫切需要；欲求

↓

**中古英语 nede → 英语 need**  
需要；有必要

↓

**need + -ed → needed**  
过去需要；被需要；所需的

Help is needed 是现在需要帮助，不因 needed 有 -ed 就成了过去。We needed help 才由过去式说明当时需要。much-needed 常作带连字符修饰语。

**常见搭配与例句**

the information needed；help is needed；more time was needed。

> No special equipment is needed.

不需要特殊设备。

> We needed more time to check the results.

我们当时需要更多时间检查结果。

**别混淆**

needed 是否有过去时间，要看整个结构。is needed 是现在时的被动；was needed 才把需要放到过去。

<a id="w-2"></a>

### 3. unneeded — 不需要的；多余而用不上的

**音标**：/ʌnˈniːdɪd/

**先抓住这个画面**

已经有一把钥匙，又递来第五把；这一次并不需要它，可以说 unneeded，而不是说它永远没价值。

**怎么拆**

un- 不 + needed 所需要的；needed 是 need + -ed 的分词、形容词形式。这里 un- 否定需要这一状态，不把已经发生的需要动作倒放回去。

**怎么变成今天的意思**

**need + -ed → needed**  
需要过；所需要的

↓

**un- + needed → unneeded**  
在某个场景里不需要的

unneeded files 不需要的文件；unneeded equipment 暂时用不上的设备。含义要按当前任务、用途判断，不是判断这个东西本身坏。

**常见搭配与例句**

unneeded items；remove unneeded steps。

> We removed the unneeded steps from the instructions.

我们删掉了说明里不需要的步骤。

> The box held several unneeded cables.

盒子里放着几根用不上的电线。

**别混淆**

unneeded 不需要的与 unwanted 不想要的不同：一个人可能很想要某样东西，但眼下确实不需要。unnecessary 常与 unneeded 接近，搭配重点各异。

## 这一组要分清什么

unneeded 不需要与 unwanted 不想要不同；needed 的 -ed 不一定单独定位时间；need to do 和 need doing 等结构仍看具体句型。

## 串起来练习

We kept the needed files and moved the unneeded copies into a separate folder.

我们保留了所需文件，把用不上的副本移进另一个文件夹。
