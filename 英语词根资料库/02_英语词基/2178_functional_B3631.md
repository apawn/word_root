# 2178 · functional — 功能；实际用途相关

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

functional 联系 function 的执行、作用一支。functionality 说功能或功能性，multifunctional 说多功能，nonfunctional 说不起作用；functionalism、functionalist 有各学科的理论用法。

**FUNCTIONAL：看它能做什么、能否正常起作用**

有外形之外，还需要实际完成任务。

- **功能与运作**：functional · functionality · functionally
- **数量与状态**：multifunctional · nonfunctional
- **理论立场**：functionalism · functionalist

## 词形与演化规律

-ly 构成副词，multi- 多，non- 否定；-ism、-ist 不只是表示功能数量，而涉及思想或流派及其持有者。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-1"></a>

### 1. functional — 能正常工作的；实用的；功能方面的

**音标**：/ˈfʌŋkʃənəl/

**先抓住这个画面**

先问“它能不能把该做的事做好”，再谈外观或其他特点。

**怎么拆**

现代可看作 function + -al；历史解释也包括中世纪拉丁 functionalis，都是“与履行作用有关”。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

a functional kitchen 是好用、布局满足需要的厨房；fully functional 表示功能已正常可用。a functional difference 是功能上的区别。医学、数学和编程中另有专门用法，需跟着领域读，不能全部机械翻成“实用”。

**常见搭配与例句**

fully functional；functional design；functional requirements。

> The room is small but functional.

房间虽小，但很实用。

> The replacement system is now fully functional.

替换后的系统现在已能正常发挥全部功能。

**别混淆**

functional 说明能发挥作用或侧重实用；decorative 强调装饰。东西可以既 functional 又 attractive。

<a id="w-2"></a>

### 2. functionality — 功能性；具备的功能；发挥作用的能力

**音标**：/ˌfʌŋkʃəˈnæləti/

**先抓住这个画面**

把产品拿来实际用：它能做哪些事，这些本领合起来就是这里说的 functionality。

**怎么拆**

functional + -ity；词尾 -al 在接 -ity 后重音移到 /næl/ 附近。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional → functionality**  
具有功能的 → 功能性、功能集合

added functionality 常说增加了可用功能；test the functionality of a device 是检查它的功能是否能实现。谈软件时常用作整体概念，不必总译成拗口的“功能性”；added search functionality 就是增加了搜索功能。

**常见搭配与例句**

basic functionality；additional functionality；retain functionality。

> The update adds search functionality to the app.

这次更新给应用增加了搜索功能。

> We tested the device’s basic functionality before packing it.

打包前，我们测试了设备的基本功能。

**别混淆**

function 常能数出具体一个功能；functionality 常把能做的事或功能表现作为整体来谈。

<a id="w-3"></a>

### 3. functionally — 从功能上；就实际作用而言

**音标**：/ˈfʌŋkʃənəli/

**先抓住这个画面**

先把外观、名字放一边，只看它实际完成什么工作。

**怎么拆**

functional + -ly，表示评价采用功能或实际作用的角度。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional → functionally**  
从功能或实际作用来看

functionally equivalent 说两个东西能完成相同作用，不保证材料、结构和外观一样。functionally separate 说工作上各自负责不同任务，也不一定物理上隔得很远。

**常见搭配与例句**

functionally equivalent；functionally similar；functionally separate。

> The two buttons look different but are functionally identical.

这两个按钮外观不同，但功能相同。

> The teams are functionally separate even though they share an office.

这两个团队虽然共用办公室，但职责彼此独立。

**别混淆**

physically 看物理形态，functionally 看作用；不同结构也可能在特定任务上功能相近。

<a id="w-5"></a>

### 4. functionalism — 功能主义；重视作用与功能关系的观点

**音标**：/ˈfʌŋkʃənəlɪzəm/

**先抓住这个画面**

理解一个东西时先问：它在整套系统里做什么，这种作用怎样影响设计或解释？

**怎么拆**

functional + -ism“学说、主张”。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional + -ism → functionalism**  
功能的 → 以功能为中心的观点

建筑中的 functionalism 主张形式要配合用途、材料和结构。心灵哲学中的同名观点，则按某种心理状态在系统中发挥的作用来理解它。不同领域有不同版本，不能把所有“功能主义”缩成一句“只要好用就行”。

**常见搭配与例句**

architectural functionalism；a version of functionalism；the debate over functionalism。

> The architect’s design reflects an interest in functionalism.

建筑师的设计体现了对功能主义的重视。

> The seminar compared functionalism with other theories of mind.

研讨课比较了功能主义与其他心灵理论。

**别混淆**

functional 是功能方面的形容词；functionalism 是一种理论立场。说某物好用，不一定就在主张功能主义。

<a id="w-6"></a>

### 5. functionalist — 功能主义者；功能主义的

**音标**：/ˈfʌŋkʃənəlɪst/

**先抓住这个画面**

习惯用“它承担什么作用”作为解释或设计出发点的人，以及这种观点。

**怎么拆**

functional + -ist；与 functionalism 的主张相对应，既可作名词也可作形容词。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 functional + -ist → functionalist**  
重视功能的观点 → 功能主义者、功能主义的

a functionalist 可以是某领域的功能主义者；a functionalist approach 是采取相应思路的方法。必须先看语境是在建筑、社会研究还是哲学，才知道具体主张。

**常见搭配与例句**

a functionalist approach；functionalist architecture；a functionalist account。

> The functionalist asked how the parts contributed to the whole.

这位功能主义者询问，各部分怎样为整体发挥作用。

> The article presents a functionalist account of the institution.

文章从功能主义角度解释了这个制度。

**别混淆**

functionalist 指理论立场或其支持者；functionary 指机构里的工作人员，两者虽然同族，意思相差很大。

<a id="w-4"></a>

### 6. multifunctional — 多功能的

**音标**：/ˌmʌltiˈfʌŋkʃənəl/

**先抓住这个画面**

一个空间、物件或部件可以发挥好几种作用。

**怎么拆**

multi- + functional“有某种功能的”；也可与 multifunction 联系理解，但不必认定每次都是后者加 -al。

**怎么变成今天的意思**

**拉丁 multus → 组合形式 multi-**  
多、许多；多次

↓

**英语借用 multi- 参与构词**  
与已有名词、形容词等相接，表示多个、多方面

↓

**英语 multi- + functional → multifunctional**  
具有多种功能的

multifunctional furniture 可收纳、坐卧等；a multifunctional space 可适应不同活动。比单独说 useful 更具体地强调功能种类。

**常见搭配与例句**

multifunctional furniture；a multifunctional space；multifunctional equipment。

> The small flat uses multifunctional furniture to save space.

这套小公寓用多功能家具节省空间。

> The lobby was designed as a multifunctional space.

大厅被设计成一个多功能空间。

**别混淆**

functional 常说能正常发挥作用或偏实用；multifunctional 再增加多种功能这一层意思。

<a id="w-7"></a>

### 7. nonfunctional — 不能起作用的；不具实用功能的；非功能方面的

**音标**：英 /ˌnɒnˈfʌŋkʃənəl/；美 /ˌnɑːnˈfʌŋkʃənəl/

**先抓住这个画面**

东西可能还摆在那里，但没有发挥所说的那项作用。

**怎么拆**

non-“不、非” + functional。

**怎么变成今天的意思**

**拉丁 fungi／fungor；分词词干 funct-**  
履行、执行、完成职责

↓

**两种历史分析：英语 function + -al；或中世纪拉丁 functionalis**  
两条路线都接“履行、功能”的来源，不互相当作先后阶段

↓

**英语 functional**  
与功能有关；能起作用、实用的

↓

**英语 non- + functional → nonfunctional**  
具有功能的 → 不起作用的、非功能方面的

a nonfunctional display 可能是不能工作的显示屏，也可能是只作展示的模型，须看语境。软件文档中的 nonfunctional requirements 通常谈性能、可靠性等质量要求；这里不是说这些要求“没用”。

**常见搭配与例句**

a nonfunctional prototype；a nonfunctional device；nonfunctional requirements。

> The museum uses a nonfunctional model to show the machine’s shape.

博物馆用一个不能运转的模型展示机器外形。

> The damaged keyboard is now completely nonfunctional.

损坏的键盘现在完全不能用了。

**别混淆**

malfunctioning 常指工作失常；nonfunctional 可以表示根本不能工作，也可能原本就没有实用功能。

## 这一组要分清什么

functional 可说实用，也可说可运作；设计朴素不等于功能差，理论的 functionalism 也不等于一张功能清单。

## 串起来练习

The device is functional, but its functionality is more limited than the multifunctional model.

设备能正常使用，但功能比多功能型号少。
