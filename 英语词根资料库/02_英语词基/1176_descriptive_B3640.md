# 1176 · descriptive — 描写的；描述实际状况的

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁 descriptivus 与 describere 描写词族相连，后进入英语。describe、description、descriptive 共享动作、结果、性质的历史关系。

**DESCRIPTIVE：把是什么样说明白**

一段文字告诉你颜色、声音、形状，是 descriptive writing；研究描述人实际怎样使用语言，也可叫 descriptive。

- **描写动作、内容和性质**：describe · description · descriptive

## 词形与演化规律

describe → description → descriptive 是学习对应；describe 的 scrib- 在相关形式中变为 script-，不用为此另造一个常用英语动词 descript。

## 逐词讲解

<a id="w-3"></a>

### 1. describe — 描述；描写

**音标**：/dɪˈskraɪb/

**先抓住这个画面**

describe 是把你看到或经历的东西，用话语递给没在现场的人。可以写，也可以口头说。

**怎么拆**

拉丁语 dē- + scrībere 形成 dēscrībere“写下、描画”，经法语进入英语；这里 de- 不能机械理解成否定。

**怎么变成今天的意思**

![describe 的词源演化](../assets/evolution/describe-c52028f3.svg)

历史画面是写出轮廓，现代把范围扩展到各种语言描绘。describe someone as… 是把某人说成某种样子。

**常见搭配与例句**

describe the situation（描述情况）；describe A as B（把 A 描述为 B）；describe something to someone（向某人描述某事）。

> Can you describe the person you saw?

你能描述一下你看到的那个人吗？

> She described the room to me in great detail.

她非常详细地向我描述了那个房间。

**别混淆**

不要照中文说 describe me the room；通常说 describe the room to me。tell 与 describe 的句型不完全一样。

<a id="w-2"></a>

### 2. description — 描述；说明

**音标**：/dɪˈskrɪpʃən/

**先抓住这个画面**

description 像用文字画的一幅画：别人没见过那个人或东西，读完你的描述，也能大致知道它是什么样。

**怎么拆**

经法语来自拉丁语 dēscrīptiō，是 dēscrībere“描写”的动作名词。script- 与 scrib- 是拉丁词形的对应。

**怎么变成今天的意思**

![description 的词源演化](../assets/evolution/description-c9046f7a.svg)

它可以写外貌，也可以说明职责、过程或情况。job description 不是工作的感想，而是说明这个岗位要做什么。

**常见搭配与例句**

a detailed description（详细描述）；a job description（职位说明）；a description of the scene（场景描写）。

> Her description helped us find the missing bag.

她的描述帮助我们找到了丢失的包。

> Read the job description before applying.

申请前先阅读职位说明。

**别混淆**

description 描述是什么样；explanation 解释为什么或怎么回事。definition 则划清概念的边界。

<a id="w-1"></a>

### 3. descriptive — 描述性的；描写生动的

**音标**：/dɪˈskrɪptɪv/

**先抓住这个画面**

告诉你它是什么样、发生了什么，是 descriptive 的基本方向；如果文字细节鲜明，还能说描写得很生动。

**怎么拆**

与拉丁 describere 描写及 descript- 变化词干相联，再接 -ive；现代把 describe、description、descriptive 一起看，不把剩下的 descript 当作必须单背的常用动词。

**怎么变成今天的意思**

**拉丁 describere → descript- 等**  
写下、描写的材料

↓

**英语 descriptive**  
以描述为性质、用途；描写鲜明的

a descriptive passage 描写段落；descriptive statistics 描述统计；descriptive grammar 描述实际用法的语法研究。

**常见搭配与例句**

descriptive language；a descriptive account。

> The essay opens with a descriptive passage about the harbour.

文章开头描写了港口的景象。

> The report is descriptive and makes no forecast.

报告只作描述，没有作预测。

**别混淆**

descriptive 侧重描述，prescriptive 侧重规定应该怎样；predictive 侧重预测。三个形容词回答的问题不同。

## 这一组要分清什么

descriptive 常说描述实际情况；prescriptive 常说规定应当怎样。具体学科用法仍要结合研究目的读。

## 串起来练习

The writer used descriptive language to bring the street to life.

作者用生动的描写让那条街跃然纸上。
