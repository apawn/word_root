# 2999 · pi — 希腊字母被数学借作圆周率符号

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

绕圆一圈与横穿圆心，两种长度随圆同比放大。这个直观关系说明 π 的用途，比只记一串数字更容易理解。

**PI：圆可以变大，周长与直径的比值不变**

pi 先是字母名，后来为圆周率命名，数学用途不是一个普通英语派生后缀。

- **字母与圆周率**：pi

## 词形与演化规律

希腊字母 π 的名称 → 英语 pi；圆周率符号的选择通常联系圆周相关希腊词首字母。

## 逐词讲解

<a id="w-1"></a>

### 1. pi — 希腊字母 π；圆周率

**音标**：/paɪ/

**先抓住这个画面**

一个圆沿边走一圈的长度，除以穿过圆心的直径，得到同一个比值 π。圆放大了，两种长度都一起变大，比值留下不变。

**怎么拆**

来自希腊字母名称。数学用 π 记圆周率，通常联系表示圆周的希腊词 periphereia 首字母；字母名称的历史与后来选作符号的用途要分开。

**怎么变成今天的意思**

**希腊字母名称 pi，字形 π**  
先是字母名称，数学借其作符号

↓

**π 用作普通平面圆的周长与直径之比**  
圆周率，约为 3.14159，近似值不等于精确有限小数

the value of pi 圆周率的值；pi times the diameter π 乘直径；digits of pi 圆周率各位数字。普通欧氏平面圆的周长 C = πd。

**常见搭配与例句**

the value of pi；digits of pi。

> Pi is the ratio of a circle’s circumference to its diameter.

圆周率是圆的周长与直径之比。

> The student wrote the first ten digits of pi.

学生写出了圆周率的前十位数字。

**别混淆**

3.14 是近似值，π 不是精确等于 3.14；半径 r 对应直径 d = 2r，所以 C = 2πr。

## 这一组要分清什么

pith 是日耳曼语来源的髓、核心词，与 pi 的字母名分源，不按 pi + th 来拆。
