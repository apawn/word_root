# 0357 · number — 数；数量；编号

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

number 经古法语 nombre 来自拉丁语 numerus。numbering 是编号、计数活动，outnumber 是数量多于。

**NUMBER：数有多少，也给东西一个号码**

number 的数量与编号两种功能分开看，才能读懂 numberless 的两种意思。

- **数量、编号及其过程**：number · numbering
- **数量比较与无数、无编号**：outnumber · numberless
- **number → numbered：编号、计数与期限**：numbered

## 词形与演化规律

number → numbering；outnumber 比较数量；numberless 是否定数量可数尽或否定有号码。

number 经法语接拉丁 numerus 数、数量。number + -ed，/ə/、/ɚ/ 后读 /d/；be numbered 可说编了号，days are numbered 又说时间所剩不多。

## 逐词讲解

<a id="w-1"></a>

### 1. number — 数；数量；号码；编号；总数达到

**音标**：英 /ˈnʌmbə/；美 /ˈnʌmbər/

**先抓住这个画面**

既能说有多少，也能给每个东西一个便于认出的号。

**怎么拆**

名词经古法语 nombre、盎格鲁法语 noumbre 接拉丁 numerus；动词有古法语 nombrer 的借入支线，不必全看成英语名词临时变动词。

**怎么变成今天的意思**

**拉丁 numerus**  
数；数量

↓

**古法语 nombre / 盎格鲁法语 noumbre；动词 nombrer**  
数量；数、计数

↓

**中古英语 nombre / nombren → 英语 number**  
数、号码；计数、编号

a phone number 是识别号码，不是电话总数。the number of students 说学生总人数，通常接单数动词；a number of students 相当于若干学生，接复数动词。动词还可说给页面编号、人数总计多少。

**常见搭配与例句**

the number of；a number of；a phone number；number the pages。

> The number of visitors has doubled.

访客总人数翻了一番。

> A number of visitors have asked for a map.

有些访客索要了地图。

> Please number the pages before printing the document.

打印文档前请给页面编号。

> The volunteers now number over a hundred.

志愿者现在总共有一百多人。

**别混淆**

numeral 更明确指表示数的符号；number 可指抽象数值、数量或识别号码。

<a id="w-5"></a>

### 2. numbered — 编了号的；计数了；数量达〔过去式、过去分词〕

**音标**：英 /ˈnʌmbəd/；美 /ˈnʌmbɚd/

**先抓住这个画面**

给每一页、每件东西标上号码，是 numbered；把一群人的数量算出来，也能用这个词。

**怎么拆**

number + -ed → numbered，/ə/、/ɚ/ 后读 /d/，不另加 /ɪd/ 音节。number 经法语 nombre、nombrer 等接拉丁 numerus 数、数量。

**怎么变成今天的意思**

**拉丁 numerus 数、数量 → 法语对应名词、动词 → number**  
英语名词和动词有相应来源

↓

**number + -ed → numbered**  
编号、计数或说明总数的过去形式

numbered pages 是标了页码的页面；numbered from one to ten 是从一编到十；days are numbered 是所剩时间不多。

**常见搭配与例句**

numbered pages；numbered from one to ten；its days are numbered。

> The pages are numbered from one to fifty.

这些页面从一编到了五十。

> The old system’s days were numbered once the replacement arrived.

替代系统到来后，旧系统就用不了多久了。

**别混淆**

be numbered 的意义看搭配；the system’s days are numbered 不是给系统的日子逐个写编号，而是说它快被取代、结束了。

<a id="w-2"></a>

### 3. numbering — 编号；编号方式；号码顺序

**音标**：英 /ˈnʌmbərɪŋ/；美 /ˈnʌmbərɪŋ/

**先抓住这个画面**

把一串号码安到一组东西上，让人能按号寻找。

**怎么拆**

number 加 -ing；中古英语已有 nombrynge。作为名词常指编号过程或采用的编号体系。

**怎么变成今天的意思**

**拉丁 numerus**  
数；数量

↓

**古法语 nombrer → 中古英语 nombren / nombrynge**  
计数、编号；编号的过程

↓

**英语 number / numbering**  
给号；编号方法与顺序

page numbering 是页码设置；a numbering system 是如何分配号码的规则。号码不一定从一连续递增，也可能按区域、类别分段。

**常见搭配与例句**

page numbering；a numbering system；consecutive numbering。

> The page numbering starts after the introduction.

页码从引言之后开始。

> The new numbering system makes each item easier to trace.

新的编号体系让每件物品更容易追踪。

**别混淆**

counting 重点是算出总数；numbering 重点是给对象标上号码。

<a id="w-4"></a>

### 4. numberless — 无数的；没有号码的

**音标**：英 /ˈnʌmbələs/；美 /ˈnʌmbərləs/

**先抓住这个画面**

可以是多得数不过来，也可以按字面说没有给它分配号码。

**怎么拆**

number + -less，没有……的；常用文学性义把没有可给出的数理解成数量极多，另有无编号的字面用法。

**怎么变成今天的意思**

**拉丁语 numerus → 古法语 nombre → 中古英语 number**  
数；数量

↓

**英语 number**  
数字、数量、编号；还可作编号等动词

↓

**number + -less → numberless**  
数、号码 → 无数；没有号码的

numberless stars 无数星辰；a numberless house 没有门牌号的房子。前者偏文学，日常很多场合直接说 countless、many。

**常见搭配与例句**

numberless stars；numberless times；a numberless door。

> Numberless stars filled the dark sky.

无数星辰布满夜空。

> The address led us to a numberless door in a narrow lane.

地址把我们带到一条窄巷里一扇没有门牌号的门前。

**别混淆**

numberless 不等于数量为零；无数与无编号由名词、上下文分清。numbered 则是有编号的。

<a id="w-3"></a>

### 5. outnumber — 数量超过；人数多于

**音标**：英 /ˌaʊtˈnʌmbə/；美 /ˌaʊtˈnʌmbər/

**先抓住这个画面**

两边排开来数，这一边的人或东西更多。

**怎么拆**

out-“超过” + number；这里 out 表示在数量上胜过，不是把数字拿到外面。

**怎么变成今天的意思**

**拉丁 numerus**  
数；数量

↓

**古法语 nombre / 盎格鲁法语 noumbre；动词 nombrer**  
数量；数、计数

↓

**中古英语 nombre / nombren → 英语 number**  
数、号码；计数、编号

↓

**英语 out- + number → outnumber**  
在数量上超过

A outnumbers B 表示 A 比 B 多。be outnumbered 则是自己处在人数或数量较少的一边；不是说自己一定会输。

**常见搭配与例句**

outnumber someone；be heavily outnumbered；outnumber two to one。

> On this street, bicycles outnumber cars.

这条街上的自行车比汽车多。

> The home fans outnumbered the visitors by three to one.

主队球迷人数是客队球迷的三倍。

**别混淆**

outperform 是表现更好；outnumber 只比较数量，多不等于强。

## 这一组要分清什么

numberless 常是无数，不是零；a numberless door 则可以是没有门牌号码的门。

## 串起来练习

The volunteers numbered the boxes, but two remained numberless.

志愿者给箱子编号，但仍有两个没有标上号码。
