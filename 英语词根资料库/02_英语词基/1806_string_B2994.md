# 1806 · string — 细绳、弦，及绳般排列和束缚的扩展

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

先抓细线，再看拉紧、串连、支撑三种画面。字符串把字符排成一串；限制条件像牵制的绳；并非每个后来义都能追成一个确定的故事。

**STRING：细长能绷紧，也能把许多东西串起来**

string → stringed/stringy/stringer；鞋、抽拉、膝后部分别和 string 组成有用途的词。

- **线、弦与性质角色**：string · stringed · stringy · stringer
- **绳的用途与比喻**：shoestring · drawstring · hamstring
- **string → strings：一根根绳、弦与串起来的条件**：string · strings

## 词形与演化规律

strenġ → string；string + -ed/-y/-er；shoe/draw/ham + string；动词常见 string/strung/strung。

古英语 streng 的绳线材料，延伸到弦、字符串和牵制关系。

## 逐词讲解

<a id="w-1"></a>

### 1. string — 细绳、线；弦；一串、一系列；字符串；穿成串、给……装弦

**音标**：/strɪŋ/

**先抓住这个画面**

一根细绳能拴东西，也能把珠子串起来；把珠子换成事件、字母，就有一连串事情和字符串。

**怎么拆**

接古英语 strenġ，与绷紧、绳索的日耳曼语词族相关，不是英语 strong 删字得到。动词由名词发展，常见过去式、分词 strung。

**怎么变成今天的意思**

**古英语 strenġ → 中古英语 streng/string → string**  
绳、线，联系绷紧的古老词族

↓

**英语意义扩展**  
弦；串在一起的物件 → 一连串事件、文字字符

a piece of string 一段细绳，guitar strings 吉他弦，a string of failures 一连串失败，a text string 文本字符串，string beads 把珠子穿成串。no strings attached 没有附带条件。

**常见搭配与例句**

a piece of string；a string of；guitar strings；no strings attached。

> She tied the parcel with a piece of string.

她用一段细绳捆好包裹。

> A string of small mistakes delayed the project.

一连串小错误拖慢了项目。

**别混淆**

string 绳线一般比 rope 细；a string of events 不要求东西真的挂在线上。计算机的字符串可含数字字符，但不因此自动成可运算的数值。

<a id="w-8"></a>

### 2. strings — 绳、弦、字符串〔复数〕；串起〔第三人称单数〕

**音标**：/strɪŋz/

**先抓住这个画面**

一根细长的线能捆东西、绷成琴弦，也能把东西一个个串起来。strings 把实体的绳线和连续排列的比喻连起来。

**怎么拆**

string + -s，/ŋ/ 后读 /z/。string 继承古英语 streng，接绷紧、绳索的日耳曼词族；动词串起由名词发展。

**怎么变成今天的意思**

**古英语 streng → string**  
绳、线 → 弦；串起来的东西、文字

↓

**string + -s → strings**  
多根绳弦、多个字符串；某人把东西串起

guitar strings 吉他弦；strings of lights 一串串灯；text strings 文本字符串。

**常见搭配与例句**

no strings attached 不附加条件；pull strings 托关系、暗中运作。

> Two guitar strings needed replacing.

两根吉他弦需要更换。

> The program compares short strings of text.

程序比较短文本字符串。

**别混淆**

no strings attached 借绳线说牵制，不是真的检查有没有绳子。strings 动词三单与过去式 strung 分开，不写 stringed 来替代所有常用过去义。

<a id="w-3"></a>

### 3. stringer — 特约通讯员、非正式员工的供稿者；纵向支撑构件等

**音标**：英 /ˈstrɪŋə/；美 /ˈstrɪŋər/

**先抓住这个画面**

新闻里是没有列入正式记者编制、按约为媒体供稿的人；工程图上则可能是一根沿长度方向支撑结构的构件。

**怎么拆**

string + -er，早有做弓弦者等人物义，支撑构件借线条般长形命名。新闻义的具体来路并非确定；有词源解释联系把词串起来的写作者，不能断言是记者把稿子挂绳上量长度。

**怎么变成今天的意思**

**古英语 strenġ → 中古英语 streng/string → string**  
绳、线，联系绷紧的古老词族

↓

**英语意义扩展**  
弦；串在一起的物件 → 一连串事件、文字字符

↓

**string + -er → stringer**  
制弦、穿串者；长条支撑件

↓

**新闻用法发展**  
非正式编制的通讯供稿者；具体命名路线有不确定性

a local stringer 当地特约通讯员，a freelance stringer 自由供稿通讯员，a stair stringer 楼梯侧面承托踏步的构件。

**常见搭配与例句**

a local stringer；a freelance stringer；a stair stringer。

> The newspaper relies on a local stringer for reports from the island.

报社依靠当地特约通讯员报道岛上的消息。

> The carpenter checked the stair stringer before fitting the steps.

木工安装踏步前检查了楼梯侧梁。

**别混淆**

stringer 不保证一定业余或水平低，关键是工作关系；staff reporter 则是媒体正式记者。工程义也不是弹弦的人。

<a id="w-6"></a>

### 4. stringed — 有弦的、装弦的

**音标**：/strɪŋd/

**先抓住这个画面**

乐器上装着能振动发声的弦，就有 stringed 这个性质。

**怎么拆**

string + -ed，接中古英语相应形式；这里 -ed 可以表装有、具有。结尾读 /d/，整个词不因 -ed 再多一个音节。

**怎么变成今天的意思**

**古英语 strenġ → 中古英语 streng/string → string**  
绳、线，联系绷紧的古老词族

↓

**英语意义扩展**  
弦；串在一起的物件 → 一连串事件、文字字符

↓

**string + -ed → stringed**  
有弦的，装了弦的

a stringed instrument 弦乐器，a stringed musical instrument 有弦的乐器；吉他、竖琴、小提琴都可包含在广义里。

**常见搭配与例句**

a stringed instrument；stringed musical instruments。

> The exhibition includes stringed instruments from several countries.

展览包括来自几个国家的弦乐器。

> She chose a stringed instrument rather than a wind instrument.

她选择了弦乐器，而不是管乐器。

**别混淆**

stringed 强调具有弦的性质；strung 常是 string 动词的过去分词。the strings 作乐队分部时常有更具体范围，不能机械等同所有带弦乐器。

<a id="w-7"></a>

### 5. stringy — 纤维多而难嚼的；细长成丝的；瘦而筋腱明显的

**音标**：/ˈstrɪŋi/

**先抓住这个画面**

食物一口咬下去全是拉不断的丝，或头发结成一绺绺细条，都让人想到 string。

**怎么拆**

string + -y，-y 表具有绳线般性质。可从材料组成走向咀嚼口感、外观；不同对象不能全译成像绳子。

**怎么变成今天的意思**

**古英语 strenġ → 中古英语 streng/string → string**  
绳、线，联系绷紧的古老词族

↓

**英语意义扩展**  
弦；串在一起的物件 → 一连串事件、文字字符

↓

**string + -y → stringy**  
成丝、多纤维；细瘦而筋腱明显

stringy meat 纤维粗韧难嚼的肉，stringy celery 纤维多的芹菜，stringy hair 一绺绺的头发；评价外貌时常不太好听。

**常见搭配与例句**

stringy meat；stringy celery；stringy hair。

> The meat was tough and stringy.

那块肉又老又多筋，嚼不动。

> His wet hair hung in stringy strands.

他湿漉漉的头发一绺绺地垂着。

**别混淆**

stringy 和 stretchy 有时都能形容拉丝，但 stringy 强调丝条、纤维，stretchy 强调能拉伸。stringy meat 不只是肉被切成长条。

<a id="w-2"></a>

### 6. hamstring — 腘绳肌、膝后相关肌腱；严重妨碍、束缚

**音标**：/ˈhæmstrɪŋ/

**先抓住这个画面**

腿后方有像绷紧绳索的肌腱，帮助腿活动；比喻中让一个项目迈不开腿，就是 hamstring it。

**怎么拆**

ham 这里是膝后部的旧义 + string 绳、筋腱，现代也用来称大腿后侧肌群。动词借使腿失去行动力的画面表达严重限制；英语比喻义记录还早于字面伤害义，并非火腿捆绳。

**怎么变成今天的意思**

**古英语 strenġ → 中古英语 streng/string → string**  
绳、线，联系绷紧的古老词族

↓

**英语意义扩展**  
弦；串在一起的物件 → 一连串事件、文字字符

↓

**ham 膝后部 + string → hamstring**  
腿后相关肌腱、肌群

↓

**动词比喻**  
借失去行动力的画面 → 严重妨碍项目、组织等

a hamstring injury 腘绳肌损伤，tight hamstrings 腿后肌群紧绷，be hamstrung by 缺乏某条件而受阻；过去式、分词常用 hamstrung。

**常见搭配与例句**

a hamstring injury；tight hamstrings；be hamstrung by。

> The player missed the match with a hamstring injury.

球员因腘绳肌损伤缺席比赛。

> The research was hamstrung by a lack of funding.

资金短缺让研究难以推进。

**别混淆**

ham 在此不是熟食火腿；hamstring 项目是比喻限制行动，不是单说有一点不方便。

<a id="w-4"></a>

### 7. shoestring — 鞋带；极少的钱、微薄预算；细长条

**音标**：/ˈʃuːstrɪŋ/

**先抓住这个画面**

字面是一根鞋带；说 on a shoestring，就像手里只剩一根细鞋带那么点资源，也得把事情做起来。

**怎么拆**

shoe 鞋 + string 绳，先形成鞋带名词。极少资金是由细小、有限的形象发展出的习惯比喻，不是拿鞋带当货币的史实。

**怎么变成今天的意思**

**古英语 strenġ → 中古英语 streng/string → string**  
绳、线，联系绷紧的古老词族

↓

**英语意义扩展**  
弦；串在一起的物件 → 一连串事件、文字字符

↓

**shoe + string → shoestring**  
鞋带 → 细长条；on a shoestring 用极少资金

on a shoestring 靠微薄预算，a shoestring budget 极低预算，shoestring fries 细条薯条。日常鞋带也常用 shoelace。

**常见搭配与例句**

on a shoestring；a shoestring budget；shoestring fries。

> They made the film on a shoestring.

他们用极少的经费拍成了这部电影。

> We ordered sandwiches and shoestring fries.

我们点了三明治和细条薯条。

**别混淆**

a shoestring budget 是钱很少，不是预算写在鞋带上；shoestring fries 是形状细长，不是鞋带做的食物。

<a id="w-5"></a>

### 8. drawstring — 抽绳、束口绳

**音标**：/ˈdrɔːstrɪŋ/

**先抓住这个画面**

拉一下绳，袋口或裤腰就收紧；绳在布边通道里滑动，把开口聚拢。

**怎么拆**

draw 拉 + string 绳。draw 在这里不是画画；合成词指出绳的用途，常装在袋口、裤腰或兜帽边。

**怎么变成今天的意思**

**古英语 strenġ → 中古英语 streng/string → string**  
绳、线，联系绷紧的古老词族

↓

**英语意义扩展**  
弦；串在一起的物件 → 一连串事件、文字字符

↓

**draw + string → drawstring**  
拉动就能收紧开口的绳

a drawstring bag 抽绳袋，a drawstring waist 抽绳裤腰，tighten the drawstring 拉紧抽绳。

**常见搭配与例句**

a drawstring bag；a drawstring waist；tighten the drawstring。

> Pull the drawstring to close the bag.

拉抽绳，把袋口收起来。

> The trousers have a comfortable drawstring waist.

这条裤子的抽绳裤腰穿着很舒服。

**别混淆**

drawstring 是具体结构和用途；shoelace 是鞋带。两者都可能用绳，但不能只因材料相同就随意互换。

## 这一组要分清什么

draw 这里是拉；ham 是膝后旧义；stringed 有弦，strung 动词分词；stringer 新闻义不编造唯一来源；on a shoestring 说预算很少。

## 串起来练习

The stringer covered the concert on a shoestring budget.

那位特约通讯员用很少的预算报道了音乐会。
