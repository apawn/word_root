# 2981 · processor — 执行处理的部件，前缀限定微型、协同、多处理或预处理

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

micro- 说微型集成处理器名称，co- 说协助角色，multi- 说多个处理部件，pre- 说正式处理之前的一步。preprocessor 还常是软件工具，不一律是芯片。

**PROCESSOR：承担处理工作，前缀再说角色和结构**

processor → microprocessor、coprocessor、multiprocessor、preprocessor。

- **处理器、微处理器与协同角色**：processor · microprocessor · coprocessor
- **多处理配置与预处理工具**：multiprocessor · preprocessor

## 词形与演化规律

process + -or → processor；micro- 微，co- 协同，multi- 多，pre- 之前。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| [microprocessor](#w-2) | 英 /ˌmaɪkrəʊˈprəʊsesə/；美 /ˌmaɪkroʊˈprɑːsesər/ | 微处理器 |

## 逐词讲解

<a id="w-1"></a>

### 1. processor — 处理器；加工设备、企业；处理某事者

**音标**：英 /ˈprəʊsesə/；美 /ˈprɑːsesər/

**先抓住这个画面**

把东西送进去，按规则变成结果的那个人、设备或机构；电脑里处理指令的芯片是常见一例。

**怎么拆**

process + -or，-or 形成执行作用的人、物名称。电脑处理器、食品加工机、加工企业等取不同对象，不是所有 processor 都是 CPU。

**怎么变成今天的意思**

**拉丁 prōcēdere → prōcessus → 法语 proces → 英语 process**  
向前推进 → 行进、进程、过程

↓

**英语 process 的动词和派生词**  
按程序处理；处理过的；执行处理的设备、人或机构

↓

**process + -or → processor**  
处理 → 执行处理的人、设备、机构

a computer processor 计算机处理器，a food processor 食品加工机，a payment processor 支付处理服务商；word processor 文字处理软件或设备。

**常见搭配与例句**

a computer processor；a food processor；a payment processor；a word processor。

> The laptop has a more powerful processor.

这台笔记本电脑有一个更强的处理器。

> She chopped the vegetables in a food processor.

她用食品加工机切碎了蔬菜。

**别混淆**

processor 是执行处理的设备或主体，process 是过程或处理动作；processing 是处理活动，三者句法对象不同。

<a id="w-2"></a>

### 2. microprocessor — 微处理器

**音标**：英 /ˌmaɪkrəʊˈprəʊsesə/；美 /ˌmaɪkroʊˈprɑːsesər/

**先抓住这个画面**

把执行指令和处理数据的核心功能装进很小的芯片里。

**怎么拆**

micro- 小 + processor 处理器；近代电子技术复合词，不是每个里面有 micro 的东西都按百万分之一计算。

**怎么变成今天的意思**

**希腊 mikros 小 → 组合形式 micro-**  
通常说小；在计量单位前严格表示百万分之一

↓

**英语 micro- + processor → microprocessor**  
小型集成电路中的处理器

a microprocessor controls the device 是微处理器控制设备。它能执行程序和处理数据，但整台机器还需要存储、电源及其他部件配合。

**常见搭配与例句**

a microprocessor chip；a powerful microprocessor；controlled by a microprocessor。

> A microprocessor controls the washing machine’s cycle.

微处理器控制洗衣机的运行程序。

> The engineers tested the new microprocessor under different loads.

工程师测试了新微处理器在不同负载下的表现。

**别混淆**

microchip 是芯片统称，microprocessor 强调计算和控制功能；不能把所有芯片都叫处理器。

<a id="w-3"></a>

### 3. coprocessor — 协处理器

**音标**：英 /ˌkəʊˈprəʊsesə/；美 /ˌkoʊˈprɑːsesər/

**先抓住这个画面**

主处理器负责总体工作，某些专门计算交给旁边能协同完成的处理部件，是 coprocessor 的角色画面。co- 点明一起分工，不要求它一定装在另一块独立电路板上。

**怎么拆**

co- 共同、协同 + processor 处理器。计算机按辅助主处理器的任务关系命名，常用于浮点计算、图形等专门处理角色。

**怎么变成今天的意思**

**process 处理 → processor 处理器、处理者**  
执行相应处理任务

↓

**co- 一起、协同 + processor → coprocessor**  
协助主处理器承担特定任务的处理器

a maths coprocessor 数学协处理器；a graphics coprocessor 图形协处理器；a dedicated coprocessor 专用协处理器。

**常见搭配与例句**

a maths coprocessor；a dedicated coprocessor。

> The system used a coprocessor for specialised calculations.

系统使用协处理器完成专门计算。

> The diagram shows how the main processor communicates with the coprocessor.

图示展示主处理器怎样与协处理器通信。

**别混淆**

coprocessor 说协助关系，multiprocessor 说多处理器配置；不靠同一个中文“多”来混同。

<a id="w-4"></a>

### 4. preprocessor — 预处理器；预处理程序

**音标**：英 /priːˈprəʊsesə/；美 /ˈpriːˌprɑːsesər/

**先抓住这个画面**

把原材料先整理一遍，再交给后面的主要处理程序。

**怎么拆**

pre- + processor；在计算机语境中指执行前置处理的程序或组件，不一定是一块硬件芯片。

**怎么变成今天的意思**

**拉丁语 prae → 法语、中世纪拉丁语 pre- → 英语 pre-**  
时间在先；位置在前；后来可与英语现成词自由组合

↓

**英语 pre- + processor → preprocessor**  
在主要处理前先加工输入的程序、设备

C 预处理器可展开宏、引入头文件、按条件保留代码等，让后续编译阶段处理变换后的内容。别把名字中的 processor 一律理解为 CPU。

**常见搭配与例句**

the C preprocessor；a preprocessor directive；preprocessor output。

> The preprocessor expands the macro before the code is compiled.

预处理器在代码编译前展开这个宏。

> We inspected the preprocessor output to find the missing declaration.

我们查看了预处理器输出，以查找缺失的声明。

**别混淆**

compiler 负责更完整的编译工作；preprocessor 负责前置变换，实际工具可以把两者整合。

<a id="w-5"></a>

### 5. multiprocessor — 多处理器的；多处理器系统

**音标**：英 /ˌmʌltiˈprəʊsesə/；美 /ˌmʌltiˈprɑːsesər/

**先抓住这个画面**

让多个处理单元共同参与计算，而不只依赖一个。

**怎么拆**

multi- + processor“处理器”；processor 来自 process + -or，整个词是现代计算机复合词。

**怎么变成今天的意思**

**拉丁 multus → 组合形式 multi-**  
多、许多；多次

↓

**英语借用 multi- 参与构词**  
与已有名词、形容词等相接，表示多个、多方面

↓

**英语 multi- + processor → multiprocessor**  
含多个处理器的系统或结构

a multiprocessor system 是多处理器系统；具体文献对处理器、核心的划分可能不同，读架构说明时要看它的定义。不是只开了几个软件窗口就叫多处理器。

**常见搭配与例句**

a multiprocessor system；multiprocessor architecture；a multiprocessor machine。

> The operating system supports multiprocessor systems.

这个操作系统支持多处理器系统。

> The team tested the workload on a multiprocessor machine.

团队在一台多处理器机器上测试了这项工作负载。

**别混淆**

multicore 强调一颗芯片内多个核心；multiprocessor 强调系统中多个处理器，较广的讨论中两者可能有交集。

## 这一组要分清什么

coprocessor 与 multiprocessor 的观察点不同；preprocessor 不自动指硬件。

## 串起来练习

The processor delegated a specialised task to the coprocessor.

处理器把一项专门任务交给协处理器。
