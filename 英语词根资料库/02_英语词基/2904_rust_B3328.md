# 2904 · rust — 红褐铁锈的颜色和久不用的生疏感

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

铁门、工具给出实物画面；多年不练的钢琴、外语给出比喻画面。生疏往往意味着以前学过，练习断了。

**RUST：金属不再灵活，技能也会像生锈一样**

rust 是锈、生锈；rusty 是有锈的，也可说本领生疏。

- **锈与有锈、生疏的状态**：rust · rusty

## 词形与演化规律

古英语 rust → rust；rust + -y → rusty。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

|---|---|---|

## 逐词讲解

<a id="w-1"></a>

### 1. rust — 铁锈；生锈；锈色；植物锈病

**音标**：/rʌst/

**先抓住这个画面**

铁器表面长出红褐色、松散的腐蚀层，就是最熟悉的 rust。东西放着不用会锈，人的本领久不用也借来讲“生锈”。

**怎么拆**

承古英语 rust，经中古英语 rust、rost 等延续，词源联系红色词族。后来扩展到锈色；植物叶片上有锈色斑点的一类真菌病也叫 rust。

**怎么变成今天的意思**

**古英语 rust → 中古英语 rust、rost 等 → rust**  
铁锈，和红色的古老词族有关

↓

**rust + -y → rusty；生锈 → 技能久不用而生疏**  
物质表面的锈、锈色；不再灵活熟练

covered in rust 满是铁锈；rust away 锈蚀损坏；rust spots 锈斑。作锈这种物质时通常不可数。

**常见搭配与例句**

covered in rust；rust away。

> There was rust around the edge of the old tin.

旧铁罐边缘有一圈锈。

> The unused tools began to rust.

那些闲置的工具开始生锈。

**别混淆**

corrosion 是腐蚀的大类，rust 常指铁、钢的锈蚀产物；不是所有金属变色都叫铁锈。

<a id="w-2"></a>

### 2. rusty — 生锈的；锈色的；技能生疏的

**音标**：/ˈrʌsti/

**先抓住这个画面**

一把锈住的剪刀不再灵活，久没用的外语也可能不顺手。rusty 把金属生锈的状态借给暂时生疏的技能。

**怎么拆**

rust + -y → rusty。原来描述锈覆盖、锈颜色，后来用于缺乏练习、不再熟练的比喻。

**怎么变成今天的意思**

**古英语 rust → 中古英语 rust、rost 等 → rust**  
铁锈，和红色的古老词族有关

↓

**rust + -y → rusty**  
有锈、锈色 → 久不用而生疏

a rusty gate 生锈的门；be rusty at something 某方面生疏；My French is rusty 我的法语生疏了。

**常见搭配与例句**

a rusty lock；a bit rusty at maths。

> The rusty gate was difficult to open.

那扇生锈的门很难打开。

> My piano playing is a little rusty after five years without practice.

五年没练，我的钢琴弹得有点生疏了。

**别混淆**

rusty 常暗示以前会、现在缺练习；不会一个技能，不一定适合说 rusty。

## 这一组要分清什么

rust 通常是铁、钢的锈；更广的腐蚀叫 corrosion。

## 串起来练习

The tools were rusty, and his repair skills were rusty too.

工具生锈了，他的修理手艺也生疏了。
