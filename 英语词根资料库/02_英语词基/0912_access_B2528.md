# 0912 · access — 进入、使用与减少理解障碍

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

拉丁接近词形成名词与关系形容词，经法语进入英语；现代扩展到设施、信息、文字理解。

**ACCESS：能进去；ACCESSIBLE：能接近、用得上**

access 已精讲，紧接 accessible → inaccessible、accessibility。

- **基本进入与可用性质**：access · accessible
- **否定与性质名词**：inaccessible · accessibility
- **access → accessed：访问、获取**：access · accessed

## 词形与演化规律

access → 相关借入形容词 accessible；in- + accessible；accessible + -ity → accessibility。

ss 后 ed 读 t，不另加音节。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| 单词 | 音标 | 核心意思 |
|---|---|---|
| [access](#w-1) | /ˈækses/ | 进入或使用的机会、权利；通道；访问、获取 |
| [accessible](#w-2) | /əkˈsesəbl/ | 可到达、可使用的；无障碍的；易理解的 |
| [accessibility](#w-3) | /əkˌsesəˈbɪləti/ | 可达性；易用、易理解程度；无障碍性 |
| [inaccessible](#w-4) | /ˌɪnəkˈsesəbl/ | 难以到达的；无法使用的；难懂的 |
| [accessed](#w-5) | /ˈæksest/ | 访问了、获取了、进入了〔过去式、过去分词〕 |

## 逐词讲解

<a id="w-1"></a>

### 1. access — 进入或使用的机会、权利；通道；访问、获取

**音标**：/ˈækses/

**先抓住这个画面**

能够走到它那里，再接触或使用它。

**怎么拆**

接拉丁 accessus“走近、通路”，可经法语 acces 或直接借入；现代“访问”动词由名词发展。

**怎么变成今天的意思**

**拉丁 cēdere；分词词干 cess-**  
走、离开；让步、让出

↓

**拉丁 ad- + cēdere → accēdere**  
走近、进入；加入、答应

↓

**拉丁 accessus／法语 acces → 中古英语 acces / accesse**  
接近、进入；早期也说发作

↓

**英语 access 名词 → 动词**  
进入机会、通道 → 访问、获取

have access to a library 是能使用图书馆，不一定拥有它；access a file 是打开或读取文件。名词常带 to，动词直接接宾语。

**常见搭配与例句**

have access to；gain access；access a database。

> Students have free access to the archive.

学生可以免费使用档案库。

> You can access the document from your phone.

你可以通过手机访问这份文档。

**别混淆**

accede to 是正式同意、加入或就位；access 是能够接近或使用。不能把 access to 当成所有动词场景的固定组合。

<a id="w-2"></a>

### 2. accessible — 可到达、可使用的；无障碍的；易理解的

**音标**：/əkˈsesəbl/

**先抓住这个画面**

路能走到，设施用得上，文章读得懂：共同点是原本隔着的障碍少了。

**怎么拆**

经法语及晚期拉丁 accessibilis，接 accessus 接近、入口；现代可对应 access + -ible。形容词有自己的借入历史。

**怎么变成今天的意思**

**拉丁 ad- + cēdere → accēdere；accessus**  
朝向 + 走 → 接近；接近、入口

↓

**晚期拉丁 accessibilis → 法语 accessible → 英语 accessible**  
能够接近、进入 → 易用、易理解

accessible by bus 公交可达，accessible to everyone 人人可用，an accessible explanation 通俗解释；无障碍设施强调相关使用者确实能用。

**常见搭配与例句**

accessible to；accessible by bus；an accessible explanation；an accessible entrance。

> The museum is accessible by public transport.

博物馆乘公共交通可以到达。

> She gives an accessible explanation of a difficult idea.

她把一个难懂的想法解释得通俗易懂。

**别混淆**

available 有供应、可获得，accessible 能接近、能使用；有一份文件不一定所有人都能打开或读懂。

<a id="w-3"></a>

### 3. accessibility — 可达性；易用、易理解程度；无障碍性

**音标**：/əkˌsesəˈbɪləti/

**先抓住这个画面**

把能不能到、用起来有没有障碍作为一个整体问题：入口、文字、操作都可能影响它。

**怎么拆**

accessible + -ity，-ible 对应 -ibility，形成性质名词；受到法语、晚期拉丁相应名词形式影响。重音移到 -bil-。

**怎么变成今天的意思**

**拉丁 ad- + cēdere → accēdere；accessus**  
朝向 + 走 → 接近；接近、入口

↓

**晚期拉丁 accessibilis → 法语 accessible → 英语 accessible**  
能够接近、进入 → 易用、易理解

↓

**accessible + -ity → accessibility**  
可接近、可使用、可理解的程度及设计性质

website accessibility 网站无障碍，improve accessibility 提高可达性和易用性，accessibility features 无障碍功能；具体对象决定评估内容。

**常见搭配与例句**

improve accessibility；website accessibility；accessibility features。

> The redesign improved the website’s accessibility.

改版提高了网站的无障碍性。

> The survey asks residents about the accessibility of local services.

问卷询问居民使用当地服务是否方便、有无障碍。

**别混淆**

access 是进入或使用的机会、动作，accessibility 说这种进入、使用有多可行；无障碍性不只是否装了坡道。

<a id="w-4"></a>

### 4. inaccessible — 难以到达的；无法使用的；难懂的

**音标**：/ˌɪnəkˈsesəbl/

**先抓住这个画面**

入口被隔断、资料打不开，或文章太晦涩，让人进不去。

**怎么拆**

经法语接晚期拉丁 inaccessibilis；现代可分析 in- 不 + accessible，in- 在这里否定，不是表示里面。

**怎么变成今天的意思**

**拉丁 ad- + cēdere → accēdere；accessus**  
朝向 + 走 → 接近；接近、入口

↓

**晚期拉丁 accessibilis → 法语 accessible → 英语 accessible**  
能够接近、进入 → 易用、易理解

↓

**拉丁 in- + accessibilis → 法语、英语 inaccessible**  
不能接近、使用或理解

an inaccessible island 难抵达的岛，inaccessible data 无法访问的数据，inaccessible writing 晦涩文字。

**常见搭配与例句**

inaccessible to；inaccessible data；an inaccessible location。

> The village became inaccessible after the bridge collapsed.

桥塌后村庄变得无法到达。

> The report was inaccessible to readers without a subscription.

未订阅的读者无法访问报告。

**别混淆**

inaccessible 不一定不存在；文件可能完好，但你没有权限或连接不上。inaccessible 与 unacceptable 不可接受也要分。

<a id="w-5"></a>

### 5. accessed — 访问了、获取了、进入了〔过去式、过去分词〕

**音标**：/ˈæksest/

**先抓住这个画面**

原来有一道通路或入口，现在通过它拿到文件、信息或系统内容，是 accessed。重点是取得接触、使用的机会。

**怎么拆**

access 接拉丁 accessus 走近、通路，连 ad- + cedere，可能经法语或直接借入；英语访问动词由名词发展。现代直接加完整 -ed，/s/ 后读 /t/。

**怎么变成今天的意思**

**拉丁 accedere、accessus → 名词 access → 动词**  
走近、通路 → 访问、获取

↓

**access + -ed → accessed**  
已经访问、读取或进入

accessed the file 访问、读取了文件；accessed online 在线获取；accessed through… 通过……进入。

**常见搭配与例句**

accessed the archive 查阅了档案；easily accessed 容易访问、到达的。

> She accessed the archive through the library website.

她通过图书馆网站查阅了档案。

> The file was accessed from two different computers.

这个文件曾从两台不同电脑访问过。

**别混淆**

accessed 不自动等于修改了内容。打开、读取或接触到，都可能这样说；是否改动要另看动词。

## 这一组要分清什么

available 有供应不保证 accessible 能用；inaccessible 不等于不存在；accessibility 不只坡道。

## 串起来练习

Better accessibility makes the service accessible to more people.

改善无障碍性让更多人能使用这项服务。
