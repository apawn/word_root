# 2214 · spider — 按纺丝行为形成的动物名，再借网形成技术比喻

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

历史解释负责说明名称来历，现代分类、动物行为要分别理解；有产丝能力，不代表所有蜘蛛都织同样的捕猎网。

**SPIDER：历史上可理解为纺丝的动物**

spider → spiderweb；计算机 spider 借网页链接之网。

- **动物、网与技术比喻**：spider · spiderweb
- **纺丝者的老名称 → spider → spiders**：spiders

## 词形与演化规律

spin 相关旧词族 → spīþra 等 → spider；web 网形成 spiderweb。

spider 承古英语 spiðra，远接纺、拉伸词族；历史中 n 脱落、th 与 d 等变化造成现代外形。复数 -s，不能把词尾误作现代 -er 才解释整词。

## 逐词讲解

<a id="w-1"></a>

### 1. spider — 蜘蛛；网络爬虫程序

**音标**：英 /ˈspaɪdə/；美 /ˈspaɪdər/

**先抓住这个画面**

蜘蛛会产丝，名称历史上就联系纺丝。网络程序沿着网页链接到处搜集信息，也借蜘蛛在网上活动的形象叫 spider。

**怎么拆**

承古英语 spīþra 等，经中古英语 spithre、spider。更早联系 spin 纺丝的日耳曼词族；历经音变，不是现代英语直接把 spin + -er 原样拼成 spider。

**怎么变成今天的意思**

**日耳曼语纺、纺丝的词族**  
按纺丝行为给动物命名

↓

**古英语 spīþra 等 → 中古英语 spithre、spider → spider**  
原来类似纺丝者的名称，音变后成为现代词形

↓

**网的比喻用于计算机**  
沿网页链接爬行、收集信息的程序

a spider’s web／spiderweb 蜘蛛网，a web spider 网页爬虫。蜘蛛属于蛛形类，不能因为中文都说虫，就在英语分类里都称 insect。

**常见搭配与例句**

a spider’s web；a web spider。

> A spider had built a web across the window.

一只蜘蛛在窗前结了网。

> The search engine uses a spider to discover pages.

搜索引擎使用爬虫发现网页。

**别混淆**

蜘蛛不是六足昆虫；不同蜘蛛捕食方式不同，不能把所有蜘蛛都说成靠同样的捕猎网抓食。程序 spider 是比喻名称。

<a id="w-4"></a>

### 2. spiders — 蜘蛛〔复数〕

**音标**：英 /ˈspaɪdəz/；美 /ˈspaɪdɚz/

**先抓住这个画面**

能吐丝的八足小动物，是 spiders。名字远处像在说“纺丝者”，很适合把词义与它的动作连起来。

**怎么拆**

spider + -s → spiders，-s 读 /z/。spider 承古英语 spiðra 等，远接纺、拉伸的词族；历史里的 n 脱落、th 与 d 的变化，让它与 spin 的联系变得不那么显眼。

**怎么变成今天的意思**

**日耳曼纺丝者的名称 → 古英语 spiðra**  
以纺丝的动作给动物命名

↓

**历史语音变化 → spider → spiders**  
现代把 spider 当整体，复数规则加 -s

spiders in the garden 是花园里的蜘蛛；spiders’ webs 是蜘蛛网；different spiders 是不同的蜘蛛。

**常见搭配与例句**

spiders in the garden；spiders’ webs；different kinds of spiders。

> We found several spiders in the garden.

我们在花园里发现了几只蜘蛛。

> The book explains how spiders use silk.

这本书解释了蜘蛛怎样使用蛛丝。

**别混淆**

蜘蛛与昆虫的分类不同，spiders 通常有八条腿。名字联系纺丝，但不能据此认为所有蜘蛛都织同一种捕食网。

<a id="w-3"></a>

### 3. spiderweb — 蜘蛛网；蛛网状结构

**音标**：英 /ˈspaɪdəweb/；美 /ˈspaɪdərweb/

**先抓住这个画面**

蜘蛛吐丝结成的网；交错线条、裂纹像它，也可以借这个名称。

**怎么拆**

spider 蜘蛛 + web 网，透明复合词，也常写 spider web。名字说的是来源、样子，不是所有蜘蛛网都同样圆、同样规则。

**怎么变成今天的意思**

**spider 蜘蛛；web 网**  
并列构词部分

↓

**spiderweb**  
蜘蛛结的网 → 蛛网状结构

a spiderweb in the corner 角落的蛛网，a spiderweb of cracks 蛛网般裂纹；后一种是外形比喻。

**常见搭配与例句**

a spiderweb；a spiderweb of cracks；a delicate spiderweb。

> A spiderweb glistened with morning dew.

蜘蛛网上的晨露闪着光。

> A spiderweb of cracks covered the old glass.

旧玻璃上布满蛛网般的裂纹。

**别混淆**

spiderweb 蛛网，website 网站；同有 web 并不能替代前面的对象。

## 这一组要分清什么

spider 不属于 insect；名称和 spin 有历史联系，但现代不能直接按规则变词形。

## 串起来练习

The spider waited beside its spiderweb.

蜘蛛待在它结的网旁边。
