# 0646 · written — 写下的；书面的；write 的过去分词

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

written 是 write 的不规则过去分词形式，属于古老强变化动词的延续。现代 write—wrote—written 的元音和尾部有配套变化。

**WRITTEN：从写的动作，看到已经留下的文字**

written instructions 是写下来的说明；handwritten 靠手写，typewritten 用打字机等打出；unwritten 是没有落成文字。

- **基本词形和书面关系**：write · written
- **形成文字的方法**：handwritten · typewritten
- **没有落成文字**：unwritten

## 词形与演化规律

write—wrote—written；hand + written → handwritten；type + written → typewritten；un- + written → unwritten。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

## 逐词讲解

<a id="w-5"></a>

### 1. write — 写；创作；写入

**音标**：/raɪt/

**先抓住这个画面**

先在表面留下有意义的痕迹，后来键盘输入、数据保存也都能叫写。

**怎么拆**

接古英语 wrītan，经中古英语 writen，早与刻划、划出痕迹有关。现代开头 w 不发音；过去式 wrote /rəʊt/（英）、/roʊt/（美），过去分词 written /ˈrɪtən/。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen**  
刻划、写出文字

↓

**英语 write**  
书写；创作；写入数据

write a letter 是写信，write a novel 是创作小说，write to someone 是给人写信；write data to disk 是把数据写入磁盘。

**常见搭配与例句**

write a letter；write about；write to；write down；write data to。

> Please write your name at the top of the page.

请在页顶写上姓名。

> She writes stories for children.

她为儿童写故事。

**别混淆**

write /raɪt/ 与 right 常同音但词源不同。write 关注写下或创作，不一定是用笔，作者在电脑上也在 write。

<a id="w-1"></a>

### 2. written — 写成的；书面的；write 的过去分词

**音标**：/ˈrɪtən/

**先抓住这个画面**

话没有只停在嘴边，已经落成文字，可以再看、保存、核对。

**怎么拆**

write 的过去分词，可辨历史 -en 分词后缀及元音变化。write /raɪt/ → wrote → written /ˈrɪtən/，不是把 -en 直接加到原形读音后。

**怎么变成今天的意思**

**古英语 wrītan → 中古英语 writen**  
刻划、写出文字

↓

**英语 write**  
书写；创作；写入数据

↓

**write → wrote → written**  
书写动作的过去式与过去分词变化

a written agreement 是书面协议，written instructions 是书面说明；has written 是完成时结构。形容词强调形式，具体效力不由这个词单独决定。

**常见搭配与例句**

a written agreement；written instructions；a written reply。

> We received written instructions before the visit.

访问前我们收到书面说明。

> She has written three books on local history.

她已写了三本当地历史著作。

**别混淆**

written 是书面的，spoken 是口头的；a written reply 不等于只能手写，打字回复也属于书面。

<a id="w-2"></a>

### 3. handwritten — 手写的

**音标**：/ˈhændrɪtən/

**先抓住这个画面**

内容由人一笔笔写出来，而不是键盘排印的文字。

**怎么拆**

hand + written，written 是 write 的过去分词；注意 writing /ˈraɪtɪŋ/ 与 written /ˈrɪtən/ 元音不同。

**怎么变成今天的意思**

**英语 hand；written〔write 的过去分词〕**  
并列组合的两部分

↓

**hand + written〔write 的过去分词〕 → handwritten**  
由手写成的

a handwritten note 是手写便条，handwritten instructions 是手写说明；用数位笔书写也可能用此词，不限墨水纸张。

**常见搭配与例句**

a handwritten note；a handwritten letter；a handwritten label。

> She found a handwritten note inside the book.

她在书里发现了一张手写便条。

> The jar had a handwritten label.

罐子上贴着手写标签。

**别混淆**

handwritten 说明文字写法，handmade 可形容卡片制作；机器印刷卡片上可以再加 handwritten message。

<a id="w-3"></a>

### 4. unwritten — 未写下的；不成文的；尚未写出的

**音标**：/ˌʌnˈrɪtən/

**先抓住这个画面**

大家都知道午饭后要顺手清理桌面，可墙上没有贴规定：这可以是 an unwritten rule。也可直说一本书还没写出来。

**怎么拆**

古英语 unwriten、unġewriten 经中古英语延续，对应 un- 未 + written。written 是 write 的不规则过去分词，不是 write 按普通规则加 -ed。

**怎么变成今天的意思**

**古英语未写下的相应形式 → 中古英语 unwriten**  
没有落成文字

↓

**现代 unwritten**  
不成文的惯例；尚未写出的内容

an unwritten rule 不成文的规矩；an unwritten agreement 默契；an unwritten chapter 还未写的章节，可比喻未定的未来。

**常见搭配与例句**

unwritten rules；remain unwritten。

> There is an unwritten rule that everyone helps clean up.

这里有条不成文的规矩：大家都帮忙收拾。

> The final chapter remained unwritten for years.

最后一章多年都没有写出来。

**别混淆**

unwritten rule 可以已经很明确地存在，只是没写下；unknown rule 则是人不知道的规则。没有文字不等于没有惯例。

<a id="w-4"></a>

### 5. typewritten — 打字机打出的；打字形成的

**音标**：英 /ˈtaɪpˌrɪtən/；美 /ˈtaɪpˌrɪtən/

**先抓住这个画面**

纸上是一行行由机器字形组成的文字，而不是手写笔迹。

**怎么拆**

英语 type + written，written 是 write 的过去分词；也可对应动词 typewrite 的分词。

**怎么变成今天的意思**

**古希腊 typtein / typtō → typos**  
敲击 → 打出的印记；形状、样式

↓

**拉丁 typus → 中古英语 type → 英语 type**  
形象、象征 → 类型；印刷字模；后有打字动词

↓

**英语 type + written / typewrite 的分词 → typewritten**  
以打字方式写成的

常见于档案、旧信和文稿描述。通常让人想到打字机成稿；现代数字文件常直接说 typed。

**常见搭配与例句**

a typewritten letter；a typewritten manuscript。

> The archive contains several typewritten letters from the expedition.

档案中保存了几封探险队的打字信件。

> She compared the typewritten draft with the author’s handwritten corrections.

她把打字稿与作者的手写修改作了对照。

**别混淆**

handwritten 是手写的；typewritten 强调机器打字形成的文字。

## 这一组要分清什么

a written rule 和 an unwritten rule 都可能存在；前者写明，后者靠约定、习惯默认。written by 后面引出作者，不表示作者每次都亲笔写。

## 串起来练习

The handwritten note explained an unwritten rule.

那张手写便条说明了一条不成文的规矩。
