# 1045 · standard — 参照标准、统一与非标准形式

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

基础词由标识、标杆等历史发展出参照要求。现代后缀说使符合，前缀 non- 说非标，sub- 常说低于标准。

**STANDARD：选定参照；STANDARDIZE：让做法一致**

standard 已精讲，standardize 与 standardise 放一起，接 nonstandard，再对照已有 substandard。

- **标准与统一动词**：standard · standardize · standardise
- **非标准与不达标**：nonstandard · substandard
- **standard 标准 + -ize → standardized**：standardized

## 词形与演化规律

standard + -ize/-ise；non-/sub- + standard。

standardize 在英语中由 standard + -ize 形成，现代去 e 加完整 -ed，/z/ 后读 /d/；使方法、格式按共同标准一致。

## 单词速览（按词族由简到繁）

同一基础词的相关扩展放在一起，先读基础形式，再读扩展；各组之间优先读常用的。具体词源关系见各词讲解。

| [standardize](#w-3) | 英 /ˈstændədaɪz/；美 /ˈstændərdaɪz/ | 标准化；统一规范或格式 |

## 逐词讲解

<a id="w-1"></a>

### 1. standard — 标准；水准；标准的；旗帜〔历史〕

**音标**：英 /ˈstændəd/；美 /ˈstændərd/

**先抓住这个画面**

大家需要同一个参照来判断尺寸、质量或做法，而不是各用各的尺。

**怎么拆**

经古法语 estandart、相关中世纪拉丁语形式借入，早有军旗、集结标志义；更早是否站稳、固定地点等组合有不同分析。不能把现代拼写简单当 stand + ard，然后断言标准就是站得稳。

**怎么变成今天的意思**

**古法语 estandart 等 → 中古英语 standard**  
军旗、显著标志等早期义

↓

**英语 standard 的度量、规范用法**  
比较所依据的尺度；标准的

meet a standard 是达到标准，a high standard 是高水准，standard size 是标准尺寸。历史小说里 a royal standard 可能是王旗；这些义相关，但中间语义转化不全是确定单一路线。

**常见搭配与例句**

meet standards；set a standard；a high standard；standard practice。

> The product meets the required safety standard.

产品符合所要求的安全标准。

> This is standard practice in the workshop.

这是车间的常规做法。

**别混淆**

standard 是衡量规范或普通规格，standing 常是地位、长期有效；standard procedure 是标准程序，不写 standing procedure 来表达完全相同的概念。

<a id="w-3"></a>

### 2. standardize — 标准化；统一规范或格式

**音标**：英 /ˈstændədaɪz/；美 /ˈstændərdaɪz/

**先抓住这个画面**

大家原来各写各的日期、各量各的尺寸，现在约定同一套规则，让结果能比较、能配合。

**怎么拆**

standard + -ize，形成使符合标准的动词。standardise 是同义拼写；-ize 常见于美式，也用于部分英式规范。

**怎么变成今天的意思**

**standard 的历史旗帜、标杆义 → 通行参照**  
已有基础词精讲，现代作为统一要求或形式

↓

**standard + -ize／-ise；non- + standard**  
使统一到标准；非标准形式

standardize the format 统一格式，standardize measurements 统一测量标准。标准可以是技术要求，也可以是组织约定。

**常见搭配与例句**

standardize the format；standardize measurements；standardize procedures。

> We need to standardize the date format across the database.

我们需要统一整个数据库的日期格式。

> The company standardized its training procedures.

公司统一了培训流程。

**别混淆**

standardize 让一致，improve 改善；一致以后未必每个方面都更好，仍需看采用的标准。

<a id="w-6"></a>

### 3. standardized — 使标准化了；按统一标准处理的

**音标**：英 /ˈstændədaɪzd/；美 /ˈstændɚdaɪzd/

**先抓住这个画面**

原来各人各做各的，现在把尺寸、步骤、格式放到同一套标准下，就是 standardized。别人看到相同格式，就更容易对照、使用。

**怎么拆**

standard 标准 + -ize 使成为 → standardize，去末尾 e 加完整 -ed → standardized，/z/ 后读 /d/。另有 standardise、standardised 拼写。

**怎么变成今天的意思**

**英语 standard + -ize → standardize**  
按共同标准调整、规定

↓

**standardize + -ed → standardized**  
现代既说完成了统一，也描述已标准化的状态

standardized forms 是标准化表格；standardized procedures 是统一规程；standardized tests 是按统一设计、实施或评分安排的测试。

**常见搭配与例句**

standardized forms；standardized procedures；standardized tests。

> The team standardized the file names across the project.

团队统一了整个项目的文件命名。

> All branches use the same standardized form.

所有分支机构都使用同一份标准化表格。

**别混淆**

standardized 说明遵循共同标准，不自动说明标准最好，也不要求每个内容完全相同。表格字段统一后，填进去的信息仍可以不同。

<a id="w-5"></a>

### 4. standardise — 标准化〔standardize 的拼写变体〕

**音标**：英 /ˈstændədaɪz/；美 /ˈstændərdaɪz/

**先抓住这个画面**

换成 s，仍是在说统一规则、尺寸或格式；不用再学一套新意思。

**怎么拆**

standard + -ise，与 standardize 同族同义；-ise 广见于英式用法，但不是所有英式文本都只用这一种。

**怎么变成今天的意思**

**standard 的历史旗帜、标杆义 → 通行参照**  
已有基础词精讲，现代作为统一要求或形式

↓

**standard + -ize／-ise；non- + standard**  
使统一到标准；非标准形式

↓

**standard + -ise → standardise**  
标准化动词的另一常见拼写

standardise spelling 统一拼写，standardise the process 规范流程。同一项目选择一套拼写习惯，读者更好跟。

**常见搭配与例句**

standardise spelling；standardise the process；standardise equipment。

> The editor helped standardise spelling throughout the report.

编辑帮助统一了整份报告的拼写。

> The school plans to standardise its assessment forms.

学校计划统一评估表格。

**别混淆**

standardise 与 standardize 主要是拼写差异，不是一个更严格、另一个更宽松；读音相同。

<a id="w-2"></a>

### 5. substandard — 不达标的；低于应有水平的

**音标**：英 /ˌsʌbˈstændəd/；美 /ˌsʌbˈstændərd/

**先抓住这个画面**

有一条最低合格线，交来的东西却落在线下面。

**怎么拆**

sub-“低于” + standard“标准”，英语构词。

**怎么变成今天的意思**

**拉丁语：sub**  
在下面；从下向上；靠近

↓

**英语前缀：sub-**  
下方；下一级；低于某个标准

↓

**英语：sub- + standard → substandard**  
低于规定或通常标准

substandard housing 常指居住条件未达到应有要求；不只是房子旧，也不是豪华程度不足。

**常见搭配与例句**

substandard work；substandard materials。

> The inspector rejected the substandard materials.

检查员拒收了不合格材料。

> The report documented substandard conditions in the building.

报告记录了楼内不达标的环境条件。

**别混淆**

ordinary 是普通但可能合格；substandard 明确说未达到该有的水平。

<a id="w-4"></a>

### 6. nonstandard — 非标准的；不采用通行形式的

**音标**：英 /ˌnɒnˈstændəd/；美 /ˌnɑːnˈstændərd/

**先抓住这个画面**

没有按选定的标准来，可能是特殊规格，也可能是方言、口语里的另一种形式。

**怎么拆**

non- 非、不属于 + standard，否定的是标准归属，不自动评价东西没用或质量差。

**怎么变成今天的意思**

**standard 的历史旗帜、标杆义 → 通行参照**  
已有基础词精讲，现代作为统一要求或形式

↓

**standard + -ize／-ise；non- + standard**  
使统一到标准；非标准形式

↓

**non- + standard → nonstandard**  
不符合或不采用指定标准的

a nonstandard size 特殊非标尺寸，nonstandard spelling 非标准拼写，nonstandard usage 非标准用法。判断语言时先说明采用哪种标准。

**常见搭配与例句**

a nonstandard size；nonstandard spelling；nonstandard usage。

> The machine uses screws of a nonstandard size.

机器使用非标准尺寸的螺丝。

> The dictionary labels the spelling as nonstandard.

词典把这种拼写标为非标准。

**别混淆**

nonstandard 非标不等于 substandard 低于质量标准；特殊接口可以非标但质量很好。

## 这一组要分清什么

standardize 与 standardise 同义拼写；nonstandard 非标，substandard 常不达标，两者不相同。

## 串起来练习

We standardized the common parts but kept one nonstandard component.

我们统一了通用零件，但保留了一个非标部件。
