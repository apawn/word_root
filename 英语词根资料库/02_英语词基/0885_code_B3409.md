# 0885 · code — 规则、符号编码与计算机代码

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

code 经法语接拉丁书册、法典词，符号系统与计算机指令是后来扩展。生物 codon 为现代 code+-on，冷门希腊钟形同形词不混讲。

**CODE：按规则表达信息，也可收集成规则体系**

先看 code、coding、coder，再配对 encode 与 decode；recode、codebase 继续扩展，codify 走成文规则，codon 走遗传编码。

- **基本词、活动与主体**：code · coding · coder
- **编码、解码与重编码**：encode · decode · recode
- **代码集合与成文规则**：codebase · codify
- **遗传与已有代码复合**：codon · codeword · codename · postcode · passcode
- **code → codes：书册、法典到规则与符号体系**：code · codes
- **code 的通行、解锁组合及复数**：passcode · passcodes

## 词形与演化规律

code → coding、coder；en-、de-、re- → encode、decode、recode；code + base → codebase；-ify → codify；-on → codon。

法语接拉丁 codex，现代规则、密码、程序等义继续发展。

代码用于放行，不限制为某一种固定长度或字符类型。

## 逐词讲解

<a id="w-1"></a>

### 1. code — 代码；编码；准则、法规；编程、编码

**音标**：英 /kəʊd/；美 /koʊd/

**先抓住这个画面**

一条路是把规则收成一套，另一条是用约定的符号表达信息；计算机代码也是按规则写给机器执行的指令。

**怎么拆**

经法语来自拉丁 codex，早期木板书、书册，后有法典义。规则系统与符号体系逐渐扩展，不能把现代程序语言说成古罗马人在写软件。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

a code of conduct 行为准则，a secret code 秘密编码，source code 源代码；code a program 编写程序。

**常见搭配与例句**

a code of conduct；source code；a secret code；write code。

> The club has a strict code of conduct.

俱乐部有严格行为准则。

> She writes code for a weather application.

她为一款天气应用编写代码。

**别混淆**

code 不一定秘密，公开邮编也是 code；code 规则、编码体系不等于每次都是 password 密码。

<a id="w-14"></a>

### 2. codes — 代码、编码；密码；规则体系、法典等〔复数〕；编码、编程〔第三人称单数〕

**音标**：英 /kəʊdz/；美 /koʊdz/

**先抓住这个画面**

大家先约好某个符号代表什么、某条规则要求什么，就能有 codes。它既能组织行为，也能组织信息。

**怎么拆**

code + -s，/d/ 后读 /z/。code 经法语接拉丁 codex 木板书、书册，后有汇集规则的法典；规则、符号体系及程序等用法继续扩展。

**怎么变成今天的意思**

**拉丁 codex → 法语 → code**  
书册、法典 → 规则或符号体系

↓

**code + -s → codes**  
多种编码、口令、规则体系；也可说某人编程

access codes 访问码；postal codes 邮政编码；codes of conduct 行为准则。

**常见搭配与例句**

colour codes 颜色编码；codes a small tool 编写一个小工具的程序。

> Each box has a label with several codes.

每个盒子都有一个写着几个编码的标签。

> The organisation has clear codes of conduct.

这个组织有明确的行为准则。

**别混淆**

程序源代码作为总体常常用不可数 code；codes 复数常数不同的编码、标识码、密码或规则体系。不能每见几行程序就一定加 s。

<a id="w-2"></a>

### 3. coding — 编程；编码、按类别标记

**音标**：英 /ˈkəʊdɪŋ/；美 /ˈkoʊdɪŋ/

**先抓住这个画面**

把信息写进代码、符号或分类体系；不只计算机里敲程序这一种。

**怎么拆**

code 去 e + -ing，形成动作名词与动词形式。研究里 coding responses 可指给回答分类标记。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

↓

**code + -ing → coding**  
编码动作 → 编程、分类编码

learn coding 学编程，colour coding 颜色编码，coding interview responses 给访谈回答编码分类。

**常见搭配与例句**

learn coding；colour coding；coding skills。

> The school offers an introduction to coding.

学校开设编程入门课。

> The researchers used colour coding to organize the files.

研究人员用颜色编码整理文件。

**别混淆**

coding 可能编程，也可能研究分类；一个采访研究的 coder 不一定在写应用软件。

<a id="w-7"></a>

### 4. coder — 程序员；编码人员、器具

**音标**：英 /ˈkəʊdə/；美 /ˈkoʊdər/

**先抓住这个画面**

执行写代码或编码分类的主体；具体角色取决于代码是哪种。

**怎么拆**

code 去末尾 e，加完整表人或器物后缀 -er，得 coder。-er 可指人，也可指编码器物。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

↓

**code + -er → coder**  
执行编码的主体

a skilled coder 熟练程序员，a medical coder 医疗记录编码员；后者处理分类代码，不因此变医生。

**常见搭配与例句**

a skilled coder；a software coder；an independent coder。

> The team hired another coder to work on the app.

团队又雇了一名程序员开发应用。

> Two coders classified the interview responses independently.

两名编码人员独立给访谈回答分类。

**别混淆**

coder 角色比软件工程全部职责更具体，但日常两类职称有重合；medical coder 不等于提供治疗的人。

<a id="w-8"></a>

### 5. codename — 代号；给……起代号

**音标**：英 /ˈkəʊdneɪm/；美 /ˈkoʊdneɪm/

**先抓住这个画面**

不直接说真实名称，用另一个约定称呼来指某个计划、人物或产品。

**怎么拆**

code（约定代号）+ name，可作名词、动词；code 在此不一定是程序源代码。

**怎么变成今天的意思**

**英语 code；name**  
并列组合的两部分

↓

**code + name → codename**  
替代真实名称的约定称呼

a project codename 是项目代号，codenamed Aurora 是代号为 Aurora。可能用于保密，也可能仅是开发期间临时命名。

**常见搭配与例句**

a project codename；under the codename；codenamed ...。

> The project was developed under the codename Aurora.

项目以 Aurora 为代号开发。

> Each team used a different codename during the exercise.

演练中每组使用不同代号。

**别混淆**

codename 常指约定使用的别名，nickname 常是个人绰号；代号不一定带亲昵、戏谑意味。

<a id="w-9"></a>

### 6. codon — 密码子

**音标**：英 /ˈkəʊdɒn/；美 /ˈkoʊdɑːn/

**先抓住这个画面**

遗传信息中三个核苷酸组成的一组，像按三个字符分组读取的代码单位；对应氨基酸或终止信号。

**怎么拆**

生物学现代词由 code + -on 构成单位名，不是 con- 加 don。另有从希腊钟形词来的冷门同形义，与遗传密码子分开。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

↓

**code + -on → codon**  
遗传编码单位 → 密码子

a stop codon 终止密码子，an RNA codon RNA 密码子；本页记词与概念，不从单个密码子预测个人健康。

**常见搭配与例句**

a stop codon；a start codon；an RNA codon。

> The diagram groups the RNA sequence into codons.

图把 RNA 序列分成一组组密码子。

> A stop codon signals the end of protein synthesis.

终止密码子发出蛋白质合成结束的信号。

**别混淆**

codon 一组三个核苷酸，不等于一个 gene 基因；多个密码子可以编码同一种氨基酸，也存在终止信号。

<a id="w-10"></a>

### 7. codify — 编纂成法规、规则；把做法系统化

**音标**：英 /ˈkəʊdɪfaɪ/；美 /ˈkɑːdɪfaɪ/

**先抓住这个画面**

原本散着的规定、惯例整理成一套明确条文，让人能查、能统一照做。

**怎么拆**

code 的规则集义 + -ify 使成，词干表现 cod-，不是 cod 鳕鱼 + 一个无关尾巴。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

↓

**code + -ify → codify**  
形成成套规则 → 编纂、系统化

codify the rules 编纂规则，codify existing practices 把现有做法明确成文；不一定是编电脑程序。

**常见搭配与例句**

codify the rules；codify a practice；codify standards。

> The policy codifies practices already used by the team.

政策把团队已有做法明确成文。

> The committee worked to codify the rules.

委员会着手把规则系统编纂成文。

**别混淆**

codify 系统整理为规则，code 写程序或编码；把公司惯例写成手册通常 codify，不必说写软件。

<a id="w-11"></a>

### 8. codebase — 代码库；一套项目代码

**音标**：英 /ˈkəʊdbeɪs/；美 /ˈkoʊdbeɪs/

**先抓住这个画面**

不是某一行程序，而是支持某个项目、系统的那一整套代码。

**怎么拆**

code + base 基础、集合体。现代软件名词，不一定与一个 Git 仓库边界完全一致。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

↓

**code + base → codebase**  
项目的代码基础集合 → 代码库

a large codebase 大型代码库，maintain a codebase 维护代码库，a shared codebase 共享代码基础。

**常见搭配与例句**

a large codebase；maintain a codebase；a shared codebase。

> The team is gradually cleaning up the old codebase.

团队正逐步整理旧代码库。

> Both applications use the same codebase.

两个应用使用同一套代码基础。

**别混淆**

codebase 一套代码，database 数据库主要存数据；repository 仓库是管理容器，边界不必与 codebase 完全相同。

### 9. codeword — 代号；暗语

**音标**：英 /ˈkəʊdwɜːd/；美 /ˈkoʊdwɜːrd/

**先抓住这个画面**

表面说的是普通词，双方约定它实际代表另一个指令、人物或事情。

**怎么拆**

code 编码、约定代号 + word 词，形成约定替代含义的词语名称。也常分写 code word。

**怎么变成今天的意思**

**code 编码、约定代号；word 词**  
并列构词部分

↓

**codeword**  
代指特定信息的约定词

use a codeword 使用暗语，the codeword for a mission 任务代号；社会评论中也能指表面中性、实际暗示某态度的词。

**常见搭配与例句**

use a codeword；a secret codeword；the codeword for。

> In the story, “lantern” is the codeword for the meeting.

故事里，lantern 是那次会面的暗语。

> The team used a codeword to refer to the secret project.

团队用一个代号称呼这个保密项目。

**别混淆**

codeword 可以传达约定信息而不用于登录；password 主要认证身份或权限，二者有时能在具体故事里重合。

### 10. decode — 解码；理解隐藏、复杂的含义

**音标**：英 /ˌdiːˈkəʊd/，亦 /dɪˈkəʊd/；美 /diːˈkoʊd/

**先抓住这个画面**

按编码规则把符号读回信息；也可比喻弄懂别人含糊难懂的话。

**怎么拆**

de- 解除、反向 + code，形成与编码方向相反的动词。不是 delete 删除数据的缩写。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

↓

**de- + code → decode**  
把编码读回信息 → 解码、理解

decode a signal 解码信号，decode a message 解读消息，decode someone’s remarks 弄懂话意。

**常见搭配与例句**

decode a signal；decode a message；decode the meaning。

> The software decoded the signal successfully.

软件成功解码了信号。

> I tried to decode the meaning behind his vague reply.

我试着弄懂他含糊答复背后的意思。

**别混淆**

decode 读回编码，与 decrypt 解密相关但不完全同义；没有加密的文件也需正确解码。

### 11. postcode — 邮政编码〔尤英式〕

**音标**：英 /ˈpəʊstkəʊd/；美 /ˈpoʊstkoʊd/

**先抓住这个画面**

地址不只靠整段文字，还用一组代码帮助系统分区、分拣、投递。

**怎么拆**

post（邮政）+ code（代码），不是电脑程序 post 的源代码。

**怎么变成今天的意思**

**post〔邮政〕；code**  
并列构词部分

↓

**postcode**  
帮助邮政分拣、定位地址区域的编码

enter your postcode 输入邮编，a postcode area 邮编区；各国编码结构不同。美国日常通常说 ZIP code。

**常见搭配与例句**

enter a postcode；a postcode area；a full postcode。

> Please enter your postcode below the address.

请在地址下面填写邮编。

> The search tool finds nearby branches by postcode.

搜索工具按邮编查找附近网点。

**别混淆**

postcode 邮政编码，area code 电话区号；都像几位字符，但所属系统与用途不同。

### 12. encode — 编码；把信息转成特定形式

**音标**：英 /ɪnˈkəʊd/；美 /ɪnˈkoʊd/

**先抓住这个画面**

按一套规则把原信息换一种表示法，方便储存、传送或处理。

**怎么拆**

en- 使进入 + code，把信息放入编码形式。现代技术、信息表达领域都常见。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

↓

**en- + code → encode**  
置入编码形式 → 编码

encode text as UTF-8 把文本按 UTF-8 编码，encode a video 编码视频。

**常见搭配与例句**

encode data；encode text；encode a video。

> The system encodes the text as UTF-8.

系统把文本编码为 UTF-8。

> The message encodes information in a series of symbols.

消息用一串符号编码信息。

**别混淆**

encode 编码不等于 encrypt 加密；编码规则可以完全公开，不必有秘密密钥。

### 13. passcode — 通行码；解锁码

**音标**：英 /ˈpɑːskəʊd/；美 /ˈpæskoʊd/

**先抓住这个画面**

输入约定的一串代码，门禁或设备才放行、解锁。

**怎么拆**

pass 通过、获准 + code 代码，形成认证或访问用代码名称。常见数字代码，但名称不保证只能使用数字。

**怎么变成今天的意思**

**pass 获准通过；code 代码**  
并列构词部分

↓

**passcode**  
用于放行、解锁的代码

enter a passcode 输入解锁码，a device passcode 设备解锁码；具体格式由系统规定。

**常见搭配与例句**

enter a passcode；set a passcode；a device passcode。

> Enter your passcode to unlock the device.

请输入解锁码以解锁设备。

> The app asked her to set a new passcode.

应用要求她设置新的通行码。

**别混淆**

passcode 与 password 实际产品命名有交叠；passphrase 特别强调以短语式较长内容组成，不能仅凭名称断言哪种绝对更安全。

<a id="w-15"></a>

### 14. passcodes — 通行码、解锁码〔复数〕

**音标**：英 /ˈpɑːskəʊdz/；美 /ˈpæskoʊdz/

**先抓住这个画面**

输入约定代码，设备或门禁才放行；有多份代码时就用 passcodes。

**怎么拆**

pass 获准通过 + code 代码 → passcode，整词加 -s，/d/ 后读 /z/。末尾 e 保留。

**怎么变成今天的意思**

**pass + code → passcode**  
用于放行、解锁的代码

↓

**passcode + -s → passcodes**  
多个通行、解锁代码

device passcodes 设备解锁码；temporary passcodes 临时通行码。

**常见搭配与例句**

enter passcodes 输入通行码；different passcodes 不同代码。

> The devices used different passcodes.

这些设备使用不同解锁码。

> The visitors received temporary passcodes for the doors.

访客拿到了门禁的临时通行码。

**别混淆**

passcodes 常用于数字代码的名称，但词本身不保证只含数字、固定几位；password 与它也有用法交叠。

<a id="w-13"></a>

### 15. recode — 重新编码；改变分类代码

**音标**：英 /ˌriːˈkəʊd/；美 /ˌriːˈkoʊd/

**先抓住这个画面**

已有编码、分类或程序，再按新的规则做一次；不一定从零重写整套软件。

**怎么拆**

re- 重新 + code，可用在数据编码、研究分类和程序修改。具体改变范围由对象决定。

**怎么变成今天的意思**

**拉丁 caudex、codex 木板书、书册 → 古法语 code**  
成册法规、法典

↓

**英语 code**  
成套规则 → 符号编码体系；计算机指令

↓

**re- + code → recode**  
重新编码、分类

recode a variable 重新编码变量，recode the data 重新编码数据。

**常见搭配与例句**

recode a variable；recode the data；recode a category。

> The researchers recoded the responses into three categories.

研究人员把回答重新编码为三类。

> We had to recode the variable before the analysis.

分析前，我们得重新编码这个变量。

**别混淆**

recode 改编码、分类，decode 解码；把类别1改为类别0是 recode，不一定是把秘密信息读出来。

## 这一组要分清什么

encode 不等于 encrypt；codify 不必写软件；codebase 不是 database；codon 是三核苷酸单位，不是整个基因。

## 串起来练习

The coder decoded the data before adding it to the codebase.

程序员先解码数据，再把它加入代码库。
