# 1671 · tag — 标签、身份与数字标注；游戏触碰义分支

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

大部分扩展从附着小标签很容易看懂。捉人游戏的历史却需另联系触碰词，不能因为现代 tag 有多个义就强画成一条。

**TAG：挂一片身份记号，或者在数字世界贴个标记**

tag → tagger；hashtag # 话题标签；gamertag 玩家代号；nametag 姓名牌；tagline 宣传短句。

- **基本标签与标注者**：tag · tagger
- **标签内容和使用场景**：hashtag · gamertag · nametag
- **短句宣传**：tagline
- **hashtag → hashtags：用 # 标出的标签**：hashtag · hashtags
- **tag → tags、tagged：标签与标注**：tags · tagged

## 词形与演化规律

tagge → tag 标签；tag + -er 双写 g；hash/gamer/name + tag；tag + line；游戏 tag 的触碰来源另看。

hash 在这里指 # 符号，加 tag 标签 → hashtag；整体复数 hashtags。标签可帮助聚合内容，也能补充态度、评论，不仅有分类一种用途。

标签义 tag 较早与衣物上垂下的小片等有关，远源不定；捉人游戏的触碰义另有来源分析。tags 加 -s，tagged 双写 g 加完整 -ed。

## 逐词讲解

<a id="w-1"></a>

### 1. tag — 标签、标记；贴标签、标注；捉人游戏〔另一支〕

**音标**：/tæɡ/

**先抓住这个画面**

行李上挂一片写名字的小牌，照片旁也能挂一个可点击的名字；tag 就从实物标签伸进了数字世界。

**怎么拆**

标签义接中古英语 tagge 挂出的小片，更早可能与北欧等材料相关。捉人游戏 tag 常另联系到 tig 触碰等词，来路有不确定性；不把全部义定成同一条标签派生。

**怎么变成今天的意思**

**中古英语 tagge**  
衣物挂出的小片、垂饰；更早来源不确定

↓

**英语 tag**  
附着的小标签 → 身份标记、数字标签；贴标签

↓

**另一路：tig 等触碰词 → 游戏 tag**  
捉人、轻触；具体路线不确定

a price tag 价签，a luggage tag 行李牌，tag someone in a photo 在照片里标出某人；play tag 玩捉人游戏，tag along 跟着一起去。

**常见搭配与例句**

a price tag；a luggage tag；tag someone in a photo；play tag；tag along。

> Please leave the price tag on the gift.

请把礼物上的价签留着。

> She tagged me in the group photo.

她在合照里标出了我。

**别混淆**

tag 数字标签不一定只指 # 话题，HTML tag、人员标记也是 tag；hashtag 是带 # 的具体一类。

<a id="w-9"></a>

### 2. tags — 标签；标记〔复数〕；给……加标签、标注〔第三人称〕

**音标**：英、美 /tæɡz/

**先抓住这个画面**

商品上挂一小片说明，文件上加一个便于分类的名字，都可以叫 tags。动作 tags a photo 则是在照片上作标注。

**怎么拆**

tag + -s → tags，/ɡ/ 后读 /z/。标签义较早从衣物上垂下的小片等发展，远源不明；游戏中触碰的 tag 有另一条来源分析。

**怎么变成今天的意思**

**tag 垂下的小片 → 附着的说明标签**  
实体小片的名称扩展到分类标记

↓

**标签义及标注动作 → tags**  
现代名词复数、动词第三人称

price tags 是价签；name tags 是姓名牌；tags a photo 是给照片加标注；网页里的 tags 又是标签、标记名称。

**常见搭配与例句**

price tags；name tags；tags the photo。

> The boxes have clear name tags.

这些箱子上有清楚的姓名标签。

> The app tags each photo with a date.

这个应用给每张照片标上日期。

**别混淆**

tags 的数字用途不一定真有小纸片；标签可作为分类、说明的名称。游戏 tag 不能用 labels 的故事强解释。

<a id="w-8"></a>

### 3. tagged — 加了标签的；标注了；碰到、触及了〔过去式、过去分词〕

**音标**：英、美 /tæɡd/

**先抓住这个画面**

箱子贴上标签、照片标出人物，便是 tagged。追逐游戏里碰到某人，也可以用这个过去形式，但词源分支要分开。

**怎么拆**

tag 双写末尾 g，加完整 -ed → tagged，/ɡ/ 后读 /d/，末尾 /ɡd/。标签和游戏触碰的 tag 分别有自己的历史材料。

**怎么变成今天的意思**

**tag 的标签与触碰游戏等分支**  
标签义远源不定，触碰游戏常联系 tig 等名称

↓

**tag + -ed → tagged**  
双写 g，现代规则过去式、过去分词

tagged boxes 是贴好标签的箱子；tagged in a photo 是在照片中被标注；tagged along 是跟着一起去了。

**常见搭配与例句**

tagged boxes；tagged in a photo；tagged along。

> Each box was tagged with the owner’s name.

每个箱子都标了主人的名字。

> She tagged me in the group photo.

她在合照中标注了我。

**别混淆**

tagged along 作为完整短语说跟随同行，不能逐字译成给旁边贴标签。读音也不加一个 /ɪd/ 音节。

<a id="w-3"></a>

### 4. tagline — 广告语、品牌标语；结尾点题句

**音标**：/ˈtæɡlaɪn/

**先抓住这个画面**

一小句跟在品牌、电影或广告旁边，像标签一样让人记住它的主张；不是整篇广告正文。

**怎么拆**

tag 附加、标记材料 + line 一行话，组合为附在后面的短句；常用义是广告、宣传中的标语。

**怎么变成今天的意思**

**中古英语 tagge**  
衣物挂出的小片、垂饰；更早来源不确定

↓

**英语 tag**  
附着的小标签 → 身份标记、数字标签；贴标签

↓

**tag + line → tagline**  
附带、点题的短句 → 宣传标语

a memorable tagline 令人记住的广告语，a movie tagline 电影宣传短句，the brand’s tagline 品牌标语。

**常见搭配与例句**

a memorable tagline；a movie tagline；a brand tagline。

> The poster uses a short, memorable tagline.

海报用了一句简短好记的宣传语。

> They changed the logo but kept the old tagline.

他们换了标志，却保留了原来的标语。

**别混淆**

tagline 宣传短句，headline 标题，caption 图注；短不等于同一种功能，位置、用途要看内容。

<a id="w-6"></a>

### 5. tagger — 标注者、标注工具；涂鸦签名者；捉人者

**音标**：英 /ˈtæɡə/；美 /ˈtæɡər/

**先抓住这个画面**

谁在贴标记、什么工具在做标注，都可接 -er；墙上留下固定涂鸦签名的人也能这样称。游戏义则是在追着碰别人的人。

**怎么拆**

tag 双写 g + -er，按 tag 的标签、涂鸦、游戏等义分别命名执行者。双写保留短元音构词习惯，不把 g 读成长音。

**怎么变成今天的意思**

**中古英语 tagge**  
衣物挂出的小片、垂饰；更早来源不确定

↓

**英语 tag**  
附着的小标签 → 身份标记、数字标签；贴标签

↓

**tag + -er → tagger**  
贴标签、标注或涂鸦的人或工具；游戏中的追捕者

a graffiti tagger 涂鸦签名者，a part-of-speech tagger 词性标注工具，the tagger in a game 捉人游戏中负责追的人。

**常见搭配与例句**

a graffiti tagger；a part-of-speech tagger；the tagger in a game。

> The program includes a part-of-speech tagger.

程序包含一个词性标注工具。

> The tagger chased the other children across the playground.

负责捉人的孩子追着其他孩子跑过操场。

**别混淆**

tagger 可是程序，不限人；tagline 是短句，不是做标记的人。具体含义先看 tag 做了哪种动作。

<a id="w-2"></a>

### 6. hashtag — 带 # 的话题标签；# 号〔相关语境〕

**音标**：/ˈhæʃtæɡ/

**先抓住这个画面**

给一条内容贴上 # 后跟关键词的标签，别人能沿标签找同主题内容；hash 指 #，tag 指标签。

**怎么拆**

hash 符号名 + tag 标签，早期也写 hash tag。现代网络用法把符号和标签内容结合，不是 hash 食物肉末，也不等于密码散列值。

**怎么变成今天的意思**

**中古英语 tagge**  
衣物挂出的小片、垂饰；更早来源不确定

↓

**英语 tag**  
附着的小标签 → 身份标记、数字标签；贴标签

↓

**hash 符号 + tag → hashtag**  
# 开头的主题、元数据标签

add a hashtag 添加话题标签，a trending hashtag 热门话题标签，use the same hashtag 用同一话题标签。

**常见搭配与例句**

add a hashtag；a trending hashtag；use the same hashtag。

> Use the hashtag #CityWalk for photos from the event.

活动照片请使用 #CityWalk 这个话题标签。

> The hashtag helped us find posts about the same topic.

这个话题标签帮我们找到了同主题帖子。

**别混淆**

hashtag 完整标签常包括 # 和后面的关键词；把 # 本身叫 hashtag 也有口语用法，但符号名 hash 与完整标签仍可区分。

<a id="w-7"></a>

### 7. hashtags — 话题标签〔复数〕

**音标**：英、美 /ˈhæʃtæɡz/

**先抓住这个画面**

帖子后面带 # 的词组，像 #CityWalk，可以是 hashtags：把内容挂上一个能被找到的话题牌。

**怎么拆**

hash 这里指 # 符号 + tag 标签 → hashtag；再加 -s → hashtags，/ɡ/ 后读 /z/。不是 hash 食物或杂烩义直接组成的话题名。

**怎么变成今天的意思**

**hash mark 的 hash：# 符号 + tag 标签 → hashtag**  
用带 # 的词语标出、聚合话题，也能补充评论

↓

**hashtag + -s → hashtags**  
多个话题标签，词尾 /ɡz/

add hashtags 是添加话题标签；search hashtags 是搜索标签；popular hashtags 是热门话题标签。

**常见搭配与例句**

add hashtags；popular hashtags；search by hashtags。

> She added two hashtags to the post.

她给帖子加了两个话题标签。

> We used the same hashtags to find photos from the event.

我们用相同的话题标签查找活动照片。

**别混淆**

tag 范围更广，可以是各种标签；hashtags 特别强调 # 形式及其话题用法。

<a id="w-5"></a>

### 8. nametag — 姓名标签；胸牌

**音标**：/ˈneɪmtæɡ/

**先抓住这个画面**

活动里不认识彼此，把姓名贴在衣服上，见面就能叫出来。

**怎么拆**

name + tag（标签），也常写 name tag 两词。tag 在这里是标记身份的物件，不是捉人游戏的动词。

**怎么变成今天的意思**

**英语 name；tag**  
并列组合的两部分

↓

**name + tag → nametag**  
显示佩戴者姓名的标签

wear a nametag 是戴姓名牌，a conference nametag 是会议胸牌；可以贴纸，也可挂牌，不必金属材质。

**常见搭配与例句**

wear a nametag；a conference nametag；write on a nametag。

> Everyone wore a nametag at the workshop.

工作坊里每个人都佩戴姓名牌。

> She wrote her first name on the blank nametag.

她在空白姓名牌上写了自己的名字。

**别混淆**

nametag 主要给现场的人认身份，username 用于系统账号；现场胸牌可以印昵称，但不必就是登录名。

### 9. gamertag — 玩家代号、游戏用户名

**音标**：英 /ˈɡeɪmətæɡ/；美 /ˈɡeɪmərtæɡ/

**先抓住这个画面**

多人游戏里，别人不一定知道你的真名，先认屏幕上的那串名字；那就是你挂在游戏身份上的标签。

**怎么拆**

gamer 玩家 + tag 身份标签。gamer 自己是 game + -er，-er 在前半段，不是整个 gamertag 的人物后缀。

**怎么变成今天的意思**

**中古英语 tagge**  
衣物挂出的小片、垂饰；更早来源不确定

↓

**英语 tag**  
附着的小标签 → 身份标记、数字标签；贴标签

↓

**game → gamer；gamer + tag → gamertag**  
玩家 → 标识玩家的代号

choose a gamertag 选择玩家代号，change your gamertag 更改游戏用户名，recognize a gamertag 认出玩家代号。

**常见搭配与例句**

choose a gamertag；change your gamertag。

> She chose a gamertag that her friends could remember.

她选了一个朋友们记得住的玩家代号。

> I recognized his gamertag before I heard his voice.

还没听到他的声音，我就认出了他的玩家代号。

**别混淆**

gamertag 是显示的玩家标识，不必是真名，也不等于登录密码；username 更泛。

## 这一组要分清什么

hashtag 是具体一类 tag；gamertag 不是密码；tagline/headline/caption 按宣传、标题、图注功能分。

## 串起来练习

Her nametag and gamertag were different, but she used the same hashtag.

她的姓名牌和玩家代号不同，但用了同一个话题标签。
