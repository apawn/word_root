# 0243 · set — 使就位、设定；一组、一套

[逐词精讲目录](../00_逐词精讲目录.md) · [总目录](../00_总目录_按常用程度.md)

## 核心词根与来源

set 动词接古英语 settan，与 sit 的使动词历史相连；原形、过去式、过去分词相同。名词集合、场景等形成还牵涉旧名词及可能的借词合流，应分别识别。

**SET：先让位置或状态定下来，再看具体用法**

桌子摆好，闹钟定好，胶凝固了；但一套工具的名词来源也有自己的历史，不能全按一个简单动词故事解释。

- **基本词及设置者**：set · setter
- **重设、偏移与状态**：reset · preset · upset · offset · inset · onset · outset
- **日落、心态与设备**：sunset · mindset · handset · headset
- **曲目、工具及其他组合**：setlist · chipset · toolset · ruleset · subset · superset · playset · typeset
- **setting：放置、设定与安排好的环境**：set · setting
- **setup：把东西安排就位后的整体**：set · setup
- **set → sets：使就位、固定与一套**：set · sets
- **setting → settings：安置后的环境与配置**：set · setting · settings
- **set 的成套设备义进入 headset**：set · headset · headsets
- **reset 的重新设定：s 与双写 t 的 ing**：reset · resets · resetting
- **set 的一组材料义进入 dataset**：set · dataset · datasets
- **handset → handsets：手持电话部件、装置**：handset · handsets
- **set 的排好字模义进入 typeset**：typeset · typesets · typesetting · typesetter · typesetters
- **upset 的打乱、心烦与意外结果复数**：upset · upsets · upsetting

## 词形与演化规律

set、setter 先讲基本动作和执行者；reset、preset、upset、offset、inset、onset、outset 按各自整词意义学习。sunset、mindset 作意象扩展；设备、演出和集合再分 handset、headset、setlist、chipset、toolset、ruleset、subset、superset、playset、typeset。

set 双写 t 加 -ing；场景、设置、镶座等名词义抓住某物被安置在何种环境或状态中，不假定每项义都同一天形成。

setup 从 set up 设立、安排、装配的短语名词化，现代说配置、安排及设下的圈套等；不把名词直接当分写动词。

动词继承本族使坐定材料，集合名词有旧名词及可能法语背景，不硬画单线。

set 双写 t 加 ing，名词发展场景、配置、镶座等，再加复数。

不是动作放置义直接逐字相加。

过去式与过去分词仍为 reset；resetting 是进行形式，末尾 t 双写。

一组按某个目的收集的数据，组成现代数据用语。

set 取一套装置的名词用法。

typeset 不规则过去仍为 typeset；进行形式双写 t，人物名可按 typeset 加 er 认识。

up 与 set 的组合经历不同历史义；现代动词三单与名词复数同写 upsets，重音有别。

## 逐词讲解

<a id="w-1"></a>

### 1. set — 放置；设定；凝固；固定的；一套、集合、场景

**音标**：/set/

**先抓住这个画面**

动词先抓“让它就位”：摆好杯子、定好时间，材料也能固定成形。

**怎么拆**

动词接古英语 settan，与 sit 的使动词历史相连，可理解为使坐定、使就位。集合等名词有旧英语名词及可能法语影响等不同历史分析，不把所有现代义硬画成一个英语动词新派生。

**怎么变成今天的意思**

**古英语 settan → 中古英语 setten**  
使就位、放置；与 sit 的历史词族相连

↓

**英语 set**  
设定、放置；固定的；一套、场景等名词义

set the alarm 是设闹钟，set a date 是定日期，the glue sets 是胶凝固。a set of keys 是一串钥匙，a film set 是片场布景，all set 是准备好了；set 的过去式、过去分词仍为 set。

**常见搭配与例句**

set a date；set the table；set an example；a set of；be all set。

> Please set the alarm for seven.

请把闹钟设到七点。

> Give the glue time to set.

给胶一些凝固时间。

> The box contains a set of drawing pencils.

盒里装着一套绘画铅笔。

**别混淆**

put、set 都可放置，set 更常出现在固定安排、设定等搭配。set an example 是树立榜样，不是随意把例子放某处。

<a id="w-22"></a>

### 2. setting — 环境、背景、场景；设置；镶座；set 的 -ing 形式

**音标**：/ˈsetɪŋ/

**先抓住这个画面**

把故事放在什么地方、把机器调到什么档，都是给东西安置一个位置或状态。setting 可以是周围场景，也可以是设定好的选项。

**怎么拆**

set 双写 t 加 -ing；动词上接古英语 settan 使就位。名词逐渐用于安置的环境、安排的状态，以及把宝石固定住的镶座等。

**怎么变成今天的意思**

**古英语 settan → set**  
使就位、摆放；设定

↓

**set + -ing → setting**  
安置过程；环境、设置、镶嵌结构

the setting of a story 故事背景；a rural setting 乡村环境；change the settings 更改设置；a low heat setting 低温档；a diamond setting 钻石镶座。

**常见搭配与例句**

a beautiful setting；privacy settings。

> The village provides the setting for the novel.

小说以这个村庄为背景。

> Check the volume setting before playing the recording.

播放录音前检查一下音量设置。

> She opened the privacy settings on her phone.

她打开了手机的隐私设置。

**别混淆**

setting 作为背景常看故事发生的时地环境；plot 看情节怎样推进。手机 settings 常用复数，因为里面有多项选项。

<a id="w-25"></a>

### 3. settings — 设置、配置项；场景、环境；餐具摆设、镶座等〔复数〕

**音标**：/ˈsetɪŋz/

**先抓住这个画面**

把东西安放在某种位置、状态，就有 setting。软件里是设好的选项，故事里是安放人物的环境，餐桌上也能是一人一套摆好的餐具。

**怎么拆**

set 双写 t 加 -ing → setting，再加 -s，/ŋ/ 后读 /z/。set 接古英语 settan 使就位，名词再发展出环境、状态、镶座等分支。

**怎么变成今天的意思**

**古英语 settan → set；set + -ing → setting**  
使就位 → 安置后的状态、环境或固定装置

↓

**setting + -s → settings**  
多项配置、多种场景或多套餐具等

change the settings 更改设置；different settings 不同环境、配置；place settings 餐桌上每人一份的餐具摆设。

**常见搭配与例句**

camera settings 相机设置；urban and rural settings 城市和乡村环境。

> You can change the language in the settings.

你可以在设置里更改语言。

> The study compared learning in different classroom settings.

研究比较了不同课堂环境中的学习。

**别混淆**

settings 页面通常是配置项；故事研究中的 settings 多说场景。动词 set 的过去式仍是 set，settings 是由名词 setting 再形成的复数。

<a id="w-24"></a>

### 4. sets — 套、组；集合〔复数〕；放置、设定、落下等〔第三人称单数〕

**音标**：/sets/

**先抓住这个画面**

把东西安排到一个确定位置或状态，是 sets 的动作线索；搭配好的几件东西是一套，名词便有 sets。太阳落下、把时间定下，也都有固定用法。

**怎么拆**

set + -s，/t/ 后读 /s/。动词继承古英语 settan，使坐定、使就位，与 sit 是较早使动关系；集合名词有旧英语名词及可能法语影响等不同分析，不把所有名词义都强归为现代动词新派生。

**怎么变成今天的意思**

**古英语 settan → 动词 set；集合名词另有历史分析**  
使就位、安排；一套一组的名词义

↓

**set + -s → sets**  
多套、多组；单数主语设定、放置或落下

sets of tools 几套工具；sets the time 设定时间；sets the table 摆餐具；the sun sets 太阳落下。

**常见搭配与例句**

two sets of keys；sets a date for the visit。

> The room has two sets of keys.

这个房间有两套钥匙。

> She sets the table before dinner.

她晚饭前摆好餐具。

> The sun sets behind the hills.

太阳在山丘后落下。

**别混淆**

set 的过去式、过去分词仍是 set。sets 可以是一套套名词，也可是他、她、它进行设定的动词，先找主语和后面的对象。

<a id="w-23"></a>

### 5. setup — 安排、配置；装配、设置过程；整套装置；圈套、设计好的局

**音标**：/ˈsetʌp/

**先抓住这个画面**

桌子、设备、人员怎样摆好，形成一套能运作的安排，就是 setup。若这套安排专为引人上当，也能说 a setup。

**怎么拆**

由 set up 放置、设立、安排的短语名词化。set 的使就位、设定线与 up 的建立、达到状态等用法结合，后来固定为安排、配置、布置好的局面。

**怎么变成今天的意思**

**set up**  
使就位；设立、装配、安排

↓

**名词 setup**  
安排好的整体；设置过程；有意设下的局

a simple setup 简单配置；the initial setup 初始设置；a recording setup 录音设备配置；the office setup 办公布局、工作安排；It was a setup 那是个圈套。

**常见搭配与例句**

a new setup；the setup process。

> The initial setup took less than an hour.

初始设置用了不到一个小时。

> The new office setup gives everyone more space.

新的办公安排给每个人留出了更多空间。

**别混淆**

名词常合写 setup，动词用 set up：The setup is simple；We set up the equipment。set 的过去式仍是 set，不是 setted。

<a id="w-12"></a>

### 6. setter — 设置、出题的人；塞特猎犬

**音标**：英 /ˈsetə/；美 /ˈsetər/

**先抓住这个画面**

人把题目、趋势或标准先设出来；狗的品种名则与发现猎物后的特定姿态相关。

**怎么拆**

set + -er，接中古英语 settere。人物义按设置动作理解；猎犬义源于 set 的停住、摆出姿态用法，不是狗会替人出题。

**怎么变成今天的意思**

**古英语 settan → 中古英语 setten**  
使就位、放置；与 sit 的历史词族相连

↓

**英语 set**  
设定、放置；固定的；一套、场景等名词义

↓

**set + -er → setter**  
设置者；猎犬名称取其特定姿态

an exam setter 是出题者，a trend setter 是引领潮流者；an Irish setter 是爱尔兰塞特犬。普通岗位常把具体任务加在前面。

**常见搭配与例句**

an exam setter；a trend setter；an Irish setter。

> The exam setter included several practical questions.

出题者加入了几道实践题。

> An Irish setter ran across the field.

一只爱尔兰塞特犬跑过田野。

**别混淆**

setter 表设置者或特定犬种，sitter 常是坐着的人、照看者；中间元音不同，来源虽有关联，现代不能混。

<a id="w-14"></a>

### 7. setlist — 演出曲目单

**音标**：/ˈsetlɪst/

**先抓住这个画面**

一场表演要唱哪些歌、按什么顺序，先写成一张清单。

**怎么拆**

set（一次演出的一组曲目、节目）+ list（清单）；不是电脑设置菜单的通用名称。

**怎么变成今天的意思**

**英语 set〔一组演出曲目〕；list**  
并列组合的两部分

↓

**set〔一组演出曲目〕 + list → setlist**  
一场表演计划演出的曲目清单

change the setlist 是调整曲目单，a printed setlist 是打印出的演出歌单。实际现场也可能临时改动，不保证纸上内容每首都照演。

**常见搭配与例句**

the concert setlist；change the setlist；a printed setlist。

> The band added two new songs to the setlist.

乐队把两首新歌加入演出曲目单。

> A printed setlist lay beside the microphone.

麦克风旁放着一张打印的演出曲目单。

**别混淆**

playlist 是播放列表更泛，setlist 常对应一次现场表演安排；听歌软件里的清单不都叫 setlist。

<a id="w-2"></a>

### 8. upset — 使难过；心烦的；打乱；意外胜利

**音标**：动、形 /ʌpˈset/；名 /ˈʌpset/

**先抓住这个画面**

本来稳妥的安排、心情被翻乱；比赛里也能把原定强弱局面掀翻。

**怎么拆**

up- + set，早期有设立、竖起等用法，后来发展出翻倒、打乱及情绪义；up- 在整词里不能固定只翻成向上。

**怎么变成今天的意思**

**古英语 settan → 中古英语 setten**  
使就位、放置；与 sit 的历史词族相连

↓

**英语 set**  
设定、放置；固定的；一套、场景等名词义

↓

**up- + set → upset 的早期用法**  
设起等用法，后来有翻倒、扰乱义

↓

**英语 upset**  
打乱状态；心烦；意外结果

be upset about the news 是因消息难过，upset the schedule 是打乱日程；a major upset 是冷门胜利。过去式仍是 upset，重音随常用词性变化。

**常见搭配与例句**

be upset about；upset the balance；cause an upset；an upset stomach。

> She was upset about the cancelled trip.

旅行取消让她很难过。

> The underdogs caused a major upset in the final.

不被看好的一方在决赛中爆冷获胜。

**别混淆**

upset 情绪义比 angry 更宽，可以悲伤、担忧或生气；an upset 名词在赛事里又可能是弱者获胜，不能一律译成难过。

<a id="w-36"></a>

### 9. upsetting — 令人难过、不安的；打乱、弄翻；upset 的 -ing 形式

**音标**：/ʌpˈsetɪŋ/

**先抓住这个画面**

消息把心情搅乱，事情让人难以平静，就可以叫 upsetting。前面的事物是引起不安的原因。

**怎么拆**

upset + -ing，词末重读短元音后的 t 在这一形式中双写。upset 由较早的翻动、弄翻等物理用法，扩展到打乱情绪。

**怎么变成今天的意思**

**upset 的翻乱、扰动词族**

↓

**upset + -ing → upsetting**  
令人不安的；正在扰乱、弄翻

**常见搭配与例句**

> The news was deeply upsetting.

这个消息令人十分难过。

> She found the scene too upsetting to watch.

她觉得那一幕太令人难受，看不下去。

**别混淆**

upset 常说人已经难过、不安；upsetting 常评价使人不安的事。I am upset 与 The news is upsetting 分别落在人和原因上。

**古英语 insettan → 中古英语 insetten → inset**  
置入、嵌入；嵌入的部分

a map inset 是地图中的小附图，a glass inset 是嵌入的玻璃片；也可作动词。set 过去形式相同的关系也体现在 inset 上。

**常见搭配与例句**

an inset map；a glass inset；an inset panel。

> An inset map shows the island’s location.

一幅小附图标出岛屿位置。

> The door has a decorative glass inset.

门上嵌着一块装饰玻璃。

**别混淆**

inset 是整体内部另嵌入一块，insert 是插入动作或插入物更泛；相似不等于所有搭配都可替换。

### 26. chipset — 芯片组

**音标**：/ˈtʃɪpset/

**先抓住这个画面**

不是单独看一块芯片，而是看配合完成系统功能的一组芯片或相关控制功能。

**怎么拆**

chip（集成电路芯片）+ set（一组），由配套芯片组合命名。后来功能可集成进更少器件，名称不严格保证每个年代都有同样数量实体芯片。

**怎么变成今天的意思**

**英语 chip；set〔一组〕**  
并列组合的两部分

↓

**chip + set〔一组〕 → chipset**  
配套协作的芯片、控制功能组合

主板、手机等硬件介绍常见，具体包含哪些功能随产品架构变化。词义先抓一组协作控制，不把 chipset 与整个电脑画等号。

**常见搭配与例句**

a motherboard chipset；chipset features；chipset compatibility。

> The manual lists the motherboard’s chipset.

手册列出了主板采用的芯片组。

> The driver supports several chipsets.

该驱动支持几种芯片组。

**别混淆**

chip 可以是单个器件，chipset 强调配套功能组合；CPU 是处理器这个角色，不总等于整套 chipset。

### 27. playset — 成套玩具；组合游乐设施

**音标**：/ˈpleɪset/

**先抓住这个画面**

不是只有一件玩具，而是一组能一起构成场景或玩法的组件。

**怎么拆**

play（游戏）+ set（成套物件），指成套玩具，也可指带滑梯等的户外组合设施。

**怎么变成今天的意思**

**英语 play；set**  
并列的构词材料

↓

**play + set → playset**  
供游戏的一套组件或设施

a farm playset 可有农场、动物等配件；an outdoor playset 可有秋千滑梯。set 说明组合，不保证具体件数。

**常见搭配与例句**

a toy playset；an outdoor playset；a castle playset。

> The child arranged the animals from the farm playset.

孩子摆放着农场玩具套装里的动物。

> They installed a wooden playset in the garden.

他们在花园装了一套木制游乐设施。

**别混淆**

playset 是成套玩具或设施，playlist 是播放清单；set 与 list 在此决定物理组件和媒体项目的区别。

### 28. typeset — 排版；用字模或软件编排文字；已排版的

**音标**：/ˈtaɪpset/

**先抓住这个画面**

把一串文字变成准备呈现在页面上的行和段，安排它们的位置与间隔。

**怎么拆**

英语 type 印刷字模 + set 放置、排好；由摆放字粒走到数字文字排版。过去式和过去分词也是 typeset。

**怎么变成今天的意思**

**古希腊 typtein / typtō → typos**  
敲击 → 打出的印记；形状、样式

↓

**拉丁 typus → 中古英语 type → 英语 type**  
形象、象征 → 类型；印刷字模；后有打字动词

↓

**英语 type + set → typeset**  
排列印刷字模 → 编排文字版面

typeset a book 是排一本书的版，不只是把内容键入电脑。电子排版仍需处理换行、字距、页边距等细节。

**常见搭配与例句**

typeset a manuscript；professionally typeset；typeset text。

> The publisher hired a specialist to typeset the book.

出版社聘请了一位专业人员为这本书排版。

> The equations were carefully typeset to avoid ambiguity.

这些公式经过仔细排版，以免产生歧义。

**别混淆**

type 是输入文字；typeset 是把文字组织成可呈现的版面。

<a id="w-32"></a>

### 29. typesetting — 排字、排版；正在排版

**音标**：/ˈtaɪpsetɪŋ/

**先抓住这个画面**

文字已经有了，再把字、行、段落在页面里排好，这项工作叫 typesetting。

**怎么拆**

type + set → typeset，再双写 t 加 -ing。旧时排字粒，数字时代也保留排版这个用途。

**怎么变成今天的意思**

**type + set → typeset**  
放好字模、排字

↓

**typeset + -ing → typesetting〔双写 t〕**  
排版工作、进行动作

digital typesetting 数字排版；typesetting a book 给书排版。

**常见搭配与例句**

good typesetting 好的版面安排；finish typesetting 排版完。

> The book is ready for typesetting.

书稿已经可以交付排版。

> She was typesetting the poetry collection.

她正在给诗集排版。

**别混淆**

typing 是输入文字，typesetting 是安排文字呈现；打出内容以后还可以继续排版。

<a id="w-33"></a>

### 30. typesetter — 排字员、排版人员；排版设备或工具

**音标**：英 /ˈtaɪpsetə/；美 /ˈtaɪpsetər/

**先抓住这个画面**

把字安排到页面该在的位置，形成能印、能读的版面，做这项工作的人或工具叫 typesetter。

**怎么拆**

type 印刷字模 + setter 排放者，也可现代对应 typeset + -er。setter 中 set 双写 t 加完整 -er。

**怎么变成今天的意思**

**type + set → typeset；type + setter → typesetter**  
排好字模；执行排字、排版的人或工具

↓

**数字排版场景扩展**  
也可指软件排版工具

a professional typesetter 专业排版人员；a digital typesetter 数字排版工具。

**常见搭配与例句**

work as a typesetter 做排字工作；send to the typesetter 交给排版人员。

> The typesetter arranged the poem on the page.

排版人员在页面上安排了这首诗。

> The publisher sent the manuscript to a typesetter.

出版社把稿件交给了排版人员。

**别混淆**

typist 是打字人员，typesetter 着重字在版面里的安排；实际工作可能重叠，名称焦点不同。

### 31. typesetters — 排字员、排版人员或工具〔复数〕

**音标**：英 /ˈtaɪpsetəz/；美 /ˈtaɪpsetərz/

**先抓住这个画面**

多位负责把文字安排成版面的人，或多种执行这项功能的工具，就是 typesetters。

**怎么拆**

typesetter + -s，读 /z/；type 字模 + setter 排放者，setter 内有完整 -er。

**怎么变成今天的意思**

**type + setter → typesetter**  
按排字、排版作用命名

↓

**typesetter + -s → typesetters**  
多个排字人员、工具

experienced typesetters 有经验的排字员；digital typesetters 数字排版工具。

**常见搭配与例句**

the typesetters’ work 排版人员的工作；train typesetters 培训排字员。

> The typesetters checked the spacing between the lines.

排版人员检查了行间距。

> The exhibition showed the tools used by early typesetters.

展览展示了早期排字员使用的工具。

**别混淆**

词尾 er 可给人也可给工具起名；这里指哪一种，由对象、时代、工作背景决定。

软件把公式排得很整齐。

### 34. superset — 超集；超级组〔健身〕

**音标**：英 /ˈsuːpəset/；美 /ˈsuːpərset/

**先抓住这个画面**

集合里是一个把另一集合全部成员包进去的集合；训练里则把两组动作紧接着做，像合成一个更大的组。

**怎么拆**

英语 super- + set。集合义用“上一级、包含”的 super-；训练义用组合加强的意思。

**怎么变成今天的意思**

**拉丁 super**  
在上方、超过、越过

↓

**英语构词成分 super-**  
超出一般程度；在上、额外或超过某界限

↓

**英语 super- + set → superset**  
包含另一集合的集合；连续完成的训练组

数学中 A 是 B 的超集，意思是 B 的每个元素都在 A 中；A 可以等于 B，真超集才排除相等。健身的 superset 通常指两组动作之间不休息或仅短暂停顿。

**常见搭配与例句**

a superset of；a proper superset；perform a superset。

> The set of real numbers is a superset of the integers.

实数集是整数集的超集。

> She paired the two exercises in a superset.

她把这两个动作组合成一个超级组。

**别混淆**

subset 从被包含的一方说；superset 从包含者的一方说。不要把“超”误当成必须多一个元素。

### 36. dataset — 数据集

**音标**：/ˈdeɪtəset/〔data 另有 /ˈdɑːtə/、/ˈdætə/ 等读法〕

**先抓住这个画面**

为了一个问题，把有关的数据收成一组，像把同一次调查的答卷装进同一份材料包，这一组就是 dataset。

**怎么拆**

data 数据 + set 一组的现代英语组合。data 原是拉丁 datum 的复数，英语又可把它作为整体资料使用。

**怎么变成今天的意思**

**拉丁 datum → data；英语 set 的集合义**  
给出的资料；一组材料

↓

**data + set → dataset**  
按某种范围、目的形成的一组数据

a training dataset 训练数据集；a survey dataset 调查数据集。

**常见搭配与例句**

a dataset of measurements 一组测量数据；analyse a dataset 分析数据集。

这个数据集包含五十家农场的测量结果。

我们用一个较小的数据集测试方法。

### 37. datasets — 数据集〔复数〕

**音标**：/ˈdeɪtəsets/〔data 的其他读法也可带入〕

**先抓住这个画面**

不同调查、不同范围各收成一组数据，多组就叫 datasets。组与组可以比较，也可以按研究目的合并。

**怎么拆**

data + set → dataset，加 -s，/t/ 后读 /s/。data 内部的历史复数与整个组合的现代复数是不同层次。

**怎么变成今天的意思**

**data + set → dataset**  
一组有边界、用途的数据

↓

**dataset + -s → datasets**  
多个数据集

compare datasets 比较数据集；public datasets 公开数据集。

**常见搭配与例句**

combine datasets 合并数据集；large datasets 大型数据集。

> The website offers several public datasets.

网站提供几个公开数据集。
